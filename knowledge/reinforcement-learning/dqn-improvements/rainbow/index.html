前六个子页各讲一项改进。本页是专题的收尾，不重讲任何一项的机理，只回答论文摘要提出的那个问题：

社区对 DQN 做了若干各自独立的改进。但尚不清楚这些扩展中哪些是互补的、可以被富有成效地组合起来。

Rainbow 的价值因此不在「性能更强」，而在它做了一次系统的消融——回答了哪几项真正有贡献、哪几项在组合中变得可有可无，以及一些与单项论文结论并不一致的地方。

本页重点。必须精读的是两节：「组合时的互相适配」——各组件不是简单堆叠，放在一起时都要改，其中 PER 改用 KL 损失作优先级最值得注意；「消融说明了什么」——给出完整排序，并澄清一条广为流传但机制被说错的结论。

本页不重复任何单项的推导。每一项的完整展开见对应子页，正文中会逐处给出链接。

六项改进各自解决什么

论文引言用一句话概括了每一项针对的问题。这张表同时也是本专题的索引。

改进 它针对的问题（论文原述）
Double DQN 处理 Q-learning 的过估计偏差，做法是解耦自举动作的选择与评估
优先经验回放 改善数据效率，更频繁地重放那些可学到更多的转移
Dueling 网络 通过分别表示状态价值与动作优势，帮助在动作之间泛化
多步自举目标 移动偏差-方差权衡，并帮助把新观察到的奖励更快传播到更早访问的状态
分布式 Q-learning 学习折扣回报的类别分布，而不是估计其均值
Noisy DQN 用随机网络层来做探索

各项链接：过估计与 Double、Dueling 分解、优先经验回放、多步回报、分布式与 C51、NoisyNet。

论文给出的组合理由是两条：这些算法各自解决的是截然不同的问题，而且它们建立在同一套框架之上，因此看起来是可以合并的。此前已有部分组合的先例（例如 Prioritized DDQN 与 Dueling DDQN 都用了 double Q-learning）。

组合时的互相适配

这是本页独占的内容，也是最容易被忽略的一节：六项改进放在一起时，每一项都要做改动，不是简单叠加。

多步与分布式：收缩再平移

先把 1 步的分布式损失换成多步变体。目标分布的构造方式是：把 \(S_{t+n}\) 处的值分布按累积折扣收缩，再按截断 \(n\) 步折扣回报平移：

\[d_t^{(n)} = \Big( R_t^{(n)} + \gamma_t^{(n)} \bm{z}, \; \bm{p}_{\bar\theta}\big(S_{t+n}, a^{*}_{t+n}\big) \Big)\]

损失仍是投影后的 KL：

\[D_{\mathrm{KL}}\Big( \Phi_{\bm{z}}\, d_t^{(n)} \;\big\|\; d_t \Big)\]

其中 \(\Phi_{\bm{z}}\) 是投影到支撑 \(\bm{z}\) 上的算子（见子页⑤）。

注意「收缩加平移」这个说法的含义：\(n\) 步的效果作用在支撑位置上——原子位置被乘以 \(\gamma^{(n)}\) 再加上 \(R^{(n)}\)，而概率本身不动。这正是分布视角下「回报变了」的正确表达方式。

Double：嵌在自举动作的选取里

多步分布式损失与 double Q-learning 的结合方式是：用在线网络在 \(S_{t+n}\) 上选出的贪心动作作为自举动作 \(a^{*}_{t+n}\)，再用目标网络去评估它。这与子页①的解耦是同一件事，只是被搬进了分布式的框架。

PER：改用 KL 损失作优先级

标准的比例式优先经验回放用绝对 TD 误差作优先级。在分布式设定下这仍然算得出来（用均值动作值），但 Rainbow 没有这么做：

\[p_t \;\propto\; \Big( D_{\mathrm{KL}}\big( \Phi_{\bm{z}} d_t^{(n)} \,\|\, d_t \big) \Big)^{\omega}\]

论文的理由是：这正是算法在最小化的那个量。并给出了一条更深的观察——

用 KL 损失作优先级，可能对含噪的随机环境更鲁棒，因为即使回报不是确定性的，这个损失仍然可以继续下降。

这一点值得对照着想：TD 误差在回报本身随机时不会降到零，于是那些「回报天生就抖」的转移会被永久地判为高优先级、被反复重放。而分布式损失衡量的是「预测的分布与目标分布差多少」，回报的随机性可以被分布本身吸收掉，损失仍能收敛。

Dueling：在每个原子上聚合，再过 softmax

网络采用适配了回报分布的 dueling 架构：共享表示 \(\phi = f_\xi(s)\)，送入有 \(N_{\text{atoms}}\) 个输出的价值流 \(v_\eta\)，以及有 \(N_{\text{atoms}} \times N_{\text{actions}}\) 个输出的优势流 \(a_\psi\)。对每个原子 \(z^i\) 按 dueling DQN 的方式聚合价值与优势，然后过一个 softmax 层得到归一化的概率：

\[p^i_\theta(s, a) = \frac{\exp\big( v^i_\eta(\phi) + a^i_\psi(\phi, a) - \bar{a}^i_\psi(s) \big)}{\sum_j \exp\big( v^j_\eta(\phi) + a^j_\psi(\phi, a) - \bar{a}^j_\psi(s) \big)}, \qquad \bar{a}^i_\psi(s) = \frac{1}{N_{\text{actions}}} \sum_{a'} a^i_\psi(\phi, a')\]

减均值的形式被完整保留（理由见子页②），只是现在它作用在每个原子上，且最后多了一层 softmax 把结果归一化成分布。

NoisyNet：替换全部线性层

最后，把所有线性层都替换成噪声版本，其中使用因子化高斯噪声（见子页⑥）。

观察 说明
\(\varepsilon = 0\) 用了 NoisyNet 之后，论文完全贪心地行动，探索全部交给噪声层

论文对调参过程是坦白的：超参数的组合空间过于庞大，无法穷举搜索，因此他们只做了有限的调优——对每个组件从引入该组件的那篇论文所用的取值出发，再用手动坐标下降去调其中最敏感的几个。

另有一条很实用的脚注：噪声是在 GPU 上生成的，而 TensorFlow 在 GPU 上生成噪声可能不可靠；若改在 CPU 上生成，把 \(\sigma_0\) 降到 0.1 可能会有帮助。

消融说明了什么

消融的做法是：每次从完整的 Rainbow 中移除一个组件，看中位归一化分数掉多少。

条形长度只表示论文描述的相对影响程度，不是按论文图表数值等比绘制。两条与单项论文结论不一致之处值得留意：Dueling 与 Double 在组合中都变得可有可无——而它们各自的原论文都报告了明显收益。这说明「某项改进有没有用」这个问题，在不同的组合背景下答案可以不同。

最关键的两项：优先回放与多步回报

优先经验回放与多步学习是 Rainbow 最关键的两个组件，移除其中任何一个都会造成中位性能的大幅下降。

两条细节：

  • 移除任一都会损害早期性能，这不意外；
  • 更令人意外的是，移除多步学习也损害了最终性能。
  • 逐游戏看，两个组件几乎在所有游戏上都有帮助：完整 Rainbow 在 57 个游戏中的 53 个上优于这两种消融变体。

分布式 Q-learning：作用出现得晚

它的重要性紧随前两者之后，但时间特征很特别：

在早期学习中看不出差别——前 4000 万帧里，去掉分布式的变体表现得与完整智能体一样好。但在那之后，没有分布的智能体开始落后。

按人类水平分层看，分布式消融主要在达到或超过人类水平的那些游戏上落后。

NoisyNet：总体有利，但并非普遍

以中位性能计，包含 NoisyNet 时更好；把它去掉、探索交回传统的 \(\varepsilon\)-贪心之后，总体表现更差。但逐游戏看：移除 NoisyNet 在若干游戏上造成大幅下降，同时也在另一些游戏上带来小幅提升。

Dueling：总体无显著差别

总体上，从完整 Rainbow 中移除 dueling 网络并未观察到显著差别。

但论文提醒中位数掩盖了分游戏的差异：Dueling 也许在超过人类水平的游戏上带来了一些改善，而在低于人类水平的游戏上造成了一些退化。

Double：影响有限，但机制常被说错

这是本页最需要讲准的一条。

事实部分：在中位性能上，移除 double Q-learning 的差别同样有限，该组件时而有害、时而有益，取决于具体游戏。

机制部分——论文做了一步额外的检查，把训练好的智能体的预测与由裁剪奖励算出的实际折扣回报作比较：

论文的观察是：实际回报常常高于 10，因而落在分布支撑（从 −10 到 +10）之外。这导致的是回报被低估，而不是被高估。论文由此提出一个假设：把值裁剪到这个受限范围，抵消了 Q-learning 的过估计偏差。

并且论文紧接着给出了适用边界：如果把分布的支撑范围扩大，double Q-learning 的重要性可能会上升。

因此，「在 Rainbow 里 Double 没用，是因为分布式学习本身消除了过估计」这个流传较广的说法并不准确。准确的表述是三层：

其一，起作用的是支撑有界这个事实（\([-10, 10]\) 的截断），而不是「学分布」本身；
其二，论文用的是假设（hypothesize）的措辞，不是已证结论；
其三，论文明确说扩大支撑后 Double 的重要性可能回升——也就是说这个「没用」是特定配置下的现象，不是普遍结论。

过估计本身的机理见子页①，分布支撑的设定见子页⑤。

数据效率

论文强调组合带来的提升同时体现在数据效率与最终性能两方面。以 57 个游戏的中位人类归一化性能计：

专题收尾

到这里，DQN 改进专题的七个子页齐了。把它们放在一起看，有三条贯穿性的判断：

  1. 各项改进针对的是不同层面。 目标值构造（Double）、网络结构（Dueling）、采样分布（PER）、回报构造（多步）、学习对象（分布式）、探索方式（NoisyNet）——正因为彼此正交，才谈得上组合。
  2. 组合不是叠加。 放在一起时每一项都要改：PER 的优先级换成 KL 损失、Dueling 的聚合搬到每个原子上、Double 嵌进自举动作的选取、超参需要重调（如 \(\omega\) 从 0.6 改为 0.5）。
  3. 单项论文的结论不能直接搬到组合里。 Dueling 与 Double 各自的原论文都报告了明显收益，而在 Rainbow 的消融中两者都变得可有可无。「这项改进有没有用」这个问题，离开了具体的组合背景就没有确定答案。

后续方向（本专题不展开）：沿分位数参数化的 QR-DQN 与 IQN 换了一条路来做分布式；R2D2 与 Ape-X 则把重点移到了分布式采集与循环网络上。

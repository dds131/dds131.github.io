DDPG 的损失可以平滑下降，策略却同时变差。原因在于两个 loss 都依赖可学习 Critic： Critic 拟合的是 bootstrap target，Actor 最大化的是 Critic 预测，而最终关心的是环境回报。 三个量相关，却不等价。本页不提供“一看到某种曲线就断言某个原因”的速查口诀， 而是把现象变成可证伪假设。

诊断原则。先核对环境和 transition 语义，再检查 Critic 校准，再看 Actor 是否利用误差， 最后调耦合超参数。直接从“回报下降”跳到“减小学习率”会把动作缩放、终止掩码、 wrapper 或数据覆盖错误埋在更慢的训练里。

一、四层诊断顺序

flowchart TD
  P["策略表现异常"] --> E{"环境与数据语义正确？"}
  E -->|"否"| E1["修复 observation / action / reward<br/>termination / reset / wrapper"]
  E -->|"是"| C{"Critic 对真实回报校准？"}
  C -->|"否"| C1["检查 target、reward scale、UTD<br/>覆盖、bootstrap 与 Q 分布"]
  C -->|"是"| A{"Actor 动作合理且有支持？"}
  A -->|"否"| A1["检查 dQ/da、tanh、scale/bias<br/>饱和率与局部支持代理"]
  A -->|"是"| U["检查两时间尺度、target 滞后<br/>噪声、seed 与训练预算"]

1.1 环境与数据层

优先确认：

  • 观测是否包含做出 Markov 决策所需的信息；
  • 动作 scale / bias、控制频率和实际执行动作；
  • reward 的符号、尺度与 wrapper；
  • terminated、truncated、reset 与 final observation；
  • 训练和评估是否使用相同观测与动作预处理。

1.2 Critic 层

观察 Q、target Q、TD error、梯度范数和对实际折扣回报的校准。Critic loss 是内部一致性， 不是外部准确性。留出 replay 上的 TD error 仍使用自举标签，只能帮助发现拟合差距， 不能单独证明 Q 对真实环境回报准确。

1.3 Actor 层

观察动作分布、pre-tanh logit、饱和率、\(\lVert\nabla_aQ\rVert\)， 以及 Actor 动作相对 replay 行为动作的近邻距离、偏差分位数等局部支持代理。 高维连续空间的真实密度很难可靠估计，不能把某个近邻分数直接当作概率密度。 Actor 可能正确地最大化了一个错误 Critic。

还要记录动作梯度采用的坐标系。若物理动作满足 \(a=\mathrm{bias}+\mathrm{scale}\odot u\)，则

\[\nabla_u Q = \mathrm{scale}\odot\nabla_a Q.\]

\(\nabla_aQ\) 的每一维带有“回报 / 物理动作单位”的量纲；仅仅改变关节量程或单位就会改变其范数， 并不表示 Critic 的几何关系发生同样幅度的变化。跨动作维、任务或实现比较时，应同时报告逐维 \(\nabla_aQ\)、动作 scale 与规范化坐标下的 \(\nabla_uQ\)，不要把一个未注明单位的总范数当作通用阈值。

1.4 耦合与实验层

最后才调整 Actor / Critic 学习率、更新数据比、target 速度、噪声和网络规模； 同时用多种子和独立评估判断变化是否超出随机波动。

二、Critic loss 下降，但真实回报没有提高

2.1 为什么不矛盾

Critic 最小化

\[\mathbb E\left[(Q_\phi-y)^2\right],\]

其中 \(y\) 也来自目标网络。若 target 持续有偏，Critic 可以越来越准确地拟合偏置标签。 训练 MSE 下降只说明“当前 Q 与当前 target 更一致”。

2.2 候选原因

  1. target Q 已经高估或低估；
  2. terminated / truncated 掩码错误；
  3. reward scale 很小，使 loss 的绝对数值看似很小，掩盖相对误差；它本身不必然造成动作排序错误；
  4. UTD 过高，Critic 记住有限 replay；
  5. Actor 动作落在 buffer 覆盖外，Critic 训练 loss 不包含这些动作；
  6. shape 广播使 loss 实际比较了 \(B\times B\) 对。

2.3 验证实验

  • 划出不参与梯度更新的固定 replay 子集，分别记录训练 TD error 与 held-out TD error； 该对照检测拟合差距，但 target 仍会随目标网络变化，不能当作外部真值。
  • 在可克隆/恢复模拟器状态或可控初始状态的环境中，执行当前策略 rollout，计算 H 步自举回报 \(G_t^{(H)}=\sum_{k=0}^{H-1}\gamma^k r_{t+k}+\gamma^H\hat V(s_{t+H})\)， 与预测 Q 比较。它含估计尾值，不是纯 Monte Carlo；若 rollout 到真实终止且不加尾值， 才得到完整样本回报。随机环境还需对同一状态—动作做多次 rollout 估计期望。
  • 冻结 Actor，只训练 Critic；若 Q 仍无界漂移，问题不来自最新 Actor step。
  • 加 shape 断言；统计 terminated / truncated 的比例和边界处 target。
校准比 loss 绝对值更重要。若真实折扣回报为 −100，预测从 1000 降到 900， MSE 可能下降，但策略依据的价值方向仍然严重错误。

三、Q 值不断变大，动作表现却变差

3.1 Actor 会主动寻找正误差

把训练随机性视为对 Critic 估计误差的随机化，设

\[\hat Q(s,a)=Q^\mu(s,a)+\varepsilon(s,a).\]

在动作集合有界、最大值与相关期望存在，并且对每个固定动作都有 \(\mathbb E[\varepsilon(s,a)]=0\) 时，Actor 也不是随机选动作； 它沿 \(\nabla_a\hat Q\) 上升，更可能到达 \(\varepsilon>0\) 的区域。 选择操作打破正负误差抵消：

\[\mathbb E\left[\max_a\left(Q^\mu(s,a)+\varepsilon(s,a)\right)\right] \ge \max_a Q^\mu(s,a).\]

这里的期望针对估计器随机性，不是对一个已经训练完成的固定 Critic 再取平均； 不等式来自“最大值的期望不小于期望的最大值”。它说明选择会产生 optimizer’s curse， 但不是 DDPG 高估幅度的定量定理。实际 Actor 只做局部梯度优化，也未必找到全局最大值。 它仍会主动搜索 Critic 高点，而高点可能是真实高价值，也可能是外推误差峰。

3.2 自举如何放大

高估进入

\[y=r+\gamma Q_{\bar\phi}(s',\mu_{\bar\theta}(s')),\]

下一轮在线 Critic 再拟合这个 target。若偏差持续同向，它沿 Bellman 链传播； 目标网络只减慢传播，不能识别偏差。

3.3 验证实验

  • 记录 deterministic evaluation return 与 Q mean 的散点，而不是只画各自时间序列。
  • 另外训练一个不同初始化、不同 mini-batch 顺序的诊断 Critic，观察两者在 Actor 动作上的分歧。 该分歧只是函数逼近不确定性的代理，不是校准后的置信区间，也不应宣称已实现 TD3。
  • 对 Actor 动作加小扰动，画局部 Q 曲线；极尖且 replay 稀疏的峰值可疑。
  • 用短 rollout 回报与预测 Q 做校准图：按预测 Q 分箱，比较每箱预测均值与经验回报均值。

3.4 Q 量级的 sanity check

若奖励满足 \(|r_t|\le R_{\max}\)、\(0\le\gamma<1\) 且采用无限折扣， 真实价值满足

\[|Q^\mu(s,a)| \le \frac{R_{\max}}{1-\gamma}.\]

学习得到的 Q 远超这个范围是强警告。有限时域还有更紧的几何级数界； reward wrapper 会改变 \(R_{\max}\)，未折扣累计量或不同任务定义也会改变比较口径。 这个量级检查是告警而非正确性证明：落在界内的 Q 仍可能严重失准。

四、Actor loss 越来越负，但回报不增加

Actor loss 为

\[L_\mu=-\mathbb E[Q_\phi(s,\mu_\theta(s))].\]

变得更负意味着当前 batch 上，Critic 对 Actor 动作给出更高预测。由于 Critic 参数和 replay 状态分布都在变化，不同时间的 Actor loss 不在固定标尺上； 它既不是 reward，也不是 policy improvement 保证。

4.1 候选原因

  • Critic 高估，Actor 正在利用它；
  • reward 或 observation normalization 的统计在变化；
  • Actor 只改善 replay 常见状态，对评估初始分布无改善；
  • 动作进入边界，Critic 的局部梯度与实际可执行变化不一致；
  • 评估 wrapper 或动作单位不同。

4.2 必须并排记录

  1. Actor loss；
  2. deterministic evaluation return；
  3. Q 与短 rollout return 的校准误差；
  4. 每维动作饱和率；
  5. \(\lVert\nabla_aQ\rVert\) 与 Actor 参数梯度范数。

只有 Actor loss 改善、其余不改善时，不应继续把它当“学习有效”的证据。

五、动作长期贴在上界或下界

5.1 可能是正确策略

Pendulum 等任务的某些阶段确实需要最大力矩。动作触边本身不是 bug； 要看它是否与状态变化、回报和动力学一致。

5.2 也可能是实现或估计错误

  • 非对称区间误用 max_action * tanh；
  • 噪声按错误物理单位缩放；
  • pre-tanh logit 过大，tanh 梯度消失；
  • reward 鼓励不合理的大控制；
  • Critic 在边界外推为单调上升；
  • clip 率太高，多个不同网络输出变成同一执行动作。

5.3 诊断记录

指标 能区分什么
pre-tanh logit 网络内部饱和还是外部 clip
normalized action Actor 在统一尺度上的分布
pre-clip / executed action 噪声和 clip 的影响
deterministic Actor 的 tanh 饱和率 哪些维的 pre-tanh 过大、tanh 导数接近零
executed action 的 clip 率 哪些维经常触边；它可能来自探索噪声，不等同于 Actor 断梯度
逐维 \(\nabla_aQ\)、动作 scale 与 \(\nabla_uQ\) Critic 是否持续推向边界，并排除物理单位造成的范数差异
动作变化率 贴边但稳定，还是边界间抖动

六、推理动作抖动、近似常数或突然翻转

6.1 抖动

候选原因：

  • 观测含传感噪声，Actor 对局部扰动的 Lipschitz 常数过大；
  • 状态缺少速度或历史，单帧无法区分运动方向；
  • 训练时 OU 噪声的平滑掩盖了确定性 Actor 抖动；
  • 控制频率与训练环境不同；
  • normalization 统计不一致。

验证：固定一段观测序列离线重放，测动作对微小观测扰动的敏感度；同时核对真实系统延迟。

6.2 近似常数

候选原因：

  • Actor 最后层权重几乎为零；
  • tanh 长期在同一饱和端；
  • observation normalization 把不同状态压成近似相同输入；
  • Critic 对动作梯度接近 0；
  • buffer 状态多样性不足。

验证：统计中间激活、pre-tanh logit、动作方差与 \(\nabla_aQ\)。

6.3 突然翻转

候选原因：

  • Critic 局部 Q 曲面存在尖锐峰；
  • 两个近似等价动作的估值排序受小误差改变；
  • 输入跨过 ReLU 分段边界；
  • 归一化统计、控制模式或 wrapper 在 episode 边界改变。

验证：沿两动作之间插值，画 Q 与真实短 rollout 回报；检查 episode/reset 附近日志。

七、训练 return 与评估 return 背离

7.1 训练差、评估好

训练动作含探索噪声，故训练 return 可低于确定性策略。噪声过大或长期不衰减时差距更明显。

7.2 训练好、评估差

可能是噪声偶然纠正了差策略，或训练环境 / wrapper 与评估不一致。也可能评估仍使用训练中的 动态 normalization 统计，却未正确冻结或加载。

7.3 正确协议

  • 独立评估环境；
  • 无探索噪声；
  • 相同 observation/action/reward wrapper；
  • 固定评估 episode 数与 seed 集；
  • 不把评估 transition 写入训练 replay；
  • 同时报告训练步数，而不是只报告墙钟时间。

固定 seed 集便于纵向比较 checkpoint，但它仍是有限测试集。频繁据此调参会形成评估集适配； 最终结果应增加未参与模型选择的 seeds，并把 episode 波动与独立训练 seed 波动分开报告。

八、训练后期突然坍塌

DDPG 的后期坍塌常来自闭环而非单一步骤：

  1. Critic 在数据稀疏动作处出现正误差；
  2. Actor 移向该动作；
  3. 新数据分布改变；
  4. 高估进入 target；
  5. Replay 中旧数据暂时无法纠正新区域；
  6. 策略回报突然下降。

其他候选还包括学习率调度、归一化统计漂移、buffer 覆盖替换、环境随机化阶段改变或 NaN。

8.1 需要保留的检查点

  • 定期保存在线与目标网络、optimizer、replay 指针、归一化统计和 RNG 状态；
  • 坍塌前后比较同一固定状态集的动作与 Q；
  • 不只保存“最终模型”和“最好模型”，否则无法复现转折。

8.2 什么时候应停止训练

出现以下任一项应暂停并定位，而不是继续等：

  • loss、参数或动作出现 NaN / Inf；
  • 动作大面积持续饱和且评估回报下降；
  • Q 远超有界奖励给出的合理量级；
  • deterministic evaluation 达到预先定义的连续退化条件，而不是训练后临时挑阈值；
  • terminated / truncated 计数或 episode 长度突然改变；
  • replay 样本 shape、wrapper 或环境版本发生变化。

九、随机种子差异很大

DDPG 的随机性来自网络初始化、warm-up 动作、行为噪声、ReplayBuffer 采样、 环境初始状态和 GPU 运算。早期少量探索差异会改变 buffer，随后 Actor-Critic 闭环进一步放大。

9.1 报告要求

  • 至少多个独立 seeds；
  • 同一训练预算和评估 seed 集；
  • 报告均值、中位数、离散程度和所有单 seed 曲线；
  • 预先定义主指标与选 checkpoint 规则；
  • 不以最好 seed 代表算法。

9.2 可复现不等于确定性

固定 seed 有助于重放某次运行，但硬件、库版本和并行环境仍可能引入差异。 研究结论应依赖统计分布，而不是依赖“一次完全逐位复现”。

十、必须记录的日志

层 指标 目的
环境 return、length、terminated/truncated 计数 验证任务和边界
动作 均值、标准差、min/max、clip 率、变化率 识别饱和与抖动
Replay size、reward 分布、样本年龄 识别覆盖和陈旧
Critic loss、Q/target Q 分布、TD error 识别自举漂移
Actor loss、参数梯度、逐维 \(\nabla_aQ\) 与规范化 \(\nabla_uQ\) 识别断梯度与过强利用，并保留动作单位

评估 独立 deterministic return 衡量真正策略质量

日志应保留分布而不只均值。Q 的均值正常、极少数样本爆炸时，平均值可能掩盖即将发生的坍塌。

十一、最小消融矩阵

  1. 随机策略基线：验证 reward 和动作方向。
  2. 冻结 Actor：只训练 Critic，判断自举是否稳定。
  3. 冻结 Critic：做极少 Actor step，确认 Actor 是否提高固定 Critic 的预测并检查动作边界； 这不能证明环境真实回报方向正确。
  4. Gaussian vs OU：固定预算和 seeds，并报告离散时间步、边际标准差、执行动作 RMS 与 clip 率； 仅令同名 \(\sigma\) 相等不代表实际扰动强度相同。
  5. 正确 vs 错误 truncation mask：验证时间边界偏差。
  6. 低 vs 高 UTD：观察 held-out TD error 与 Q 校准。
  7. 不同 replay 容量：记录样本年龄而不只改数字。
  8. DDPG vs TD3：尽量匹配预算、共享网络尺度和评估协议，比较整套稳定化机制的净效果； 完整算法对照同时改变双 Critic、目标平滑和延迟更新，不能单独归因于某一项。
  9. 单机制消融：若要定位 twin critics 的影响，只改变 Critic 数量/取最小规则， 其余机制和计算预算保持或明确折算。

每次只改一个主因素。若同时换网络、噪声、环境版本和训练预算，结果无法归因。

十二、现象—假设—验证总表

现象 至少两个假设 最小验证
Critic loss 降、回报不升 target 有偏；训练集过拟合 held-out replay + rollout 校准
Q 上升、回报下降 Actor 利用高估；reward scale 错 Q/return 散点 + 有界量级检查
Actor loss 更负、回报不升 Critic 标尺漂移；覆盖外动作 deterministic eval + 动作支持

十三、知识重点、诊断创新与结论边界

13.1 知识点与重点

  1. 内部一致不等于外部正确。 TD loss 与 Actor loss 都依赖学习中的价值标尺， 必须结合环境 rollout、独立评估和动作支持检查。
  2. 相关现象不唯一指向原因。 Q 膨胀、动作贴边或 return 背离都至少有环境、数据、 估计和优化多个候选，需要最小对照实验逐一证伪。
  3. 诊断量也有边界。 held-out TD error 不是真实回报，双 Critic 分歧不是置信区间， 近邻距离不是精确密度，有限 seed 均值也不是总体性能。
  4. 记录时点和分布。 Q、target、动作与梯度应保留分位数/极值及采样时点， 只看均值可能漏掉少量爆炸样本；动作梯度还必须注明物理或规范化坐标。

13.2 方法上的创新

本页的价值不在发明新 DDPG 变体，而在建立可证伪的 “环境语义 → Critic 校准 → Actor 利用 → 更新耦合”诊断链。 它把“调超参数”推迟到数据语义和梯度路径核验之后，并要求每个修复都配单因素对照。

13.3 必须保留的边界

  • \(\mathbb E[\max]\) 不等式解释选择偏差机制，不证明某次 DDPG 运行必然高估或给出高估幅度。
  • H 步自举回报仍依赖尾值；只有真实 rollout 回报才提供环境侧校准证据。
  • 动作触边可能是最优控制，也可能来自噪声、缩放或 Critic 外推，不能单独判错。
  • target network、replay 和 soft update 只缓和耦合，不消除函数逼近偏差或保证收敛。
  • 完整 DDPG–TD3 对比衡量机制组合；单个机制的因果结论需要受控消融。

这不是一页“复制即可运行”的大代码块，而是一份实现审计地图：每个函数只承担一个数学职责，每个张量都有形状与快照语义，每个高风险步骤都有最小测试。主线采用概念化 PyTorch 写法，并用《动手学强化学习》、Spinning Up、SB3-Contrib、OpenAI Baselines 等实现对照差异。

代码调用链：批数据快照 → GAE → 替代目标 → Actor 梯度 → KL-HVP → CG → 满步定标 → 线搜索 → 参数接受或恢复 → Critic 回归

阅读约定：本页统一最大化替代目标，因此梯度是 \(g=\nabla_\theta L\)，候选参数是 \(\theta_{\mathrm{old}}+\alpha s\)。如果源码把 policy loss 定义成 \(-L\)，梯度与更新符号都要成套翻转。片段是概念化 PyTorch 写法，突出不变量，不承诺脱离模型类和缓冲区直接运行。

层次 代表实现 适合学什么 阅读时的限制

二、一次更新的函数调用图

flowchart TD U["update(batch)"] --> A["compute_advantage"] U --> O["freeze_old_policy_info"] A --> T["固定 advantages / returns"] O --> S["surrogate_objective"] T --> S S --> G["flat_actor_gradient"] O --> K["mean_kl"] K --> H["hessian_vector_product(v)"] G --> C["conjugate_gradient(HVP, g)"] H --> C C --> M["scale_to_trust_region"] M --> L["backtracking_line_search"] S --> L K --> L L --> P{"接受？"} P -- 是 --> N["保留 candidate"] P -- 否 --> R["restore old_params"] T --> V["critic_regression"]

一个稳健实现至少应把以下职责分成可单测函数：

  • 参数展平与写回；
  • 轨迹边界和 GAE；
  • 分布构造、log-prob 与解析 KL；
  • Fisher 向量积；
  • 共轭梯度；
  • 候选评估与线搜索；
  • Critic 回归；
  • 指标采集。

把所有逻辑塞进一个 update()，最容易让快照时序、符号和参数顺序错误互相掩盖。

三、批数据与旧策略快照

3.1 最小字段

字段 典型形状 用途 快照要求
states \([N,\mathrm{obs\_dim}]\) Actor、Critic 前向 本轮固定
actions 离散 \([N]\)；连续 \([N,\mathrm{act\_dim}]\) ratio 与环境动作 本轮固定
rewards \([N]\) TD residual 本轮固定
next_states \([N,\mathrm{obs\_dim}]\) bootstrap 本轮固定
terminated \([N]\) bool 真终止 mask 不与 truncated 混合
truncated \([N]\) bool 环境外部截断与 reset 边界诊断 value 可 bootstrap，GAE 不跨 reset
old_values \([N]\) GAE 与 value target detach
old_log_probs \([N]\) ratio 分母 detach
old distribution params logits，或 mean 与 log std 解析 KL detach 且不可由更新后网络重算

3.2 不要只保存“分布对象引用”

一些分布对象内部引用由网络前向得到的张量；另一些自定义对象可能延迟读取模型参数。最稳妥的方法是保存重建旧分布所需的 detach 后张量：

  • Categorical 保存所有 old logits；
  • 对角高斯保存 old mean 与 old log standard deviation；
  • 多分支动作空间按分支保存全部参数；
  • 若动作分布含同一个可逆变换（例如 tanh），保存基础分布参数和变换配置；若环境侧做硬裁剪，不能把裁剪后的动作当成原分布动作直接计算 log-prob。
old 的含义是“本次更新开始前的数值快照”，不是“之后再调用一次当前网络”。旧 log-prob、旧分布参数、旧 value 与旧 Actor 参数必须来自同一策略批的同一时间点。

四、GAE：代码必须表达两个边界 mask

with torch.no_grad():
    values = critic(states)
    next_values = critic(next_states)

    bootstrap_mask = 1.0 - terminated.float()
    trace_mask = 1.0 - torch.logical_or(terminated, truncated).float()
    deltas = rewards + gamma * bootstrap_mask * next_values - values

    advantages = reverse_gae(
        deltas=deltas,
        continue_mask=trace_mask,
        discount=gamma * lam,
    )
    returns = advantages + values

advantages = advantages.detach()
returns = returns.detach()

这里故意使用两个 mask：bootstrap_mask 只在真正终止时置零，因此时间限制截断仍可用最终观测的价值 bootstrap；trace_mask 在 terminated 或 truncated 的 reset 边界都置零，阻止 GAE 穿过环境重置继续递推。单纯用 1 - terminated 跨整块数组累积，会把 reset 后的新 episode 串到旧轨迹。rollout 仅因缓冲区装满而切断、但环境没有 reset 时，不应伪造 truncated；尾部 TD residual 使用下一状态价值，而递推自然在当前缓冲区尾结束。代码还假定 next_states 在 truncation 处保存的是真正最终观测；向量环境若自动 reset，必须从 info 中取 final observation，不能把新 episode 的初始观测拿来 bootstrap。

检查点：

  • torch.no_grad() 防止 Actor 沿优势反传到 Critic；
  • true termination 不 bootstrap；
  • time-limit truncation 在下一状态有效时 bootstrap；
  • GAE 不跨 reset 串联；
  • returns 使用计算优势时的 old values；
  • Critic 更新后不重算本轮 advantages。

五、替代目标：ratio 的形状必须是 \([N]\)

new_dist = actor.distribution(states)
new_logp = new_dist.log_prob(actions)

if new_logp.ndim > 1:
    new_logp = new_logp.sum(dim=-1)

ratio = torch.exp(new_logp - old_log_probs)
surrogate = (ratio * advantages).mean()

对未包装成事件分布的连续多维独立高斯，框架可能返回每个动作维度的 log-prob，此时必须先跨动作事件维求和，再指数化；若已用 Independent 或库分布封装得到每个样本一个标量 log-prob，则不能再次求和。判断依据是分布的 batch_shape/event_shape 契约，而不是看到二维张量就盲目压缩：

\[\frac{\pi_\theta(a\mid s)} {\pi_{\mathrm{old}}(a\mid s)} = \exp \left( \sum_i \log\pi_\theta(a_i\mid s) - \sum_i \log\pi_{\mathrm{old}}(a_i\mid s) \right)\]

若 ratio 是 \([N,\mathrm{act\_dim}]\)、advantages 是 \([N,1]\)，PyTorch 会静默广播并产出一个标量，却已经不再是正确目标；advantages 为 \([N]\) 时通常会因尾维不匹配报错，但在维度偶然相等时仍可能错误广播。因此不能依赖运行时报错，必须显式断言一维形状。

5.1 最小断言

  • new_logp.shape == old_log_probs.shape == advantages.shape；
  • 三者维度均为一维批向量；
  • ratio 在 Actor 尚未更新时接近全 1；
  • 初始 surrogate 接近 advantage 的批均值；
  • 所有张量 dtype 与 device 一致。

六、平均 KL：必须使用完整分布

new_dist = actor.distribution(states)
old_dist = rebuild_detached_distribution(old_dist_params)

state_kl = torch.distributions.kl_divergence(
    old_dist, new_dist
)
if state_kl.ndim > 1:
    state_kl = state_kl.sum(dim=-1)

mean_kl = state_kl.mean()

ratio 只关心采到的动作；KL 则比较该状态下的完整动作分布。因此：

  • Categorical KL 需要所有类别 logits；
  • 对角高斯 KL 需要每维 mean 与 standard deviation；
  • 单个采样动作上的 log-prob 差不是解析 KL。若动作确由旧策略采样且样本在求导时固定，批均值可作为 \(D_{\mathrm{KL}}(\pi_{\mathrm{old}}\|\pi_\theta)\) 的蒙特卡洛估计，但它有采样误差、有限批上甚至可能为负；在旧点的有限批梯度也不必恰为零，因此不能与完整分布的解析 KL 混称或不加说明地替代其 HVP；
  • KL 的方向由库函数参数顺序决定，必须用非对称测试验证。

若新旧策略使用同一个可逆、可微变换，KL 在变换前后不变，可在基础分布上计算；硬裁剪不是可逆变换，不能据此沿用基础分布 KL。还要先确认所用库是否为该分布组合注册了解析 KL，不能假定任意 transformed distribution 都受支持。

在旧新参数完全相同时，应满足：

\[D_{\mathrm{KL}}=0, \qquad \nabla_\theta D_{\mathrm{KL}}=0\]

但 Hessian-vector product 一般不为零。这是 HVP 单元测试的重要基准。

七、Actor 梯度展平与参数向量

actor_params = tuple(actor.parameters())

grads = torch.autograd.grad(
    surrogate,
    actor_params,
    allow_unused=True,
)

flat_parts = []
for param, grad in zip(actor_params, grads):
    if grad is None:
        flat_parts.append(torch.zeros_like(param).reshape(-1))
    else:
        flat_parts.append(grad.reshape(-1))

flat_g = torch.cat(flat_parts)

不应静默丢弃 None 梯度。若展平梯度跳过一个参数，而写回函数仍包含它，向量切片会从此错位。更严格的实现可以直接把非预期 None 视为错误；若允许未用参数，也要补等长零向量。

参数工具必须互逆：

old_params = parameters_to_vector(actor_params).detach().clone()

with torch.no_grad():
    vector_to_parameters(candidate, actor_params)

必要检查：

  • 向量元素数等于 Actor 参数总数；
  • actor_params 在整个更新期间顺序固定；
  • clone 旧参数，不能只保留同一 storage 的视图；
  • 写回在 no-grad 上下文进行；
  • dtype 和 device 不发生隐式迁移。

八、KL-HVP：高阶图只在需要时保留

def fisher_vector_product(v):
    v = v.detach()
    new_dist = actor.distribution(fvp_states)
    old_dist = rebuild_detached_distribution(old_fvp_params)
    kl = analytic_mean_kl(old_dist, new_dist)

    grad_kl = torch.autograd.grad(
        kl,
        actor_params,
        create_graph=True,
    )
    flat_grad_kl = flatten_exact(grad_kl, actor_params)

    directional = torch.dot(flat_grad_kl, v)
    hvp_parts = torch.autograd.grad(
        directional,
        actor_params,
        retain_graph=False,
    )
    flat_hvp = flatten_exact(hvp_parts, actor_params).detach()
    return flat_hvp + damping * v

最危险的六处：

  1. 忘记 create_graph=True，第二次求导无图可走；
  2. old distribution 没有 detach，KL 两端一起移动；
  3. 在计算 directional 前 detach flat gradient；
  4. 把阻尼加到 KL 标量，而不是最终向量；
  5. FVP 与 flat gradient 使用不同参数顺序或不同子集语义；
  6. actor_params 混入不影响策略分布的参数，却没有用 allow_unused=True 和等长零块处理。更简单的做法是从一开始就只传入真正控制策略分布的参数。

8.1 对称性测试

在旧参数处、对正确解析 KL 求 Hessian 时，对随机向量 \(v,w\) 应近似满足

\[v^{\top}Hw \approx w^{\top}Hv\]

阻尼后同样成立。还应检查 \(v^{\top}Hv\ge -\varepsilon\)。Fisher 允许存在零空间，所以“随机 HVP 必须非零”不是严格断言；更可靠的是在可辨识方向上与有限差分对照，并允许冗余参数方向得到近零结果。这些测试能发现图断裂、参数错位和非解析的采样 KL 实现。

九、共轭梯度：保护条件不可省略

def conjugate_gradient(matvec, b, max_steps, tol_sq, curvature_rtol):
    x = torch.zeros_like(b)
    r = b.clone()
    p = r.clone()
    rr = torch.dot(r, r)

    if not torch.isfinite(rr) or rr <= tol_sq:
        return x, {"status": "zero_or_invalid_rhs"}

    for step in range(max_steps):
        Ap = matvec(p)
        denom = torch.dot(p, Ap)
        denom_scale = torch.linalg.vector_norm(p) * torch.linalg.vector_norm(Ap)

        if not torch.isfinite(denom) or not torch.isfinite(denom_scale):
            return x, {"status": "invalid_curvature"}
        if denom <= curvature_rtol * denom_scale:
            return x, {"status": "nonpositive_or_tiny_curvature"}

        alpha = rr / denom
        x = x + alpha * p
        r = r - alpha * Ap
        new_rr = torch.dot(r, r)

        if not torch.isfinite(new_rr):
            return x, {"status": "invalid_residual"}
        if new_rr <= tol_sq:
            return x, {"status": "converged", "steps": step + 1}

        beta = new_rr / rr
        p = r + beta * p
        rr = new_rr

    return x, {"status": "max_steps", "residual_sq": rr}

本页代码和子页 ④公式逐项对应：b 是 \(g\)，matvec 是 \(v\mapsto(H+\kappa I)v\)，返回的 x 近似 \((H+\kappa I)^{-1}g\)，而不是未阻尼的 \(H^{-1}g\)。

片段把参数明确命名为 tol_sq：调用者若配置的是残差二范数阈值 cg_tol，就传入 cg_tol ** 2。curvature_rtol 用相对于 \(\lVert p\rVert_2\lVert Ap\rVert_2\) 的阈值拦截正但近零的分母；只判断严格小于零仍可能产生爆炸步长。工程实现还适合同时使用绝对阈值和相对阈值 \(\lVert r_k\rVert_2/\max(\lVert b\rVert_2,\epsilon)\)。还应记录残差序列；欧氏残差偶尔上升不必立刻失败，但长期停滞或整体放大需要检查条件数、阻尼、FVP 子批与 HVP 正确性。

十、最大步长：统一最大化符号

direction, cg_info = conjugate_gradient(
    fisher_vector_product,
    flat_g,
    max_steps=cg_steps,
    tol_sq=cg_tol ** 2,
)

Ad = fisher_vector_product(direction)
curvature = torch.dot(direction, Ad)
linear_gain = torch.dot(flat_g, direction)

if target_kl <= 0:
    return restore_and_report("invalid_target_kl")
if not torch.isfinite(curvature) or curvature <= 0:
    return restore_and_report("invalid_curvature")
if not torch.isfinite(linear_gain) or linear_gain <= 0:
    return restore_and_report("nonascent_direction")

scale = torch.sqrt(2.0 * target_kl / curvature)
full_step = scale * direction

本页选择阻尼曲率 \(d^{\top}(H+\kappa I)d\) 定标，并显式拒绝非上升方向。若对照源码使用未阻尼 \(d^{\top}Hd\)，实现与文档必须一起改变，不能让 CG 和步长分母分别暗用不同口径而不记录。还应分别记录未阻尼与阻尼的二次型；后者等于目标预算，不代表解析 KL 一定等于该值。

符号快速检查：

  • 最大化 surrogate：flat_g = grad(surrogate)，候选为 old params 加 step；
  • 最小化 negative surrogate：梯度方向和候选写法应整体反向；
  • 不要同时对 gradient、direction、candidate 三处各自“修正”负号。

十一、线搜索：候选评估必须是无副作用的纯读操作

old_params = parameters_to_vector(actor_params).detach().clone()
old_obj = evaluate_surrogate().detach()
expected_full = torch.dot(flat_g, full_step).detach()

accepted = False
failure_reason = "no_candidate"

for j in range(max_backtracks):
    fraction = shrink ** j
    candidate = old_params + fraction * full_step

    with torch.no_grad():
        vector_to_parameters(candidate, actor_params)
        new_obj, new_kl = evaluate_candidate()
        predicted = fraction * expected_full

    finite = torch.isfinite(new_obj) & torch.isfinite(new_kl)
    improves = new_obj > old_obj
    respects_kl = new_kl <= target_kl

    if finite and improves and respects_kl:
        accepted = True
        break

if not accepted:
    with torch.no_grad():
        vector_to_parameters(old_params, actor_params)

predicted 是当前缩步候选的一阶预测改善，可记录或用于明确声明的改善比变体；本页基本接受谓词不强制改善比阈值。evaluate_candidate() 只能读取固定 states、actions、advantages、old log-prob 和 old distribution params；它不能：

  • 更新 BatchNorm 运行统计；
  • 打开 dropout 随机性；
  • 重新采样动作；
  • 改写缓冲区；
  • 做 Critic optimizer step；
  • 根据候选重算 advantages。

若网络含训练态副作用，线搜索候选将无法公平比较。策略评估应使用一致模式并显式控制随机层。

11.1 失败时恢复要单测

测试方法：构造一个接受谓词永远为假的候选评估器，运行完整线搜索，断言更新前后 Actor 参数逐元素相等。只检查返回的 accepted=False 不够，因为参数可能仍停留在最后一个失败候选。

十二、Critic 更新与共享参数保护

fixed_returns = returns.detach()

for _ in range(n_critic_updates):
    pred = critic(value_states).squeeze(-1)
    value_loss = ((pred - fixed_returns) ** 2).mean()

    critic_optimizer.zero_grad(set_to_none=True)
    value_loss.backward()

    clear_actor_owned_shared_grads_if_needed()
    critic_optimizer.step()

关键语义：

  • Actor 不使用这个 optimizer；
  • SB3-Contrib 的 learning rate、batch size 和多轮更新针对 Critic；
  • returns 在多轮 Critic 更新中固定；
  • 若共享骨干不允许由 Critic 修改，必须从 optimizer 参数组排除，或在 step 前清除相关梯度；
  • Critic step 前后应在固定状态集上测策略 KL，验证没有绕过信任域。

Actor 与 Critic 参数完全独立，或 Critic step 被证明不会改变策略分布时，两者先后都可行。若存在共享参数泄漏，先更新 Critic 会先改变 Actor，再让 CG 在线搜索开始前就偏离旧策略；此时即使 advantages、returns 和 old policy info 已冻结，数学依赖仍被破坏。

十六、最小测试矩阵

参数 round-trip

展平、扰动、写回、再展平应逐元素一致；覆盖不同形状参数和未用参数。

捕获顺序与切片错误

KL 局部性质

同策略 KL 与一阶梯度接近零；可辨识方向的 HVP 对上有限差分，二次型非负；旧新方向用非对称分布核对。

捕获 KL 与 detach 错误

HVP 对称性

随机 v、w 满足 vᵀHw 与 wᵀHv 在容差内相等。

捕获图断裂与参数错位

CG 对角系统

用已知 SPD 对角矩阵验证近似解、最终相对残差和非正曲率保护；不要求欧氏残差逐轮单调。

捕获公式与停止条件错误

线搜索回滚

强制所有候选失败，Actor 参数必须与 old params 完全一致。

轨迹边界

手算 terminated、truncated 和跨 episode 小序列，核对 bootstrap 与 GAE。

共享参数隔离

只执行 Critic step，固定状态上的策略 KL 应为零或在数值容差内。

捕获绕过信任域更新

完整 toy update

小网络单批更新后，替代目标改善、KL 合格；强制异常时能恢复。

十八、实现审计顺序

面对一份陌生 TRPO 代码，按下面顺序阅读最省时间：

  1. 找出旧策略快照在何处创建、保存哪些张量；
  2. 确定 surrogate 的正负号和 ratio 维度；
  3. 确定 KL 方向、聚合维度和解析形式；
  4. 跟踪 Actor 参数列表如何展平、传给 HVP、再写回；
  5. 核对阻尼位置与满步分母；
  6. 写下线搜索完整接受谓词；
  7. 找到所有失败分支是否恢复 old params；
  8. 检查 Critic optimizer 参数组与共享特征；
  9. 核对 advantages 在何时计算和是否重算；
  10. 查批次是否被用于多次 Actor 更新；
  11. 最后再比较网络规模和超参数。
先审计不变量，再看训练曲线。很多 TRPO 错误不会立刻报错：它们只会表现为“偶尔崩”“非常慢”或“调参无效”。把快照、形状、符号、参数顺序、回滚与共享边界写成断言和测试，比继续试新的 $$\delta$$ 更有价值。

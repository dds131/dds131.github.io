子页 ③得到了理想更新

\[\Delta\theta^{*} = \sqrt{ \frac{2\delta} {g^{\top}H^{-1}g} }\,H^{-1}g\]

但这还不是可运行算法：神经网络的 (H) 大到无法存储，更不能显式求逆；局部解析步也不能保证有限步仍满足真实 KL 约束。本页把这两个缺口合成一条工程闭环：用 Fisher 向量积驱动共轭梯度求方向，用阻尼稳定曲率，用 KL 预算缩放满步，再用真实目标与真实 KL 回溯验收。

推导链位置：一阶目标 + 二阶 KL → 解析自然梯度步（子页 ③） → FVP → 共轭梯度 → 阻尼 → 满步缩放 → 回溯线搜索（本页） → 网络、GAE 与完整训练循环（子页 ⑤）

本页拥有：矩阵自由求解、CG 公式、KL-HVP 与 (J^{\top}MJv)、子采样、阻尼、步长定标、线搜索接受条件、失败恢复与诊断。不在本页展开：Fisher 为什么来自 KL 见子页 ③；轨迹、GAE、Critic 与训练顺序见子页 ⑤；可执行代码逐行映射见子页 ⑥。

一、输入、输出与三个控制层

一次 Actor 更新的输入是旧策略采集的一批 ((s_t,a_t,\hat A_t))、替代目标梯度 (g)、平均 KL 的局部曲率 (H) 和预算 (\delta)。最终输出只有两种：接受一个通过检验的新参数，或恢复 (\theta_{\mathrm{old}}) 并跳过本轮 Actor 更新。得到这个结果要经过四个阶段：

  1. 找到矩阵自由的近似方向 (x\approx(H+\kappa I)^{-1}g)；
  2. 把方向缩放成局部二次模型允许的满步 (s)；
  3. 从满步开始回溯，接受第一个同时通过目标和 KL 检验的候选；
  4. 若全部候选失败，完整恢复 (\theta_{\mathrm{old}})，本轮 Actor 不更新。
CG不形成矩阵，近似解线性系统
FVP只提供向量到曲率乘积
阻尼抬高近零曲率，稳定求解
线搜索用真实量验收有限步

这里有三层作用不同的风险控制：

  • Fisher 几何让搜索方向尊重策略分布的局部敏感度；
  • (\delta) 把候选满步定标到局部 KL 边界；
  • 线搜索对非线性的真实替代目标与真实 KL 做最后验收。

只保留其中一层，都不等于完整 TRPO；即使三层都具备，也只是对有限批次平均 KL 与替代目标的局部控制，不是对真实回报单调上升或逐状态最大 KL 的保证。

二、为什么不能显式构造 Fisher

若 Actor 有 (n) 个参数，梯度向量只需 (O(n)) 存储，而稠密 Fisher 需要 (O(n^2)) 存储，通用稠密求解的时间复杂度还通常达到 (O(n^3))。

论文的 Atari 策略约有 33,500 个参数。仅一个 float32 稠密矩阵就需要

\[33500^2\times 4\ \mathrm{bytes} = 4.489\times 10^9\ \mathrm{bytes}\]

也就是约 4.49 GB，或约 4.18 GiB；这还没有包括网络参数、轨迹批次、自动微分图、临时向量与线性求解工作区。若 Actor 有一百万个参数，矩阵元素数会达到 (10^{12})，单精度存储约 4 TB。

真正要算的从来不是 (H^{-1}) 本身，而是线性方程

\[(H+\kappa I)x=g\]

的一个足够好的近似解。只要算法能回答“给定任意向量 (v)，返回 ((H+\kappa I)v)”这一问题，就不需要看见矩阵的任何元素。

这就是 TRPO 选择共轭梯度与 Fisher 向量积的原因。

三、共轭梯度：用乘法黑盒求线性系统

3.1 适用条件

共轭梯度法（Conjugate Gradient, CG）用于对称正定线性系统。Fisher 在理论上是半正定矩阵，可能有零特征值；实际算法通常加入 (\kappa I)：

\[A=H+\kappa I, \qquad Ax=g, \qquad \kappa>0\]

只要数值误差没有破坏对称性，正阻尼就能把特征值整体抬高，使系统更接近正定并改善条件数。

3.2 逐步公式

取 (x_0=0)，则初始残差和搜索方向为

\[r_0=g-Ax_0=g, \qquad p_0=r_0\]

第 (k) 轮先调用一次矩阵向量乘积黑盒：

\[z_k=Ap_k\]

然后更新

\[\alpha_k = \frac{r_k^{\top}r_k} {p_k^{\top}z_k}\] \[x_{k+1}=x_k+\alpha_kp_k\] \[r_{k+1}=r_k-\alpha_kz_k\] \[\beta_k = \frac{r_{k+1}^{\top}r_{k+1}} {r_k^{\top}r_k}\] \[p_{k+1}=r_{k+1}+\beta_kp_k\]
这里的 \(\alpha_k\) 是 CG 在第 \(k\) 个共轭方向上的内部系数，不是策略学习率，也不是线搜索的收缩系数。三个概念数值上都可能小于 1，但职责完全不同。

3.3 为什么比最速下降少“来回摆动”

CG 的第 (k) 个近似解位于 Krylov 子空间

\[\mathcal K_k(A,g) = \mathrm{span} \left\{ g,Ag,A^2g,\ldots,A^{k-1}g \right\}\]

它构造的搜索方向满足 (A)-共轭关系：

\[p_i^{\top}Ap_j=0 \qquad (i\ne j)\]

在理想二次问题与精确算术下，每个方向解决一个新的曲率维度，不会像普通最速下降那样在狭长椭圆两侧锯齿反弹。理论上至多 (n) 步得到精确解；TRPO 并不追求机器精度，而是只做少量迭代获得可用方向。论文报告 10 次 CG 迭代已经有效，更多迭代并未带来更快的策略改进。

3.4 实际停止与异常退出

可同时设置以下条件：

  • 固定最大迭代次数，例如 10；
  • 残差平方 (r_k^{\top}r_k) 低于阈值；
  • (p_k^{\top}Ap_k) 非正，说明正定假设、HVP 或数值精度有问题；
  • 任一向量或标量出现 NaN、Inf；
  • 相对残差在多轮内停滞或整体放大，标记求解质量异常。

CG 保证单调改善的是二次目标或能量范数误差，不是每一步的欧氏残差范数；因此不能因一次 (\lVert r_k\rVert_2) 上升就宣告失败。输出仍应伴随迭代数、初始和最终相对残差、非正曲率次数，而不是只返回一个方向向量。

四、Fisher 向量积：两次自动微分，不形成 Hessian

定义在同一批旧策略状态上的经验平均 KL 标量

\[D(\theta) = \hat{\mathbb E}_{s} \left[ D_{\mathrm{KL}} \big( \pi_{\theta_{\mathrm{old}}}(\cdot\mid s) \Vert \pi_{\theta}(\cdot\mid s) \big) \right]\]

以下所有导数都在 (\theta=\theta_{\mathrm{old}}) 处求值；状态批固定，KL 的旧策略一端也固定。第一遍自动微分得到带计算图的梯度：

\[q(\theta)=\nabla_\theta D(\theta)\]

将其与给定常量向量 (v) 做内积：

\[z(\theta)=q(\theta)^{\top}v\]

再对 (z) 求梯度：

\[\nabla_\theta z = \nabla_\theta \left[ (\nabla_\theta D)^{\top}v \right] = Hv\]

第二次求导所得是这批状态上的经验 KL Hessian 向量积；在旧参数处，它就是相应的解析 Fisher 向量积。最后加阻尼项：

\[Av=Hv+\kappa v\]

v 视为常量"] M -->|"第二次自动微分"| H["Hv = ∇θz"] H --> A["Av = Hv + κv"]

4.1 四个实现不变量

  1. 第一遍求导必须保留高阶计算图；在 PyTorch 中通常对应 create_graph=True。
  2. 旧策略分布必须停止梯度，否则 KL 的两端都会移动，曲率定义就变了。
  3. (v) 在二阶求导中是常量，不应意外连入别的计算图。
  4. 参数的展平、切片与拼回顺序必须完全一致；顺序错一位，CG 仍可能输出有限数值，却不再是在解正确的系统。

4.2 为什么 KL 在旧参数处为零仍能求出曲率

在 (\theta=\theta_{\mathrm{old}}) 时，KL 的值与一阶梯度都为零，但二阶导不为零。若为了“省图”把第一遍梯度 detach，或者在 KL 达到零时提前返回，都会把真正需要的二阶信息一起删掉。

五、另一条 FVP 路径：(J^{\top}MJv)

子页 ③证明了

\[H=J^{\top}MJ\]

因此向量积可以分成三步：

\[u=Jv, \qquad w=Mu, \qquad Hv=J^{\top}w\]
路径 优点 代价与风险 适用场景
对平均 KL 做通用 Hessian-vector product 写法统一；更容易与自动微分框架核对 需要高阶自动微分图，内存与框架细节更敏感 教学实现、分布族经常变化
利用分布族的 (J^{\top}MJv) 可利用 softmax、对角高斯的解析 (M)，通常更高效 必须为分布族正确实现 (M)，批次与维度处理更复杂 性能敏感、策略分布固定
采样动作得分外积 代码看似简单 是经验 Fisher，方差高；不是论文标准 TRPO 的解析 Fisher 只适合作对照或明确标注的变体

论文附录 C.1 同时讨论了前两种路线。关键不是代码写成哪种形式，而是乘积必须对应所声明的 KL 曲率。

六、FVP 子采样：省计算，但不是免费午餐

TRPO 论文按每次 FVP 成本约等于一次梯度、CG 做 10 轮来估算：在其朴素实现中，超过 90% 的计算会花在 Fisher 向量积。论文进一步报告，用约 10% 的状态估计曲率，可使全部 FVP 的总成本接近一次完整梯度计算。这是论文实现中的成本估计与经验选择，不是所有网络、硬件和自动微分框架都成立的固定比例。

常见接口语义并不统一：

  • 旧版 OpenAI Baselines 的实现按固定间隔抽取样本；
  • SB3-Contrib 用 sub_sampling_factor 控制，值为 1 表示不子采样；
  • 有些实现随机抽子集，有些使用固定步长切片。

子采样的收益是减少每次 CG 迭代成本，代价是：

  • 曲率估计方差增大；
  • CG 残差可能不再平滑下降；
  • 候选方向对抽样更敏感；
  • 真实全批 KL 的线搜索回退次数可能上升。
梯度批、FVP 子批与线搜索验收批可以不同，但必须记录。若目标是只降低重复 FVP 的成本，一个清晰口径是让目标梯度和线搜索验收使用完整策略批，只对子采样后的状态计算 FVP。也有实现（例如当前 SB3-Contrib）先对子批切片，再在同一子批上完成梯度、FVP 与线搜索；这改变了整个 Actor 更新的经验目标与约束，不能描述成“只对子采样 Fisher”。

七、阻尼：数值保险与几何偏差同时存在

把特征分解写成 (H=U\Lambda U^{\top})，则

\[(H+\kappa I)^{-1}g = U(\Lambda+\kappa I)^{-1}U^{\top}g\]

原来很小的特征值 (\lambda_i) 会从放大因子 (1/\lambda_i) 变成 (1/(\lambda_i+\kappa))。这带来四个直接效果：

  • 消除精确零特征值造成的不可逆；
  • 限制近零曲率方向的巨大参数步；
  • 改善条件数，让有限轮 CG 更快得到稳定方向；
  • 降低有限样本曲率噪声被反演后放大的程度。

但阻尼不是越大越好。若 (\kappa) 远大于所有特征值，

\[(H+\kappa I)^{-1}g \approx \frac1\kappa g\]

方向会退化为缩放后的普通梯度，参数化不变性也不再严格成立。

参考实现 源码默认值 阅读时要注意
OpenAI Baselines (10^{-2}) 参数名为 cg_damping，实验脚本可覆盖
OpenAI Spinning Up 0.1 参数名为 damping_coeff
SB3-Contrib 0.1 参数名为 cg_damping

原论文附录 C 的推导直接使用 Fisher 矩阵 (H)，没有给出阻尼默认值；因此不能把某个代码库的阻尼反写成“论文参数”。上表是所链接源码当前版本的接口默认值，也不是可脱离实现复制的常数。判断阻尼是否合理，应同时看 CG 相对残差、所用二次型、满步长度、实际 KL 和回溯次数。

八、从方向到满步：分母口径必须说清

CG 得到近似方向

\[x\approx A^{-1}g, \qquad A=H+\kappa I\]

原论文没有阻尼时，方向满足 (x\approx H^{-1}g)，并用 (x^{\top}Hx) 定标。加入阻尼以后，OpenAI Baselines、Spinning Up 与当前 SB3-Contrib 都把“加了 (\kappa v) 的乘法黑盒”同时用于 CG 和满步分母；在这一口径下，满步系数为

\[\beta = \sqrt{ \frac{2\delta} {x^{\top}Ax} }\]

候选满步为

\[s=\beta x\]

于是 (\tfrac12s^{\top}As=\delta)。注意这使“求解”和“定标”自洽，但边界对应的是阻尼二次型，而不是原始 KL 二次型。另一种数学上可定义的做法，是仍用阻尼系统求稳定方向，却额外计算 (x^{\top}Hx) 来按未阻尼 KL 曲率定标；它与上述三个源码的口径不同，实验记录必须明确区分。

无论采用哪种分母，阻尼二次型都不是真实有限步 KL。最终候选必须重新前向计算真实平均 KL；线搜索正是消化不同定标口径与高阶误差的最后一道门。

还要检查三个退化情况：

  • (x^{\top}Ax\le 0)：不应开平方，应判为曲率异常并跳过更新；
  • (g) 或 (x) 范数接近零：没有可靠改善方向；
  • (\beta) 或 (s) 非有限：恢复旧参数并记录数值失败。

九、为什么有了解析步仍必须线搜索

满步依赖至少三层近似：

  1. 替代目标只保留一阶项；
  2. KL 只保留二阶项；
  3. (A^{-1}g) 只由有限轮 CG 与有限批 FVP 近似。

此外，平均 KL 约束本来就不等于最大状态 KL 约束。论文明确指出，省略线搜索会偶尔产生过大的更新，并可能导致灾难性性能下降。

9.1 回溯候选序列

设收缩系数 (c\in(0,1))，第 (j) 个候选为

\[\theta_j = \theta_{\mathrm{old}}+c^j s, \qquad j=0,1,\ldots,m-1\]

每次候选都必须在同一验收批上重新计算：

  • 候选替代目标；
  • 实现所声明方向的真实平均 KL；
  • 所有关键量是否有限。

完整步的线性模型预测改善是 (g^{\top}s)，第 (j) 个缩步候选则是 (c^j g^{\top}s)。实际/预测改善比可以作为诊断量，也可成为某些变体的额外接受条件；原论文附录 C、Spinning Up 与当前 SB3-Contrib 的基本接受谓词只要求目标改善且 KL 合格，并不强制改善比阈值。

flowchart TD A["保存 θ_old、旧策略分布、旧目标"] --> B["CG 得到方向 x"] B --> C["按 δ 缩放满步 s"] C --> D["候选 θ_j = θ_old + c^j s"] D --> E{"数值有限？"} E -- 否 --> H["继续缩步"] E -- 是 --> F{"KL 合格且目标改善？"} F -- 是 --> G["接受候选并结束"] F -- 否 --> H H --> I{"还有候选？"} I -- 是 --> D I -- 否 --> J["恢复 θ_old，本轮不更新"]

9.2 失败恢复是算法语义，不是清理工作

尝试候选时参数已经被写入 Actor。若所有候选都失败，必须显式写回 (\theta_{\mathrm{old}})。保留“最后一个失败候选”会让训练轨迹悄悄违反约束，而且下一批数据将由一个未被接受的策略采集。

十、各实现的线搜索接受条件并不逐字相同

为了可比，下面统一用“替代目标越大越好”的语言；若源码实现最小化负目标，条件的符号应反转。

来源 目标条件 KL 条件 本表核对口径
TRPO 论文附录 C 替代目标改善 旧策略到新策略不超过 (\delta) 论文算法描述
OpenAI Baselines 实际改善非负且所有量有限 旧策略到新策略不超过 (1.5\delta) GitHub master 的归档源码
OpenAI Spinning Up policy loss 不高于旧 loss 不超过 (\delta) GitHub master 的 TF1 源码
SB3-Contrib 替代目标严格高于旧目标 新策略到旧策略小于目标 KL GitHub master 当前源码
风险受控的更新是共同目标，接受谓词不是统一 API。表中四行甚至包含不同 KL 方向与 \(1.5\) 倍阈值松弛。复现实验时必须记录实现名和提交版本、KL 方向、阈值松弛、是否使用改善比、回溯次数与收缩系数；只写“使用 TRPO 线搜索”不足以复现。

十一、矩阵自由 Actor 更新伪代码

输入：旧参数 θ_old，策略批 B，KL 预算 δ，阻尼 κ
     CG 轮数 K，回溯次数 M，收缩系数 c

1. 冻结旧策略分布，计算旧替代目标 L_old
2. g ← ∇θ L(θ) 在 θ_old 处的梯度
3. 定义 Av(v):
       kl ← mean KL(π_old || π_θ)
       hv ← HessianVectorProduct(kl, v)
       return hv + κ v
4. x ← ConjugateGradient(Av, g, K)
5. curvature ← xᵀ Av(x)       # 或实现明确声明的 xᵀHx
6. 若 curvature 非正或非有限：恢复 θ_old，返回失败
7. s ← sqrt(2δ / curvature) x
8. 对 j = 0 ... M-1:
       θ_candidate ← θ_old + c^j s
       写入 θ_candidate
       重新计算 L_candidate 与真实平均 KL
       若数值有限、目标改善且 KL 合格：
           接受并返回
9. 写回 θ_old
10. 返回“线搜索全部失败”

伪代码里 Av(x) 的额外调用可以通过复用 CG 末端量优化，但只有在口径严格一致时才可复用。为了可读性与正确性，教学实现宁可显式再调用一次。

十二、一次 Actor 更新的计算账

若 CG 做 (K) 次迭代、线搜索最多尝试 (M) 个候选，则一次“策略只更新一次”的背后通常包含：

计算 大致次数 是否需要高阶图 目的
替代目标梯度 1 否 得到 (g)
Fisher 向量积 约 (K) 次 是 CG 求近似自然梯度方向
曲率核对 0–1 次 是 定标满步，或复用 CG 量
候选目标与真实 KL 前向 最多 (M) 次 否 回溯验收
参数展平、写回、恢复 多次 否 构造候选与保证失败回滚

因此，TRPO 的 Actor “每批只接受一次更新”并不等于“每批只做一次反向传播”。FVP 才是主要计算瓶颈，子采样与较少 CG 轮数都是在这个账本上做权衡。

十三、故障诊断：不要把所有失败压成一个布尔值

现象 优先检查 可能措施
梯度范数接近零 优势方差、奖励尺度、动作 log-prob、旧新参数是否意外相同 跳过 Actor 更新并保留诊断值
(p^{\top}Ap\le 0) HVP 对称性、参数展平顺序、阻尼、浮点精度 增大阻尼；做双线性对称性测试
CG 相对残差长期停滞或放大 条件数、FVP 子批、create_graph、旧策略是否 detach 减少子采样或增大阻尼；不要因单轮上升误判
满步 KL 远超预算 步长分母口径、KL 方向、批次是否一致、高阶误差 核对公式并依赖回溯，不直接接受满步
所有候选都因 KL 失败 方向或曲率估计差、(\delta) 太大、FVP 子批偏差 记录回退轨迹，检查全批曲率
KL 合格但目标不改善 梯度噪声、优势符号、概率比方向、局部模型失真 检查目标定义与 predicted improvement
出现 NaN 或 Inf 标准差参数、log-prob、除零、过小曲率 立即恢复旧参数，保存最小复现批

至少应分别计数“非有限失败”“KL 超限”“目标不改善”和“CG 异常”；若实现把改善比设为接受条件，再单列“改善比不足”。子页 ⑦会把这些信号组织成训练诊断面板。

十四、本页结论

TRPO 的数值核心不是二阶矩阵，而是一套矩阵自由、可回滚的验证协议。CG 只近似求方向，阻尼只改善数值条件，二次模型只给候选长度；真正决定是否改变策略的是对真实替代目标与真实 KL 的逐候选验收。

从工程视角看，一次可靠更新需要同时满足：

  • 方向可计算：FVP 的二阶图、参数顺序与 KL 定义正确；
  • 求解可诊断：CG 残差、曲率与非有限值被记录；
  • 长度有口径：阻尼是否进入分母明确；
  • 有限步可验证：线搜索在固定批次上重算目标和 KL；
  • 失败可回滚：任何异常都恢复旧参数。

下一页把这个 Actor 求解器放进完整训练系统：策略网络怎样输出分布、轨迹怎样切分、GAE 怎样计算、Critic 在什么时候更新，以及论文、Spinning Up 与 SB3-Contrib 的默认设置为何不同。

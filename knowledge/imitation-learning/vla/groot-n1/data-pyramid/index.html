一、先分清三个维度

GR00T N1 的数据侧贡献，不只是“把更多视频放进训练”，而是让动作空间、物理真实性和采集成本不同的数据能够共同提供训练目标。理解本页前，先把三个常被混用的维度分开：

维度 分类 回答的问题
数据金字塔 顶层真机；中层合成；底层人类视频与 VLM 的网络预训练数据 数据的规模、成本和机器人相关性如何分布？
GR00T 动作预训练语料 真机、合成、人类视频；合成又分仿真与神经轨迹 Table 7 实际统计了哪些数据？
生成或标注策略 潜在动作、神经轨迹、仿真轨迹 没有真值动作时，怎样得到可训练目标或新增轨迹？

这三者不是同一套分类。 数据金字塔是一种组织数据来源的概念图，不表示数据必须从底层逐级生成到顶层；论文 Table 1 也是策略适用范围表，不是数据之间的派生流程图。

还要区分两种“网络数据”。 Eagle-2 视觉语言主干曾在互联网规模图文数据上预训练；GR00T N1 的动作预训练则使用 Table 7 所列的时序数据。网络图文数据没有被逐项计入 Table 7，也不能笼统地说成“都由 VQ-VAE 生成了潜在动作标签”。

本页聚焦数据的来源、标签与边界。采样比、冻结策略和优化配置见 ④ 训练配方、损失组合与优化配置；各数据组合的实验结果见 ⑤ 实验、基准与合成数据收益。

二、为什么需要数据金字塔

真机轨迹具有真实物理交互和可执行动作，但通常需要操作者逐条采集。GR00T N1 自建的 GR-1 人形数据只有 88.4 小时；论文因此引入人类视频、神经生成视频和仿真轨迹，扩大行为与场景覆盖。

2.1 自建真机数据如何采集

环节 论文报告的做法
机器人 Fourier GR-1 人形机器人
腕部与手指 VIVE Ultimate Tracker 采腕部位姿，Xsens Metagloves 采手指动作
其他探索 Apple Vision Pro、Leap Motion
重定向 将人体运动经逆运动学转换为机器人动作
控制与记录 20 Hz 遥操作；记录机器人动作、头戴相机图像，以及操作者的低维本体感知与动作

操作者信号属于这套自建遥操作系统；公共人类视频通常没有同类信号。二者能够进入同一预训练框架，依赖的是后文的视觉转移潜在动作，而不是公共视频与操作者本体状态之间已有一一对应。

2.2 两级语言标注能提供什么

  • 细粒度标注描述抓取、移动、放置等原子动作。
  • 粗粒度标注把一串原子动作概括为任务级指令。

论文认为这种层级标注同时支持精细运动控制与高层任务推理。它在功能上与双系统分工相符，但论文没有说明两级标注被显式分别路由给 System 1 与 System 2，也没有相应消融；因此不应写成确定的模块对应关系。

三、三层数据与三种策略

层 数据 可用于动作预训练的目标 关键价值与限制
底层 人类时序视频 潜在动作 行为和场景广，但不是机器人控制量
中层 神经轨迹 潜在动作、同本体 IDM 伪动作 反事实场景丰富，但物理正确性不受保证
中层 仿真轨迹 仿真器真值动作；也可提取潜在动作 可规模化且可验证任务成功，但受资产与 Sim-to-Real 差距限制
顶层 真机机器人轨迹 真实动作和潜在动作 物理真实、可执行，但采集昂贵

  • 潜在动作只依赖具有时间关系的视觉帧对，不需要原始动作标签；但它要求合适的时序数据和被联合编码器覆盖的数据分布，并非任意两张图片都能产生有效动作语义。

  • 仿真轨迹依赖仿真器、机器人模型、场景资产和源示范。GR00T N1 使用少量人类遥操作示范作为 DexMimicGen 的种子；“必须从真机数据出发”不是 DexMimicGen 的普遍数学前提。

4.1 怎样理解“金字塔”

按 Table 7 的时长，真机数据 3,288.8 小时多于人类视频 2,517.0 小时，所以金字塔并不是严格的“逐层小时数递减图”。底层还包括未列入 Table 7 的 VLM 网络预训练数据；同时，真机总量主要来自公开数据，自建 GR-1 数据只有 88.4 小时。更准确的读法是：金字塔表达可扩展性、监督直接程度与机器人相关性的权衡，而不是每一层的精确面积。

Table 7 也只能说明帧数、时长、帧率和视角，不能单独判断数据价值；训练采样权重、动作质量、标签噪声、任务覆盖和重复度同样重要。

4.2 数字中容易读错的地方

  • 神经视频为 8 FPS，低于许多 15–30 FPS 数据，但不是表中最低：RT-1 为 3 FPS，Bridge-v2 与 RoboSet 为 5 FPS。
  • Ego4D 占人类视频时长约 (2144.7/2517.0\approx85.2\%)，因此“七个数据集”不代表时长均衡。
  • 论文第 3.1 节重点介绍自建 GR-1、OXE 和 AgiBot-Alpha 三个来源组，但 Table 7 还列出 RH20T-Robot。统计页面时应把它视为独立条目，而不能把真机语料简单概括为只有三个数据集。
  • OXE 实际使用 七个子集：RT-1、Bridge-v2、Language Table、DROID、MUTEX、RoboSet 和 Plex。

五、潜在动作：把视觉转移变成代理监督

5.1 编码、量化与策略目标

给定当前帧 (x_t) 和固定视觉时间跨度后的未来帧 (x_{t+H})，VQ-VAE 编码器先产生连续表示。这里的 (H) 是潜在动作模型选取未来帧的间隔，不应与 GR00T 策略动作块长度 (H=16) 当成同一个超参数：

\[z_t^{\mathrm{pre}}=E(x_t,x_{t+H}).\]

训练 VQ-VAE 时，表示被映射到最近的码本向量：

\[k^*=\arg\min_k\left\lVert z_t^{\mathrm{pre}}-e_k\right\rVert_2, \qquad z_t^{q}=e_{k^*},\]

解码器再根据当前帧和量化表示重建未来帧：

\[\hat{x}_{t+H}=D(x_t,z_t^q).\]

为便于阅读，上式把潜在动作写成一个向量；若编码器输出潜在序列，最近邻量化按相应位置执行。GR00T N1 论文只说明使用 VQ-VAE 目标，没有给出其在 N1 中的完整重建项形式、承诺损失权重或码本更新细节，因此这三式描述的是编码—量化—重建的信息流，不是可据此复现的完整损失函数。

GR00T N1 训练策略时使用的是量化前连续表示 (z_t^{\mathrm{pre}})，将它作为独立的 “LAPA” 本体目标，复用连续 flow-matching 框架。码本仍参与前一阶段 VQ-VAE 的瓶颈学习，不能因为策略最后读取量化前表示就说“量化没有作用”。连续目标在实现上便于复用连续速度场，但论文没有给出离散码策略头的对照实验，所以不能断言这是唯一设计动机或必然优于预测离散码。

5.2 它学到的是“视觉变化代理”，不是可执行动作

重建目标迫使潜变量保留从 (x_t) 到 (x_{t+H}) 的信息，但不保证其中只有控制动作。它还可能编码相机运动、遮挡、光照、物体自主运动或背景变化。因此：

  • 潜在动作可以作为与行为相关的代理监督；
  • 它不是关节角、末端位姿或力矩；
  • 它不能直接发送给机器人执行；
  • 视觉结果相同也不意味着底层控制序列唯一。

论文 Figure 4 的跨具身检索样例显示，相似潜变量常对应相似的左右移动模式。这是与“学习到跨具身运动规律”一致的定性证据，不是潜变量与真实动作等价的定量证明。

5.3 不同数据到底使用什么标签

数据 论文明确使用或声明适用的目标 说明
人类视频 潜在动作 没有机器人真值动作；论文第 2.3 节明确用于预训练
真机机器人数据 真实动作 + 潜在动作 论文第 2.3 节明确同时使用两者
神经轨迹 潜在动作 + IDM 伪动作 生成视频没有原生动作标签；论文明确同时使用两者
仿真机器人数据 仿真器动作；潜在动作方法也适用 Table 1 证明“适用”，但不能单凭勾选断言每条仿真轨迹都实际配了潜在动作目标

论文称在异构时序数据上联合训练一个 VQ-VAE，以获得共享潜在动作空间；这里不包括 Eagle-2 的互联网图文语料。论文只说这种共享空间“可能”改善跨具身泛化，也没有给出各数据源训练 VQ-VAE 时的采样权重，因此不能写成已证明的因果结论或默认各来源等权。

5.4 IDM：更接近控制空间，但仍是伪标签

这里有一个容易混淆的术语重叠：论文也把 VQ-VAE 编码器称作一种 inverse dynamics model，但它输出的是共享的潜在视觉变化表示；本节的 IDM 则按本体训练，输出该机器人的动作块伪标签。二者都由帧对反推动作相关信息，却不是同一个模型，也不共享同一种输出空间。

动作空间 IDM 接收当前帧与未来帧，预测二者之间的动作块。论文按本体分别训练 IDM，复用 System 1 的 DiT，采用 SigLIP-2 视觉嵌入和 flow-matching 目标，训练 30K 或 60K 步。

IDM 输出位于相应机器人的控制坐标中，因此比潜在动作更接近可执行动作；但它仍可能受到逆问题一对多、生成视频违反动力学以及分布外预测误差影响，不能称为真值动作。

论文只报告：在其具体数据和验证设置中，加入状态信息或更多图像帧没有显著提高动作预测性能。这不等于“两帧包含全部信息”，也不能据此认定“状态导致捷径”；后两种说法至多是待验证假设。

六、神经轨迹：扩场景，不直接产生真值动作

6.1 生成与标注流程

步骤 做法
视频模型 WAN2.1-I2V-14B，使用 LoRA 微调
微调数据 3,000 条带语言标注的真机样本；480P、81 帧；训练 100 epochs
指令扩展 多模态模型识别初始帧物体，并生成“把物体从 A 移到 B”的候选指令；提示词要求只考虑物理上可行的组合
视频生成 给定初始帧与新指令，生成反事实机器人视频
语义检查 抽样 8 帧，判断视频是否遵循原指令
重新描述 不符合原指令的视频降至 16 帧 / 256P 后重新生成描述
动作目标 潜在动作，或同本体 IDM 伪动作

重新描述的含义是让失败视频获得与其实际画面更一致的新文本，而不是让视频重新遵循原始指令。论文没有报告重新描述后保留了多少视频，也没有描述独立的接触、关节、碰撞或动力学验证；因此这一步最多修复语言—视频语义对齐，不能证明轨迹物理正确。

论文第 2.2 节写作“使用全部 88 小时自建遥操作数据微调”，第 3.2 节又把训练数据描述为 3,000 条样本，但没有解释“小时、轨迹、裁剪样本”之间的换算关系。本页因此同时保留两个原始口径，不把 3,000 条样本简单等同于完整 88 小时。

6.2 规模与成本怎样正确换算

生成视频从 88.4 小时扩展到 827.3 小时：

\[\frac{827.3}{88.4}\approx9.36,\]

所以论文概括为“约 10 倍”是合理近似。按“一张 L40 生成 1 秒视频需 2 分钟”计算理想算力：

\[827.3\times3600\times\frac{2}{60} \approx99{,}276\ \text{L40 GPU-hours}.\]

论文报告约 105,000 L40 GPU-hours，并在括号中写作“3,600 张 L40 约 1.5 天”。直接相除得到约 29.2 小时（1.22 天），与 1.5 天并不完全相等。论文没有说明 1.5 天是实测墙钟、保守取整，还是包含调度与失败生成等开销，因此只能并列报告两个口径，不能替作者指定差额来源。

神经视频减少的是新增人工遥操作需求，不是把 827.3 小时视频等价替换成同等价值的真机示教。105k L40 GPU-hours 与约 50k H100 GPU-hours也不能只按 GPU 小时直接比较成本，因为硬件、工作负载和吞吐不同。

6.3 官方样例与证据边界

反事实场景

同一初始帧配合不同指令，生成未实际采集的行为。

更换对象与位置

展示条件生成带来的任务组合扩展。

复杂倾倒样例

视觉上展示仿真较难覆盖的多体交互，不代表物理有效性已验证。

液体与铰接物体

论文给出定性样例，但将其下游定量评估留作未来工作。

修补初始帧

展示无需重新布置现场即可扩展初始图像的可能性；论文将进一步探索留作未来工作。

视频来源于 NVIDIA Isaac-GR00T 固定提交中的 media/videos。论文声称视频模型对新初始帧、新物体和新运动具有较强泛化，并展示液体、铰接物体和多轮生成样例；这些主要是作者报告和定性展示，不能扩写成“已经证明能可靠解决相应机器人任务”。

七、仿真轨迹：DexMimicGen 的规模与边界

7.1 先统一统计口径

数字 对应范围
540k 条 预训练任务的 54 个源—目标容器组合，每个组合 10,000 条
1,742.6 小时 Table 7 中计入动作预训练语料的 GR-1 仿真数据
780k 条 / 6,500 小时 论文所述预训练与后训练仿真数据合计
11 小时 生成上述 780k 条轨迹的墙钟时间

这些数字口径不同，不能互相替代。“6,500 小时等效人工演示”是按轨迹时长换算的规模描述，不代表仿真数据与真机人工示教具有相同价值。论文也没有给出“11 小时”背后的仿真并行度或硬件数量，所以它只能作为端到端墙钟口径，不能换算成 GPU-hours，更不能直接与神经视频的 105k L40 GPU-hours 比成本。

7.2 生成机制

  1. 将示范分割为以单个物体为中心的子任务片段。
  2. 根据新场景中的物体位姿变换片段，尽量保持末端执行器—物体的相对位姿。
  3. 在当前机器人状态与变换后片段之间插值。
  4. 按子任务顺序执行完整轨迹。
  5. 用仿真任务成功条件检查结果，只将成功回放加入数据集。

保持相对位姿是有效的局部几何先验，但不是普遍保证：机器人可达性、关节限位、碰撞、物体几何、接触模式及双臂协调都会影响变换能否成功。论文中的“只保留成功示范”指通过仿真任务条件筛选，不意味着轨迹一定能无差异迁移到真实机器人。

7.3 预训练任务设计

项 设计
仿真框架 RoboCasa
任务模板 把物体 A 从源容器 B 移到目标容器 C
组合数 54 个源—目标容器类别组合
每组合数量 10,000 条，共 540k 条预训练示范
初始状态 随机摆放物体与容器，并加入干扰物和干扰容器
源示范 几十条 Leap Motion 遥操作示范，经 mink 全身 IK 重定向

干扰物让场景中存在多个候选对象和容器，策略必须结合语言选择目标，而不能仅依靠视觉显著性。这是合理的数据设计分析，但并不自动证明模型已经形成稳健的语言定位能力。辅助检测损失只是额外监督信号，它的存在本身不是验证；实际效果需要由留出场景中的目标定位指标、语言扰动对照和任务成功率检验。

DexMimicGen 的独立论文还显示，生成数据从 1,000 条增至 5,000 条时，策略成功率并非在所有任务上继续上升。因此它提供的是可扩展数据生成能力，而不是“数量越大、效果必然越好”的保证。

八、哪些是 GR00T N1 的创新，哪些不是

层次 内容
已有方法或外部资源 VQ-VAE、LAPA 潜在动作思想、IDM 伪标签、WAN 视频模型、DexMimicGen、RoboCasa，以及各公开数据集
GR00T N1 的主要数据侧贡献 在同一策略中联合真实动作、潜在动作和 IDM 伪动作；把真机、人类视频、神经轨迹和仿真轨迹组织为统一的异构预训练混合；实现大规模生成、标注、筛选与预训练管线
仍需谨慎的主张 潜在动作的物理可辨识性、神经视频的动力学正确性、液体和铰接任务的定量收益、各层数据的独立贡献

真正的创新重点不是单独发明了其中每个算法，而是把监督强度不同的数据转化为可由统一 flow-matching 策略共同学习的目标，并在大规模人形机器人预训练与后训练管线中实现和评估这些组合。

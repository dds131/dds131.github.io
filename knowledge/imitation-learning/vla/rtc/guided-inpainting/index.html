RTC/ ① 时序/ ② 引导式 Inpainting

原始 RTC 不先生成一个完整新动作块，再对输出做平滑。它在 Flow Matching 的每个数值积分步上，估计当前样本最终会变成什么动作块，再根据上一动作块提供的约束修正当前速度场。这个修正通过向量—雅可比积（VJP）计算，因此影响的是当前样本的生成轨迹，不是在推理时更新模型参数。

条件补全把旧块重叠动作视为已知约束
VJP无需显式构造完整 Jacobian
Soft Mask约束强度随未来距离衰减
β最大引导权重，而不是最小值

时间约定：本页与 RTC 原论文一致，\(\tau=0\) 为噪声端，\(\tau=1\) 为动作端。若既有 openpi 页面使用 \(t=1\) 为噪声、\(t=0\) 为动作，则二者满足 \(\tau=1-t\)。

一、基础 Flow Policy

令 \(A\in\mathbb R^{H\times M}\) 是真实动作块，\(\epsilon\sim\mathcal N(0,I)\) 是同形状高斯噪声。论文采用线性条件路径：

\[x_\tau=(1-\tau)\epsilon+\tau A, \qquad \tau\in[0,1].\]

端点为

\[x_0=\epsilon,\qquad x_1=A,\]

所以对固定动作—噪声对有条件速度

\[u_\tau=\frac{\mathrm d x_\tau}{\mathrm d\tau}=A-\epsilon.\]

网络学习条件速度场

\[v_\theta(x_\tau,o,\tau),\]

其中 \(o\) 包含图像、语言与机器人状态。普通推理从 \(x_0\sim\mathcal N(0,I)\) 出发，用 Euler 或其他 ODE 求解器积分到 \(\tau=1\)。完整 Conditional Flow Matching 推导见 π0 · Flow Matching。

RTC 不改变这个基础策略的训练目标。它在推理速度上增加一个与旧动作块约束有关的项。

二、动作块衔接为什么是 Inpainting

新块生成时，旧动作块能提供部分时间位置上的可信目标：

  • 已经确定会在推理期间执行的前缀，是近似确定的已知值；
  • 与旧块仍重叠的未来动作，提供策略模式信息，但可信度随未来距离降低；
  • 超出旧块范围的后缀没有旧目标，应由新观测和策略生成。

先从当前块裁掉距离上次推理启动已经过去的 \(s\) 步，得到与本次推理时间原点对齐的旧块后缀

\[A_{\mathrm{prev}}=A_{\mathrm{cur}}[s:H].\]

再把这个长度为 \(H-s\) 的后缀右侧补齐到长度 \(H\)，记为目标 \(Y\)；用同形状 Mask \(W\) 表示各时间位置的引导权重。问题变成：生成一个在 \(W\) 非零区域尽量与 \(Y\) 一致的完整动作块。权重为 0 的位置没有直接匹配旧块的误差项，主要由基础速度场与新观测决定；这并不构成“严格保持原条件分布”的保证。

“Inpainting”只描述已知部分约束未知部分的生成结构。动作序列具有时间、动力学和控制坐标语义，不能由图像补全的视觉直觉代替机器人验证。

三、从当前状态估计最终动作

在时间 \(\tau\)，当前动作状态是 \(x_\tau\)。若当前网络速度在剩余区间近似保持不变，一步向前外推得到最终动作估计：

\[\widehat A^1_\tau = x_\tau+(1-\tau)v_\theta(x_\tau,o,\tau).\]

这个式子不是新的策略输出头，而是当前采样状态上的 denoising function。其含义是：如果从当前点沿当前速度走完剩余 Flow 时间，最终可能得到什么动作块。

必须保留三个限制：

  1. \(\widehat A^1_\tau\) 是估计，不是真实最终样本；
  2. 少步积分、非线性速度场会增加外推误差；
  3. 它依赖当前观测 \(o\) 和当前随机样本。

四、加权误差与 VJP

比较旧块目标与最终动作估计：

\[e_\tau = W\odot\left(Y-\widehat A^1_\tau\right).\]

误差定义在“最终动作空间”，但积分变量是当前 \(x_\tau\)。因此要通过最终估计对当前状态的导数把误差传回：

\[g_\tau = J_{\widehat A^1_\tau}^{\mathsf T}e_\tau, \qquad J_{\widehat A^1_\tau} = \frac{\partial\widehat A^1_\tau}{\partial x_\tau}.\]

实现不显式构造维度为 \((HM)\times(HM)\) 的 Jacobian，而用反向自动微分计算 vector-Jacobian product。官方 JAX 代码对应：

def denoiser(x_t):
    v_t = policy(obs, x_t, time)
    return x_t + (1 - time) * v_t, v_t

x_1, vjp_fun, v_t = jax.vjp(denoiser, x_t, has_aux=True)
error = (previous_chunk - x_1) * weights[:, None]
pinv_correction = vjp_fun(error)[0]

网络参数参与前向和求导图，但没有 optimizer、没有参数写回。VJP 返回的是对当前采样状态的修正方向。

五、为什么需要引导权重裁剪

论文使用与线性 Flow 路径相关的方差项：

\[r_\tau^2 = \frac{(1-\tau)^2}{\tau^2+(1-\tau)^2},\]

并把引导权重定义为

\[\lambda_\tau = \min\left( \beta, \frac{1-\tau}{\tau r_\tau^2} \right).\]

最终速度为

\[v_{\mathrm{RTC}} = v_\theta + \lambda_\tau g_\tau.\]

将未裁剪权重化简可得

\[\lambda_{\mathrm{raw}}(\tau) = \frac{\tau^2+(1-\tau)^2}{\tau(1-\tau)} = \frac{\tau}{1-\tau}+\frac{1-\tau}{\tau}.\]

因此它在 \(\tau\to0^+\) 和 \(\tau\to1^-\) 时都发散，并在 \(\tau=1/2\) 取得最小值 2；它不是从噪声端到动作端单调衰减的函数。

官方 Euler 实现只在

\[\tau_k=\frac{k}{n},\qquad k=0,\ldots,n-1\]

调用网络，最后一次更新后直接得到 \(x_1\)，不会在 \(\tau=1\) 再求速度。运行时直接遇到的奇点因而是第一步 \(\tau_0=0\)。当论文使用 \(n=5\) 时，最后求值点 \(\tau_4=0.8\) 的未裁剪权重为 4.25；Appendix A.2 指出，若 \(\beta\ge4.25\)，裁剪只改变第一步的无限权重。论文根据消融采用 \(\beta=5\)。实时控制只有少量 Flow 步，起点的巨大修正可能使动作块发散，因此 \(\beta\) 是最大引导权重，不是越大越好。

六、Hard Mask：只冻结确定前缀

最直接的 Mask 是

\[W_i= \begin{cases} 1,&i<d,\\ 0,&i\ge d. \end{cases}\]

它只约束推理期间必然由旧块执行的前 \(d\) 步。优点是语义清楚，不对更远未来施加强制约束。问题是当 \(d\) 很小时，前缀包含的运动模式信息有限；VJP 本身也只是近似条件化，新块仍可能切换到另一种策略。

七、Soft Mask：利用整个重叠区

在前一页定义的局部坐标与可行调度下，旧块可为新块前 \(H-s\) 个位置提供对应目标。RTC 将其中尚未执行、但与旧计划重叠的部分作为软条件：

\[W_i= \begin{cases} 1,&i<d,\\[3pt] c_i\dfrac{e^{c_i}-1}{e-1},&d\le i<H-s,\\[8pt] 0,&i\ge H-s, \end{cases}\]

其中

\[c_i= \frac{H-s-i}{H-s-d+1}.\]

三个区间的含义是：

  1. \(i<d\)：动作已经被承诺，权重为 1；
  2. \(d\le i<H-s\)：仍与旧计划重叠，但越远越不确定，权重逐渐衰减；
  3. \(i\ge H-s\)：旧块没有对应未来动作，权重为 0。

Soft Mask 加权的是 \(Y-\widehat A^1_\tau\) 这一生成引导误差。它不是对新旧动作执行逐元素加权平均，也不是 Transformer 中新增的注意力层。

方案 非零约束区间 优点 风险
Hard Mask 仅 \(i<d\) 不额外限制可反应未来 \(d\) 小时模式约束弱
Soft Mask \(i<H-s\)，中间衰减 用旧块重叠部分保持策略连续 权重或执行长度过大时可能抑制必要反应
全重叠硬冻结 整个 \(i<H-s\) 权重 1 最强连续性 容易固守旧计划；不是论文 RTC 的默认 Soft Mask

八、完整 GuidedInference

把上述步骤合并，每个 Flow 积分步执行：

输入：观测 o、当前块 A_cur、延迟 d、执行/调度跨度 s
对齐：A_prev ← A_cur[s:H]；再把 A_prev 右侧补齐到长度 H
构造：Soft Mask W
初始化：x ← N(0, I)，Δτ ← 1/n

for k = 0, ..., n−1:
τ ← k / n
v ← vθ(x, o, τ)
Â ← x + (1 − τ) v
e ← W ⊙ (A_prev − Â)
g ← VJP(Â with respect to x, vector=e)
λ ← min(β, (1 − τ) / (τ r²τ))
x ← x + Δτ (v + λg)

返回：生成动作块 x

这段伪代码没有动作队列、线程锁、实测延迟裁剪和机器人安全逻辑；它只描述生成器内部。完整运行时见③ 异步执行系统。

九、数学正确仍可能工程失效

9.1 动作维度尺度不一致

若不同关节或夹爪维度的归一化尺度不同，欧氏误差会隐式改变各维引导强度。旧块目标和新块采样必须在同一归一化空间比较。

9.2 相对动作锚点不同

两个数值相同的相对动作，如果分别以不同机器人状态为参考，并不对应同一绝对目标。工程实现可能需要把旧前缀重锚定到新推理的参考状态。

9.3 Flow 步数与 beta 共同决定稳定性

增加采样步数可以减小单步积分跨度，但会增加延迟 \(d\)；减小步数又使大引导更容易过冲。这是模型计算和控制调度之间的耦合，不存在只看一个超参数的通用答案。

9.4 命令连续不等于动力学安全

较小的相邻动作差不能证明速度、加速度、力或碰撞约束满足要求。RTC 应与硬件限位、低层控制和任务安全机制共同评估。

十、本页结论

  • RTC 用最终动作估计把旧块约束引入 Flow 采样，而不是在生成后平均。
  • VJP 把最终动作空间的加权误差传回当前采样状态，不更新模型权重。
  • \(\beta\) 是为少步控制采样增加的最大引导权重裁剪。
  • Hard Mask 只约束已承诺前缀；Soft Mask 还利用整个重叠区的策略信息。
  • 数学引导必须与动作归一化、坐标锚点、Flow 步数和运行时延迟一起验证。

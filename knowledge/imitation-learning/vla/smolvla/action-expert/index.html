SmolVLA 总览/主干与多模态 Token/动作专家与交错注意力

ACTION EXPERT · INTERLEAVED ATTENTION · PER-LAYER KV

SmolVLA 的标准动作专家是 16 层、720 隐藏维的条件速度场网络：第 0、2、…、14 层以因果联合自注意力读取逐层 prefix K/V 与当前/此前动作，第 1、3、…、15 层只以 cross-attention 读取同层 prefix K/V。所有层都条件化于观测，但每层只执行一种注意力；公开 checkpoint 的 16↔16 路径可静态核验，减少专家层数的非默认路径存在索引与投影形状不一致，未经修正和测试不能直接启用。

16 layers8 个联合 SA 与 8 个 CA，逐层交错。
720 / 2048专家 residual hidden 与重算后的 FFN 宽度。
960 / 32015 个 Query heads 与 5 个 KV heads 的工作宽度。
50 × 32整块含噪动作输入与同形速度场输出。
16 KV pairs每个专家层读取同深度 prefix K/V。
0 runtime evidence只有静态源码、配置、论文与形状审计。
paper · Tables 6 / 7 / 9fixed code · layer dispatch/cachecheckpoint · standard 16↔16causal mask ≠ serial execution

角色卡与绝对尺寸

动作专家不是语言生成 head，也不是逐 token 自回归执行器。它一次接收 50 个含噪连续动作位置与一个样本级 Flow 时刻，使用观测 prefix 的逐层 K/V 作为条件，输出 [B,50,32] 条件速度场。动作反归一化、Euler 积分、动作队列与机器人安全均不属于本页。

CA 与联合 SA 的可见集合

两类层都从 720 维动作 hidden 生成 Query，也都读取同层 prefix 条件。区别只在于键值集合是否加入当前动作块的 K/V。

“每层读观测”与“只有联合层读动作历史”可以同时成立
层类型 Action Query 条件 K/V 动作 K/V 动作间可见性
cross-attention 当前动作 hidden 同层 prefix cache 无 无直接通路
因果联合 SA 当前动作 hidden 同层 prefix cache 当前全部动作位置 自身与此前位置

16 层交错、训练与推理

固定配置为 attention_mode="cross_attn"、self_attn_every_n_layers=2。这个名字不等于纯 CA：去噪时偶数层走联合 SA，奇数层走 CA。标准 16 层恰为 8+8，第 0 层是联合 SA。

训练：prefix 与 suffix 同时存在

训练使用 [prefix,suffix]、past_key_values=None、use_cache=false。联合层让 prefix 与 suffix 共用注意力接口；CA 层先更新 prefix，再让动作 Query 读取该层即时 K/V。prefix 与 suffix 都逐层演进，不是一份末层表示扇出给所有专家层。

final_norms: [vlm-text-norm, expert-norm]
loss_owner: smolvla-flow-matching

推理：一次 prefill，多次 suffix 查询

prefill 输入 [prefix,null] 并建立 16 层 K/V。每个去噪步只输入 suffix：联合层临时追加动作 K/V，CA 层不追加；两者只更新动作 hidden。步末 crop(prefix_len) 把 cache 恢复为 prefix 张量长度。缓存只能复用于同一固定观测的去噪轨迹。

schema: smolvla.action-expert-inference-path.v1
prefill:
  inputs_embeds: [prefix, null]
  creates_dynamic_cache: true
  all_layers_write_prefix_kv: true
denoise_step:
  inputs_embeds: [null, suffix]
  reads_same_layer_prefix_kv: true
  joint_layers_append_action_kv: temporary
  cross_layers_append_action_kv: false
  updates_prefix_hidden: false
after_step:
  crop_cache_to: prefix-tensor-length
cache_reuse_scope: one-fixed-observation-denoising-trajectory

训练的 use_cache=false 有完整 prefix 与 suffix；这不等于标准推理关闭 cache 后仍能获得条件。

逐层 KV、投影与矩阵规模

标准 16↔16 时，专家第 i 层读取 cache 第 i 层的 (K_i,V_i)。K 在缓存前已应用 RoPE，V 未旋转；这不是单份第 15 层特征，也没有证据为不同深度虚构“几何层/语义层”职责。

CA：缓存 K/V 的 320→320 接口

prefix cache 每位置为 [5,64]，展平后是 320。CA 把缓存 K/V 送入专用 320→320 投影；动作 Query 走 720→960，再按 15×64 分头。5 个 KV heads 以 3 组复制到 15 个 Query heads。320 是当前缓存接口选择，不是 cross-attention 的数学强制维度。

“未来动作不存在”是错误解释

推理时 50 个含噪动作 token 同时存在，双向 mask 在计算上可用。Table 7 的差异不是“训练看到未来、推理未来 token 不存在”的 availability mismatch。论文只概括为避免未来动作依赖；“小 t 时双向通路形成相关性捷径”是页面假说，尚未验证。

未验证假说：邻近含噪动作在某些 Flow 时刻可能高度相关，双向通路可能形成相关性捷径。要区分这一解释与更强观测依赖、轨迹平滑或物理因果性，需要按 Flow 时刻做观测敏感度、邻近动作消融、注意力质量与多 seed 对照。

LAPA 连续 latent 与动作空间 IDM

LAPA：视觉转移代理，不是可执行动作

VQ-VAE encoder 接收当前帧 x_t 与固定间隔后的 x_{t+H_latent}。训练 VQ-VAE 时使用最近码本向量重建未来帧；策略预训练读取量化前连续 embedding，并把它放在独立 LAPA embodiment 下作为 Flow target。

z_pre = E(x_t, x_{t+H_latent})
k* = argmin_k ||z_pre - e_k||_2
x_hat_{t+H_latent} = D(x_t, e_{k*})
policy target = z_pre under a distinct LAPA embodiment

H_latent 是视频帧间隔，H_policy=16 是策略动作块，二者不可混写。论文没有公开 N1 的完整 VQ-VAE 损失权重、码本大小、latent 维度或采样权重。latent 可能编码相机运动、光照、遮挡、背景与物体自主变化，视觉终态也不能唯一确定底层控制序列；跨本体检索只能支持定性一致性，不能证明动作等价或泛化收益。

IDM：按本体输出动作块，但仍是伪标签

动作空间 IDM 是另一套模型：输入当前与未来图像，按 embodiment 分别训练，用 System 1 DiT、SigLIP-2 表征与 Flow Matching，在 30K 或 60K steps 后预测与策略 horizon 相同的控制动作块。论文只报告初步验证中加入 state 或更多图像帧没有显著提升；这不证明两帧包含全部控制信息，也不证明状态必然产生捷径。

两种视频监督不能混为一种标签
维度 LAPA 动作空间 IDM
输入 当前帧 + 未来帧 当前图像 + 未来图像
输出 量化前连续视觉 embedding 本体控制动作块

神经轨迹：生成、筛选、成本与物理边界

固定事实链为 WAN2.1-I2V-14B + LoRA，以 3,000 条带语言真机样本、480P、81 帧、100 epochs 微调。多模态模型从初始帧识别对象并形成“物体从 A 到 B”的候选指令；生成后抽 8 帧检查指令遵循，不符合原指令的视频用 16 帧、256P 重新描述。

唯一成本公式如下：

827.3 h × 3600 s/h × 2 min/s ÷ 60 min/h = 99,276 L40 GPU-hours

论文另报约 105,000 L40 GPU-hours，并称 3,600 张 L40 约 1.5 天；直接相除是 29.17 h = 1.215 d，与 1.5 天不完全相等，差额原因未报告。105k L40 GPU-hours 也不能和策略预训练约 50k H100 GPU-hours直接比较成本或能耗。

仿真轨迹：DexMimicGen 机制与四种数字口径

预训练任务在 RoboCasa 中使用 54 个源—目标容器类别组合，每组合生成 10,000 条，共 540k。源示范是数十条 Leap Motion 遥操作，经 mink whole-body IK 重定向；场景随机化物体、容器并加入 distractors。DexMimicGen 将示范分割为对象中心子任务，按新物体位姿变换片段，保持末端—物体相对位姿，在当前状态和变换片段间插值并顺序执行，最后只保留仿真成功轨迹。

公开代码样本管线、特殊键与 mask 缺口

固定源码公开七类常规机器人配置：gr1_arms_waist、gr1_arms_only、gr1_full_upper_body、bimanual_panda_gripper、bimanual_panda_hand、single_panda_gripper、so100。它们声明 video、state、action、language key 的固定顺序，使用 observation index [0] 和 action indices 0..15。

典型静态链是：视频 tensor/crop/resize/color jitter；state/action tensor；按字段归一化并按需转换 rotation；依 manifest 顺序 concat；GR00TTransform 形成 64 维 state、32 维 action、mask、VLM 输入与 embodiment_id。schema 的 absolute 控制越界复制或零填充，continuous 约束归一化，rotation_type 控制表示变换；字段顺序是 ABI，不能只凭维数猜含义。

dataset.py 对 lapa_action 与 dream_actions 跳过普通 modality metadata，注释称 LAPA action 已归一化。这只证明特殊键入口存在；它不公开值的生成过程、latent 维度、专用 DataConfig、采样权重、human state 处理、双目标复制规则或完整预训练脚本。常规机器人路径默认的 has_real_action=true 也不是四分类 provenance。

公开 loader 在轨迹首尾越界时，对 absolute state/action 复制首值或末值，对 relative 使用零。_prepare_action 只按动作维创建 [16,32] feature mask，没有 temporal padding mask，所以 episode 尾部复制/补零的时间步仍可能在真实动作维上进入 loss。state 缺失时返回全零和全 false mask，大于64维截断、小于64维补零，但动作头不消费 state mask；action 大于32维 assert，小于32维补零，action mask 只用于 loss，不能阻止无效输入经 encoder 耦合。

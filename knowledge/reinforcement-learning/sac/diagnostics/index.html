07 · DIAGNOSTICS

先证明哪里错，再决定改哪个参数

自动温度 SAC 有 Actor、Critic、Alpha 三套相互耦合的优化器；固定温度版本没有 Alpha optimizer。单看一条 Loss 很容易误判：负 Actor Loss、负 Alpha Loss甚至正 log-prob 都可能完全正常。诊断应从环境与 shape 开始，再沿数据、Critic、Actor、温度和部署逐层收缩。

SAC 枢纽 ← 机器人与视觉 改进研究地图 →

诊断漏斗

flowchart TD
  E["1. 环境 API<br/>奖励、终止、动作范围"] --> D["2. 数据合同<br/>shape、dtype、scale、Replay"]
  D --> Q["3. Critic<br/>target、Q 偏差、TD error"]
  Q --> P["4. Actor<br/>mu、log_std、饱和、梯度"]
  P --> A["5. Temperature<br/>alpha、经验熵、目标熵"]
  A --> X["6. 部署<br/>延迟、归一化、安全层、执行动作"]
  X --> H["7. 最后才调超参数或更换算法"]

前两层若错，后面所有曲线都可能“有规律但无意义”。优先检查：[B,1] 广播、动作 scale/bias、tanh 修正、Target 初始复制、terminated/truncated 和评估 wrapper。

先区分“异常数值”与“异常行为”。Loss 正负、微分熵正负或单个 log density 的正负不是健康指标；NaN、无穷、持续饱和、梯度消失/爆炸、Q 与真实回报严重失配才是证据。

诊断前先固定三个口径

1. Soft Q 不是原始环境回报

SAC 的 Critic 满足

\[Q^\pi(s_t,a_t)=r_t+\gamma\,\mathbb E[V^\pi(s_{t+1})],\qquad V^\pi(s)=\mathbb E_{a\sim\pi}\left[Q^\pi(s,a)-\alpha\log\pi(a\mid s)\right].\]

因此，用 rollout 校准 Q 时应构造同一策略、同一终止语义和同一熵口径的 n-step soft return：

\[G^{\mathrm{soft}}_{t,n}=\sum_{k=0}^{n-1}\gamma^k r_{t+k} -\sum_{k=1}^{n-1}\gamma^k\alpha\log\pi(a_{t+k}\mid s_{t+k}) +\gamma^n V(s_{t+n}),\]

并在终止处去掉 bootstrap。原始 episode return、确定性代理策略的 return 和 soft Q 是三个不同对象，只能在说明差异后做尺度参考；单条 Monte Carlo 轨迹也不是 Q 的无噪声真值。

2. 熵、log-prob 与 target entropy 必须同坐标

记经验微分熵 \(H_{\mathrm{emp}}=-\mathbb E[\log\pi(a\mid s)]\)，代码目标为 \(H_{\mathrm{target}}\)。为与 Loss 页统一，本专题把 entropy gap 定义为

\[g=H_{\mathrm{emp}}-H_{\mathrm{target}} =-\mathbb E[\log\pi(a\mid s)]-H_{\mathrm{target}}.\]

于是严格 log 参数化温度目标可写成 \(J_\beta=e^\beta g\)，常见 surrogate 写成 \(L_\beta=\beta g\)；两者对 \(\beta\) 的梯度分别是 \(\alpha g\) 与 \(g\)。若 log-prob 包含环境动作缩放的 Jacobian，target entropy 也必须在环境动作坐标；否则 alpha 的“异常”只是口径错位。

3. tanh(mu) 不是 squashed Gaussian 的均值

常用确定性评估动作是 \(a_{\mathrm{det}}=c\odot\tanh(\mu)+b\)。通常 \(a_{\mathrm{det}}\ne\mathbb E[a]\)，所以本页统一称“确定性代理”，不称“均值动作”。随机策略与确定性代理是两种不同部署策略，必须分别报告。

十四类高频现象

Actor Loss 为负

机制
$$L_\pi=\mathbb E[\alpha\log\pi-Q]$$ 是待最小化目标，不是非负误差。Q 较大、奖励缩放或奖励加常数都可改变 Loss 数值；常数 Q 基线甚至可改变 Loss 而不改变 Actor 的动作梯度。
证据
梯度有限，soft Q 与同口径 return 大致校准，动作分布和评估回报正常。
动作
不要为“变成正数”修改公式；改看 Q 校准、entropy、动作饱和和 return。
误判
要求 Actor Loss 收敛到 0 会驱动无意义的调参。

Alpha Loss 为负或持续变号（仅自动温度）

机制
设 $$\beta=\log\alpha$$，并使用本专题统一的 $$g=H_{\mathrm{emp}}-H_{\mathrm{target}}$$。严格 log 参数化 Loss $$e^\beta g$$ 与常见 surrogate $$\beta g$$ 的梯度尺度不同，但更新方向相同；Loss 绝对值不是误差范数。surrogate 在 $$\beta=0$$ 时甚至可数值为 0 而梯度非零。
证据
同时画 `alpha`、$$H_{\mathrm{emp}}$$、$$H_{\mathrm{target}}$$ 与 gap。若熵低于目标，则 $$g<0$$，梯度下降应提高 beta/alpha；熵高于目标则 $$g>0$$ 并降低 alpha。
动作
验证 `log_prob.detach()`、target entropy 符号/坐标和实际采用的 alpha Loss 变体。
误判
只看 alpha loss 正负或是否趋零，忽略 gap 的定义与更新方向。

连续动作 log-prob 为正

机制
连续分布使用概率密度；窄分布的密度可大于 1，因此 log density 可为正。
证据
积分归一化由分布保证，单点密度不受 1 的上界限制。
动作
只有数值极端时检查 log_std、tanh Jacobian 和 action-scale Jacobian。
误判
把密度当作离散概率，强行 clamp log-prob 到非正。

Return 上升但 Q 持续爆炸

机制
奖励尺度、终止 mask、target 未停止梯度、过估计或 Actor 利用外推峰都可能让 Q 脱离合理尺度。
证据
比较 Q 与多条 rollout 的同口径 n-step soft return，检查 TD target/TD error 分位数、Q1/Q2 差值和 bootstrap 比例。
动作
先修 mask/target/shape；再降低 UTD、检查奖励和 Q 正则，而不是立刻裁剪 Q。
误判
拿确定性评估的原始 return 与 soft Q 逐点相等，或用短期 return 上升证明价值估计健康。

Critic Loss 很小，策略仍然很差

机制
自举系统可能对错误 target 内部自洽；Replay 覆盖窄、奖励漏洞或 Actor 查询 OOD 动作。
证据
held-out Bellman error、同口径 n-step/Monte Carlo 对照、策略动作相对数据覆盖的位置。注意 held-out target 仍来自自身网络，不是独立真值。
动作
扩展覆盖、修正奖励/观测、降低高 UTD 过拟合，并用动作切片检查 Q。
误判
把训练 MSE 或 held-out Bellman MSE 当作真实 Q 误差。

Q1 与 Q2 几乎完全相同

机制
误用同一模块对象、参数引用或保存/加载覆盖；共享 encoder 也会提高相关性。
证据
比较参数对象与 data pointer、初始化差异、同一 batch 的输出差分。
动作
独立实例化与优化；若共享表示，明确共享范围并监控 head disagreement。
误判
认为两条曲线重合代表“双重确认更稳定”。

Q 系统性低估

机制
clipped minimum 会引入保守偏差，另有 target 过慢、过强正则或截断 mask 错。
证据
比较 min/mean/max Q 与同口径 soft return；检查 Q1/Q2 噪声、策略动作排序和 true terminal 比例。
动作
修正语义错误后，再研究 TQC、REDQ 或适当聚合策略；不要直接把 min 改成 max。
误判
低估并不总是坏事，关键是是否破坏动作排序与策略学习；原始 return 与 soft Q 的差也不自动等于低估。

Alpha 持续趋近于零（仅自动温度）

机制
策略经验熵高于同坐标目标；漏 tanh 修正通常会把熵估高，而 scale Jacobian 遗漏的偏移方向取决于各维 scale；target entropy 符号或坐标错误也会造成同类现象。
证据
同时记录压缩前后 log-prob、log_std、动作直方图、饱和率和 entropy gap。
动作
先对照已验证的 log-prob 实现，再调整目标熵；不要直接设置 alpha 下限掩盖错误。
误判
alpha 小不必然表示策略确定，需看环境动作空间中的实际分布。

Alpha 持续增大（仅自动温度）

机制
策略过窄、log_std 卡下界、tanh 饱和、目标熵过高/不可达或 Actor 学习太慢。
证据
检查 `log_std` 贴边比例、pre-tanh `u`、mu 范数、entropy gap。
动作
修正饱和/范围/梯度，重新校准目标熵与 action scale。
误判
仅增大 Actor 学习率可能放大 Q 误差。

动作长期贴在上下界

机制
Q 在边界外推虚高、奖励鼓励极端动作、mu 过大、scale 错或安全层持续裁剪。
证据
比较 pre-tanh `u`、normalized `z`、command action 与 executed action。
动作
修正尺度与奖励；扩大边界附近数据；考虑动作变化/能耗约束。
误判
只看最终 action 无法区分策略饱和与安全层裁剪。

随机评估好，确定性代理评估差

机制
$$a_{\mathrm{det}}=\tanh(\mu)$$ 既不是压缩后分布均值，也不保证位于高 Q 区；非线性 Q 还使 $$Q(\mathbb E[a])\ne\mathbb E[Q(a)]$$。标准对角 Gaussian 不能表达任意多模态动作，增大方差可能同时覆盖多个高值区和中间低值区。
证据
同状态画策略样本与 Q 动作切片，对比 sampled 与 deterministic-proxy 的完整回报分布。用 Q 从多样本中择优属于新的 Q-filtered 策略，只能作诊断并需警惕 Q 外推误差。
动作
重新审视策略族、评估口径和任务多模态性，而非强行把 std 压到零。
误判
随机评估高可能由偶然尾部动作贡献，必须报告多 episode 方差、分位数与失败率。

确定性代理好，随机评估差

机制
策略中心位置已学对，但 alpha/方差过高，随机尾部动作危险。
证据
比较两种策略的 return 分布、失败类型和动作分位数。
动作
校准目标熵、奖励与安全约束；真机重点看尾部风险与安全触发。
误判
只报告确定性代理结果，会掩盖训练时随机策略的风险分布。

训练后期突然崩溃

机制
Replay 分布漂移、高 UTD 反复拟合、Q 偏差被 Actor 放大、归一化统计变化或旧覆盖被挤出。
证据
回看崩溃前 Q/target、alpha、saturation、gradient norm、buffer age 与策略动作 OOD 程度。
动作
保留崩溃前 checkpoint；降低 UTD；检查数据年龄和评价环境；做单因素复现。
误判
只从崩溃后的 Loss 找原因，忽略此前数千步的反馈累积。

从 checkpoint 恢复后行为改变

机制
遗漏 log_alpha、optimizer、normalizer、Replay、RNG、wrapper 或动作尺度；训练/评估 mode 不一致。
证据
保存前后同一观测批的 deterministic action、固定 RNG 下的 sampled action、Q1/Q2、alpha 与归一化输出逐项比较。
动作
建立 checkpoint schema 与 round-trip 单元测试；区分“推理等价恢复”“学习器继续训练”和包含环境/Replay/RNG 的“轨迹级精确恢复”。
误判
权重文件可加载不等于训练状态完整，也不保证下一条 transition 完全一致。

Tanh 与 log-prob 专项审计

正确关系：

\[u\sim\mathcal N(\mu(x),\sigma(x)),\quad z=\tanh(u),\quad a=c\odot z+b,\] \[\log\pi_A(a\mid x) =\log\mathcal N(u;\mu,\sigma) -\sum_j\log(1-z_j^2) -\sum_j\log|c_j|.\]

这里用状态 \(x\)、正尺度 \(c_j>0\)，避免让 s 同时表示 state 与 scale；\(\log\mathcal N\) 表示各动作维联合 log density。代码中优先用 pre-tanh 变量的稳定等价式

\[\log(1-\tanh^2 u)=2\,[\log 2-u-\operatorname{softplus}(-2u)],\]

再单独处理 \(\log c_j\)，避免在饱和区依赖任意 epsilon。

错误 结果 检查方式
对 action 再 tanh Jacobian 重复压缩 保存 u,z,a 分别对照
用 1-u^2 非变量变换公式 与 1-tanh(u)^2 比较
多维不求和 alpha 尺度随 shape 错 断言 log-prob [B,1]
忽略 scale 环境动作密度口径错 非 [-1,1] Box 测试
log(1-z²+eps) 的 epsilon 太大 饱和区修正被 epsilon 主导 与稳定 softplus 式比较
直接算 log(1-z²) 舍入到 z=±1 后出现 -inf 极端 u 压力测试，改用 softplus 式

现象 Q / target alpha log_std 饱和率 第一检查点
回报跌、Q 升 持续升或 gap 扩大 任意 任意 可能升 Q 过估计、奖励、覆盖

七个最小排障实验

单状态动作切片
固定状态，画 Q1/Q2 与策略样本，检查确定性代理是否落在低价值区。
固定 batch 重算
同时固定参数和 RNG，或缓存 next action，区分策略采样方差与参数变化。
固定 alpha 对照
暂时关闭自动温度，判断异常是否来自温度反馈。
单位动作空间
用保持物理执行动作不变的 wrapper 做 `[-1,1]` 对照，并同步变换 log-prob/目标熵；否则不是等价实验。
UTD 降为 1
在明确“Critic 批更新数 / 新增 transition 数”的定义下，排除高更新比的重复拟合与偏差累积。
双评估
同一 checkpoint 同时报告 deterministic-proxy 与 sampled action。
小环境多种子
用廉价环境建立回归门禁，避免单种子偶然性。

何时研究改进算法

  • 高 UTD 下 Q 偏差与样本效率：REDQ、DroQ、CrossQ。
  • clipped minimum 低估或需要细粒度偏差控制：TQC、REDQ 的 ensemble 聚合等。
  • 像素样本效率：DrQ、SAC+AE。
  • 固定离线数据的 OOD 估计：CQL。
  • 已有数据加少量在线交互：RLPD。
  • 真机样本昂贵且可学习动力学：MBPO。

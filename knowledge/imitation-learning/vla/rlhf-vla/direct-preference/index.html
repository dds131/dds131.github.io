RLHF-VLA/三分支架构/DPO、KTO 与 APO

DIRECT_PREFERENCE branch · training · comparison · data interface

DPO、KTO 与 APO 共享的是 Current/Reference 比率接口，不共享监督单元、标签含义或成立条件；选方法必须先选数据合同，再谈 loss。

本分支从 Architecture 直接进入，不要求显式 Reward Model、Critic、Old Policy 或 PPO。共同前提是 Current/Reference 对同一 action event 的 context、support、measure、transform、mask 与 aggregation 可证明兼容。

direct_preference branch16 versioned contractstarget training/evaluation: not-run

方法路由与三种监督单元

入口先读 supervision unit，不用方法热度或 loss 名称猜路由：

方法 合法输入单元 不足以单独构成输入 共同禁止偷换
DPO 同一 condition key 的 chosen/rejected pair 两条不同任务的 success/failure 用 outcome 当逐动作因果标签
KTO 单样本 action/sequence + desirable/undesirable 无固定定义的 thumbs-up/down 跨任务难度不校准地混合正负
APO 带事件时钟和 provenance 的 intervention-derived action 只有 episode success 或 generic pair 把 no-intervention 当 safe/success

pair | binary-desirability | intervention-derived-action | mixed | unknown 必须唯一声明。mixed view 先 materialize 为带独立 artifact/hash/schema/split 的方法专属 view，不能在同一 batch 动态猜 objective。

flowchart TD
  U[supervision unit] --> P{schema complete?}
  P -->|matched pair + same condition| D[DPO candidate]
  P -->|binary D/U + fixed semantics| K[KTO candidate]
  P -->|intervention timeline complete| A[APO candidate]
  P -->|mixed · missing · unknown| R[review · unsupported · reject]
  D --> C[probability compatibility + safety plan]
  K --> C
  A --> C

无脚本等价路由：matched pair 且 same-condition proven 才进入 DPO；binary desirability 且 label semantics 固定才进入 KTO；intervention-derived action 且 timeline 完整才进入 APO；随后三者都要独立通过 probability compatibility 与 safety evaluation plan。

DPO pair 保存 pair/condition IDs、两侧 serialized action、Current/Reference context identity、provenance/policy/time、annotator protocol、tie/abstain、mask/length/units/frame/execution 和 group split。KTO 样本保存 D/U/abstain/unknown、label revision/source/confidence、task difficulty、policy/operator、mask/weight/split。APO 保存 observe→infer→command→safety-filter→execute→intervene→takeover→correct 的时钟、policy/commanded/executed/corrective actions、label provenance、delay/window、human availability 与 monitoring coverage。

Current/Reference 概率、隐式 score 与生命周期

Current Actor 是唯一共同被优化候选；Reference 是 ratio denominator/behavior anchor，在 immutable run 或 APO loop 内冻结。即使两者起点 bit-identical，也保留不同 role、purpose、refresh、expiry 与 revoke。Reference 不接梯度、不属于 Current optimizer，也不能用 latest alias 漂移。

公共 score 定义为：

\[s_\theta(x,a)=\log \pi_\theta(a\mid x)-\log \pi_{ref}(a\mid x).\]

它随 Reference 改变，只在共同 action variable、context 和 base measure 下有意义；不是绝对任务 reward、显式 RM 输出、calibrated success probability 或安全分数，也不提供跨任意不同 $x$ 的可比尺度。

兼容收据逐项固定 observation/history/prompt serialization、tokenizer/vocabulary、action dimension/order/units/frame、codec/quantizer/normalizer/decoder、support/base measure、squash/scale/Jacobian/boundary、teacher-forced prefix、action/stop/pad/dimension/horizon/executed masks、aggregation 和 numerical policy。任一项 mismatch/missing/unknown，ratio fail closed。

对 action token：

\[\log\pi_\theta(a\mid h)= \sum_{k\in\mathcal M}\log p_\theta(u_k\mid h,u_{<k}).\]

$\mathcal M$ 只含本 objective 的 action factors。sum 是联合序列 log-prob；mean 是长度归一化 surrogate；per-control-step 是物理步目标；executed-prefix 只有在 conditioning/边缘化定义正确时合法。四者不是等价显示方式，Current/Reference 与正负两侧必须使用同一规则并报告有效长度。

Reference、codec/normalizer、context/mask、support/measure/transform、dataset/split/sampling/label、objective/β/weight/z0 estimator、parameter owner 或 safety protocol 变化，都创建新 run 或使旧 run invalid。revoked/corrupt/unknown lineage 不能警告后继续。

DPO：成对偏好、同条件与目标函数

对固定条件 $x$，DPO 来源推导写为：

\[\pi_r(a\mid x)=\frac{1}{Z(x)}\pi_{ref}(a\mid x) \exp\left(\frac{r(x,a)}{\beta}\right),\] \[r(x,a)=\beta\log\frac{\pi_r(a\mid x)}{\pi_{ref}(a\mid x)} +\beta\log Z(x).\]

在 Bradley–Terry 模型下，仅比较同一 $x$ 的 $a^+$ 与 $a^-$ 时，$\log Z(x)$ 相消：

\[\mathcal L_{DPO}=-\mathbb E\log\sigma\left( \beta\left[s_\theta(x,a^+)-s_\theta(x,a^-)\right] \right).\]

same-condition 不只是 instruction 字符串相同；它绑定 observation/history/time、robot/calibration/frame/control mode、initial state/scene/object、horizon/codec/mask/execution opportunity 和 evaluator view。若只能 matched/counterfactual 比较，必须标 exact | matched | approximate | counterfactual | unknown，不能宣称 exact same-state。

pair 保留 chosen/rejected/tie/abstain、exposure/order randomization、agreement/uncertainty、policy/version/quality provenance、length/factor count、理由、sampling probability/reweighting 和 group split。终局 outcome 回推单动作只能标 proxy。

DPO 增大 chosen 相对 rejected 的 reference-adjusted margin；因归一化与参数共享，不保证每个样本 chosen 绝对概率必升、rejected 必降，也不定义未比较动作的绝对 reward 或闭环安全。condition 不同、mask/action variable 不同、Reference 不可重放、pair/neighbor 泄漏、tie 被硬分、强混杂未分层或 probability unsupported 时不得 ready。

KTO：二元标签、KL 参考点与有偏估计

KTO 单元是 $(x,a,y)$，$y\in{D,U}$；它省去逐样本 pairing，不省去 label protocol、条件可比性、coverage 和 confound control。令

\[r_\theta(x,a)=s_\theta(x,a),\qquad z_0(x)=D_{KL}\left(\pi_\theta(\cdot\mid x)\Vert\pi_{ref}(\cdot\mid x)\right).\] \[v(x,a)= \begin{cases} \lambda_D\sigma\left(\beta[r_\theta-z_0]\right), & y=D,\\ \lambda_U\sigma\left(\beta[z_0-r_\theta]\right), & y=U, \end{cases} \qquad \mathcal L_{KTO}=\mathbb E[\lambda_y-v(x,a)].\]

$z_0$ 是 Current 相对 Reference 的群体参考点，不是负样本 reward、Critic baseline 或安全阈值。本页冻结 PMLR 235/ICML 2024 已发表版与 arXiv:2402.01306v5 为两个来源记录；不能用一个“最新论文”覆盖版本差异。

v5 描述的实用近似为错配 microbatch surrogate：

\[\hat z_0=\max\left(0,\frac{1}{m}\sum_{i=1}^{m} \log\frac{\pi_\theta(a_{j(i)}\mid x_i)} {\pi_{ref}(a_{j(i)}\mid x_i)}\right).\]

它必须标 biased，clamp 为 max(0, mean)，且 gradient_through_z0: false；不是 exact per-context KL。manifest 固定 shift/permutation、seed/order、microbatch/accumulation、local-rank 或 global-reduced、mask denominator、effective count、empty/singleton 和 NaN/Inf policy。local/global 语义、shuffle、drop-last 或 batch composition 都可能改变 surrogate。

D/U label 同时审计 task difficulty、policy version、operator/evaluator、safety abort/takeover、length/modality、class balance 与 sampling weight。任何 λD/λU 或 class ratio 范围只按具体 source/version 记录，不能冒充 current v5 canonical、VLA 默认或理论保证。

APO：干预标签、动作 token 与误差重加权

本页 APO 只指 Human-assisted Robotic Policy Refinement via Action Preference Optimization；冻结证据是论文 v3 的 human-assisted autoregressive action-token VLA。diffusion、flow 和一般 regression policy 是 transfer hypothesis，不是原公式已验证范围。

事件时钟为 observe → policy-infer → command → safety-filter → execute → human-detect → intervention-start → takeover → corrective-action → resume/reset。

c 来源 分支 语义与风险
1 专家示范动作 desirable strong-positive candidate；保留 demonstrator/protocol
1 未触发介入的策略动作 desirable weak-positive only；必须有 monitoring coverage/availability
2 接管后的纠正动作 desirable corrective-positive；绑定 takeover alignment/control mode
0 介入前 K 步策略动作 undesirable reaction-delay proxy；不是精确失败起点
unknown 缺事件或不可归因 exclude/review 保留 missingness reason

K 绑定 control frequency、human reaction distribution、inference/command/execution latency、chunk queue/replan、intervention timestamp、task dynamics、false/missed intervention 和 monitoring gaps。论文 K=10 只是 source-domain reported setting，不是新机器人默认值。

对 action token：

\[r_\theta(o,\hat a)= \log\frac{\pi_\theta(\hat a\mid o)}{\pi_{ref}(\hat a\mid o)}.\]

APO 可按 c 分到 KTO 同方向 utility；Reference 只在 deployment–optimization loop 边界 snapshot，不能在 optimizer steps 同步刷新。连续动作误差权重为：

\[l_i=\|\tilde a_\theta(o_i)-a_i\|_1, \qquad w_i=\frac{l_i}{\varepsilon+\sum_{j=1}^{B}l_j},\] \[\lambda_{D_i}=1-e^{-\beta_Dw_i}, \qquad \lambda_{U_i}=e^{-\beta_Uw_i}.\]

必须固定 decode/argmax/sampling 与 codec、units/normalization/L1 reduction、epsilon/batch/mask/denominator、detach path、zero-sum/NaN/Inf/outlier policy 和 sampling ratio。若 discrete argmax decode 后 detach，权重只重标 utility，不产生额外 regression gradient。官方仓库 commit 未固定时，代码级行为只能标 paper-described | code-unpinned。

no-intervention 还可能来自后果未显现、人类忙碌、监控缺失、阈值偏高、接管太迟或自动安全阻断，因此不等于安全成功。takeover 后未执行 suffix 不按真实后果归因，corrective action 也不能无差别并入普通 expert demo。

证据层总图锚点 ## 证据层与双专家总图 继承双专家骨架锚点 论文完整配方中，图像、prompt与离散state构成全可见prefix；FAST动作token形成因果离散块；连续动作expert形成块内双向的连续块。连续块能看prefix与自身，但看不到FAST；任何VLM embedding都看不到连续动作expert，避免两种动作表示互相泄漏。 固定提交 215abfb217dbac7d5f1273282331b9b1866c0479 的 Pi0 是flow-only路径：embed_prefix只含图像、语言和可选离散state，embed_suffix只含连续动作与time条件，make_attn_mask形成prefix/suffix两块。固定 compute_loss没有FAST动作token或文本logits损失，不能把论文完整训练序列塞进这一函数。 两层共同继承π0/PaliGemma双专家：SigLIP视觉token与语言token进入约2B VLM expert，连续动作进入约300M action expert；两expert在联合attention中沿序列轴拼接Q/K/V，但保留各自投影、norm与FFN参数。双专家原理回到 π0 Architecture 与公共VLM grounding，本页不重讲SigLIP内部教材。

Token ledger

输入：图像、prompt、可选离散state、连续动作。输出：paper六段或fixed两段序列。证据层：PAPER_FULL_RECIPE / CODE_215ABFB。

Paper FAST长度、固定prompt容量与单样本有效长度必须分栏；FAST不进入固定 Pi0.compute_loss。

Mask truth table

输入：query block、key block与 ar_mask。输出：可见/不可见关系。证据层：论文Fig.18或固定 make_attn_mask。

上文两张四列表已分别覆盖query block、key block、可见/不可见和证据层；不得把两者合并成一条运行路径。

Shape ledger

输入：residual width、query projection width、head dimension、sequence length、action dimension与horizon。输出：拼接兼容条件和容量上界。证据层：CODE_215ABFB / DERIVED_STATIC。

这些轴不能互换：query width可为2048而action residual width为1024；序列1018也不是action dimension。

价值函数合同锚点

EQ.1 · EQ.5 · DISTRIBUTIONAL VALUE

样本回报是标签，价值是行为分布下的条件期望。终止结果先变成逐步奖励与经验回报，再经未公开的离散规则形成201箱监督；价值网络输出概率分布，按箱代表值取期望后才得到标量。

奖励定义锚点

奖励与经验回报

Eq.5三种奖励；C_fail仅知为足够大的常数
情形 奖励 边界
成功且t=T r_t=0 成功终止。
失败且t=T r_t=-C_fail 具体值、任务变化及与最大长度关系未报告。
其他步 r_t=-1 逐步代价把速度信息带入回报。

经验回报锚点

无折扣经验回报为R_t(τ)=Σ_{t'=t}^T r_{t'}。成功轨迹代数上有R_t(τ)=-(T-t)，只是单条样本从t到终止的负剩余步数。V^{π_ref}(o_t,l)是给定观测和语言、在行为分布下的未来回报条件期望；若同一观测可成功或失败，它同时混合失败概率与后续行为，不能把V=-k译成“必定还需k步”。

任务级归一化锚点

任务级归一化

论文实践把价值预测按各任务最大episode长度归一化到(-1,0)，0对应成功完成。原始-C_fail不直接等于区间端点；跨任务的-0.5也不保证同一成功概率、秒数或难度。

NOT_REPORTED：最大长度来自协议上限还是数据最大值、端点/失败值映射、超长轨迹处理、clip、epsilon与数值精度。页面不构造未报告归一化公式。

201箱分布与Eq.1

Eq.1锚点

回报分布交叉熵保留数据集、轨迹和时间三层
对象 定义 边界
分布 p_φ(V|o_t,l)∈Δ_B，B=201 distributional value不是分布式训练，也不是201个独立回归器。
目标 把R_t(τ)离散为R_t^B 箱上下界、宽度、代表值、硬分配/插值、越界与端点处理未公开。

标量价值锚点

从分布还原标量

V^{π_ref}(o_t,l)=Σ_b p_φ(V=b|o_t,l)v(b)，其中v(b)是箱b代表值；该期望进入下一页优势估计。但v(b)表、箱边界和归一化值到箱索引映射未公开，所以Eq.1不足以独立复现标量出口。

完整分布理论上可保留超过均值的信息，仅标EDITORIAL_EXPLANATION。论文未报告校准、NLL/Brier、置信区间、多峰案例或标量MSE消融；不得把“201箱改善梯度/不确定性”写成作者动机或已证优越性，实际是否校准仍未知。

Monte Carlo边界锚点

Monte Carlo、无折扣与非自举边界

当前目标来自完整轨迹，不从下一状态价值预测自举
可确认 不能确认

行为分布锚点

π_ref与估计对象

预训练时D对应人类演示；迭代后估计偏向演示回报与学到策略回报的加权组合。π_ref不是当前单一策略，而是人类与多代部署策略的行为混合。新rollout改变数据分布，也改变价值估计对象；这是状态账本事实，不是Algorithm 1每轮重训的“根本原因”，论文重启理由仍是避免漂移。

NOT_REPORTED：演示/旧策略/新策略/介入的来源比例、采样权重、旧新轨迹再平衡和任务平衡。阈值是否重估及其影响下沉Advantage。

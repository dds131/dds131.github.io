ACT · 动作分块 Action Chunking

CORE 2 OF 8 · REPRESENTATION · TRAINING TARGET · EXECUTION CONTRACT

Action Chunking 把策略目标从“预测下一步”改成“从同一当前观测联合预测未来一段动作”。

单步 BCo_t → â_t：一个观测对应一个动作标签。
动作块监督o_t → â[t:t+H)：同一条专家轨迹上的连续 H 步构成一个有序目标。
H · Prediction horizon一次前向预测多少个动作；训练时固定并影响模型形状。
E · Execution window一次查询结果最多连续提供多少个实际低层动作。
R · Replanning period相邻两次策略查询间隔多少个控制步。

H、E、R 不是同一个量。关闭时间集成并整块消费时通常有 E=R=H；ACT 公开实现开启时间集成时保持 H 不变，而 E=R=1。

单步 BC 与动作块的监督对照

单步策略与动作块策略可以从同一个观测起点比较，不需要先引入 latent 或 Transformer：

\[\text{single-step:}\quad \pi_\theta(o_t) \rightarrow \hat a_t, \qquad \text{chunk:}\quad \pi_\theta(o_t) \rightarrow \hat a_{t:t+H-1}.\]

动作块目标是同一条专家轨迹上按时间顺序截取的连续动作段。它改变的是输出覆盖的时域和监督对象，而不是把一条轨迹复制成 H 份独立样本。相邻动作通常高度相关，episode 尾部还可能包含补齐位，因此不能声称信息量自动增加 H 倍。

两种目标使用同一观测起点，区别在输出时域
维度 单步 BC Action Chunking 边界
目标 a_t a[t:t+H) 动作段有时间顺序，不是 H 个独立标签。
输出形状 [B,d_a] [B,H,d_a] H 是动作数，不是图像高度。
局部协调 只在每步损失中间接体现 整段动作共同作为监督目标 联合目标不自动保证平滑或协调。
网络要求 不限 不限 动作块不必然要求 Transformer 或并行解码。

ACT 的固定实现使用 action queries 一次给出 H 个位置，这是该模型的实现事实；“非自回归”不是所有动作块策略的定义。query、decoder 和位置表示由 DETR-style Transformer 页面解释。

两种公开执行配置

同一个 H 可以搭配不同执行与重规划协议
配置 H E R 闭环含义
关闭 temporal aggregation，整块消费 训练固定 H，末块可按 episode 余量裁断 H 块内不会因新观测改变已选动作。

随机起点、对齐分支与尾部补齐

官方 EpisodicDataset 以 episode 为数据项；每次取样时先在该 episode 内随机选择 start_ts，而不是预先展开所有时间步。仿真分支从 start_ts 取动作，公开真机分支从 max(0,start_ts-1) 取动作。后一项是该数据记录方式的实现对齐，不是所有机器人的普适时间规则。

ACT 的动作表示

ACT/ALOHA 公开接口中的单步动作语义是绝对目标关节位置。在该双臂系统里，公开实现的本体状态和动作均为 14 维；这个数字绑定 ALOHA，不是 ACT 方法对所有机器人的固定维度。

它是什么按时间排序的绝对目标关节位置，块形状为 [B,H,d_a]。
它不是什么不是关节速度、位置增量、末端位姿、力矩或接触力输出。
系统仍需什么低层位置跟踪、限位、碰撞处理、时序监督与独立安全层。

绝对位置避免在数值表示层把预测速度或增量连续积分成后续目标，但不消除物理误差传播：跟踪误差、碰撞、形变和物体滑动仍会改变未来状态。关闭逐步重规划时，块尾动作还可能基于过期观测。训练与部署也必须使用匹配的标准化统计；具体统计生成、保存和加载属于 Training/Source Code 页面。

源页的 reactive_cup.mov 与 robot_obs/open_cup.mp4 本页不再内嵌：前者不能单独把反应性归因于 Temporal Ensembling，后者更适合可观测性与局限讨论。删减只为收窄页面职责，不表示源证据失效。

有效决策时域的边界

论文把动作分块描述为缩短有效时域。这个直觉最清楚的语境是：关闭时间集成、每次查询后完整消费 H 个动作。长度为 T 的 episode 仍执行 T 个底层控制动作，但策略查询或宏观决策点约为

\[N_{\mathrm{query}}=\left\lceil \frac{T}{H}\right\rceil.\]

这个宏观直觉不能变成一条新的理论保证。不得把 DAgger 文献中带条件的单步 0–1 不一致率与任务代价分析，直接用 T/H 替换 T，再套到 ACT 的连续 L1 动作块损失。完整条件见 Background；本页只保留防误推边界。

块长 H 的折中与口径

两端代价

H 不是越大越好；执行协议决定长块的实际风险
H 的变化 可能收益 可能代价 必须同时检查
较小 预测更近；整块消费时更快重新观测。 局部时间结构覆盖更短；查询更频繁。 控制频率、推理延迟与最小协调尺度。
较大 表达更长的动作关联；整块消费时减少高层查询。 块尾更难预测；query/位置表更大；整块消费时反应更慢。 可预测尺度、E/R、算力与扰动风险。
H=1 退化为单步输出。 失去多步目标。 不表示 CVAE 或 Transformer 必然消失。
H=T 覆盖整段 episode。 仅在 E=R=H 时成为一次性开环轨迹。 开启每步重规划时仍会重复查询。

90、100 与 1.8 秒不能混写

两个 H 来自不同公开语境；1.8秒是换算值而非实测延迟
事实 值 来源域 不能推出
真机 ALOHA chunk size 90 ALOHA 官方项目页 ACT 论文或所有真机的统一 H。
真机控制频率 50 Hz ALOHA 官方项目页 本站实测控制频率。
90 步物理跨度 1.8 s 90/50 的标注推导值 推理延迟、语义子动作长度或实测反应时间。
论文附录 / 官方仿真命令 100 ACT Table III / 官方仓库 README 真机统一配置。

改变 H 还会改变固定实现中的 num_queries、query embedding 和相关位置表形状，所以它不是部署后可随意改动的裁剪参数。新平台应根据控制频率、任务可预测尺度、E/R、反应性和资源成本做验证；本页不给出一个虚构的通用推荐值。

执行窗口、重规划与 Temporal Ensembling 接口

当 R<H 时，相邻查询覆盖的未来时间范围相交，于是形成重叠预测：同一个实际执行时刻可能收到多个候选。这个“生产冗余候选”的接口只在本页定义到此；候选集合、二维缓冲区索引、指数权重方向、系数、融合伪代码与平滑/响应权衡都由 Temporal Ensembling 页负责。

失效条件、证据边界与下一页

何时应怀疑动作块合同

块内未见扰动整块消费时，扰动后的动作继续依赖块首旧观测。
关键接触不可观RGB与关节位置不能唯一判断贴合、夹紧或卡住；融合无法补出未观测信息。
反应尺度短于 E任务需要更快重规划时，长执行窗口会使候选过期。
块尾多种可行未来单一 L1 回归可能在多个合理动作段之间折中。
归一化合同不一致训练与部署统计不匹配会改变动作幅值，即使结构和 H 都正确。

交给 CVAE 的问题

下一页接收固定目标形状 [B,H,d_a] 和 H/E/R 合同。剩余问题是：同一个当前观测可能对应多个合理未来动作块，确定性单一 L1 回归可能形成折中。CVAE 页面解释条件潜变量、训练后验与部署路径；它不会重复标签切片、90/100 口径或执行协议。

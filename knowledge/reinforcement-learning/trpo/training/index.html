TRPO 的创新是怎样更新策略，不是某种固定网络层。前四页已经完成了理论下界、可计算约束、自然梯度和数值求解；本页把它们装入一个完整训练系统：Actor 产生分布，Critic 提供基线，轨迹缓冲区处理终止与截断，GAE 固化优势，Actor 经过信任域更新，Critic 再做回归。

训练链位置：策略网络与价值网络 → on-policy 采样 → 终止/截断 bootstrap → TD 残差 → GAE 与价值目标 → Actor 信任域更新 → Critic 回归 → 记录诊断 → 丢弃旧策略批次

先澄清一个常见误写：TRPO 不要求固定 MLP、固定 CNN、GAE 或 Adam Critic。只要策略能计算动作对数概率、新旧分布 KL、策略梯度和 KL 的 Hessian-vector product，就可以使用不同骨干。论文原始算法、GAE 论文实验与现代库是三个历史层次，本页会分开标注，避免把今天的默认值倒写成 2015 年算法定义。

一、完整系统的模块边界

π_θ(·|s_t)"] A --> X["采样动作 a_t"] X --> E["环境"] E --> R["奖励 r_t
terminated / truncated"] S --> V["Critic
V_φ(s_t)"] R --> B["轨迹缓冲区"] V --> B A --> B B --> G["TD 残差与 GAE
冻结 Â_t、R̂_t"] G --> P["Actor 分支
目标梯度 + FVP + CG + 线搜索"] G --> C["Critic 分支
价值回归"] P --> N["新策略 θ"] C --> W["新价值参数 φ"]

模块之间最重要的契约是：

  • 缓冲区必须保存旧策略信息，不能更新后再临时重算；
  • 优势与价值目标必须在 Actor、Critic 任一参数更新前计算并冻结；
  • 在本页讨论的标准矩阵自由实现中，Actor 参数由 CG、定标与线搜索写回，不经过 Adam 式 optimizer.step()；
  • Critic 可以对同一批价值目标做多次梯度回归；
  • 下一轮 Actor 必须重新用当前策略采样，不能把旧批次当成 PPO 数据多轮复用。

二、原始 TRPO 论文中的策略网络

2.1 连续控制：对角高斯策略

连续动作策略写成

\[\pi_\theta(a\mid s) = \mathcal N \left( \mu_\theta(s), \operatorname{diag}(\sigma^2) \right)\]

神经网络输出状态相关均值 (\mu_\theta(s))，而 (\log\sigma) 是与状态无关、可训练的独立参数向量。Swimmer、Hopper、Walker 等任务使用了不同的隐层规模；这说明网络容量是实验配置，不是 TRPO 理论的一部分。

原论文实用算法使用采样回报构造 (Q) 或优势估计，没有现代 on-policy 库中常见的神经网络 Critic 加 GAE 组合。

2.2 Atari：小型卷积策略

论文的 Atari 策略包含：

  • 两层卷积，每层 16 个通道、步长 2；
  • 一层 20 单元全连接隐层；
  • softmax 类别分布输出；
  • 总策略参数量约 33,500。

论文还把多分量离散动作建模为多个类别分布的乘积。这里的结构服务于当时的计算预算；现代 CNN 更大并不会让算法“更像 TRPO”，真正决定算法身份的仍是策略更新规则。

2.3 原论文明确没有的现代组件

组件 2015 TRPO 原论文实用算法 现代常见 TRPO
神经网络 Critic 不是主算法必需组件 通常有
GAE 尚未作为该论文算法的一部分 通常采用
Adam 训练 Critic 不是原论文标准设置 常见
Actor 与 Critic 共享骨干 不适用 框架可支持，但要防参数泄漏
优势标准化 不是算法定义 常见工程选项

三、现代 Actor-Critic 形态

3.1 离散动作 Actor

网络输出 logits (z_\theta(s))，再构造类别分布：

\[s \longrightarrow z_\theta(s) \longrightarrow \pi_\theta(a\mid s) = \operatorname{softmax}(z_\theta(s))_a\]

训练系统至少要能返回：

  • 采样动作；
  • 该动作的 (\log\pi_\theta(a\mid s))；
  • 分布熵；
  • 与冻结旧分布之间的解析 KL。

直接对概率做手工截断会改变 KL 几何；更稳妥的是由框架的 Categorical 分布从 logits 计算 log-prob 与 KL。

3.2 连续动作 Actor

常见形式是对角高斯：

\[s \longrightarrow \mu_\theta(s), \qquad a\sim \mathcal N \left( \mu_\theta(s), \operatorname{diag}(\sigma_\theta^2) \right)\]

(\log\sigma) 可以是状态无关参数，也可以由网络输出。状态无关形式更接近 TRPO 论文和 Spinning Up；状态相关形式表达力更强，但会改变 Fisher 结构、探索动态与数值条件。

若环境动作有界，还必须区分：

  • 高斯采样后由环境裁剪；
  • 用 tanh 变换分布并包含 Jacobian 修正；
  • 只对均值做 tanh，而采样分布仍在无界空间。

这些并非等价实现，尤其会影响 log-prob、KL 与动作边界附近的行为。

3.3 Critic

Critic 输出单个标量：

\[V_\phi(s)\in\mathbb R\]

它不直接决定动作，也不出现在 Actor 的 KL 公式中；若与 Actor 共享参数，第四节的隔离问题是例外。其主要职责是：

  1. 作为策略梯度基线降低方差；
  2. 提供 TD 残差；
  3. 在 rollout 被时间限制或固定批长截断时提供 bootstrap；
  4. 给出用于监控的价值误差与 explained variance。

四、Actor 与 Critic 是否共享网络

可以有三种结构：

完全独立

Actor 与 Critic 各自拥有特征提取器。参数边界清晰，最容易保证 Critic 更新不会绕过 KL 约束改变策略。

教学实现优先

共享骨干、分离头

节省计算与样本，但 Critic optimizer 若修改共享参数，也会改变策略分布。

需要显式梯度隔离

共享视觉特征

图像任务常共享 CNN，再分出策略和值头；任何共享层变化都必须纳入策略更新语义。

高风险边界
TRPO 的 KL 约束只保护它实际控制的策略参数更新。若 Critic 的普通梯度步骤修改了共享特征，策略会在没有线搜索的情况下改变。SB3-Contrib 的实现会在 Critic 更新时处理共享参数梯度；自定义实现仍应在每次 Critic 更新前后测量策略 KL，验证隔离是否成立。

六、轨迹边界：terminated 不等于 truncated

值函数 bootstrap 的核心公式是

\[\delta_t^V = r_t + \gamma m_t V_{\phi_{\mathrm{old}}}(s_{t+1}) - V_{\phi_{\mathrm{old}}}(s_t)\]

其中 (m_t) 是 bootstrap mask：

  • 真正的 MDP 终止（terminated）时，(m_t=0)；
  • 时间上限、固定 rollout 长度或外部截断（truncated）时，若下一状态有效，通常 (m_t=1)；
  • 批次末尾但 episode 未结束时，同样要从最后状态 bootstrap。
旧版环境接口常把两种情况都压成一个 done。若把所有 done 都当成真正终止，时间限制处的未来价值被强制设为零，会系统性低估边界状态，继而污染 TD 残差、GAE、Critic 目标和 Actor 梯度。

还要区分两个 mask：

  • bootstrap mask：决定 (\delta_t^V) 是否包含下一状态价值；
  • recursion mask：决定 GAE 是否跨越当前 episode 边界传播。

固定批长截断允许 bootstrap，但不能把优势递推串到 reset 后的另一个 episode。向量化环境还必须读取截断 transition 的最终观测来算 (V(s_{t+1}))，不能误用自动 reset 后的新 episode 初始观测。

七、从 TD 残差推导 GAE

7.1 一步、两步与 (k) 步优势

一步估计就是 TD 残差：

\[\hat A_t^{(1)}=\delta_t^V\]

两步形式为

\[\hat A_t^{(2)} = \delta_t^V+\gamma\delta_{t+1}^V\]

一般的 (k) 步形式：

\[\hat A_t^{(k)} = \sum_{\ell=0}^{k-1} \gamma^\ell\delta_{t+\ell}^V\]

当中间价值项展开时会望远镜消去，剩下 (k) 步折扣奖励、末端 bootstrap 与当前价值基线。

7.2 对不同时间跨度做指数混合

在同一 episode 的理想无限序列上，当 (0\le\lambda<1) 时，GAE 用 (\lambda) 对各阶估计做归一化的指数权重：

\[\hat A_t^{\mathrm{GAE}(\gamma,\lambda)} = (1-\lambda) \sum_{k=1}^{\infty} \lambda^{k-1} \hat A_t^{(k)}\]

交换求和次序后：

\[\boxed{ \hat A_t = \sum_{\ell=0}^{\infty} (\gamma\lambda)^\ell \delta_{t+\ell}^V }\]

GAE 不是另一种价值函数，而是把不同长度的 TD 残差组合成策略梯度需要的优势估计。

(\lambda=1) 不能直接代入前一行带 ((1-\lambda)) 的混合式，而应取极限；在轨迹真正终止或末端 bootstrap 正确时，它化为折扣 Monte Carlo return 减去 (V(s_t))。有限 rollout 也不是字面上的无限和，而是在边界处停止递推并按下一节处理末端价值。

7.3 有限 rollout 的反向递推

实际缓冲区从后向前计算：

\[\hat A_t = \delta_t^V + \gamma\lambda\,c_t\hat A_{t+1}\]

(c_t) 是“下一个优势项是否仍可沿同一 episode 递推”的 mask。普通的同 episode transition 取 1；真正终止、时间上限后发生 reset，或下一个样本来自另一个 episode 时取 0。它与 bootstrap mask (m_t) 不能合并：时间上限截断常见的是 (m_t=1)（保留最终状态价值），但 (c_t=0)（不跨 reset 递推）。固定 rollout 分块若保留了同 episode 的后续信息，也可以跨块继续递推；否则就在块边界用 bootstrap 截断。

价值回归目标为

\[\hat R_t = \hat A_t + V_{\phi_{\mathrm{old}}}(s_t)\]

注意右边必须使用计算优势时的旧价值预测；优势与目标一旦算完就固定。若随后标准化优势，Critic 目标仍使用标准化前的 (\hat A_t)，不能把归一化后的优势重新加回价值预测。

八、(\gamma) 与 (\lambda) 分工不同

参数 控制什么 端点 偏差来源
(\gamma) 折扣目标、价值函数尺度与长程权重 越小越强调短期奖励 即使 Critic 精确，(\gamma<1) 也会改变相对未折扣目标的梯度
(\lambda) 不同跨度 TD 残差的混合 0 为一步 TD；1 的极限在正确边界处理下为折扣 Monte Carlo 减基线 (\lambda<1) 的额外偏差依赖 Critic 不准确程度
  • (\lambda=0)：低方差，但强依赖当前 Critic；
  • (\lambda=1)：若终止与末端 bootstrap 正确，得到折扣 Monte Carlo return 减基线，通常方差更高；
  • 中间值在许多连续控制任务上更实用，但不是普适定理。

GAE 论文实验比较了多种 (\lambda)；现代代码常见 0.95 或 0.97，但这只是经验默认值。具体选择必须与 rollout 长度、奖励尺度、Critic 容量和环境时间尺度一起验证。

九、优势标准化：理想不变，有限实现仍会受影响

现代实现常对一批优势做

\[\tilde A_t = \frac{ \hat A_t-\operatorname{mean}(\hat A) }{ \operatorname{std}(\hat A)+\epsilon }\]

减去批均值看起来像加入一个常数基线，但这个均值由同一批动作和回报估计，有限样本下会改变梯度估计，不能直接当作严格无偏恒等变换；除以标准差则改变梯度整体尺度。子页 ③证明，在精确解析步中，优势乘正数会被信任域缩放因子抵消，所以理想 TRPO 对纯比例缩放不敏感。

有限实现仍可能变化，因为：

  • 减均值并非纯比例缩放；
  • CG 轮数有限；
  • 阻尼改变了精确自然梯度；
  • 线搜索接受谓词对数值误差敏感；
  • 小批量 Critic 与 FVP 子采样引入额外噪声。

因此必须记录是否标准化、统计量在何种范围上计算，以及分布式训练中是否做全局聚合。

十、Actor 的目标、约束与“loss”说法

固定旧策略数据后，样本替代目标为

\[\hat L(\theta) = \frac1N \sum_{t=1}^N \exp \left( \log\pi_\theta(a_t\mid s_t) - \log\pi_{\mathrm{old}}(a_t\mid s_t) \right) \hat A_t\]

约束为

\[\hat{\bar D}_{\mathrm{KL}} \left( \pi_{\mathrm{old}}, \pi_\theta \right) \le\delta\]
替代目标是要最大化的目标，KL 是约束，不是两个普通 loss 的加权和。源码常定义 policy loss 为负替代目标，便于自动微分框架按“最小化”习惯计算梯度；符号改变不代表算法变成惩罚法。

Actor 更新步骤是：

  1. 对替代目标求梯度；
  2. 用 KL-HVP 和 CG 求方向；
  3. 按 (\delta) 定标；
  4. 回溯检查真实目标与 KL；
  5. 直接写入接受的参数。

在标准 CG + 回溯实现中，没有 Actor 的 Adam 学习率，也不会用 Adam 的 optimizer.step() 完成策略步；若软件把参数写回封装成“优化器”接口，也必须仍然实现同一个受约束求解与验收语义，不能因此变成多轮一阶训练。

十一、Critic 的目标与三种历史形态

11.1 现代常见均方误差回归

\[L_V(\phi) = \frac1N \sum_{t=1}^{N} \left( V_\phi(s_t)-\hat R_t \right)^2\]

可用 Adam 做若干次全批或小批量更新。这里的学习率是 Critic 学习率，不能误写成 TRPO 的策略学习率。

11.2 GAE 论文中的价值函数信任域

GAE 论文实验还对价值更新施加类似约束：

\[\frac1N \sum_n \frac{ \left( V_\phi(s_n)-V_{\phi_{\mathrm{old}}}(s_n) \right)^2 }{ 2\sigma^2 } \le\epsilon\]

若把价值输出视为固定方差的条件高斯，这正是平均 KL 形式。它是 GAE 论文的实验设置，不是所有现代 TRPO 实现的标准要求。

11.3 原始 TRPO 的回报估计

原始 TRPO 实用算法可以直接由采样轨迹构造 Monte Carlo (Q) 估计，并不要求神经 Critic。因此“TRPO 必须带 Critic”是现代实现习惯，不是算法定义。

十二、更新顺序：优势必须先冻结

推荐的数据依赖顺序如下：

flowchart TD A["用 θ_old 采样并保存旧分布信息"] --> B["用 φ_old 计算 value 与末端 bootstrap"] B --> C["反向递推 TD residual、GAE、价值目标"] C --> D["冻结 Â 与 R̂"] D --> E["Actor: 梯度、FVP、CG、线搜索"] D --> F["Critic: 若干次回归"] E --> G["记录新旧目标、KL、回溯信息"] F --> G G --> H["丢弃策略批，使用 θ_new 重新采样"]

GAE 论文明确说明优势使用本轮旧价值函数 (V_{\phi_i})，而不是更新后的 (V_{\phi_{i+1}})。优势和价值目标必须在任何参数更新前算好并停止梯度。Actor 与 Critic 参数完全独立，或 Critic 更新被证明不会改变策略分布时，两者的优化先后可以互换；若存在共享参数泄漏，先更新 Critic 会连 Actor 的展开中心都一起改变，不能只靠“优势已冻结”来保证正确。

若先把 Critic 过拟合到本批回报，再用更新后的 Critic 重算 TD 残差，残差可能被压得很小，Actor 会看到接近零的优势。这不是策略已收敛，而是数据依赖顺序被破坏。

十三、一轮训练的数据生命周期

  1. 用当前策略收集固定步数或若干完整轨迹。
  2. 保存 observation、action、reward、terminated、truncated、旧 value、旧 log-prob 和重建旧分布所需参数。
  3. 对未真正终止的末状态计算 bootstrap value。
  4. 从后向前计算 TD 残差与 GAE。
  5. 构造固定 value target。
  6. 可选地对优势标准化。
  7. 在完整策略批上计算 Actor 梯度。
  8. 用 FVP 与 CG 求方向。
  9. 按 KL 预算缩放满步。
  10. 回溯并接受候选，或恢复旧 Actor。
  11. Critic 对固定目标做若干回归更新。
  12. 记录策略、求解器、价值与采样指标。
  13. 丢弃本轮用于 Actor 的旧策略批次，使用新策略重新采样。

13.1 为什么同一批只做一次 Actor 更新

目标与 KL 都围绕采样策略 (\theta_{\mathrm{old}}) 构建。第一次更新通常已经接近信任域边界；若在同一批上再做一次，当前策略不再等于展开中心，状态与动作分布也越来越偏离采样分布。

PPO 用裁剪目标支持多轮小批量优化；TRPO 没有同等语义的 clip 保护。把 TRPO Actor 放进多 epoch Adam 循环，会变成另一个算法。

Critic 可以多轮使用同一批，因为它解决的是监督式价值回归，不是 on-policy 策略约束问题。

十五、训练必须记录的指标

层级 指标 能回答的问题
环境 episodic return、episode length 策略最终是否更好
策略分布 平均 KL、批内状态 KL 最大值或高分位、熵、动作标准差 样本覆盖范围内更新是否异常
替代目标 更新前后目标、predicted improvement、actual improvement、二者比值 局部模型是否可信
求解器 梯度范数、CG 初末残差、曲率、满步范数、接受步长比例、回溯次数 方向为何失败或变慢
优势 均值、标准差、极值、是否标准化 梯度尺度与异常轨迹是否可见
Critic value loss、explained variance、value target 统计 基线是否有效，而非只看 loss
数据边界 terminated、truncated、bootstrap 次数 GAE 是否正确处理轨迹边界

平均 KL 合格并不能证明每个状态都安全；批内最大值或高分位只能暴露已采到状态的异常，也不等于整个状态空间的最大 KL。线搜索失败还应按 KL 超限、目标不改善与非有限值分别计数。

十六、五种常见反常现象

16.1 Critic loss 下降，策略回报却下降

价值回归误差和策略梯度方向误差不是同一目标。Critic 可能在批内拟合得更好，却在策略真正访问的新状态上泛化更差；也可能改变优势排序。

16.2 平均 KL 合格，个别状态行为突变

平均约束允许少量状态消耗远高于平均值的 KL。对安全敏感任务，应额外监控状态 KL 分布，而不是只看一个均值。

16.3 Actor 完全不动

可能是优势接近零、梯度图断开、CG 异常、曲率非正，或所有线搜索候选被拒绝。要沿“优势 → 梯度 → CG → 满步 → 接受条件”逐段定位。

16.4 Critic 更新后策略 KL 变化

这是共享参数泄漏的直接证据。若只想更新 Critic，Actor 分布在固定观测集上应保持不变。

16.5 训练后期动作均值变化越来越小

若高斯标准差下降，均值方向 Fisher (1/\sigma^2) 上升，同一 KL 预算允许的绝对均值变化自然缩小。这可能是信任域几何的结果，不一定是优化器“失去学习率”。

十七、本页结论

TRPO 是 Actor 更新规则，完整训练系统则是数据依赖协议。策略批必须 on-policy，旧分布必须冻结，终止与截断必须分清，优势必须在参数更新前固化，Actor 只接受一次信任域更新，Critic 的普通优化不能偷偷改变策略。

完整理解 TRPO 需要同时守住三条边界：

  • 历史边界：原论文、GAE 论文与现代库不能混写；
  • 参数边界：Actor、Critic 与共享特征的更新权限必须明确；
  • 时间边界：采样、bootstrap、GAE、Actor、Critic 的依赖顺序不能颠倒。

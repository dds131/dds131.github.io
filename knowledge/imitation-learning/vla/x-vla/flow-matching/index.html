Rotate6D codec 与退化区

欧拉角存在周期跳变与奇异，四元数 q/−q 双覆盖会造成分量标签符号歧义。Zhou 等人的连续表示定义下，SO(3) 在四维及以下不存在该类连续表示，5D 与 6D 都有构造；6D 不是理论最低维。

固定 codec 从四元数得到旋转矩阵 R，取前两列后按行优先交错展平：

r6 = [R00, R01, R10, R11, R20, R21] a1 = [r6[0], r6[2], r6[4]] = R[:,0] a2 = [r6[1], r6[3], r6[5]] = R[:,1] b1 = normalize(a1) b2 = normalize(a2 - dot(b1,a2)b1) b3 = cross(b1,b2)，R_hat=[b1 b2 b3]
schema: xvla.rotate6d-codec.v1
source_function_family: {encode: quaternion-to-matrix-then-first-two-columns, decode: sixd-to-rotation-matrix-then-quaternion}
storage_layout: {flatten_order: row-major, values: [R00, R01, R10, R11, R20, R21]}
column_recovery: {first: [0, 2, 4], second: [1, 3, 5]}
decoder: {orthogonalization: gram-schmidt, third_axis: cross-first-second}
incompatible_without_permutation: {layout: column-concatenated-3-plus-3, values: [R00, R10, R20, R01, R11, R21]}
equivalence_kind: exact-coordinate-permutation

它与常见 [第一列3项,第二列3项] 布局只在确定性置换后等价；直接套 PyTorch3D 风格 3+3 解码会错配。解码器没有显式 epsilon，a1≈0 或两向量共线会使归一化退化，并可能产生 NaN/Inf。

论文条件 Flow Matching

论文以 s 表示从噪声到数据的时间，真实动作 A、独立高斯噪声 A⁰：

A^s = (1-s)A⁰ + sA，s∈[0,1] s=0：噪声端；s=1：数据端 u_s(A^s|A⁰,A) = dA^s/ds = A-A⁰ v_s*(x,o) = E[A-A⁰ | A^s=x,o,s]

配对条件速度 A−A⁰ 用于构造监督；平方损失点态最优解是给定混合点、观测和时间的条件期望，即边际速度场，不能说模型在任意 x 唯一恢复隐藏配对。

schema: xvla.paper-flow-matching.v1
path: {equation: A_s=(1-s)*A_0+s*A, noise_endpoint: s=0, data_endpoint: s=1}
pairwise_conditional_velocity: A-A_0
model_inputs: [interpolated-action, observation-context, time]
squared_loss_pointwise_optimum: {equation: E[A-A_0 | A_s=x, observation, s], semantic: marginal-velocity-field}
forbidden_shortcut: [unique-pair-velocity-at-every-x, direct-equivalence-to-clean-action-regression-without-conditions]

论文正文称采样为 “Euler–Maruyama”，但展示式是 A_next=A_current+Δs·v_θ，没有布朗增量；公式层只能分类为 ODE 的确定性显式 Euler。应忠实保留论文术语，同时说明显示公式边界；该处也没有固定发布推理步数。

固定代码的 x0 训练路径

固定代码用反向时间 t：

x_t = tε + (1-t)A t=0：数据端；t=1：噪声端 连续通道：A_hat_θ 直接预测干净动作 A 夹爪通道：输出 logit，以 BCEWithLogits 监督

训练链顺序是 action slice → 采样噪声/时间 → 线性混合 → 动作空间 preprocess → Transformer → 连续 MSE 与夹爪 BCE → 加权求和。ee6d preprocess 会清零 noisy action 和 proprio 的夹爪输入，不把夹爪噪声当成有效条件。

夹爪配置权重是 1；展开系数 0.5 来自两个通道先取平均，不能称“夹爪权重 0.5”。总损失直接求三项和，没有再按有效臂、有效维度或损失种类归一化。

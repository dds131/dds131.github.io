本页要建立的判断有四条。其一，π0.6 的机器人数据目标包含子任务文本、FAST 离散动作和连续动作，但它们不是三个并列的回归损失——前两项用自回归交叉熵，连续项用流匹配。其二，论文附录 C 为策略改进推导了连续动作对数似然的一个证据下界，其中平方误差带噪声相关权重 \(w(\eta) = e^{-\eta/2}\)；正文则只把训练权重记作可随噪声变化的 \(\alpha_\eta\)，没有公开 π0.6 基座实际采用的权重函数。因此下界解释的是似然代理，不应倒推成基座训练超参数。其三，知识隔离是选择性截断梯度，不是冻结主干。其四，截断流匹配到主干的梯度后，FAST 分支承担主干的直接低层动作监督；没有它，主干仍可学习子任务与共训练数据，但缺少低层动作 token 目标。

一、本页在专题中的位置

本页承接子页 ①。① 已经讲完结构：四路图像与语言、本体状态拼成序列，主干自回归输出子任务文本与 FAST 离散动作 token，动作专家用流匹配输出连续动作块，且两路动作独立预测。本页在此基础上只回答训练问题。

一处必须先说清的口径问题。论文正文与附录写出的损失公式，形式里都带着优势指示 \(I_t\)——那是 π*0.6 的训练目标。π0.6 基座的对应形式是把 \(I_t\) 去掉，但论文并没有单独列出基座版本的公式。因此本页每次引用这些式子时，都会先给出论文原式并注明其归属，再给出去掉 \(I_t\) 的基座形式，并说明那是按论文式子推出的对应形式。

二、训练目标的三项构成

π0.6 的一个训练样本涉及三类机器人输出，训练目标由相应的三类项构成。它们不是一次前向同时完成：文本与 FAST token 需要自回归预测，连续动作项则在随机采样的流时间与噪声上计算。论文附录 C 把完整模型似然分解成三个因子（原式含 \(I_t\)，属 π*0.6）：

\[\pi_{\theta}\!\left(a_{t:t+H},\ a^{\ell}_{t:t+H},\ \hat{\ell} \mid I_t,\ o_t,\ \ell\right) = \pi_{\theta}\!\left(a_{t:t+H} \mid I_t, o_t, \ell, \hat{\ell}\right)\ \pi_{\theta}\!\left(a^{\ell}_{t:t+H} \mid I_t, o_t, \ell, \hat{\ell}\right)\ \pi_{\theta}\!\left(\hat{\ell} \mid I_t, o_t, \ell\right)\]

Eq. 6 把 \(I_t\) 写在总条件和三个因子中；但论文第五节 B 小节同时规定，优势指示位于 \(\hat{\ell}\) 之后、动作之前，因而只有两类动作似然受它影响。在实际序列掩码下，子任务项应读作

\[\pi_\theta(\hat{\ell}\mid I_t,o_t,\ell) = \pi_\theta(\hat{\ell}\mid o_t,\ell).\]

这不是删除论文符号，而是把 Eq. 6 的总条件记法与其序列位置说明对齐。

去掉优势指示，π0.6 基座的对应形式是

\[\pi_{\theta}\!\left(a_{t:t+H},\ a^{\ell}_{t:t+H},\ \hat{\ell} \mid o_t,\ \ell\right) = \underbrace{\pi_{\theta}\!\left(a_{t:t+H} \mid o_t, \ell, \hat{\ell}\right)}_{\text{连续动作：流匹配}}\ \underbrace{\pi_{\theta}\!\left(a^{\ell}_{t:t+H} \mid o_t, \ell, \hat{\ell}\right)}_{\text{离散动作：自回归}}\ \underbrace{\pi_{\theta}\!\left(\hat{\ell} \mid o_t, \ell\right)}_{\text{子任务文本：自回归}}\]

符号逐项解释：

  • \(a_{t:t+H}\)：连续动作块，即实际下发给机器人的 50 Hz 关节角与夹爪指令。
  • \(a^{\ell}_{t:t+H}\)：同一段动作块经 FAST 分词器得到的离散 token 表示。论文用上标 \(\ell\) 与连续动作区分。
  • \(\hat{\ell}\)：模型预测的下一个子任务文本。
  • \(o_t,\ \ell\)：观测与语言输入，构成见子页 ①第三节。

这个分解包含两层依据。 第一层是链式法则与生成顺序：先生成 \(\hat{\ell}\)，因此两类动作都可以把它作为条件。第二层是模型结构给出的条件分离：动作专家不读取 FAST token，所以连续动作项不以 \(a^\ell\) 为条件；FAST 分支也不读取连续动作样本作为输入。论文所说的 independently 指的正是这种计算路径分离。它不表示两种动作在无条件意义下统计独立，因为二者仍共享 \(o_t,\ell,\hat{\ell}\)。

取对数之后三项变成相加，对应三个损失项：

项 对应输出 损失形式 梯度到达哪里
子任务文本项 \(\hat{\ell}\) 逐 token 交叉熵（自回归） 主干
离散动作项 \(a^{\ell}_{t:t+H}\) 逐 token 交叉熵（自回归） 主干
连续动作项 \(a_{t:t+H}\) 流匹配，形式见第三节 仅动作专家
共训练项 网络多模态数据 逐 token 交叉熵（下一 token 预测） 主干

表中第四行是 MC 单独提到的：主干除了预测 FAST 动作 token 之外，还要预测共训练样本，例如多模态网络数据。它不属于机器人数据上的三项，但在同一次训练中一起优化。论文 Fig. 3 的图注把预训练概括为「在多种数据源上做下一 token 预测」，因此这一项与前两项同属交叉熵。按知识隔离的设计意图，它的作用是让主干保住预训练得到的语义能力（机理见 π0.5 · 知识隔离与梯度干扰）。

最后一列是本页的核心，第四节展开。

三、连续动作项为什么不是普通的均方误差

前两项是标准的自回归交叉熵。第三项的基础训练形式是流匹配平方误差；附录 C 进一步推导了一个带权形式，用来把它解释为连续动作对数似然的下界。要区分“训练目标的形式”和“为策略改进建立的似然解释”。

3.1 问题的来源：流匹配没有闭式似然

要把三项写成一个统一的对数似然，就需要 \(\log \pi_{\theta}(a_{t:t+H} \mid \cdot)\) 的表达式。但论文明确指出，对连续动作而言闭式似然不可得。前两项可以用真值 token 上的交叉熵直接估计，第三项不行。

论文的处理是分两步绕过去。

3.2 第一步：把单步扩散过程视为高斯

论文沿用已有工作的做法，把单步扩散过程当作一个高斯分布来处理，于是得到（原式含 \(I_t\)）：

\[\log \pi_{\theta}\!\left(a_{t:t+H} \mid a^{\eta,\omega}_{1:H},\ I_t,\ o_t,\ \ell,\ \hat{\ell}\right) = \log \mathcal{N}\!\left(\omega - f_{\theta}\!\left(a^{\eta,\omega}_{1:H},\ I_t,\ o_t,\ \ell,\ \hat{\ell}\right),\ \mathbf{I}\right)\]

其中加噪动作的构造与 π0 一致：

\[a^{\eta,\omega}_{t:t+H} = \eta\, a_{t:t+H} + (1 - \eta)\,\omega, \qquad \omega \sim \mathcal{N}(0, \mathbf{I}), \qquad \eta \in [0, 1]\]

\(\eta\) 是流匹配的时间索引，\(f_{\theta}\) 是动作专家给出的连续输出。注意这套记法下 \(\eta = 1\) 对应纯数据、\(\eta = 0\) 对应纯噪声，与 π0 专题所用的时间方向约定需要对照着读，详见 π0 · 时间方向约定与推理期现象。

3.3 第二步：对噪声与时间求期望，得到证据下界

在上式基础上对 \(\eta\) 与 \(\omega\) 求边际，论文得到一个证据下界（evidence lower bound）：

\[\log \pi_{\theta}\!\left(a_{t:t+H} \mid I_t, o_t, \ell, \hat{\ell}\right) \ \geq\ \frac{1}{2}\, \mathbb{E}_{\eta,\,\omega} \left[ -\,w(\eta)\, \left\lVert \omega - a_{1:H} - f_{\theta}\!\left(a^{\eta,\omega}_{1:H},\ I_t,\ o_t,\ \ell,\ \hat{\ell}\right) \right\rVert^{2} \right] + c\]

其中

\[\boxed{\,w(\eta) = e^{-\eta/2}\,}\]

是一个噪声相关的权重项，\(c\) 是与 \(f_{\theta}\) 无关的常数。π0.6 基座的对应形式就是把上式中的 \(I_t\) 去掉。

最后把这个下界与离散动作的自回归似然合并，并把各权重项吸收进一个记号 \(\alpha_{\eta}\)，就得到论文正文的 Eq. 4。下式是去掉 \(I_t\) 后的基座对应形式：

\[\log \pi_{\theta}\!\left(a_{t:t+H},\ a^{\ell}_{t:t+H} \mid o_t, \ell, \hat{\ell}\right) \ \geq\ \mathbb{E}_{\eta,\,\omega} \left[ \log p_{\theta}\!\left(a^{\ell}_{t:t+H} \mid o_t, \ell, \hat{\ell}\right) -\ \alpha_{\eta} \left\lVert \omega - a_{1:H} - f_{\theta}\!\left(a^{\eta,\omega}_{1:H},\ o_t, \ell, \hat{\ell}\right) \right\rVert^{2} \right]\]

论文在正文处对 \(\alpha_{\eta}\) 的说明是：它是一个损失权重项，可以与噪声相关，完整细节在附录 C。上面的推导正是那个细节。

注意正文用的是「可以」。附录 C 说明的是：若平方误差按 \(w(\eta)\) 加权，流匹配损失就构成连续动作对数似然的一个下界。它没有说明实际训练时 \(\alpha_\eta\) 取的就是 \(w(\eta)\)，模型卡与论文也都没有给出 π0.6 基座训练时的权重设置。因此本节讲的是「这个下界长什么样、权重从哪里来」，而不是「π0.6 实际用了什么权重」。

3.4 这个权重的方向意味着什么

\(w(\eta) = e^{-\eta/2}\) 是 \(\eta\) 的单调减函数。代入两个端点：

\(\eta\) \(a^{\eta,\omega}\) 的状态 \(w(\eta)\) 在该下界中的相对权重
0 纯噪声 \(e^{0} = 1\) 最大
0.5 噪声与数据各半 \(e^{-0.25} \approx 0.78\) 居中
1 纯数据 \(e^{-0.5} \approx 0.61\) 最小

也就是说，在这个下界里，越接近纯噪声的时间点权重越大；越接近真实动作的时间点，权重越小。两端的比值约为 1.65 倍，是一个温和的倾斜，不是数量级上的差别。

对这个方向的一种直观理解是：去噪轨迹的早期（高噪声端）决定了整条轨迹会落向哪个模态，一旦早期方向偏了，后面再精细也回不来；而末期只是在已经选定的模态内做微调，估计误差的后果有限。把更大的权重放在高噪声端，等于把优化预算优先分配给「选对模态」这件事。

但这个解释只是对权重形状的事后解读，不是它的来源。必须强调：\(w(\eta)\) 不是按上述直觉调出来的超参，而是证据下界推导的产物——论文把它称为「a noise dependent weighting term」，并指明推导见所引文献——Kingma 与 Gao 的 Understanding Diffusion Objectives as the ELBO with Simple Data Augmentation（论文参考文献 [80]），该文献附录 D.3 同时给出了在这一权重选择下流匹配与扩散之间的对应关系。换句话说，这个权重的形状由推导确定，不是按直觉挑选的。

3.5 为什么要推这个下界：给策略改进提供连续动作的似然代理

附录 C 的标题是「为策略改进计算对数似然」。这句话点明了整段推导的目的：不是为了把基座训练得更好，而是为了让流匹配这一路具备一个可计算的对数似然代理。

理由在于 RECAP 的策略目标写成负对数似然形式，需要 \(\log \pi_{\theta}(a_{t:t+H} \mid o_t, \ell)\) 这样的动作块似然（完整形式见子页 ⑤）。离散分支的对数似然可以直接计算；连续分支没有闭式似然，而它又是实际控制输出。论文用这个下界说明：以流匹配平方误差充当连续动作负对数似然的代理是有依据的。正文使用「roughly motivate」，因此这是近似的理论桥梁，不是严格等式。

因此本节的结论是：附录 C 这段推导服务于 π*0.6 的策略改进，它说明了流匹配损失为什么可以放进似然形式的目标里；它并不说明 π0.6 基座训练时实际采用了哪种权重。

四、知识隔离：梯度在哪里被截断

模型卡第 2 节对这件事的表述非常具体，这里逐句拆开：模型用 Knowledge Insulation 训练；视觉-语言主干预测 FAST 动作 token 与共训练样本，例如多模态网络数据；动作专家预测连续动作；而动作专家的梯度不回流到主 VLM 主干。

用式子写，知识隔离的梯度路由可以记为：

\[\nabla_{\theta_{\mathrm{VLM}}} \mathcal{L}_{\text{flow}} = 0, \qquad \operatorname{route}\!\left( \nabla_{\theta_{\mathrm{VLM}}}\mathcal{L}_{\text{FAST}} \right)=\text{保留}\]

第一条是结构性恒等式：stop-gradient 让流匹配损失对主干的偏导为零。第二条不能写成逐样本恒成立的「不等于零」——梯度在收敛点或特定样本上完全可能数值为零；它表达的是 FAST 梯度路径没有被截断。在 π0.6 的 KI 配方中，前者负责隔离连续控制梯度，后者给主干保留直接的低层动作监督。

这里的两条设计方向并不对称。若截断连续动作梯度又移除 FAST，主干仍会收到子任务文本和共训练监督，但失去直接的低层动作目标；反过来，KI 论文的对照实验显示，若有充足的 VLM 数据共训练，不截断梯度的联合训练也能保持良好的语言跟随。所以不能据此推断「不截断梯度就一定会损伤语言能力」。完整论证见 π0.5 · 知识隔离与梯度干扰第五节。

五、与「冻结主干」的本质区别

这是本页最容易被一句话带过、也最容易理解错的一节。「知识隔离」这个名字容易让人以为是把主干保护起来不动，实际不是。

  冻结主干 知识隔离（π0.6 的做法）
主干参数是否更新 不更新 更新
主干是否收到动作监督 收不到 收到，经 FAST 离散动作项
主干是否收到语义监督 收不到 收到，经子任务文本项与网络共训练项
流匹配梯度是否进主干 不进（因为整体不更新） 不进（被显式截断）
动作专家能否读主干激活 能 能
结果 主干停在预训练状态，无法适配机器人数据 主干持续适配，但适配方向由离散与语义目标决定

两者的相同点只有一条：流匹配的梯度都没有进主干。差别在其余全部。

5.1 为什么不能简单冻结

KI 的官方材料把「冻结主干」作为对照组做过实验，结论是否定的：在 items in drawer 与 shirt folding 两个任务上均不可行，原因是预训练表征不足以支撑控制（逐条记录见 π0.5 · 知识隔离与梯度干扰第四节与第七节）。

从机理上看，冻结主干会让模型失去从机器人数据中学习表征的能力。机器人场景与网络图文数据在分布上差得很远——相机视角、光照、物体摆放、本体状态的表示方式，这些都需要主干去适配。冻结意味着这些全都学不到，只能靠动作专家在固定表征上硬拟合。

5.2 为什么也不能放开

如果允许流匹配梯度直接回流，主干就会被连续控制任务的梯度改写。本站 π0.5 · 知识隔离与梯度干扰依据 KI 官方材料整理了这件事，要点有三：

  • 实验观察：来自动作专家的梯度让学习慢得多，并让主干丢失一部分互联网规模预训练中获得的知识，表现为语言指令跟随变差。
  • 对原因的解释是假说：官方认为梯度干扰了模型处理语言的能力，使模型转而先抓住别的相关性。这一条是官方明确标为假说的，不是已证实的机制。
  • 有限定条件：若有充足的 VLM 数据共训练，不截断梯度的联合训练也能保持良好的语言跟随（见本页第四节的说明）。

这些论证的完整展开在该页，本页不重复。

5.3 「端到端训练」与「梯度不回流」为什么不矛盾

论文第五节在同一句话里写了两件事：KI「在连续动作与离散化 token 上端到端训练整个模型」，同时「用 stop gradient 阻止流匹配动作专家影响模型的其余部分」；模型卡的表述则是「动作专家的梯度不回流主干」。「端到端」与「梯度不回流」初看像是冲突的，实际不是。

  • 「端到端」指的是所有组件在同一次训练中一起优化，不存在先训一段再训另一段的分阶段流程，也不存在某个模块被排除在优化之外。
  • 「梯度不回流」指的是计算图上的一条特定边被切断，即从流匹配损失出发、经动作专家、回到主干的那条路径。

两者描述的是不同层面的事：前者说的是训练流程的组织方式，后者说的是反向传播的路由。一个模型完全可以既是端到端训练的，又在内部某处放置了 stop-gradient。

判断这类表述是否冲突有一个简单办法：看主干的参数在训练过程中是否变化。知识隔离下主干在变，所以不是冻结；变化的来源是离散动作项、子任务文本项与共训练项，而不是流匹配项，所以也不是无约束的联合训练。它是一种有选择的联合训练。

六、为什么 KI 配方必须保留 FAST 离散动作分支

子页 ① 已经指出一个结构事实：动作专家不接收 FAST token 作为输入，两路动作独立预测。那么一个自然的问题是——既然实际执行用的是连续那一路，离散那一路存在的意义是什么？

答案在上一节的梯度约束里：一旦切断流匹配到主干的梯度，FAST 分支就成为主干获得直接低层动作监督的通路。子任务文本仍是高层行为监督，机器人观测与共训练数据也会更新主干；FAST 的独特性在于它直接编码与连续动作块相同的低层动作。

把这件事按反事实推一遍：

假设的配置 主干收到的监督 后果
有 KI，有 FAST 分支（π0.6 的实际配置） 语义 + 离散动作 主干既保住语义，又形成动作相关表征
有 KI，无 FAST 分支 语义与高层子任务 主干缺少直接低层动作目标；是否仍能形成足够控制表征需要实验，不能仅凭计算图断言完全脱节
无 KI，无 FAST 分支 语义 + 流匹配梯度 连续动作梯度直接改写主干，正是 KI 要避免的情形。KI 的对照组里与之最接近的是 π0（只有流匹配、只有机器人数据），其语言跟随差

第二行是关键：切断连续动作梯度后，需要另一路低层动作目标。KI 不是简单地「少训一点」，而是把主干的低层动作监督从连续流匹配梯度改成离散 token 预测；后者与主干原本擅长的下一 token 预测同型。KI 官方材料报告：FAST 动作 token 让模型更快地获得运动表征，而且交叉熵对主干预训练知识的干扰更小（见 π0.5 · 知识隔离与梯度干扰第五节）。这是一项经验结论，不等于证明没有 FAST 的所有替代设计都必然失败。

至于两路动作为什么要独立预测，π0.6 的材料只写了事实——动作专家不接收 FAST token 作为输入，离散与连续动作独立预测——没有写理由。上一代 π0.5 论文附录 E 对同一设计给出的理由是避免两种动作表示之间的信息泄漏：训练时序列里的 FAST token 是真值动作块的离散编码，若动作专家能读到它们，就可以直接从中取得答案，而推理时并没有这份真值（掩码规则见 π0.5 · 网络架构与结构差异第五节）。

与 π0-FAST 的区别值得再强调一次。π0-FAST 是只有离散那一路的自回归模型，动作由 FAST token 解码得到，离散分支承担实际控制职责；π0.6 的离散分支不承担控制职责——实际下发给机器人的动作块由动作专家产生，而论文把 FAST 动作 token 的预测明确放在「训练时」；这一路存在的理由是训练期给主干提供动作监督。两者同名同分词器，职责完全不同。需要说明的是，π0.6 自己的材料并没有一句话直接写「推理时不使用这一路」；可以作为旁证的是 KI 官方材料的原话「训练结束后离散动作被丢弃」（the discretized actions are discarded，见 π0.5 · 知识隔离与梯度干扰第五节），而 π0.6 用的正是 KI 训练流程。上述判断的完整依据见子页 ①第四节的说明。

七、训练数据的构成

模型卡第 3 节说明，π0.6 大体沿用 π0.5 的训练数据构成，包含以下几类：

数据类别 内容 对应的训练项
跨本体数据 自采数据与外部数据源 两路动作项
家庭环境数据 移动与非移动平台在家庭环境中采集 两路动作项
高层子任务预测 子任务文本的标注 子任务文本项
多模态网络数据 含边界框预测与关键点预测 共训练项

官方材料明确写出的数据层面增量只有一条，即子页 ① 第二节讲的第一点改进：预训练数据集增补了来自多个机器人平台的额外数据。模型卡对整体的措辞是「大体沿用」（largely inherits），因此不能据此断言其余部分与 π0.5 完全相同。

数据规模方面，论文第四节只给出了总体量级：预训练数据集包含来自众多任务与多种机器人的数万小时演示（原文 tens of thousands of hours，指 π*0.6 预训练阶段所用的数据集）。各类数据各自的规模与配比未公开，本页不做推算。

八、「不做任务特定微调」这个定位

模型卡第 3 节有一段对理解这一代很关键的表述：在以往的模型中，使用精选高质量数据做任务特定微调（即 post-training）被发现非常有效，有时甚至是取得良好表现的必要条件；而 π0.6 由于训练数据多样且具备丰富的 metadata 条件化，在不做任务特定微调的情况下就能取得显著更强的表现。

这段话有两层含义需要分开看。

  • 第一层是能力层面的。 它意味着基座的开箱即用水平提高到了一个新位置。官方的三组评测正是在这个口径下做的——模型卡明确称之为 out-of-the-box evaluation，两个被比较的模型都没有做任务特定后训练。这组实验的内容见子页 ⑥。
  • 第二层是方法论层面的，属本站的理解。 模型卡把原因归结为两点：训练数据更多样、metadata 条件化更丰富。后者意味着一部分原本要靠微调才能指定的执行方式，可以改由输入端的 metadata 来指定。模型卡没有展开 metadata 的具体内容，这一层只是依据其措辞做的解读。
必须与 π*0.6 的后训练区分开。本节说的「不做任务特定微调」指的是 π0.6 基座不需要用精选数据做监督微调就已经够强，模型卡的三组评测都在这个口径下进行。π*0.6 的 RECAP 则是面向具体任务的后训练：它同样从该任务的演示数据开始（先做一轮监督微调），但随后加入部署之后自主执行产生的数据与人工纠正，并用价值与优势给出监督学习给不出的信号。两者都可以叫「后训练」，但目的与所用信号不同。

九、本页留下的问题

本页讲完了 π0.6 基座的训练。从这里开始，话题转向 π*0.6：

  1. 演示、自主试跑、人工纠错这三类数据，怎么在同一个目标下被消化。
  2. 一轮 RECAP 具体做哪几步，为什么每一轮都要从预训练检查点重训。
  3. 本页第三节那个对数似然下界，最终被用在了什么形式的目标里。

前两个问题在子页 ③，第三个问题在子页 ⑤。

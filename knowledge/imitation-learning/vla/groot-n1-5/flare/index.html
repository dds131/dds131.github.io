知识库首页 /模仿学习 /VLA 总览 /GR00T N1.5 总览 /② FLARE 未来潜在表征对齐

FLARE 全称 Future Latent Representation Alignment。它训练动作策略在生成动作的同时，让一组额外 token 的中间表示预测未来观测的紧凑语义表示，而不直接生成未来像素。

本页必须区分三件事：FLARE 论文提出的方法、NVIDIA 官方声称 N1.5 采用的训练目标、以及 n1.5-release 公开代码实际执行的路径。三者有关联，但并不等价；尤其公开训练前向没有计算 FLARE 对齐损失。

证据层次。方法公式、目标编码器、EMA、消融和人类视频实验以 FLARE 论文 v1 为准；N1.5 是否使用 FLARE 及系数 0.2 以 NVIDIA Research 页为准；公开行为以固定源码 commit 4af2b622… 和固定权重配置 commit 869830fc… 为准。FLARE 论文正文没有出现“GR00T N1.5”，论文实验不能直接冒充 N1.5 的训练实现或结果。

一、本页在专题中的位置

本页只讲 FLARE 这一项训练目标。以下内容不在本页：

  • 流匹配损失本身的推导、加噪式与时间方向约定，见 GR00T N1 · Flow Matching、损失与时间方向。本页把 $\mathcal L_{fm}$ 当作已知项。
  • future token 的维度、它使 DiT 序列变长多少、动作头前置自注意力的配置细节，见 ① 架构增量与 VL 接口重建。
  • 「官方页写了 FLARE 而公开源码没有实现它」这一事实的完整含义与复现影响，见 ⑤ 推理流程与反常现象；本页第九节只陈述事实，不展开。
  • 实验数字的完整表格见 ⑦ 实验结果与横向对比。

二、FLARE 要解决什么问题

论文讨论的对照路线，是让策略在预测动作的同时生成未来图像或连续视觉潜变量。作者指出两类负担：

计算负担高保真未来生成通常需要更大的生成模块，会增加训练与推理成本；机器人闭环控制对延迟尤其敏感。
目标竞争像素重建要求保留纹理、光照等细节，动作预测更需要紧凑、任务相关的状态。共享有限容量时，两类目标可能互相牵制。

FLARE 的取舍是只监督未来观测的潜在表示。这既减少高保真生成负担，也把辅助目标集中在任务相关变化上。不过“纹理永远无用”并不成立：精细接触、透明物体或细粒度视觉任务仍可能依赖局部细节。论文主张的是更合适的容量分配，不是对像素信息价值的普遍否定。

三、机制：future token 在内部层预测未来表示

3.1 输入序列与张量角色

论文在动作 DiT 的查询序列中加入 $M$ 个可学习 future token：

组成 论文记号 来源
当前本体状态 $q_t$ 经状态编码器 当前观测
加噪动作块 $A_t^{\tau}={\tau a+(1-\tau)\epsilon}_{t}^{t+H}$ 示范动作与噪声
future token $M$ 个可学习嵌入 模型参数

future token 不是未来图像的输入，也没有预先规定每个 token 对应哪个物体或未来时刻；它们通过 DiT 中的交叉注意力读取当前视觉语言条件，并通过自注意力与状态、动作 token 交换信息。

3.2 中间层切出、投影与停止梯度目标

设第 $L$ 个 DiT block 后 future token 的隐藏状态为 $H_L^F\in\mathbb R^{B\times M\times D_h}$。论文的计算链是：

  1. 从内部层 $L$ 切出 $H_L^F$；
  2. 用投影 MLP $P$ 映射到目标宽度，得到 $Z=P(H_L^F)$；
  3. 用目标编码器 $g$ 编码未来观测，得到 $Y=g(\phi_{t+H})$；
  4. 停止目标侧梯度，用余弦相似度对齐 $Z$ 与 $Y$。

附录伪代码把 $P$ 注释为两层 MLP。论文没有给出 $D_h$、目标宽度 $D$ 和逐 token 余弦的具体归约实现，因此复现时不能从公式之外臆造这些超参数。

3.3 与 REPA 的区别：分流但不独立

论文把 FLARE 与图像生成中的 REPA 联系起来：

  • REPA 对齐当前样本表示；FLARE 对齐未来观测表示，因此辅助目标包含时间转移信息。
  • FLARE 为未来预测增加单独 token 流；动作与 future token 在同一 DiT 中通过自注意力交互。

这里应写“分开的 token 流”，不能写“完全独立的两条流”：它们共享 DiT 参数并相互注意，FLARE 正是依靠这种交互让未来监督影响动作表示。对策略结构而言，新增部分较小；对完整训练系统而言仍需投影 MLP、目标编码器、未来帧数据与 EMA，不能概括成“只加 token、没有新分支”。

四、损失、归约与流匹配符号

4.1 对齐损失

论文式 (2) 为

\[\mathcal L_{\mathrm{align}}(\theta) =-\mathbb E_{\tau}\!\left[ \cos\!\left(f_\theta(\phi_t,A_t^\tau,q_t),\,g(\phi_{t+H})\right) \right].\]

其中两侧形状均为 $B\times M\times D$。一种自然实现是沿 $D$ 维计算每个 token 的余弦，再对批量和 token 求均值：

\[\mathcal L_{\mathrm{align}} =-\frac{1}{BM}\sum_{b=1}^{B}\sum_{m=1}^{M} \frac{z_{bm}^{\mathsf T}y_{bm}} {\lVert z_{bm}\rVert_2\lVert y_{bm}\rVert_2}.\]

第二式是对论文公式的实现性展开，不是论文明确规定的归约代码；论文和伪代码都没有说明余弦的维度参数、epsilon 或批量归约。式中只显式写了对 $\tau$ 的期望，数据样本与噪声的期望被记号省略。

余弦对齐只约束表示的方向，不直接约束范数：对任意正数 $c$，有 $\cos(cz,y)=\cos(z,y)$。当 $z,y\neq0$ 时，

\[\nabla_z\cos(z,y)=\frac{y}{\lVert z\rVert\lVert y\rVert}-\frac{(z^{\mathsf T}y)z}{\lVert z\rVert^3\lVert y\rVert}.\]

该梯度与 $z$ 正交，即 $z^{\mathsf T}\nabla_z\cos(z,y)=0$；忽略数值稳定项时，它主要推动预测表示旋转到目标方向，而不是匹配目标向量长度。因此 FLARE 学到的是“未来表示方向的一致性”，不能把余弦损失解释成逐元素重建未来特征。

4.2 总损失与常数差

论文式 (3)：

\[\mathcal L=\mathcal L_{\mathrm{fm}}+\lambda\mathcal L_{\mathrm{align}}.\]

FLARE 论文实验和 N1.5 官方页都给出 $\lambda=0.2$；官方页进一步说 N1.5 的预训练与后训练均使用该值。这个一致只证明系数相同，不能证明 N1.5 的目标编码器、层号和数据路由逐项等同于论文实验。还要注意，0.2 的实际权重依赖两项损失各自采用求和还是均值、是否按有效动作维归一，以及余弦损失如何跨 $B\times M$ 归约；改动这些约定后，数值相同的 $\lambda$ 不再代表相同的梯度权衡。

附录伪代码使用 1-cos，正文使用 $-\cos$。二者只相差常数 1，关于模型参数的梯度相同；前者非负，更便于记录损失值。

4.3 论文式 (1) 的流匹配目标反号

论文定义

\[A_t^\tau=\tau A_t+(1-\tau)\epsilon,\]

并从 $\tau=0$ 到 1 用加法欧拉更新。对插值求导得到

\[\frac{\mathrm d A_t^\tau}{\mathrm d\tau}=A_t-\epsilon.\]

但正文式 (1) 写成拟合 $\epsilon-A_t$。这与插值导数、加法欧拉式、附录伪代码的 velocity = actions - noise 以及公开 N1.5 源码的 velocity = actions - noise 均相反。除非同时把积分方向或更新号改掉，否则正文式 (1) 无法从噪声走向动作。因此复现应采用 $A_t-\epsilon$；本页保留并明确标注这一论文内部不一致。

五、动作感知目标编码器：默认教师，但不是唯一选择

5.1 结构与训练职责

论文默认的目标编码器输出 32 个紧凑视觉语言 token：

阶段 构造 作用
单模态编码 SigLIP-2 视觉编码器与文本编码器 分别编码图像和指令
跨模态融合 四层自注意力 Transformer 融合视觉、语言 token
压缩 Q-former 的 32 个学习查询 输出固定长度 32-token 表示
动作感知预训练 临时接 8 个 DiT block，用动作流匹配训练 让编码器表示对控制任务有用

最后的 8 个 DiT block 是预训练目标编码器时施加动作监督的策略头；FLARE 对齐阶段使用的是前面的视觉语言嵌入模型 $g$，不能把这 8 个 block 也算进每次目标编码。

附录 A 给出更具体的单相机规格：siglip2-large-patch16-256 把 256×256 图像变成 256 个视觉 token，指令补齐为 32 个文本 token；四层融合后仍为 288 个 token，再由 Q-former 压缩成 32 个 token。Q-former 的具体层数未公开，不能从图中的字母 $N$ 猜测。

5.2 数据时长存在论文内部不一致

正文第 3.2 节称预训练混合数据“约 2,000 小时”；附录 B 的逐数据集表合计却是 2,989.5 小时、169.5M 帧，其中 GR-1 Simulation 单项为 1,742.6 小时。页面不能只引用“约 2,000 小时”而忽略附录总计。最稳妥的写法是并列记录两处数字，说明论文未解释差异，可能涉及统计版本或取整口径。

5.3 通用 SigLIP2 目标也有效，动作感知目标最好

论文在 GR-1 仿真基准给出目标编码器消融：

目标 成功率
无 FLARE 43.9%
SigLIP2 原始 256 token 49.6%
SigLIP2 2×2 平均池化为 64 token 50.9%
动作感知嵌入 55.0%

因此“目标编码器不是通用视觉编码器”过于绝对。准确结论是：FLARE 可兼容通用视觉目标，动作感知、紧凑的目标在该实验中最好。55.0−43.9 是 11.1 个百分点；论文所说通用 SigLIP2 带来约 7% 提升，按表格更接近 7 个百分点而非相对百分比。

5.4 EMA 的正确读法与论文记号问题

参数级 EMA 的意图是

\[\theta_{\mathrm{target}} \leftarrow \rho\theta_{\mathrm{target}} +(1-\rho)\theta_{\mathrm{policy}}.\]

论文公式左侧写 target_vl_embedding，右侧却缩写成 target_embedding，属于下标命名不一致；语义上仍是旧目标参数与策略编码器参数的加权平均。该更新要求两侧参数结构可对应，这在论文中通过“策略编码器由预训练嵌入模型初始化”满足。

论文比较 $\rho\in{0.99,0.995,0.999,1.0}$：0.995 最好并用于全部实验；1.0 表示目标完全冻结，仍优于无 FLARE 基线；0.99 最差，作者归因于目标更新过频带来的不稳定。EMA 的直接证据是“慢速适应并提高稳定性”；把它进一步类比为 BYOL/DINO 的防坍塌机制只能算一般性解释，论文没有对表示坍塌做实验诊断。

5.5 与 N1.5 发布配置的对应只能说“相容”

FLARE 论文使用 32 个 future token 与 32 个目标 token；N1.5 配置的 num_target_vision_tokens=32 与之高度相容，字段名也保留了目标视觉 token 的语义。但公开源码没有目标编码器或对齐损失，因此不能仅凭数字相同证明发布训练路径完整实现了论文 FLARE。

N1.5 的四层 vl_self_attention 位于 Eagle 主干之后；论文目标编码器的四层融合位于 SigLIP2 双塔之后。两者输入、位置和职责不同，“同为四层”不是同构证据。

六、论文伪代码：应读作算法草图，不是可直接运行实现

6.1 去除笔误后的核心训练逻辑

下面用与正文一致的中间层抽取方式重写算法骨架：

noise, tau = sample_noise_and_time(actions)
a_tau = tau * actions + (1 - tau) * noise
v_target = actions - noise

vl_now = policy_encoder(current_obs)
queries = concat(state_tokens, action_tokens(a_tau, tau), future_tokens)
output, hidden = dit(queries, vl_now, return_all_hidden_states=True)

v_pred = action_decoder(select_action_tokens(output))
z_pred = embedding_projector(select_future_tokens(hidden[L]))

with no_grad():
    z_target = target_encoder(future_obs)

align_loss = mean(1 - cosine(z_pred, z_target, dim=-1))
loss = mse(v_pred, v_target) + lambda_align * align_loss
update_policy(loss)
ema_update(target_encoder, policy_encoder, rho)

这不是声称存在于公开仓库的代码，而是把论文正文、算法 1 与 EMA 段落合成的可实现契约。

6.2 论文算法 1 的缺项与笔误

原伪代码现象 正确解读或修正
vl_embedding.load_state_dict(vl_embedding.state_dict()) 自己加载自己是空操作；结合正文，意图应是用预训练嵌入模型初始化策略编码器，但复制方向未在算法中正确写出
完全没有 EMA 更新行 必须从正文第 3.2 节补入；否则无法复现 $\rho$ 消融
从 dit(...) 最终输出取 future token 正文与 Figure 2 要求从内部层 $L$ 取；算法是简化写法
hiddem_dim、prioprioceptive、state/proprio 明显拼写或变量名错误
future embedding 直接参与批量拼接 实际实现需要沿批量维扩展
M: Number of tokens in VL 这里应理解为被对齐的紧凑目标／future token 数，不是原始视觉语言序列总长度

算法 1 正确写出了 $A-\epsilon$ 的速度方向、目标侧停止梯度、两层 embedding projector 和 $1-\cos$ 损失。它没有给出人类视频样本缺少状态与动作时如何构造 DiT 查询序列，也没有给出机器人与视频样本的批次混合方式。

6.3 论文顺序与 N1.5 公开顺序不同

来源 查询序列 动作切片 future 切片
论文算法 1 状态 → 动作 → future 单状态 token 时从索引 1 开始取动作 末 $M$ 个
n1.5-release 状态 → future → 动作 末 $H$ 个 公开前向未取

若状态段长度为 $S$，把 FLARE 接入公开顺序时，future token 应切为 [:, S:S+M]；只有内置常用配置 $S=1$ 时才退化为 [:, 1:1+M]。直接照搬论文的 [:, -M:] 会落到末尾动作段。

公开 DiT 已支持 return_all_hidden_states=True，返回列表的索引 0 是 block 输入，索引 $L$ 才是第 $L$ 个 block 之后的状态；实现论文“第 6 层”时需避免 off-by-one。

七、无动作人类视频如何参与训练，以及未知部分

对机器人示范，论文同时计算动作流匹配与未来对齐；对没有动作标签的人类第一视角视频，只计算未来对齐：

数据 可用监督 论文明确的损失
机器人示范 当前／未来观测、本体状态、动作 $\mathcal L_{\mathrm{fm}}+\lambda\mathcal L_{\mathrm{align}}$
人类第一视角视频 当前／未来帧，无机器人动作 仅 $\mathcal L_{\mathrm{align}}$

论文的人类视频实验为每个新物体采集 150 条头戴 GoPro 示范，机器人侧最多采集 10 条遥操作示范；在每个物体仅 1 条机器人轨迹时也报告了显著收益。这证明该训练范式可以利用无动作视频，但不证明模型从视频中恢复了真实机器人动作。

一种合理机制解释是：视频监督让表示学习当前到未来的任务相关变化，再由少量机器人示范把这种表示与机器人动作联系起来。论文没有对这一内部因果链做表示探针，因此应标成解释，不应写成已经观测到的“模型学会了世界如何变化”。

复现层面仍有关键缺口：论文未说明人类视频分支给状态／动作查询放什么、两类数据如何采样与加权、不同视角如何对齐、未来间隔如何随视频帧率换算。这些不能从 Figure 1 自行补全。

八、层号、系数与目标编码器消融

8.1 论文主设置是 8 层中的第 6 层

论文 FLARE 实验使用 8 个 DiT block，主设置在第 6 层施加对齐。消融显示多个层号和 $\lambda$ 都能工作，但第 4 层明显下降；作者据此强调未来预测目标要与动作去噪过程协调。页面标题不应写成“必须加在中间层”：现有证据只支持“在该 8 层策略和基准中，第 6 层优于过早的第 4 层”。

从计算图可以确定：若在第 $L$ 层抽取，FLARE 梯度至少覆盖 future token、投影器和前 $L$ 个 block。由于 $f_\theta$ 还依赖当前视觉语言条件、状态 token 与加噪动作 token，只要这些上游编码器未冻结且未显式停止梯度，对齐损失也会反传到策略侧视觉语言编码器、状态编码器和动作编码器；目标编码器 $g$ 则在当前步停止梯度，只通过 EMA 更新。更深的 $L$ 让更多早期 block 接收辅助监督，同时也让预测表示经历更多动作去噪交互。至于各层是否分别编码“低级噪声”和“高级语义”，论文没有表示分析，不能当成事实。

8.2 不能把论文层号直接搬到 N1.5

公开 N1.5 DiT 有 16 个交替 block，而论文消融模型只有 8 个 block。官方 N1.5 页面只公开 $\lambda=0.2$，没有公开抽取层 $L$、目标编码器结构、EMA 系数或人类视频批次路由。因此“论文第 6 层”既不是 N1.5 已证实配置，也不能按比例机械换成第 12 层；需要受控验证。

九、GR00T N1.5 中的落地边界与复现清单

9.1 三层证据不能混写

证据 能确认什么
NVIDIA Research 页 N1.5 声称加入 FLARE，预训练与后训练均用系数 0.2，并用其学习人类视频
FLARE 论文 方法、8 层实验策略、目标编码器、EMA、消融和算法草图
固定 n1.5-release 定义并拼接 32 个 future token；DiT 能返回中间层，但训练前向硬编码 return_all_hidden_states=False 并注释“not using flare now”
固定发布配置 num_target_vision_tokens=32；未提供 FLARE 层号、投影器或目标编码器配置

公开训练前向只计算动作 MSE，没有目标编码器、embedding projector、未来观测编码、余弦损失或 EMA。因此不能说“开源代码已实现完整 FLARE”。但 32 个 future token 也不是完全惰性的：公开 DiT 的自注意力层会让它们影响动作 token，动作损失可沿这条路径间接更新它们。

9.2 补齐完整 FLARE 至少需要五项

  1. 数据管线同时返回当前观测、未来观测及未来间隔，并定义无动作视频的查询输入；
  2. 在指定 block 后取中间隐藏状态，按 $[S:S+M]$ 切出 future token；
  3. 增加两层投影器，使预测宽度与目标宽度一致；
  4. 增加与策略编码器参数可对应的目标编码器，目标侧停止梯度并在优化器更新后执行 EMA；
  5. 按机器人／视频样本掩码组合流匹配与对齐损失，并记录各自分母，避免缺失动作样本污染 MSE。

还需要明确 $L$、$D$、余弦归约、$\rho$、视频采样权重和未来帧间隔。论文提供了方向，但没有把这些全部落实到 N1.5 公开训练栈。

9.3 核心创新点

  • 用未来潜在表示代替未来像素生成，把世界建模变成轻量辅助监督；
  • 用单独 future token 承载预测目标，同时通过自注意力与动作生成交互；
  • 用动作感知目标编码器把监督集中到控制相关信息，并用 Q-former 压成固定 32 token；
  • 让无动作人类视频通过未来对齐进入训练；
  • 用 EMA 缓慢更新教师，兼顾下游域适应与目标稳定。

这些是 FLARE 论文方法的创新点；N1.5 公开代码只显示部分结构痕迹，不能把完整方法行为归于发布前向。

TD3：不让确定性 Actor 把估值误差当作捷径

TD3 继承 DDPG 的确定性 Actor、经验回放、在线/目标网络和 Polyak 更新；相对 DDPG，它增加第二套 Critic，并用 Clipped Double Q、延迟 Actor/Target 更新和目标策略平滑共同限制函数逼近误差的传播。重点不是背诵三个技巧，而是理解它们分别作用于价值聚合、更新频率和目标动作邻域，并各自带来什么代价。

3 项核心改动价值聚合、更新时序、动作邻域
Off-policyReplay 复用历史交互
确定性策略探索噪声不属于策略分布

本专题的前置边界。 确定性策略梯度、DDPG 的四套逻辑参数、Replay Buffer、行为探索和普通 Polyak 更新已在 DDPG 专题 展开。离散动作中“选择最大估值为何偏向正误差”的推导和 Double DQN 见 高估偏差页；连续确定性 Actor 通过学习到的动作梯度近似寻找高值动作，机制相近，但不是离散 \(\max\) 的同一个严格定理。

页面顺序不等于算法谱系。 本站把 TD3 放在 SAC 专题之后，便于对照随机最大熵路线；但 TD3 在算法谱系上直接由 DDPG 演化而来，并非 SAC 的后继。SAC 的最大熵、Squashed Gaussian、重参数化和自动温度均链接到 SAC 页面，不在这里重复推导。

1. TD3 修复的是怎样的反馈回路

Critic 是函数逼近器，局部估值误差不可避免。确定性 Actor 沿当前 Q 曲面的动作梯度更新，因此可能优先移向被高估、但数据覆盖不足的区域。策略变化会逐步改变行为数据分布；若乐观误差进入 Bellman target，还可能经后续 bootstrap 传播。问题不是“每个状态必然高估”，而是选择、评价和自举之间可能形成正反馈。

flowchart LR
  E["Critic 局部估值误差"] --> A["Actor 可能沿动作梯度<br/>偏向局部虚高区域"]
  A --> D["行为策略与后续数据分布<br/>可能逐步移动"]
  D --> B["Bellman target 与 Replay<br/>继续训练 Critic"]
  B --> E
  C["Clipped Double Q"] -. "阻止任一单 Critic 的较大估计<br/>直接决定 target" .-> B
  L["Delayed Policy/Target Updates"] -. "降低追随瞬时 Q 误差的频率" .-> A
  S["Target Policy Smoothing"] -. "降低狭窄 Q 峰对 target 的影响" .-> B

Actor 只是受网络参数化、优化器与数据覆盖限制的近似高值动作搜索器，并不等同于求得连续动作空间的精确全局 \(\arg\max\)。完整误差分解、证据边界与反例见 误差机理与研究动机。

2. 三项改动：同一反馈回路的三个切口

01 · Clipped Double Q

两个目标 Critic 评价同一个平滑目标动作，Bellman target 逐样本取较小值。它可阻止任一 Critic 的单独正误差直接进入 bootstrap，但不能消除两个 Critic 的共同高估，同时可能引入低估。

02 · Delayed Policy/Target Updates

双 Critic 每个 learner 更新步优化一次；Actor 与三套 Target 参数每隔 \(d\) 个 Critic 更新步才更新。它降低追逐瞬时价值误差的频率，不保证 Critic 已收敛；\(d\) 过大会拖慢响应。

03 · Target Policy Smoothing

只在 Bellman target 的下一动作上加入受限噪声。一次更新用一个噪声样本近似邻域期望；它不改变当前 Actor 的确定性输出，也不同于环境交互时的探索噪声。过强平滑会损害精细动作最优。

创新归因。 经验回放、目标 Actor/Critic、Polyak 更新和确定性策略梯度继承自 DDPG；Double Q 思想也有更早来源。TD3 的核心贡献，是分析函数逼近误差怎样在确定性 Actor–Critic 中被策略更新放大，并把 Clipped Double Q、延迟 Actor/Target 更新和目标策略平滑组织成一套连续控制稳定化方案。三项机制都只是缓解风险，不是稳定性保证。

3. 一次完整更新：先统一符号和计数

本专题统一使用：

\(\text{Online Actor: }\mu_\phi,\qquad \text{Target Actor: }\mu_{\phi'},\) \(\text{Online Critics: }Q_{\theta_1},Q_{\theta_2},\qquad \text{Target Critics: }Q_{\theta_1'},Q_{\theta_2'}.\)

Replay 应保存 \((s,a,r,s'_{\mathrm{final}},terminated,truncated)\)，或直接保存已按任务语义判定的 bootstrap mask。自动重置/向量环境中，\(s'_{\mathrm{final}}\) 必须是重置前的 final observation，不能把下一 episode 的初始观测当成当前 transition 的 \(s'\)。

flowchart TB
  TD3_RB[("Replay Buffer<br/>s, a, r, s_final_next,<br/>terminated, truncated")] --> TD3_BATCH["随机 minibatch"]
  TD3_BATCH --> AT["Target Actor<br/>mu_target(s_final_next)"]
  AT --> N["目标噪声裁剪<br/>再做动作边界裁剪"]
  N --> T1["Target Q1"]
  N --> T2["Target Q2"]
  T1 --> M["逐样本 minimum"]
  T2 --> M
  TD3_BATCH --> RM["reward r<br/>bootstrap mask m_boot"]
  RM --> Y["Bellman target y"]
  M --> Y
  TD3_BATCH --> Q1["Online Q1(s,a)"]
  TD3_BATCH --> Q2["Online Q2(s,a)"]
  Y -. "整体 stop-gradient" .-> LQ["两个 Critic loss 之和"]
  Q1 --> LQ
  Q2 --> LQ
  LQ --> UQ["成功执行双 Critic optimizer step<br/>critic_updates += 1"]
  UQ --> G{"critic_updates mod d = 0?"}
  G -->|"否"| X["结束本次 learner 更新"]
  G -->|"是"| LA["Actor loss<br/>-mean Q1(s, policy_action)"]
  LA --> UA["更新 Actor"]
  UA --> ST["用最新 Online 参数<br/>Polyak 更新三套 Target"]

critic_updates 是跨训练调用保存的累计 Critic optimizer 步数；它不是环境 transition 数、并行环境 step 数或 episode 数。只有 Critic optimizer step 成功后才递增，再判断是否进入延迟分支。

总公式

先在统一的归一化动作坐标中构造目标动作：

\(\epsilon\sim\mathcal N(0,\sigma_{\mathrm{targ}}^2I),\qquad \hat\epsilon=\operatorname{clip}(\epsilon,-c,c),\) \(\tilde u' = \operatorname{clip}\!\left( \mu_{\phi'}(s'_{\mathrm{final}})+\hat\epsilon,-1,1 \right),\qquad \tilde a'=\mathcal T(\tilde u').\)

\(\mathcal T\) 表示 Actor 输出到 Critic 动作接口的统一变换；若 Critic 直接接收归一化动作，它就是恒等映射。若接收环境物理动作，则可用 \(\mathcal T(u)=b+d\odot u\)，其中 \(d=(a_{\max}-a_{\min})/2\)、\(b=(a_{\max}+a_{\min})/2\)。若直接在物理动作坐标加噪声，\(\sigma_{\mathrm{targ}}\) 与 \(c\) 应按各维尺度设置。噪声裁剪和动作边界裁剪是两次不同操作；靠近边界时，有效扰动不再对称。

令 \(m_{\mathrm{boot}}\) 表示是否允许 bootstrap：

\(m_{\mathrm{boot}}= \begin{cases} 0,&\text{真正的 MDP 终止},\\ 1,&\text{普通非终止转移，或仅由外部时间上限造成且任务仍可延续的截断}, \end{cases}\) \(y= r+\gamma m_{\mathrm{boot}} \min_{i\in\{1,2\}} Q_{\theta_i'}(s'_{\mathrm{final}},\tilde a'),\) \(L_Q= \mathbb E\!\left[ \bigl(Q_{\theta_1}(s,a)-y\bigr)^2+ \bigl(Q_{\theta_2}(s,a)-y\bigr)^2 \right],\) \(L_\pi= -\mathbb E_{s\sim\mathcal D} \left[ Q_{\theta_1}\!\left(s,\mathcal T(\mu_\phi(s))\right) \right].\)

若超时本身属于有限时域 MDP 的终止语义，mask 应按任务定义设置，状态还应包含必要的剩余时间信息。Actor 更新时可冻结 Critic 参数以避免累积无用梯度，但必须保留 \(Q_{\theta_1}\) 对动作输入的梯度；不能把整个 Critic 前向放进 no_grad。Bellman target \(y\) 则应整体停止梯度。

在延迟分支中，Actor optimizer 成功更新后，再用最新 Online 参数执行：

\[\phi'\leftarrow\tau\phi+(1-\tau)\phi',\qquad \theta_i'\leftarrow\tau\theta_i+(1-\tau)\theta_i', \quad i\in\{1,2\}.\]

详细推导分别见 Clipped Double Q、延迟更新、目标策略平滑和损失与优化。

4. 六套逻辑参数与梯度职责

逻辑参数 输入 → 输出 参数更新 独有职责
Online Actor 状态 → 策略动作 延迟 Actor optimizer 生成策略动作，接收 Q1 的动作梯度
Online Critic 1 状态、动作 → Q1 每个 Critic step TD 回归，并为 Actor 提供动作梯度
Online Critic 2 状态、动作 → Q2 每个 Critic step 用独立 Q 参数拟合同一 target
Target Actor 下一状态 → 目标动作 无 optimizer；延迟 Polyak 构造 target action
Target Critic 1 下一状态、目标动作 → target Q1 无 optimizer；延迟 Polyak 参与逐样本 minimum
Target Critic 2 下一状态、目标动作 → target Q2 无 optimizer；延迟 Polyak 参与逐样本 minimum

“六套逻辑参数”不要求六个顶层 Python 对象：两个 Critic 可以封装在同一个模块。两个 Q 使用相同数据与 target，因此并非统计独立；但它们不能退化为完全相同的参数化函数。若有意共享 encoder，应记录共享范围，因为更高的误差相关性会削弱 minimum 对单 Critic 正误差的过滤能力。所有 Actor 路径必须使用同一套动作 scale/bias 约定。

5. DDPG、常用 SAC 与 TD3 的最小对照

此处 SAC 指目前常见的 twin-Q、无独立 value network 版本。

维度 DDPG 常用 SAC TD3
策略/探索 确定性；外加行为噪声 随机 Squashed Gaussian；策略分布内生 确定性；外加行为噪声
价值估计 单 Q 双 Q；soft Bellman target 含熵项 双 Q；target 逐样本取较小值
Actor 使用的价值 单 Q 通常用双 Q 的较小值并加入熵项 Online Q1
Target 动作 Target Actor 当前随机 Actor 采样；通常无 Target Actor Target Actor + 受限目标噪声
Actor 调度 通常随 Critic 更新 实现相关 每 \(d\) 个 Critic 更新步一次
相对 DDPG 的代表性新增机制 本行无额外项 随机策略、熵正则与温度调节，常配 twin Q twin Critic、clipped target、延迟更新、目标策略平滑

SAC 中 twin Q、soft target 和自动温度的具体定义见 SAC 损失函数与 SAC 训练流程。

6. 九个子页：每页只承担一个主要问题

01 · MOTIVATION

7. 按问题选择阅读路径

想理解论文误差机理 → Clipped Double Q → 延迟更新 → 目标平滑；重点区分论文证据、机制解释与适用边界。
想从零实现网络结构 → 损失与梯度 → PyTorch；先验证动作单位、shape、target 无梯度、延迟计数和 checkpoint 恢复。
训练结果异常先读诊断页，按“环境与数据 → target → Critic → Actor → 评估”五层逐步收缩，不要先盲调学习率。
做机器人控制目标平滑 → 架构 → 实现 → 诊断 → 改进地图；TD3 之外还需单独验证控制频率、动作平滑、能耗、约束和 sim-to-real 偏差。
准备研究改进诊断 → 改进地图；先判断瓶颈属于离线数据、表示、稀疏目标还是并行训练规模，再选消融。

8. 适用边界

标准 TD3 常作为有界连续动作、允许在线交互且希望通过 Replay 提高数据复用率时的候选基线；是否优于 SAC 或其他方法，仍需在相同数据与计算预算下验证。它不是以下问题的自动答案：

  • 离散动作需要不同的动作选择与策略表示。
  • 固定离线数据需要额外抑制分布外动作，例如 TD3+BC。
  • 单一确定性 Actor 表示单峰动作映射；多模态动作决策可能超出其表达能力。
  • 稀疏目标任务常需 HER 等数据重标记。
  • 真实机器人还需安全层、执行延迟建模、动作约束与接口契约，以及独立部署验证。
  • twin Q、delay 和 smoothing 缓解部分误差反馈，但不保证所有任务稳定或优于 SAC。

最大熵目标如何变成可训练的策略迭代

本页只回答理论问题：熵约束怎样改变价值定义、策略提升为什么等价于 KL 投影、现代 SAC 的 Actor Loss 与自动温度从哪里来。普通 Bellman 方程和策略梯度定理不在这里重复。

← SAC 枢纽 下一页：网络结构 → 前置：策略梯度 前置：Actor-Critic

从约束而不是“加奖励技巧”开始

先固定符号。策略在状态 \(s\) 的熵定义为

\[\mathcal H(\pi(\cdot\mid s)) =\mathbb E_{a\sim\pi(\cdot\mid s)}[-\log\pi(a\mid s)].\]

自动温度版本不是简单地“给奖励加一个熵 bonus”，而是从最小期望熵约束出发。有限时域的严谨表述是：对每个时刻 \(t\)，在该时刻的状态边缘分布 \(d_{\pi,t}\) 上，平均策略熵不低于 \(\bar{\mathcal H}\)：

\[\max_{\pi_{0:T}}\quad \mathbb E_{\rho_\pi}\left[\sum_{t=0}^{T}\gamma^t r(s_t,a_t)\right] \quad\text{s.t.}\quad \mathbb E_{s_t\sim d_{\pi,t}} \left[\mathcal H(\pi_t(\cdot\mid s_t))\right] \ge \bar{\mathcal H},\quad \forall t.\]

这里约束的是每个时刻对已访问状态的平均熵，不是对每个状态逐点施加下界，也不是只对 replay 中动作的经验频数计算离散熵。

为每个约束引入 \(\alpha_t\ge0\) 后，对偶结构是“外层最小化温度、内层最大化策略”：

\[\min_{\alpha_{0:T}\ge0}\ \max_{\pi_{0:T}} \mathbb E_{\rho_\pi}\left[ \sum_{t=0}^{T}\gamma^t \left(r_t+\alpha_t\bigl(\mathcal H(\pi_t(\cdot\mid s_t))-\bar{\mathcal H}\bigr)\right) \right].\]

实用 SAC 假设平稳策略和单个共享温度 \(\alpha\)。当只更新策略且固定 \(\alpha\) 时，\(-\alpha\bar{\mathcal H}\) 对策略参数是常数，可以省略，于是得到常见目标：

\[J(\pi)=\mathbb E_{\tau\sim\pi}\left[\sum_{t=0}^{\infty}\gamma^t \left(r(s_t,a_t)-\alpha\log\pi(a_t\mid s_t)\right)\right].\]

\(\alpha\) 不是环境噪声尺度，而是熵约束的对偶变量：经验熵低于 \(\bar{\mathcal H}\) 时，提高 \(\alpha\) 会加重熵项；经验熵高于约束时，降低 \(\alpha\) 会把权重交还给回报。注意：\(-\alpha\bar{\mathcal H}\) 只对策略参数是常数，学习 \(\alpha\) 时不能删掉。

固定 \(\alpha\) 对奖励尺度敏感：奖励整体放大十倍，熵项相对变小。自动温度可以减轻逐任务手调，但不会消除目标熵、优化速度、动作坐标系和策略族等工程选择。

Soft Q 与 Soft V：先统一记号

本专题采用现代 SAC 常见约定：\(Q^\pi(s,a)\) 在当前动作 \(a\) 已给定时，不重复计入“当前动作的随机性”；当前状态的熵出现在对动作分布求期望的 \(V^\pi\) 中。

\[Q^\pi(s,a)=r(s,a)+\gamma\,\mathbb E_{s'\sim p(\cdot\mid s,a)}[V^\pi(s')],\] \[V^\pi(s)=\mathbb E_{a\sim\pi(\cdot\mid s)} \left[Q^\pi(s,a)-\alpha\log\pi(a\mid s)\right].\]

代入后得到固定策略下的 soft Bellman 递推：

\[Q^\pi(s,a)=r(s,a)+\gamma\,\mathbb E_{s',a'} \left[Q^\pi(s',a')-\alpha\log\pi(a'\mid s')\right].\]

代码中的 \(\min_i\bar Q_i(s',a')-\alpha\log\pi(a'\mid s')\)，是对下一状态 soft value 的单样本、双 Q 近似；双 Q minimum 是稳定化选择，不属于 soft Bellman 定义本身。

为什么熵项在下一状态

Replay Buffer 给出的当前动作已经发生；Critic 回归的是这个已执行动作的价值。下一状态的价值需要对当前策略接下来会选择的动作取期望，并把下一步策略熵计入。若又在当前 replay 动作上减一次 \(\alpha\log\pi(a\mid s)\)，就改变了这里采用的 Q 定义，容易造成重复计入。

不同论文也可能把当前熵奖励吸收到 Q 的定义中，式子外观随之改变。核对实现时应比较完整递推和时间索引，不能只截取一项判断“符号错了”。

Soft Policy Evaluation

固定 \(\pi\) 后，soft Bellman operator 为

\[(\mathcal T^\pi Q)(s,a)=r(s,a)+\gamma\,\mathbb E_{s',a'} \left[Q(s',a')-\alpha\log\pi(a'\mid s')\right].\]

SAC 论文的表格型结论在有限动作集合、精确期望与有界回报等条件下成立：反复应用该算子收敛到固定策略的 soft Q。深度 SAC 并没有每轮把 Critic 精确评估到收敛；它从 replay 抽有限 batch，只做若干梯度步，并使用函数逼近和目标网络。因此，理论给出设计依据，却不保证任意神经网络实现都稳定或逐次单调改进。

Soft Policy Improvement：KL 投影如何给出 Actor Loss

在表格型推导中，给定旧策略的 soft Q 且 \(\alpha>0\) 后，理想改进分布具有 Boltzmann 形状：

\[q_Q(a\mid s)=\frac{\exp(Q^{\pi_{\mathrm{old}}}(s,a)/\alpha)}{Z(s)}, \qquad Z(s)=\int_\mathcal A\exp(Q^{\pi_{\mathrm{old}}}(s,a)/\alpha)\,\mathrm da.\]

离散有限动作时 \(Z(s)\) 自动有限；连续动作时还必须满足 \(0<Z(s)<\infty\)，否则右侧不是合法概率密度。有限有界动作域加上有界 \(Q\) 是一个充分条件；无界动作域则需要 \(Q(s,a)\) 在动作远离时具有足够的负增长，不能仅凭“写出指数”就假设可归一化。

受限策略族中的改进写成正向为策略、反向为 Boltzmann 目标的 information projection：

\[\pi_{\mathrm{new}} =\arg\min_{\pi'\in\Pi} D_{\mathrm{KL}}\left( \pi'(\cdot\mid s)\;\middle\|\; \frac{\exp(Q^{\pi_{\mathrm{old}}}(s,\cdot)/\alpha)}{Z(s)} \right).\]

逐步展开：

写开 KL。期望内为 log pi'(a|s) - Q(s,a)/alpha + log Z(s)。
去掉常数。log Z(s) 对新策略参数无梯度。
乘回 alpha。得到最小化 E[alpha log pi'(a|s) - Q(s,a)]。
用参数策略近似。连续动作中通常无法显式计算 Z，用可重参数化策略采样估计期望。

现代双 Q SAC 的工程 Actor Loss 因而写成：

\[L_\pi(\theta)=\mathbb E_{s\sim\mathcal D,\epsilon\sim\mathcal N} \left[ \alpha\log\pi_\theta(a_\theta(s,\epsilon)\mid s) -\min_{i\in\{1,2\}}Q_{\phi_i}(s,a_\theta(s,\epsilon)) \right].\]

状态来自 replay 的经验分布，动作由当前 Actor 重新采样。更新 Actor 时 \(\phi_i\) 不由 Actor 优化器更新，但 不能把 \(Q_{\phi_i}(s,a)\) 对动作 \(a\) 的梯度截断；这条路径正是重参数化梯度让 Actor 学会提高 Q 的通道。

表格型受限策略族的“不变差”结论还需要旧策略属于候选族 \(\Pi\)、每个状态上的 KL 投影被全局精确求解，并且 soft Q 已被精确评估。神经网络 SAC 只用 replay 小批量做有限次参数梯度，因此上述 Actor Loss 给出的是理论投影的随机近似，不继承逐次策略改进保证。

受限策略族的边界。Boltzmann 目标可能复杂甚至多峰，而标准连续 SAC 的单个对角高斯经 tanh 后仍受表达能力限制。上述方向的 KL 投影只在策略族 \(\Pi\) 中寻找近似成员；“最大熵”不会自动把单高斯变成任意多峰策略，也不能保证确定性代理动作位于高价值模式。

Soft Policy Iteration 的完整逻辑

flowchart LR
  P0["当前策略 pi_k"] --> EV["Soft policy evaluation<br/>学习 Q^{pi_k}"]
  EV --> BI["构造 Boltzmann 目标<br/>exp(Q/alpha)/Z"]
  BI --> KL["受限策略族内<br/>最小化 KL"]
  KL --> P1["改进策略 pi_{k+1}"]
  P1 --> EV
  EV -. "深度实现：有限 batch、有限梯度步" .-> KL

SAC 把抽象循环近似成并行的三个学习器：Critic 近似评估，Actor 近似投影，温度优化器调节约束强度。Replay Buffer 让评估使用历史分布，Target Critic 让自举目标变化得更慢。这是“理论迭代”到“联合随机优化”的近似，不应把表格型证明直接当作深度网络收敛证明。

自动温度：对偶目标与工程实现不要混写

在更新温度时，Actor 输出和 log_prob 应视为常量。论文的对偶目标是

\[J_\alpha(\alpha)= \mathbb E\left[-\alpha \left(\log\pi_\theta(a\mid s)+\bar{\mathcal H}\right)_{\mathrm{stopgrad}} \right],\qquad \alpha\ge0.\]

令 \(\beta=\log\alpha\)、\(\alpha=\exp(\beta)\) 可保证温度为正。严格代入得到

\[J_\alpha(\exp\beta)= -\mathbb E\left[\exp(\beta) \left(\log\pi_\theta(a\mid s)+\bar{\mathcal H}\right)_{\mathrm{stopgrad}} \right].\]

也有实现使用下面的预条件化 surrogate：

\[L_\beta(\beta)= -\mathbb E\left[\beta \left(\log\pi_\theta(a\mid s)+\bar{\mathcal H}\right)_{\mathrm{stopgrad}} \right].\]

它与严格的 \(\exp(\beta)\) 目标具有相同的更新方向和驻点，但梯度少了正比例因子 \(\alpha\)，所以步长尺度不同；比较代码时不能只看 Loss 数值是否一致。

用 \(\mathcal H_{\mathrm{emp}}=\mathbb E[-\log\pi]\) 检查方向：

  • 若 \(\mathcal H_{\mathrm{emp}}<\bar{\mathcal H}\)，约束被违反，梯度下降会增大 \(\beta\) 与 \(\alpha\)；
  • 若 \(\mathcal H_{\mathrm{emp}}>\bar{\mathcal H}\)，约束有余量，梯度下降会减小 \(\alpha\)。

这只说明反馈方向，不保证存在有限稳定点。若目标熵高于当前策略族在给定动作坐标与边界下可达到的最大平均熵，约束不可行，\(\alpha\) 可能持续增大；若优化器、log-std 限幅或数值饱和阻止策略达到目标，也会出现同样现象。诊断时必须同时检查经验熵、log-std、tanh 饱和率和 \(\alpha\)，不能把温度发散一律归因于学习率。

目标熵的负号不是笔误

连续动作代码常取 \(\bar{\mathcal H}=-\dim(\mathcal A)\)。这里比较的是微分熵，它本来就可以为负，因此不应把 -dim(A) 擅自改成正数。这个值只是启发式，不是任务最优性定理；动作坐标系、策略分布族和安全约束都会影响合理口径。离散 SAC 的 categorical entropy 也不能直接沿用同一规则。

连续微分熵与动作尺度的三个陷阱

  1. 微分熵可以为负。它不是离散熵的非负量直觉。
  2. 概率密度可以大于 1。所以单样本 log_prob 可以为正。
  3. 变量尺度会改变熵。若 \(a=b+c\odot\tanh u\)，物理动作密度的 log-prob 还包含 \(-\sum_i\log\lvert c_i\rvert\)。这个固定常数不直接改变固定温度下熵项对 Actor 参数的梯度，却会平移 soft value/TD target，并改变自动温度看到的绝对熵值；在策略可影响 episode 长度的任务中，每步常数还可能间接改变行为偏好。log_prob、奖励口径与目标熵必须定义在同一动作坐标系中。

早期与现代 SAC

比较项 ICML 2018 早期形式 现代双 Q 形式
在线价值网络 Q1、Q2、V Q1、Q2
目标网络 Target V Target Q1、Target Q2
下一状态价值 Target V(s’) min Target Q(s',a') - alpha log pi
温度 主要作为固定超参数 可由平均熵约束自动学习
工程影响 多一套 V 回归及误差 结构更简，成为常见基线

Spinning Up 展示的是无独立 V 网络、固定 alpha 的教学版本；CleanRL 与 Stable-Baselines3 提供自动温度。它们不是互相矛盾的算法，而是不同实现版本；阅读代码时必须先确认网络与温度约定。

SAC 理论框架真正创新在哪里

  1. 随机性进入优化目标。探索不再只是给确定性动作外加噪声，而是策略本身学习状态相关的分布。
  2. Soft policy iteration。策略改进从硬 argmax Q 变为向 Boltzmann 目标的受限 KL 投影。
  3. 可微随机控制。重参数化把随机动作写成参数与独立噪声的可微函数，以较低方差优化 Actor。
  4. 后续自动温度扩展把温度变成对偶变量。探索—利用权衡可由平均熵约束在线调节，而不只是固定超参数；这不是 ICML 2018 固定温度版本中已经具备的机制。

Twin-Q minimum、Target Critic 与 Replay Buffer 对实用稳定性很重要，但它们分别来自偏差控制、目标平滑与 off-policy 数据复用，不应被误写成最大熵理论的必然结论。

理论结论不能推出什么

  • 不能推出神经网络近似下单调改进或必然收敛。
  • 不能推出 clipped minimum 无偏；它可能以低估换取对正偏差的抑制。
  • 不能推出单高斯能表示理想 Boltzmann 分布。
  • 不能推出最大熵策略天然满足真机安全、动作平滑或时序约束。
  • 不能推出 off-policy SAC 能在任意固定数据集上工作；那属于 offline RL 的分布外估计问题。

本页重点：三处完整推导。其一是贝尔曼方程——从回报的定义出发，先把 \(G_t\) 拆成一步奖励加折扣后的剩余回报，再用全期望公式对动作与下一状态逐层条件化，其中「用马尔可夫性把条件从整段历史缩到下一状态」这一步是全篇的关键。其二是贝尔曼期望方程与最优方程的区别，前者对 \(V\) 线性因而有解析解 \(V = (I - \gamma P)^{-1} R\)，后者含 \(\max\) 因而只能迭代求解。其三是占用度量，它把「策略」这个函数对象翻译成「状态-动作上的分布」，是模仿学习与 GAIL 的理论起点。马尔可夫过程与 MRP 的基础定义用一张递进关系表带过，不展开。

本章要解决什么问题

上一章的多臂老虎机只有一个状态，因此每一步的处境完全相同，「这个动作有多好」就等于「这一步的期望奖励」。真实问题不是这样：机械臂现在把夹爪张开，好处要到几十步之后抓取成功时才体现出来；现在走错一步，可能把自己置于一个之后怎么补救都来不及的位形。一旦当前动作会改变未来的处境，动作的好坏就不能只看眼前的奖励。

这带来三个必须回答的问题。

  • 怎么描述「处境」？ 需要引入状态，并且需要一个假设来保证状态是「够用」的——否则智能体必须记住全部历史，问题在计算上不可解。这个假设就是马尔可夫性质。
  • 怎么把「未来的好处」折算到现在？ 需要回报与价值函数，把一整条尾巴上的奖励压缩成一个标量。
  • 怎么让这个标量可计算？ 价值函数按定义是对无穷长轨迹求期望，直接算不动。贝尔曼方程把它变成一个自己引用自己的递推式，从而可解——这是本章最重要的结果，也是后续每一个算法（动态规划、时序差分、DQN、Actor-Critic 的 Critic）的共同地基。

本章还会给出一个看起来抽象、但在模仿学习那条线上极其关键的工具：占用度量。它把「策略」翻译成「状态-动作上的一个概率分布」，使得「两个策略是否相同」可以用「两个分布是否相同」来判定。这条等价关系是 GAIL 用判别器区分专家与学生的全部理论依据。

本章的一切都建立在「模型已知」的假设上，也就是假定 \(P\) 与 \(r\) 都写得出来。这个假设在本章成立（示例 MDP 是手写的），但在真实任务里几乎不成立。本章末尾的蒙特卡洛方法是第一个不需要模型的估值方法，它把「无法计算期望」换成「大量采样后取平均」，这条思路会一直延续到时序差分与 DQN。

形式化定义：从马尔可夫过程到 MDP

马尔可夫性质

一个随机过程具有马尔可夫性质（Markov property），是指下一时刻的状态只依赖当前状态，与更早的历史无关：

\[P\big(s_{t+1} \mid s_t,\ s_{t-1},\ \dots,\ s_0\big) = P\big(s_{t+1} \mid s_t\big)\]

这个假设的作用不是「历史不重要」，而是「历史的全部有用信息都已经被压进当前状态」。因此马尔可夫性质与其说是对世界的描述，不如说是对状态定义的要求：如果单帧图像看不出速度，那单帧图像就不是一个合格的状态，把连续几帧堆叠起来才是。工程上补齐马尔可夫性的三种常见做法是堆叠历史观测、引入循环网络的隐状态、把速度等导出量显式加进观测向量。

它的价值在于把「策略是整段历史的函数」压缩成「策略是当前状态的函数」。前者的定义域随时间指数增长，后者是固定的，价值函数与贝尔曼方程才有可能存在。

三层模型的递进关系

从马尔可夫过程到 MDP 是逐层加东西的过程，一张表即可概括，本页不逐层展开。

层级 记号 相对上一层新增的成分 能回答的问题
马尔可夫过程（MP） 二元组，状态集合与状态转移矩阵 无（最底层） 系统会怎么演化
马尔可夫奖励过程（MRP） 三元组，MP 再加奖励函数与折扣因子 奖励与折扣 演化过程「值多少」
马尔可夫决策过程（MDP） 五元组，MRP 再加动作集合，转移与奖励改为依赖动作 动作（可干预） 该怎么做才能让它值更多

三层的关键分界在有没有动作。MP 与 MRP 里智能体只是旁观者，系统按固定的转移矩阵演化；MDP 里智能体能干预演化方向，于是「策略」这个概念才有意义，「最优」这个问题才成立。本页后面会看到，MDP 加上一个固定策略之后又会退化回 MRP——这个退化关系是所有策略评估算法的技术基础。

MDP 写成五元组，与强化学习总览一页保持同一记号：

\[\mathcal{M} = \langle \mathcal{S},\ \mathcal{A},\ P,\ r,\ \gamma \rangle\]
  • \(\mathcal{S}\) 是状态集合，\(\mathcal{A}\) 是动作集合。
  • \(P(s' \mid s, a)\) 是状态转移概率，满足对每个 \((s, a)\) 在 \(s'\) 上求和为 1。
  • \(r(s, a)\) 是奖励函数，本页取「奖励只依赖当前状态与动作」这一常用形式。
  • \(\gamma \in [0, 1)\) 是折扣因子。
  • 策略 \(\pi(a \mid s)\) 不属于 MDP 本身，它是智能体的一部分。这一点常被混淆：MDP 描述环境，策略描述智能体，价值函数是二者共同的产物。

回报与价值函数

从时刻 \(t\) 起的回报（return）定义为折扣奖励和：

\[G_t = r_t + \gamma r_{t+1} + \gamma^{2} r_{t+2} + \cdots = \sum_{k=0}^{\infty} \gamma^{k} r_{t+k}\]

折扣因子在这里有三重作用：保证无穷级数在奖励有界时收敛（因为 \(\sum_k \gamma^k = 1/(1-\gamma)\) 有限）；表达「近期奖励比远期更可信」这一先验；以及让后面的压缩映射论证成立。

回报是一个随机变量——同一个状态出发，不同的动作采样与转移采样会给出不同的 \(G_t\)。价值函数就是它的期望，状态价值函数 \(V^{\pi}\) 与动作价值函数 \(Q^{\pi}\) 分别定义为

\[V^{\pi}(s) = \mathbb{E}_{\pi}\big[\, G_t \mid s_t = s \,\big], \qquad Q^{\pi}(s, a) = \mathbb{E}_{\pi}\big[\, G_t \mid s_t = s,\ a_t = a \,\big]\]

后者比前者多固定了这一步的动作，二者由对动作分布求期望相联系：

\[V^{\pi}(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s)\, Q^{\pi}(s, a)\]

贝尔曼方程的完整推导

价值函数按定义是对无穷长轨迹求期望，无法直接计算。贝尔曼方程把它改写成一个只涉及「一步奖励」与「下一状态的价值」的递推式。下面把推导完整写出来，每一步标明依据。

第一步：把回报拆成一步奖励加折扣后的剩余回报

从回报的定义出发，把第一项单独提出来，其余各项提出公因子 \(\gamma\)：

\[G_t = r_t + \gamma r_{t+1} + \gamma^{2} r_{t+2} + \cdots = r_t + \gamma \big( r_{t+1} + \gamma r_{t+2} + \cdots \big)\]

括号内正是从 \(t+1\) 起的回报，于是

\[G_t = r_t + \gamma\, G_{t+1}\]

这一步是纯代数恒等变形，只用到了级数可以重排（在奖励有界且 \(\gamma < 1\) 时绝对收敛，重排合法）。注意它对每一条具体轨迹逐条成立，而不只是在期望意义下成立。

第二步：两边取条件期望，用期望的线性性拆开

对 \(s_t = s\) 取条件期望，期望是线性算子，可以逐项拆：

\[V^{\pi}(s) = \mathbb{E}_{\pi}\big[\, G_t \mid s_t = s \,\big] = \underbrace{\mathbb{E}_{\pi}\big[\, r_t \mid s_t = s \,\big]}_{\text{即时奖励项}} + \gamma\, \underbrace{\mathbb{E}_{\pi}\big[\, G_{t+1} \mid s_t = s \,\big]}_{\text{未来回报项}}\]

两项分别处理。

第三步：即时奖励项对动作取期望

\(r_t = r(s_t, a_t)\) 依赖于这一步实际执行的动作，而动作由策略采样，因此

\[\mathbb{E}_{\pi}\big[\, r_t \mid s_t = s \,\big] = \sum_{a \in \mathcal{A}} \pi(a \mid s)\, r(s, a)\]

这一步用的是全期望公式（law of total expectation）的最简形式：对 \(a_t\) 做一次条件分解，而 \(a_t\) 的条件分布正是 \(\pi(\cdot \mid s)\)。

第四步：未来回报项——本推导的关键一步

未来回报项 \(\mathbb{E}_{\pi}[G_{t+1} \mid s_t = s]\) 里，\(G_{t+1}\) 依赖于 \(t+1\) 之后的整条轨迹，而那条轨迹的起点是 \(s_{t+1}\)。用全期望公式对 \((a_t, s_{t+1})\) 做条件分解：

\[\mathbb{E}_{\pi}\big[\, G_{t+1} \mid s_t = s \,\big] = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} P(s' \mid s, a)\ \mathbb{E}_{\pi}\big[\, G_{t+1} \mid s_t = s,\ a_t = a,\ s_{t+1} = s' \,\big]\]

这一步成立的依据是全期望公式（也叫塔性质）：先对内层随机变量取条件期望，再对条件本身取期望，结果不变。这里的内层条件是「知道了这一步选了什么动作、落到了哪个状态」。

现在处理最内层那个条件期望。用马尔可夫性质把条件从整段历史缩到 \(s_{t+1}\)：

\[\mathbb{E}_{\pi}\big[\, G_{t+1} \mid s_t = s,\ a_t = a,\ s_{t+1} = s' \,\big] = \mathbb{E}_{\pi}\big[\, G_{t+1} \mid s_{t+1} = s' \,\big] = V^{\pi}(s')\]

这一步为什么成立，需要说清楚，它是整个推导里唯一用到马尔可夫性质的地方：\(G_{t+1}\) 由 \(s_{t+1}, a_{t+1}, s_{t+2}, \dots\) 决定；由马尔可夫性质，给定 \(s_{t+1}\) 之后，\(s_{t+2}\) 的分布与 \(s_t, a_t\) 无关；由策略是平稳的（只依赖当前状态、不依赖时刻），\(a_{t+1}\) 的分布也只依赖 \(s_{t+1}\)。逐级递推下去，\(t+1\) 之后整条轨迹的联合分布只由 \(s_{t+1}\) 决定，因此再多知道 \(s_t\) 与 \(a_t\) 也不提供任何额外信息。若马尔可夫性质不成立，这一步就断了，价值函数也就不能只写成状态的函数。

第二个等号还用到了平稳性：\(\mathbb{E}[G_{t+1} \mid s_{t+1} = s']\) 与 \(\mathbb{E}[G_t \mid s_t = s']\) 是同一个量，因为回报的定义相对起点是平移不变的，而 \(P\)、\(r\)、\(\pi\) 都不显含时刻。所以它就是 \(V^{\pi}(s')\)。

第五步：合并，得到贝尔曼期望方程

把第三步与第四步的结果代回第二步：

\[V^{\pi}(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \left[ r(s, a) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s, a)\, V^{\pi}(s') \right]\]

同样的推导用在 \(Q\) 上（区别只是第一步不对 \(a_t\) 取期望，因为它被条件固定了），得到

\[Q^{\pi}(s, a) = r(s, a) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \sum_{a' \in \mathcal{A}} \pi(a' \mid s')\, Q^{\pi}(s', a')\]

这两条式子就是贝尔曼期望方程。它们的意义在于：一个关于无穷长轨迹的量，被改写成了一个只涉及一步转移与「同一个未知函数在别处的取值」的方程组。未知数是 \(\lvert \mathcal{S} \rvert\) 个数（或 \(\lvert \mathcal{S} \rvert \times \lvert \mathcal{A} \rvert\) 个数），方程也是同样多个，问题从「求期望」变成了「解方程组」。

MRP 的解析解及其代价

把 MDP 的策略固定下来（下一节的边缘化会说明这一步怎么做），问题就退化成 MRP，贝尔曼期望方程简化为

\[V(s) = R(s) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s)\, V(s')\]

把 \(V\) 与 \(R\) 看作长度为 \(n = \lvert \mathcal{S} \rvert\) 的列向量、\(P\) 看作 \(n \times n\) 的转移矩阵，上式就是一个矩阵方程：

\[V = R + \gamma P V\]

移项：

\[V - \gamma P V = R \quad \Longrightarrow \quad (I - \gamma P)\, V = R\]

若 \(I - \gamma P\) 可逆，则

\[V = (I - \gamma P)^{-1} R\]

为什么 \(I - \gamma P\) 一定可逆。\(P\) 是随机矩阵，每行非负且和为 1，因此它的无穷范数 \(\lVert P \rVert_{\infty} = 1\)，从而 \(\lVert \gamma P \rVert_{\infty} = \gamma < 1\)。由 Neumann 级数的标准结论，当矩阵范数小于 1 时 \(I - \gamma P\) 可逆，且

\[(I - \gamma P)^{-1} = \sum_{k=0}^{\infty} (\gamma P)^{k} = I + \gamma P + \gamma^{2} P^{2} + \cdots\]

把这个展开代回去还能得到一个直观的解释：

\[V = \sum_{k=0}^{\infty} \gamma^{k} P^{k} R\]

其中 \(P^k R\) 正是「\(k\) 步之后所处状态的期望奖励」。也就是说，解析解与「回报是折扣奖励和」的原始定义完全一致——矩阵求逆不过是把那个无穷级数一次性求和了。

为什么实际不用它。四条理由，按重要性排列：

  • 计算复杂度。矩阵求逆（或等价地解稠密线性方程组）的复杂度是 \(O(n^{3})\)，\(n\) 是状态数。状态数一千时尚可，一万时已经吃力，十万时基本不可行。而真实任务的状态空间往往是连续的，\(n\) 直接是无穷。
  • 需要显式知道 \(P\) 与 \(R\)。解析解是彻头彻尾的 model-based 方法。真实机器人任务里没人写得出转移概率矩阵，这一条比复杂度更致命。
  • 不适合函数逼近。当 \(V\) 用神经网络表示时，「解方程」这个操作根本无从谈起，只能靠梯度下降逐步逼近。
  • 数值条件。\(\gamma\) 越接近 1，\(I - \gamma P\) 越接近奇异，条件数变大，求逆的数值误差被放大。

这四条正好构成了后续算法的路线图：复杂度问题由迭代法解决（见动态规划的策略评估与值迭代，每轮 \(O(n^{2})\) 而非 \(O(n^{3})\)）；模型未知问题由采样解决（本页的蒙特卡洛方法，以及时序差分）；函数逼近问题由神经网络加梯度下降解决（见 DQN）。

贝尔曼最优方程

上面解决的是「给定策略，它值多少」这个评估问题。真正要回答的是「哪个策略最好」这个优化问题。定义最优状态价值函数为所有策略中的最大者：

\[V^{*}(s) = \max_{\pi} V^{\pi}(s), \qquad Q^{*}(s, a) = \max_{\pi} Q^{\pi}(s, a)\]

这个定义本身有一处不平凡：它要求存在某个策略同时在所有状态上都取到最大值，而不是每个状态各有各的最优策略。这个结论（最优策略的存在性）在有限 MDP 上成立，且最优策略可以取成确定性的，证明依赖压缩映射与策略改进定理，本页只使用结论。

最优方程的推导分两个方向。

上界方向。对任意策略 \(\pi\)，由贝尔曼期望方程与 \(V^{\pi} \leq V^{*}\)，再注意右端是以 \(\pi(\cdot \mid s)\) 为权重的凸组合、凸组合不会超过其中的最大项：

\[V^{\pi}(s) = \sum_{a} \pi(a \mid s) \left[ r(s,a) + \gamma \sum_{s'} P(s' \mid s,a) V^{\pi}(s') \right] \leq \max_{a \in \mathcal{A}} \left[ r(s,a) + \gamma \sum_{s'} P(s' \mid s,a)\, V^{*}(s') \right]\]

对 \(\pi\) 取上确界，得到 \(V^{*}(s) \leq \max_a [\,\cdot\,]\)。

下界方向。构造对 \(V^{*}\) 贪婪的确定性策略，即在每个状态取右端的 argmax。这个策略在状态 \(s\) 上恰好取到 \(\max_a[\,\cdot\,]\)，而 \(V^{*}\) 是所有策略的上确界，故 \(V^{*}(s) \geq \max_a[\,\cdot\,]\)。

两个方向合起来即得贝尔曼最优方程：

\[V^{*}(s) = \max_{a \in \mathcal{A}} \left[ r(s, a) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s, a)\, V^{*}(s') \right]\] \[Q^{*}(s, a) = r(s, a) + \gamma \sum_{s' \in \mathcal{S}} P(s' \mid s, a) \max_{a' \in \mathcal{A}} Q^{*}(s', a')\]

期望方程与最优方程的区别

维度 贝尔曼期望方程 贝尔曼最优方程
对动作的处理 按 \(\pi(a \mid s)\) 取期望 取 \(\max\)
是否依赖某个策略 是，评估的是给定的 \(\pi\) 否，直接刻画最优
对 \(V\) 的性质 线性 分段线性但非线性（\(\max\) 不可加）
有无解析解 有，\(V = (I - \gamma P)^{-1} R\) 一般没有闭式解
主要求解方式 解线性方程组，或迭代式策略评估 值迭代、Q-learning 等迭代法
对应的问题 策略评估（prediction） 最优控制（control）

最关键的一条是线性与否。期望方程里对动作的求和是固定权重的线性组合，整个方程组对未知向量 \(V\) 线性，所以能一次性求逆解出。最优方程里的 \(\max\) 破坏了线性——两个 \(\max\) 之和一般不等于和的 \(\max\)——因此写不成 \(AV = b\) 的形式，闭式解不存在。

不过两个方程有一个共同的救命性质：它们各自定义的算子都是关于无穷范数的 \(\gamma\)-压缩映射。以最优算子为例，对任意两个价值向量 \(V_1, V_2\) 有

\[\big\lVert \mathcal{T}V_1 - \mathcal{T}V_2 \big\rVert_{\infty} \leq \gamma \big\lVert V_1 - V_2 \big\rVert_{\infty}\]

由 Banach 不动点定理，压缩映射有唯一不动点，且从任意初值反复作用都会几何速率收敛到它。这就是为什么最优方程虽然没有闭式解，却可以靠反复迭代解出来，也是动态规划一章值迭代算法的全部理论保证。\(\gamma\) 同时是收敛速率：\(\gamma\) 越接近 1，压缩越弱，需要的迭代轮数越多。

边缘化与占用度量

MDP 加上策略如何退化成 MRP

前面说过 MRP 有解析解，而 MDP 没有。但如果把策略固定下来，智能体就不再有选择权，动作变成了环境随机性的一部分，MDP 就退化成 MRP。技术上这一步叫边缘化（marginalization）：把动作这个维度按策略的概率加权求和消掉。奖励与转移各做一次，两条都是全概率公式的直接应用：

\[r_{\pi}(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s)\, r(s, a), \qquad P_{\pi}(s' \mid s) = \sum_{a \in \mathcal{A}} \pi(a \mid s)\, P(s' \mid s, a)\]

得到的 \(\langle \mathcal{S}, P_{\pi}, r_{\pi}, \gamma \rangle\) 就是一个 MRP，它的价值函数与原 MDP 在策略 \(\pi\) 下的 \(V^{\pi}\) 完全相同——把边缘化后的量代入 MRP 的贝尔曼方程，展开后恰好是 MDP 的贝尔曼期望方程，两者是同一个方程的两种写法。

这个退化关系的实际用途是：要评估 MDP 上的任意策略，只需边缘化成 MRP，再用解析解或迭代法求 \(V\)。本页代码实现的第一段就是这件事。它也是策略迭代算法里「策略评估」那一步的全部内容。

需要注意 \(P_{\pi}\) 依赖 \(\pi\)：策略一变，转移矩阵就变，\(V\) 也跟着变。这正是上一章提到的「数据分布由策略决定」在 MDP 层面的精确表述。

占用度量的定义

边缘化告诉我们策略如何改变状态转移。占用度量则更进一步，直接刻画策略最终会把智能体带到哪些状态-动作对上、各占多少比重。

设初始状态服从分布 \(\nu_0\)。状态访问分布与占用度量（occupancy measure）分别定义为

\[\nu^{\pi}(s) = (1 - \gamma) \sum_{t=0}^{\infty} \gamma^{t} P\big(s_t = s \mid \pi, \nu_0\big), \qquad \rho^{\pi}(s, a) = (1 - \gamma) \sum_{t=0}^{\infty} \gamma^{t} P\big(s_t = s,\ a_t = a \mid \pi, \nu_0\big)\]

后者是前者在状态-动作对上的版本。逐项解释：

  • \(P(s_t = s, a_t = a)\) 是在第 \(t\) 步恰好处于 \(s\) 并选择 \(a\) 的概率，它由 \(\nu_0\)、\(P\)、\(\pi\) 共同决定。
  • \(\gamma^{t}\) 是折扣权重，越晚访问到的状态-动作对权重越低。这与回报里的折扣一致，因此占用度量与价值函数天然匹配。
  • \((1 - \gamma)\) 是归一化系数。验证如下：对所有状态-动作对求和，内层的 \(\sum_{s,a} P(s_t = s, a_t = a) = 1\)（对每个 \(t\) 都是一个完整的概率分布），于是
\[\sum_{s, a} \rho^{\pi}(s, a) = (1 - \gamma) \sum_{t=0}^{\infty} \gamma^{t} = (1 - \gamma) \cdot \frac{1}{1 - \gamma} = 1\]

所以 \(\rho^{\pi}\) 本身就是一个概率分布。这一点是它全部作用的来源：它把「策略」这个函数对象翻译成了「状态-动作空间上的一个分布」，从而两个策略的比较可以变成两个分布的比较。

由定义直接可得两者的关系：

\[\rho^{\pi}(s, a) = \nu^{\pi}(s)\, \pi(a \mid s)\]

因为在给定 \(s_t = s\) 时选中 \(a\) 的条件概率恰好是 \(\pi(a \mid s)\)，与 \(t\) 无关（策略平稳），可以从求和号里提出来。

目标函数可以写成占用度量的线性泛函

有了占用度量，强化学习的目标函数可以完全脱离时间下标来写：

\[J(\pi) = \mathbb{E}_{\tau \sim \pi}\left[ \sum_{t=0}^{\infty} \gamma^{t} r(s_t, a_t) \right] = \frac{1}{1 - \gamma} \sum_{s, a} \rho^{\pi}(s, a)\, r(s, a)\]

推导只是把定义代进去：把期望写成对 \((s_t, a_t)\) 求和，交换求和次序（绝对收敛保证可交换），再凑出 \((1-\gamma)\) 的归一化因子并在外面补上它的倒数。

这个式子的意义值得强调：目标函数对 \(\rho^{\pi}\) 是线性的。原本的优化问题「在策略空间上最大化 \(J(\pi)\)」是非凸的；换到占用度量空间上，目标变成线性函数，可行域（所有合法占用度量构成的集合）是一个由线性约束刻画的凸多面体。这就是把强化学习写成线性规划的理论基础，也是离线强化学习与约束强化学习里常用的对偶视角。

两个策略的占用度量相同当且仅当策略相同

这是本节最重要的结论。

充分性（策略相同则占用度量相同）是显然的：占用度量由 \(\nu_0\)、\(P\)、\(\pi\) 唯一决定，\(\pi\) 相同则轨迹的联合分布相同，逐项的 \(P(s_t = s, a_t = a)\) 也相同。

必要性（占用度量相同则策略相同）需要一点推导。由前面的关系 \(\rho^{\pi}(s, a) = \nu^{\pi}(s) \pi(a \mid s)\)，对动作求和得

\[\sum_{a' \in \mathcal{A}} \rho^{\pi}(s, a') = \nu^{\pi}(s) \sum_{a' \in \mathcal{A}} \pi(a' \mid s) = \nu^{\pi}(s)\]

代回原式，在 \(\nu^{\pi}(s) > 0\) 的状态上可以解出策略：

\[\pi(a \mid s) = \frac{\rho^{\pi}(s, a)}{\sum_{a' \in \mathcal{A}} \rho^{\pi}(s, a')}\]

也就是说，占用度量本身就编码了策略：把它在每个状态上按动作归一化，就还原出策略。因此 \(\rho^{\pi_1} = \rho^{\pi_2}\) 蕴含 \(\pi_1 = \pi_2\)，在所有被访问到的状态上成立。

这里有一个必须写明的限定：结论只在 \(\nu^{\pi}(s) > 0\) 的状态上成立。若某个状态的访问概率为零，占用度量在那里恒为零，无法反推出策略在该状态的取值——两个策略可以在永远访问不到的状态上任意不同而占用度量完全相同。这个限定并非无关紧要：它正是离线强化学习中「分布外状态」问题的形式化表述。另一个方向的结论同样重要：一个非负函数 \(\rho\) 是某个策略的占用度量，当且仅当它满足 Bellman 流约束（每个状态的流入等于流出）；这条刻画把「所有可实现的占用度量」描述成一个线性约束集合，本页不展开证明。

为什么这条结论是模仿学习的起点

模仿学习要解决的问题是：只有专家演示的轨迹数据、没有奖励函数，如何学出一个与专家一样好的策略。上面的结论给出了一条清晰的技术路径。

  • 「学生策略等于专家策略」等价于「学生的占用度量等于专家的占用度量」。这把一个关于函数的等式，换成了一个关于分布的等式。
  • 分布之间的差异可以用各种散度或距离来度量，而这些量都有成熟的估计方法。特别地，训练一个判别器去区分两个分布的样本，判别器的最优损失就是两个分布之间的一种散度——这正是生成对抗网络的机制。
  • 于是模仿学习被转化成一个对抗训练问题：判别器学着区分「专家轨迹的状态-动作对」与「学生轨迹的状态-动作对」，策略学着骗过判别器。判别器骗不动时，两个占用度量相同，由上面的定理，学生策略就等于专家策略。

这正是 GAIL 的做法，细节见模仿学习与 GAIL。与之对照，行为克隆（behavior cloning）只做单步的监督学习，不匹配占用度量，因此会出现误差累积——学生走到专家从未访问过的状态上时没有任何监督信号，偏差逐步放大。这个对比见模仿学习总览。

占用度量在另外两条线上也会出现：离线强化学习：CQL要处理的核心矛盾是「学到的策略的占用度量偏离了数据集的占用度量」；TRPO的性能差分引理也是在占用度量的语言下叙述的。

蒙特卡洛方法与算法流程

解析解需要显式知道 \(P\) 与 \(r\)。真实任务里这两者都拿不到，只能与环境交互。蒙特卡洛方法给出了最直接的替代方案：价值函数按定义是回报的期望，那就多采几条轨迹、把实际得到的回报平均一下。

从定义到估计

回到定义 \(V^{\pi}(s) = \mathbb{E}_{\pi}[G_t \mid s_t = s]\)。设采样了 \(N\) 条经过状态 \(s\) 的轨迹，第 \(i\) 条从 \(s\) 出发实际得到的回报为 \(G^{(i)}\)，则由大数定律，

\[\hat{V}(s) = \frac{1}{N} \sum_{i=1}^{N} G^{(i)} \ \xrightarrow[\ N \to \infty\ ]{} \ V^{\pi}(s)\]

这个估计是无偏的（每条 \(G^{(i)}\) 都是 \(G_t\) 的一次无偏采样），代价是方差大——回报是整条轨迹上所有随机性的累积，轨迹越长方差越大。这一条无偏但高方差的特性，与后续时序差分一章「有偏但低方差」的自举方法构成本领域最基本的一组权衡。

增量式更新的推导

直接存下所有回报再求平均，空间开销随样本数增长。用与上一章相同的代数变形（把第 \(N\) 项单独提出、其余凑成 \((N-1)\hat{V}_{N-1}\)）可得增量形式：

\[\hat{V}_{N}(s) = \hat{V}_{N-1}(s) + \frac{1}{N}\Big( G^{(N)} - \hat{V}_{N-1}(s) \Big)\]

括号里是「这次实测的回报」与「当前估计」之差，可看作误差信号；\(1/N\) 是步长。把 \(1/N\) 换成固定步长 \(\alpha\) 就得到常步长版本 \(\hat{V}(s) \leftarrow \hat{V}(s) + \alpha( G - \hat{V}(s))\)。二者的区别是：\(1/N\) 收敛到所有历史样本的算术平均，适合平稳问题；固定 \(\alpha\) 是指数移动平均，持续遗忘旧样本，适合环境或策略在变化的情形。后续所有值函数更新式都是这个形式，区别只在于把 \(G\) 换成什么目标——换成 \(r + \gamma V(s')\) 就是 TD(0)，换成 \(r + \gamma \max_{a'} Q(s', a')\) 就是 Q-learning。

一条轨迹里同一个状态可能出现多次，有两种处理：首次访问（first-visit）只用该状态第一次出现时的回报，估计无偏；每次访问（every-visit）每次出现都算一个样本，同一条轨迹内的样本相关因而有偏，但样本数趋于无穷时仍收敛到真值，实现更简单、样本利用率更高。本页代码用每次访问版本。

算法流程

下面把本页要实现的三件事写成统一的编号伪代码。

输入: MDP 五元组 (S, A, P, r, gamma), 策略 pi,
      采样回合数 M, 单回合最大步数 T_max

--- 流程 A: 解析解（需要已知模型）---
A1  边缘化: r_pi[s] <- sum_a pi(a|s) * r(s,a)
A2  边缘化: P_pi[s][s'] <- sum_a pi(a|s) * P(s'|s,a)
A3  解线性方程组 (I - gamma * P_pi) V = r_pi, I 为 n x n 单位阵, n = |S|
A4  输出 V

--- 流程 B: 蒙特卡洛估值（不需要模型，只需能采样）---
B1  初始化 V_hat[s] <- 0, N[s] <- 0, 对所有 s
B2  for episode = 1 .. M do
B3      从初始分布采样 s_0, 置 episode_data <- 空列表
B4      for t = 0 .. T_max - 1 do
B5          a <- 从 pi(.|s) 采样; r <- r(s, a); s_next <- 从 P(.|s,a) 采样
B7          把 (s, a, r, s_next) 追加进 episode_data; s <- s_next
B9      end for
B10     G <- 0
B11     for (s, a, r, s_next) in reversed(episode_data) do   # 从后往前累加
B12         G <- r + gamma * G                                # 用 G_t = r_t + gamma * G_{t+1}
B13         N[s] <- N[s] + 1
B14         V_hat[s] <- V_hat[s] + ( G - V_hat[s] ) / N[s]    # 增量式更新
B15     end for
B16 end for
B17 输出 V_hat

--- 流程 C: 占用度量估计 ---
C1  用流程 B 的 B2 至 B9 采样 M 条轨迹, 每条长度 T_max
C2  for t = 0 .. T_max - 1 do
C3      cnt <- 在第 t 步恰好取到 (s, a) 的轨迹条数
C4      rho_hat[s][a] <- rho_hat[s][a] + gamma^t * (cnt / M)
C5  end for
C6  rho_hat <- (1 - gamma) * rho_hat        # 归一化系数
C7  输出 rho_hat

四处实现要点：

  • A4 在代码里应当用线性方程组求解器而不是显式求逆再相乘，后者数值稳定性更差且计算量更大。本页代码为了与公式逐字对应仍写了求逆版本，并在讲解里注明替代写法。
  • B11 必须从后往前遍历。正向遍历需对每个时刻重新累加一遍尾部奖励，复杂度 \(O(T^{2})\)；反向遍历利用 \(G_t = r_t + \gamma G_{t+1}\) 一遍扫完，复杂度 \(O(T)\)。这是全篇最容易写错的地方。
  • B10 的 \(G\) 在每条轨迹开始前必须重置为 0，否则回报会跨回合累加。
  • C4 里 \(\gamma^{t}\) 的指数是该状态-动作对出现的时刻，不是轨迹编号。截断到 \(T_{\max}\) 会丢掉 \(\gamma^{T_{\max}}\) 量级的尾部，\(\gamma\) 接近 1 时必须把 \(T_{\max}\) 取得足够大。

代码实现

下面在一个 5 状态的小型 MDP 上把三件事都实现一遍：解析解、蒙特卡洛估值、占用度量估计。依赖只有 numpy，最后一段用 Gymnasium 与 PyTorch 把同样的方法搬到连续状态任务上。

第一段：定义 5 状态 MDP

import numpy as np

STATES = ["s1", "s2", "s3", "s4", "s5"]
S_IDX = {s: i for i, s in enumerate(STATES)}
GAMMA = 0.5                      # 折扣因子，取 0.5 便于手算核对

# P_sas[(s, a)] 是一个 dict：下一状态 -> 转移概率，对应 P(s' | s, a)
P_SAS: dict[tuple[str, str], dict[str, float]] = {
    ("s1", "保持s1"): {"s1": 1.0},
    ("s1", "前往s2"): {"s2": 1.0},
    ("s2", "前往s1"): {"s1": 1.0},
    ("s2", "前往s3"): {"s3": 1.0},
    ("s3", "前往s4"): {"s4": 1.0},
    ("s3", "前往s5"): {"s5": 1.0},
    ("s4", "前往s5"): {"s5": 1.0},
    ("s4", "概率前往"): {"s2": 0.2, "s3": 0.4, "s4": 0.4},   # 唯一的随机转移
    ("s5", "停留"): {"s5": 1.0},                              # 吸收态自环
}

# R_SA[(s, a)] 对应 r(s, a)
R_SA: dict[tuple[str, str], float] = {
    ("s1", "保持s1"): -1.0,
    ("s1", "前往s2"): 0.0,
    ("s2", "前往s1"): -1.0,
    ("s2", "前往s3"): -2.0,
    ("s3", "前往s4"): -2.0,
    ("s3", "前往s5"): 0.0,
    ("s4", "前往s5"): 10.0,
    ("s4", "概率前往"): 1.0,
    ("s5", "停留"): 0.0,
}

# 每个状态可用的动作列表
ACTIONS_OF: dict[str, list[str]] = {}
for (s, a) in P_SAS:
    ACTIONS_OF.setdefault(s, []).append(a)

# 均匀随机策略：每个状态在可用动作上等概率
POLICY_UNIFORM: dict[str, dict[str, float]] = {
    s: {a: 1.0 / len(acts) for a in acts} for s, acts in ACTIONS_OF.items()
}

for (s, a), probs in P_SAS.items():                 # 合法性自检：转移概率之和必须为 1
    assert abs(sum(probs.values()) - 1.0) < 1e-9, (s, a)

这段把 MDP 五元组逐项落成数据结构，与形式化定义一一对应：STATES 是 \(\mathcal{S}\)，ACTIONS_OF 给出每个状态的 \(\mathcal{A}\)，P_SAS 是 \(P(s' \mid s, a)\)，R_SA 是 \(r(s, a)\)，GAMMA 是 \(\gamma\)。

三处设计说明。第一，s5 被设计成吸收态：它只有一个动作「停留」，转移回自己且奖励为 0。好处有两个——\(V(s_5) = 0\) 自动成立；占用度量上所有状态-动作对的总和严格等于 1（轨迹若提前终止，总和会小于 1，归一化性质就不成立）。第二，s4 的「概率前往」是全图唯一的随机转移，它使这个例子不至于退化成确定性问题，蒙特卡洛估值才会真正体现出方差。第三，GAMMA 取 0.5 而非常用的 0.99，是因为 0.5 衰减很快，\(\gamma^{20}\) 已在百万分之一量级，截断到 20 步的偏差可忽略，方便验证两种方法是否一致。

容易写错的地方：ACTIONS_OF 是从 P_SAS 的键遍历出来的；若另外手动维护一份动作列表而与 P_SAS 不同步，某些状态的策略概率就不会归一，后面所有结果都会错。末尾那句 assert 就是为了拦住这类错误。

第二段：边缘化并求解析解

def marginalize(policy: dict[str, dict[str, float]]) -> tuple[np.ndarray, np.ndarray]:
    """把 MDP 加策略边缘化成 MRP。

    返回 (P_pi, r_pi)：
      P_pi[i][j] = sum_a pi(a|s_i) * P(s_j | s_i, a)
      r_pi[i]    = sum_a pi(a|s_i) * r(s_i, a)
    """
    n = len(STATES)
    P_pi = np.zeros((n, n))
    r_pi = np.zeros(n)
    for s, action_probs in policy.items():
        i = S_IDX[s]
        for a, pa in action_probs.items():
            r_pi[i] += pa * R_SA[(s, a)]                    # 奖励的边缘化
            for s_next, p in P_SAS[(s, a)].items():
                P_pi[i][S_IDX[s_next]] += pa * p            # 转移的边缘化
    return P_pi, r_pi


def analytic_value(P_pi: np.ndarray, r_pi: np.ndarray, gamma: float) -> np.ndarray:
    """MRP 的解析解 V = (I - gamma * P)^(-1) R。"""
    n = P_pi.shape[0]
    I = np.eye(n)
    # 逐字对应公式的写法（数值上不推荐）：
    V = np.linalg.inv(I - gamma * P_pi) @ r_pi
    # 生产环境应当写成解方程而非求逆，二者数学等价但下面这行更稳更快：
    # V = np.linalg.solve(I - gamma * P_pi, r_pi)
    return V


P_pi, r_pi = marginalize(POLICY_UNIFORM)
V_analytic = analytic_value(P_pi, r_pi, GAMMA)

print("边缘化后每行之和（应全为 1）:", P_pi.sum(axis=1).round(6))
print("解析解 V:")
for s in STATES:
    print("  V(%s) = %+.6f" % (s, V_analytic[S_IDX[s]]))

marginalize 逐字实现了前文的两条边缘化公式。注意 P_pi[i][S_IDX[s_next]] += pa * p 用的是累加而不是赋值：不同动作可能转移到同一个下一状态（本例中 s4 的两个动作都可能到 s2 之外的状态），必须把这些路径的概率加起来。写成赋值是这段代码最典型的错误，且不会报错，只会让结果悄悄偏小。

analytic_value 逐字实现了 \(V = (I - \gamma P)^{-1} R\)。这里刻意保留显式求逆以便与公式对照，同时把推荐写法作为注释附在下面：np.linalg.solve 数值上更稳定且计算量更小。前文分析过 \(I - \gamma P\) 一定可逆（\(\lVert \gamma P \rVert_{\infty} = \gamma < 1\)），因此求逆不会抛异常，但 \(\gamma\) 越接近 1 条件数越差，结果的有效位数会下降。自检那行 P_pi.sum(axis=1) 值得保留：边缘化后每一行仍应是概率分布，和为 1；若不为 1，问题一定出在策略概率没归一或转移概率写错。

第三段：轨迹采样与蒙特卡洛估值

Transition = tuple[str, str, float, str]


def sample_episode(policy: dict[str, dict[str, float]], start: str,
                   max_steps: int, rng: np.random.Generator) -> list[Transition]:
    """按策略采样一条长度为 max_steps 的轨迹，返回 (s, a, r, s_next) 列表。"""
    episode: list[Transition] = []
    s = start
    for _ in range(max_steps):
        acts = list(policy[s].keys())
        probs = np.array([policy[s][a] for a in acts])
        a = acts[rng.choice(len(acts), p=probs)]          # 按 pi(.|s) 采样动作
        r = R_SA[(s, a)]
        next_states = list(P_SAS[(s, a)].keys())
        next_probs = np.array([P_SAS[(s, a)][x] for x in next_states])
        s_next = next_states[rng.choice(len(next_states), p=next_probs)]  # 按 P(.|s,a) 采样
        episode.append((s, a, r, s_next))
        s = s_next
    return episode


def monte_carlo_value(policy, num_episodes: int, max_steps: int,
                      gamma: float, seed: int = 0) -> np.ndarray:
    """每次访问型蒙特卡洛估值，增量式更新。"""
    rng = np.random.default_rng(seed)
    V_hat = np.zeros(len(STATES))
    counts = np.zeros(len(STATES))
    start_states = ["s1", "s2", "s3", "s4"]      # 均匀地从各非吸收态出发
    for ep in range(num_episodes):
        start = start_states[ep % len(start_states)]
        episode = sample_episode(policy, start, max_steps, rng)
        G = 0.0                                   # 每条轨迹开始前必须清零
        for (s, a, r, s_next) in reversed(episode):   # 从后往前，O(T) 而非 O(T^2)
            G = r + gamma * G                     # 直接用 G_t = r_t + gamma * G_{t+1}
            i = S_IDX[s]
            counts[i] += 1
            V_hat[i] += (G - V_hat[i]) / counts[i]    # 增量式经验平均
    return V_hat


V_mc = monte_carlo_value(POLICY_UNIFORM, num_episodes=20000, max_steps=20,
                         gamma=GAMMA, seed=0)
print("解析解与蒙特卡洛估值对比:")
for s in STATES:
    i = S_IDX[s]
    print("  %s  解析 %+.6f   MC %+.6f   差 %+.6f"
          % (s, V_analytic[i], V_mc[i], V_mc[i] - V_analytic[i]))

sample_episode 实现流程 B 的 B4 至 B9：先按 \(\pi(\cdot \mid s)\) 采样动作，再按 \(P(\cdot \mid s, a)\) 采样下一状态。两次采样必须分开做，因为这是两个不同的分布；把它们合成一步是常见的概念错误。

monte_carlo_value 是本页最需要仔细看的一段。三处对应关系：G = r + gamma * G 逐字对应推导第一步的 \(G_t = r_t + \gamma G_{t+1}\)；reversed(episode) 保证在计算 \(G_t\) 时 \(G_{t+1}\) 已经算好；V_hat[i] += (G - V_hat[i]) / counts[i] 逐字对应增量式更新公式，分母是更新后的计数。

四处容易写错。其一，忘记 reversed 而正向遍历，此时 G 累加出来的是前缀和而非后缀和，结果完全错误且不会报错。其二，G 没有在每条轨迹开始前清零，回报会跨回合累加，估值会发散。其三，counts[i] += 1 必须写在更新之前，否则第一次更新会除零。其四，起始状态的选择会影响哪些状态拿到足够样本——这里用 ep % len(start_states) 轮流从四个非吸收态出发，是为了让每个状态都被充分访问；如果只从 s1 出发，s4 的样本会少很多，它的估值方差明显更大。

由于 s5 是吸收态且奖励恒为 0，它的 V_hat 会稳定在 0，与解析解一致，可以当作一个免费的正确性检查。

第四段：占用度量估计与恒等式校验

def occupancy_measure(policy, num_episodes: int, max_steps: int,
                      gamma: float, seed: int = 0) -> dict[tuple[str, str], float]:
    """估计 rho^pi(s, a) = (1 - gamma) * sum_t gamma^t * P(s_t = s, a_t = a)。"""
    rng = np.random.default_rng(seed)
    # counts_at_t[t][(s, a)]：第 t 步恰好取到 (s, a) 的轨迹条数
    counts_at_t: list[dict[tuple[str, str], int]] = [dict() for _ in range(max_steps)]
    start_states = ["s1", "s2", "s3", "s4"]
    for ep in range(num_episodes):
        start = start_states[ep % len(start_states)]
        episode = sample_episode(policy, start, max_steps, rng)
        for t, (s, a, r, s_next) in enumerate(episode):
            counts_at_t[t][(s, a)] = counts_at_t[t].get((s, a), 0) + 1

    rho: dict[tuple[str, str], float] = {}
    for t in range(max_steps):
        discount = gamma ** t                       # 注意指数是时刻 t，不是轨迹编号
        for key, cnt in counts_at_t[t].items():
            rho[key] = rho.get(key, 0.0) + discount * (cnt / num_episodes)
    for key in rho:
        rho[key] *= (1.0 - gamma)                   # 归一化系数
    return rho


rho_hat = occupancy_measure(POLICY_UNIFORM, num_episodes=20000, max_steps=20,
                            gamma=GAMMA, seed=1)

print("占用度量总和（理论值 1，截断会略小）: %.6f" % sum(rho_hat.values()))

# 校验一：由占用度量反推策略，应还原出均匀策略
print("由 rho 反推的策略:")
for s in STATES:
    denom = sum(v for (ss, aa), v in rho_hat.items() if ss == s)
    if denom <= 0:
        continue
    recovered = {aa: v / denom for (ss, aa), v in rho_hat.items() if ss == s}
    print("  %s -> %s" % (s, {k: round(v, 4) for k, v in recovered.items()}))

# 校验二：J(pi) = 1/(1-gamma) * sum_{s,a} rho(s,a) * r(s,a)
J_from_rho = sum(rho_hat[(s, a)] * R_SA[(s, a)] for (s, a) in rho_hat) / (1.0 - GAMMA)
print("由占用度量算出的 J(pi) = %+.6f" % J_from_rho)

这段逐字实现了流程 C，并附带两个校验，它们分别对应前文的两条理论结论。

校验一用的是必要性证明里那条反推公式 \(\pi(a \mid s) = \rho^{\pi}(s, a) / \sum_{a'} \rho^{\pi}(s, a')\)。因为本例的策略是均匀的，每个状态有两个动作（s5 只有一个），反推结果应当接近 0.5（s5 接近 1.0）。这个校验直接验证了「占用度量编码了策略」这一结论，是本页最值得亲手跑一遍的部分。

校验二验证 \(J(\pi) = \frac{1}{1-\gamma}\sum_{s,a}\rho^{\pi}(s,a) r(s,a)\)。它算出的结果应当与「按初始状态分布对解析解 \(V\) 加权平均」一致，二者是同一个目标函数的两种算法。把两个数字打印出来对比，是检查占用度量实现是否正确的最好办法。

两处容易写错：discount = gamma ** t 的指数必须是时刻 \(t\)，写成轨迹编号或常数是最常见的错误；(1.0 - gamma) 只能乘一次且必须在对所有时刻求和之后乘，提前乘进每一项虽然等价，但容易在后续修改中漏乘或重复乘。

关于总和：理论上 \(\sum_{s,a}\rho^{\pi}(s,a) = 1\)，但代码把轨迹截断到 max_steps 步，丢掉的尾部总权重是 \(\gamma^{T_{\max}}\)。本例中这项在百万分之一量级，因此打印出的总和应当非常接近 1。若把 \(\gamma\) 改成 0.99 而不同步增大 \(T_{\max}\)，总和会明显小于 1——这不是实现错误，而是截断偏差，是这个方法的固有代价。

第五段：把同样的方法搬到 Gymnasium 上

上面四段的状态是有限的，价值函数是一个数组。真实任务的状态是连续的，只能用函数逼近。这一段用 Gymnasium 的 CartPole-v1 与一个小型 PyTorch 网络演示同一套蒙特卡洛思路。

import gymnasium as gym
import torch
import torch.nn as nn


def mc_value_cartpole(num_episodes: int = 500, gamma: float = 0.98,
                      lr: float = 1e-3, seed: int = 0) -> nn.Module:
    """用蒙特卡洛回报作为回归目标，训练随机策略下的 V(s)。"""
    env = gym.make("CartPole-v1")
    torch.manual_seed(seed)
    # 输出层不接激活：V 是折扣回报的期望，量级无上界，套饱和激活会人为设上限
    value_net = nn.Sequential(
        nn.Linear(env.observation_space.shape[0], 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 1),
    )
    optimizer = torch.optim.Adam(value_net.parameters(), lr=lr)

    for ep in range(num_episodes):
        obs, _ = env.reset(seed=seed + ep)
        states, rewards = [], []
        for _ in range(500):
            action = env.action_space.sample()      # 固定的随机策略，评估的就是它
            next_obs, reward, terminated, truncated, _ = env.step(action)
            states.append(obs)
            rewards.append(float(reward))
            obs = next_obs
            if terminated or truncated:
                break

        returns, G = [], 0.0                        # 反向累加，与第三段同一套逻辑
        for r in reversed(rewards):
            G = r + gamma * G
            returns.append(G)
        returns.reverse()                           # 让 returns[i] 与 states[i] 对齐

        s_batch = torch.tensor(np.array(states), dtype=torch.float32)
        mc_target = torch.tensor(returns, dtype=torch.float32).detach()  # 目标不带梯度
        loss = nn.functional.mse_loss(value_net(s_batch).squeeze(-1), mc_target)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    env.close()
    return value_net


# value_net = mc_value_cartpole()

这段与第三段是同一个算法，只有两处变化：估值从「数组的一个格子」变成「网络的一次前向」，更新从「增量式平均」变成「对回归目标做梯度下降」。mc_target 就是蒙特卡洛回报 \(G\)，它无偏但方差大，所以训练曲线会明显抖动，这正是后续章节引入自举来降方差的动机。

三处容易写错：mc_target 必须 detach，否则梯度会流进目标本身；reversed 之后必须 reverse() 回来，忘记这一步会把回报序列整个倒过来，损失照样能降但学到的东西完全错误；这里评估的是随机策略，得到的是 \(V^{\pi}\) 而非 \(V^{*}\)，要得到后者须同时改进策略，那是动态规划之后各章的内容。

实验与结果分析

实验设定

  • 环境：本页定义的 5 状态 MDP，折扣因子 0.5，均匀随机策略。
  • 对比对象：解析解 \(V = (I - \gamma P)^{-1} R\) 与蒙特卡洛估值。
  • 采样规模：20000 条轨迹，每条截断到 20 步，起始状态在四个非吸收态之间轮换。
  • 附加实验：CartPole-v1 上的蒙特卡洛价值网络，折扣因子 0.98。

观察到的现象与解释

两种方法的一致性。蒙特卡洛估值应当收敛到解析解，差值随采样量增加而缩小。判断是否收敛的方法不是看某一次的差值，而是看差值随轨迹数增加的下降趋势：蒙特卡洛估计的标准误差按 \(1/\sqrt{N}\) 下降，因此把轨迹数扩大 100 倍，误差大约缩小到十分之一。若增加样本后差值不再下降而是停在某个水平，说明存在系统性偏差，最常见的原因是轨迹截断太短或反向累加写错。

各状态的收敛速度不同。s5 是吸收态且奖励恒为 0，估值一步到位。s1 与 s2 的转移是确定性的，回报的方差只来自策略的随机性，收敛较快。s4 含唯一的随机转移（「概率前往」以 0.4 的概率停在原地），回报的方差最大，收敛最慢，需要的样本数明显多于其它状态。这条现象是通用的：状态的下游随机性越强，蒙特卡洛估值的方差越大。

折扣因子对截断偏差的影响。把 \(\gamma\) 从 0.5 提到接近 1 而不同步增大 max_steps 时，会观察到两件事同时发生：占用度量的总和明显小于 1，以及蒙特卡洛估值系统性地偏低。二者同源——都是因为被丢弃的尾部权重 \(\gamma^{T_{\max}}\) 不再可忽略。这不是实现缺陷，而是有限长度采样的固有代价，正确的应对是按 \(\gamma\) 调整截断长度，经验口径是让 \(T_{\max}\) 达到有效视野 \(1/(1-\gamma)\) 的若干倍。

占用度量的两个校验都应通过。反推出的策略在每个双动作状态上接近 0.5，在 s5 上接近 1.0；由占用度量算出的 \(J(\pi)\) 与按初始状态分布加权的解析解一致。这两项若有一项对不上，问题几乎一定出在折扣指数用错了时刻或归一化系数漏乘。

CartPole 上的现象不同。那里的损失曲线抖动明显且不会单调下降，原因是每个回合只做一次梯度更新，而蒙特卡洛回报的方差很大。这与表格情形形成对照：表格法的增量式平均自带 \(1/N\) 的步长衰减，天然收敛；函数逼近加固定学习率则没有这个保证。这个差别是理解「为什么深度强化学习比表格强化学习难得多」的一个入口。

最后一条方法论提醒：只跑几百条轨迹就发现结果与解析解差得不多，不足以说明样本量够了——小样本下的接近往往是运气，换一个种子差值可能大出数倍。正确做法是在多个种子上重复，观察差值的分布而非单个数字。

折扣因子 gamma

  • 本页取值：0.5。连续控制任务的常用区间是 0.95–0.99。
  • 为什么这么配：\(\gamma\) 决定有效视野，粗略口径是 \(1/(1-\gamma)\) 步。本页取 0.5 是教学考虑：有效视野只有两步，20 步截断的尾部权重是百万分之一量级，可以放心地把「解析解与采样结果是否一致」当作实现正确性的判据，不受截断偏差干扰。真实任务不会这么取。
  • 配错了会怎样：偏小时有效视野之外的奖励几乎不参与优化，需要中长程规划的任务退化成贪心行为。偏大时不仅收敛慢（压缩映射的收缩系数就是 \(\gamma\)，越接近 1 迭代轮数越多），\(I - \gamma P\) 的条件数也变差，解析解的有效位数下降；同时截断偏差急剧变大，本页两项校验都会失真。

轨迹截断长度

  • 本页取值：20 步，配合 \(\gamma = 0.5\)。
  • 为什么这么配：截断丢掉的尾部总权重是 \(\gamma^{T_{\max}}\)。要让这项可忽略，\(T_{\max}\) 应当是有效视野 \(1/(1-\gamma)\) 的若干倍。本页 \(1/(1-0.5) = 2\)，取 20 是十倍余量。
  • 配错了会怎样：太短时占用度量的总和明显小于 1，价值估计系统性偏低，且偏差不随样本量增加而消失——这是偏差而非方差，加样本没有用。太长时每条轨迹的计算量线性上升，而超出有效视野的部分对结果几乎没有贡献，纯属浪费。

采样轨迹数

  • 本页取值：20000 条。
  • 为什么这么配：蒙特卡洛估计的标准误差按 \(1/\sqrt{N}\) 下降。要把误差压到小数点后两三位，样本数需要到万的量级。这个数应当由「希望多少位有效数字」倒推，而不是随手取。
  • 配错了会怎样：太少时结果的随机波动可能大于要检验的差异，容易把运气当成正确性。太多时运行时间线性增长，而精度只按平方根提升，收益递减明显。

起始状态分布

  • 本页取值：在四个非吸收态之间轮换。
  • 为什么这么配：蒙特卡洛只能估计被访问到的状态的价值。若全部从 s1 出发，下游状态拿到的样本远少于上游，估值方差差异很大；轮换起点等价于人为构造一个覆盖全状态的初始分布，让每个状态都拿到足够样本。这个做法在理论上叫 exploring starts。
  • 配错了会怎样：只从单一状态出发时，某些状态可能样本极少甚至从未被访问，其估值要么方差巨大要么保持在初值 0。注意这会让「与解析解对比」这个校验失去意义——解析解给出所有状态的值，而蒙特卡洛只在被访问的状态上有意义。这个覆盖问题在离线强化学习里以更严重的形式出现。

更新步长

  • 本页取值：\(1/N\)，即增量式经验平均。
  • 为什么这么配：\(1/N\) 使估计恰好等于所有历史样本的算术平均，在策略与环境都固定的本页设定下是无偏且方差最小的选择，且不需要调参。
  • 配错了会怎样：换成固定步长 \(\alpha\) 会得到指数移动平均，它持续遗忘旧样本，因此不会收敛到真值而是在真值附近波动，波动幅度正比于 \(\alpha\)。这在本页的静态评估任务里是纯粹的损失；但在策略不断变化的场景（后续所有控制算法）里恰恰是必要的，因为旧样本对应的是旧策略，本来就该被遗忘。选 \(1/N\) 还是固定 \(\alpha\)，取决于被估计的对象是否平稳。

小结与下一章的衔接

本章确立了四件事。

  • 马尔可夫性质是全部理论的前提。它把「策略是整段历史的函数」压缩成「策略是当前状态的函数」，价值函数与贝尔曼方程才得以存在。工程上补齐它的手段（堆帧、循环网络、显式加入速度）不是技巧，而是必需。
  • 贝尔曼方程把无穷长轨迹的期望改写成一步递推。推导的关键是用全期望公式逐层条件化，再用马尔可夫性把条件从整段历史缩到下一状态。这一步是后续每一个算法的共同地基。
  • 期望方程与最优方程的分野在于线性与否。前者有解析解，后者只能迭代；而两者的算子都是 \(\gamma\)-压缩映射，这保证了迭代一定收敛。
  • 占用度量把策略翻译成分布。由此「两个策略相同」等价于「两个分布相同」，模仿学习才能转化成分布匹配问题。

本章遗留的问题有三个，分别由后面三章解决。

  • 解析解的 \(O(n^{3})\) 复杂度。状态数稍大就不可行。解法是迭代：从任意初值反复作用贝尔曼算子，每轮 \(O(n^{2})\)，靠压缩性保证收敛。这是动态规划一章的策略迭代与值迭代。
  • 必须已知 \(P\) 与 \(r\)。本章的蒙特卡洛方法迈出了第一步，但它必须等一整个回合结束才能更新，且方差很大。把「等回合结束拿真实回报」换成「走一步就用自己的估计来自举」，就得到方差小得多的更新方式，这是时序差分：Sarsa 与 Q-learning一章的内容。
  • 状态必须可枚举。表格法在连续状态上完全失效，需要用神经网络逼近价值函数，随之而来的是训练不稳定的一系列新问题，见 DQN。

本章的占用度量会在三处再次出现：模仿学习与 GAIL用它把模仿转化成分布匹配；TRPO用它叙述性能差分引理；离线强化学习：CQL要处理的正是学到的策略与数据集之间的占用度量偏移。整条主线的脉络见强化学习总览。

知识库 · 机器人模仿学习与 VLA · Behavior Cloning

Behavior Cloning（行为克隆，BC）把专家示范中的观测—动作对变成监督学习问题：它学习“专家在这个上下文会做什么”，却不会自动优化学习器闭环运行时自己访问到的状态分布。因此，低 validation loss 与可靠控制之间仍隔着数据契约、分布漂移、闭环评测和安全门禁。

  • 写出 BC 的样本、策略与经验风险目标，并区分状态、观测和历史。
  • 解释专家分布与学习器分布为何分叉，以及误差如何沿时间复合。
  • 用可证伪实验区分七类常见失败，并选择加数据、改表示或进入交互式模仿。
范围：本页讨论从专家动作监督策略的 BC，不把它等同于全部 Learning from Demonstration、逆强化学习、GAIL 或仅观测模仿；离线训练也不等于可以跳过闭环验证。

一句话定义与使用边界

BC 从观测或有限历史 h_t 预测专家动作 a_t^*，输出策略 πθ(a_t | h_t)。连续动作可做回归，离散动作可做分类，多峰动作可做条件密度估计；无论模型是哪一种，策略输出都会通过环境改变下一时刻输入。

输入

当前观测或有限历史，可包含图像、本体状态、力觉、语言条件与过去动作。

边界：真实环境状态未必可直接观测。

监督与输出

监督是时间对齐的专家动作、动作类别或动作片段；输出是条件策略。

边界：标签必须绑定坐标系、单位与控制模式。

成立条件

示范覆盖部署状态，观测足以决定动作，训练和执行接口一致。

核心风险：普通监督学习的 i.i.d. 直觉不直接适用于闭环。

先做 BC 的合理场景：任务时域短、初始状态受控、环境重复性高、动作模式较单一，且能在低风险条件下充分 rollout。这里的“合理”是工程筛选，不是成功保证。

问题定义、符号与监督目标

有限时域轨迹写作：

\[\tau=(s_0,o_0,a_0,s_1,o_1,a_1,\ldots,s_T), \qquad o_t\sim\mathcal{O}(\cdot\mid s_t), \qquad a_t^*\sim\pi^*(\cdot\mid h_t).\]
符号 含义 常见误读
s_t 环境真实状态 训练与部署时未必可见，不应与图像观测混称。
o_t 传感器可见信息 同一观测可能对应不同任务阶段或隐藏状态。
h_t 策略实际使用的上下文 可以是当前观测，也可以包含历史和过去动作。
a_t^* 专家动作标签 数值之外还需坐标系、单位、模式与时间语义。
π* 产生示范的专家策略或操作过程 不同操作者与质量层级不能默认同分布。
πθ 参数为 θ 的学习器策略 离线拟合好不代表它诱导的闭环分布安全。

给定 N 条示范轨迹，统一的经验风险目标可写成：

\[\hat{\theta}=\arg\min_\theta \frac{1}{N}\sum_{i=1}^{N}\sum_{t=0}^{T_i-1} w_{i,t}\,\ell\!\left(\pi_\theta(\cdot\mid h_{i,t}),a^*_{i,t}\right).\]

其中 w_{i,t} 可表示 padding mask、有效长度或样本重权。按帧求和只是训练实现；相邻帧不是统计独立样本，训练、验证和测试仍应按 episode 或更高层互斥单位切分。

动作输出 常见监督目标 不能忽略的边界
连续单点动作 L1、L2、Huber 单峰点估计可能把多种合法动作平均成不可执行动作。
离散动作 交叉熵 类别边界、量化和离散化误差来自动作定义。
条件分布 负对数似然 似然依赖分布族，也不能替代闭环稳定性。
动作块 序列回归或生成目标 预测时域、执行时域和重规划频率必须分开报告。

动作块、CVAE、Diffusion 和 Flow 的机制在 ACT 专题与生成式动作页面展开；本页只保留选择出口。

数据契约：训练之前先确认标签含义

字段 必须记录 缺失或错误的影响
episode / step 唯一 episode ID、单调 step、终止原因 历史窗口跨轨迹，或相邻帧泄漏到不同划分。
observation 相机顺序、颜色空间、尺寸、内外参、本体与力觉字段 训练和部署预处理不一致。
action joint / Cartesian、absolute / delta、frame、unit、control mode 数值看似正常，物理语义却错误。
time 观测、命令生成、下发和执行反馈时间戳 策略学到过去或未来错位动作。
robot / config 本体、工具、控制器、标定与软件版本 混合不可互换的动力学与接口。
operator / task 操作者、任务、目标、场景与语言条件 数据偏置无法分层诊断。
outcome success、partial、failure、abort、intervention 只能拟合动作，无法分析轨迹质量与恢复行为。
  • 动作时间戳究竟代表命令生成、下发还是实际执行，必须只有一种约定；同一数组索引不等于同一物理时刻。
  • 感知、网络、推理和执行延迟要进入对齐检查，先画观测—命令—反馈时间线，再决定配对偏移。
  • train / validation / offline test 按 episode 划分是最低要求；评估泛化时还要按场景、对象、操作者、机器人或任务条件建立互斥层。
  • normalization 统计只能从训练划分计算，并与数据版本、checkpoint、动作 schema 和代码 revision 一起留下 hash。
  • 成功、失败、纠正和恢复轨迹应分层标记，不能不加说明地只保留成功帧。
工程建议：先做“单位、方向、坐标系、absolute / delta、控制模式、时间戳”六项旁路回放。动作 ABI 错误不会因为模型更大而消失。

为什么离线准确、闭环仍会失败

训练样本近似来自专家策略与环境共同诱导的时间相关分布：

\[(s_t,o_t)\sim d_{\pi^*}^{\,t}.\]

部署样本则来自学习器策略诱导的分布：

\[(s_t,o_t)\sim d_{\pi_\theta}^{\,t}.\]

BC 优化专家分布下的监督风险，却运行在学习器分布下。小动作误差改变下一状态，下一观测随之偏移；越偏离示范覆盖，预测就越不可靠。d_{π*} 与 d_{πθ} 不是两份静态数据集，而是由策略、环境动力学和时间共同生成的分布。

flowchart LR
  D[专家示范数据] --> R[监督风险最小化]
  R --> P[学习器策略 πθ]
  P --> A[执行动作]
  A --> E[环境状态转移]
  E --> O[下一观测]
  O --> P
  D -. 主要覆盖 .-> X[专家诱导分布 dπ*]
  O -. 实际产生 .-> Y[学习器诱导分布 dπθ]

图 1｜数据—训练—部署闭环。 实线是部署反馈环，虚线标出训练数据和实际访问状态的来源差异；监督目标没有直接约束整条闭环路径。

flowchart TB
  S[共同起点] --> EX[专家动作]
  S --> LE[学习器近似动作]
  EX --> DX[仍处于示范密集区域]
  LE --> D1[小状态偏移]
  D1 --> D2[训练覆盖变稀]
  D2 --> D3[后续误差更可能增大]
  D3 --> D1

图 2｜专家分布与学习器分布分叉。 分叉不是由单一“坏帧”定义；应通过受控扰动、数据密度和闭环结果共同检查。

优先做四个反事实测试：从专家轨迹正常状态启动；加入受控位置或姿态扰动；保持任务语义但替换背景或光照；遮蔽或延迟历史动作。同步记录扰动幅度、与训练集最近邻的距离、恢复时间和安全终止，避免只凭肉眼断言“分布外”。

复合误差的量级直觉与边界

在有限时域 T、单步代价有界，并把专家分布下的单步错误概率记为 ε 时，第 t 步之前至少发生一次错误的概率可用 union bound 粗略上界为 tε。若首次错误后，最坏情况下每个剩余步骤都可能产生额外单位代价，则有量级直觉：

\[J(\pi_\theta)-J(\pi^*) \;\lesssim\; \sum_{t=1}^{T}t\varepsilon \;=\;O(\varepsilon T^2).\]
  1. t = 0：学习器从示范覆盖的初始状态出发。
  2. t = k：首次错误改变后续状态；这里只标记可能的分叉，不断言必然失败。
  3. k < t ≤ T：最坏情况把剩余时域计入额外代价，逐步求和形成二次量级。

图 3｜复合误差时间轴。 它表达上界推导中的最坏情况计数，不是机器人成功率曲线。

原论文事实与迁移边界：这里依据 Ross & Bagnell（2010）的序列决策归约解释非 i.i.d. 误差复合。真实机器人不必严格遵循该公式；环境恢复性、闭环稳定性、动作连续性和安全控制器都会改变结果。

该式不能推出“任一错误都会毁掉剩余轨迹”，也不能把归一化 L1/L2 直接当作 ε 再换算成功率。把 ε 减小仍会线性改善该上界；问题只是长时域可能继续放大残余错误。DAgger 的方向是在学习器访问到的状态上请求专家标签，算法与保证留给 下一专题。

七类常见失效与证伪实验

先从“现场信号”提出多个候选原因，再用区分性实验排除；不要看到抖动就直接归因于多峰，或看到失控就一律称为分布漂移。

训练、评估与发布的最小闭环

flowchart LR
  A[冻结数据与 schema] --> B[episode 级互斥划分]
  B --> C[训练与离线评估]
  C --> D[低风险闭环测试]
  D --> E{门禁通过?}
  E -- 否 --> F[定位第一分叉并修正]
  F --> A
  E -- 是 --> G[进入更高风险验证]
离线指标

连续动作按维度和物理单位报告 MAE / Huber；概率输出报告 NLL、交叉熵和校准。

按任务阶段、速度、接触状态和数据密度分桶，不只给归一化总 loss。

闭环指标

任务成功与安全成功分开；记录部分完成、失败时刻、恢复、干预、碰撞和终止原因。

绑定 trial、seed、checkpoint、控制频率、安全层和 p50 / p95 延迟。

发布血缘

关联数据版本、划分清单、normalization hash、动作 schema、代码 revision 和模型制品。

validation loss 不能替代 rollout，也不能替代独立安全控制器。

BC checkpoint 进入更高风险测试前，至少通过五项门禁：schema 和动作契约可解析；episode 级划分无交叉；正常起点与受控扰动可重复；停止、终止与安全回退通过；离线和闭环指标都有完整记录。真机还需要独立安全层和人工接管路径。

证据标签：工程建议。上述划分、日志与门禁是本站的可审计工程建议，不是 Ross 2010 的原论文流程，也不能替代具体机器人平台的风险评估。

何时 BC 足够，何时升级路线

继续使用 BC

任务短、初始状态受控、观测近似 Markov、动作模式单一，示范含合理扰动与恢复，低层控制稳定。

进入 DAgger / HG

失败集中在策略自己诱导的偏离状态，并且可以安全查询专家、接管或采集恢复轨迹。

进入 ACT / 生成式动作

覆盖尚可，但主要困难是长时序累积、单步抖动、动作块连贯性或条件多峰。

进入 VLA 公共基础

任务依赖语言、开放词汇、多任务共享或跨本体迁移，并已准备处理更复杂的动作接口、时延、评测与安全。

这些路线并不互斥：交互式数据聚合解决覆盖，动作块改变时间表示，VLA 扩展条件与共享范围。先用失效证据定位问题，再决定组合，不把模型规模当成闭环可靠性的替代品。

证据分层：论文明确给出的设定、算法和结论标为“原论文事实”；迁移到机器人视觉控制的解释标为“方法迁移”；数据、日志和门禁标为“工程建议”；针对某台机器的失败原因在实验前只能标为“待验证假设”。

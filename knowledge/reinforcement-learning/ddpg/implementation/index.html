本页把前四页的公式落实为一份单文件 PyTorch 教学实现。环境选用 Gymnasium Pendulum-v1，因为它动作连续、依赖轻、便于先检查算法是否有基本生命迹象。 代码目标是暴露所有关键路径，而不是用框架封装隐藏更新细节。为避免伪装成通用框架， 本实现明确只接受一维 Box 观测和一维 Box 动作；图像、字典观测、 多轴动作形状和向量环境需要额外的 flatten/unflatten 与终止处理。

代码定位。这份代码可作为正确性模板，但不宣称复现 DDPG 原论文的 MuJoCo 结果。 原论文使用不同环境、网络、归一化、噪声与训练预算。复制运行前应安装与项目兼容的 PyTorch、Gymnasium；本专题没有为网页构建安装训练依赖，也没有把训练结果写成事实。

一、实现与公式的对应表

数学对象 代码对象 核心不变量
\(\mu_\theta(s)\) Actor.forward 输出逐维落在环境边界
\(Q_\phi(s,a)\) Critic.forward 每个样本一个标量
\(\mathcal D\) ReplayBuffer 存实际执行动作和 terminated
Bellman target DDPGAgent.update 的 no-grad 块 目标 Actor/Critic 不反传
\(L_Q\) critic_loss 当前 Q 对固定 target 回归
\(L_\mu\) actor_loss 动作由当前 Actor 生成
Polyak soft_update target 向 online 移动比例 \(\tau\)
行为策略 DDPGAgent.act(..., explore=True) 逐维缩放 Gaussian 后再 clip
确定性评估 evaluate 独立环境、无噪声、不训练

二、完整单文件实现

from __future__ import annotations

import random
from copy import deepcopy
from dataclasses import dataclass

import gymnasium as gym
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F


@dataclass
class Config:
    env_id: str = "Pendulum-v1"
    seed: int = 7
    total_steps: int = 120_000
    buffer_size: int = 200_000
    batch_size: int = 256
    gamma: float = 0.99
    tau: float = 0.005
    actor_lr: float = 3e-4
    critic_lr: float = 1e-3
    start_steps: int = 5_000
    update_after: int = 1_000
    update_every: int = 50
    exploration_std: float = 0.1
    eval_every: int = 10_000
    eval_episodes: int = 10
    hidden_dim: int = 256


def validate_config(config: Config) -> None:
    if not 0.0 <= config.gamma < 1.0:
        raise ValueError("gamma must be in [0, 1) for this discounted task")
    if not 0.0 < config.tau <= 1.0:
        raise ValueError("tau must be in (0, 1]")
    if not 0 < config.batch_size <= config.buffer_size:
        raise ValueError("require 0 < batch_size <= buffer_size")
    if config.total_steps <= 0:
        raise ValueError("total_steps must be positive")
    if config.start_steps < 0 or config.update_after < 0:
        raise ValueError("start_steps and update_after must be non-negative")
    if config.update_every <= 0 or config.eval_every <= 0:
        raise ValueError("update_every and eval_every must be positive")
    if config.eval_episodes <= 0:
        raise ValueError("eval_episodes must be positive")
    if config.exploration_std < 0.0:
        raise ValueError("exploration_std must be non-negative")


def seed_everything(seed: int) -> None:
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)


class Actor(nn.Module):
    def __init__(
        self,
        obs_dim: int,
        action_low: np.ndarray,
        action_high: np.ndarray,
        hidden_dim: int,
    ) -> None:
        super().__init__()
        action_low_t = torch.as_tensor(action_low, dtype=torch.float32)
        action_high_t = torch.as_tensor(action_high, dtype=torch.float32)
        self.register_buffer("action_scale", (action_high_t - action_low_t) / 2.0)
        self.register_buffer("action_bias", (action_high_t + action_low_t) / 2.0)

        action_dim = int(action_low_t.numel())
        self.network = nn.Sequential(
            nn.Linear(obs_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),
        )

    def forward(self, obs: torch.Tensor) -> torch.Tensor:
        normalized_action = torch.tanh(self.network(obs))
        return self.action_bias + self.action_scale * normalized_action


class Critic(nn.Module):
    def __init__(
        self,
        obs_dim: int,
        action_dim: int,
        hidden_dim: int,
    ) -> None:
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(obs_dim + action_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1),
        )

    def forward(
        self,
        obs: torch.Tensor,
        action: torch.Tensor,
    ) -> torch.Tensor:
        return self.network(torch.cat((obs, action), dim=-1))


class ReplayBuffer:
    def __init__(
        self,
        obs_dim: int,
        action_dim: int,
        capacity: int,
        seed: int,
    ) -> None:
        self.capacity = capacity
        self.rng = np.random.default_rng(seed)
        self.obs = np.empty((capacity, obs_dim), dtype=np.float32)
        self.next_obs = np.empty((capacity, obs_dim), dtype=np.float32)
        self.action = np.empty((capacity, action_dim), dtype=np.float32)
        self.reward = np.empty((capacity, 1), dtype=np.float32)
        self.terminated = np.empty((capacity, 1), dtype=np.float32)
        self.position = 0
        self.size = 0

    def __len__(self) -> int:
        return self.size

    def add(
        self,
        obs: np.ndarray,
        action: np.ndarray,
        reward: float,
        next_obs: np.ndarray,
        terminated: bool,
    ) -> None:
        index = self.position
        self.obs[index] = obs
        self.action[index] = action
        self.reward[index, 0] = reward
        self.next_obs[index] = next_obs
        self.terminated[index, 0] = float(terminated)
        self.position = (self.position + 1) % self.capacity
        self.size = min(self.size + 1, self.capacity)

    def sample(
        self,
        batch_size: int,
        device: torch.device,
    ) -> dict[str, torch.Tensor]:
        indices = self.rng.integers(0, self.size, size=batch_size)
        return {
            "obs": torch.as_tensor(self.obs[indices], device=device),
            "action": torch.as_tensor(self.action[indices], device=device),
            "reward": torch.as_tensor(self.reward[indices], device=device),
            "next_obs": torch.as_tensor(self.next_obs[indices], device=device),
            "terminated": torch.as_tensor(
                self.terminated[indices],
                device=device,
            ),
        }


@torch.no_grad()
def soft_update(
    target: nn.Module,
    source: nn.Module,
    tau: float,
) -> None:
    for target_parameter, source_parameter in zip(
        target.parameters(),
        source.parameters(),
        strict=True,
    ):
        target_parameter.lerp_(source_parameter, tau)


class DDPGAgent:
    def __init__(
        self,
        obs_dim: int,
        action_low: np.ndarray,
        action_high: np.ndarray,
        config: Config,
        device: torch.device,
    ) -> None:
        self.config = config
        self.device = device
        self.action_low = np.asarray(action_low, dtype=np.float32)
        self.action_high = np.asarray(action_high, dtype=np.float32)
        self.action_scale = (self.action_high - self.action_low) / 2.0

        self.actor = Actor(
            obs_dim,
            self.action_low,
            self.action_high,
            config.hidden_dim,
        ).to(device)
        self.critic = Critic(
            obs_dim,
            self.action_low.size,
            config.hidden_dim,
        ).to(device)

        self.target_actor = deepcopy(self.actor).to(device)
        self.target_critic = deepcopy(self.critic).to(device)
        self.target_actor.requires_grad_(False)
        self.target_critic.requires_grad_(False)
        self.target_actor.eval()
        self.target_critic.eval()

        self.actor_optimizer = torch.optim.Adam(
            self.actor.parameters(),
            lr=config.actor_lr,
        )
        self.critic_optimizer = torch.optim.Adam(
            self.critic.parameters(),
            lr=config.critic_lr,
        )

    @torch.no_grad()
    def act(
        self,
        obs: np.ndarray,
        explore: bool,
    ) -> np.ndarray:
        obs_tensor = torch.as_tensor(
            obs,
            dtype=torch.float32,
            device=self.device,
        ).unsqueeze(0)
        action = self.actor(obs_tensor).squeeze(0).cpu().numpy()
        if explore:
            noise = np.random.normal(
                loc=0.0,
                scale=self.config.exploration_std,
                size=action.shape,
            ).astype(np.float32)
            action = action + noise * self.action_scale
        return np.clip(action, self.action_low, self.action_high)

    def update(
        self,
        replay: ReplayBuffer,
    ) -> dict[str, float]:
        batch = replay.sample(self.config.batch_size, self.device)

        with torch.no_grad():
            next_action = self.target_actor(batch["next_obs"])
            next_q = self.target_critic(batch["next_obs"], next_action)
            target_q = (
                batch["reward"]
                + self.config.gamma
                * (1.0 - batch["terminated"])
                * next_q
            )

        q = self.critic(batch["obs"], batch["action"])
        assert q.shape == target_q.shape
        critic_loss = F.mse_loss(q, target_q)

        self.critic_optimizer.zero_grad(set_to_none=True)
        critic_loss.backward()
        self.critic_optimizer.step()

        self.critic.requires_grad_(False)
        actor_action = self.actor(batch["obs"])
        actor_loss = -self.critic(batch["obs"], actor_action).mean()

        self.actor_optimizer.zero_grad(set_to_none=True)
        actor_loss.backward()
        self.actor_optimizer.step()
        self.critic.requires_grad_(True)

        soft_update(self.target_actor, self.actor, self.config.tau)
        soft_update(self.target_critic, self.critic, self.config.tau)

        return {
            "critic_loss": float(critic_loss.detach().cpu()),
            "actor_loss": float(actor_loss.detach().cpu()),
            "q_before_update_mean": float(q.detach().mean().cpu()),
            "target_q_mean": float(target_q.detach().mean().cpu()),
        }


@torch.no_grad()
def evaluate(
    agent: DDPGAgent,
    config: Config,
    seed_offset: int,
) -> tuple[float, float]:
    env = gym.make(config.env_id)
    returns: list[float] = []
    actor_was_training = agent.actor.training
    agent.actor.eval()

    try:
        for episode in range(config.eval_episodes):
            obs, _ = env.reset(seed=config.seed + seed_offset + episode)
            terminated = False
            truncated = False
            episode_return = 0.0

            while not (terminated or truncated):
                action = agent.act(obs, explore=False)
                obs, reward, terminated, truncated, _ = env.step(action)
                episode_return += float(reward)

            returns.append(episode_return)
    finally:
        env.close()
        agent.actor.train(actor_was_training)

    return float(np.mean(returns)), float(np.std(returns))


def train(config: Config) -> None:
    validate_config(config)
    seed_everything(config.seed)
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    env = gym.make(config.env_id)
    env.action_space.seed(config.seed)

    assert isinstance(env.observation_space, gym.spaces.Box)
    assert isinstance(env.action_space, gym.spaces.Box)
    assert env.observation_space.shape is not None
    assert env.action_space.shape is not None
    assert len(env.observation_space.shape) == 1
    assert len(env.action_space.shape) == 1
    assert np.all(np.isfinite(env.action_space.low))
    assert np.all(np.isfinite(env.action_space.high))
    if not np.all(env.action_space.high > env.action_space.low):
        raise ValueError("every action dimension needs high > low")

    obs, _ = env.reset(seed=config.seed)
    obs_dim = int(np.prod(env.observation_space.shape))
    action_dim = int(np.prod(env.action_space.shape))
    agent = DDPGAgent(
        obs_dim,
        env.action_space.low,
        env.action_space.high,
        config,
        device,
    )
    replay = ReplayBuffer(
        obs_dim,
        action_dim,
        config.buffer_size,
        config.seed,
    )

    episode_return = 0.0
    episode_length = 0
    metrics = {"q_before_update_mean": float("nan")}

    try:
        for step in range(1, config.total_steps + 1):
            if step <= config.start_steps:
                action = env.action_space.sample()
            else:
                action = agent.act(obs, explore=True)

            next_obs, reward, terminated, truncated, _ = env.step(action)
            replay.add(obs, action, reward, next_obs, terminated)

            episode_return += float(reward)
            episode_length += 1
            obs = next_obs

            if terminated or truncated:
                print(
                    f"step={step} "
                    f"train_return={episode_return:.1f} "
                    f"length={episode_length} "
                    f"terminated={terminated} "
                    f"truncated={truncated}"
                )
                obs, _ = env.reset()
                episode_return = 0.0
                episode_length = 0

            ready = (
                step >= config.update_after
                and len(replay) >= config.batch_size
                and step % config.update_every == 0
            )
            if ready:
                for _ in range(config.update_every):
                    metrics = agent.update(replay)

            if step % config.eval_every == 0:
                eval_mean, eval_std = evaluate(agent, config, seed_offset=10_000)
                print(
                    f"step={step} "
                    f"eval_return={eval_mean:.1f}+/-{eval_std:.1f} "
                    f"q_before_update_mean="
                    f"{metrics['q_before_update_mean']:.3f}"
                )
    finally:
        env.close()


if __name__ == "__main__":
    train(Config())

三、逐段审计

3.1 Config：把时钟分开

start_steps、update_after、update_every 分别控制行为切换、学习启动和集中更新。示例令每 50 个环境步做 50 个梯度步， 长期 UTD 约为 1；这与每步更新一次不完全等价，但能提高批量计算效率。 由于 update_after=1000 小于 start_steps=5000， 本例会在随机动作阶段就开始学习；这是有意展示两个阈值可以不同，不是通用推荐。

validate_config 在创建训练状态前检查折扣、软更新比例、buffer/batch 容量、 调度间隔、评估回合数和噪声标准差。尤其是 \(\tau\notin(0,1]\) 时， lerp_ 不再表示合法的凸组合；update_every=0 或 eval_every=0 会破坏取模调度。动作空间还必须逐维满足有限且 high > low，否则 scale / bias 没有正确的控制区间含义。 这些检查不提高算法性能，但能在训练前阻止配置把数学公式悄悄改成另一种运算。

超参数是教学起点，不是跨环境推荐。Pendulum 的奖励尺度、动作维和 episode 长度 与 MuJoCo locomotion 不同；至少要对多个随机种子和训练预算报告结果。 seed_everything 只设置常用伪随机数状态；CUDA kernel、驱动和库版本仍可能 带来非确定性。需要逐位复现时还要记录软件/硬件版本并配置 PyTorch 的确定性选项， 且接受潜在性能损失。

3.2 Actor：动作边界是 buffer，不是可训练参数

action_scale 与 action_bias 用 register_buffer 注册：

  • 会随模型移动到 CPU / GPU；
  • 会进入 state_dict；
  • 不会进入 optimizer。

前向先产生 \([-1,1]\) 动作，再做逐维仿射映射，可处理非对称边界。 这里的“逐维”只覆盖一维动作向量；若环境动作原始形状为矩阵，必须在送入网络前后 显式 flatten/unflatten。本页通过环境断言拒绝静默接受这类输入。

3.3 Critic：输出保持二维

Critic 返回 \([B,1]\)，ReplayBuffer 的 reward 和 terminated 也保存为 \([B,1]\)。 assert q.shape == target_q.shape 防止静默广播。不要为了“看起来方便” 随意 squeeze 一个张量而保留另一个张量的末维。

3.4 ReplayBuffer：只用 terminated 屏蔽 bootstrap

单环境 Gymnasium 在调用 reset 前返回的 next_obs 是当前 transition 的真实下一观测，因此截断时可以保存它并继续 bootstrap。向量环境的自动 reset 语义不同，需从 info 取 final observation，不能机械照搬。

Buffer 还使用独立 NumPy generator，避免采样索引与全局噪声共享完全相同的随机流。 rng.integers 是有放回采样，同一 transition 可在一个 mini-batch 中重复； 这是合法的经验分布抽样约定，不应误解为每批一定包含互不相同的索引。

3.5 soft_update：lerp 的方向

PyTorch 的

target_parameter.lerp_(source_parameter, tau)

等价于

\[\mathrm{target} \leftarrow (1-\tau)\,\mathrm{target} +\tau\,\mathrm{source}.\]

helper 带 no_grad，并用 strict=True 要求参数数量一致。 不过 zip(target.parameters(), source.parameters()) 只遍历参数， 不会同步 BatchNorm running mean/variance 等持久 buffer。Actor 的动作 scale/bias 在构造时已由 deepcopy 精确复制且之后不变，所以本例没有问题； 若加入动态 buffer，必须另行定义其硬复制、软更新或冻结策略。

3.6 act：相对噪声与最终 clip

Actor 已输出物理动作，噪声先按每维 action_scale 缩放，再 clip。 Replay 保存传给环境的 action，因此 Critic 的动作标签与真实动力学一致。

3.7 update：四个最重要的边界

  1. Target 前向完全位于 torch.no_grad()。
  2. Critic step 使用 replay action。
  3. Actor step 使用当前 Actor action，并临时冻结 Critic 参数。
  4. Target 更新发生在两个在线 optimizer step 之后。

返回的 q_before_update_mean 来自 Critic optimizer step 之前那次前向， 而 target_q_mean 来自同一 batch 的固定目标。明确时点可以防止把日志误读成 “更新后 Q”；若要记录更新后值，应在 step 之后用 no_grad 重新前向。

冻结 Critic 参数不会阻断对动作的梯度。Critic 前向仍在计算图中， 只是其权重不积累梯度；\(\partial Q/\partial a\) 仍可传给 Actor。 若给 Critic 前向加 no_grad 或 detach Actor action，Actor 才会真正断梯度。

3.8 evaluate：必须独立、无噪声、不写 replay

评估新建环境，使用独立 seed 区间，调用 explore=False， 不写 ReplayBuffer、不运行 update。平均值与标准差来自多个 episode。 若网络含 dropout / BatchNorm，eval() 还会改变模块行为；本例虽只有 MLP， 仍显式切换并恢复模式。

每次评估重建环境并使用同一组 episode seeds，优点是不同 checkpoint 面对相同初始随机性； 缺点是这组 seeds 仍只是有限测试集。最终报告应增加未参与调参的 seed 集，并把 episode 间标准差与跨训练 seed 的不确定性分开。

四、建议补充的断言与单元测试

4.1 初始化一致

def assert_same_state(online: nn.Module, target: nn.Module) -> None:
    online_state = online.state_dict()
    target_state = target.state_dict()
    assert online_state.keys() == target_state.keys()
    for name in online_state:
        assert torch.equal(online_state[name], target_state[name]), name


assert_same_state(agent.actor, agent.target_actor)
assert_same_state(agent.critic, agent.target_critic)

使用 state_dict 而不只遍历 parameters，才能同时检查动作 scale/bias 或 BatchNorm 统计等持久 buffer。初始化时目标网络应是在线网络的精确副本。

4.2 目标无梯度

assert all(parameter.grad is None for parameter in agent.target_actor.parameters())
assert all(parameter.grad is None for parameter in agent.target_critic.parameters())

在至少一次 update 后仍应成立。

4.3 Actor step 不改 Critic

Actor step 前 clone Critic 参数，step 后逐项 torch.equal； 这能发现 optimizer 参数集合写错或忘记冻结。

4.4 动作边界

随机生成一批观测，检查

\[\ell_j\le\mu_\theta(s)_j\le u_j\]

对每个 batch、每个动作维成立。

4.5 Soft update 极端值

  • \(\tau=0\)：target 不变；
  • \(\tau=1\)：target 等于 online。

这两个值只用于测试插值方向，不是常规训练推荐。

4.6 截断测试

构造相同 reward、next Q 的两条样本：

  • terminated=True：target 等于 reward；
  • truncated=True, terminated=False：target 仍含 \(\gamma Q'\)。

4.7 形状与时钟测试

  • 非一维 Box observation/action 应在初始化阶段明确失败，不能等到矩阵乘法或 buffer 写入时报错。
  • 非有限或退化动作边界、非法 \(\gamma/\tau\)、空评估集以及非正调度间隔应在训练前明确失败。
  • 前 start_steps 次必须走随机动作分支，第 start_steps+1 次才走 Actor。
  • 第一次更新还必须同时满足 step >= update_after、buffer 大小和更新触发条件。

五、公式—代码逐项定位

公式 代码表达 易错点
\(a=\mathrm{bias}+\mathrm{scale}\tanh z\) Actor.forward 只乘上界无法处理非对称区间
\(y=r+\gamma(1-m_{\mathrm{term}})Q_{\bar\phi}(s',\mu_{\bar\theta}(s'))\) with torch.no_grad() 把 truncated 当 terminated
\(L_Q=\mathbb E[(Q-y)^2]\) F.mse_loss(q, target_q) \([B]\) / \([B,1]\) 广播
\(L_\mu=-\mathbb E[Q(s,\mu(s))]\) -critic(obs, actor(obs)).mean() 使用 replay action 或 detach
\(\bar\psi\leftarrow(1-\tau)\bar\psi+\tau\psi\) target.lerp_(source, tau) 方向写反
\(a_{\mathrm{exec}}=\mathrm{clip}(\mu+\epsilon)\) act(..., explore=True) 噪声单位与动作尺度不一致

六、主流实现对照

6.1 OpenAI Spinning Up

优点是公式、伪代码、core 网络和训练循环对应清楚。审计时注意：

  • PyTorch DDPG 代码面向旧 Gym API，done 语义需要迁移到现代 terminated / truncated。
  • 教学实现曾用 action_space.high[0] 作为统一动作上限，隐含各维对称同界； 本页实现改为逐维 scale / bias。
  • polyak=0.995 表示保留旧 target 的比例，不是本页的 \(\tau\)。

6.2 CleanRL

CleanRL 把算法集中在一个文件，适合从环境 step 一直跟到 optimizer step。 其文档明确现代实现与原论文的差异，包括 Gaussian 对 OU、256×256 对 400×300、 环境版本和 Critic 融合位置。文档还指出其 DDPG 基于 sfujim 的 OurDDPG.py 风格；因此不能用一条 CleanRL 曲线直接声称复现原论文。

6.3 Stable-Baselines3

SB3 把 DDPG 作为 TD3 的特殊情况实现，复用 TD3 policy 和 off-policy 基础设施。 以当前官方源码为例，DDPG 构造器令 policy_delay=1、 target_noise_clip=0，并在未显式覆盖时令 n_critics=1， 从而关闭延迟策略更新、目标策略平滑以及 twin critics 取最小这组 TD3 机制。 因此“继承 TD3 代码”不等于启用了 TD3 改进；阅读框架时应固定版本或 commit， 检查最终配置与真实数据流，不能只看类继承关系或策略类的默认签名。

6.4 sfujim/TD3

仓库同时有 OurDDPG.py、DDPG.py 与 TD3.py。 前两者服务于不同基线口径；README 也提示论文发表后部分超参数和实现有调整。 正确用法是固定 commit 后逐项 diff，而不是把任一文件无条件称为“原始官方 DDPG”。

七、如何进行一次可信的小规模验证

  1. 先运行随机策略，确认环境 reward 方向和 episode 长度。
  2. 只跑一个 seed 检查代码能学习，不把它当实验结论。
  3. 增加 5–10 个 seeds，固定总环境步与评估间隔。
  4. 评估用独立环境和无噪声动作，报告均值、标准差或置信区间。
  5. 保存每次运行的配置、库版本、commit、曲线和最终模型。
  6. 至少记录 Q、target Q、动作饱和率和 terminated/truncated 计数。
  7. 与同预算 TD3 / SAC 或可信框架基线比较，不只比较最终最好一次。

Pendulum 上出现回报提升只能说明代码有基本生命迹象，不能证明在高维 MuJoCo、 机器人任务或稀疏奖励上正确。逐级增加环境难度，比一次跳到复杂真机更容易定位错误。

八、常见代码错误

错误 程序是否常报错 结果
Target 网络独立随机初始化 否 初始 target 无稳定参考
Target 参数放入 optimizer 否 滞后副本失去定义
target 未 no-grad 未必 构图浪费；错误 optimizer 时会串梯度
Actor loss 使用 replay action 否 Actor 梯度为零或无依赖
对 Critic 前向整体 no-grad 否 Actor 收不到 \(\partial Q/\partial a\)
\([B]\) 与 \([B,1]\) 混算 否 广播成 \([B,B]\)
存 clip 前动作 否 Critic 动作标签与环境动力学错配
用 done 屏蔽 truncation 否 时间边界 target 系统性偏低
评估仍加噪声 否 训练探索与策略质量混在一起
只复制参数、忽略 BatchNorm buffer 否 目标统计量漂移

九、知识重点、实现创新与适用边界

9.1 三层知识结构

  1. 算法层：确定性 Actor、单 Critic、replay、目标网络和软更新定义 DDPG 主干。
  2. 实现层：张量 shape、动作缩放、终止掩码、梯度开关、设备和随机流决定公式是否被正确执行。
  3. 框架层：vector env、callback、特征提取器、保存加载和日志属于工程能力， 不能反向当作 DDPG 原论文的算法创新。

9.2 本页最重要的审计链

从环境实际动作开始，沿 “执行动作 → replay action → Critic 输入 → 固定 Bellman target → Actor 通过 Q 的动作梯度 → 在线参数更新 → target 软更新”逐段核对。只看 loss 曲线无法证明这条链正确； shape 广播、错误 done、clip 前动作或断开的动作梯度都可能静默地产生数值。

9.3 创新点与边界

  • DDPG 的算法创新在于把确定性策略梯度与深度 Critic、replay、target network 组合到连续控制； 本页的断言、独立随机流和日志命名是可审计工程设计，不冒充原始算法贡献。
  • 冻结 Critic 参数仍保留 \(\partial Q/\partial a\)，体现“冻结被求导函数的参数” 与“切断函数对输入的导数”是两件事。
  • 单个 Pendulum seed 上回报上升只说明训练链具有基本生命迹象，不能证明正确复现或跨任务泛化。
  • 本实现不是通用 Box/图像/字典/向量环境库，也不提供 CUDA 逐位确定性、安全控制或真机验证。
  • 上游框架会变化；任何“与 SB3/CleanRL 等价”的结论都必须附版本或 commit。

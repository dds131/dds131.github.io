七条局限与论文尚未证明的事

论文 5.1 Limitations 的七条范围按原顺序保留；它们是作者自陈的限制和未来工作，不等于每项已有定量失败实验：

  1. 数据多样性与跨 embodiment 训练不足：预训练来自单一 SO100。
  2. 数据规模有限：约 23K trajectories，对比 OpenVLA 约 1M。
  3. 模型规模与硬件效率仍需共同扩展。
  4. VLM backbone 主要在文档阅读/OCR 上预训练，是否最适合真实机器人未知。
  5. 多模态数据与机器人数据尚未联合训练。
  6. 复杂和长时程任务仍不足；层级策略/多级规划是未来方向。
  7. 主要依赖 imitation learning；RL 对复杂、长时程、灵巧控制的收益未验证。

23K / 1M≈1/43.5 只说明数据量级差；episode 定义、质量和采样不同，不能直接推出样本效率或饱和。跨机器人 fine-tune 也不等于 multi-embodiment joint pretraining 或 zero-shot transfer。

当前论文尚未建立九类结论：消融差异的统计显著性；八表严格单变量控制；多模态性是 FM 增益唯一原因；后半 VLM 层普遍无用；交错 attention 的实测速率/平滑优势；各表赢家可组合；10 的普遍最优性；异步执行质量完全相同；以及多本体联合预训练、长时程或 RL 收益。

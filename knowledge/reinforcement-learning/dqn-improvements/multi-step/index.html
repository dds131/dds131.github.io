前三个子页分别改了目标值怎么算、网络怎么搭、从池里怎么抽样。本页改的是回报怎么构造——把 TD 目标里那一步真实奖励，换成 \(n\) 步真实奖励再接自举。

这项改进有一个与前三个不同的边界：把未修正的 \(n\) 步回报用于离策略回放时，一般不能精确评估当前目标策略；但在行为策略等于目标策略、轨迹内动作恰好匹配目标策略，或退化到单步等特殊情形，问题可以消失。它仍被广泛使用，并在 Rainbow 的特定消融中贡献很大。本页要区分「一般无保证」与「一概无效」，再解释它为何仍有经验收益。

n = 3Rainbow 在 1、3、5 的受测设置中选择
需条件未修正离策略 n 步目标并非普遍正确
该实验唯一Fedus 受测组合中启用大池收益的组件
可组合与其它 DQN 改进有接口与统计交互
本页重点。必须精读的是三节：「离策略边界」区分一般偏差与成立的特殊条件；「与回放池的交互」只在 Fedus 等的 Atari、算法与容量范围内解读结论；「实现要点」明确区分 terminated 与 truncated，并在回合边界刷新窗口尾部。

偏差—方差图是一种有限样本直觉，不是「MC 天生无偏、TD 天生有偏」的无条件定理；函数逼近、离策略数据、有限时域建模与不准确的自举值都会改变结论。

符号与前置

表格型的 \(n\) 步 TD 与 \(n\) 步 Sarsa 推导见时序差分，本页不重写。两者的关键差别是：那里是同策略、表格型的设定，而本页面对的是离策略、函数逼近、且样本来自回放池的设定——恰恰是在这个差别里，\(n\) 步回报从一个有保证的方法变成了一个有欠账的方法。

经验回放的基本作用与容量权衡见 DQN。

截断 n 步回报

从状态 \(S_t\) 出发的截断 \(n\) 步回报定义为

\[R_t^{(n)} \;\equiv\; \sum_{k=0}^{n-1} \gamma_t^{(k)} R_{t+k+1}\]

先说清记号，否则这两个式子会被读错：\(\gamma_t^{(k)}\) 不是 \(\gamma_t\) 的 \(k\) 次方，而是从 \(t\) 起往后 \(k\) 步的累积折扣

\[\gamma_t^{(k)} \;\equiv\; \prod_{i=1}^{k} \gamma_{t+i}, \qquad \gamma_t^{(0)} = 1\]

写成逐步连乘而不是 \(\gamma^{k}\)，是为了让每一步折扣可不同。对真正的 MDP 终止（terminated），可令后续折扣为 0，使目标停止自举；但时间上限等外部截断（truncated）只结束这段采样，通常仍应从最后观测自举。工程上因此仍要保存两个标志：二者都会截断窗口并触发尾部刷新，只有 terminated 默认把自举掩码置零。折扣恒定且没有边界时才退化为通常的 \(\gamma^{k}\)。

于是 \(R_t^{(n)}\) 就是累加 \(n\) 步真实奖励，然后由多步 DQN 变体去最小化

\[\Big( R_t^{(n)} + \gamma_t^{(n)} \max_{a'} q_{\bar\theta}(S_{t+n}, a') \;-\; q_\theta(S_t, A_t) \Big)^2\]

与单步目标相比，唯一的改动是：自举点从 \(S_{t+1}\) 推后到了 \(S_{t+n}\)，中间那 \(n\) 步换成了真实收到的奖励。Rainbow 对它的评价是一句简短的经验判断：适当调过的 \(n\) 常常带来更快的学习。

偏差与方差：n 是一根插值杆

可以把 \(n\) 步回报看成在两个极端之间插值：

常见有限样本直觉是：增大 n 会减少对当前自举估计的依赖，却累积更多随机奖励与转移。只有在同策略、完整回报对应正确目标且终止语义正确等条件下，才能把 MC 简称为「无自举偏差」；单步 TD 的误差也会随自举估计逐渐准确而消失。

具体地说，两端的来源不同：

  • 完整回报的随机性来自奖励与环境动力学，时间跨度越长，通常累积得越多；但相关性、折扣与任务结构决定实际方差，不保证随 \(n\) 单调上升。
  • 单步 TD 的有限样本误差常来自不准确的自举值；若表格型同策略学习收敛且自举值准确，这种误差可以消失，所以不能把「高偏差」当成 TD 的永久属性。
  • 离策略与函数逼近会额外改变两端：完整行为轨迹回报未必是目标策略回报，而投影、数据分布与移动目标也会影响所谓偏差。

一条必须带上的限定。Hernandez-Garcia 与 Sutton 将 Kearns 与 Singh 的结果概括为线性函数逼近下的偏差—方差权衡，并指出深度强化学习中仍缺少同等系统的研究。这里沿用的是该文的有限样本解释框架，不把「低/高偏差」当作算法永久属性。

因此，把这条权衡迁移到深度网络上可以作为实验假设，但实际结果还会同时受离策略程度、目标网络、回放分布、优化器与边界语义影响。

离策略边界：未修正目标一般不等于目标策略回报

这是本页的核心。

\(n\) 步回报里的 \(R_{t+1}, \dots, R_{t+n}\)，是当初采集这条轨迹时的行为策略走出来的。而我们要估的是目标策略（贪心策略）的价值。两者不是同一个策略——回放池里的数据来自过去若干个版本的策略，而目标策略随着网络更新一直在变。

若要严格评估指定目标策略，跨越的中间动作必须按行为策略与目标策略之差做校正。逐决策重要性采样是一种做法；Tree Backup 使用目标策略概率构造备份系数，Retrace 则使用截断系数来控制方差，不能把它们都简化成「直接乘完整 IS 比率」。Rainbow 式未修正 \(n\) 步 Q-learning 则不做这类校正，直接使用行为轨迹上的奖励。

Fedus 等 2020 把它称为对离策略数据「缺少理论依据」的未修正目标，因为它没有校正行为策略与目标策略之差，但仍因便利与经验收益被使用。准确地说，它一般不能保证等于当前目标策略的 n 步回报；这不表示每条样本都必然产生偏差，更不表示该启发式在经验上无效。

成立的特殊情形包括行为策略与目标策略一致、轨迹内相关动作恰好与目标策略一致，或 $$n=1$$ 时中间没有待校正动作。把「一般无保证」写成「任何离策略样本都理论错误」同样过度。

欠账为什么能被接受：三条实证

Hernandez-Garcia 与 Sutton 把 Retrace、Q-learning、Tree Backup、Sarsa、\(Q(\sigma)\) 这几个 \(n\) 步动作价值算法接到 DQN 式的架构上做了系统比较。

先说清被测对象，否则这组结论会被用过头，而且有两层限定都容易漏。下面三条结论出自该文 4.1 节，那一节比较的是带修正与不带修正两个版本，被测智能体是 Sarsa、Q(σ=0.5) 与 decaying σ 三个（论文摘要把它们统称为「Sarsa 与 Q(σ)」）。

限定一（算法）：DQN 所用的 Q-learning 目标不在被测之列。
★ 限定二（步长）：该节测的是这些算法的「单步」版本——论文原文写的是「We tested two versions of the one-step algorithms Sarsa, Q(σ=0.5), and decaying σ」。也就是说，被验证的是「单步更新可以不做离策略修正」，而不是「n 步未修正回报无害」。

这一条对本页尤其要紧，因为本页讨论的恰恰是 n 步。所以这组结论能说明的是「离策略修正并非总是必要」这件事在深度设定下有实证支持，而不是「DQN 的未修正 n 步回报已被实验证明无害」。那笔欠账至今没有被直接验过。

在这个前提下，三条结论是：

结论 含义
不使用离策略修正时，Sarsa 与 \(Q(\sigma)\) 的整体与最终性能没有受到不利影响 欠账在这个任务上没有暴露成实际损失
若修正做得朴素，反而会对学习产生不利影响 修正不是「加上总没坏处」的东西
但使用修正时，早期性能确实被显著改善 欠账在训练早期是有代价的

由此论文提出了一个自然的设想：只在训练早期使用离策略修正、之后关掉，可能兼得两端的好处。

引用这组结论时必须同时带上三条限定。其一是算法范围（结论针对 Sarsa 与 Q(σ)，不含 Q-learning）。其二是步长范围（4.1 节测的是单步版本，不是 n 步）。其三是任务范围：该实验是在 mountain car 上做的（选它是为了更快的训练与更大的样本量），论文自己写明这一发现是 problem specific 的，只是「提示离策略修正对于从回放池样本中学习并非总是必要」。它不是一个普适定理。

这篇论文另有一条结论适用面更宽，与被测算法无关：增大回溯长度 n 在所有受测算法上都一致地改善了性能。

与回放池的交互：本专题最反直觉的一条

到这里为止，多步回报看起来只是一个「调节偏差方差的旋钮」。但 Fedus 等 2020 在系统研究经验回放时发现了一件出人意料的事。

他们的做法是把回放池的两个基本属性拆开独立控制：回放容量，以及学习更新次数与采集经验之比（replay ratio）。然后做了一组 Rainbow 的消融——每次剥掉一个组件，看它还能不能从更大的回放池中获益。

在论文受测的 Atari 子集、DQN/Rainbow 变体与 1M→10M 容量比较中，移除多步回报的 Rainbow 不再从更大容量获益，而移除 PER、Adam 或 C51 的版本仍有改进。添加实验里，也只有 DQN + n-step 对增大容量出现实质改善。

因此作者说 n-step 在这组实验中具有「独一无二的重要性」。这是对特定实验网格的归纳，不是「任何 Q 学习算法能否利用大回放池只由 n-step 决定」的普适定理。

同一组实验里还有第二个反直觉的发现：

在这组容量实验中，加入或移除优先经验回放没有显著改变智能体从更大回放池获得的相对收益。这不等于 PER 对总体性能无效，只说明「PER 会随容量增大而额外变得关键」的直觉未在该设置中得到支持。

PER 本身的机理见子页③。

机制：一条在对照中不足，另一条只获部分支持

论文专门用一节来找这两者之间的机制，并在开头就交代了结果：在它评估的几个假设中，有一条起到了部分作用。

在该对照中不足的解释：更低的收缩率。 \(n\) 步目标的自举项乘 \(\gamma^{n}\)，因此一个自然猜测是更小的系数降低了自举误差与发散风险。论文在单步更新中人为使用同样小的系数，却没有得到「容量增大即受益」；固定最老策略年龄时，普通 DQN 也没有随容量变大而改善。结论应写成：较低收缩因子本身不足以解释受测现象。它没有否定收缩性在其它任务或 n-step 稳定性中的作用。

获得部分支持的解释：方差与数据多样性。 作者假设在其设置中，较长 \(n\) 的目标方差更大，因而对回放池数据组成的变化更敏感。增大容量不改变从某个固定池中抽 minibatch 的条件方差，却会改变池中 transition 的覆盖与随时间波动：数据生成策略快速变化时，小池子的组成可能剧烈漂移，大池子则混合更多时期的数据。这是待检验的机制假设，不是所有 MDP 上的方差定理。

作者据此提出可检验预测：若额外收益部分来自回报方差，那么降低环境随机性后，扩大回放容量的收益应变小。论文把 ALE sticky actions 关闭，以减少动作重复造成的转移随机性，并比较 1、3、5、7 步 DQN；这是一种干预代理，不能保证只改变回报方差。

结果方向与假设一致：关掉 sticky actions 后，增大容量的相对改进更小，且开/关差距随受测 \(n\) 增大。这为方差解释提供了部分证据，但不证明一般任务中回报方差必随 \(n\) 单调增大，也不排除 sticky actions 同时改变了其它学习难度。

但论文自己收住了口：即使把随机性去掉，n 步回报在容量增大时仍然有改进。因此方差缩减只能部分地解释 n 步为何能利用更大的回放池，不是完整答案。

引用这一段时要把两层都带上：较低收缩因子在该对照中不足以解释现象；方差假设获得部分支持，但不是完整机制。把它写成「收缩率在任何场景都无作用」或「机制已确定就是方差」，都不准确。

最老策略的年龄

为什么容量与多步回报会扯上关系？论文给出的中间量是最老策略的年龄：

回放池的大小直接影响最老策略的年龄。这个量可以宽松地看作池中数据离策略程度的一个代理——一个策略越老，它与当前策略不同的可能性就越大。

这条链只能当作诊断启发：固定 replay ratio 增大池子时，最老 transition 的更新年龄通常上升，也可能意味着更强的离策略性；但论文明确称它是宽松代理。若策略变化很慢、已经收敛，或在少数策略间循环，数据更老也未必离当前策略更远。多步回报又恰好对策略不匹配更敏感，因此二者值得联合监控，而不能用年龄直接替代策略距离。

至于这条链背后的机制，上一节给出了两步检验：仅靠较低收缩因子不足以复现现象，方差与数据多样性解释获得部分支持但并不完整。论文追查了机制，却没有得到唯一因果解释——这一点在引用时要写准。

还有一条相反方向的观察，同样值得记住：在数据较少时，带多步回报的 DQN 反而可能表现更差。因此「把 n 调大」不是一个无条件的改进——它与手头数据量、回放容量是绑在一起的。

n 取多少

Rainbow 把 \(n\) 称作一个敏感的超参数，并在其 Atari 配置中比较了 \(n = 1, 3, 5\)：

\(n = 3\) 与 \(n = 5\) 初期表现都不错，但整体上 \(n = 3\) 到最后表现最好。

Fedus 等在扫描 \(n\) 时也确认：曲线形状取决于具体使用的智能体，但取 \(n = 3\)（他们全部先前实验采用的值）表现良好。

实现要点

多步回报不要求更换 Q 网络，但会改变回放池记录、窗口状态与目标构造。下面骨架把最容易漏掉的边界一并写出；单步记录格式为 (s, a, r, s_next, terminated, truncated)：

from collections import deque


def build_n_step(window, gamma):
    """把窗口最左端前缀聚合成一条 n-step transition。"""
    assert window
    reward_n = 0.0
    actual_k = 0
    for i, (_, _, reward, _, terminated, truncated) in enumerate(window):
        reward_n += (gamma ** i) * reward
        actual_k = i + 1
        if terminated or truncated:       # 两种边界都不能跨过去拼接下一回合
            break

    state, action = window[0][0], window[0][1]
    _, _, _, state_k, terminated_k, truncated_k = window[actual_k - 1]
    return (
        state, action, reward_n, state_k,
        terminated_k, truncated_k, actual_k,
    )


def append_and_emit(window, step, n, gamma):
    """普通步最多产出一条；边界到来时刷新全部残余前缀。"""
    window.append(step)
    emitted = []
    terminated, truncated = step[-2:]

    if len(window) >= n:
        emitted.append(build_n_step(window, gamma))
        window.popleft()

    if terminated or truncated:
        while window:                     # 保留回合末尾不足 n 步的样本
            emitted.append(build_n_step(window, gamma))
            window.popleft()
    return emitted


n_step_window = deque()
# 每个环境步：把 append_and_emit(...) 返回的所有 transition 写入 replay

# 学习时：边界样本的折扣用实际步数；只有 terminated 阻止自举
with torch.no_grad():
    q_next = target_net(state_k).max(dim=1).values
    bootstrap_mask = (~terminated_k).float()
    target = reward_n + (gamma ** actual_k) * q_next * bootstrap_mask

五处易错点：

  • terminated 与 truncated 都结束当前窗口，但只有前者默认停止自举。 时间上限截断若被当成 MDP 终止，会系统性低估边界附近价值。
  • 截断时的 state_k 必须是真实 final observation。 自动 reset 或向量环境可能把 reset 后观测放进普通 obs，要按环境 API 取出最终观测再入池。
  • 自举折扣使用 actual_k，不是固定 \(n\)。不足 \(n\) 步的尾部若仍用 \(\gamma^n\)，目标会被过度折扣。
  • 任何回合边界都必须刷新剩余前缀并清空窗口。 否则末尾 \(n-1\) 条样本丢失，或下一回合奖励被错误拼接进来。
  • 目标网络分支放在 torch.no_grad() 中。 这保证 DQN 的半梯度目标不被反向传播；若任务把时间上限定义为真正有限时域终点，则应显式建模剩余时间或重新定义掩码，而不是盲套默认规则。

小结与出口

  • 多步回报把自举点推后，用更多真实奖励换取对更长随机轨迹的依赖；「MC 低偏差高方差、单步 TD 低方差高偏差」只是带条件的有限样本直觉。
  • 未修正离策略 \(n\) 步目标一般不等于当前目标策略回报，但同策略、动作匹配或 \(n=1\) 等特殊情形可以成立；经验有效不等于获得了普适理论保证。
  • Hernandez-Garcia 与 Sutton 关于修正可能有害的结果只覆盖 mountain car 中若干单步 Sarsa / \(Q(\sigma)\) 版本，不能替未修正 n-step Q-learning 背书。
  • Fedus 等的 Atari 容量实验中，n-step 是受测组件里唯一启用更大容量收益的因素；较低收缩因子不足以单独解释，方差假设只获部分支持。
  • 工程上必须同时保存 terminated、truncated 与 actual_k：两种边界都刷新窗口，通常只有 terminated 关闭自举。
  • Rainbow 在其 \(n=1,3,5\) 比较中选择 \(n=3\)；这是敏感超参数，不是跨任务最优常数。

接下来：分布式强化学习与 C51改的是学什么——从回报期望改为整个分布。它可与 n-step、PER 等组件组合，但目标分布、TD 误差与采样优先级会相互影响；Rainbow 的排序只适用于其报告的组合与基准。

逐条核验过的来源

  1. Rainbow: Combining Improvements in Deep Reinforcement Learning（Hessel 等；AAAI 2018，arXiv:1710.02298） 核验内容：截断 \(n\) 步回报的定义式与多步 DQN 变体的损失函数（本页两式逐项对照）；「适当调过的 \(n\) 常带来更快学习」这一评价；\(n\) 是 Rainbow 的敏感超参数，比较 \(n = 1, 3, 5\) 后「\(n = 3\) 与 \(5\) 初期都不错，整体上 \(n = 3\) 最终最好」。本页只取其中与多步回报直接相关的部分，Rainbow 的整体组合与消融留给专门的子页。

  2. Revisiting Fundamentals of Experience Replay（Fedus 等；ICML 2020，arXiv:2007.06700） 核验内容：把回放容量与 replay ratio 作为两个基本属性独立控制的研究框架；「未修正的 n 步回报对离策略数据在理论上不成立，因为不修正行为策略与目标策略的差异，但因便利与经验收益仍被使用」原句；剥掉 n-step 的 Rainbow 不再从更大回放容量获益、而剥掉其它组件的仍能获益这一消融结论，及「n 步回报在能否借更大回放池变强这件事上具有独一无二的重要性」的判断；优先经验回放不显著影响大容量下表现这一反直觉发现；第 5 节开篇的自述「在我们评估的假设中，有一条起到了部分作用」；5.1 节由更低收缩率带来的改进不足以解释 n-step 的重要性（含单步换用同样小的收缩因子、以及固定最老策略年龄两个对照）；5.2 节的方差缩减假设全过程——把 n 步回报刻画为在 MC 与单步 TD 之间插值且MC 低偏差高方差、单步 TD 低方差高偏差、MC 的方差来自奖励与环境动力学的随机性、大池子通过提高转移多样性抹平数据生成策略的波动、由此导出的可检验预测、用 sticky actions 开关调节回报方差并跑 1/3/5/7 步 DQN 的验证（关掉后相对改进一致更小、且差距随 n 拉开），以及论文自己的收口「即使去掉随机性 n 步仍随容量改进，故该假设只能部分解释」；回放池大小直接影响最老策略的年龄、该量可宽松视作池中数据离策略程度的代理；「数据较少时带 n-step 的 DQN 可能表现更差」；扫描 \(n\) 后确认 \(n = 3\) 表现良好。

  3. Understanding Multi-Step Deep Reinforcement Learning: A Systematic Study of the DQN Target（Hernandez-Garcia 与 Sutton；arXiv:1901.07510） 核验内容：所比较的算法集合（Retrace、Q-learning、Tree Backup、Sarsa、\(Q(\sigma)\) 接到 DQN 式架构上）；三条主要结论——不使用离策略修正时整体与最终性能未受不利影响、朴素的修正反而可能有害、但使用修正时早期性能显著改善，并由此提出「只在早期修正、之后关闭」的设想。★ 这三条结论有两层范围限定，本页已在引用处显式标出：其一，论文是针对 Sarsa 与 \(Q(\sigma)\) 陈述的（摘要原文「the performance of Sarsa and \(Q(\sigma)\)」），DQN 所用的 Q-learning 目标不在其列；其二，4.1 节测的是这些算法的单步版本（原文「We tested two versions of the one-step algorithms Sarsa, \(Q(\sigma=0.5)\), and decaying \(\sigma\)」），因此被验证的是「单步更新可以不做修正」，不是「n 步未修正回报无害」。另核：4.1 节被测智能体实为三个（Sarsa、\(Q(\sigma=0.5)\)、decaying \(\sigma\)）；回溯长度 \(n\) 的增大在所有受测算法上一致改善性能（这一条适用面覆盖全部被测算法）；Kearns 与 Singh 2000 的偏差方差权衡「在线性函数逼近下被观察到，但在深度强化学习设定下仍有待系统研究」这一限定；实验在 mountain car 上进行、论文自称结论 problem specific 这一适用范围声明（本页在引用处已标明）。

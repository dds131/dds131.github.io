π0.5问题与范围锚点

问题与范围：开放世界不等于无限开放

π0.5关注四条泛化轴：环境变化、物体实例变化、任务组合变化，以及长时程任务能推进到什么程度。论文把评测放在三个未进入训练集的真实家庭和一个受控仿制家庭中；这支持“在指定未见家庭协议下评估”，不支持“任意新家庭、任意机器人和任意指令均可直接泛化”。

失败也不是单一维度。语义接地可能找错对象，任务分解可能选择错误子任务，陌生中间态恢复可能失败；低层控制误差同样可能贡献失败。这三类高层问题彼此不排斥，也不能从最终分数反推出唯一故障源。

论文的 task progress 按任务 rubric 记录部分完成度，不是只看成功/失败的二值成功率。总览只固定口径；场景、评分细节与结果解释进入 Open World 页面。

方法主线：训练侧以异构数据共训练扩展知识，推理侧以分层输出把可读子任务与连续动作块连接起来。现有证据不证明这两项是开放世界泛化的唯一方案，也不把它们各自独立写成已证实因果。</div>

相对π0差异锚点

相对π0的最小差异摘要

π0.5继承 PaliGemma/SigLIP 视觉语言主干、异构宽度双专家联合注意力、Flow Matching 和连续动作块。它不是重新定义这些基础机制；需要推导时回到 π0 的 Architecture、Flow Matching、Time 与 Training 页面。

“继承”与“新增关注”必须分开
轴 π0 基线 π0.5 新增或改变的重点 本页证据边界
目标问题 视觉语言条件到连续动作块。 未见家庭中的语义、组合与长时程泛化。 只覆盖论文给定评测范围。
数据 跨任务、跨本体机器人数据。 MM/ME/CE/HL/WD/VI 参与不同训练阶段的异构共训练。 数据类别不等于全部原始数据已公开。
训练 以 Flow Matching 学习连续动作。 先离散预训练，再加入连续动作专家联合后训练。 阶段变化不只是损失系数变化。
状态/时间 状态作为连续 token 路径的一部分。 固定代码的 pi05 分支改变 state 路径和时间注入。 这是模型类差异，不代表完整论文系统。
推理 直接生成连续动作块。 同一模型先生成可读子任务，再以动作专家生成连续动作候选块。 不是两个互相独立的模型。
公开实现 固定代码可审计训练/采样骨架。 pi05=True 支持 π0.5 的连续路径。 不等于 FAST 预训练和高层解码全链公开。

固定 Pi0Config 中常说的“两处变化”，只指模型类里的 state 路径与时间注入差异，不能代替对论文完整训练系统的说明。现有材料也不足以声称任一单项改动已被独立消融证明为性能原因。

评测与本地案例证据边界锚点

指标、结果与本地案例证据边界

任何 π0.5 结果都必须和场景类别、家庭是否进入训练集、任务 rubric、试验数、机器人本体、checkpoint、控制协议一起解释。“在三个未见真实家庭与一个受控仿制家庭上评估”不能压缩成“适用于所有家庭”；部分任务推进度也不能改名为成功率。

DQN 把 Q-learning 里的那张表换成了一个神经网络。这一步换来的是对连续、高维状态空间的处理能力，同时打开了三个表格法里根本不存在的问题：函数逼近的泛化会让一处更新牵动别处、自举目标随参数一起移动、离策略数据的分布与被优化的策略不匹配。三者同时出现时，Q-learning 的收敛保证不再成立，训练可以发散。经验回放与目标网络这两项设计，就是用来把这个不稳定压住的工程手段。

本章要解决什么问题

前五页的所有算法都把 \(Q\) 存成一张表。表格表示有两个隐含前提：状态可枚举，并且每个状态都能被访问足够多次。这两个前提在稍微真实一点的任务上立刻失效。

  • 状态连续时无法枚举。CartPole 的状态是四维实向量（小车位置与速度、杆的角度与角速度），取值连续，表格的行数是无穷。强行离散化会带来两难：分得粗则同一格里的状态被迫共享一个 \(Q\) 值，分得细则格子数按维度指数增长。
  • 状态离散但过大时同样不可行。Atari 游戏的一帧 \(84 \times 84\) 灰度图像若按像素枚举，状态数远超任何存储介质的容量；围棋的合法局面数同理。
  • 表格没有跨状态泛化能力。表格里每个条目彼此独立，访问过状态 \(s\) 不会自动更新相邻状态 \(s'\)。连续任务常具有可利用的局部平滑或共享结构，但接触切换、约束边界等位置也可能不连续，不能假定“邻近状态必有相近最优动作”。
  • 访问覆盖不可能达成。表格型 Q-learning 的收敛证明要求每个状态-动作对被访问无穷多次。状态空间一大，绝大多数条目一次也访问不到。

因此本章要解决的问题是：把 \(Q(s,a)\) 从查找表换成带参数的函数 \(Q_{\phi}(s,a)\)，用有限参数表示大状态空间，并通过表示与参数共享引入泛化。 是否能在“该相似的状态”之间正确共享，取决于输入表示、网络归纳偏置与数据覆盖，并非自动保证。这一步称为函数逼近（function approximation）。

代价同样明确，而且是本页的主线：函数逼近破坏了表格更新的局部性——更新一个样本会改变所有共享参数所影响的估值。它与自举和离策略采样叠加后会形成后文的致命三要素。DQN 用经验回放与目标网络显著改善了原始 Atari 实验中的可训练性，但没有提供“一定不发散”的一般保证。

与上一页的关系值得先说清楚。Dyna-Q 面对的是「真实交互太贵」，解法是建模型、把一条经验重放多次；本页面对的是「状态太多存不下」，解法是换表示。两者正交，可以叠加。DQN 的经验回放在形式上与 Dyna-Q 的规划循环很像——都是重复利用历史转移——但含义不同：Dyna-Q 重放的是模型生成的虚拟转移，DQN 重放的是真实发生过的转移，因此 DQN 没有模型误差这一项。

形式化定义：从 Q 表到 Q 网络

沿用前五页的部分（可快速略过）：MDP 五元组 \(\langle \mathcal{S}, \mathcal{A}, P, r, \gamma \rangle\)、动作值函数 \(Q^{\pi}(s,a)\) 的定义、Bellman 最优方程

\[Q^{*}(s,a) = \mathbb{E}_{s'} \left[ r + \gamma \max_{a'} Q^{*}(s',a') \right]\]

以及 \(\varepsilon\)-贪婪行为策略，全部与时序差分一页一致，此处不再展开。

本章新增的部分。把 \(Q\) 换成一个参数为 \(\phi\) 的神经网络：

\[Q_{\phi}: \mathcal{S} \to \mathbb{R}^{|\mathcal{A}|}, \qquad Q_{\phi}(s) = \big[ Q_{\phi}(s, a_1), \dots, Q_{\phi}(s, a_{|\mathcal{A}|}) \big]\]

注意输出形式：网络吃一个状态，一次吐出所有动作的 \(Q\) 值，而不是吃 \((s,a)\) 对吐一个标量。这个设计不是随意的，它带来两处实实在在的好处：

  • 计算 \(\max_{a'} Q_{\phi}(s', a')\) 只需一次前向传播，而不是 \(\lvert \mathcal{A} \rvert\) 次。这一项在每次更新里都要算，省下的是常数倍但可观的开销。
  • 同一状态下不同动作共享除输出层以外的全部特征提取，样本效率更高。
  • 代价是动作空间必须离散且有限，输出维度就是动作数。连续动作空间下这一步走不通，只能改用 DDPG那样单独训练一个策略网络来代替 argmax。

三种表示的对照如下。

表示形式 参数量 跨状态泛化 更新的影响范围 典型理论边界
查找表 状态数乘动作数 无 只影响被更新的那一格 有限表格、充分访问且步长满足条件时，Q-learning 可收敛
线性逼近 特征数乘动作数 由特征决定 影响共享特征的状态 某些策略评估或专门算法下有保证
神经网络（本章） 与状态数无直接线性关系 由表示与数据决定 影响全部共享参数的状态 无一般性保证

最后一列是本章全部麻烦的来源，也是下一节的出发点：表格型 Q-learning 的收敛证明用不到函数逼近这一栏，一旦换成神经网络，那套证明的前提就整体失效了。

算法推导：损失函数、半梯度与致命三要素

从 Bellman 最优方程到回归问题

表格型 Q-learning 的更新是一条赋值语句，无法直接搬到网络上——网络没有「某一格」可以赋值。标准做法是把 Bellman 最优方程改写成一个回归问题：如果 \(Q_{\phi}\) 已经等于 \(Q^{*}\)，那么对任意转移都应有

\[Q_{\phi}(s,a) = r + \gamma \max_{a'} Q_{\phi}(s', a')\]

两侧之差就是要被压到零的残差。于是定义目标值

\[y = r + \gamma\,(1 - d)\, \max_{a'} Q_{\phi^{-}}(s', a')\]

与均方误差损失

\[L(\phi) = \mathbb{E}_{(s,a,r,s',d) \sim \mathcal{D}} \left[ \big( Q_{\phi}(s,a) - y \big)^{2} \right]\]

逐项说明：

  • \(d \in \{0,1\}\) 是 bootstrap mask 中的真终止标志。外部时间上限导致的 truncation 通常仍要自举；若有限时域本身属于任务定义，则剩余时间必须进入状态，边界应按该 MDP 的终止语义处理。统一合同见环境 API 与时间边界。
  • \(\phi^{-}\) 是目标网络参数，取值是主网络参数在过去某个时刻的副本。为什么不直接写 \(\phi\)，是本节后半段与下一节的主题。
  • \(\mathcal{D}\) 是经验回放池，期望对池中的分布取，而不是对当前策略的轨迹分布取。这一行就是 DQN 成为离策略算法的形式表达。
  • \(\max\) 算子对所有动作取最大，与行为策略实际选了哪个动作无关。这是 Q-learning 与 Sarsa 的分水岭，也使 DQN 能直接使用离策略回放数据；“能使用”不等于任意历史分布都没有覆盖或外推风险。

梯度推导与半梯度

对 \(\phi\) 求导。若把 \(y\) 当作与 \(\phi\) 无关的常量，得到

\[\nabla_{\phi} L(\phi) = \mathbb{E} \left[ -2 \big( y - Q_{\phi}(s,a) \big) \nabla_{\phi} Q_{\phi}(s,a) \right]\]

单个样本上做一步梯度下降，参数的更新量是

\[\Delta \phi = \alpha \big( y - Q_{\phi}(s,a) \big) \nabla_{\phi} Q_{\phi}(s,a)\]

把它与表格型 Q-learning 的更新对照，可以看到严格的对应关系：表格情形下 \(Q_{\phi}(s,a)\) 就是参数本身，\(\nabla_{\phi} Q_{\phi}(s,a)\) 是一个只在 \((s,a)\) 处为 1 的指示向量，代入上式立刻还原成

\[Q(s,a) \leftarrow Q(s,a) + \alpha \left[ y - Q(s,a) \right]\]

把表格看成 one-hot 特征的线性模型时，上式可以退化为表格更新；神经网络则把指示向量换成稠密梯度，使一次更新影响共享参数所覆盖的多个状态。这个对应关系有助于理解实现，但不意味着神经网络在优化性质和收敛保证上“严格包含并保持”表格 Q-learning。

这里有一个必须讲清的细节：当目标网络参数 \(\phi^{-}\) 在一次优化步中固定且与在线参数 \(\phi\) 分离时，上式就是“冻结目标损失”对 \(\phi\) 的真实梯度。若不用独立目标网络而令目标也由在线参数生成，标准 Q-learning 更新仍会停止目标分支的梯度；相对于完整 Bellman 残差，这才通常称为半梯度（semi-gradient）。

  • 为什么通常停止目标梯度。Q-learning 的更新规则把 bootstrap 目标视作本步的监督信号；若同时优化目标分支，得到的是另一类“残差梯度”目标，采样无偏估计还会遇到 double-sampling 问题，不能把它当作漏写一次反向传播。
  • 理论边界。半梯度更新一般不是完整均方 Bellman 残差的梯度，因此不能直接套用监督学习的优化结论；即便使用冻结目标网络，每次回归的标签也会在同步后改变，仍不等于一个全程固定的监督学习问题。
  • 实现上。PyTorch 通常用 torch.no_grad() 或 detach() 阻断 bootstrap 目标的梯度。若目标网络完全独立且不在优化器中，这主要避免无用计算与目标网络梯度累积；若复用在线网络计算目标，它还定义了算法本身的半梯度更新。

致命三要素

本段是全页重点之一。它解释的是「为什么 DQN 需要那两项工程设计」，而不只是「DQN 用了哪两项设计」。

Sutton & Barto 用“致命三要素”（deadly triad）概括一类高风险组合：函数近似、自举、离策略。三者同时出现时，即使线性逼近也存在发散反例；但这是风险结构，不是“出现即发散”的充要条件。DQN 在不少任务上可训练，也不等于把这一风险消除或把发散概率压到某个已证明的界内。

不能把“去掉任意一项”写成无条件安全。经典同策略线性 TD 在遍历性、特征与步长等条件下有收敛结果；换成非线性逼近、控制问题或不满足采样条件时，结论不能直接外推。下面的投影视角用于解释分布、投影与 Bellman 更新为何会冲突，不是对深度 DQN 收敛性的证明。

先把每一项的作用写清楚：

  • 函数近似破坏了更新的局部性。表格型更新只动一格；网络更新会顺着参数改变所有状态的估值，包括那些恰好出现在自举目标里的状态。
  • 自举让回归目标依赖于被优化的对象自身。监督学习的标签是外部给定的固定量，而这里的标签由网络自己算出来，更新预测的同时也在移动标签。
  • 离策略让更新所依据的数据分布，与被评估策略实际会访问的状态分布不一致。回放池里存的是历史行为策略采集的数据，被评估的却是当前的贪婪策略。

三者的相互作用可以写成算子形式，这是最能说清机理的方式。定义 Bellman 最优算子

\[(\mathcal{T}Q)(s,a) = \mathbb{E}_{s'} \left[ r + \gamma \max_{a'} Q(s',a') \right]\]

它在无穷范数下是 \(\gamma\)-压缩：

\[\| \mathcal{T}Q_1 - \mathcal{T}Q_2 \|_{\infty} \le \gamma\, \| Q_1 - Q_2 \|_{\infty}\]

同步、精确地应用表格 Bellman 最优算子时，值迭代由压缩映射定理收敛到唯一不动点 \(Q^{*}\)；基于样本的异步 Q-learning 还需要充分访问与合适步长等随机近似条件。函数逼近时，\(\mathcal{T}Q_{\phi}\) 一般不在可表示函数族里，可用“先做 Bellman 更新、再按数据分布投影”的理想化视角描述为

\[Q_{k+1} = \Pi_{\mu}\, \mathcal{T}\, Q_{k}\]

问题就出在这里：\(\Pi_{\mu}\) 在 \(\mu\)-加权的 \(L_2\) 范数下是非扩张的，\(\mathcal{T}\) 的压缩性却是在无穷范数下成立的。两个范数不匹配，复合算子 \(\Pi_{\mu}\mathcal{T}\) 未必是压缩映射，迭代可以发散。

这个缺口在什么条件下能补上，正好解释了「离策略」为什么是三要素之一：

  • 同策略线性策略评估时，在经典假设下，TD(0) 的期望更新具有稳定解并可证明收敛；这里的限定包括固定策略、合适特征、遍历采样与步长条件。
  • 离策略时，\(\mu\) 由行为数据决定，与目标策略的占用分布不同，经典保证不再直接成立。Baird 反例说明：即使在线性、简单转移与奖励下，离策略半梯度 TD 也可能发散。
  • 一种直观风险链条是：覆盖不足状态的估值产生误差 → 误差进入其他转移的自举目标 → 共享参数传播误差 → 行为分布又缺少足够样本纠正它。它是解释性机制，不表示每个 DQN 失败都遵循同一条单调路径。

去掉任意一项，问题都会缓解。这也给出了一张实用的排查表。

去掉哪一项 典型替代 风险如何变化 仍需满足的条件或代价
函数近似 表格型 Q-learning 更新恢复局部性 有限表格、充分访问与合适步长；无跨状态泛化
自举 蒙特卡洛回报 不再传播当前估值误差 回报方差高，通常要等回合或截断段结束；函数逼近优化仍可能失败
离策略 Sarsa / 同策略评估 行为与目标分布差异减小 经典保证只覆盖特定线性评估条件；同策略批次仍可做有限次复用

DQN 三者一个都没去掉——它要泛化能力所以保留函数近似，要低方差增量更新所以保留自举，要复用历史数据所以采用离策略 Q-learning。经验回放降低短时相关性并延缓分布漂移，目标网络让 bootstrap 标签在一段更新窗口内固定；两者是经验上有效的缓解，不是收敛保证。

两项稳定化设计：经验回放与目标网络

本节两个小节都是全页重点。它们不是可选的工程润色：把任意一项从 DQN 里去掉，CartPole 这样简单的任务都可能训不出来。后续的 DDPG、TD3、SAC 原样继承了这两个部件。

经验回放：为什么随机采样能打破样本相关性

问题。与环境交互产生的转移是一条时间序列，相邻样本往往高度相关：连续几帧里小车的位置几乎不变，杆的角度只差一点点。随机梯度法并不严格要求样本完全独立同分布，但强相关、持续漂移的数据会降低梯度估计的有效样本量，并让优化器反复追逐局部轨迹。

  • 梯度方向被局部轨迹主导。连续若干步的样本几乎在说同一件事，网络在这一小段状态上被反复拉扯，等效于在极小的数据集上过拟合。
  • 分布随策略漂移。策略每更新一次，接下来采集到的状态分布就变一次。网络刚拟合好上一段分布，输入分布就整体移走，旧状态上的估值随之退化——这就是灾难性遗忘在强化学习里的表现。
  • 样本复用率低。若每条转移只更新一次，昂贵交互提供的监督信号没有被充分利用；是否“无法接受”取决于任务与计算预算。

做法。维护一个容量为 \(N\) 的先进先出队列 \(\mathcal{D}\)，每次交互至少保存 \((s,a,r,s',\text{terminated},\text{truncated})\)；每次更新从池中均匀随机抽取大小为 \(B\) 的小批量。两个边界标志都保存，目标 mask 再按任务语义选择。

为什么有效，逐条对应上面三个后果：

  • 随机抽样把时间上邻近的样本打散，通常降低批内相关性；样本仍来自有限、非平稳的历史混合分布，所以不能据此宣称梯度无偏或方差一定受控。
  • 池中混合多个历史行为策略的数据，能减慢输入分布漂移和灾难性遗忘，但过旧数据、窄覆盖和策略突变仍可能造成偏差。
  • 每条转移会被抽中多次，单条真实经验的利用率大幅提高。

为什么标准 DQN 可以直接回放历史数据。池中的转移由过去的行为策略采集，而目标使用当前贪婪动作的 bootstrap 值；Q-learning 的离策略结构允许这种更新，但仍依赖足够的状态—动作覆盖。标准 PPO 通常只在同一批旧策略数据上做有限轮更新，随后丢弃，因为策略继续变化会让重要性比率和信赖域近似失真；若要长期回放，必须加入重要性采样、V-trace、Retrace 等校正，或改变目标函数，不能简单概括为“同策略算法永远不能回放”。

\[y = r + \gamma \max_{a'} Q_{\phi^{-}}(s',a') \quad \text{中不含任何行为策略的信息}\]

容量 \(N\) 与批量 \(B\) 各自的作用，两者常被混为一谈：

参数 控制什么 太小的后果 太大的后果
容量 N 池中数据的策略年龄跨度 旧数据被过早挤出，分布仍随策略漂移，回放的去相关作用减弱 池中长期充斥早期随机策略的数据，与当前策略相关的样本占比过低
批量 B 单次梯度估计的方差 梯度噪声大，训练曲线抖动 单步计算量线性上升，而每个环境步仍只更新一次，收益有限
起训阈值 开始更新前池中至少要有多少数据 在极少量样本上反复更新，迅速过拟合 前期交互预算浪费在纯随机策略上

容量和批量没有跨任务通用的固定比例。容量应覆盖足够多的状态、奖励与行为阶段，同时避免过旧数据长期主导；批量在显存、吞吐与梯度噪声之间权衡。两者作用不同但并非完全独立：改变批量、更新比率或容量都会改变每条样本被复用的次数与数据年龄分布。

目标网络：不要追一个自己在移动的靶子

问题。回到损失函数。若不引入 \(\phi^{-}\)，目标写成

\[y = r + \gamma \max_{a'} Q_{\phi}(s',a')\]

那么每次更新 \(\phi\) 都可能同时改变预测与后续 bootstrap 目标，优化器面对的是会随参数移动的标签。共享表示可能让二者的误差相互传播，但影响的符号和大小取决于梯度相关性，不能断言提高 \(Q_{\phi}(s,a)\) 必然提高邻接状态的值。在不利的数据与优化条件下，这种耦合可形成正反馈，使估值尺度持续膨胀或振荡。

做法。另存一份参数 \(\phi^{-}\) 专门用于计算目标，每隔 \(C\) 步把主网络硬拷贝过去：

\[\phi^{-} \leftarrow \phi \quad \text{每 } C \text{ 步执行一次}\]

为什么有效。在两次拷贝之间，\(\phi^{-}\) 固定，因此同一条转移的 bootstrap 标签不会因在线网络每次更新而立刻移动。这把快速反馈变成较慢的分段变化，通常更容易优化；但数据分布、采样批次和在线网络仍在变化，非凸回归也没有一般收敛保证。目标网络削弱的是自举误差的即时反馈，而不是把整个训练严格变成固定数据的监督学习。

更新周期 \(C\) 的影响是一处典型权衡：

  • \(C\) 很小时，目标网络接近在线网络，削弱移动目标的作用有限；\(C=1\) 的硬更新在参数值上等同于每次 learner update 后同步，但是否发散仍取决于其他因素。
  • \(C\) 很大时，目标可能过旧，学习会变慢或产生滞后；“平稳但不涨”只是可能症状，不能只凭曲线形状定因。
  • \(C\) 应与 learner update 频率、梯度步长和任务变化尺度一起调节，并明确“步”指环境步还是优化器更新步；没有跨任务通用的夹逼公式。

硬更新与软更新。DQN 用每 \(C\) 步整体拷贝的硬更新，目标值因此每 \(C\) 步跳变一次；DDPG及其后续把它换成每步做一次小幅插值的软更新

\[\phi^{-} \leftarrow \tau \phi + (1 - \tau) \phi^{-}, \qquad \tau \ll 1\]

两者都用于降低目标变化速度，但不是严格等价。软更新是指数滑动平均，参数权重的时间尺度约为 \(1/\tau\) 次更新；硬更新在间隔内完全冻结并周期跳变。即使取相近时间尺度，两者的频率响应和优化轨迹也可能不同。

算法流程

先看一次完整更新中的数据流向。实线为数据通路，虚线表示不回传梯度的参数复制或估值调用。

flowchart TB
  S["当前状态 s"] --> QM["主网络 Q_phi"]
  QM -->|"argmax，以概率 epsilon 改为随机"| ACT["动作 a"]
  ACT --> ENV["环境 CartPole-v1"]
  ENV -->|"奖励 r、下一状态 s_next、terminated、truncated"| TR["六元组，两个边界标志都保存"]
  TR --> BUF["回放池 D，先进先出，容量 N"]
  BUF -->|"均匀随机采样批量 B"| BATCH["小批量样本"]
  BATCH -->|"取出 s 与 a"| PRED["预测项 q_values<br/>用 gather 取实际执行动作那一列"]
  BATCH -->|"取出 s_next"| QT["目标网络 Q_phi_minus"]
  QT -->|"对动作取最大值"| MAXQ["max_next_q"]
  BATCH -->|"取出 r 与 terminated；truncated 留作边界审计"| Y["外部时间上限下：td_target = r + gamma 乘 1 减 terminated 再乘 max_next_q"]
  MAXQ --> Y
  Y -.->|"no_grad，切断梯度"| LOSS["均方误差损失"]
  PRED --> LOSS
  LOSS --> UPD["梯度下降更新 phi"]
  UPD -.->|"每 C 次更新硬拷贝一次"| QT
  UPD --> QM

读图要点有三处。其一，terminated 与 truncated 都进入回放池；对 CartPole 的外部时间上限，只有 terminated 切断自举。其二，预测项走 gather、目标项走 max，两条路径的取值方式不同。其三，目标网络不由在线网络的优化器更新，参数只通过周期性硬拷贝变化。

方括号内为该步骤对应的公式或小节。

输入: 折扣 gamma, 学习率 lr, 批量 B, 池容量 N, 目标网络更新周期 C,
      探索率 epsilon 的初值 / 终值 / 衰减方式, 起训阈值 T_start

1  随机初始化主网络参数 phi
2  目标网络硬拷贝初始化: phi_minus <- phi                  [目标网络一节]
3  初始化空的回放池 D, 容量 N                              [经验回放一节]
4  env_step_count <- 0; update_count <- 0
5  for episode = 1, 2, ... do
6      重置环境, 得到初始状态 s
7      repeat
8          # ---- 与环境交互 ----
9          以概率 epsilon 随机选动作, 否则 a <- argmax_a Q_phi(s, a)
10         执行 a, 观测 r, s_next, terminated, truncated
11         把 (s, a, r, s_next, terminated, truncated) 存入 D
12         s <- s_next; env_step_count <- env_step_count + 1
13         按预定方式衰减 epsilon
14         # ---- 更新主网络 ----
15         if len(D) < T_start then continue                # 池太小不更新
16         从 D 中均匀随机采样 B 条转移                      [打破时间相关性]
17         max_next_q <- max_a' Q_phi_minus(s_next, a')      # 用目标网络, 切断梯度
18         y <- r + gamma * (1 - terminated) * max_next_q    [TD 目标公式]
19         q_values <- Q_phi(s) 中按 a 取出的那一列           # gather, 不是 max
20         loss <- mean( ( q_values - y )^2 )                [损失函数]
21         对 phi 做一步梯度下降; update_count <- update_count + 1
22         # ---- 同步目标网络 ----
23         if update_count mod C == 0 then phi_minus <- phi
24     until terminated 或 truncated
25 end for

实现时最容易出错的五处，代码一节会逐条对应到具体行：

  • 第 17 行使用 \(\phi^{-}\)，与本页定义的目标网络版本一致；若改用 \(\phi\)，算法与稳定性假设也随之改变。
  • 第 17 至 18 行停止目标梯度。独立目标网络不在优化器中时，这可避免无用计算和梯度累积；若复用在线网络计算目标，停止梯度还定义了半梯度更新。
  • 第 18 行按环境合同构造 mask。CartPole 的 500 步外部 TimeLimit 截断不切断自举，所以只用 terminated；任务内生有限时域则要把剩余时间纳入状态，并按该 MDP 的终止语义处理。
  • 第 19 行是 gather，不是 max。预测项取实际执行动作的 \(Q\) 值；误写为 max 会优化错误的 Bellman 残差，但损失不一定接近零，不能只靠 loss 数值发现。
  • 第 23 行按 learner update 计数。环境步、梯度更新和回合是三种不同单位；记录配置时必须写清同步周期的单位。

CartPole 的要点一张表带过：状态是四维连续向量（小车位置、小车速度、杆角度、杆角速度），动作是二维离散（向左推、向右推），每存活一步奖励 \(+1\)，CartPole-v1 的单回合上限为 500 步，因此回合回报的上限就是 500。杆倾角或小车位置越界时 terminated 为真，达到 500 步上限时 truncated 为真——这两个标志在本页的语义完全不同，第四段会用到。

第二段：Q 网络（样板，从简）

class Qnet(nn.Module):
    """两层 MLP，输入状态，一次输出全部动作的 Q 值。"""

    def __init__(self, state_dim: int, hidden_dim: int, action_dim: int):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, action_dim)   # 输出维度等于动作数

    def forward(self, x):
        x = F.relu(self.fc1(x))
        return self.fc2(x)                             # 输出层不接激活

只有两点需要说明，其余是标准写法。其一，输出维度等于动作数，与形式化一节说的「一次前向拿到全部动作的 \(Q\) 值」对应，\(\max\) 与 gather 都在这个输出向量上做。其二，标准 DQN 通常用线性输出层，让估值尺度不被 tanh 或 sigmoid 预先限制。若任务有已知严格回报界，也可以显式变换或约束输出，但目标、损失与反变换必须保持一致，不能随手加激活函数。

第三段：经验回放池（核心，逐行讲）

class ReplayBuffer:
    """先进先出的回放池，均匀随机采样。"""

    def __init__(self, capacity: int):
        self.buffer = deque(maxlen=capacity)   # 满了自动挤掉最旧的一条

    def add(self, state, action, reward, next_state, terminated, truncated):
        # 两种边界都保存；构造目标时再按环境合同选择 bootstrap mask
        self.buffer.append((state, action, reward, next_state, terminated, truncated))

    def sample(self, batch_size: int):
        transitions = random.sample(self.buffer, batch_size)   # 均匀随机，不放回
        state, action, reward, next_state, terminated, truncated = zip(*transitions)
        return (np.array(state), action, reward, np.array(next_state),
                terminated, truncated)

    def __len__(self):
        return len(self.buffer)

这三十行不到的代码承担了经验回放一节的全部机制，逐条对应：

  • deque(maxlen=capacity) 实现容量上限与先进先出。写满后追加会丢弃最旧转移；容量由数据覆盖、年龄分布、内存和更新比率共同决定，不能只把它解释成“策略年龄跨度”。
  • random.sample 做均匀、不放回抽样，通常能降低批内时间相关性。取最近的连续样本会保留强相关，但具体影响要用有效样本量、TD 误差和回报等指标验证，不能仅凭曲线形状定因。
  • add 同时保存 terminated 与 truncated。对 CartPole 的外部 500 步上限，TD mask 只读取 terminated；保留 truncated 便于统计边界比例、审计任务语义，也避免以后更换 wrapper 时丢失信息。
  • zip(*transitions) 后再转 NumPy 数组：先按字段拆开、再整体转张量，比逐条 torch.tensor 快一个量级。状态数组必须显式转成 np.array 再喂给 torch.tensor，直接把 tuple 列表交给 torch.tensor 会触发逐元素拷贝的慢路径。
  • 池里存 NumPy 数组或标量，而不是带计算图的设备张量。这样避免回放池长期占用显存或保留计算图；若专门实现 CPU 张量池或 pinned memory，也可以安全使用已分离的张量。

第四段：DQN 类与目标构造（核心，逐行讲）

class DQN:
    def __init__(self, state_dim, hidden_dim, action_dim, lr, gamma,
                 target_update, device):
        self.action_dim = action_dim
        self.q_net = Qnet(state_dim, hidden_dim, action_dim).to(device)
        # 目标网络：结构相同，参数初始化为主网络的副本
        self.target_q_net = Qnet(state_dim, hidden_dim, action_dim).to(device)
        self.target_q_net.load_state_dict(self.q_net.state_dict())
        self.optimizer = torch.optim.Adam(self.q_net.parameters(), lr=lr)
        self.gamma = gamma
        self.target_update = target_update      # 即公式里的 C
        self.count = 0                          # 更新次数计数器
        self.device = device

    def take_action(self, state, epsilon):
        """epsilon-greedy 行为策略。"""
        if random.random() < epsilon:
            return random.randrange(self.action_dim)
        state_t = torch.tensor(state, dtype=torch.float, device=self.device).unsqueeze(0)
        with torch.no_grad():                   # 采集动作时不需要梯度
            return int(self.q_net(state_t).argmax(dim=1).item())

初始化里有一行不能省：load_state_dict 让目标网络与主网络从同一组参数出发。若让两个网络各自随机初始化，训练开始时的 TD 目标由一个与主网络毫无关系的随机网络给出，前若干次更新纯属噪声。take_action 里用 torch.no_grad() 包住前向，是因为这一步只是选动作、不参与优化，留着计算图既浪费显存也拖慢速度。

    def update(self, transitions):
        states, actions, rewards, next_states, terminateds, _truncateds = transitions
        states = torch.tensor(states, dtype=torch.float, device=self.device)
        actions = torch.tensor(actions, dtype=torch.int64,
                               device=self.device).view(-1, 1)
        rewards = torch.tensor(rewards, dtype=torch.float,
                               device=self.device).view(-1, 1)
        next_states = torch.tensor(next_states, dtype=torch.float, device=self.device)
        terminateds = torch.tensor(terminateds, dtype=torch.float,
                                   device=self.device).view(-1, 1)

        # 预测项：取「实际执行过的那个动作」的 Q 值，用 gather 而不是 max
        q_values = self.q_net(states).gather(1, actions)

        # 目标项：用目标网络算下一状态的最大 Q 值，并切断梯度
        with torch.no_grad():
            max_next_q = self.target_q_net(next_states).max(dim=1)[0].view(-1, 1)
            td_target = rewards + self.gamma * max_next_q * (1 - terminateds)

        loss = F.mse_loss(q_values, td_target)   # 均方误差，对应损失函数公式

        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()

        # 每 C 次更新，把主网络硬拷贝给目标网络
        self.count += 1
        if self.count % self.target_update == 0:
            self.target_q_net.load_state_dict(self.q_net.state_dict())
        return float(loss.item())

这是全页最需要看清的一段，逐行对应前面的公式与伪代码：

  • q_values 用 gather 取值，对应伪代码第 19 行、损失里的 \(Q_{\phi}(s,a)\)。网络一次输出所有动作的估值，而预测项只要「当时真正执行的那个动作」的那一列。写成 .max(dim=1) 是最常见的致命错误：那样预测项与目标项都变成最大值，损失衡量的就不再是 Bellman 残差，训练看似在收敛，策略却毫无进展。actions 必须是 int64 且形状为 \((B, 1)\)，gather 对 dtype 与形状都很敏感。
  • max_next_q 用 self.target_q_net，不是 self.q_net，对应伪代码第 17 行、公式里的 \(\max_{a'} Q_{\phi^{-}}(s',a')\)。这一处写成主网络，就等于取消了目标网络，回到了「追一个自己在移动的靶子」的状态。这是排查 \(Q\) 值发散时第一个要检查的地方。
  • .max(dim=1)[0] 取的是最大值而非下标。max 返回的是「值与下标」的二元组，取 [1] 会把动作编号当成 \(Q\) 值代入目标，量级完全错乱。
  • with torch.no_grad() 包住目标构造。在这里目标网络独立且未加入优化器，漏写通常不会让 Adam 更新目标参数，但会构建无用计算图并累积目标网络梯度；若用在线网络计算目标，detach 与否还会改变更新规则。
  • (1 - terminateds) 乘在自举项上，对应公式里的 \((1-d)\)。终止转移之后没有未来回报，这一项把自举整体置零。这里的 terminateds 来自回放池中存的 terminated，不含截断，与第三段的讲解闭合。
  • 三行优化器调用的顺序不能变：先 zero_grad 清空上一步的梯度，再 backward 反传，最后 step 更新。漏掉 zero_grad 时梯度会逐步累加，等效学习率不断放大，训练很快发散。
  • 目标网络同步放在更新之后，且计数器按更新次数计。本实现里 TARGET_UPDATE = 10 的含义是「每 10 次参数更新同步一次」。若改成按环境步计数，同一个数字的实际含义会随「每步更新几次」而改变，与他人的配置对照时必须先问清口径。

第五段：训练循环

def train():
    env = gym.make(ENV_ID)
    env.action_space.seed(SEED)
    state_dim = env.observation_space.shape[0]      # CartPole 为 4
    action_dim = env.action_space.n                 # CartPole 为 2
    agent = DQN(state_dim, HIDDEN_DIM, action_dim, LR, GAMMA,
                TARGET_UPDATE, device)
    buffer = ReplayBuffer(BUFFER_CAPACITY)

    returns, global_step = [], 0
    for episode in range(N_EPISODES):
        state, _ = env.reset(seed=SEED if episode == 0 else None)
        ep_return = 0.0
        while True:
            # epsilon 线性衰减：前期广泛探索，后期接近贪婪
            eps = max(EPS_END, EPS_START - (EPS_START - EPS_END)
                      * global_step / EPS_DECAY_STEPS)
            action = agent.take_action(state, eps)
            next_state, reward, terminated, truncated, _ = env.step(action)
            # 两种边界都保存；本任务的外部 TimeLimit 不切断自举
            buffer.add(state, action, reward, next_state, terminated, truncated)
            state = next_state
            ep_return += reward
            global_step += 1

            # 池中样本足够多才开始更新，避免在极少数样本上过拟合
            if len(buffer) >= MIN_BUFFER_SIZE:
                agent.update(buffer.sample(BATCH_SIZE))

            if terminated or truncated:             # 两者都要结束回合
                break
        returns.append(ep_return)
        if (episode + 1) % 20 == 0:
            print(f"episode {episode + 1}, "
                  f"avg return (last 20) {np.mean(returns[-20:]):.1f}, "
                  f"epsilon {eps:.3f}")
    env.close()
    return returns

训练循环里有三处与前文直接对应，其余是常规写法：

  • terminated 与 truncated 都保存，但用途不同。CartPole 的目标 mask 只用 terminated；控制流用 terminated or truncated 结束回合。向量环境自动重置时还要保存 wrapper 提供的 final observation，不能误把重置后的首状态当作 next_state。
  • MIN_BUFFER_SIZE 阈值对应伪代码第 15 行。池里只有几十条样本时就开始更新，网络会在这一小撮高度相关的样本上迅速过拟合，且此时的数据全部来自初始随机策略，覆盖极窄。
  • \(\varepsilon\) 按全局步数线性衰减，而不是按回合。CartPole 的回合长度在训练中从几十步增长到几百步，按回合衰减会让后期的探索率下降得过快。

实验与结果分析

本页提供的是实验协议与可检验假设，不是已经执行过的结果。没有原始日志、配置快照与多 seed 汇总时，不应把“先上升、后回落”“去掉目标网络必然发散”等写成既成事实。统一统计口径见评估、统计与可复现性。

先固定协议，再看曲线

  • 独立重复：至少 5 个训练 seed；若要比较细小差异，优先 10 个或更多。每个 run 重新初始化网络、环境随机流与回放池，不能把同一训练 run 的多个回合当作独立样本。
  • 等预算比较：各变体使用相同环境步、learner update 数、评估频率和网络规模，同时记录墙钟时间。环境步与更新步都要保存，避免更新比率不同却声称样本效率更高。
  • 独立评估：每隔固定环境步，在单独评估环境中用固定策略运行一组 episode；评估转移不进入回放池。固定一组评估 seed 便于配对比较，但训练 seed 与评估 seed 要分开记录。
  • 预先声明选择规则：若保存“最佳 checkpoint”，先写明基于哪组验证 seed、哪个窗口和哪个指标选择，并同时报告最终 checkpoint。反复查看测试回报再挑最好的一版会产生选择偏差。
  • 保存逐 run 原始量：episode return、评估 return、TD 误差分位数、$$\max Q $$、Q 值中位数、梯度范数、loss、terminated/truncated 比例、epsilon、回放池年龄分布和运行时间。平滑曲线只用于展示，统计检验用未平滑数据。

怎样测“过估计”

td_target 的批均值与整回合 return 不是同一个条件下、同一个时间尺度的量，直接比较不能证明过估计。一个可审计的校准检查是：冻结 checkpoint，从固定的 held-out 状态—动作对出发，在明确的后续评估策略下估计多次折扣 Monte Carlo 回报 \(\widehat G(s,a)\)，再比较

\[\Delta_{\mathrm{cal}}(s,a)=Q_{\phi}(s,a)-\widehat G(s,a).\]

这衡量的是给定策略与采样协议下的估值校准，不等同于知道了 \(Q^{*}\)。若要检验 max 算子带来的系统偏差，应在相同预算和调参规则下比较 DQN 与 Double DQN，并报告跨 seed 的差值分布，而不是挑一条最符合叙事的曲线。

结果报告模板

主结果表至少给出每个变体的独立 run 数、最终评估回报的中位数与四分位距、均值的置信区间、失败 run 数、总环境步与墙钟时间；学习曲线显示跨 seed 区间。结论只写数据支持的范围，例如“在本配置和预算下，中位数下降且区间几乎不重叠”，不要外推成“该部件在所有任务上都是必要且充分的”。

折扣因子 \(\gamma\)

  • 取值：本页 0.98；0.95–0.99 是常见搜索区间，不是任务无关标准。
  • 为什么：\(1/(1-\gamma)\) 是几何权重尺度的启发式，0.98 约为 50 步，但不等于“只看 50 步”或 CartPole 的真实因果延迟。
  • 配错了会怎样：较小值降低远期奖励权重，可能形成短视偏差；较大值延长信用传播并放大 bootstrap 误差与截断语义错误。影响方向还取决于奖励、时域和学习率。

学习率与优化器

  • 取值：本页 Adam 配 2e-3；Nature 版用带特定超参数的 RMSProp 与 0.00025。优化器不同，数字不能只按倍数比较。
  • 为什么：2e-3 是待验证的 CartPole 起点，不是“低维任务可放大学习率”的定律。Adam 与 RMSProp 的有效步长还受梯度尺度、动量、epsilon 和损失定义影响。
  • 配错了会怎样：过大可能造成估值振荡、梯度尖峰或回报下降，过小可能在固定预算内学不到；它与目标同步周期、更新比率、批量和奖励尺度耦合，应做联合敏感性分析。

回放池容量 \(N\) 与起训阈值

  • 取值：本页容量 1e4、阈值 500，都是示例起点。阈值必须不小于批量；是否需要大很多取决于覆盖、多样性与更新比率。
  • 为什么：容量共同影响覆盖、样本年龄与平均复用次数；阈值避免在极小的初始数据集上立即优化，但不保证样本已经独立或覆盖充分。
  • 配错了会怎样：容量过小可能保留强相关和遗忘旧区域，过大可能让过旧数据长期占比高；阈值过小可能早期过拟合。实际方向要结合池中状态覆盖、数据年龄和 TD 误差验证。

批量 \(B\)

  • 取值：本页 64；32–256 可作为小型任务的搜索范围，不是推荐区间保证。
  • 为什么：批量影响梯度噪声、吞吐、显存和每条样本的复用分布；本实现恰好每个环境步最多更新一次，其他实现可能不同。
  • 配错了会怎样：较小批量常有更高梯度噪声，较大批量增加单次计算并可能需要重调学习率。最终影响用等环境步与等墙钟两种口径分别报告。

目标网络更新周期 \(C\)

  • 取值：本页每 10 次 learner update 同步；Nature 表列出 10000 的 target network update frequency。复现时必须依据对应实现确认单位，不能在环境步、原始帧与参数更新之间自行换算。
  • 为什么：\(C\) 控制同一转移的 bootstrap 标签跟随在线网络变化的速度。窗口过短时解耦较弱，过长时目标滞后；没有已知的跨任务最佳夹逼公式。
  • 配错了会怎样：两端都可能导致学习变慢、方差增加或估值失稳，但具体曲线不唯一。排查时联看评估回报、Q 值尺度、TD 误差、梯度和同步事件。

探索率 \(\varepsilon\) 的初值、终值与衰减

  • 取值：本页从 1.0 线性降到 0.01，衰减跨度约 5000 步。
  • 为什么：训练初期网络参数随机，贪婪动作没有任何意义，必须靠随机探索把回放池铺开；后期策略已经可用，过多随机动作只会污染数据分布并压低回报。终值不取 0，是为了持续提供少量探索、避免策略锁死。
  • 与 Nature 版的口径差别：Nature 版在前 100 万帧把 \(\varepsilon\) 从 1.0 线性退火到 0.1，此后训练期一直固定在 0.1，不再继续下降；常被一并提到的 0.05 是评测时用的探索率，不属于训练调度。引用「DQN 的 epsilon 降到多少」时要说清是训练值还是评测值。
  • 配错了会怎样：衰减过快时池中数据覆盖不足，网络在未访问区域只能外推，而外推值往往虚高、贪婪策略又恰好会朝虚高处走。衰减过慢时后期大量步数浪费在随机动作上，回报曲线长期压在低位。终值取 0 时策略可能停在次优解上且无法自行跳出。

隐层宽度

  • 取值：本页两层各 128。
  • 为什么：CartPole 的输入只有四维，两层 MLP 是便于教学与快速试验的基线；“足够表达”仍需由学习结果与容量消融支持。
  • 配错了会怎样：太窄可能产生欠拟合，太宽会增加计算量并改变优化动力学；网络更宽究竟提高稳定性还是放大估值误差没有单调结论。

小结与下一章衔接

本章可以压缩成四句话：

  • 表格法在状态连续或过大时失效，DQN 用神经网络逼近 \(Q\) 函数，一次前向输出全部动作的估值；这要求动作空间离散有限。
  • 每次更新最小化冻结 bootstrap 目标的 TD 回归损失；独立目标网络下这是该步损失的真实梯度，复用在线网络并停止目标梯度时才是相对于完整 Bellman 残差的半梯度。
  • 函数近似、自举、离策略构成已知的发散风险组合；投影与 Bellman 更新的范数不匹配是一种解释视角，不是深度 DQN 的收敛或发散定理。
  • DQN 保留三者，经验回放降低短时相关性并复用数据，目标网络减慢 bootstrap 标签变化；两者通常改善训练，但都不是稳定性保证。

遗留问题：\(Q\) 值过估计。 目标里的 \(\max_{a'}\) 同时承担两件事——选出最优动作、并给出它的估值，而这两件事用的是同一个网络的同一份带噪估计。设逼近误差为 \(\varepsilon(s',a')\)，即使它零均值，也有

\[\mathbb{E}\left[ \max_{a'} \big( Q^{*}(s',a') + \varepsilon(s',a') \big) \right] \ \geq\ \max_{a'} Q^{*}(s',a')\]

在每个动作估计无偏等条件下，最大化更容易选中正误差，因此产生非负选择偏差；误差相关性、动作间真实差距和训练分布都会影响偏差大小。自举可能传播这份偏差，但不能把实际放大量固定写成 \(1/(1-\gamma)\)。连续动作 Actor-Critic 中也有“对带误差 Critic 做近似最大化”的相似风险，具体算子与假设并不完全相同。

Double DQN 的修正非常直接：把「选动作」与「评估该动作」交给不同的网络，用主网络选出 \(\arg\max\)，再用目标网络给这个动作打分，

\[y = r + \gamma\,(1-d)\, Q_{\phi^{-}}\Big(s',\ \arg\max_{a'} Q_{\phi}(s',a')\Big)\]

在线网络负责选择、目标网络负责评估，减少了“同一份噪声同时选中并评高动作”的直接耦合；两网参数相关，因此偏差通常只是降低而非保证消失。连同 Dueling DQN 对网络结构的改造（把 \(Q\) 拆成状态价值与优势两支），构成下一页 DQN 改进的主要内容。

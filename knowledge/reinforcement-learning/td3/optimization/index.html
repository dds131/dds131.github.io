一次训练迭代：损失、梯度与计数器各守边界

核心原则：先在 no_grad 下构造固定监督目标，再更新两个在线 critic；仅在延迟策略步更新 actor，让梯度穿过在线 Q1 对动作的导数，但不更新 Q1 参数；最后才对三套目标参数执行 Polyak 更新。本页重点是梯度、优化器和计数器边界，不重复推导三项机制的动机。

Clipped Double Q、延迟策略更新、目标策略平滑和六网络职责已在前页说明。本页把它们组装成一次可复现的优化迭代；策略梯度与 MSE 基础仍可回看策略梯度、Actor–Critic和 DDPG。

1. 固定的 critic target 与双 critic loss

沿用前页约定：actor 输出归一化动作 (u\in[-1,1]^{d_a})，(\mathcal T) 把 (u) 映射到 critic 使用的动作坐标；若 critic 本来就读取 (u)，则 (\mathcal T) 为恒等映射。对 batch 中每个样本、每个动作维独立采样：

[ u’j=\mu{\phi’}(s’j),\qquad \xi_j\sim\mathcal N(0,\sigma^2I{d_a}),\qquad \epsilon_j=\operatorname{clip}(\xi_j,-c,c), ] [ \tilde u’j=\operatorname{clip}(u’_j+\epsilon_j,-1,1), \qquad \tilde a’_j=\mathcal T(\tilde u’_j), ] [ m_j=1-\mathbb 1[\mathrm{terminated}_j], \qquad y_j=r_j+\gamma m_j \min{i\in{1,2}}Q_{\theta’_i}(s’_j,\tilde a’_j). ]

两项裁剪均按维执行；(\epsilon) 的 batch 形状为 ([B,d_a])，两个目标 critic 评价同一个 (\tilde a’_j)。这里是“高斯采样后裁剪”，不是严格的截断正态分布。(m,r,y) 均使用 ([B,1])，逐样本取 min；需要 bootstrap 的截断 transition 必须使用截断前的最终观测，不能使用自动重置后的新 episode 初始状态。

从目标 actor 到 (y) 的整条分支都在 no_grad 下计算。若目标网络含 BatchNorm 或 Dropout，还需明确 eval 模式和 buffer 同步；no_grad 只阻止 autograd，不会自动阻止运行统计改变。

两个在线 critic 拟合同一个停止梯度的 target：

[ L_i(\theta_i)=\frac1B\sum_{j=1}^{B} \left(Q_{\theta_i}(s_j,a_j)-y_j\right)^2,\qquad L_Q=L_1+L_2. ]

标准基线先使用 MSE。Huber loss 是工程变体：必须记录阈值 (\delta) 与 reduction，并在确认 target、动作单位和形状正确后再比较；它不能用来掩盖终止 mask 或广播错误。

2. Actor loss 与确定性策略梯度

actor 只在延迟策略步更新。若 critic 使用物理动作，先经过与 replay 相同的 (\mathcal T)：

[ a_{\phi,j}=\mathcal T(\mu_\phi(s_j)),\qquad J(\phi)=\frac1B\sum_{j=1}^{B}Q_{\theta_1}(s_j,a_{\phi,j}), \qquad L_\pi=-J. ]

actor loss 不加入探索噪声，也不加入 target noise。固定 (\theta_1) 时，梯度仍必须穿过 Q1 的动作输入：

[ \nabla_\phi J =\frac1B\sum_{j=1}^{B} \left. \nabla_aQ_{\theta_1}(s_j,a) \right|{a=a{\phi,j}} \nabla_\phi a_{\phi,j}. ]

“固定 Q1”只表示 actor step 不更新 (\theta_1)。可以暂时关闭 Q1 参数的 requires_grad 以避免累计无用梯度，但不能对 actor 动作或 Q1 输出 detach，也不能把 Q1 前向放进 torch.no_grad()。实现应恢复 Q1 原有的梯度标志，最好用上下文管理器或 try/finally，避免异常后永久冻结。

3. 精确更新顺序

采样 batch。统一 device、dtype、动作坐标与形状；按真正终止构造 bootstrap mask。
无梯度构造 target。目标 actor、逐样本逐维 target noise、动作裁剪、两个目标 Q 和逐样本 min 全程停止梯度。
更新两个 critic。critic optimizer 清梯度，反传 \(L_1+L_2\)，执行 optimizer step。
递增持久计数。total_critic_updates += 1；一次 Q1+Q2 联合 learner 迭代只计一次。
条件更新 actor。仅当 total_critic_updates % policy_delay == 0；清 actor 梯度、固定 Q1 参数、反传 \(L_\pi\)、actor optimizer step，再恢复 Q1 状态。
条件更新目标参数。紧随 actor step，用更新后的 actor、Q1、Q2 各做一次 Polyak 更新。
flowchart TD
  A["sample batch"] --> B["no_grad: build target y"]
  B --> C["zero critic grads → backward LQ → critic step"]
  C --> D["total_critic_updates += 1"]
  D --> E{"global count % delay == 0?"}
  E -- no --> A
  E -- yes --> F["freeze Q1 params<br/>zero actor grads"]
  F --> G["backward actor loss → actor step"]
  G --> H["restore Q1 grad flags"]
  H --> I["Polyak update all 3 targets"]
  I --> A

判断发生在 critic step 和全局计数加一之后。计数器必须跨训练函数调用持续存在并写入 checkpoint；不要使用每次局部循环都从 0 开始的索引，否则会在调用边界额外更新 actor。一次 critic update 的定义与 UTD 换算见延迟策略更新页。

4. 联合或分别更新 critic：等价有条件

当 Q1、Q2 参数和计算图完全独立、target 已停止梯度，且没有跨网络全局梯度操作时，对 (L_1+L_2) 一次 backward 与分别 backward 会给每套参数相同的单网络梯度。联合 optimizer 的常见顺序是一次 zero_grad、一次 backward、一次 step。

使用 (L_1+L_2) 或 ((L_1+L_2)/2) 都合法，但必须固定 reduction。对不共享参数的 Q1、Q2，除以 2 会把每套 critic 梯度缩小一半；在 Adam、梯度裁剪和权重衰减存在时，不一定能用简单学习率缩放完全抵消。

若两个 optimizer 且参数完全独立，可以分别执行 zero_grad → backward → step，通常无需 retain_graph=True。若共享 encoder、共享计算图、使用全局 norm clipping 或联合正则项，则不能直接声称等价；应先完成所需 backward 再 step，并明确共享参数的 loss 与 optimizer 所有权，避免同一参数被重复更新。

5. Polyak 方向与实际时间尺度

在延迟 actor 更新后，对三组目标参数执行：

[ \phi’\leftarrow(1-\tau)\phi’+\tau\phi, \qquad \theta’_i\leftarrow(1-\tau)\theta’_i+\tau\theta_i,\quad i=1,2. ]

(\tau=0.005) 表示 target 保留 0.995 的旧值、吸收 0.005 的最新 online 值；不要写反 online 与 target。赋值在 no_grad 下进行，target 参数不属于任何 optimizer。

若每 (d) 个 critic 步才 Polyak 一次，在 online 参数近似固定的理想条件下，每个 critic 步对应的等效系数为

[ \tau_{\mathrm{eff}}=1-(1-\tau)^{1/d}\approx\tau/d. ]

因此比较实现时必须同时报告 (\tau) 与 target 更新频率，不能只比较同名参数。

6. 超参数耦合与基线来源

下表只总结优化层面的耦合；target noise 的单位见目标策略平滑页，delay 与 UTD 的关系见延迟策略更新页。

| 超参数 | 主要作用 | 强耦合对象 | 调整时看什么 | |---|---|---|---| | \(\gamma\) | 有效回报时域 | 控制时间步、终止语义 | target 与 Q 的数值尺度 | | \(\tau\) | 目标跟随速度 | target 更新频率、delay | target-online 参数距离 | | policy delay \(d\) | 策略时间尺度 | UTD、critic LR | 实际 critic/actor 更新比 | | target noise \(\sigma\) | 动作邻域平滑 | 动作单位、\(c\) | 噪声裁剪率、动作边界命中率 | | noise clip \(c\) | 限制单维扰动 | \(\sigma\)、动作范围 | 裁剪率、评估回报 | | actor LR | 策略移动速度 | Q 动作梯度、delay | 动作漂移、tanh 饱和率 | | critic LR | 价值拟合速度 | batch、reward scale、UTD | Q 分位数、Bellman 残差、评估回报 | | batch size | 梯度方差与吞吐 | replay 大小、UTD | 稳定性、样本覆盖、吞吐 |

TD3 论文实验采用 actor/critic Adam 学习率 (10^{-3})；作者当前公开 PyTorch 实现采用 (3\times10^{-4})。两者均使用 (\gamma=0.99)、(\tau=0.005)、delay=2，以及归一化动作尺度下的 target noise=0.2、noise clip=0.5。选择具体基线时必须注明来源，并同时报告网络宽度、batch、动作单位、Adam 的 betas/eps/weight decay 与学习率调度器；这些默认值不是理论常数。

7. Warm-up 与精确续训

随机动作 warm-up、replay 最小容量和无噪声评估属于 DDPG/TD3 共用框架，基础流程见 DDPG。对 TD3 特别重要的是：warm-up 决定双 critic 最初看到的动作覆盖；若过早改用尚未训练的 actor 加小幅探索噪声，数据可能集中在动作空间中部，使两个 critic 形成相似的外推误差。

若要求精确续训，checkpoint 不只保存模型权重，还应保存：

  • 在线/目标网络完整 state dict 与 actor/critic optimizer 状态；
  • replay buffer 或可恢复的内容与写指针；
  • observation/reward normalizer 的统计；
  • 全局环境步、critic/actor/target 更新计数与 modulo 相位；
  • Python、NumPy、框架、环境和 replay 采样器的 RNG 状态；
  • 学习率调度器、AMP GradScaler，以及代码版本或 Git commit。

8. 数值稳定：先证伪逻辑错误

遇到爆炸或 NaN/Inf 时，按因果顺序排查：

  1. reward、动作缩放、terminated/truncated、最终观测和 shape 是否正确；
  2. target 是否停止梯度，两个 Q 是否逐样本取 min；
  3. 学习率、reward scale、初始化与运行统计是否合理；
  4. 再考虑 gradient clipping、Huber loss 或归一化层。

每次 optimizer step 前至少检查 target、Q1/Q2、各 loss 和梯度范数是否 finite，并监控 Q/target 高分位绝对值。若使用 gradient clipping，必须记录阈值、norm 类型，以及分别裁剪 Q1/Q2 还是联合裁剪全部 critic 参数；两者不等价。不要用裁剪掩盖 ([B]) 与 ([B,1]) 广播成 ([B,B]) 之类的逻辑错误。

混合精度边界：大幅 Q、Bellman target 的加法、TD error 平方以及 actor 经 critic 反传的动作梯度都可能受半精度范围和舍入误差影响。先建立 FP32 基线；启用 AMP 后，建议至少用 FP32 计算 target、critic loss reduction 与关键日志统计，并比较 Q/target 分位数、TD error、梯度范数和非有限值计数。两个 Q 很接近时，低精度还可能改变 min 选择。

9. 知识点、创新归因与验收

  • 知识点：target 全程停止梯度；critic step 只更新在线 Q1/Q2；actor step 保留 Q1 的动作梯度但不更新 Q1 参数；三套 target 只在延迟策略步后跟随。
  • 继承部分：MSE critic 回归、确定性策略梯度、经验回放与 Polyak 目标网络来自 DDPG/通用 Actor–Critic。
  • TD3 新增组合：clipped twin-critic target、带扰动的目标动作以及延迟 actor/target 更新被装配到同一迭代时序。创新不在 MSE 或反向传播规则本身，而在误差控制机制的组合。
  • 核心边界：动作表示、全局更新计数、optimizer 参数集合和 no_grad 范围必须同时正确；低 critic 训练 loss 不能证明价值估计正确。
  • 验收标准：实际 critic/actor 更新比正确；target、Q1、Q2 形状一致；目标参数无梯度；评估不含探索噪声；checkpoint 能恢复计数、optimizer、replay 与随机状态。

10. 自测

  1. 为什么 actor step 时可以冻结 Q1 参数，却不能把 Q1 前向放进 no_grad？
  2. 为什么 delay 判断必须使用 critic step 后递增的持久计数？
  3. 为什么 (\tau) 必须和 target 更新频率一起报告？
  4. Q1/Q2 共享 encoder 时，为什么不能直接套用“分别 backward 与联合 backward 等价”？
  5. 哪些错误不应靠 Huber loss 或 gradient clipping 修补？

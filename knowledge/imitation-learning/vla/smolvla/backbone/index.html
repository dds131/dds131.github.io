VLA 模型家族/SmolVLA 总览/主干与多模态 Token

BACKBONE · TOKEN CONTRACT · CACHE BOUNDARY

SmolVLA 的主干让 12 层视觉塔处理 512×512 图像产生 1024 个 patch，再以可逆空间重排和有损 12288→960 投影压成每相机 64 个视觉 token；文本侧只保留 SmolVLM2 前 16/32 层，并把图像、语言与状态组成不可被动作反向改写的 prefix。它降低的是文本侧序列与稳态层数成本，不等于视觉塔只算 64 个 patch，也不保证细粒度控制信息无损。

12 / 12视觉塔层数；全部执行，不受文本层截断影响。
16 / 32连续保留前 16 个文本层；不是动态 early exit。
1024 → 64每个有效相机的视觉位置数。
12288 → 960connector 的有损线性投影瓶颈。
48 + 1语言最大槽位与状态 token 数。
0 runtime evidence只完成静态证据与页面验证，没有加载或运行模型。
paper · Table 8 / 11fixed code · token/mask/cachefixed configs · checkpoint/backbonetheoretical ratio ≠ runtime speedup

先做任务判断，而不是先看“140.3 倍”

四项主干选择的收益与拒绝条件
设计 主要降低 信息或能力代价 更适合 不足以证明
全局图像、关闭 tiling 多 tile 的视觉与序列成本 不显式保留高分辨率 tile 目标在全局 512 视图中仍可辨 小物体与精细定位一定可靠
1024→64 token 文本侧条件序列和注意力项 12288→960 形成有损瓶颈 预算敏感、场景结构较稳定 视觉塔只计算 64 个 patch
文本塔前 16/32 层 稳态参数、后半层前向与 KV Table 8 点估计比 32 层低 1.8 pp 接受经验性能—成本折中 构造阶段从未加载完整 VLM
冻结视觉/VLM 梯度与优化器状态 受既有 VLM 预训练偏置约束 机器人数据与预算有限的适配 冻结模块不再执行前向

决策顺序是：先确认任务需要的物体尺度、遮挡与接触边缘信息能否在全局 512 视图中保留；再判断有损 960 维接口是否可接受；最后才评估 16 层折中与实测系统预算。若任务要求未经验证的 tile 级细节、要求表示严格无损，或唯一依据只是理论注意力比，就不应直接采用该假设。

视觉 Token：512→1024→64→960

公开 checkpoint 声明三路 [3,256,256] 相机特征；这是输入字段规格，不是视觉塔最终执行分辨率。固定 prepare_images 取每路最后一个观测帧，按长宽比缩放并补到 512×512。实际路径调用 resize_with_pad：向左侧和顶部补边，而不是同文件未调用的居中 resize_with_pad_torch。

处理顺序是：输入按 [0,1] → 双线性缩放、align_corners=false → 左/上以 0 补到 512×512 → x*2−1。因此补边像素送入视觉塔时为 −1。若输入已为 512×512，则直接返回，不添加补边。

视觉塔仍处理 1024 个 patch

输入边长 512、patch 边长 16：

\[512\div16=32,\qquad 32\times32=1024.\]

每个 patch 映射为 768 维，经过全部 12 层视觉 Transformer；patch_attention_mask=None，所以补边区域不会在视觉塔入口按 patch 删除。freeze_vision_encoder=true 只冻结参数，不跳过前向，也不把 12 层截成 6 层。

Connector：空间重排可逆，降维投影有损

固定 scale_factor=4。源码沿用 pixel_shuffle 名称，但此处数学方向是 space‑to‑depth/unshuffle：32×32 网格中每个 4×4 邻域的 16 个 768 维向量被重排到通道维：

\[(32/4)^2=8^2=64,\qquad 768\times4^2=12288.\]

随后权重形状 [960,12288] 把 [B,64,12288] 映射到 [B,64,960]。

“所有空间块进入投影”不等于“所有细节被完整保留”。论文没有专门的小目标、遮挡、接触边缘或 tile 开关消融；这些只能登记为后续按目标尺度和遮挡分层的验证维度，不能写成已观察到的失败。

140.3 的限定口径

在两路有效相机、固定 48 个语言槽、1 个状态 token 的教学示例中：

\[S_{raw}=2\times1024+48+1=2097,\qquad S_{compressed}=2\times64+48+1=177,\] \[2097/177\approx11.85,\qquad (2097/177)^2\approx140.3.\]

140.3 只对应文本塔密集注意力 S² 项的理论比例，不包含视觉塔、connector、投影、MLP、内存访问、kernel 调度、cache、动作专家或系统 I/O；它不是端到端速度、总 FLOPs、吞吐、延迟或显存实测。文本层 32→16 也不能与它相乘制造“280 倍”结论。

语言、状态与 prefix_length

tokenizer_max_length=48 是截断上限。类默认 pad_language_to=longest，张量长度取批内最长、最多 48；公开 checkpoint 保存 max_length，固定占 48 槽，短指令在右侧 padding 并由 lang_masks 屏蔽。调大上限不会让短指令内容自动增长。

状态在外部 processor 使用 mean/std 归一化，取最后观测步，尾部补到 32 维，再由 state_proj:32→960 形成 1 个 token。投影统一维度并学习表示，不证明物理量纲已自动正确。

prefix_length 类默认 −1，checkpoint 保存 0。固定代码只在实际序列短于正的 prefix_length 时补齐，因此二者都不触发额外 padding，不会得到零长度 prefix，也不是 Python 负索引切片；更长 prefix 从不被该字段截断。

Mask、位置与 KV Cache

pad_masks 与 att_masks 是两个不同合同：

  • pad_masks[b,i] 表示位置是否有效，同时约束 query 和 key。
  • att_masks[b,i] 表示位置 i 是否开启新块，不是 keep/drop mask。

令 c_i 为 att_masks 到位置 i 的累计和，则允许关系为：

\[c_i=\sum_{k\le i}att\_masks_k,\qquad A_{ij}=pad_i\land pad_j\land(c_j\le c_i).\]

图像与语言的块起点标志为 0，状态为 1。因此图像/语言同块双向可见，不能读取后块状态；状态可以读取图像、语言与自身。该二维允许矩阵不表示每一层都执行同一方阵 self-attention：Action Expert 页将区分 CA 的矩形 query→prefix K/V 与周期性 joint SA。

prefix 内部可见性；有效位仍由 pad mask 独立约束
Query 可读图像/语言 可读状态
图像或语言 是，同块双向 否，不能看后块
状态 是，可读早块 是，可读自身

三种前向的位置编号

训练时 prefix 与 suffix 合并，推理 prefill 时只有 prefix；两者有效 token 都使用 cumsum(pad_masks)-1。padding 位置可能得到 −1 或重复值，但其 query/key 会被 mask 屏蔽。

每个去噪步的 suffix 使用：

\[position^{suffix}=prefix\_offsets+cumsum(suffix\_pad)-1,\]

其中 prefix_offsets=sum(prefix_pad_masks) 是每个样本的有效 prefix 数，不是统一 padded tensor 长度。语言有效长度或相机有效性不同，会使不同样本的动作起始 position 不同；这些位置编号也不是物理控制时间。

inference_prefix: cumulative-valid-count-minus-one
inference_suffix_offset: per-sample-valid-prefix-count
suffix_position: offset-plus-cumulative-valid-suffix-minus-one
padding_positions_may_be_negative_or_repeated: true
padding_positions_are_attention_masked: true
uses_raw_padded_prefix_length_as_offset: false

Cache 的有效范围只有一个固定观测

推理先对当前图像、语言、状态执行 prefix prefill，16 个文本层分别写 K/V。key 在存入前已应用 RoPE，value 不应用 RoPE。每个 Flow 去噪步生成 suffix：CA 读取 prefix cache，周期性 SA 可临时追加 suffix K/V；步结束后 crop(prefix_len) 恢复为 prefix 张量长度。

crop 长度使用 padded prefix tensor length，而 suffix RoPE offset 使用每样本有效 prefix 数；二者用途不同。下一去噪步可以继续复用同一观测的 prefix，但新图像、新语言、新状态或新控制 tick 都必须重新 prefill。cache 不会消除视觉塔和第一次 prefix 前向，也不跨任意观测永久有效。

继承、SmolVLA 选择和验证债

SigLIP-like 视觉塔、SmolLM2 文本解码器、space-to-depth connector 与 modality projection 继承自 SmolVLM2。SmolVLA 的选择是关闭 tiling、仅使用全局图像、连续保留前 16 层、把 64-token 接口用于动作条件、把状态放入新 prefix 块，并向动作专家暴露逐层 cache。Flow Matching、动作分块与异步执行不属于本页的 Backbone 创新。

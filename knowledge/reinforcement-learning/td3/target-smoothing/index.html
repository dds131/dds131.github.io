降低自举目标对动作方向狭窄 Q 峰的依赖

目标策略平滑：构造 Bellman target 时，在目标 actor 的下一动作附近采一个裁剪高斯扰动，再把动作投影到合法范围。每次更新只评价一个扰动动作；经过多样本和多次更新，随机采样才近似形成邻域平均，降低自举目标反复依赖同一狭窄虚高峰的机会。它是隐式 target 正则化，不等同于显式约束整个 Q 曲面平滑。

这一机制不是 SAC 的随机策略，也不是与环境交互的探索噪声。DDPG 的动作缩放与探索基础请看 DDPG；本页只讲 TD3 新增的 target-side 正则化。

1. 完整公式与操作顺序

为避免不同物理动作量纲混淆，本页先在归一化动作空间 \([-1,1]^{d_a}\) 定义平滑。令 \(\mu_{\bar\phi}\) 为目标 actor，\(d_{\text{term}}=1\) 仅表示真正终止：

\[ u'=\mu_{\bar\phi}(s'),\qquad \epsilon\sim\mathcal N(0,\sigma_{\text{targ}}^2 I),\qquad \bar\epsilon=\operatorname{clip}(\epsilon,-c,c), \] \[ \tilde u'=\operatorname{clip}(u'+\bar\epsilon,-1,1), \qquad \tilde a'=b+s\odot\tilde u', \] \[ b=\frac{a_{\max}+a_{\min}}2,\qquad s=\frac{a_{\max}-a_{\min}}2, \] \[ y=r+\gamma(1-d_{\text{term}}) \min_{i=1,2}Q_{\bar\theta_i}(s',\tilde a'). \]

顺序必须是“采样噪声 → 逐元素裁噪声 → 加到归一化动作 → 逐元素裁动作 → 缩放到物理范围”。先采高斯再 clip 得到的是 clipped Gaussian：尾部概率会集中到 \(\pm c\)，并非拒绝采样后重新归一化的严格 truncated Gaussian。若环境动作本来就是 \([-1,1]^{d_a}\)，则 \(\tilde a'=\tilde u'\)。逐坐标裁剪只保证 \(\lvert\bar\epsilon_j\rvert\le c\)，整体 \(\ell_2\) 范数仍可能随动作维数约按 \(\sqrt{d_a}\) 增长。

flowchart LR
  S["下一状态 s'"] --> A["目标 actor"]
  A --> RAW["归一化动作 u∈[-1,1]"]
  E["ε~N(0,σ²)"] --> C["clip(ε,-c,c)"]
  RAW --> PLUS["u + ε̄"]
  C --> PLUS
  PLUS --> B["clip 到 [-1,1]"]
  B --> SCALE["缩放到环境动作范围"]
  SCALE --> Q["Q1', Q2' → min"]

2. 三种动作路径必须分开

环境交互动作
在线 actor 动作加探索噪声，裁剪并缩放后送入环境；用于改变数据覆盖。
Bellman 目标动作
目标 actor 动作加截断 target noise；只在 no-grad 的 target 路径出现，用于邻域正则。
评估动作
通常直接使用在线 actor 的确定性输出，经相同缩放后执行；不添加两类噪声。

三条路径可能都出现“高斯噪声”，但参数和语义不同。把同一个 noise_std 变量复用，常导致调探索时意外改变 target 正则强度。

3. 平滑究竟在逼近什么

每次 TD3 更新只采一个噪声样本；经过多次独立采样后，Bellman target 的期望包含一个邻域平均。忽略动作边界并固定 \(s',u'\) 时，可写成

\[ \bar Q_{\min}(s',u') = \mathbb E_{\epsilon} \left[ \min_i Q_{\bar\theta_i} \left(s',\,b+s\odot(u'+\bar\epsilon)\right) \right]. \]

因此，若一个动作只在极窄位置被错误估高、相邻动作估值普通，它在多次 target 采样中的影响会被削弱。actor loss 本身仍读取未加 target noise 的在线 Q1；它受到平滑的影响是间接的——在线 critic 正在拟合这些平滑过的自举目标。

为给出局部直觉，定义 \(F(u)=Q(s',b+s\odot u)\)，暂时忽略 twin-Q 的 min，并假设 \(F\) 二阶可微。令有效归一化扰动的均值为 \(m\)、协方差为 \(\Sigma\)，则

\[ \mathbb E[F(u+\delta)] \approx F(u)+\nabla_uF(u)^\top m +\frac12\operatorname{tr} \left(\nabla_u^2F(u)\,\Sigma\right). \]

远离动作边界时，裁剪高斯仍关于零对称，故 \(m=0\)；尖锐局部最大值处 Hessian 通常含较大的负特征值，邻域平均因而低于峰顶。在局部最小值处二阶项反而可能为正，所以这不是对“一切高曲率”的惩罚。接近边界时动作投影使 \(m\ne0\)，一阶项也会出现。该展开只是小扰动直觉，不等于显式 Hessian 正则、对抗式最坏情况优化或部署鲁棒性保证。

4. 动作单位：最常见的隐藏问题

论文常用 policy_noise=0.2、noise_clip=0.5；作者代码会按 max_action 缩放这些相对尺度。因此 0.2 和 0.5 应理解为相对动作范围的基线，而不是任意环境都通用的物理单位。若环境某维动作范围是 \([-100,100]\)，直接在物理单位上加 0.2 几乎没有平滑；若范围是 \([-0.01,0.01]\)，则会完全撞边界。

推荐在归一化空间工作：

\[ u=\tanh(z)\in[-1,1],\qquad a=b+s\odot u, \] \[ b=\frac{a_{\max}+a_{\min}}{2},\qquad s=\frac{a_{\max}-a_{\min}}{2}. \]

推荐在 \(u\) 空间定义并裁剪 target noise。若 critic 与 replay 存物理动作，再仿射缩放后送 critic；若整个学习管线统一存归一化动作，critic 可直接接收 \(u\)，只在 env.step 前缩放。关键是 replay action、actor output、target noise 与 critic input 使用同一坐标系。

例如两个动作维的范围分别是 \([-2,2]\) 与 \([-100,100]\)，归一化噪声标准差 0.2 对应物理标准差 0.4 与 20。若两维都直接加物理噪声 0.2，相对半范围分别为 10% 与 0.2%，平滑强度相差 50 倍。

5. 边界会改变噪声分布

接近动作上界时，正向扰动更容易被裁到边界，负向扰动仍可向内部移动；执行后的扰动分布因此不再零均值，并产生向可行域内部的偏置。这是盒约束与裁剪带来的统计效应，不应直接解释成“更安全”。需要注意：

  • actor 若长期饱和，target 平滑近似不再对称；
  • 多数 target 动作被 clip，说明 \(\sigma_{\text{targ}}\) 可能相对范围过大；
  • 环境最优动作确实在边界时，过强平滑会低估它。

建议分别记录 target_noise_clip_fraction（原始噪声超出 \([-c,c]\) 的比例）、target_action_projection_fraction（加噪动作被投影到边界的比例）、每维有效扰动的均值/标准差，以及 actor 本身的边界命中率；否则无法区分“噪声过大”和“策略本来就在边界”。

6. 参数怎样调

| 参数 | 过小 | 合理现象 | 过大 | |---|---|---|---| | \(\sigma_{\text{targ}}\) | 邻域约束很弱 | 局部敏感度降低且评估性能未受明显拖累 | 邻域过宽，真实窄最优可能被抹平 | | \(c\) | 大量尾部被压到很窄范围，实际扰动弱于设定 \(\sigma\) | 限制高斯尾部的极端扰动 | 远大于 \(\sigma\) 时几乎不起裁剪作用 |

标准基线可从归一化空间 \(\sigma=0.2,c=0.5\) 起步，但必须结合动作维数、环境灵敏度和 clip 比例验证，不是普适常数。

7. 与 SAC 随机性的差别

项目 TD3 目标平滑 SAC 随机策略
随机性位置 只用于 target 动作 策略本身是分布
actor 输出 确定性动作 动作分布参数
目标函数 无熵项 含 \(-\alpha\log\pi\)
评估常见做法 直接 actor 输出 常取分布参数均值经 squashing 后的确定性动作；它不一定等于变换后分布的严格期望
主要目的 抑制 Q 动作尖峰 探索与最大熵优化

SAC 细节请直接看 最大熵与 Soft 策略迭代，这里不重复推导。

8. 消融与故障定位

可做三组受控实验：

  1. \(\sigma_{\text{targ}}=0\)：移除目标平滑，其他机制不变；
  2. 保留噪声但移除 noise clip：观察极端 target 和动作边界命中率；
  3. 保留平滑但改变探索噪声：验证两种噪声是否在代码中真正解耦。

若只改变探索噪声就显著影响性能，这是“数据覆盖可能是重要因素”的证据；若只移除 target noise 后局部 Q 敏感度、Q 高分位数和崩溃率上升，则支持“目标动作邻域脆弱性较重要”的假设。单次性能变化不能证明唯一主因，应跨多个 seed，并保持训练预算、评估协议和其他噪声不变。

实现审计：target noise 必须在 no_grad 区域为每个样本、每个动作维度独立采样，张量形状通常为 [batch_size, action_dim]，device 与 dtype 必须和目标动作一致。两个目标 critic 必须评价同一个带噪动作，不能各采一份噪声；也不能把 target noise 加到 replay 当前动作、环境探索或确定性评估路径。

9. 重点与创新点

  • 知识点：目标策略平滑只改变 Bellman target 中的下一动作，不直接改变 replay 当前动作、actor loss 或确定性评估动作。
  • 核心重点：每次更新通常只采一个扰动动作，邻域平均是跨样本和多次更新形成的 Monte Carlo 效果。
  • 创新点：TD3 把裁剪随机扰动用于确定性 Actor–Critic 的自举路径，并与双 Q、延迟更新组合；这是平均意义下的 target-side 正则，不是“给动作加噪声”这一一般思想的首次出现，也不是最坏情况鲁棒优化。
  • 边界：真实最优解若要求精确窄动作，过强平滑可能伤害性能；动作边界还会使有效扰动产生状态依赖偏差。
  • 工程关键：统一动作坐标；优先在归一化空间定义噪声，或逐维换算到物理单位；分别监控 noise clipping、action projection 与 actor 边界饱和。
  • 与前两机制协同：双 Q 控制价值聚合，延迟更新控制时间尺度，本页控制动作邻域尺度。

SmolVLA 的动作专家不直接输出一个确定动作，而是学习一个条件速度场，在推理时把高斯噪声逐步变换成动作块。本页沿用 LeRobot 源码的时间变量 \(t\)，依次说明：单点回归为何难以表示多峰动作分布、条件 Flow Matching 的监督目标如何得到、训练目标为何按增大 \(t\) 的方向定义而推理沿减小 \(t\) 的方向积分、Beta 时间采样实际改变了什么，以及哪些设计继承自 π0、哪些才是 SmolVLA 的贡献。

网络结构见① 主干与② 动作专家，推理期的积分迭代见⑥ 推理、动作块与异步执行，代码逐行对照见⑤ 官方源码剖析。

复核基线。论文公式与消融按 arXiv v1（2506.01844v1）核对；实现细节按 LeRobot 提交 8c920c4 与公开 lerobot/smolvla_base 配置修订 d9f33c9 核对，日期为 2026-10-05。后续源码可能改变采样、归约或推理路径，因此本页涉及“固定实现”的判断均限定在这组版本。

一、为什么不直接回归动作

1.1 单点估计无法完整表示多峰分布

行为克隆常用 L1 或 L2 损失回归动作。它们并不预先假设「正确动作只有一个」，但模型每次前向传播只给出一个点估计：L2 的总体最优解是条件均值，逐元素 L1 的总体最优解是逐维条件中位数（可能不唯一）。因此，当同一观测对应多种有效策略时，单点回归无法保存完整的条件分布 \(p(A\mid o)\)。

例如，机械臂既可以从障碍物左侧绕行，也可以从右侧绕行。在一个近似对称的双峰示例中，L2 解为：

\[a_{\text{pred}}^{\star} = \mathbb{E}\!\left[A \mid o\right] \approx \frac{a_{\text{左}} + a_{\text{右}}}{2}\]

这个均值可能既不像左绕也不像右绕，甚至穿过障碍物。这里的「落在两个模式之间」是双峰示例中的风险，而不是所有多峰分布的必然结论；L1 中位数也未必总在低密度区。Flow Matching 的目标是学习一个可由随机初态经 ODE 采样的条件生成模型，而不是把所有有效策略压成一个代表值；有限数据、有限容量和训练误差仍可能导致模式遗漏或概率失准。

1.2 论文数据

训练目标 Spatial Object Goal Long 平均
Flow Matching（采用） 89 94 85 53 80.25
L1 回归 92 85 86 38 75.25

该次实验中 Flow Matching 的平均分高 5 个百分点，但各组趋势并不一致：Spatial 为 −3、Object 为 +9、Goal 为 −1、Long 为 +15。优势主要来自 Object 与 Long，而 L1 在 Spatial 与 Goal 上略高。论文据此提出 Flow Matching 对复杂、多峰动作分布可能具有更合适的归纳偏置；这张表比较的是最终成功率，并未直接测量分布是否多峰或模式覆盖是否改善。

不过，表中没有给出多随机种子方差，也没有直接测量各任务的模态数量。因此，「Long 提升较大是因为路径分叉更多」只能作为可能解释；长时序误差累积和任务难度也可能造成同样现象，不能由这张表单独确定因果关系。

1.3 连续流与离散动作 token 的取舍

把动作离散化后做分类同样能够表示多峰分布，OpenVLA 是代表性方案。两条路线的差别应理解为表示与解码方式的取舍，而不是「离散方法不能建模多峰」。

  • 表示精度：标量分桶存在有限的数值分辨率；训练可以优化分桶预测，却不能突破既定表示的粒度。学习式动作 tokenizer 的性质则取决于其码本与解码器。
  • 序列与计算量：若每个动作维度对应一个 token，序列长度主要随动作维数和预测 horizon 增长；增加分桶数通常扩大词表，而不会直接增加 token 数量。
  • 输出接口：Flow Matching 直接在连续动作空间生成整个动作块；逐 token 自回归方案通常还需要离散编码、顺序解码和反量化。

SmolVLA 论文采用连续 Flow Matching，但没有通过同一架构下的离散 tokenizer 对照实验逐项证明上述取舍，因此这里不把它们写成作者已经验证的选型原因。

二、条件 Flow Matching：监督信号从哪里来

2.1 先固定源码约定

设观测条件为 \(o\)，归一化后的真实动作块为 \(A\sim p_{\mathrm{data}}(A\mid o)\)，独立高斯噪声为 \(\epsilon\sim\mathcal N(0,I)\)。本页从这里开始统一使用 LeRobot 源码变量 \(t\)：

\[X_t=(1-t)A+t\epsilon,\qquad t\in[0,1].\]

因此，\(t=0\) 是动作端，\(t=1\) 是噪声端。对固定配对 \((A,\epsilon)\) 求导得到样本级目标速度：

\[U=\frac{\mathrm dX_t}{\mathrm dt}=\epsilon-A.\]

它对这个固定配对而言不随 \(X_t\) 或 \(t\) 变化。这是训练时可以直接计算的监督信号。

2.2 样本级速度与边缘速度场不是一回事

推理时模型只看到 \((X_t,t,o)\)，看不到产生当前中间状态的真实 \(A\) 与噪声 \(\epsilon\)。因此它需要学习的不是某一条配对路径的 \(U\)，而是给定当前状态后所有可能配对速度的条件期望：

\[v^*(x,t,o) = \mathbb E\!\left[ \epsilon-A \mid X_t=x,\,t,\,o \right].\]

这就是平方损失下的总体最优预测，也是相应条件概率路径的边缘速度场。这里的条件不能省略：在给定 \(X_t=x\) 后，\(\epsilon\) 一般不再是零均值，所以不能把这一步解释成「噪声项在平均中消失」。

在相应密度为正、并允许交换微分与积分等常规条件下，条件 Flow Matching 与直接匹配边缘速度场具有相同的期望参数梯度，等价地说，两种总体目标只相差与模型参数无关的项。实际训练仍使用有限批次对这个期望作随机估计，并不意味着每个批次的梯度完全相同。

这个结论可以直接从平方损失分解看出。令 \(Z=(X_t,t,o)\)、\(U=\epsilon-A\)，记 \(v^*(Z)=\mathbb E[U\mid Z]\)，并把原始回归风险 \(\mathbb E[\lVert v_\theta(Z)-U\rVert_2^2]\) 记为 \(\mathcal R(\theta)\)，则

\[\begin{aligned} \mathcal R(\theta) &= \mathbb E\!\left[\lVert v_\theta(Z)-v^*(Z)\rVert_2^2\right]+C,\\ C &= \mathbb E\!\left[\lVert U-v^*(Z)\rVert_2^2\right]. \end{aligned}\]

第二项不含 \(\theta\)；交叉项因 \(\mathbb E[U-v^*(Z)\mid Z]=0\) 而消失。因此模型并不是要从同一个 \(x\) 恢复某个唯一的配对噪声，而是在回归所有可能配对速度的条件均值。

把独立采样的 \(A\) 与 \(\epsilon\) 经线性插值得到的条件密度记为 \(p_t(x\mid o)\)。上述边缘速度场满足连续性方程

\[\frac{\partial p_t(x\mid o)}{\partial t} + \nabla_x\!\cdot\!\bigl(p_t(x\mid o)v^*(x,t,o)\bigr)=0,\]

其端点是 \(p_0(\cdot\mid o)=p_{\mathrm{data}}(\cdot\mid o)\) 与 \(p_1=\mathcal N(0,I)\)。推理沿反方向积分同一个场，才把噪声分布运输回条件动作分布；仅有逐样本直线插值，还不足以说明生成分布为何正确。

2.3 直线的是条件路径，不一定是生成轨迹

线性插值的优点是样本级目标 \(U=\epsilon-A\) 简洁、无需额外构造扩散方差日程。但必须区分：

  • 固定 \((A,\epsilon)\) 的条件路径是直线，目标速度为常量；
  • 模型学习的边缘场 \(v_\theta(x,t,o)\) 汇总了许多可能配对，通常仍随 \(x,t,o\) 变化；
  • 沿学得速度场积分得到的生成轨迹不必是直线。

速度网络在给定 \((x,t,o)\) 后是确定的，但生成器仍然可以是随机的：随机性来自初始样本 \(x^{(0)}=\epsilon\)。固定同一观测和同一初始噪声时，确定性 ODE 求解器给出同一结果；更换初始噪声才会得到另一条候选动作轨迹。因此“确定性速度场”和“可表示条件分布”并不矛盾。

默认 10 步 Euler 积分是效率与近似精度之间的工程选择，而不是由直线插值保证的精确解。更高阶求解器或更多步数仍可能降低数值误差，只是会增加推理成本。

三、SmolVLA 的训练目标与张量语义

3.1 训练样本的构造

LeRobot 对一个批次采样 \(t\) 和 \(\epsilon\)，然后计算：

\[X_t=t\epsilon+(1-t)A, \qquad U=\epsilon-A.\]

注意：训练监督的箭头随 \(t\) 增大指向噪声端；推理则从 \(t=1\) 向 \(t=0\) 以负步长积分，所以二者方向相反但并不矛盾。

3.2 条件速度的均方误差

\[\mathcal L(\theta) = \mathbb E_{o,A,\epsilon,t} \left[ \left\| v_\theta(X_t,t,o)-(\epsilon-A) \right\|_2^2 \right].\]
符号 含义与典型形状
\(A\) 归一化后的真实动作块，\([B,H,D_{\max}]\)；默认 \(H=50\)，不足最大动作维数的部分补零
\(\epsilon\) 与 \(A\) 同形状的独立标准高斯噪声
\(t\) 每个样本一个 Flow 时刻，形状 \([B]\)；它不是动作块内部的物理时间步
\(X_t\) 模型实际接收的含噪动作块，形状与 \(A\) 相同
\(U\) 样本级监督速度 \(\epsilon-A\)
\(o\) 图像、语言和本体状态形成的条件；训练时作为层对齐的条件表示参与前向计算，推理时不变的 prefix K/V 可以缓存复用
\(v_\theta\) 动作专家预测的速度，形状与动作块相同

默认配置中参与训练的参数范围见④ 训练配方。这里的公式只定义 Flow 损失，不应据此推断所有主干参数都被冻结或都被更新。

3.3 有效元素归约与梯度

modeling_smolvla.py 先用 reduction="none" 计算逐元素平方误差；策略包装层再裁到机器人真实动作维数，用 action_is_pad 将越过 episode 末尾的整步损失置零，并以“有效时间步数 × 真实动作维数”为分母。设有效标量元素数为 \(N_{\mathrm{valid}}\)，则

\[\mathcal L = \frac{1}{N_{\mathrm{valid}}} \sum_{i\in\mathrm{valid}} (v_i-U_i)^2, \qquad \frac{\partial\mathcal L}{\partial v_i} = \frac{2}{N_{\mathrm{valid}}}(v_i-U_i).\]

所以，在默认标量归约路径中，真实动作维以外的输出和 episode 末尾无效步都没有直接损失梯度。这里还必须区分两种 padding：

  • 动作维 padding：干净动作 \(A\) 在特征轴补零到 32 维，但噪声 \(\epsilon\) 仍按完整 32 维采样，所以补齐坐标的模型输入实际是 \(X_{t,\mathrm{pad}}=t\epsilon_{\mathrm{pad}}\)，并非始终为零。action_in_proj 会读取这些随机坐标；策略外层只是在计算损失和返回动作时裁掉相应输出。因此“没有直接监督”不等于“没有进入网络”，这些坐标构成额外随机输入；模型是否会利用或忽略它们，论文没有对此做消融。
  • episode 时间步 padding：action_is_pad 只作用于逐元素 MSE 的外层归约。送入动作专家的 suffix mask 仍把固定 \(H\) 个动作槽位标为有效，所以末尾 padding 槽仍会完成前向计算。在当前因果动作掩码下，这些位于末尾的槽不能反向影响更早的有效动作槽，但它们自身可以读取此前动作；不能把“损失被屏蔽”改写成“该 token 已从网络中删除”。

每次重采 \(t\) 与 \(\epsilon\)，是在对 CFM 期望做 Monte Carlo 估计，使同一示范在训练过程中覆盖不同插值状态；它比“数据增广”更准确。该随机覆盖有助于估计整体速度场，但不能从理论上排除模型记忆训练数据。

3.4 推理为何使用负步长

推理从 \(x^{(0)}\sim\mathcal N(0,I)\) 开始，并令代码时间 \(t_0=1\)。默认配置用 \(N=10\) 步 Euler 法：

\[\Delta t=-\frac{1}{N}, \qquad x^{(k+1)} = x^{(k)}+\Delta t\, v_\theta(x^{(k)},t_k,o), \qquad t_k=1+ k\Delta t.\]

训练目标 \(U=\epsilon-A\) 定义的是随 \(t\) 增大、由动作指向噪声的速度；乘上负的 \(\Delta t\) 后，推理更新自然由噪声指向动作。这里没有符号矛盾。10 步是默认配置，不是 Flow Matching 理论规定的常数。

默认 \(N=10\) 时，网络实际在 \(t_k=1.0,0.9,\ldots,0.1\) 这 10 个时刻被调用；最后一次更新把状态推进到 \(t=0\)，但不会再在 \(t=0\) 评估一次速度。区分“速度评估节点”和“更新后的终点”有助于判断训练时刻覆盖与推理节点是否一致。

四、论文公式与源码时间约定

这是本页最需要防止符号误读的地方。下面把论文变量记为 \(\tau_{\mathrm p}\)，把 LeRobot 源码变量保留为 \(t\)。

4.1 论文正文的两式相差一个负号

SmolVLA 论文第 3.1 节写为：

\[A^{\tau_{\mathrm p}} = \tau_{\mathrm p}A + (1-\tau_{\mathrm p})\epsilon, \qquad u(A^{\tau_{\mathrm p}}\mid A)=\epsilon-A.\]

但对左式求导得到：

\[\frac{\mathrm d A^{\tau_{\mathrm p}}}{\mathrm d\tau_{\mathrm p}} = A-\epsilon,\]

它与论文给出的速度目标符号相反。因此，插值式、速度符号和积分方向中至少有一项没有使用同一套约定。

4.2 LeRobot 实现内部自洽

当前源码直接构造：

x_t = time_expanded * noise + (1 - time_expanded) * actions
u_t = noise - actions

即

\[X_t=t\epsilon+(1-t)A, \qquad \frac{\mathrm dX_t}{\mathrm dt}=\epsilon-A.\]

推理代码从 \(t=1\) 的高斯噪声出发，并用负步长积分到 \(t=0\)，与这套公式完全一致。本页所有训练、采样和图示均采用这套源码约定。

4.3 换元时必须同时改变速度符号

令

\[\tau_{\mathrm p}=1-t,\]

论文插值与源码插值经过换元后可以表示同一组路径位置；但时间方向反转，所以

\[\frac{\mathrm dX}{\mathrm d\tau_{\mathrm p}} = A-\epsilon = -\frac{\mathrm dX}{\mathrm dt}.\]

因此不能只把 \(\tau_{\mathrm p}\) 政名为 \(t\)，然后继续沿用同一个速度符号。

可以确定的结论：论文展示的插值式和速度目标在同一个时间方向下不自洽；仅凭论文正文不能唯一判定究竟应修正插值式、速度符号还是积分方向。固定提交中的 LeRobot 实现使用了一套内部自洽的约定，复现时应明确记录并整套采用，不能混用两套符号。

同类问题的进一步讨论见 π0 · 时间方向约定与推理期现象。处理此类差异时，应分别检查路径端点、导数符号和实际积分方向，而不是笼统地断言论文或代码必然正确。

五、Beta 时间采样：分布事实与证据边界

5.1 源码实际采样什么

实现先采样

\[s\sim\mathrm{Beta}(1.5,1.0),\]

再作仿射变换：

\[t=0.999s+0.001.\]

这与当前 LeRobot/OpenPI 风格的配置一致。连续 Beta 随机变量以概率 1 落在 \((0,1)\)，所以变换后的 \(t\) 也以概率 1 落在 \((0.001,1)\)；若使用拓扑意义上的分布支持（支持闭包），对应闭区间分别是 \([0,1]\) 与 \([0.001,1]\)。有限精度采样是否可能返回端点，则由具体实现决定。

5.2 它确实偏向噪声端

对基础变量 \(s\)，归一化密度和累积分布分别是：

\[p(s)=1.5\sqrt{s}, \qquad F(s)=s^{1.5}.\]

密度随 \(s\) 单调增加。因为 \(t\) 是 \(s\) 的递增仿射变换，而且源码约定 \(t=1\) 为噪声端，所以训练样本更偏向噪声侧。下表的区间与概率均指变换前的 \(s\)：

\(s\) 的区间 概率 均匀采样作为参照
\([0,0.25]\) 12.5% 25%
\((0.25,0.5]\) 22.9% 25%
\((0.5,0.75]\) 29.6% 25%
\((0.75,1]\) 35.0% 25%

于是

\[P(s>0.5) = 1-0.5^{1.5} \approx64.6\%.\]

期望值也能量化这种偏置：

\[\mathbb E[s] =\frac{1.5}{1.5+1} =0.6, \qquad \mathbb E[t]=0.999\times0.6+0.001=0.6004.\]

最靠近高值端四分之一区间的采样质量约为低值端四分之一区间的 2.8 倍。仿射变换会平移并缩放支持区间，但不改变这种相对偏置；这些统计量只描述训练时刻的权重分配，不直接证明高 \(t\) 样本更难或更重要。

5.3 可以确认什么，不能确认什么

可以从源码直接确认的是：训练更频繁地监督高 \(t\)、也就是更靠近噪声端的状态。结合第 2.2 节的平方损失分解还可以得到一个重要限定：在无限数据、无限容量且时刻密度为正的理想条件下，改变 \(p(t)\) 不会改变某个固定 \((x,t,o)\) 处的逐点最优场 \(v^*(x,t,o)\)；它改变的是不同时刻对总体风险、随机梯度方差以及有限容量模型折中的相对权重。

一个合理但尚未被本页证据验证的直觉是，高噪声状态离最终动作较远，速度估计更困难，因此值得分配更多样本。

但不能仅凭采样公式推出「起点误差必然被每一步放大」。ODE 误差会传播、衰减还是放大，取决于学得速度场的局部 Jacobian 和数值积分稳定性。SmolVLA 论文也没有在此处提供 uniform sampling 对照或机制实验，所以不能断言均匀采样一定造成动作幅度偏移。

阅读原则：Beta 参数与采样偏向是源码事实；「为什么这样更好」目前主要是设计直觉。若要建立因果结论，需要在相同模型与训练预算下比较均匀采样和不同 Beta 参数，并报告多随机种子结果。

5.4 0.999 与 0.001 的作用

仿射变换使采样避开精确的数据端点 \(t=0\)，同时保留向高值端偏斜的形状。需要避免两种错误解释：

  • \(t=0\) 时虽然 \(X_0=A\)，监督目标 \(\epsilon-A\) 通常仍非零，所以该样本并非「没有学习信号」；
  • 当前这段路径构造没有对 \(t\) 取对数或除以 \(t\)，不能把偏移量解释成在这里防止某个已知除零错误。

源码和论文没有明确说明为什么恰好选择 0.999 与 0.001。最稳妥的写法是陈述其数值效果和沿用关系，不虚构未记录的数值稳定性原因。

还要注意一个边界细节：连续训练分布以概率 1 不会恰好采到 \(t=1\)，而默认推理第一次速度评估恰好在 \(t=1\)。不过训练支持的闭包包含 1，样本可以任意接近该端点，并不存在一个正长度的未训练区间；现有论文也没有证明这项边界差异造成性能问题。另一方面，默认推理最低只在 \(t=0.1\) 评估速度，更新后直接到达 0，因此训练下界 0.001 并不会形成默认 Euler 节点上的空档。

六、Flow 时刻如何进入网络

SmolVLA 把速度场实现为显式依赖时间的非自治条件场 \(v_\theta(X_t,t,o)\)。同一个数值状态 \(x\) 在不同时间可能对应不同的条件后验和不同速度；若不给模型时间信息，平方损失会把这些跨时间目标混合。对这条概率路径而言，显式时间条件是合理且通常必要的设计，但不能据此断言所有可能的生成流在数学上都必须使用非自治场。

当前 SmolVLA 实现分三步注入时间：

源码步骤 可以确认的作用
正弦/余弦编码 把每个样本的标量 \(t\) 映射成多频率向量；默认 min_period=4e-3、max_period=4.0 定义使用的周期范围
与动作嵌入拼接 让后续映射同时读取当前含噪动作特征和 Flow 时刻
两层线性映射与 SiLU 把拼接后的特征投影回动作专家隐藏维，得到送入专家的动作 token 表示

固定配置的专家隐藏维为 \(d_e=720\)，因此源码构造 360 个按对数间隔排列的周期。若 \(j=0,\ldots,359\)，则

\[\begin{aligned} P_j &= 0.004\left(\frac{4.0}{0.004}\right)^{j/359},\\ e_j^{\sin}(t) &= \sin(2\pi t/P_j),\\ e_j^{\cos}(t) &= \cos(2\pi t/P_j). \end{aligned}\]

源码把 \(e_0^{\sin},\ldots,e_{359}^{\sin}\) 与 \(e_0^{\cos},\ldots,e_{359}^{\cos}\) 依次拼接成 720 维向量。每个样本只有一个 \(t\)，其 720 维编码会广播到 50 个动作位置；动作块内部的位置差异另由 RoPE 表达。多频率编码使相近时刻具有连续但可区分的表示，构造上与 Transformer 的正弦位置编码同源，但两者承担的语义不同。

源码能够证明网络使用了上述编码与 MLP，但不能单独证明「标量一定会被高维特征淹没」、该方案一定比逐层调制更省参数，或配置错误必然表现为某一种动作幅度问题。这些可以作为设计直觉或诊断假说，不能写成已验证结论。

七、与 π0 的关系：继承了什么，创新在哪里

SmolVLA 明确沿用了 π0 风格的连续动作生成路线。下表左列指原始 π0 论文及 SmolVLA/LeRobot 明示沿用的 OpenPI 实现口径，右列指本页固定提交中的 SmolVLA 默认配置；它不是对 π0、π0.5 或 SmolVLA 所有未来版本的概括。

7.1 不是 SmolVLA 新提出的部分

线性随机插值、速度回归目标、Beta 时间采样、正弦时间条件和 Euler 采样都建立在 Flow Matching/π0 路线之上。理解这些数学时可以参考 π0，但这不代表 π0 与 SmolVLA 的网络结构、注意力掩码和条件注入实现完全等价。

7.2 SmolVLA 的主要贡献边界

SmolVLA 论文与系统实现所主张的重点不是提出新的 Flow Matching 方程，而是把这套连续动作生成机制放进更低成本的 VLA 系统，包括：

  • 轻量视觉语言骨干与层截断，并复用 SmolVLM2 已有的视觉 token 压缩机制；
  • 更窄的动作专家，以及 cross-attention/因果 self-attention 的交错结构；
  • 面向低算力训练与部署的整体设计；
  • 异步推理栈，以及论文任务中减少动作块边界等待的系统结果。

这些贡献分别涉及模型结构、计算效率和执行系统；不能把它们笼统归功于 Flow Matching，也不能把继承自 π0 的采样公式称为 SmolVLA 的数学创新。

八、本页要点回顾

单点回归的限制 L2 与 L1 分别给出条件均值和中位数。它们能预测一个代表动作，却不能完整保存多峰条件动作分布。

CFM 的核心 样本级目标是 \(\epsilon-A\)；模型的总体最优输出是给定 \(X_t,t,o\) 后该目标的条件期望，而不是靠噪声「自动平均为零」。

直线路径的边界 固定数据—噪声配对的路径是直线；边缘速度场和实际生成轨迹仍可能弯曲，Euler 步数仍是工程权衡。

时间方向 源码用 \(t=1\) 表示噪声并以负步长积分。论文展示的插值式与速度目标差一个负号；换元时必须同时反转速度符号。

Beta 采样 约 64.6% 的基础采样落在 \(s>0.5\)，变换后 \(\mathbb E[t]=0.6004\)。它改变有限训练对各时刻的权重；理想逐点速度目标不变，具体收益机制仍需对照实验支持。

创新边界 Flow Matching 数学主要继承自既有路线；SmolVLA 的贡献集中在小模型结构、计算降本与异步执行。

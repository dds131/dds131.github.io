OBSERVATION · HYPOTHESIS · FALSIFIER · FIRST DIVERGENCE

反常现象不是机制结论：本页把论文观察、作者解释、静态复算和候选假设分层，为每个可争议解释给出可观察的 falsifier、first divergence 与不越过当前授权边界的最小测试；确定性数学冲突则交给静态裁决。

8 cases中间层、handover、规模/表冲突、逐任务、基线例外、神经轨迹、标签翻转、论文/源码差异。
≥2除确定性数学或制品核对外，每张诊断卡至少两个竞争假设。
D0当前只完成静态规格与算术，未开始新实验。
0 runtime不运行训练、推理、评测、仿真、SIL/HIL 或机器人。

证据阶梯与统一诊断流程

证据级别依次是 observed、author-explanation、derived、hypothesis、unsupported。因果词需要受控反事实，统计词需要不确定性；作者解释不等于已验证原因，单案例不等于总体规律，系统差值不等于组件效果，页尾免责声明也不能修复正文过度断言。

flowchart LR
  O[observation + exact scope] --> E[evidence label]
  E --> H[competing hypotheses]
  H --> P[discriminating prediction]
  P --> F[falsifier]
  F --> D[first divergence]
  D --> T[minimum safe test]
  T --> C[evidence ceiling]

每张卡固定 observation ID、scope/protocol、direct evidence、author explanation、至少两个 competing hypotheses、各自 prediction/falsifier、first divergence、minimum safe test 与 evidence ceiling。first divergence 按数据切片→制品→离线输出→动作块→命令队列→执行轨迹→结果逐层寻找；数学恒等式或论文表冲突进入静态核对支路，不强造运行机制。

现象一：中间层读取更快且结果更高

论文观察是从中间层读取带来更快推理与更高策略成功率，但没有公开数值曲线。固定发布 config 选择第12层；实现把 lm_head 换为 Identity，从24层物理 pop(-1) 到12层，再读取截断模型的 hidden_states[-1]。删除后12层可解释少算力；成功率机制仍 unresolved，不能写成“第12层全局最优”。

同一观察的四种可区分解释
假设 预测 falsifier
representation match held-out action probe 在所选深度附近最优 matched probe 与policy均不偏好中间深度
optimization / regularization 冻结或容量匹配adapter会改变增益 匹配优化与接口后增益仍不变
compute budget 等延迟/参数时速度优势保留而成功率优势消失 等预算仍保留成功率增益
backbone specific 不同backbone/任务偏好不同相对深度 多backbone/任务都由同相对深度获胜

first divergence 是 vl-feature-at-action-interface；最小测试是固定动作头协议的 offline layer sweep。当前状态 hypotheses-unranked，不运行该测试。

现象二：预训练 handover 成功、后训练失败

指令是 red apple→basket，物体位于左侧；预训练 checkpoint 完成左抓→交右→入篮，后训练 checkpoint 失败。repeat count、paired success rate 与 smoothness metric 均未报告。作者解释是后训练数据只含右手、没有换手；现有证据只支持 compatible-with-forgetting-not-diagnostic，不构成灾难性遗忘确诊。

从策略选择到接触状态的首次分歧
假设 预测 falsifier
capability forgetting post-training后预训练回归套件系统性下降 matched-seed paired suite无系统性下降
scene/perception variance 分歧始于观测或接触状态 重放相同观测仍在接触前分歧
sampling variance 重复rollout分布跨checkpoint重叠 足量配对rollout稳定分离
handedness prior narrowing 接触前动作计划已偏向右手 matched scene中动作侧选择仍平衡

first divergence 是 policy chunk 的手侧选择与 pre-contact trajectory；最小安全测试限于 offline regression replay 和 simulation paired rollouts。data replay、左右手平衡数据、freezing、regularization 都只是待测缓解方案。

现象三：规模曲线与 DexMG 表间冲突

Table 4 的 N1−DP 差为 RoboCasa [2.7,6.5,6.4]、DexMG [5.9,11.6,5.8]、GR‑1 [21.9,17.3,8.9]；仅GR‑1三个测点单调下降。Table 2/4的DexMG 100-demo分别为DP/N1 56.1/66.5 与 46.9/58.5，差9.2/8.0 pp；原因 not-reported。系统差不能改名为纯预训练效果。

曲线形状与表冲突必须分开诊断
假设 区分性预测 falsifier
floor effect 只看可达任务后差值扩大 远离score floor仍保留同曲线
subset coverage 匹配任务组成会改变曲线 nested matched subsets仍保持曲线
checkpoint selection noise last-5 max跨seed不稳定 重复seed与固定选点仍保持形状
system budget interaction 组件呈现不同learning curve 同架构pretrain control已解释差值

表冲突的候选解释仅列为 different runs、different aggregation、version drift、transcription；first divergence 在 paper-table-artifact，应先做论文源表对账，再考虑nested subset或重复离线训练协议。当前状态是 curve mechanism unranked、table cause unresolved。

现象四与五：逐任务非单调、特殊计分和初始不动

Dark Cabinet 从86.6到69.7，Δ=−16.9 pp；Wooden Chest从72.9到63.2，Δ=−9.7 pp；White Drawer从26.4到79.9，Δ=+53.5 pp。三项显示差均值8.9667 pp，对应类别显示62.0→70.9、+8.9 pp。每任务10次且采用staged partial credit，不能直接套单一二项成功模型。

逐任务候选解释是 subset coverage、quality/mixture、optimization/checkpoint selection、evaluation noise。first divergence 可位于dataset slice、checkpoint trajectory或per-rollout stage score；在新执行前先发布subset manifest和per-rollout score。工程发布门必须看per-task regression，不能只看category average。

Machinery Packing 的DP/N1在10%档为20/8、Full为44/56。只有5个rollout×每次最多5件=25个物件机会，对应5/2/11/14件；同一rollout内机会相关，不能当25个独立样本。Pack Machinery 与 Machinery Packing 是同任务命名变体。DP initial immobility 是无时长、无频率的作者观察；两者没有共同根因证据。

两个异常必须分别定位
对象 竞争假设 关键falsifier
Machinery small-count variance；scoring sensitivity；object order/difficulty；planning difference 扩大预注册paired rollout仍保留差；stage/object两种指标排序一致；分层顺序后仍保留差；matched object state计划不分歧
initial immobility near-zero policy output；conditioning failure；execution gate/queue；selection bias raw policy chunk明显非零；matched offline condition产生正常计划；首步命令与执行一致；预注册rollout仍有稳定频率

联合first divergence只定义为first valid command与first executed action；最小测试是offline log与command ledger reconciliation，不启动服务或机器人。

现象六与七：神经轨迹增益及 LAPA/IDM 翻转

RoboCasa baseline [17.4,32.1,49.6]；LAPA [21.6,39.5,52.9]，增益 [4.2,7.4,3.3]；IDM [21.2,40.9,56.4]，增益 [3.8,8.8,6.8]。六个显示差都为正，但两条增益序列均非单调；headline [4.2,8.8,6.8] 是逐档上包络，不是一种方法的曲线。真机只覆盖低数据8任务子集，状态 preliminary。

神经轨迹的候选机制包括 pseudo-label quality、complementarity、mixture ratio、generated-domain shift、optimization/evaluation noise；对应falsifier分别要求标签误差不跟随增益、coverage overlap不跟随增益、固定比例重加权仍保留曲线、按物理/域分层后效果不变、multi-seed paired evaluation仍保持形状。first divergence 位于pseudo-label error、training mixture或validation loss by source；最小测试是固定生成集的offline factorial analysis。

LAPA−IDM为 [0.4,-1.4,-3.5]，反向IDM−LAPA为 [-0.4,1.4,3.5]。作者解释是更多数据改善IDM动作对齐，但未直接测pseudo-label error，也未证明IDM误差趋零、LAPA有不可消除鸿沟或“高数据通用选IDM”。

标签器竞争假设是 IDM data scaling、inverse-dynamics ambiguity、interface match、domain-bias interaction。区分试验应在有真动作的held-out clips上测误差，并按任务、embodiment、labeler、data budget以及可逆性、遮挡、接触阶段分层；first divergence 必须在policy training之前的heldout pseudo-action。当前只确认crossover，机制仍unresolved。

现象八：论文、源码、配置与 mask 差异

paper interpolation: x_tau = (1-tau) * epsilon + tau * A
mathematical derivative: A - epsilon
paper printed velocity: epsilon - A
fixed source target: actions - noise; positive Euler

tau_paper_reading = s * (1-U)
tau_source = 1 - U/s, s=0.999
maximum point difference = 0.001001001
source negative-time probability ≈ 0.149962494%

速度符号的导数、源码训练/推理正号配对与两个Beta变换不相等可静态判定。为什么文稿和实现不同、微小时间差是否影响性能都未知。论文K=4、checkpoint K=16只说明配置不同，不给质量/延迟排序。固定调用链把传入 encoder_attention_mask 置为 None，所以该参数在该链不生效；mask影响仍unknown，不能直接定性为性能缺陷。

first divergence 依次是printed equation、fixed-source expression、checkpoint field、block-call argument；最小测试仅包括symbolic check、static call-chain check和offline fixed-fixture ablation。禁止声称反号必然发散、Beta差解释结果差、K16优于K4或inactive mask已证明有害。

局限与 D0–D6 停止线

论文局限包括短时程桌面操作、未覆盖long-horizon mobile manipulation、更强VLM与新架构/预训练仍是未来工作、合成数据难兼顾多样性/反事实/物理一致性。额外负证据包括无matched VLA基线、无同架构scratch control、真机仅GR‑1、trial少、无CI、无multi-training-seed variance。中间层观察不与“更强VLM”方向构成逻辑矛盾。

验证阶梯是D0 static spec/arithmetic → D1 artifact/paper reconciliation → D2 offline log/fixed fixture → D3 isolated service → D4 simulation → D5 SIL/HIL → D6 separately authorized supervised robot。当前仅D0，禁止跳级。缺artifact identity、protocol mismatch、unsafe/nonfinite output、stale/unlogged command或缺独立safety supervisor任一出现即停止；safe-test 字段不是执行授权。

VLA（Vision-Language-Action，视觉-语言-动作）是把「看」「听懂指令」「动」三件事压进同一个模型的做法。它与 ACT 这类专用策略最大的区别在于起点：不再从零训练一个视觉编码器，而是拿一个已经在互联网图文数据上学会认物体、懂语言的视觉-语言模型（VLM backbone，视觉-语言主干）当主干，再在其上教它输出动作。

本页只交代共性结构与路线分野，具体模型与跨模型方法的层数、超参数、损失和系统细节下沉到十六个专题页。凡是本页未能在论文或官方实现中核实到的数字，一律写成定性描述。
本站有一个 VLA 的真机落地案例。基于 openpi 0.5（π0.5）在七自由度机械臂上完成 数据转换、后训练与单卡实时部署，真机成功率 92%。 见 VLA 视觉-语言-动作模型训练与真机部署； 其中用到的示范数据由 VR 遥操作项目采集。

十六个模型与方法专题页

π0

本板块唯一展开成多页专题的模型。总览页把整条主线讲通，另有六个子页分别深入网络架构与双专家、Flow Matching 动作生成、时间方向约定与推理期现象、官方源码剖析、训练配置与实验局限。

Flow Matching · 动作专家 · 连续动作块 · 多页专题

π0.5

已展开成八个子页的多页专题。在 π0 基础上主攻开放世界泛化，模型代码只改了两处，真正的升级在训练范式与数据体系：动作在训练期先用离散 token、推理期才用流匹配，数据从机器人扩展到网页语义与高层标注，推理时先写出子任务文本再生成动作块。枢纽页把整条主线讲通，子页分别深入数据配方与消融、网络架构、两阶段训练与组合损失、知识隔离、分层推理、源码剖析、论文与实现的差异，以及从 π0 到 π0.5 的演进对比。

开放世界泛化 · 异构共训练 · 子任务推理 · 多页专题

π0.6

本板块第八个展开成多页的专题。让模型从真实部署经验里继续学习，把离线示范训练的单向流程变成闭环。总览页先建立「π0.6 基座」与「π*0.6 后训练」的区分；子页分别深入基座架构与输入输出、三项联合目标与知识隔离、RECAP 框架与迭代算法、分布式价值函数、优势估计与优势条件策略、实验结果与七个反直觉现象、演进与开源现状，以及源码映射与工程复现路线。

经验学习 · 价值函数 · 优势条件 · 闭环改进 · 多页专题

π0.7

以可引导性为主线的通用机器人基础模型：把多样化提示、MEM 历史、多视角视觉子目标、Episode Metadata、CFG 与 training-time RTC 组合进分层系统。枢纽页串联全部机制，八个子页分别深入架构、提示、记忆、世界模型、训练、异步推理、实验现象与开源复现边界。

Gemma 3 · 视觉子目标 · MEM · CFG · RTC · 多页专题

Harness VLA

不重训 VLA 主干，而是在冻结 VLA 外围加入 Planner、固定解析原语与分层 Memory，把长时程任务变成可检查、可重规划、可积累经验的闭环。枢纽页与九个子页覆盖方法边界、架构、原语、记忆、训练与 Loss 边界、Flash Mode、实验异常、RPent 源码和横向研究路线。

Frozen VLA · Planner · Primitive · Memory · RPent · 多页专题

RTC · Real-Time Chunking

跨模型的实时动作分块方法专题，而不是另一套 VLA 主干。枢纽页从推理延迟与块间错位出发，七个子页分别深入 H/s/d 时序、引导式 Inpainting 与 VJP、异步队列、Training-Time RTC、固定版本源码、实验消融和故障诊断，并明确连续性、反应性、吞吐与安全的边界。

异步执行 · Soft Mask · VJP · Training-Time · 多页专题

HG-DAgger · Human-Gated DAgger

面向真实闭环数据采集的交互式模仿学习方法。策略先自主执行，人判断何时连续接管并示范恢复，再把人工控制段聚合回训练集。枢纽页与四个子页依次讲清 BC/DAgger 谱系、控制权状态机、Ensemble Doubt 与风险阈值、VLA 动作块数据和 Loss 适配，并明确原论文的阈值主要用于风险评估，不是自动接管开关。

人工门控 · 恢复轨迹 · Dataset Aggregation · 风险阈值 · 多页专题

RLT · RL Token

冻结大 VLA，用任务示范学习紧凑 RL token，再让小型 Actor-Critic 在 VLA 参考动作块附近进行样本高效的在线改进。枢纽页与七个子页依次讲清方法定位、表征重建、Twin Critic 与 Loss、reference/dropout、异步 Replay 系统、开源复现和真机实验现象。

RL Token · Frozen VLA · Actor-Critic · Online RL · 多页专题

RLHF-VLA · 人类反馈与偏好对齐

把人类比较、评分、接管和纠正转成 VLA 后训练信号。枢纽页与十个子页系统拆解反馈数据、Actor/Reference/RM/Critic 数据流、PPO、DPO/KTO/APO、轨迹与连续策略、在线数据飞轮、开源源码映射和异常诊断，并明确 RLHF、自动偏好、介入 RL 与普通在线 RL 的边界。

Human Feedback · Reward Model · PPO · DPO/APO · 多页专题

OpenVLA

本板块第四个展开成多页的专题。完全开源的 7B VLA，离散动作 token 路线的标准实现，也是社区最常用的对比基线。总览页把整条主线讲通——为什么把动作改写成词表 token 就能复用整套 VLM 训练栈、量化精度上界由什么决定、训练目标为何只是一个交叉熵；子页分别深入网络架构、动作 token 化、训练与优化、数据配方、源码、部署、反常现象与 OpenVLA-OFT。

离散 token · Prismatic 主干 · 7B · 多页专题

X-VLA

本板块第二个展开成多页的专题。专门针对跨本体设计的统一架构，每个数据源配一组可学习 soft prompt 吸收本体差异，主干只用标准 Transformer，规模约 0.9B。总览页把整条主线讲通，子页分别深入 Soft Prompt 机制、网络架构、动作表示与损失、训练配方、源码、部署与反常现象。

cross-embodiment · soft prompt · 0.9B · 多页专题

SmolVLA

已展开成七个子页的多页专题。小模型路线，参数量压到 0.45B 量级，靠层跳过、视觉 token 缩减与异步推理在消费级硬件上跑到可用帧率。总览页把整条主线讲通，子页分别深入主干与多模态 token、动作专家与交错注意力、Flow Matching 与损失、训练配方、源码、推理与异步执行，以及论文全部消融与反直觉现象。

0.45B · 异步推理 · 消费级硬件 · 多页专题

GR00T N1

已展开成七个子页的多页专题。NVIDIA 面向人形机器人的开放基础模型，把「理解」与「运动」显式拆成 System 2（Eagle-2 视觉语言模型）与 System 1（扩散 Transformer），两者用交叉注意力衔接。数据侧用潜在动作把无动作标签的人类视频也变成可训练样本。总览页把整条主线讲通，子页分别深入网络架构、流匹配与时间方向、数据金字塔、训练配方、实验、反常现象与官方源码。

双系统 · 2.2B · 潜在动作 · 数据金字塔 · 多页专题

GR00T N1.5

已展开成七个子页的多页专题。GR00T N1 的升级版本，沿用双系统骨架但在四个方向做了实质改动：视觉语言主干换成 Qwen3-1.7B 配 SigLIP 并在训练中整体冻结、关闭 pixel shuffle 使每帧视觉 token 由 64 增至 256、动作头前新增层归一化与四层视觉语言自注意力、训练目标加入 FLARE 未来潜在表征对齐。总览页把增量主线讲通，子页分别深入架构增量、FLARE、DreamGen 数据体系、训练配方、推理与反常现象、官方源码与实验。

冻结 VLM · FLARE · 256 token · DreamGen · 多页专题

GR00T N1.6

已展开成七个子页的多页专题。N1.6 将 VLM 换为支持原生宽高比的内部 Cosmos 2B 变体，移除 N1.5 的四层后置 adapter，在预训练中解冻 VLM 顶部四层，并把 AlternateVLDiT 从 16 层加深到 32 层；动作侧以相对动作块为主，公开 3B checkpoint 使用 50 步 horizon、128 维统一容器与四步 Euler 推理。专题同时记录官方训练事实、公开源码路径、checkpoint 配置和三者之间的证据边界。

Cosmos 2B · 相对动作 · 32 层 DiT · 四步推理 · 多页专题

DexGraspVLA

已展开成七个子页的多页专题，也是本板块唯一走分层模块化路线的模型。它不把视觉语言主干纳入训练，而是用现成 VLM 把语言压成边界框、用 SAM 与 Cutie 压成逐帧掩码、用两个冻结 DINOv2 压成域不变特征，只训练一个 163M 的扩散 Transformer 控制器。约两小时演示数据即在 1287 个未见组合上达到 90.8%。总览页把整条主线讲通，子页分别深入规划器与目标抽象、观测编码器与 DiT、扩散与噪声匹配、训练与超参数、源码、推理涌现现象与实验消融。

分层 VLA · 冻结 DINOv2 · 掩码 affordance · 灵巧手 · 多页专题

VLA 的定义与三模态统一

一个 VLA 模型接收多路相机图像与一句自然语言指令，输出机器人可执行的动作。三个模态最终在同一个 Transformer 的注意力矩阵里交互：图像被切成视觉 token（视觉记号），指令被切成文本 token，动作则视路线不同或者被离散成 token、或者由一个额外的生成分支产出连续值。这里的注意力机制与位置编码就是标准 Transformer 的那一套，没有为机器人做特殊改动——本页后面出现的分块注意力掩码也只是在 Q/K/V 计算之前改了掩码矩阵，注意力本身的形式不变。

  • 输入侧：多视角 RGB（第三人称相机加腕部相机）、语言指令，通常还包括本体感知的关节状态 state。
  • 输出侧：末端位姿增量或关节目标，绝大多数现代方法一次输出一整个动作块（action chunk）而非单步。
  • 训练范式：仍然是模仿学习（监督学习），只是数据量从单任务几十条上升到跨任务跨机器人百万条量级。
  • 与传统流水线的区别：不再有「检测 → 抓取位姿估计 → 运动规划」这样的显式模块，感知到动作端到端打通。
  • 任务指定方式：任务由语言给出，新任务不必重新设计模型结构，只需换一句 prompt 并补少量微调数据。

所谓「统一」，落到实现上并不复杂：三种模态都被映射成同一维度的向量序列，拼接后送进同一个主干。差异只在于映射方式——文本走词嵌入查表，图像走视觉编码器加投影层，动作走量化查表或含噪张量投影。理解这一点，后面两条路线的分野就只是「动作那一路怎么映射、怎么解出来」的区别。

为什么要用预训练 VLM 做主干

机器人数据永远是稀缺的：采一条真机轨迹的成本比爬一张图片高好几个数量级。VLM 主干的意义就是把「认识世界」这部分能力外包给互联网数据，机器人数据只用来学「怎么动」。

  • 语义泛化：训练集里没出现过的物体，只要 VLM 认识，策略就有机会正确响应，这是从零训练的策略做不到的。
  • 开放词汇指令（open-vocabulary instruction）：指令空间不再是几十个预设任务 ID，而是自然语言，可组合、可描述新目标。
  • 空间与常识先验：VLM 已经隐含了物体常见朝向、容器开合方式这类常识，减少了机器人数据需要承担的学习量。
  • 任务分解能力：具备语言输出的主干可以先生成中间子目标（高层语言），再逐段生成动作，π0.5 就走这条路。
  • 代价一：参数量与显存占用大幅上升，实时控制需要专门的推理优化（量化、KV cache、动作块摊薄单次推理成本）。
  • 代价二：微调时容易发生灾难性遗忘，破坏预训练语义能力，需要冻结部分参数或使用较小学习率。

一个容易被忽略的前提是：VLM 的先验能否迁移，取决于机器人观测与互联网图像的分布距离。第三人称桌面场景与网络图片较接近，先验迁移得好；腕部相机的近距离、强遮挡视角与网络图片差异大，这一路的收益要小得多。这也是多数方法即使用了预训练视觉塔，仍然要让视觉侧参与微调的原因。

视觉侧的通用结构

无论走哪条动作路线，视觉到语言 token 空间这一段的结构高度一致，可以当作 VLA 的公共前端。

层 / 模块 输入 → 输出 作用 为什么这样设计
图像预处理 原始相机帧 → 固定分辨率张量 缩放到编码器要求的尺寸，数值归一化到固定区间 视觉编码器的位置编码按固定 patch 数训练，尺寸不一致会让位置编码失配；不做数值归一化则与预训练时的输入统计不同，特征分布整体偏移
patch 切分 图像张量 → 图像块序列 把二维图像变成一维序列，交给 Transformer 处理 卷积主干输出的是特征图，需要额外设计融合方式；切成 patch 后视觉与文本共用同一套序列接口，注意力可以直接跨模态计算
视觉编码器 patch 序列 → patch 特征 提取语义与几何信息 选用在大规模图文数据上预训练的编码器，机器人数据不足以从零学出稳定的视觉表征；从零训练的视觉塔换个光照或背景就失效
投影层 patch 特征 → 语言 token 空间向量 对齐两个模态的向量空间与维度 视觉编码器与语言主干的隐藏维度、数值尺度都不同，直接拼接会让主干把视觉 token 当作异常输入；用一到两层 MLP 做投影，参数量很小但可训练性好
多视角合并 多路 patch 序列 → 单条序列 把第三人称与腕部相机拼进同一序列 若为每路相机单独设分支，权重无法在视角间共享，且相机数量一变结构就要改；拼进同一序列并用掩码标记缺失路，一套权重即可适配不同相机配置
状态编码 关节状态 → 一个或多个 token 提供 patch 之外的本体信息 关节角与夹爪开合在图像里常被遮挡或不可分辨，仅靠视觉无法确定当前构型；投影成 token 后与视觉 token 同等参与注意力

这一段的设计目标只有一个：让主干在结构上无需感知模态差异。所有模态最终都是等长向量的序列，主干只做通用的注意力计算。也正因为如此，跨模态的位置信息要靠位置编码显式给出——同一条序列里既有图像块的二维空间位置，又有文本的先后顺序，还有动作块内的时间步，这三套顺序都不是注意力自己能推断出来的，具体做法见位置编码。

两条动作表示路线

这是 VLA 内部最主要的一条分界线：动作到底要不要变成 token。离散路线把连续动作值分箱（binning）成整数，复用语言模型的词表和交叉熵损失，改动最小；连续路线保留动作的连续性，另接一个 Flow Matching 或 Diffusion 生成分支，表达能力更强但结构更复杂。

甲：离散 token 路线的逐层拆解

层 / 模块 输入 → 输出 作用 为什么这样设计
分位数归一化 原始动作向量 → 固定区间内的值 把每一维动作压到统一量程 用分位数而不是最大最小值，是因为少量离群轨迹会把量程拉得极宽，绝大多数动作挤进少数几个档位，有效分辨率骤降
均匀分箱 归一化值 → 整数 bin 编号 把连续量变成有限符号 均匀分箱实现简单且反量化误差有界；非均匀分箱虽能对高频区间加密，但需要额外存储与传递码本，跨数据集复用困难
词表映射 bin 编号 → token id 让动作成为合法的语言 token 覆写词表中最少使用的 token，可以不改 embedding 层与输出层的形状；扩词表会改变输出层维度，预训练权重无法直接加载
自回归解码 上下文 token → 逐个动作 token 生成动作序列 完全复用语言模型的解码栈，无需新增模块与新损失项；代价是解码步数等于动作维度乘动作块长度
反量化 token id → 连续动作值 还原为控制器可执行的量 取 bin 中心而非边界，可以把最坏量化误差从一个档宽降到半个档宽

乙：连续生成路线的逐层拆解

层 / 模块 输入 → 输出 作用 为什么这样设计
噪声初始化 高斯噪声 → 含噪动作块 给生成过程一个起点 生成式建模天然表达多峰分布；直接回归动作在演示数据存在多种可行解时会收敛到各解的平均值，产出物理上不可行的中间动作
动作专家 含噪动作块加观测上下文 → 速度场或噪声估计 承担动作生成的主要计算 用一个较小的专用分支而不是复用主干全部权重，可以在每次迭代只重算这一小部分，主干的注意力缓存复用多次
分块注意力掩码 序列 token → 受限注意力 让信息只从观测流向动作 若观测 token 也能看到动作 token，每次去噪迭代都要重算整个主干，推理耗时按迭代步数成倍上升
迭代去噪 含噪张量 → 干净动作块 沿学到的路径把噪声推成动作 Flow Matching 的目标路径是直线，迭代步数可以压到十步量级；Diffusion 的曲线路径通常需要更多步
动作块输出 一次输出 H 步动作 覆盖未来一段时间的控制量 逐步预测会让误差沿时间累积，一次给出整段可切断这条累积链，同时天然表达动作的时间相关性

两条路线的对照

对比维度 离散动作 token 连续动作生成
代表模型 RT-2、OpenVLA π0 / π0.5 / π0.6、X-VLA、SmolVLA
动作表示 每个自由度分箱成 256 档，映射到词表 token 直接输出浮点动作块
生成方式 自回归逐 token 解码 Flow Matching 或 Diffusion，少步迭代一次出整块
训练损失 交叉熵，与语言建模完全一致 流匹配或去噪回归损失，另加动作分支参数

推理速度 慢，动作维度乘以块长等于解码步数 快，一次前向加少数几步迭代出整块

改造成本 极低，几乎不动 VLM 结构 需要设计动作专家或额外的生成分支
训练复杂度 低，无新增超参数 中，需选择噪声调度、时间步采样分布与迭代步数
控制频率 通常 3–10 Hz 可达数十 Hz

概括起来：离散路线的优势在工程侧——不改结构就能沿用 VLM 的全部预训练权重与既有推理基础设施；连续路线的优势在精度与吞吐——没有量化误差，且一次前向加少数几步迭代就产出整块动作，因此是目前精细操作任务上的主流选择。

这个结论需要限定条件，否则容易被读成「连续路线全面占优」：

  • 精度上的差距来自量化而不是模型能力。档位数足够多、动作幅度足够小的任务上，量化误差可以低于机械本身的重复定位误差，此时离散路线并不吃亏。
  • 速度上的差距来自解码步数而不是参数量。离散路线的解码步数等于动作维度乘动作块长度，因此它在长动作块上代价陡增；如果任务本身只需要短块甚至单步，这条劣势不成立。
  • 多峰建模上两条路线各有限制：离散路线的分布是词表上的 softmax，本身就能表达多峰，但峰的位置被限制在有限个档位上；连续路线在连续空间建模多峰，代价是要选噪声调度、时刻采样分布与迭代步数这些额外超参。
  • 两条路线的分歧点只在动作那一路，前端的视觉与语言处理几乎完全相同，因此实现上可以共用同一份数据管线，切换路线不需要重做数据侧。
两条路线不是互斥的。π0.5 的做法是先用离散方式输出高层语言子目标，再由连续动作专家生成低层动作块，等于把两者接在了一条流水线上。

跨本体问题

跨本体（cross-embodiment，跨机器人本体）是把多机器人数据混合训练时必须先解决的问题：不同机器人的自由度、动作空间语义、控制频率、相机数量都不一样，同一个浮点数在两台机器上含义完全不同。

  • 自由度不齐：6 轴、7 轴、双臂 14 轴，甚至带移动底盘，动作向量长度不同。
  • 动作空间语义不同：有的用末端位姿增量，有的用关节位置，有的用速度指令。
  • 观测配置不同：相机数量与安装位置不一致，视角先验无法直接迁移。
  • 控制频率不同：从 5 Hz 到 100 Hz 都有，同样长度的动作块覆盖的物理时间差很多。

常见的处理办法各有取舍：

层 / 模块 输入 → 输出 作用 为什么这样设计
统一定长动作空间补零 各本体动作向量 → 固定维度向量加有效位掩码 让不同自由度的数据共用一套输出结构 一套权重即可吃下全部数据，动作层面的知识可以共享；补零必须补在尾部并同步掩码，补在中间会让所有关节整体错位，且无效维度必须在损失中掩掉，否则模型会花容量拟合恒为零的通道
离散化到统一词表 各本体动作 → 同一套 bin 编号 用符号层面的统一绕开量纲差异 分箱后所有本体共享同一组 token，无需对齐物理单位；代价是每个本体都要单独统计分位数，换本体不重新统计会导致档位整体错位
可学习 soft prompt 数据源或本体标识 → 一组可学习向量 显式告知模型当前数据来自哪个本体 补零方案里模型只能从观测隐式推断本体，遇到外观相近但运动学不同的两台机器人会混淆；soft prompt 把这一信息作为独立条件输入，新增数据源只需训练一小组向量而不动主干
分本体动作头 共享特征 → 各本体独立输出 让每个本体有自己的输出空间 实现最简单且不会互相干扰；但动作层面的知识完全无法共享，数据量小的本体得不到迁移收益
统一到末端位姿增量 关节指令 → 末端增量 折算到通用的物理表示 末端增量在不同机械臂间语义一致，可比性最好；代价是丢失关节级冗余自由度信息，冗余臂的零空间行为无法建模

π 系列采用统一定长动作空间加补零的思路，X-VLA 用每个数据源一组 soft prompt，OpenVLA 则在数据侧只保留单臂末端控制的子集再做离散化。

关键设计选择与原因

各家 VLA 的网络结构差别不小，但有几个设计量是跨模型可比的——它们在每个模型里都要取值，量纲一致，取值差异直接反映设计取向。下表把本站相关专题页里已核实的数字放在一起，作为选型时的参照。

设计量 跨模型的典型取值 取大的收益与代价 取小的收益与代价
每维离散档位数 OpenVLA 每维 256 档（仅离散路线需要此参数） 量化误差与档位数成反比，精细操作的精度上限更高 分类目标更易学、占用词表条目更少；但档位粗，插入与装配类任务先受限于量化误差
每步动作 token 数 OpenVLA 每步 7 个，与单臂末端增量加夹爪的自由度一一对应 能表达更高自由度的本体 解码步数更少、延迟更低；但表达不了双臂或带底盘的动作空间
动作块长度 H ACT 100（50 Hz 平台）、π0、π0.7 与 SmolVLA 50、π0.5 部分配置 10–15 决策次数少、误差累积机会少、对推理频率要求低；但块内开环，无法响应块内的环境变化 反应快；但推理频次上升，离散路线的解码步数也随之成倍增加
每帧视觉 token 数 常见 VLM 约 1024，SmolVLA 压到 64 空间分辨率高，利于辨认细小目标与精确定位 注意力开销按序列长度平方下降；但小物体容易被压掉，精细定位任务受影响
迭代去噪步数 π0 与 SmolVLA 为 10，π0.7 为 5（仅连续路线需要此参数） 生成质量更稳，路径弯曲时误差更小 延迟更低；但步数过少时直线路径假设的偏差会直接体现在动作上

离散档位数：它直接决定精度上限

  • 采用「取档位中心反量化」时，单维的最坏量化误差是量程的 \(1/(2K)\)：
\[\epsilon_{\max} \;=\; \frac{a_{\max} - a_{\min}}{2K}\]
  • 这个式子给出两条直接推论。其一，档位数固定时误差与量程成正比，动作幅度大的维度绝对精度更差；其二，量程来自训练集的分位数统计，换一个动作幅度分布不同的数据集，同样的 256 档给出的实际精度完全不同。
  • 因此换本体或换数据集时必须重新统计分位数。沿用旧统计的现象是动作方向大致正确、幅度整体错位，而训练损失看不出任何异常。
  • 档位数不能无限加大：档位要征用词表中的条目，K 增大意味着占用更多低频 token；同时相邻档位在词表里只是相邻 id，嵌入空间不保证相邻 id 语义相近，档位之间的序关系要模型从数据里重新学出来，K 越大这件事越难。
  • 连续路线不存在这个参数，这正是它在毫米级任务上的结构性优势。

动作块长度：先换算成物理时间再比较

  • 步数本身不可比，可比的是 H 除以控制频率得到的物理时间。50 Hz 平台上的 100 步与 15 Hz 平台上的 30 步覆盖的时间相近，行为特征也相近。跨平台照抄步数是常见误用。
  • 上界由环境的可预测程度决定：块内是开环执行，这段时间就是无法对扰动作出反应的盲区。
  • 下界由推理延迟决定：下一块必须在当前块执行完之前算好，否则块间出现停顿。模型越大，H 越不能取小。
  • 离散路线还多一层约束：解码步数等于每步动作 token 数乘以块长，块长 50、每步 7 个 token 就是数百步串行解码。这解释了为什么长动作块几乎是连续路线的专属选项。
  • 两端约束都不满足时，解决办法不是折中取值，而是改执行方式——推理与执行重叠、块间重叠融合，让反应性与块长解耦。

视觉 token 数：注意力开销的主要来源

  • 视觉 token 通常是序列里最长的一段，而注意力开销对序列长度是平方关系，因此压缩这里的收益大于压缩任何其他部分。SmolVLA 把每帧压到 64，与常见的约 1024 相比是十几倍的差距。
  • 压缩方式有讲究：按空间重排（把空间分辨率折进通道维）不丢弃信息，直接下采样或裁剪则可能把小物体整块采掉。
  • 代价是空间分辨率变粗，需要辨认细小目标或精确定位的任务上表现下降。选型时这条与任务性质直接挂钩，而不是可以随意调的效率参数。
  • 多视角会让这个量成倍放大：三路相机意味着三倍的视觉 token。相机路数与每帧 token 数应当一起考虑，而不是分别设定。

发展脉络

按时间把这条线捋一遍，可以看清每一步在补前一步的什么缺陷。

  1. RT-1（2022）：Transformer 策略加离散动作 token 的雏形，证明大规模真机数据可以训出多任务策略。它的视觉与语言编码器虽然各自带预训练权重，但并不是在图文对上联合预训练的 VLM，因此语义泛化能力有限。
  2. RT-2（2023）：把动作 token 直接放进 VLM 词表，做视觉-语言-动作联合微调，第一次展示出对未见过物体与概念的泛化。模型权重未开源。
  3. Open X-Embodiment / RT-X（2023）：多机构联合汇总的跨本体数据集，确立了跨本体预训练这一范式，也为后续多数开源 VLA 提供了预训练语料。
  4. Octo（2024）：开源的通用机器人策略，用 Transformer 主干加 Diffusion 动作头，是连续动作路线在开源社区的早期代表。
  5. OpenVLA（2024）：7B 参数的开源 VLA，离散动作 token 路线的标准实现，附带完整的 LoRA 微调方案，是社区最常用的复现基线。
  6. π0（2024）：VLM 主干加 Flow Matching 动作专家，连续动作块生成，把控制频率与精细操作能力同时拉上去。
  7. π0.5（2025）：加入高层子目标推理与更宽的数据配方，主攻开放世界泛化，目标是进入未见过的真实家庭环境作业。
  8. π0.6（2025）：引入从真实执行经验中学习的闭环，让模型能在部署数据上持续改进，而不只依赖离线示范。
  9. π0.7（2026）：把多样化提示、短时历史、高层子任务和世界模型视觉子目标统一到可引导系统，并用 CFG、RTC 与异步执行改善部署行为。

同期还有两条值得单独看的支线：X-VLA 用「每个数据源一组可学习 soft prompt」的方式吸收跨本体异构性，主干只用标准 Transformer 加 Flow Matching，规模约 0.9B；SmolVLA 走小模型路线，参数量压到 0.45B 量级，目标是在消费级硬件上也能实时运行。

按这条时间线看，三个阶段的主题依次是：先证明大模型可以直接输出控制量（RT-1 到 RT-2），再解决数据与本体的统一（Open X-Embodiment 到 OpenVLA），最后重做动作输出这一环（Octo 到 π 系列）。

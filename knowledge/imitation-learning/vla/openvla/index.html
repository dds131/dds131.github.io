VLA 模型家族/OpenVLA

OPENVLA · BASE 7B · SUPERVISED ACTION TOKENS

OpenVLA = Prismatic-7B VLM + OXE robot demonstrations + discrete action tokens。

OpenVLA 用图像与语言条件预测离散动作 token，再反量化为机器人动作。它的训练族是 supervised behavior cloning / next-token prediction，不是 PPO、SAC、Q-learning 或 learned-reward RLHF。

本页不是部署指南。标准论文接口描述 7 维动作 token 序列；任何真机使用都必须进入 Deployment，解析固定版本的 policy I/O、统计量、坐标、时序、安全和 fallback 合同。

OpenVLA 是什么

OpenVLA 是在 Prismatic-7B 视觉语言模型上，用经筛选的 Open X-Embodiment（OXE）机器人演示做监督式微调的 7B 视觉-语言-动作模型。连续动作的每一维先映射到离散标签，再复用语言模型词表与自回归接口；训练以动作 token 上的 next-token cross entropy 学习“图像 + 指令 → 动作”。

维度 OpenVLA 基线
数据 专家机器人演示，多数据集混合
监督 动作 token 标签
目标 masked next-token cross entropy
更新 Prismatic VLM 的监督式微调
reward / critic / Q 无 learned RM、Critic 或 Q 网络
online rollout update 论文基线无
方法族 behavior cloning / supervised imitation learning

VLA 描述输入输出与用途，不自动表示强化学习；generalist 表示论文跨任务/本体的数据与评测范围，不表示任意环境零样本可用。open-source 必须拆成 code、checkpoint、data recipe、upstream component 与 license scope，不能从仓库 MIT 推导所有模型、数据和权重都使用同一许可。

最小系统主线

flowchart LR
  O[third-person RGB] --> V[DINOv2 plus SigLIP]
  L[language instruction] --> T[tokenizer and prompt]
  V --> P[Prismatic projector]
  P --> M[Llama 2 7B]
  T --> M
  M --> W[action token sequence]
  W --> D[dequantize and unnormalize]
  D --> A[robot action interface]
  1. 第三人称 RGB
  2. 双视觉表征
  3. Prismatic 对齐
  4. Llama 2 主干
  5. 动作 token
  6. 反量化与反归一化
  7. 机器人动作接口

视觉编码器只产生视觉特征，不定义动作坐标；projector 对齐特征空间，不是机器人动作头；语言主干输出 token 分布，但词表到动作的语义由 Action Tokenizer 和统计量决定。predict_action() 不包含所有 frame transform、clamp、安全控制器与底层驱动；反归一化恢复训练数据尺度，也不等于完成物理标定。

数据与训练目标摘要

970k 是论文训练混合口径，不是整个 OXE 的全部数据；RLDS/OXE 的容器一致不代表机器人语义天然一致。dataset mixture、sampling weight、transform、action statistics 和 checkpoint norm stats 是不同制品，详情由 Data 页持有。

训练标签是动作 token 序列，teacher forcing 下执行 next-token cross entropy；mask 决定进入 Loss 的位置。token accuracy 是训练代理，不是闭环成功率。EOS、FSDP、优化器、混合精度与 checkpoint 进入 Training，不在 Overview 展开。

证据边界与适用条件

论文 protocol 支持其任务、本体、checkpoint、对照与点估计，不能变成跨协议通用排名；官方项目页支持摘要、图和定性视频，不能当独立复现或因果消融；固定 repository/artifact 只约束对应 commit/revision；本站路由与合同是教学综合，不冒充作者结论。

论文在 WidowX + Google Robot 的 29 个任务协议报告相对 RT-2-X 的绝对成功率差 16.5 个百分点，只能绑定该 protocol。项目页定性视频不能证明显式恢复状态机；OFT 的 97.1% 或 26× 不能写成原始基线能力。

模型选型记录

适合：需要公开可检查的 generalist VLA 基线；研究离散动作 token 与 VLM 基础设施复用；数据具备图像、语言与可映射动作监督；可承担 7B 资源或 PEFT；愿意显式适配 prompt、统计量、坐标与控制栈。

需谨慎或不适合：极低延迟/高频/长 chunk 是不可改的硬要求；任务要求原生连续高精度输出；没有动作统计、frame transform 或安全控制器；期待一图一句 prompt 零配置控制未见本体；许可或 Llama 2 条件不适用；算法需要可验证 density、value 或 online reward update。

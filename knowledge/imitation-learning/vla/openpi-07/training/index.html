π0.7 总览/短时记忆/数据与训练目标

DATA PROVENANCE · OBJECTIVE ABSTRACTION · GRADIENT OWNERSHIP

先分样本与模型，再谈 Loss：π0.7 把异质数据标成可区分的 context；低层 VLM、Action Expert、高层语言策略与世界模型各有自己的数据、监督和参数边界。

论文没有公开一个把所有分支相加的总 Loss，也没有公开足以照抄的优化器、batch、训练步数或混合比例。本页中的 π0.7 读作 pi zero point seven。

一、数据来源与泄漏排除

既有策略数据 autonomous evaluation、policy rollout human interventions 成功、纠偏及多质量轨迹 并非 π0.7 在线 RL
低质量与失败 lower-quality demonstrations、failure episodes、含大量 mistakes 的 success episodes 带实际动作 target 与行为标签 不保证每条含有效 recovery

π*0.6 在 RL 训练与评估中产生的数据作为 additional examples，论文称这让 π0.7 “effectively”继承 specialist 行为。这里是数据蒸馏 / 条件动作监督，不表示 π0.7 自己运行在线 RL、策略梯度、value learning 或在机更新。论文脚注明确排除为 generalization-focused evaluation task 收集的 autonomous data；准确结论只到“该类自主数据被排除”，不能扩成所有相似场景、物体、技能或人类视频均保证无泄漏。PAPER_DATASET

数据清单描述“有哪些来源”，不等于一个可执行 mixture。论文没有给每类样本数、总时长、机器人/非机器人占比、采样温度、重复样本处理、跨来源去重、质量阈值或一个 batch 内的配额。即使两个来源都叫 robot video，它们也可能承担不同目标；没有 sampler 和 routing，就不能从类别数量推断梯度贡献或训练主次。

二、条件标注与混合质量轨迹

每个低层机器人样本在 observation / action 之外携带 (C_t)：总体任务、动态子任务、视觉子目标、episode metadata 和 control mode。Speed 来自 ground-truth episode length 并按 500 timesteps 分桶；quality 是 episode 级 1–5 人工评分；mistake 是 action-segment 级粗人工标签。它们是 context labels，不是 reward、return、advantage、在线故障检测或 Loss 权重。PAPER_DATASET

失败与低质量轨迹仍以实际执行动作作为 target；标签只让模型有机会区分该行为模式。论文没有逐样本纠错 target 或显式 recovery label，不能因为数据含失败就声称模型必然学会恢复。更详细 context 可能帮助利用 heterogeneous / suboptimal data，但前提是标签正确、标签与行为稳定对应、稀有组合有足够覆盖且模型没有忽略条件；结果与因果数值归 Phenomena。SITE_CONDITIONAL_EXPLANATION

未公开项包括 quality rubric、标注者数量与一致性、mistake 边界、完整 speed buckets、control mode 到 action ABI 映射、subtask 分段质量门。推理时设 quality=5、mistake=false 不意味着训练过滤掉其他数据，也不意味着只学习高质量动作。

这里应区分“保留失败样本”和“给出恢复监督”：前者只说明数据分布中有失败或低质量动作，并用标签区分；后者需要知道哪个后续动作被定义为纠错、从何时开始恢复以及如何评价恢复成功。论文没有给这类显式 recovery annotation。模型或许能从上下文中学习某些恢复模式，但这属于有条件机制解释，不能变成所有失败轨迹都有益的结论。

三、低层近似似然、Flow 与 Action Expert

论文给出的低层 VLA 抽象目标是：

[ \max_{\theta}\;\mathbb E_{\mathcal D}!\left[\log\pi_{\theta}!\left(a_{t:t+H}\mid o_{t-T:t},C_t\right)\right]. ]

这条 Eq.1 标为 PAPER_OBJECTIVE_ABSTRACTION。论文随后说明 Flow Matching Action Expert 优化的是 approximate lower bound，而不是 closed-form log-likelihood；因此不能把最大化记号直接改写成一个已公开、可数值计算的单项 Loss，也不能自行补一个“总 Loss”。

可确认的是监督路径和更新对象，不是标量总Loss
路径 监督 前向依赖 更新对象 不可推出
FAST comparatively stable discrete cross-entropy VLM context → FAST tokens VLM backbone 逐样本梯度必非零、固定 loss coefficient
Flow continuous action Flow Matching VLM activations + noisy actions + flow timestep 860M Action Expert 官方 noise / time / path / target / weighting
辅助 VLM captioning、VQA、text-only 等 任务相关输入 VLM 侧 统一 next-token CE、固定同 batch routing

Action Expert 是 860M Transformer，以 adaptive RMSNorm 注入 flow timestep，固定处理 50 个 action tokens，即 50-step chunk。这里的 50 不是 batch size、训练总步数、denoising steps 或 episode length。源页中的直线概率路径、噪声端点与 MSE 是通用教学选择，并非 π0.7 已公开配方；本页删除它们，Flow 数学见 公共 Flow Matching。论文运行时的 5 denoising steps 也不是训练步数。PAPER_RUNTIME_NOT_TRAINING

“approximate lower bound”只给出目标层级关系，并未固定实现的 noise distribution、flow-time distribution、probability path、velocity target、mask reduction、loss weighting 或 action normalization。不同自洽 Flow 参数化可以有不同端点与速度符号；缺少正式实现时，页面不能选一个常见版本当作 π0.7 事实，也不能用运行时积分器反推训练 target。

四、FAST 监督与 Knowledge Insulation

KI 不是把 FAST token 送入 Action Expert，也不是先离散规划再由连续头细化。FAST 提供训练期行为监督，最终连续动作由 Flow Expert 输出。KI 与 FAST 的原始工作只解释继承机制；“训练后是否丢弃离散分支”、alpha、消融或其他版本实现不能自动迁移为 π0.7 专属配方。INHERITED_KIINHERITED_FAST

页面不把各目标写成带自造权重的“总 Loss”，因为论文未给标量相加方式、归一化单位、系数、optimizer 分组或同步 step。可确认的是两条动作监督并存、Expert 前向读主干、Flow 梯度不回主干。

辅助 VLM 样本又增加一层未知：论文列出 captioning、VQA、定位、属性和文本任务，却没有说明每类 objective、token mask、loss owner 或它们与 FAST CE 是否同批共现。因而“VLM 有多模态监督来源”是可确认事实，“所有任务使用同一个 next-token CE 并按固定比例相加”则不是。KI 只约束 Flow 梯度路径，不替论文定义其他任务的优化规则。

五、视觉子目标样本构造

训练低层 VLA 时，每个 batch 只有 25% examples 加入 visual subgoal；对已经进入真实 future-subgoal 分支的样本，0.25 概率选当前语义 segment end，0.75 概率从当前之后 0–4 秒均匀采样。前者是 goal presence，后者是 target-time rule；两个 25% 属于不同随机过程，不能相乘、相加或互换。PAPER_TRAINING_RULE

低层训练同时使用 real future images 与 world-model-generated images。论文称从 world model 采样 large number of subgoal images，构造 additional training examples，以缓解真实训练目标与生成运行时目标的 train-test mismatch；但没有公开真实/生成比例、总数、缓存格式、生成轮次或是否在线同 batch 生成。训练读取 future frame 是监督目标构造，不是运行时 history 偷看未来，也不证明生成图物理可达、时序准确、无伪影或与真实目标同分布。

World model 自己的 (\mathcal D_g) 是高质量 subtask-label 片段子集，ground-truth target 是 segment-end observation；它与低层 0.25 / 0.75 真实目标时间规则不是同一分布定义。

生成目标 additional examples 试图缩小训练时真实目标与部署时生成目标之间的差距，但“见过生成图”不等于 mismatch 被消除。生成模型可能产生伪影、视角不一致、不可达状态或错误时间尺度；低层还可能过度依赖这些偏差。没有真实/生成消融、数量和采样时程，就不能量化这条数据增强的独立贡献。

表中的“更新对象”也不等于一个统一训练进程：低层 VLM 和 Expert 有明确的前向 / 反向关系，高层与世界模型却是独立模型。它们可以先后训练、离线产出数据或在部署时异步组合，但论文没有给一条覆盖所有对象的标准时间轴。本站只记录 sample class 到监督和参数所有者的映射，空白边保持 NOT_REPORTED。

高层 policy 可用 verbal coaching episodes finetune，把 robot observations、task specification 和 past subtask instruction history 映射为 new subtask instruction。Appendix 只说明高层与低层都 based on Gemma3 4B，不证明共享实例、权重、optimizer、cache 或 checkpoint；源页自行写出的高层交叉熵公式不能作为 π0.7 官方目标。

World model 的论文抽象写作：

[ \max_{\psi}\;\mathbb E_{\mathcal D_g}!\left[\mathcal L_{CFM}!\left(g_t^{\star},g_{\psi}(o_t,\hat\ell_t,m)\right)\right]. ]

论文把该项称为 loss 同时使用 max 记号，却未展开具体符号、负号、MSE、path 与权重；本站登记 FORMULA_SIGN_TENSION，不擅自改成 min。低层输出 continuous action chunk，高层输出 subtask text，世界模型输出 multi-view subgoal images；三者不合并 Loss，也没有已报告的联合端到端反传。

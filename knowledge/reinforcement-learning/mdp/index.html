本页重点：先固定状态、观测、联合转移—奖励核、初始分布与时间边界，再推导 Bellman 期望/最优算子。固定策略的有限 MDP 可写成线性方程；控制问题常用策略迭代、价值迭代，也可写成线性规划。占用度量只在正占用状态上恢复策略，在零占用状态上只能确定策略等价类。完整的样本估计移交蒙特卡洛方法。

本章要解决什么问题

上一章的多臂老虎机只有一个状态，因此每一步的处境完全相同，「这个动作有多好」就等于「这一步的期望奖励」。真实问题不是这样：机械臂现在把夹爪张开，好处要到几十步之后抓取成功时才体现出来；现在走错一步，可能把自己置于一个之后怎么补救都来不及的位形。一旦当前动作会改变未来的处境，动作的好坏就不能只看眼前的奖励。

这带来三个必须回答的问题。

  • 怎么描述「处境」？ 需要引入状态，并且需要一个假设来保证状态是「够用」的——否则智能体必须记住全部历史，问题在计算上不可解。这个假设就是马尔可夫性质。
  • 怎么把「未来的好处」折算到现在？ 需要回报与价值函数，把一整条尾巴上的奖励压缩成一个标量。
  • 怎么让这个标量可计算？ 价值函数按定义是对无穷长轨迹求期望，直接算不动。贝尔曼方程把它变成一个自己引用自己的递推式，从而可解——这是本章最重要的结果，也是后续每一个算法（动态规划、时序差分、DQN、Actor-Critic 的 Critic）的共同地基。

本章还会给出模仿学习、策略优化和离线 RL 共用的工具：占用度量。它把策略在给定初始分布下诱导的访问行为表示成状态—动作分布；分布相同只保证正占用状态上的条件动作分布相同，不约束永远不可达的状态。

MDP 是任务的数学描述，不等于学习器知道环境模型。解析解与下一页的动态规划需要访问转移—奖励模型；蒙特卡洛和时序差分可只使用交互样本。请把“环境存在一个 MDP”与“算法是 model-based”分开判断。

形式化定义：先固定问题合同

状态、观测与马尔可夫性质

状态 \(S_t\) 满足：给定当前状态与动作后，下一步的联合分布不再依赖更早历史，

\[\Pr(S_{t+1},R_{t+1}\mid S_0,A_0,\ldots,S_t,A_t) = \Pr(S_{t+1},R_{t+1}\mid S_t,A_t).\]

这不是说历史没有信息，而是要求状态已经包含预测未来所需的信息。智能体实际得到的通常是观测 \(O_t\)；单帧视觉、有限历史堆叠或 RNN 隐状态可能只是近似充分的历史摘要，不能保证把 POMDP 变成真实 MDP。若必须依赖历史，应显式写策略 \(\pi(A_t\mid H_t)\)、belief state 或记忆状态，而不是把 observation 无条件改名为 state。

默认设定与三层模型

除非另行说明，本页讨论有限状态、有限动作、平稳、无限时域、折扣型 MDP；奖励有界，\(0\le\gamma<1\)，策略为平稳随机策略。有限时域任务的最优价值通常随剩余时间变化，应写成 \(V_t^\pi(s)\) 或把时间并入状态。

层级 增加的对象 回答的问题
马尔可夫过程（MP） 状态与转移核 系统如何演化
马尔可夫奖励过程（MRP） 奖励与目标定义 固定演化过程价值多少
马尔可夫决策过程（MDP） 动作与策略选择 如何行动以优化回报

采用联合转移—奖励核时，可把任务写成

\[\mathcal M = \langle \mathcal S,\mathcal A,p,\gamma,\rho_0 \rangle, \qquad p(s',r\mid s,a) = \Pr(S_{t+1}=s',R_{t+1}=r\mid S_t=s,A_t=a).\]

\(\rho_0\) 是初始状态分布；它不改变一步动力学，却决定从哪些状态评价策略以及占用度量。许多教材把期望奖励 \(r(s,a)\) 与转移核 \(P(s'\mid s,a)\) 分开，写成五元组 \((\mathcal S,\mathcal A,P,r,\gamma)\)；两种约定都合法，但不能把依赖后继状态的分支奖励错误地移到期望外。

策略 \(\pi(a\mid s)\) 不属于环境动力学；它与 MDP 一起诱导轨迹分布。按全站统一时间口径，一步数据是

\[S_t,\ A_t,\ R_{t+1},\ S_{t+1}.\]

从时刻 \(t\) 开始的折扣回报是

\[G_t = \sum_{k=0}^{\infty} \gamma^kR_{t+k+1} = R_{t+1}+\gamma G_{t+1}.\]

折扣首先定义优化目标与每个决策步的时间权重；它也让有界奖励下的无穷和收敛，并使 Bellman 算子成为压缩映射。把 \(\gamma\) 解释成“未来更不可信”只是部分场景的直觉，不是定义。改变控制频率或 action repeat 后应重新校准其时间含义。

状态价值与动作价值分别是

\[V^\pi(s) = \mathbb E_\pi[G_t\mid S_t=s], \qquad Q^\pi(s,a) = \mathbb E_\pi[G_t\mid S_t=s,A_t=a],\] \[V^\pi(s) = \sum_a\pi(a\mid s)Q^\pi(s,a).\]

真正终止可建模成价值恒为 0 的吸收状态，也可在样本 target 中显式乘 termination mask；外部时间上限的 truncation 不能自动按终止处理。完整规则见环境边界与时间语义。

flowchart LR
  MDP["MDP + 初始分布"] -->|"固定策略并对动作边缘化"| MRP["策略诱导的 MRP"]
  MRP -->|"已知模型"| LIN["线性方程或迭代评估"]
  MDP -->|"已知模型做控制"| PLAN["策略迭代 / 价值迭代 / 线性规划"]
  MRP -->|"只有样本"| MC["Monte Carlo 预测"]
  MRP -->|"样本 + bootstrap"| TD["TD 预测"]

“MDP 是否存在”“模型是否已知”“用 full backup 还是 sample backup”是三组不同问题；后续算法页会分别固定这些条件。

Bellman 方程：从回报递推到固定点

1. 回报的一步展开

由回报定义逐条轨迹都有

\[G_t = R_{t+1} + \gamma G_{t+1}.\]

在奖励有界且 \(\gamma<1\) 的默认设定下，无穷级数绝对收敛。对 \(S_t=s\) 取条件期望：

\[V^\pi(s) = \mathbb E_\pi[ R_{t+1}+\gamma G_{t+1} \mid S_t=s ].\]

再对 \(A_t,S_{t+1},R_{t+1}\) 使用全期望公式。给定 \(S_{t+1}=s'\) 后，由马尔可夫性和平稳策略，

\[\mathbb E_\pi[G_{t+1}\mid S_t=s,A_t=a,S_{t+1}=s',R_{t+1}=r] = V^\pi(s').\]

因此得到 Bellman 期望方程：

\[V^\pi(s) = \sum_a\pi(a\mid s) \sum_{s',r}p(s',r\mid s,a) \left[ r+\gamma V^\pi(s') \right].\]

同理，把当前动作固定在条件中：

\[Q^\pi(s,a) = \sum_{s',r}p(s',r\mid s,a) \left[ r + \gamma \sum_{a'}\pi(a'\mid s')Q^\pi(s',a') \right].\]

这里奖励留在对 \((s',r)\) 的求和内，因此允许“进入不同后继状态获得不同奖励”。若用显式终止布尔量，则 bootstrap 项应乘 \(1-D_{t+1}\)；若终止已建成零价值吸收态，上式无需再写 mask。两种建模不能重复清零。

2. 固定策略后的线性方程

固定 \(\pi\) 后定义

\[P_\pi(s,s') = \sum_a\pi(a\mid s)\sum_r p(s',r\mid s,a),\] \[r_\pi(s) = \sum_a\pi(a\mid s) \sum_{s',r}p(s',r\mid s,a)\,r.\]

于是

\[V^\pi = r_\pi+\gamma P_\pi V^\pi, \qquad (I-\gamma P_\pi)V^\pi=r_\pi.\]

有限状态下可用线性方程求解器计算

\[V^\pi = (I-\gamma P_\pi)^{-1}r_\pi.\]

公式写逆矩阵，代码应使用 solve，不显式构造逆。因为随机矩阵满足 \(\|P_\pi\|_\infty=1\)，所以 \(\|\gamma P_\pi\|_\infty<1\)，Neumann 级数成立：

\[(I-\gamma P_\pi)^{-1} = \sum_{k=0}^{\infty}(\gamma P_\pi)^k.\]

这说明线性方程解与“累加各未来时刻的期望奖励”是同一个对象。它的限制是需要模型、存储/计算随状态数增长，而且不能直接覆盖连续或巨大状态空间；不是 Bellman 方程本身只适用于小问题。

3. Bellman 算子与压缩性

定义固定策略算子

\[(\mathcal T^\pi V)(s) = \sum_a\pi(a\mid s) \sum_{s',r}p(s',r\mid s,a) [r+\gamma V(s')],\]

以及最优算子

\[(\mathcal T_*V)(s) = \max_a \sum_{s',r}p(s',r\mid s,a) [r+\gamma V(s')].\]

对任意 \(V,W\)，概率加权平均不会放大 sup norm，因此

\[\|\mathcal T^\pi V-\mathcal T^\pi W\|_\infty \le \gamma\|V-W\|_\infty.\]

又由

\[\left|\max_a f_a-\max_a g_a\right| \le \max_a|f_a-g_a|,\]

同样有

\[\|\mathcal T_*V-\mathcal T_*W\|_\infty \le \gamma\|V-W\|_\infty.\]

两者都是 \(\gamma\)-压缩映射，因而各自有唯一固定点；反复应用算子从任意有界初值收敛到该固定点。

4. 最优固定点与最优策略存在性

不能先假设“有一个策略在所有状态同时达到逐点最大值”再证明 Bellman 最优方程。严格路线如下：

  1. 由压缩性，\(\mathcal T_*\) 有唯一固定点 \(V^\dagger\)。
  2. 在每个状态选取对 \(V^\dagger\) 贪婪的动作，得到确定性平稳策略 \(\pi^\dagger\)。
  3. 由构造， \(\mathcal T^{\pi^\dagger}V^\dagger = \mathcal T_*V^\dagger = V^\dagger.\)
  4. \(\mathcal T^{\pi^\dagger}\) 的固定点唯一，所以 \(V^{\pi^\dagger}=V^\dagger.\)
  5. 对任意策略 \(\pi\)， \(\mathcal T^\pi V^\dagger \le \mathcal T_*V^\dagger = V^\dagger.\) 利用算子单调性反复迭代并取极限，得到 \(V^\pi\le V^\dagger\)。

因此 \(V^\dagger=V^*\)，且有限折扣 MDP 存在确定性平稳最优策略。Bellman 最优方程为

\[V^*(s) = \max_a \sum_{s',r}p(s',r\mid s,a) [r+\gamma V^*(s')],\] \[Q^*(s,a) = \sum_{s',r}p(s',r\mid s,a) \left[ r+\gamma\max_{a'}Q^*(s',a') \right].\]

5. 期望方程与最优方程不要混用

维度 Bellman 期望方程 Bellman 最优方程
对动作的处理 按给定策略取期望 对动作取最大
固定点 \(V^\pi\) 或 \(Q^\pi\) \(V^*\) 或 \(Q^*\)
任务 prediction control
有限表格型常用解法 线性求解、迭代策略评估 策略迭代、价值迭代
其他合法路径 — 有限 MDP 还可用线性规划或极小规模策略枚举

“含 max”意味着不能照搬固定策略的单个线性方程求解，不意味着数学上只能使用某一种迭代算法。下一页动态规划将把两个算子变成可执行的 full-backup 算法。

策略诱导模型与占用度量

从 MDP 边缘化为 MRP

固定策略后，上一节定义的 \(P_\pi\) 与 \(r_\pi\) 对动作做了边缘化。环境模型没有消失，而是与策略共同诱导一个 MRP；这正是 prediction 可以使用 Bellman 期望算子的原因。

不要把“边缘化”理解为丢弃动作信息。若任务要优化策略，仍需保留 \(Q^\pi(s,a)\) 或原始动作条件核；只有评估固定策略时，状态价值上的 MRP 表示才足够。

归一化折扣占用度量

给定初始分布 \(\rho_0\)，定义

\[\rho^\pi(s,a) = (1-\gamma) \mathbb E_{\rho_0,\pi} \left[ \sum_{t=0}^{\infty} \gamma^t \mathbf 1\{S_t=s,A_t=a\} \right].\]

状态占用为 \(d^\pi(s)=\sum_a\rho^\pi(s,a)\)。在默认折扣设定下，

\[\sum_{s,a}\rho^\pi(s,a)=1.\]

它还必须满足 Bellman flow constraint：

\[d^\pi(s) = (1-\gamma)\rho_0(s) + \gamma \sum_{\bar s,\bar a} \rho^\pi(\bar s,\bar a) P(s\mid \bar s,\bar a).\]

这条流守恒比“把访问次数加权平均”更重要：不是任意状态—动作分布都能由某个策略和给定动力学产生。在线性规划视角中，非负性、归一化和 flow constraint 共同刻画可实现占用集合。

目标函数的线性表达

令

\[\bar r(s,a) = \mathbb E[R_{t+1}\mid S_t=s,A_t=a].\]

从 \(\rho_0\) 出发的折扣目标满足

\[J(\pi) = \mathbb E_{\rho_0,\pi}[G_0] = \frac{1}{1-\gamma} \sum_{s,a} \rho^\pi(s,a)\bar r(s,a).\]

因而固定奖励下的控制可以看成在可实现占用集合上优化线性目标；约束 RL 则加入代价占用与预算。

占用相同能推出什么

若 \(d^\pi(s)>0\)，可由占用度量恢复该状态上的条件动作分布：

\[\pi(a\mid s) = \frac{\rho^\pi(s,a)}{d^\pi(s)}.\]

若 \(d^\pi(s)=0\)，分母为零，策略在该不可达状态上怎样定义都不会改变占用度量。因此

  • 占用度量相同，推出策略在正占用状态上相同；
  • 在零占用状态上，只能说两策略属于同一个行为等价类；
  • 结论依赖相同的动力学、初始分布与折扣定义。

这也解释了离线 RL 的覆盖问题：数据没有占用的区域，不能仅靠条件频率恢复可靠策略或价值。

与 GAIL 的准确连接

GAIL 匹配专家与学习者诱导的状态—动作占用分布，而不是要求策略在每个不可达状态逐点相同。在无限判别器表达能力、判别器达到最优且使用标准 logistic 对抗目标等理想条件下，最优判别器目标可与 Jensen–Shannon 散度联系起来（相差符号、常数或缩放取决于损失约定）。

实际训练中，有限数据、有限模型和非凸优化都使“判别器分不出来”不能直接证明两个真实占用分布完全相同。完整推导见模仿学习与 GAIL；行为克隆与交互式模仿的边界见模仿学习总览。

占用度量还连接 TRPO的性能差分分析与离线强化学习的数据覆盖诊断，但各页会采用适合自身目标的归一化口径，使用前要先核对定义。

从模型期望到样本估计

本页到此只建立数学对象与已知模型下的精确关系。模型未知时，Bellman 方程仍成立，但无法直接枚举 \((s',r)\) 求期望，需要用样本近似。

学习顺序应保持三步：

  1. 动态规划：已知模型，对所有后继分支做 expected/full backup。
  2. 蒙特卡洛方法：不需要模型，用完整 episode 回报估计价值，不 bootstrap。
  3. 时序差分：不需要模型，用一步或多步样本并 bootstrap。

first-visit/every-visit、MC control、importance sampling、coverage、截断尾部和可执行测试统一由蒙特卡洛页负责，本页不再保留一份不完整副本。下面的采样代码只用于验证占用度量，不承担 MC prediction 教学。

代码实现

下面用一个 5 状态小型 MDP 验证三件事：策略边缘化、线性方程求值，以及占用度量的归一化、策略恢复和目标恒等式。示例只依赖 NumPy；完整 MC 预测代码由蒙特卡洛页负责。

第一段：定义 5 状态 MDP

import numpy as np

STATES = ["s1", "s2", "s3", "s4", "s5"]
START_STATES = ["s1", "s2", "s3", "s4"]  # rho_0：四个非吸收态上的均匀分布
S_IDX = {s: i for i, s in enumerate(STATES)}
GAMMA = 0.5                      # 折扣因子，取 0.5 便于手算核对

# P_sas[(s, a)] 是一个 dict：下一状态 -> 转移概率，对应 P(s' | s, a)
P_SAS: dict[tuple[str, str], dict[str, float]] = {
    ("s1", "保持s1"): {"s1": 1.0},
    ("s1", "前往s2"): {"s2": 1.0},
    ("s2", "前往s1"): {"s1": 1.0},
    ("s2", "前往s3"): {"s3": 1.0},
    ("s3", "前往s4"): {"s4": 1.0},
    ("s3", "前往s5"): {"s5": 1.0},
    ("s4", "前往s5"): {"s5": 1.0},
    ("s4", "概率前往"): {"s2": 0.2, "s3": 0.4, "s4": 0.4},   # 唯一的随机转移
    ("s5", "停留"): {"s5": 1.0},                              # 吸收态自环
}

# R_SA[(s, a)] 对应 r(s, a)
R_SA: dict[tuple[str, str], float] = {
    ("s1", "保持s1"): -1.0,
    ("s1", "前往s2"): 0.0,
    ("s2", "前往s1"): -1.0,
    ("s2", "前往s3"): -2.0,
    ("s3", "前往s4"): -2.0,
    ("s3", "前往s5"): 0.0,
    ("s4", "前往s5"): 10.0,
    ("s4", "概率前往"): 1.0,
    ("s5", "停留"): 0.0,
}

# 每个状态可用的动作列表
ACTIONS_OF: dict[str, list[str]] = {}
for (s, a) in P_SAS:
    ACTIONS_OF.setdefault(s, []).append(a)

# 均匀随机策略：每个状态在可用动作上等概率
POLICY_UNIFORM: dict[str, dict[str, float]] = {
    s: {a: 1.0 / len(acts) for a in acts} for s, acts in ACTIONS_OF.items()
}

for (s, a), probs in P_SAS.items():                 # 合法性自检：转移概率之和必须为 1
    assert abs(sum(probs.values()) - 1.0) < 1e-9, (s, a)

这段把 MDP 五元组逐项落成数据结构，与形式化定义一一对应：STATES 是 \(\mathcal{S}\)，ACTIONS_OF 给出每个状态的 \(\mathcal{A}\)，P_SAS 是 \(P(s' \mid s, a)\)，R_SA 是 \(r(s, a)\)，GAMMA 是 \(\gamma\)。

三处设计说明。第一，s5 被设计成吸收态：它只有一个动作「停留」，转移回自己且奖励为 0。好处有两个——\(V(s_5) = 0\) 自动成立；占用度量上所有状态-动作对的总和严格等于 1（轨迹若提前终止，总和会小于 1，归一化性质就不成立）。第二，s4 的「概率前往」是全图唯一的随机转移，它使这个例子不至于退化成确定性问题，蒙特卡洛估值才会真正体现出方差。第三，GAMMA 取 0.5 而非常用的 0.99，是因为 0.5 衰减很快，\(\gamma^{20}\) 已在百万分之一量级，截断到 20 步的偏差可忽略，方便验证两种方法是否一致。

容易写错的地方：ACTIONS_OF 是从 P_SAS 的键遍历出来的；若另外手动维护一份动作列表而与 P_SAS 不同步，某些状态的策略概率就不会归一，后面所有结果都会错。末尾那句 assert 就是为了拦住这类错误。

第二段：边缘化并求解析解

def marginalize(policy: dict[str, dict[str, float]]) -> tuple[np.ndarray, np.ndarray]:
    """把 MDP 加策略边缘化成 MRP。

    返回 (P_pi, r_pi)：
      P_pi[i][j] = sum_a pi(a|s_i) * P(s_j | s_i, a)
      r_pi[i]    = sum_a pi(a|s_i) * r(s_i, a)
    """
    n = len(STATES)
    P_pi = np.zeros((n, n))
    r_pi = np.zeros(n)
    for s, action_probs in policy.items():
        i = S_IDX[s]
        for a, pa in action_probs.items():
            r_pi[i] += pa * R_SA[(s, a)]                    # 奖励的边缘化
            for s_next, p in P_SAS[(s, a)].items():
                P_pi[i][S_IDX[s_next]] += pa * p            # 转移的边缘化
    return P_pi, r_pi


def analytic_value(P_pi: np.ndarray, r_pi: np.ndarray, gamma: float) -> np.ndarray:
    """MRP 的解析解 V = (I - gamma * P)^(-1) R。"""
    n = P_pi.shape[0]
    I = np.eye(n)
    V = np.linalg.solve(I - gamma * P_pi, r_pi)
    return V


P_pi, r_pi = marginalize(POLICY_UNIFORM)
V_analytic = analytic_value(P_pi, r_pi, GAMMA)

assert np.allclose(P_pi.sum(axis=1), 1.0)
bellman_residual = np.max(
    np.abs((np.eye(len(STATES)) - GAMMA * P_pi) @ V_analytic - r_pi)
)
assert bellman_residual < 1e-10

print("边缘化后每行之和（应全为 1）:", P_pi.sum(axis=1).round(6))
print("线性方程无穷范数残差: %.3e" % bellman_residual)
print("解析解 V:")
for s in STATES:
    print("  V(%s) = %+.6f" % (s, V_analytic[S_IDX[s]]))

marginalize 逐字实现了前文的两条边缘化公式。注意 P_pi[i][S_IDX[s_next]] += pa * p 用的是累加而不是赋值：一般 MDP 中，不同动作可能转移到同一个下一状态，边缘化时必须把这些路径的概率加起来。当前 5 状态示例恰好没有动作间共享后继，不能拿它本身证明这一点；使用累加是为了让实现对一般转移核仍然正确。写成赋值是这段代码最典型的错误，且不会报错，只会让结果悄悄偏小。

analytic_value 使用 np.linalg.solve 求解 \((I-\gamma P_\pi)V=r_\pi\)，避免显式构造逆矩阵。\(\gamma\) 越接近 1，矩阵条件数可能越差，因此还应检查线性方程残差。P_pi.sum(axis=1) 则验证边缘化后的每一行仍为概率分布。

第三段：为占用度量采样轨迹

这一采样器只服务于下一段的占用度量校验；MC prediction 的 first/every-visit 更新不再在本页重复。

Transition = tuple[str, str, float, str]


def sample_episode(
    policy: dict[str, dict[str, float]],
    start: str,
    max_steps: int,
    rng: np.random.Generator,
) -> list[Transition]:
    """从简化的五状态模型采一条定长轨迹。"""
    episode: list[Transition] = []
    state = start
    for _ in range(max_steps):
        actions = list(policy[state])
        action_probs = np.array([policy[state][a] for a in actions])
        action = actions[rng.choice(len(actions), p=action_probs)]

        reward_next = R_SA[(state, action)]
        next_states = list(P_SAS[(state, action)])
        next_probs = np.array(
            [P_SAS[(state, action)][s_next] for s_next in next_states]
        )
        next_state = next_states[
            rng.choice(len(next_states), p=next_probs)
        ]
        episode.append((state, action, reward_next, next_state))
        state = next_state
    return episode

这个示例把奖励简化为确定性的 \(r(s,a)\)。若奖励依赖后继分支，模型和采样器都应直接表示联合 \((S_{t+1},R_{t+1})\)，不能先取一个与实际分支脱钩的奖励。

第四段：占用度量估计与恒等式校验

def occupancy_measure(policy, num_episodes: int, max_steps: int,
                      gamma: float, seed: int = 0) -> dict[tuple[str, str], float]:
    """估计 rho^pi(s, a) = (1 - gamma) * sum_t gamma^t * P(s_t = s, a_t = a)。"""
    rng = np.random.default_rng(seed)
    # counts_at_t[t][(s, a)]：第 t 步恰好取到 (s, a) 的轨迹条数
    counts_at_t: list[dict[tuple[str, str], int]] = [dict() for _ in range(max_steps)]
    for ep in range(num_episodes):
        # 分层轮换实现 rho_0 上的平衡采样；num_episodes 应为 4 的倍数
        start = START_STATES[ep % len(START_STATES)]
        episode = sample_episode(policy, start, max_steps, rng)
        for t, (s, a, r, s_next) in enumerate(episode):
            counts_at_t[t][(s, a)] = counts_at_t[t].get((s, a), 0) + 1

    rho: dict[tuple[str, str], float] = {}
    for t in range(max_steps):
        discount = gamma ** t                       # 注意指数是时刻 t，不是轨迹编号
        for key, cnt in counts_at_t[t].items():
            rho[key] = rho.get(key, 0.0) + discount * (cnt / num_episodes)
    for key in rho:
        rho[key] *= (1.0 - gamma)                   # 归一化系数
    return rho


NUM_EPISODES = 20000
MAX_STEPS = 20
assert NUM_EPISODES % len(START_STATES) == 0
rho_hat = occupancy_measure(
    POLICY_UNIFORM,
    num_episodes=NUM_EPISODES,
    max_steps=MAX_STEPS,
    gamma=GAMMA,
    seed=1,
)

rho_mass = sum(rho_hat.values())
expected_truncated_mass = 1.0 - GAMMA ** MAX_STEPS
assert abs(rho_mass - expected_truncated_mass) < 1e-10
print("占用度量总和: %.6f（长度 20 的理论值 %.6f）" % (
    rho_mass, expected_truncated_mass
))

# 校验一：由占用度量反推策略，应还原出均匀策略
print("由 rho 反推的策略:")
for s in STATES:
    denom = sum(v for (ss, aa), v in rho_hat.items() if ss == s)
    if denom <= 0:
        continue
    recovered = {aa: v / denom for (ss, aa), v in rho_hat.items() if ss == s}
    print("  %s -> %s" % (s, {k: round(v, 4) for k, v in recovered.items()}))

# 校验二：J(pi) = 1/(1-gamma) * sum_{s,a} rho(s,a) * r(s,a)
J_from_rho = sum(
    rho_hat[(s, a)] * R_SA[(s, a)] for (s, a) in rho_hat
) / (1.0 - GAMMA)
J_from_value = np.mean([V_analytic[S_IDX[s]] for s in START_STATES])
print("由占用度量算出的截断 J(pi) = %+.6f" % J_from_rho)
print("由解析价值与 rho_0 算出的 J(pi) = %+.6f" % J_from_value)
print("两者差值（含采样误差与截断尾部）= %+.6e" % (
    J_from_rho - J_from_value
))

这段逐字实现了流程 C，并附带两个校验，它们分别对应前文的两条理论结论。

校验一用的是必要性证明里那条反推公式 \(\pi(a \mid s) = \rho^{\pi}(s, a) / \sum_{a'} \rho^{\pi}(s, a')\)。因为本例的策略是均匀的，每个状态有两个动作（s5 只有一个），反推结果应当接近 0.5（s5 接近 1.0）。这个校验直接验证了「占用度量编码了策略」这一结论，是本页最值得亲手跑一遍的部分。

校验二验证 \(J(\pi) = \frac{1}{1-\gamma}\sum_{s,a}\rho^{\pi}(s,a) r(s,a)\)。代码现已同时打印「截断占用估计得到的目标」与「按初始分布对解析价值加权得到的无限时域目标」，并打印差值。两者的剩余差异来自有限轨迹采样和长度 20 的尾部截断，不能强行断言为零。

两处容易写错：discount = gamma ** t 的指数必须是时刻 \(t\)，写成轨迹编号或常数是最常见的错误；(1.0 - gamma) 只能乘一次且必须在对所有时刻求和之后乘，提前乘进每一项虽然等价，但容易在后续修改中漏乘或重复乘。

关于总和：理论上 \(\sum_{s,a}\rho^{\pi}(s,a) = 1\)，但代码把轨迹截断到 max_steps 步，丢掉的尾部总权重是 \(\gamma^{T_{\max}}\)。本例中这项在百万分之一量级，因此打印出的总和应当非常接近 1。若把 \(\gamma\) 改成 0.99 而不同步增大 \(T_{\max}\)，总和会明显小于 1——这不是实现错误，而是截断偏差，是这个方法的固有代价。

连续观测上的 MC 回归、episode 边界和 truncated 尾部处理见蒙特卡洛方法与环境边界页。本页不再放置一份把 CartPole 时间上限直接当作零尾部的示例。

验证合同与参数

这段代码的目标不是给出一组“看起来接近”的数，而是建立可断言的闭环：

  1. 每个 \((s,a)\) 的转移概率和为 1，策略概率和为 1。
  2. 边缘化后 \(P_\pi\) 每行和为 1。
  3. 线性解残差 \(\|(I-\gamma P_\pi)V-r_\pi\|_\infty\) 接近数值精度。
  4. 长度 \(T\) 的占用估计总质量应接近 \(1-\gamma^T\)，而不是在有限截断下强行等于 1。
  5. 只在 \(d^\pi(s)>0\) 的状态恢复策略，并检查与原策略的最大绝对误差。
  6. 比较 \(\mathbb E_{S_0\sim\rho_0}[V^\pi(S_0)]\) 与占用度量计算的 \(J(\pi)\)，同时报告截断误差。
  7. 采样结果用多个独立 seed 汇总，不把单次运行称为实验结论；统计口径见评估与可复现页。
参数 本页示例 准确含义
\(\gamma\) 0.5 每个决策步的折扣；便于手算，不代表真实任务推荐值
\(T\) 20 占用估计截断长度；遗漏的归一化质量为 \(\gamma^T\)
轨迹数 20000 采样误差预算；应结合多 seed 区间而非有效数字拍脑袋
\(\rho_0\) 四个非吸收态均匀 决定评价目标与占用分布；代码轮换起点实现平衡采样

提高轨迹数只能降低采样方差，不能消除有限 \(T\) 的截断偏差；提高 \(T\) 也不能弥补某些状态—动作从未被覆盖。误差来源必须分开诊断。

小结与下一章的衔接

本页固定了后续算法共同依赖的合同：

  • 状态满足马尔可夫语义；实际 observation、历史摘要与 belief state 必须另行说明。
  • 一步转移用 \(S_t,A_t,R_{t+1},S_{t+1}\)，一般奖励与后继状态由联合核产生。
  • Bellman 期望算子评估固定策略；最优算子刻画控制，两者在有限折扣设定下都是压缩映射。
  • 最优固定点证明同时给出确定性平稳最优策略的存在性；max 不等于“只能用一种迭代法”。
  • 占用度量满足 flow constraint，只能在正占用状态恢复策略。

接下来的主链是 动态规划（已知模型的 full backup）→ 蒙特卡洛（完整回报、不 bootstrap）→ 时序差分（样本 backup + bootstrap）。状态/动作规模扩大后的函数逼近见 DQN；占用度量的下游分别见 GAIL、TRPO与离线强化学习。

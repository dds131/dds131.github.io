知识库/机器人模仿学习与 VLA/生成式动作模型

METHOD FOUNDATION · SAME POLICY I/O · NO CROSS-PAPER RANKING

先固定同一个条件动作块问题，再比较 Regression、CVAE、Diffusion 与 Flow Matching 学习什么、如何生成、怎样验收。

页面身份：这是 ACT Limits 的并列扩展入口和 VLA 动作头的公共方法基础，不是“CVAE → Diffusion → Flow → VLA”的升级路线；没有普通上一页或下一页。</div>

PAPER ◉论文直接给出的定义、协议或作者报告。
CODE ◆固定源码中的接口、默认值与控制流事实。
DERIVED △由公式或合同可复算的关系，不冒充实验结果。
GUIDANCE →工程选择与验收建议；当前全部实验状态为 NOT_RUN。
POINT ESTIMATERegression直接输出一个动作块；简单、可作为强基线，但单一统计量可能落在多峰之间。
LATENT VARIABLECVAE以后验训练潜变量、以先验部署解码；潜变量存在不等于上线时实际使用多样性。
ITERATIVE DENOISINGDiffusion学习噪声过程的反演参数；推理成本与参数化、schedule、sampler 和 NFE 共同决定。
CONDITIONAL ODEFlow Matching学习条件概率路径的速度场；端点、时间方向、solver 与步数必须显式登记。

统一策略输入输出合同锚点

共同问题：给定条件生成未来动作块

统一对象写为 p(A_t | c_t)。条件 c_t 至少包含当前观测，可组合图像、机器人状态；语言、历史和任务 ID 是可选条件，不能默认每种方法都拥有。输出是归一化未来动作块 A_t=[a_t,...,a_{t+H-1}]∈R^{H×D_a}。

比较前必须冻结的 generative-action-policy-io-v1
域 必须登记 未固定时的风险
观测条件 字段、shape、dtype、相机名称与顺序；状态维、单位与 frame；语言/历史/任务 ID 是否存在。 网络相同但条件信息不同，结果不可归因于生成机制。
动作张量 H×D_a、绝对/增量/速度表示、关节顺序、单位、frame、旋转与夹爪语义。 shape 相同仍可能是完全不同的控制合同。
有效性 pad、mask、loss reduction、缺失槽与 episode 边界。 无效位置进入损失或采样，产生静默偏差。
数值变换 normalizer、统计量 hash、反归一化、clip 与独立安全限幅。 输出幅值错误会被误判为模型能力问题。
生成协议 seed、schedule、solver、NFE、初始噪声、候选数与 warm start。 方法名相同但实际推理预算和随机性不同。
系统消费 H、E、R、控制频率、deadline、队列与取消/重置。 生成质量与系统时延、陈旧动作或队列切换混在一起。

单输出 Regression：点估计与条件均值边界

单输出模型写作 A_hat=f_theta(c)。在总体风险、无限容量与全局最优等理想条件下，平方误差的最优统计量是 E[A|c]；绝对误差对应条件中位数集合。这是损失函数的统计边界，不表示有限网络、有限数据和优化过程一定实际达到总体最优。

当同一条件下存在明显多峰的互斥动作时，条件均值可能落到低密度甚至不可执行区域；但条件近单峰、数据一致、延迟预算严格时，点回归仍可能是简单而有效的基线。应先把它作为同 backbone、同数据、同合同的对照，而不是因为“不是生成模型”就删除。

LEARNED OBJECT一个条件统计量MSE 常对应条件均值；L1 常对应条件中位数集合，具体还受有限样本、容量和优化影响。
STRENGTH一次前向、协议清楚适合建立延迟、误差、adapter 与闭环消费的强基线。
FAILURE MODE多峰之间的折中若条件不足以判别模式，单一输出可能不能代表任一有效策略。

不要按 loss 名称分类模型：Flow Matching 常用 MSE 回归速度，Diffusion 也常用 MSE 回归噪声或其他参数；“使用 MSE”不等于“模型是点回归”。</div>

CVAE：潜变量、后验训练与先验部署

CVAE 由训练后验 q_phi(z|A,c)、先验 p(z|c)（也可选固定 p(z)）和解码器 p_theta(A|z,c) 组成。目标通常包含重建项与 KL 正则；必须登记 latent shape、先验是否条件化、beta、采样方式、mask 与 reduction，不能只写“用了 ELBO”。

训练时后验能看到目标动作，部署时只能从先验取零、均值、随机样本或多个候选，因此 posterior collapse、训练后验与部署先验错配、固定 z 导致多样性未被使用是不同问题。潜变量可提供多样性入口，但不保证模式可解释、样本有效或系统选中了任务正确的模式。

ACT 的具体边界（PAPER/CODE）：固定实现训练时用 actions 构造 posterior；部署时不传 actions 并令 z=0，之后仍经过带 bias 的 latent_out_proj。这不是“decoder 接收全零条件”，也不是“每次从先验随机采样多个候选”。</div>

部署比较至少同时记录：取零/均值/固定样本/重采样；候选数 N；是否重排序；样本选择依据；候选计算成本；独立有效性与安全门。只报告 min-over-N 会引入 oracle 选择，必须同时报告 N、平均和最差行为。

Diffusion：前向加噪与迭代反演

离散前向过程可写为 x_k=sqrt(alpha_bar_k)A+sqrt(1-alpha_bar_k)epsilon。训练从数据动作、噪声与时刻构造 x_k，网络可预测噪声、score、v、干净动作 x0 或其他参数化；必须查看具体论文和代码，不能把所有动作扩散都写成 epsilon prediction。

推理从噪声初始化，经 scheduler 与 sampler 多次调用网络得到动作样本。训练 steps 与推理 timesteps 不是同一概念；DDPM、DDIM 和其他 solver 的随机性、更新式与步数也不同。必须记录 schedule、parameterization、sampler、是否 stochastic、clip、normalizer、condition mask、H×D_a、NFE、seed 与 warm start。

Diffusion Policy 给出条件动作扩散与 receding-horizon control 的实例，但后者是执行协议，不是扩散数学定义。DexGraspVLA 的 epsilon prediction、cosine schedule、DDIM 与 Immiscible Diffusion 是一个具体实现组合，不能外推成整个方法家族的默认配置。

“能够采样”不等于覆盖真实模式、满足动力学或碰撞约束、识别失败或选中正确候选。多样性、有效性、条件一致性、物理约束和闭环任务结果必须分开测量。

Flow Matching锚点

Flow Matching：条件路径、速度场与 ODE

统一教学约定取 tau=0 为噪声、tau=1 为动作：x_tau=(1-tau)epsilon+tau A，固定动作—噪声对的条件速度是 A-epsilon；网络学习条件边缘速度 v_theta(x_tau,tau,c)，推理从噪声端数值积分 ODE 到动作端。

openpi 使用相反时间方向：t=1 是噪声、t=0 是动作，x_t=t epsilon+(1-t)A，目标是 epsilon-A，从 1 积分到 0。两者满足 tau=1-t，只是时间和速度符号约定，不是两种算法。

CONDITIONAL PATH固定样本对的路径线性 CFM 中固定 (A,epsilon) 的插值是直线。
MARGINAL FIELD混合后的速度场边缘速度随 x/t/c 变化，不能由一条样本对路径直接替代。
NUMERICAL TRAJECTORYsolver 的积分轨迹有限 NFE、步长与数值误差共同决定实际生成轨迹。

条件路径为直线，不代表边缘流或积分轨迹全局为直线；Flow Matching 也可以使用非线性或扩散概率路径。因此不能做“Flow 一定直、Diffusion 一定弯”的伪二分。实现至少登记端点、路径、时间采样/截断、速度参数化、mask/reduction、初始噪声、solver、NFE/step size、最后端点、normalizer、条件缓存、形状与 seed。

同接口比较矩阵锚点

同一接口下的训练、采样与计算对照

REGRESSION · ONE OUTPUT动作块点估计随机量：可无。
常见监督：最终动作 L1/L2。
推理：一次前向。
多样性入口：无或另加分布头。
关键失效：条件统计量不可执行。
CVAE · LATENT给定 z 的动作解码随机量：posterior z。
常见监督：重建 + KL。
推理：一次或多 z。
多样性入口：latent。
关键失效：collapse、先验错配。
DIFFUSION · REVERSE PROCESS噪声过程的反演参数随机量：时刻与噪声。
常见监督：noise/score/v/x0。
推理：sampler 多步。
多样性入口：初始噪声。
关键失效：schedule、少步误差、无效样本。
FLOW · VELOCITY FIELD条件路径的速度场随机量：时间与端点配对。
常见监督：条件速度。
推理：ODE 多步积分。
多样性入口：初始噪声。
关键失效：时间约定、solver 误差、场未学好。
不能仅按方法名断言谁更快
成本字段 统一记录方式 禁止简化
网络调用 NFE、候选数、batch、每次评估调用的 backbone/condition cache/action head 范围。 只用“单步/多步”替代完整调用成本。
系统时延 p50/p95、jitter、硬件、精度、预处理/后处理与队列等待。 无条件声称 Flow 比 Diffusion 少步，或 CVAE 必然最快。
质量条件 同任务、数据、容量、合同、NFE/solver 和候选选择协议。 将跨论文数字拼成性能排行榜。

VLA 描述语言—视觉—动作条件和预训练范围，不自动指定动作生成器；语言能力、跨本体数据和模型规模也不能归功于 Flow 或 Diffusion 本身。

同协议评测包锚点

执行协议、评测 bundle 与故障诊断

训练 bundle 至少冻结：episode IDs/split、条件字段、动作表示、H×D_a、mask/reduction、normalizer hash、模型容量/初始化、optimizer/schedule、更新数、随机源、方法特有时间/噪声采样、checkpoint 选择、环境与代码 hash。只对齐 epoch 或参数量不够。

指标回答不同问题，不能互相替代
层级 必须报告 证据边界
离线点误差 L1/L2、mask、reduction、逐维和逐时间步统计。 只衡量指定统计量，不直接等于分布质量或闭环成功。
分布与集合 可计算时报告 NLL；否则报告代理指标、覆盖、多样性和条件一致性。 多样性高不等于任务模式正确。
物理有效性 动力学、碰撞、速度/加速度、action bounds 与无效动作拒绝。 生成器不能替代独立安全层。
多样本 N、平均/最差行为、选择器与 min-over-N。 min-over-N 是 oracle 倾向指标，不能单独报告。
闭环 同任务、观测、动作空间、频率、H/E/R、延迟、安全层、seed/trial、成功定义。 跨任务、硬件或控制协议不可直接排序。
系统 失败分类、恢复、干预、超时、NFE、生成时延 p50/p95 与拒绝率。 平均成功率不足以解释首次分歧。

执行系统边界锚点

H、E、R 与系统时间线

动作块可整块开环执行，也可只执行前 E 步后重规划、每 R 步查询、对重叠块做时间集成，或用 RTC/异步队列交接。它们都能与四类生成机制组合，不属于某一模型的专有定义。

从观测时间到控制器消费的可审计事件
阶段 事件 应记录
输入 observation timestamp、policy start。 观测年龄、预处理版本与条件字段。
生成 sample/solver 每步、policy end。 NFE、每步耗时、seed、候选数与缓存。
门禁 postprocess、安全检查、enqueue。 反归一化、frame、限幅、拒绝原因与队列深度。
执行 execution start/end、cancel/reset、next observation。 action age、deadline miss、jitter、控制器消费频率。

固定噪声有利于复现实验，不代表部署时最佳；每次重采样可能增加样本差异，也可能造成跨块模式切换。warm start、噪声复用、候选重排序和一致性约束都是额外机制，必须独立登记与消融。

安全链必须独立包含反归一化、frame 变换、限幅、碰撞/工作空间检查、watchdog、fallback 和人工接管。平滑、低 jerk 或高任务成功率都不等于物理安全。

FAULT 1条件或观测不足同一可见条件无法判别任务阶段或目标。
FAULT 2标签模式不一致多峰来自示范约定冲突，而非模型容量不足。
FAULT 3数据合同错误normalizer、mask、时间对齐或动作语义不一致。
FAULT 4生成目标错误参数化、端点或时间方向与训练目标不匹配。
FAULT 5数值求解不匹配schedule、solver、NFE 或最后端点产生偏差。
FAULT 6模式选择错误样本本身有效，但不符合当前任务意图。
FAULT 7执行系统错误延迟、队列、动作陈旧或跨块模式切换。
FAULT 8安全层拒绝输出触及 frame、限位、碰撞或工作空间门禁。

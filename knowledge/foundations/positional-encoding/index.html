位置编码要解决的是一个结构性缺陷：自注意力本身读不到顺序。把「机器人抓起杯子」里的「机器人」和「杯子」对调，自注意力算出的两份表示只是跟着对调，内容一个字不变。语言、动作序列、图像 patch 网格都依赖顺序，因此必须在进入注意力之前或之中，把位置信息显式地喂进去。

本页只讲位置信息如何进入注意力打分。缩放点积、Q/K/V 的定义与多头拆分本身在 注意力机制一页，两页配套阅读。

为什么需要位置编码：自注意力是置换等变的

这是整页的出发点，值得先把性质本身写清楚。设输入是 \(n\) 个 token 的表示矩阵 \(X \in \mathbb{R}^{n \times d}\)，第 \(i\) 行是第 \(i\) 个 token 的向量。自注意力的计算是：

\[\mathrm{Attn}(X) = \mathrm{softmax}\!\left( \frac{(XW_Q)(XW_K)^{\top}}{\sqrt{d_k}} \right) X W_V\]

取任意一个置换矩阵 \(P \in \{0,1\}^{n \times n}\)（每行每列恰有一个 1，作用是重排序列）。把输入换成 \(PX\)，逐项代入：

\[(PXW_Q)(PXW_K)^{\top} = P\,(XW_Q)(XW_K)^{\top} P^{\top}\]

softmax 是逐行、逐元素的运算，行与列被同一个置换重排后，结果就是原注意力矩阵被同样重排，即 \(P A P^{\top}\)。再右乘 \(PXW_V\)：

\[\mathrm{Attn}(PX) = P A P^{\top} P X W_V = P A X W_V = P \cdot \mathrm{Attn}(X)\]

这里用到了 \(P^{\top}P = I\)。结论是 \(\mathrm{Attn}(PX) = P \cdot \mathrm{Attn}(X)\)：输入怎么重排，输出就怎么重排，每个 token 拿到的表示内容完全不变。 这个性质叫置换等变（permutation-equivariant）。它带来两个直接后果：

  • 模型无法区分词序。「杯子在盘子上」与「盘子在杯子上」，只要词集合相同，自注意力给出的表示集合就相同。
  • 位置信息必须来自模块之外。RNN 的顺序来自逐步递推，CNN 的顺序来自卷积核的局部相对位置，而自注意力两者都没有——它换来的是完全并行与常数级的最长依赖路径，代价就是顺序信息归零。
  • 需要区分两个术语。置换等变（equivariant）指输出跟着输入一起重排，置换不变（invariant）指输出完全不受重排影响。自注意力是前者，在它上面接一个求和或平均池化之后整句表示变成后者，二者都意味着顺序没有被建模。

正弦位置编码

完整公式

Transformer 原文给出的方案，不含任何可训练参数。设序列位置为 \(pos\)，编码维度下标为 \(i\)，模型维度为 \(d_{\text{model}}\)。偶数维用正弦、奇数维用余弦：

\[PE_{(pos,\, 2i)} = \sin\!\left( \frac{pos}{10000^{\,2i / d_{\text{model}}}} \right)\] \[PE_{(pos,\, 2i+1)} = \cos\!\left( \frac{pos}{10000^{\,2i / d_{\text{model}}}} \right)\]

逐项解释每个符号：

  • \(pos\)：token 在序列中的绝对位置，从 0 开始的整数。它是唯一随 token 变化的量。
  • \(i\)：维度对的下标，取值 \(0, 1, \dots, d_{\text{model}}/2 - 1\)。第 \(i\) 对占据编码向量的第 \(2i\) 与 \(2i+1\) 两个分量。
  • \(d_{\text{model}}\)：模型隐藏维度，也是位置编码向量的长度。原文取 512。
  • \(10000\)：底数，控制频率随维度衰减的跨度，下面单独讲。
  • \(2i/d_{\text{model}}\)：把维度下标归一化到 \([0, 1)\)，使得同一套公式在任何 \(d_{\text{model}}\) 下都给出相同的频率分布形状。

为便于后面的推导，把第 \(i\) 对维度的角频率 \(\omega_i\) 与对应波长 \(\lambda_i\)（位置每前进 \(\lambda_i\)，这一对分量绕回原值）单独记出来：

\[\omega_i = \frac{1}{10000^{\,2i / d_{\text{model}}}}, \qquad \lambda_i = \frac{2\pi}{\omega_i} = 2\pi \cdot 10000^{\,2i / d_{\text{model}}}\]

于是编码可以写成紧凑形式 \(PE_{pos} = [\sin(pos\,\omega_0),\ \cos(pos\,\omega_0),\ \sin(pos\,\omega_1),\ \cos(pos\,\omega_1),\ \dots]^{\top}\)。

一：为什么用不同频率的正弦余弦对

当 \(i\) 从 0 增到 \(d_{\text{model}}/2 - 1\)，\(\omega_i\) 从 1 单调降到 \(10^{-4}\) 附近，波长 \(\lambda_i\) 相应地从 \(2\pi\) 增到 \(10000 \cdot 2\pi\)。也就是说，编码向量的前段是高频分量、后段是低频分量，一个位置被同时表示在多个尺度上。

这样设计有三个可以说清楚的理由。

  • 单一频率不足以唯一标识位置。 只用一个正弦，\(\sin\) 在一个周期内取值会重复，两个相距半个周期对称的位置得到相同的值。叠加多个互不成整数倍关系的频率之后，只有真正相同的位置才会在全部维度上同时取相同值。
  • 高频维度负责近邻分辨、低频维度负责远程定位。 相邻两个位置在高频维度上差异明显，模型据此分辨局部顺序；而在低频维度上，几十上百个位置才转过一小段相位，模型据此判断「大致在句子的哪一段」。这就是「多尺度」的实际含义。
  • 每一对的正弦与余弦必须成对出现。 单独一个 \(\sin(pos\,\omega_i)\) 只给出相位的一个投影，配上 \(\cos(pos\,\omega_i)\) 之后，这一对分量构成单位圆上的一个点，相位被完整确定。没有这一点，下一小节的线性变换推导就不成立。
把维度下标从小到大排开，各维的翻转周期依次按几何级数变长，这个结构与二进制计数器各个数位的翻转周期一致：最低位每步翻转一次，越高位翻转越慢。区别在于正弦编码是连续取值而非 0/1 取值，因此在位置之间可以平滑插值。

二：为什么这种设计能表达相对位置

这是正弦编码最关键的性质：\(PE_{pos+k}\) 可以由 \(PE_{pos}\) 经过一个只依赖于 \(k\)、与 \(pos\) 无关的线性变换得到。

只看第 \(i\) 对维度，把它写成二维向量 \(p_i(pos) = [\sin(pos\,\omega_i),\ \cos(pos\,\omega_i)]^{\top}\)。对位置 \(pos + k\) 直接展开和角公式：

\[\begin{aligned} \sin\!\big((pos+k)\,\omega_i\big) &= \sin(pos\,\omega_i)\cos(k\,\omega_i) + \cos(pos\,\omega_i)\sin(k\,\omega_i) \\ \cos\!\big((pos+k)\,\omega_i\big) &= \cos(pos\,\omega_i)\cos(k\,\omega_i) - \sin(pos\,\omega_i)\sin(k\,\omega_i) \end{aligned}\]

把这两行写成矩阵乘法：

\[p_i(pos+k) = \begin{bmatrix} \cos(k\,\omega_i) & \sin(k\,\omega_i) \\ -\sin(k\,\omega_i) & \cos(k\,\omega_i) \end{bmatrix} p_i(pos) = M_i(k)\, p_i(pos)\]

\(M_i(k)\) 是一个二维旋转矩阵，它的元素只含 \(k\) 与 \(\omega_i\)，完全不含 \(pos\)。 把所有维度对拼起来，得到一个分块对角矩阵：

\[PE_{pos+k} = M(k)\, PE_{pos}, \qquad M(k) = \mathrm{diag}\big( M_0(k),\, M_1(k),\, \dots \big)\]

这个结论的意义在于：从位置 \(pos\) 走到 \(pos+k\)，编码向量所经历的变换处处相同，与出发点无关。线性层完全有能力学到这样一个固定的线性映射，因此模型可以在不显式获得 \(k\) 的情况下，从编码里恢复出「相隔多远」这件事。再补两条推论：

  • 内积只依赖相对位置。 因为 \(M_i(k)\) 是正交矩阵，\(\langle PE_{pos},\, PE_{pos+k} \rangle\) 展开后每一对维度贡献 \(\cos(k\,\omega_i)\)，求和结果只与 \(k\) 有关。也就是说，两个位置编码的相似度是距离的函数，随距离增大而整体衰减。
  • 这个性质是「可表达」而不是「已实现」。 原始 Transformer 把 \(PE\) 加到词嵌入上再一起投影成 Q/K，交叉项里混入了词嵌入，相对位置信息并不干净。真正把这条性质用到底的是 RoPE——它把旋转直接作用在 Q/K 上，见下文。

三：为什么波长取几何级数，底数 10000 控制什么

波长按 \(\lambda_i = 2\pi \cdot 10000^{2i/d_{\text{model}}}\) 排列，是一条几何级数（等比数列），公比由底数与维度数共同决定。

  • 为什么是几何级数而不是等差数列。 等差排列会让绝大多数维度挤在相近的频率上，多尺度退化成单尺度；几何级数则让每一个数量级的尺度都分到大致相同数目的维度，\(d_{\text{model}}\) 个通道被均匀地铺在从 \(2\pi\) 到 \(10000 \cdot 2\pi\) 的对数轴上。用有限维度覆盖跨四个数量级的位置尺度，几何级数是自然的选择。
  • 底数 10000 控制的是最低频维度的波长，也就是可分辨的最大位置尺度。 取 \(i\) 的最大值时 \(2i/d_{\text{model}} \to 1\)，波长趋近 \(10000 \cdot 2\pi\)，约六万余个位置。序列长度远小于这个数时，最低频维度在整条序列上还转不满一个周期，因而单调，可以充当粗粒度的「全局进度」信号。
  • 底数改大或改小。 调大则全部维度的波长整体拉长，低频端覆盖更远的位置，长序列上不同位置的编码不容易绕回重合，代价是频率密度被摊薄、近邻分辨率下降——长上下文模型把 RoPE 的底数调大走的就是这条路；调小则波长范围压缩，最低频维度也开始快速振荡，相距较远的两个位置可能在全部维度上同时接近，编码不再单调可分，远程位置关系失真。

可学习位置编码

做法与对比

维护一个形状为 \(L_{\max} \times d_{\text{model}}\) 的参数矩阵，\(L_{\max}\) 是支持的最大序列长度。第 \(pos\) 个 token 取该矩阵的第 \(pos\) 行，加到词嵌入上。这张表随模型一起用梯度更新，初始化通常是小方差的正态分布或截断正态分布。注入方式与正弦编码完全一样（在第一层之前加到输入上），区别只在于向量从哪来：一个由公式算出，一个从数据里学出。

对比项 正弦位置编码 可学习位置编码
参数量 0 \(L_{\max} \times d_{\text{model}}\)

关于外推能力有一点需要说准确：正弦编码在长度外推上的优势是「有定义」而不是「有效」。超出训练长度时公式仍能算出向量，但模型从未见过那段相位组合，实测性能通常仍然明显下降。可学习编码则是连值都取不到，只能靠插值或重新训练。两者的差别是「退化」与「不可用」的差别。

ViT 与 BERT 为什么选它

BERT 的预训练语料被截断到固定的最大长度，训练与推理的长度分布一致，外推需求很弱；而语言里位置本身带有任务相关的规律（句首、片段边界、特殊 token 的固定位次），交给参数去学比用固定公式约束更合适，代价是模型天然被最大长度锁死。ViT 的 patch 数由分辨率和 patch 大小决定，是固定值，同样没有变长需求；论文比较过一维可学习编码、二维可学习编码与相对位置编码，结论是三者差别很小，因此选了最简单的一维可学习方案。这条结论的前提是「patch 序列长度固定」，一旦要换输入分辨率，位置编码表的行数就对不上了——通行做法是把表按二维网格排布后做插值，再送进新分辨率的模型微调。

相对位置编码

核心思想

绝对编码回答「这个 token 在第几位」，相对编码回答「这两个 token 相隔多远」。思想上的关键一步是换注入点：不把位置信息加到输入上，而是加到注意力打分里。

原因是注意力打分本来就是逐对计算的，\((i, j)\) 这一格天然对应一对位置，把 \(i - j\) 的信息写进这一格是最直接的做法。写成一般形式，就是在缩放点积的基础上加一项只依赖相对距离的偏置：

\[a_{ij} = \frac{q_i^{\top} k_j}{\sqrt{d_k}} + b_{\,i-j}\]

其中 \(b_{\,i-j}\) 是一个按相对距离查表得到的标量（有的方案是加到 \(k_j\) 上的向量，形式略有不同，思路一致）。这带来三个直接后果：平移不变——整句往后挪一位，全部 \(i - j\) 不变，打分矩阵不变；参数按距离而不是按位置分配——距离 \(k\) 与 \(-k\)、以及远距离区间可以共享同一批参数，参数量与最大长度解耦；每一层都要算——相对偏置在注意力内部逐层注入，不像绝对编码只在输入端加一次。

RoPE 旋转位置编码

它要达到的目标

前面两条路线各有缺口：绝对编码把位置加在输入上，位置信息与语义信息在后续投影里混在一起；相对偏置虽然干净，但它是加在打分之外的一项，改变了标准点积注意力的形式，与各种高效注意力实现（如按块计算的核函数）不一定兼容。

RoPE（Rotary Position Embedding，旋转位置编码）提出的目标很明确：找到一个作用在 \(q\) 与 \(k\) 上的变换 \(f\)，使得

\[\langle f(q, m),\ f(k, n) \rangle = g(q,\, k,\, m - n)\]

即变换后的内积只依赖于两者的相对位置 \(m - n\)，而不依赖各自的绝对位置，同时保持内积这一运算形式本身不变。

核心形式

答案是二维平面上的旋转。把 \(d\) 维向量按相邻两维切成 \(d/2\) 个二维子空间，第 \(i\) 个子空间配一个角频率 \(\theta_i = 10000^{\,-2i/d}\)（\(i = 0, 1, \dots, d/2 - 1\)）。对处在位置 \(m\) 的向量，第 \(i\) 个子空间旋转 \(m\theta_i\) 弧度：

\[\begin{bmatrix} \tilde{x}_{2i} \\ \tilde{x}_{2i+1} \end{bmatrix} = \begin{bmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{bmatrix} \begin{bmatrix} x_{2i} \\ x_{2i+1} \end{bmatrix}\]

把 \(d/2\) 个旋转块拼成分块对角矩阵 \(R_m\)，整个变换写作 \(f(x, m) = R_m x\)。逐项解释：\(m\) 是 token 的绝对位置，决定旋转多少角度；\(\theta_i\) 是第 \(i\) 个子空间的角频率，随 \(i\) 增大按几何级数减小，构造与正弦编码的 \(\omega_i\) 完全一致，低维子空间转得快、高维子空间转得慢；\(R_m\) 是分块对角的正交矩阵，行列式为 1，因此不改变向量的模长，只改变方向，这保证了旋转不会放大或压缩表示的数值尺度。

为什么打分只依赖相对位置

因为旋转矩阵满足 \(R_m^{\top} = R_{-m}\) 与 \(R_m R_n = R_{m+n}\)，直接展开注意力打分：

\[\langle R_m q,\ R_n k \rangle = (R_m q)^{\top} (R_n k) = q^{\top} R_m^{\top} R_n k = q^{\top} R_{\,n-m}\, k\]

最终只剩下 \(n - m\)，绝对位置在乘法中相消。 这与正弦编码那条「\(PE\) 之间的内积只依赖 \(k\)」的性质形态相同，区别是 RoPE 把旋转作用在 \(q\) 与 \(k\) 本身，因此相对位置直接落在最终打分上，而不是落在一个与词嵌入纠缠在一起的加项上。

从这个式子还能直接读出 RoPE 的衰减行为：\(q^{\top} R_{n-m} k\) 按子空间展开后，每个子空间贡献一个含 \(\cos\!\big((n-m)\theta_i\big)\) 的项。距离小时各子空间相位差都小、贡献同向；距离变大后各子空间相位散开、贡献互相抵消，打分整体趋于衰减。这给了注意力一个「近处更相关」的先验，而这个先验来自构造本身，不需要额外参数。

相对绝对位置编码的优势

  • 长度外推。 打分只依赖相对距离，只要相对距离落在训练见过的范围内，超出训练长度的绝对位置本身不构成问题。配合调整底数（把 \(\theta_i\) 的基数调大，使全部子空间转得更慢）或位置插值（把超长序列的位置索引按比例压回训练区间），可以在少量微调甚至不微调的情况下扩展上下文长度。这是 RoPE 相比可学习绝对编码最实际的收益——后者在训练长度之外根本没有取值。
  • 不占用表示容量。 旋转不改变模长、不增加维度、不引入参数，位置信息完全编码在相位里，与加法注入相比不会稀释语义信号。
  • 逐层注入且与标准实现兼容。 绝对编码只在输入端加一次，深层网络里位置信号可能被逐层变换削弱；RoPE 在每一层的每个注意力头上重新施加，位置信息在全深度上保持一致。同时变换只发生在 \(q\) 与 \(k\) 上，打分仍是普通点积，可以直接套用高效注意力内核，不需要为位置项单独开一条计算路径。
代价也要写清楚：RoPE 每层都要对 Q/K 做一次旋转，有额外计算；底数与上下文长度是绑定的，扩展长度通常需要同步调整底数或做插值，改动之后一般仍需少量微调才能恢复精度。各家开源模型采用的 RoPE 底数、上下文长度与外推方案随版本变化很快，本页不给出具体数值，以对应模型的官方配置文件为准。

二维与多模态场景下的位置编码

ViT：把二维网格摊成一维序列

ViT 把图像切成不重叠的 patch，按行优先顺序摊平成一维序列，再加位置编码。这里有一个看起来会出问题、实际影响不大的点：一维编码丢掉了「上下相邻」这层关系——同一列上下相邻的两个 patch，在一维序列里相隔一整行的宽度。ViT 论文对此做过对照实验，比较了一维可学习编码、二维可学习编码（行、列各一套）与相对位置编码，结果差异很小。合理的解释是：patch 网格的宽度是固定常数，一维下标与二维坐标之间是确定的双射，模型完全可以从一维下标里学出行列结构。

需要显式处理二维结构的场合有两个。其一是换输入分辨率：patch 数变了，位置编码表的行数对不上，通行做法是把表按原始二维网格 reshape 回去，做二维插值（双三次插值是常见选择）到新网格大小，再摊平使用，随后做一轮微调。其二是需要显式的行列分解：把 \(d\) 维编码拆成两半，前一半按行坐标算、后一半按列坐标算，再拼接，这样行方向与列方向的位移各自对应独立的相位变化，DETR 一类需要精确空间定位的模型采用这种形式。

VLA：图像 token 与语言 token 拼在同一条序列上

VLA 模型把视觉编码器输出的 patch token 与语言 token 拼成一条序列送进语言主干（见 VLA 总览）。这时位置编码分两层，需要分开看。

  • 视觉编码器内部。 SigLIP、DINOv2 这类基于 ViT 的编码器自带 patch 位置编码，按固定 patch 数训练。这解释了为什么 VLA 必须把输入图像统一 resize 到编码器的训练分辨率——尺寸不一致会让 patch 数变化，内部位置编码直接失配。OpenVLA 页里 224×224 这个约束就是从这里来的。
  • 语言主干内部。 拼接后的整条序列按 token 在序列中的下标统一编排位置索引，图像 token 与语言 token 共用同一套位置体系。也就是说，视觉侧的二维空间关系由编码器内部的位置编码负责，语言主干只负责序列先后。

在 π0 这类模型里，还要与分块注意力掩码一起理解。π0 的序列分成 prefix（图像 token 加语言 token）与 suffix（state token 加含噪动作 token）两段，位置索引沿整条序列连续排布，而掩码限定信息只能从 prefix 单向流向 suffix。两者分工明确：位置编码决定「相隔多远」，注意力掩码决定「能不能看见」，不能互相替代。 需要额外注意的是，π0 的动作 token 除了序列位置之外，还带有 Flow Matching 时间步 \(\tau\) 的编码——这是一个与序列位置无关的独立标量，不属于位置编码的范畴。

还有两点值得记住：模态之间要不要显式区分，一种常见做法是额外加一套模态嵌入（modality embedding），也可以靠位置区间隐式区分（图像 token 总在前），前者更明确、后者更省事，取决于模态顺序是否固定；更进一步，有工作把 RoPE 的旋转维度按「时间、图像行、图像列」分组，让不同模态使用位置索引的不同分量，视频与图像的时空结构因此可以被显式表达，这类方案在视频理解模型上使用较多，具体形式以各模型官方实现为准。

关键参数配置与原因

每一项按「典型取值 → 为什么这么配 → 配错了会怎样」三段写。

编码维度：必须等于 \(d_{\text{model}}\)

典型取值：与模型隐藏维度严格相等，原始 Transformer 的 base 配置是 512。为什么：位置编码是逐元素加到词嵌入上的，加法要求两个张量形状完全一致，这不是可调超参数而是注入方式决定的硬约束；附带的好处是位置信息分布在全部通道上，任何一个后续线性层都能同时读到语义与位置。配错会怎样：维度不等时张量无法相加，框架直接报形状错误；若用广播规避，位置信息会被复制到不该去的通道上，训练能跑但位置信号完全失真。

注入方式：加法还是拼接

典型取值：加法，主流实现无一例外。为什么：拼接会把序列表示的维度变成 \(d_{\text{model}} + d_{pos}\)，后续所有权重矩阵都要跟着放大，参数量与计算量按维度平方增长，而加法维度不变、零额外开销。更实质的理由是注意力打分为内积，两个相加的向量做内积会自然展开出语义与语义、语义与位置、位置与位置的交叉项，模型可以按需使用其中任意一部分；拼接得到的只是两段互不相干子空间的内积之和，表达能力反而更受限。配错会怎样：改成拼接后若忘了同步扩大后续层的输入维度，形状不匹配直接报错；若同步扩大了，显存与计算开销上升而收益不明确。

词嵌入的缩放系数

典型取值：词嵌入在与位置编码相加之前乘以 \(\sqrt{d_{\text{model}}}\)。为什么：正弦编码的每个分量取值固定在 \([-1, 1]\)，而词嵌入常用方差约 \(1/d_{\text{model}}\) 的初始化，单个分量的典型幅值在 \(1/\sqrt{d_{\text{model}}}\) 量级，两者数值尺度相差 \(\sqrt{d_{\text{model}}}\) 倍；乘上这个系数后量级相当，相加时谁也不会压过谁。配错会怎样：漏乘则位置编码在数值上压过词嵌入，训练初期模型主要在拟合位置而非语义，收敛变慢；乘得过大则位置信号被淹没，模型退回到近似置换等变的状态，对词序不敏感。

位置编码之后的 Dropout

典型取值：原始 Transformer 在「嵌入加位置编码」之后立即加一层 dropout，base 配置的比例是 0.1。为什么：这是整个网络里最靠前的正则化点，位置与语义在此处刚刚混合，随机置零可以避免模型过度依赖某几个特定通道的位置信号。配错会怎样：比例过大时位置信号在小批量里被破坏得太多，模型对顺序的建模变弱；比例为 0 在小数据集上容易过拟合到训练集的长度分布。

最大序列长度与外推

典型取值：可学习编码取一个明确的 \(L_{\max}\)（BERT 一类模型常见 512 量级）；正弦编码与 RoPE 不需要预先固定表长，但训练数据的长度分布事实上决定了有效范围。为什么：可学习方案的 \(L_{\max}\) 直接是参数矩阵的行数，必须提前确定；固定方案没有这个约束，但模型只在训练见过的相位范围内可靠。配错会怎样：\(L_{\max}\) 设小了，超长输入只能截断，尾部内容直接丢失；设大了，靠后的行在训练中几乎没有样本更新，等价于随机向量，长输入上表现不稳定。用正弦编码或 RoPE 时把推理长度开得远超训练长度，则表现为长程注意力逐渐失焦，需要配合调整底数或位置插值并做少量微调。

RoPE 底数的取值

典型取值：默认 10000，与正弦编码一致；面向长上下文的模型通常显著调大，具体数值以官方配置为准。为什么：底数决定最低频子空间的旋转周期，也就是位置索引在多长的跨度上才会绕回；调大底数让所有子空间转得更慢，相同的位置跨度对应更小的相位变化，因而落在训练时见过的相位范围内，外推更平稳。配错会怎样：底数过大时高频子空间也变慢，近邻位置之间的相位差被压缩，局部顺序分辨能力下降，短序列任务上的精度回落；底数过小则远距离位置的相位快速绕圈，不同距离对应到相近的相位组合，长程关系失真。改动底数后不做微调直接推理，通常会看到明显的精度下降。

相对位置编码的分桶数与最大距离

典型取值：T5 一类方案的桶数在几十量级，超过某个最大距离后全部归入同一个桶。为什么：近距离需要精确分辨、远距离只需知道量级，对数分桶正是按这个原则分配参数，桶数与最大距离共同决定参数量且与序列长度解耦。配错会怎样：桶数过少，不同距离被合并进同一桶，模型无法区分局部顺序；桶数过多，每个桶分到的样本变少，远距离的桶训练不充分；最大距离设得远小于实际序列长度时，超过该距离的所有位置对共享同一个偏置，长程结构被抹平。

OFT 2025 · LIMITATIONS · PROTOCOL-SCOPED EVIDENCE

OFT 不是单变量补丁：它同时改变解码方式、时间分块、动作表示、损失函数与可选输入；本页只在协议和改动集合可比时解释结果，并始终保留“问题 / 改法 / 证据 / 剩余边界”四列。

K=8 / K=25LIBERO / ALOHA 的已报告 chunk 长度。
109.7 actions/sTable II 的 OFT-L1 动作供给吞吐，不是视觉闭环 Hz。
runtime ABI: null只有 interface delta 规格，没有已验收部署合同。

本页定位与证据规则

本页是 Phenomena 与 Source Code 之间的中继页：接收五条结构性局限，登记 OFT 的方法、协议与 2025 结果，再把 base/OFT 接口差异和 OFT 固定提交缺口交给下一页。它不把 OFT 总结果拆成单模块因果，也不把项目页入口当作 commit 级实现审计。

parallel decoding

schema: openvla.oft-parallel-decoding.v1
module_id: OFT-MOD-PD
base_input_positions: prior-generated-action-tokens
oft_input_positions: empty-action-embeddings-with-position-encoding
base_attention: causal
oft_attention: bidirectional-over-action-positions
base_sequential_decode_steps: D
oft_sequential_decode_steps: 1
output_positions: D
claim_state: paper-definition
locator: section-IV-B

D→1 只指动作 decoder 的顺序生成轮数：一次前向仍保留 D 个输出位置，视觉编码、projector 与 LLM 计算不会因此严格缩短 D 倍，墙钟也不会严格除以 D。双向注意力让动作位置共享隐藏表示，不等于动作维完全独立，也不构成任意联合随机分布。

Base: observation → action token 1 → action token 2 → … → action token D
OFT:  observation + D empty action positions → one decoder pass → D outputs

原版具有显式 autoregressive factorization；OFT-L1 在给定输入时是确定性连续输出。论文关于“理论表达力可能更低但所测任务未见下降”的后半句只适用于已测任务。

action chunking

schema: openvla.oft-action-chunk.v1
module_id: OFT-MOD-AC
action_dimension: D
chunk_length: K
output_shape: [K, D]
output_position_count: K-times-D
queries_per_chunk: 1
reported_libero_K: 8
reported_aloha_K: 25
reported_execution: execute-entire-chunk-before-requery
claim_state: paper-definition

必须把四个量分开：query latency（秒/查询）、action throughput（动作/秒）、control consumption rate（Hz）和 observation replan rate（Hz）。整块执行协议里，动作供给可以快于控制消耗，但新观测大约每个 chunk 才触发一次策略查询。ALOHA 的 K=25、25 Hz 对应约 1 秒块长，不是 77.9 Hz 视觉闭环。

  1. capture observation
  2. query once
  3. produce K actions
  4. execute action 1…K
  5. capture next observation

块内新观测默认不改已生成动作；论文协议不等于 receding horizon 或 temporal ensemble。中断、异步预取、overlap 与 safety override 都需要新 runtime 合同，并会改变和论文结果的可比性。

continuous L1 与 diffusion

schema: openvla.oft-continuous-objective.v1
module_id: OFT-MOD-CONT
normalized_domain: [-1, 1]
head: mlp-action-head
primary_objective: mean-l1
alternative_objective: conditional-denoising-diffusion
main_diffusion_steps: 50
grid_quantization_removed: true
all_action_error_removed: false
deployment_denormalization_still_required: true

逐坐标 L1 的 Bayes 最优点估计是条件中位数。这说明同一观测若有互斥的多条有效轨迹，确定性 L1 可能产生折中动作；它不证明所有双臂数据必然多模态，也不证明 OFT-L1 必败。conditional denoising diffusion 可表达多模态，但需要多步推理；能采样不等于必然更优。

Table II 中 50/10/5/2/1 步 diffusion 同时改变速度与效果；一步为 109.4 actions/s，但 LIBERO-Long 为 0.0。因此不能只看吞吐选步数。diffusion 与 L1 的四套件平均点估计 95.4 与 95.3 很接近，但没有统一置信区间时不能声称统计等价。

连续输出移除了固定 256-bin 网格，仍然需要正确的 normalization、action ordering、单位/坐标系、gripper semantics、chunk timing、clipping/rejection 与独立安全层。

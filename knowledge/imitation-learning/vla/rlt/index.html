Online RLFrozen VLAAction Chunk

把大 VLA 变成“表征器 + 建议策略”，只让小型 Actor-Critic 在关键接触阶段继续学习

RLT（RL Token）不是新的动作 token，也不是重新训练一个 VLA。它先把 VLA 内部 token 压缩为紧凑状态 RL token，再冻结 VLA 与该表征模块，用轻量 actor-critic 在线改进 VLA 给出的参考动作块。

2 个阶段表征适配 → 在线 Actor-Critic
冻结大模型在线阶段不更新 VLA 与 RL-token encoder
Chunk-level RL把连续 $C$ 个 50 Hz 动作作为一次 RL 决策
少量真机练习论文报告约 15 分钟至 5 小时实际机器人数据
证据边界：原论文实验以 Physical Intelligence 的 π0.6 为基座；RLinf 的 π0.5 配置、openpi-RLT 与 rlt-openpi 是后续实现或第三方复现。它们能帮助理解代码，但其网络维度、超参数和机器人接口不能写成原论文唯一规定。

一、RLT 要解决的是“最后一毫米”

大规模 VLA 往往已经会抓取目标、移动到附近并完成粗对准，但精密插接、柔性穿孔和工具对准的关键阶段仍会暴露三个问题：细小姿态误差会在接触后放大；示范中的犹豫与回退会被行为克隆保留下来；真实机器人又不允许用海量失败轨迹从头探索。

直接在线更新十亿级 VLA，计算量和样本复杂度都太高；完全丢开 VLA、只训练小视觉策略，又会舍弃预训练得到的视觉语义与行为先验。RLT 的回答是：保留 VLA 的知识，把在线 RL 的可训练部分压缩到小网络。

\[\boxed{ \text{RLT} =\text{冻结的 VLA 表征与参考动作} +\text{轻量在线 Actor-Critic} }\]

更严格的方法定位见子页 ①：问题、方法坐标与创新链。

二、完整流程：先学接口，再学控制

flowchart LR
  D["任务示范数据"] --> V["VLA 任务适配 / SFT"]
  V --> H["VLA hidden tokens<br/>z₁ … z_M"]
  H --> E["RL-token encoder"]
  E --> Z["紧凑状态 z_rl"]
  Z --> R["decoder 重建 hidden tokens<br/>仅 Stage 1"]
  V -. "冻结" .-> F["Feature model"]
  E -. "冻结" .-> F
  F --> X["状态 x = z_rl + proprio"]
  V --> T["VLA reference chunk"]
  X --> A["轻量 Actor"]
  T --> A
  A --> U["action chunk"]
  X --> P
  T --> P
  U --> B["机器人执行 action chunk"]
  U --> P
  B --> M["reward / next state<br/>human intervention"]
  M --> P["Replay Buffer"]
  P --> Q["Twin Critic"]
  Q --> A

自制流程图，依据 RLT 原论文 Algorithm 1 整理；decoder 是 Stage 1 的训练支架，不进入 Stage 2 在线控制。

Stage 1：把 VLA 变成可供 RL 使用的特征模型

VLA 产生最终层 token embeddings $z_{1:M}$。小型 transformer encoder 在序列末尾加入一个可学习的 <rl> embedding，并读取其输出：

\[z_{\mathrm{rl}} =g_\phi([z_{1:M},e_{\texttt{rl}}])_{M+1}.\]

decoder 必须仅凭 $z_{\mathrm{rl}}$ 与先前 token 重建整段 VLA embedding，使单个向量成为信息瓶颈。若同时进行任务 SFT，总目标为

\[\mathcal L_{\mathrm{stage1}} =\mathcal L_{\mathrm{ro}} +\alpha\mathcal L_{\mathrm{vla}}.\]

重建对象、stop-gradient 与梯度边界见子页 ②：RL Token 表征学习。

Stage 2：冻结表征，只训练小型 Actor-Critic

在线状态由 RL token 与本体状态组成：

\[x=(z_{\mathrm{rl}},s^p).\]

VLA 同时给出 reference action chunk $\tilde a_{1:C}$。Actor 以 $(x,\tilde a)$ 为条件生成动作块，critic 估计该动作块的价值：

\[a_{1:C}\sim\pi_\theta(\cdot\mid x,\tilde a_{1:C}), \qquad Q_\psi(x,a_{1:C})\in\mathbb R.\]

此时 VLA 与 RL-token encoder 都冻结；更新范围集中在小型 actor、twin critic 与其 target network。完整 Loss 与 TD target 见子页 ③：Actor-Critic 与 Loss。

三、六项核心设计及其证据边界

设计 直接解决的问题 底层作用 论文中的直接证据
RL token VLA token 多且高维 学习任务相关的紧凑 RL 状态接口 用 ImageNet ResNet-10 替换后明显下降
冻结 VLA 少量在线数据不足以稳定更新大模型 固定感知与行为先验，并降低在线更新成本 方法边界；未作为独立消融项
Action chunk 50 Hz 单步决策时域过长 以 $C$ 步为一个 RL 决策 “w/o Chunk”下降，但同时更换视觉编码器，属于组合消融
Reference pass-through Actor 从头搜索效率低 让 actor 直接看到当前 VLA 建议 去掉 reference 后早期失败增多
BC regularizer Q 梯度可能把动作推向分布外 以软惩罚把搜索拉回参考动作附近 去掉后出现最大的单项消融降幅
Reference dropout Actor 容易退化为复制 reference 保留从 $z_{rl}+proprio$ 生成动作的通路 去掉后最终表现下降

这六项共同构成方法，但证据强度并不相同：论文直接消融了 RL token、action chunk、reference 输入、BC 正则与 reference dropout；“冻结 VLA”主要由方法结构与计算边界支持。尤其要注意，“w/o Chunk”还把 RL token 换成 ResNet-10，因此不能把全部降幅单独归因于 $C=1$。动作块、参考动作与 dropout 的作用链见子页 ④：动作块与参考动作改进。

四、Actor 不是盲目探索，而是在 VLA 附近做价值引导的编辑

RLT 的 actor 目标把“变得更好”和“不要跑太远”写在同一个式子中：

\[\mathcal L_\pi =\mathbb E \left[ -Q_\psi(x,a_{1:C}) +\beta\|a_{1:C}-\tilde a_{1:C}\|_2^2 \right].\]

第一项让 actor 寻找更高价值动作，第二项用 VLA reference 作行为锚点。需要注意，论文 actor 是以 reference 为条件的动作分布；“局部编辑”是行为解释，不等价于算法必须显式写成 $a=\tilde a+\Delta a$。某些复现采用 residual 参数化或零初始化输出，属于实现选择。

为何需要 reference dropout？训练早期 critic 尚不可靠，actor 同时看见 reference 并被 BC 项拉回，容易只学会复制。论文对训练 batch 的随机子集只把送入 actor 的 reference 条件置零；BC 正则的目标仍是真实 reference。推理时则始终提供真实 reference。

五、完整在线系统不只有两个 Loss

先用 VLA warmup

基座策略先填充 replay buffer，使 critic 的初始数据来自有意义的行为；它旨在降低随机 actor 与未校准 Q 相互放大误差的风险，而不是稳定性的数学保证。

Chunk-level replay

论文 Algorithm 1 的核心 transition 是当前/下一 RL 状态、实际执行 chunk、chunk 奖励与 reference。工程实现还应记录终止掩码、动作来源和时间戳，避免把扩展字段误写成论文原式。

异步高 UTD 更新

机器人采样慢、小网络更新快。论文异步进行 rollout 与学习，并使用 UTD=5；昂贵真机 transition 得到多次利用。

人在回路

人标注稀疏终止奖励（成功为 $+1$，否则为 $0$），在危险时接管，并决定关键阶段何时切入 RL。RLT 原论文不是全自主奖励与切换系统。

完整 replay schema、控制权优先级与训练伪代码见子页 ⑤：在线训练系统。

七、论文观察与“奇怪现象”的正确读法

在 Ethernet 任务中，基座 VLA 常在接触附近前进、后退、重新调整，形成反复 probing；RLT 最终策略更常用连续动作插入，首次失败后还会保持压力并轻微摆动，利用机械结构的顺应性。该任务中约一半 RL 评测回合快于全部遥操作示范，说明在线价值学习有可能找到示范未覆盖的更快局部策略；这不是对所有任务的统一速度保证。

但它不表示“摆动”是所有插接任务都应硬编码的技巧。合理结论是：当探索、BC 锚定与价值信号配合得当时，RLT 能在任务动力学中发现示范未覆盖的局部策略。原始实验口径、消融和诊断见子页 ⑦。

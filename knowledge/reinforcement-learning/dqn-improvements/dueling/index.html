子页① 处理的是目标值怎么算，本页处理的是网络怎么搭。两者改动位置不同、可以组合；但它们共享数据、目标与优化过程，组合后的效果仍需实验验证，不能把「可组合」写成统计意义上的互不影响。

Dueling 的出发点是一个观察：在很多状态上，「当前状态好不好」很重要，而「各个动作之间差多少」并不重要。单流 Q 网络把这两类信息混在同一组动作输出里；Dueling 设置价值头与优势头，再合并回 Q。真正的难点不在于「拆」，而在于聚合层必须规范化优势对 Q 的贡献——否则无法从最终 Q 唯一解释两部分；即使做了中心化，优势头的原始输出仍可整体平移，具有确定含义的是中心化后的有效优势。

75.4%30 no-ops 下胜过同容量单流 Single Clip 的比例
83.3%Human Starts 下 18 动作游戏得分更高占比
1/√2进入最后卷积层的梯度缩放
可组合与 Double DQN 的关系；组合效果需实测
本页重点。必须精读的是两节：「不可辨识性」说明为什么直接相加不能唯一解释两个头；「两种聚合式的取舍」区分原始优势、中心化后的有效优势与价值头。最大值式给出 $$V=\max_a Q$$，均值式给出 $$V=|\mathcal A|^{-1}\sum_a Q$$；后者并不保证两个头分别等于策略定义下的真实 $$V^\pi$$ 与 $$A^\pi$$，但动作排序保持不变。

可以快读的是：「工程细节」一节的三处历史训练措施和「实验证据」中的逐项百分比。但比较对象必须写清：论文专门重训的 Single Clip 使用相同梯度裁剪并配平参数量，因此 Duel Clip 对 Single Clip 的 43/57 更接近结构消融；对原始 Single 的其他占比还混有训练配方与容量差异。

符号约定与前置

本页沿用 Wang 等原论文的记号，它把网络参数按所属模块分成三份：

记号 指什么
\(\theta\) 共享的卷积层参数，两条流共用
\(\alpha\) 优势流（advantage stream）的全连接层参数
\(\beta\) 价值流（value stream）的全连接层参数
注意与上一个子页的记号冲突。子页①里的 theta 指在线网络的全部参数、theta 上标减号指目标网络，那是按「哪个网络」划分；本页的 theta 只指共享卷积部分，是按「哪个模块」划分。两处都沿用各自论文的原记号，跨页阅读时需按本表换算。

优势函数的定义本页只给一行，不展开：\(A^{\pi}(s,a) = Q^{\pi}(s,a) - V^{\pi}(s)\)，它衡量在状态 \(s\) 上选动作 \(a\) 比按策略 \(\pi\) 平均水平好多少。它在策略梯度谱系中的位置见 Actor-Critic。经验回放、目标网络与致命三要素见 DQN。

动机：两类信息的价值密度不同

论文用 Atari 的 Enduro（赛车）举例：是否该往左还是往右移动，只有在即将发生碰撞时才有意义。在空旷路段上，各个动作的优势几乎没有差别。但对自举类算法而言，情况正相反——每一个状态的状态价值估计都很重要，因为它会被写进下一轮的 TD 目标。

于是出现了一种不对称：

  • \(V(s)\)：每个状态都需要准确估计，且它与选哪个动作无关。
  • \(A(s,a)\)：只在少数状态上才需要分辨，大部分状态上各动作近乎持平。

单流 Q 网络没有显式表示这种不对称。对一个样本，TD 损失直接监督的是被选动作对应的 \(Q(s,a)\)；不过由于各动作共享下层参数，这次更新仍可能间接改变其他动作的输出。因此，准确说法不是「一次更新只改变一个输出」，而是单流结构没有一条专门把跨动作共享的状态价值显式传播给全部动作的路径。

saliency 可视化：两条流关注了不同区域

这个动机不只是设想。论文按 Simonyan 等 2013 的方法，计算训练好的价值流与优势流对输入视频的 Jacobian，得到两张显著性图（saliency map），结果是：

  • 价值流关注道路，特别是地平线——新车正是从那里出现的；它同时也关注分数。
  • 优势流在前方没有车时不太关注任何东西，只有当车就在正前方时才被激活。
这一点值得强调：两条流的响应模式是网络自己学出来的，没有任何额外监督，也没有为此设计辅助损失。论文原话是「自动产生对状态价值函数与优势函数的各自估计，无需任何额外监督」。不过 saliency 是定性可视化，能支持「关注区域不同」这一解释，不能单独证明两条输出就是严格的 $$V^\pi$$ 与 $$A^\pi$$；后者还取决于聚合约束。

网络结构

下层卷积与原始 DQN 完全相同。区别在于：卷积之后不是接一串全连接层，而是分叉成两串，最后再合并成单个 Q 输出。

论文给出的 Atari 版确切配置如下：

部分 配置
共享卷积 与 DQN 相同的三层：32 个 \(8\times8\) 步长 4 → 64 个 \(4\times4\) 步长 2 → 64 个 \(3\times3\) 步长 1
价值流 一层 512 单元全连接，再接一层全连接输出 1 个标量
优势流 一层 512 单元全连接，再接一层全连接输出 动作数 个值
非线性 相邻层之间一律插 rectifier
有效动作数 ALE 中介于 3 到 18 之间

两处细节值得对照着记。其一，两条流的宽度相同（都是 512），不对称的只有各自的输出维度——一个出标量、一个出动作数。其二，把它与单流网络比较时，单流版本的对应层是 512 单元（Nature 版 DQN），因此 Dueling 的参数量确实更大；论文的隔离实验正是为此把单流基线的第一个全连接层加宽到 1024 来配平，详见下面「论文自己做了变量隔离」一节。

两种结构的输入输出接口完全相同——都是「吃一个状态、吐出所有动作的 Q」。正因为接口一致，Dueling 可以直接套用现成的 Q 学习算法（DQN、Double DQN、SARSA）而无需改动训练流程。

不可辨识性：为什么不能直接写 Q = V + A

把两个头的原始输出直接相加，得到论文式 (7)：

\[Q(s,a;\theta,\alpha,\beta)=V(s;\theta,\beta)+A_{\mathrm{raw}}(s,a;\theta,\alpha).\]

这个参数化不可辨识。对任意只依赖状态的常数 \(c(s)\)，都有

\[\widetilde V(s)=V(s)+c(s),\qquad \widetilde A_{\mathrm{raw}}(s,a)=A_{\mathrm{raw}}(s,a)-c(s),\]

且 \(\widetilde V+\widetilde A_{\mathrm{raw}}=V+A_{\mathrm{raw}}\)。严格说，自由量可以随状态变化；在固定状态上看就是一个常数。TD 损失只监督最终 \(Q\)，无法仅凭式 (7) 唯一恢复两个头各自的水平。

这不表示两个头“完全学不到任何东西”，而是不能把它们的原始数值直接解释为唯一的 \(V^\pi\) 与 \(A^\pi\)。论文还报告：直接使用式 (7) 时，这种不可辨识性对应较差的实际表现；这是论文实验中的观察，不是所有任务都会失败的普遍定理。

必须区分两个量。后文的聚合式规范化的是“送入 Q 的有效优势” $$\widetilde A$$，不是强迫优势头原始输出 $$A_{\mathrm{raw}}$$ 自己满足零均值或最大值为零。给 $$A_{\mathrm{raw}}$$ 的所有动作同时加一个常数，中心化后仍会抵消，所以原始优势头依旧保留平移自由度；真正具有确定代数含义的是中心化后的 $$\widetilde A$$。

两种聚合式的取舍

策略优势的定义是 \(A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)\)，并满足 \(\mathbb{E}_{a\sim\pi(\cdot\mid s)}[A^\pi(s,a)]=0\)。若策略是确定性贪心策略，所选动作的优势为零。Dueling 的两种聚合方式分别借用了这两种规范化思路，但它们对网络输出的语义并不相同。

方案一：减最大值（论文式 8）

定义有效优势

\[\widetilde A_{\max}(s,a) = A_{\mathrm{raw}}(s,a)-\max_{a'}A_{\mathrm{raw}}(s,a'),\]

再令

\[Q(s,a)=V(s)+\widetilde A_{\max}(s,a).\]

由于 \(\max_a\widetilde A_{\max}(s,a)=0\)，所以

\[\max_a Q(s,a)=V(s).\]

若最终 \(Q\) 逼近的是贪心策略或最优动作价值，那么价值头具有清晰的代数语义：它等于网络输出中的最大动作价值；有效优势 \(\widetilde A_{\max}=Q-V\)，最优动作的有效优势为零。需要注意，原始头 \(A_{\mathrm{raw}}\) 的最大值未必为零，它仍可整体平移。

方案二：减动作均值（论文式 9）

论文最终使用

\[\widetilde A_{\mathrm{mean}}(s,a) = A_{\mathrm{raw}}(s,a) - \frac{1}{|\mathcal A|}\sum_{a'}A_{\mathrm{raw}}(s,a'),\] \[Q(s,a)=V(s)+\widetilde A_{\mathrm{mean}}(s,a).\]

此时有两个精确恒等式：

\[\frac{1}{|\mathcal A|}\sum_a \widetilde A_{\mathrm{mean}}(s,a)=0, \qquad V(s)=\frac{1}{|\mathcal A|}\sum_a Q(s,a).\]

因此，价值头等于网络所有离散动作 Q 输出的算术平均；有效优势等于 \(Q\) 减去这个均值。它一般不等于当前贪心策略的 \(V^\pi\) 与 \(A^\pi\)，除非策略恰好是动作均匀分布或出现其他巧合。论文所说“语义相差一个常数”应按这个口径理解，而不能写成价值头没有任何可解释性。

为什么论文选择均值式

论文给出的理由是优化稳定性：式 (9) 中优势只需随整体均值变化；式 (8) 中其他动作的有效优势还要补偿当前最大优势的变化。连续网络输出的 \(\max\) 本身连续，但动作并列处不可微，最大分支切换时梯度路由也会改变。

论文还试验了式 (8) 的 softmax 版本，结果与更简单的均值式相近，因此所有正式实验使用式 (9)。论文没有把该 softmax 变体发展成独立方法，本页也不为它补造额外语义。

聚合方式 价值头的确定含义 有效优势的约束 原始优势头是否仍可整体平移 论文使用
直接相加，式 (7) 无法由 \(Q\) 唯一恢复 无 是 否；论文报告表现较差
减最大值，式 (8) \(V=\max_a Q\) \(\max_a\widetilde A=0\) 是 否
减均值，式 (9) \(V=\lvert\mathcal A\rvert^{-1}\sum_a Q\) \(\sum_a\widetilde A=0\) 是 是

减均值保留了什么

  1. 动作排序不变。 减去的量对同一状态的所有动作相同，因此 \(\arg\max_a Q(s,a)=\arg\max_a A_{\mathrm{raw}}(s,a)\)；基于这些 Q 值的贪心与 \(\varepsilon\)-贪心动作排序不变。
  2. 跨动作共享基线。 价值头向所有动作输出提供同一个状态相关基线，TD 监督可通过这条路径同时影响所有动作的 Q。
  3. 聚合属于网络前向。 训练仍使用普通反向传播，无需新增独立算法步骤。行动时从排序角度只需优势流，但实际仍要先计算共享特征；常见实现会同时计算两个头并返回完整 Q。
“Dueling 输出真实的价值和优势”需要加限定：式 (8) 给出与贪心最大值一致的价值头；式 (9) 给出动作均值基线。两者都能提供有用表示，但只有在相应策略语义与函数逼近准确时，才能进一步解释为真正的 $$V^\pi$$ 与 $$A^\pi$$。

三处工程细节

以下三项是原论文 Atari 实验的训练配方，不是定义 Dueling 架构的必要条件。现代实现可以采用不同的初始化、优化器与裁剪策略，但若要复现论文或解释其消融，必须把这些差异记录清楚。

梯度缩放 1/√2

\[\text{进入最后一个卷积层的合并梯度} \;\longleftarrow\; \frac{1}{\sqrt{2}} \times \text{合并梯度}\]

原因写得很直白：优势流与价值流在反向传播时都会向最后一个卷积层输送梯度，两股梯度在此汇合，量级因此偏大。论文对它的定位很克制——称其为一个「简单的启发式」，作用是「温和地提升稳定性」。

容易写错的一处：缩放施加在进入最后一个卷积层的那股合并梯度上，不是给两条流各自的梯度分别乘系数。这是汇合点上的一次缩放。

梯度范数裁剪到 10

论文将整体梯度范数裁剪到不超过 10，并在 2016 年的语境中说明这当时不是深度强化学习的标准做法，而更常见于循环网络训练。这个历史判断不应改写成对当前所有实现规范的结论。

学习率：两个算法用的不一样

优化器与超参数沿用 van Hasselt 等 2015，只有学习率被调得略低一些。但论文括号里补了一句关键限定：对 double DQN 不做这个调整，因为那样会损害它的性能。

这意味着论文里的算法间比较并非所有优化超参数完全相同。尤其是 Duel Clip 与原始 Single 的差异可能同时包含学习率、梯度裁剪和容量因素；更适合隔离架构贡献的是下文重新训练的、同样裁剪且容量匹配的 Single Clip。引用百分比时必须带上具体比较对象。

论文自己做了变量隔离

这一条是本节最该记住的。为了把 Dueling 架构本身的贡献分离出来，论文重新训练了一个单流基线，并让它享有同样的待遇：

  • 同样施加梯度裁剪；
  • 第一个全连接层用 1024 个隐单元，使两种架构的参数量大致相同。

这个重训后的基线记为 Single Clip。只有 Duel Clip 对 Single Clip 的 43/57（75.4%）是相近容量、同样裁剪的直接比较；对原始 Single 的 46/57、40/57 等结果仍混有容量与训练配方差异，不能用同一句“变量已完全隔离”概括。

实验证据

corridor：用冗余 no-op 操作动作数

论文先做固定策略的评估任务，以避免学习算法自行选择探索策略，以及策略改进与策略评估相互作用这两类混杂因素。目标策略 \(\pi\) 固定为：以 \(1-\varepsilon\) 选择 \(Q^*\) 的贪心动作，以 \(\varepsilon=0.001\) 在动作集中随机选择；训练目标对应 Expected SARSA 的策略期望，但不更新这套行为策略。

环境 corridor 由三条相连走廊组成，智能体从左下角出发，抵达奖励终点后结束。两个竖直段各 10 个状态，水平段 50 个状态。基础动作是上、下、左、右和 no-op。

10 动作与 20 动作变体通过增加与 no-op 等效的冗余动作构造。状态布局、奖励和原有动作的转移保持不变，最优控制动作也不因冗余 no-op 改变；但严格说并非“只有动作数变化”：因为 \(\varepsilon\) 随机动作在更大的动作集合上分布，固定策略 \(\pi\) 的随机分量及对应 \(Q^\pi\) 也会轻微变化。这个实验主要隔离的是相似/冗余动作增多时的表示效率，不是无条件的纯动作数因果定理。

项目 单流架构 Dueling 架构
层数 三层 MLP 三层
结构 每个隐层 50 个单元 第一隐层 50 个单元后分叉为两条两层 MLP，各 25 个隐单元

评价指标是对真值的平方误差 \(\sum_{s,a} (Q(s,a;\theta) - Q^{\pi}(s,a))^2\)——这个环境足够简单，所有 \((s,a)\) 的精确 \(Q^{\pi}\) 都能单独算出来。

结论：

  • 5 个动作时，两种架构收敛速度大致相同。
  • 动作数增加后，Dueling 明显优于传统 Q 网络。

机理正是开头那个动机：Dueling 里的 \(V(s;\theta,\beta)\) 学到的是一个在该状态下许多相似动作之间共享的通用价值，因而收敛更快。论文评价这个结果「很有前景」，因为许多大动作空间的控制任务都具有这个性质。

与 Double DQN 的关系

两者改动位置不同，因此可以组合；但可组合不等于彼此独立：

维度 Double DQN Dueling DQN
改哪里 TD 目标的构造方式 网络结构
主要作用 减少选择与评估复用造成的过估计 提高相似动作间的表示共享与学习效率
是否改算法流程 是（目标值那一行） 否（只是网络前向的一部分）
能否叠加 可以——Dueling 论文的 Atari 结果包含以 DDQN 目标训练 Dueling 网络的变体 同左；仍共享数据、目标和优化，效果可能交互

需要澄清一个常见的混淆：Dueling 并不直接消除过估计。它改变表示结构，希望更有效地学习跨动作共享的状态价值；Double DQN 则改变目标中的选择—评估耦合。原论文还明确提醒，多种扩展会以细微方式交互，例如优先回放与梯度裁剪，因此组合版本仍应做消融。过估计机理见子页①。

落到代码上

完整的四种组合共用骨架实现在 DQN 改进枢纽页，本页只对照网络前向这一处：

class VAnet(torch.nn.Module):
    def __init__(self, state_dim, hidden_dim, action_dim):
        super().__init__()
        self.shared = torch.nn.Linear(state_dim, hidden_dim)
        self.adv_head = torch.nn.Linear(hidden_dim, action_dim)
        self.value_head = torch.nn.Linear(hidden_dim, 1)

    def forward(self, x):
        h = F.relu(self.shared(x))
        adv_raw = self.adv_head(h)                           # (..., action_dim)
        value = self.value_head(h)                           # (..., 1)
        adv_centered = adv_raw - adv_raw.mean(dim=-1, keepdim=True)
        return value + adv_centered                          # 式 (9)

三个检查点：

  • 均值必须沿最后的动作维计算；沿 batch 维求均值会把不同样本混在一起，代码可能不报错但语义错误。
  • keepdim=True 保留形状 (..., 1)，使价值头广播方向明确；省略后在某些恰好匹配的形状上会静默错误广播。
  • 可加入单元测试：对任意批次，q.mean(dim=-1, keepdim=True) 应在浮点容差内等于 value。这验证的是均值聚合的代数不变量，不证明 value 就是真实的 \(V^\pi\)。

小结与出口

  • Dueling 的动机是把跨动作共享的状态基线与动作间差异分开表示；saliency 图只是两条流关注区域不同的定性证据，不是 \(V^\pi/A^\pi\) 语义证明。
  • 直接相加可以表示 Q，但参数化不可辨识：\(V\) 与原始优势可作相反平移。聚合层中心化的是有效优势，原始优势头仍可整体平移。
  • 减最大值时 \(V=\max_a Q\)、有效优势最大值为零；减均值时 \(V=\lvert\mathcal A\rvert^{-1}\sum_a Q\)、有效优势均值为零。论文因优化稳定性选择均值式。
  • 两种中心化都不改变动作排序。均值式的价值头是有确定代数含义的动作均值基线，但一般不等于当前贪心策略的真实状态价值。
  • corridor 支持“相似动作增多时 Dueling 更有优势”，但新增 no-op 也会改变固定 \(\varepsilon\)-贪心策略的随机分量，不能称为只改变动作数的完美因果实验。
  • 引用 Atari 结果时必须同时给出评测协议与基线；43/57 等数字是得分更高的游戏占比，不是概率意义的胜率。论文配平了 Single Clip 的容量和梯度裁剪，但组合实验仍包含粗调与组件交互。

接下来：优先经验回放改的是从回放池里怎么抽样，可以与本页的网络结构、子页①的目标构造组合；但共享的样本分布、TD 误差和梯度裁剪会造成交互，需用组合消融验证。三者后来在 Rainbow 中被系统组合。

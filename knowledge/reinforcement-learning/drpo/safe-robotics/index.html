知识库/DRPO/安全机器人
Distributional Reachability Policy Optimization

把“未来是否安全”从一个均值变成一个风险分布

概率动力学模型带来多种可能未来；DRC 建模未来最坏约束的分布，主策略追求回报，Shield 专注降低风险，分位数判据决定训练期动作是否被覆盖。

2 个 Actor主策略 + Shield 策略
2 类 Critic奖励 Q + 分布式安全 DRC
2 个 Buffer真实经验 + 模型虚拟经验
1 条硬边界学习型安全层不替代急停

本页的 DRPO 不是 PPO 的直接改版。它是基于模型的安全连续控制框架，底层采用 SAC 风格 Actor-Critic，并额外训练概率世界模型、分布式安全 Critic、Shield 与拉格朗日乘子。

1. 为什么期望安全值还不够？

普通约束 RL 常关注期望累计 cost，但低概率严重违反可能被均值掩盖。模型式 RL 还会引入动力学不确定性：同一个 \((s,a)\) 经不同模型或随机后继，会得到不同未来轨迹。

论文从可达性证书出发：

\[Q_h^\pi(s,a)=\max_{t\in\mathbb N}\gamma^t h(s_t,a_t),\]

其中 \(h(s,a)\le0\) 表示约束满足。\(Q_h^\pi\) 关注未来轨迹上最坏的折扣约束值；相比只约束累计 cost，它更直接描述“是否能持续留在安全区域”。

其 Bellman 型递推为：

\[Q_h^\pi(s,a)= (1-\gamma)h(s,a)+ \gamma\max\{h(s,a),Q_h^\pi(s',\pi(s'))\}.\]

但在学习到的概率模型中，\(s'\) 与后续轨迹都不确定，\(Q_h^\pi(s,a)\) 应视为随机变量，而非单一标量。

2. Distributional Reachability Certificate

DRC 建模分布 \(\mathcal Z(Q_h^\pi(s,a)\mid s,a)\)。分布 Bellman 目标：

\[\mathcal T^\pi Q_h(s,a)\overset D= (1-\gamma)h(s,a)+ \gamma\max\{h(s,a),Q_h(s',a')\},\]

其中 \(s'\sim\hat P(\cdot\mid s,a)\)，\(a'\sim\pi(\cdot\mid s')\)。DRC 通过最小化目标分布与当前分布的距离迭代学习：

\[\mathcal Z_{new}= \arg\min_{\mathcal Z} \mathbb E_{(s,a)} D\!\left(\mathcal T^\pi\mathcal Z_{old},\mathcal Z\right).\]

论文采用高斯形式时，\(\beta\) 分位数可写为：

\[Z_\beta(s,a)= \mu_\psi(s,a)+\Phi^{-1}(\beta)\sigma_\psi(s,a).\]
  • \(\mu_\psi\)：未来最坏约束的预测均值。
  • \(\sigma_\psi\)：模型与分布估计的不确定性。
  • \(\beta\)：风险分位数；越接近 1，通常越关注上尾危险。
  • \(Z_\beta\le0\)：在模型覆盖与分布假设成立时，把该动作判为满足风险约束。

若 \(\Phi^{-1}(\beta)\approx2\)，判据近似“均值 + 两倍标准差”。即使均值为负，只要不确定性足够大，动作仍会被判为不安全；这是与只看期望值的本质差别。

3. 整体网络与数据流

flowchart TB
  ENV[真实环境] --> RB[Real Replay Buffer]
  RB --> ENS[概率动力学 Ensemble]
  ENS --> MODEL[短模型 Rollout]
  MODEL --> VB[Virtual Replay Buffer]
  VB --> Q[Reward Critic Q]
  VB --> DRC[Distributional Reachability Critic]
  VB --> MAIN[Main Actor]
  VB --> SHIELD[Shield Actor]
  VB --> LAMBDA[Lagrange Multiplier]
  MAIN --> CHECK{"Z_beta(s,a) <= 0?"}
  DRC --> CHECK
  CHECK -->|是| EXEC[执行主动作]
  CHECK -->|否| SAFE[训练期执行 Shield 动作]
  SHIELD --> SAFE
  EXEC --> ENV
  SAFE --> ENV
模块 学什么 为什么需要 不能替代什么
Dynamics Ensemble \(p(s'\mid s,a)\) 的概率近似 生成虚拟经验并显式表示模型分歧 真实系统覆盖验证
Reward Critic \(Q_\omega\) 累计任务回报 给主策略性能梯度 安全判据
DRC \(\mathcal Z_\psi\) 未来最坏约束值的分布 提供风险分位数和不确定性 物理安全链
Main Actor \(\pi_\theta\) 高回报、满足约束的动作 完成任务 纯安全备用策略
Shield \(\pi_{h,\nu}\) 最小化风险分位数 主动作被判危险时备用 高性能主策略
Multiplier \(\lambda_\xi\) 对偶约束强度 动态平衡回报与风险 准确的风险模型

4. 各模块 Loss 与更新方向

主 Actor

常见最小化形式：

\[\mathcal L_\pi= \mathbb E\left[ -Q_\omega(s,a) +\lambda_\xi(s)Z_\beta(s,a) +\alpha\log\pi_\theta(a|s) \right].\]

第一项提高回报，第二项惩罚风险分位数，第三项是 SAC 的熵项。三个量尺度不同，必须分别记录；只看总 Loss 无法判断回报和安全谁在主导。

Shield

\[\mathcal L_{shield}= \mathbb E_{a\sim\pi_h}[Z_\beta(s,a)].\]

Shield 直接寻找风险更低的备用动作，不以最大任务回报为首要目标，因此不能用一个 Actor 同时替代两者而不改变框架语义。

其他模块

  • Reward Critic：双 Q / Bellman TD 风格目标。
  • DRC：分布 Bellman 目标与当前安全分布之间的距离。
  • Dynamics Ensemble：真实转移的负对数似然或等价拟合目标。
  • Multiplier：对偶更新；风险违反时提高惩罚，过度满足时允许下降。

5. 一次完整训练迭代

  1. 主 Actor 给出候选动作 \(a\)。
  2. DRC 计算 \(Z_\beta(s,a)\)。
  3. 若 \(Z_\beta\le0\)，执行主动作；否则训练期执行 Shield 动作。
  4. 把真实转移写入 Real Replay Buffer。
  5. 用真实数据更新 Dynamics Ensemble。
  6. 从真实状态出发，在模型中滚动有限 horizon，写入 Virtual Replay Buffer。
  7. 用虚拟经验更新 Reward Critic、DRC、Main Actor、Shield 和 Multiplier。
  8. 评估期若主动作不安全，论文在主动作与 Shield 动作之间做线搜索，以减少完全切换的保守性。

训练期“主动作/Shield 动作二选一”与评估期“二者之间线搜索”是不同协议。展示结果时必须说明使用哪一个，否则安全与回报不可比较。

6. \(\beta\) 越大越安全吗？

\(\beta\) 增大意味着使用更高分位数，通常提高保守性，但不是单调的现实安全旋钮：

  • 太高：主策略频繁被覆盖，探索不足，回报下降，边界数据更少。
  • 太低：忽略模型不确定性尾部，漏掉危险动作。
  • DRC 未校准：无论 \(\beta\) 多高，错误分布仍可能过度自信。
  • 高斯近似失配：多峰、重尾或接触切换风险不能由均值/方差完整描述。

应联合报告真实违反率、严重度、Shield 触发率、主动作接受率、风险校准曲线与 return，而不是只调 \(\beta\) 看单一曲线。

7. 五类反常现象

有安全 Critic，违反仍发生

分布外接触、传感器误差、时延和动力学集成共同失配会让 DRC 低估风险。\(Z_\beta\le0\) 是学习模型下的判据，不是现实无条件保证。

Shield 触发率下降，违反却上升

可能是 DRC 变得过度自信，而非主策略更安全。检查分位数校准、误报/漏报和 OOD 状态，不把低触发率本身当成功。

世界模型一步 Loss 下降，控制仍变差

平均一步误差可能忽略安全边界区域；模型 rollout 会累积局部偏差。需要边界数据子集、真实/虚拟分布差和 rollout horizon 消融。

\(\beta\) 增大后回报与安全同时变差

过度保守改变访问分布，关键边界数据不足；主 Actor 的候选动作又经常不被真正执行，训练数据与候选策略发生错位。

仿真安全，真实部署不安全

真实视觉噪声、接触、控制延迟与执行器饱和超出训练分布。必须在部署前加入独立硬约束与分阶段测试。

8. 面向真实机器人必须增加的安全层

硬约束

关节、速度、力矩

底层控制器直接限制，不能等待学习型风险模型发现。

几何

碰撞与工作空间

独立距离监控、禁入区域与安全姿态。

系统

Watchdog 与急停

通信超时、传感器异常和人机共域必须有独立停止链。

验证

Shadow → 低速 → 扩权

先仿真、再只观察不执行、随后受限工作区逐级放开。

这些是面向真实系统的工程扩展，不应伪装成论文已经验证的组件。

9. 最小消融矩阵

消融 改变量 主要指标 要证伪的假设
风险分位数 \(\Phi^{-1}(\beta)\) return、违反率、触发率 越保守必然越安全
去掉分布方差 只用均值证书 训练期违反 不确定性项无贡献
去掉 Shield 只执行主策略 违反与回报 Shield 只是冗余
模型 horizon 虚拟轨迹长度 模型偏差、样本效率 越长越高效
动作协议 训练切换 vs 评估线搜索 安全与保守性 两种协议等价

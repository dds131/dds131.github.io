子页 ① 得到的算法 1 有严格的单调改进保证，却有三处无法在实践中满足：惩罚系数按最坏情况取值、约束要对所有状态取最大、优势要精确已知。本页讲 TRPO 为此做的三处让步，以及每一处的代价。这三步做完，TRPO 就从一个理论算法变成了一个能用本轮采样数据写出来的优化问题。

推导链位置：性能差恒等式 → 局部近似 L → 单调改进下界 → 算法 1（子页 ①） → 惩罚改约束 → 最大 KL 改平均 KL → 样本估计（本页） → 自然梯度（子页 ③） → 数值求解（子页 ④） → 训练系统（子页 ⑤）

本页拥有：三处让步的理由与代价、KL 的方向、式 (13) 到 (14) 的三处替换、single path 与 vine 的完整对照。不在本页展开：下界从何而来见子页 ①；这个优化问题怎么解见子页 ③与子页 ④；优势用 GAE 怎么估见子页 ⑤；把约束换成裁剪的做法见 PPO 页。

一、本页要回答的问题

  1. 为什么把惩罚换成硬约束？换了之后失去了什么、得到了什么（第三节）。
  2. 为什么可以用平均 KL 代替最大 KL？代价有多大？（第四节）
  3. KL 该写成「旧对新」还是「新对旧」？（第五节）
  4. 怎样把优化问题写成只用本轮样本就能算的形式？（第六节）
  5. 样本从哪里来？single path 与 vine 的差别（第七节）。

二、参数化之后的理论问题

论文第 4 节先把记号从策略换成参数：\(\eta(\theta) := \eta(\pi_\theta)\)、\(L_\theta(\tilde\theta) := L_{\pi_\theta}(\pi_{\tilde\theta})\)、\(D_{\mathrm{KL}}(\theta\,\Vert\,\tilde\theta) := D_{\mathrm{KL}}(\pi_\theta\,\Vert\,\pi_{\tilde\theta})\)，并用 \(\theta_{\text{old}}\) 表示要改进的那一组参数。

子页 ① 的算法 1 写成参数形式就是论文的式 (10)：

\[\max_{\theta}\;\Big[\,L_{\theta_{\text{old}}}(\theta) - C\,D_{\mathrm{KL}}^{\max}(\theta_{\text{old}},\theta)\,\Big], \qquad C = \frac{4\epsilon\gamma}{(1-\gamma)^{2}}\]

按子页 ① 第八节，只要每轮真的解出这个问题的最大值，回报就单调不降。下面三节要做的，是把这个式子里三样做不到的东西逐一换掉。

三、第一处让步：惩罚改为硬约束

3.1 论文的原话

「In practice, if we used the penalty coefficient C recommended by the theory above, the step sizes would be very small. One way to take larger steps in a robust way is to use a constraint on the KL divergence between the new policy and the old policy, i.e., a trust region constraint.」（实践中若采用上述理论推荐的惩罚系数 C，步长会非常小。一种稳健地迈出更大步子的办法，是对新旧策略之间的 KL 散度施加约束，也就是信任域约束。）

于是式 (10) 变成论文的式 (11)：

\[\max_{\theta}\; L_{\theta_{\text{old}}}(\theta) \qquad \text{s.t.} \qquad D_{\mathrm{KL}}^{\max}(\theta_{\text{old}},\theta) \le \delta\]

C 消失了，取而代之的是一个新的超参数 δ。

3.2 换成约束究竟改变了什么

以下是本站的分析。把约束问题写成拉格朗日形式 \(\max_\theta L_{\theta_{\text{old}}}(\theta) - \lambda\big(D_{\mathrm{KL}} - \delta\big)\)，可以看出：

  • 约束形式可理解为由每一步的 KKT 乘子决定有效惩罚强度。惩罚形式固定 C；若约束在局部最优点处活跃，拉格朗日乘子 λ 会随本轮梯度、曲率与 δ 改变。在线性目标、正定二次约束的局部模型中，这个对应关系可以精确写出；对原始非凸神经网络问题，只能作局部解释，不能宣称全局等价。
  • C 是按最坏情况算出来的常数，注定过于保守。它含有未知的 ε，而且随 \(1/(1-\gamma)^2\) 增长（子页 ① 第九节给出了量级与可认证步长的上限）。约束形式把「一步该走多远」这件事交给 δ，不再依赖 ε。
  • δ 比 C 更具可解释性。δ 直接限制一步的平均分布变化；精确 KL 约束在光滑、可逆的重参数化下保持不变，也不随奖励单位直接缩放。论文实验统一使用 δ = 0.01，说明它在这些任务间具有一定稳健性，但这不等于所有任务都无需调整：动作维度、策略族、批量大小、KL 方向和估计噪声都会影响合适的 δ。子页 ③ 解释局部参数化不变性。
代价很明确：式 (11) 不再有单调改进保证。子页 ① 的证明依赖「每轮最大化下界」，而下界里的惩罚项已经被换成了一个人为设定的半径。论文摘要对此的措辞是「Despite its approximations that deviate from the theory, TRPO tends to give monotonic improvement」——只是「倾向于」，不是保证。

3.3 δ 与学习率的区别

对比项 一阶优化器的学习率 信任域半径 δ
直接控制的量 参数更新的基础尺度 策略分布变化的预算（平均 KL）
与参数化的关系 通常敏感 精确约束对光滑可逆重参数化不变；有限样本与近似求解会破坏部分不变性
与奖励尺度的关系 梯度随奖励缩放；Adam 等会部分改变这种关系 δ 本身不随奖励单位变化；优势缩放在理想二次子问题中被步长归一化抵消
每一步的实际参数步长 还受梯度、动量、自适应预条件等影响，并非恒定 由 δ、当前 Fisher 曲率、梯度和线搜索共同决定
跨任务复用 往往需要重调 通常比裸学习率稳健，但仍受动作维度、策略族、批量与 KL 估计误差影响

3.4 惩罚这条路后来也有人走回去

TRPO 选择了约束，但惩罚形式并没有消失：PPO 论文里除了裁剪目标之外，还有一节「Adaptive KL Penalty Coefficient」，用的就是带惩罚系数的形式，并让系数随实测 KL 自动调整。两条路线的对照见 PPO 页。

四、第二处让步：最大 KL 改为平均 KL

4.1 论文的原话与式 (12)

「This problem imposes a constraint that the KL divergence is bounded at every point in the state space. While it is motivated by the theory, this problem is impractical to solve due to the large number of constraints. Instead, we can use a heuristic approximation which considers the average KL divergence.」（这个问题要求 KL 散度在状态空间的每一点都有界。它虽然由理论推出，却因为约束数量太多而无法求解。因此我们改用一个考虑平均 KL 散度的启发式近似。）

论文定义在状态分布 ρ 上的平均 KL

\[\bar D_{\mathrm{KL}}^{\rho}(\theta_1,\theta_2) \;:=\; \mathbb{E}_{s\sim\rho}\Big[D_{\mathrm{KL}}\big(\pi_{\theta_1}(\cdot\mid s)\,\Vert\,\pi_{\theta_2}(\cdot\mid s)\big)\Big]\]

并把 ρ 取为旧策略的状态分布，得到式 (12)：

\[\max_{\theta}\; L_{\theta_{\text{old}}}(\theta) \qquad \text{s.t.} \qquad \bar D_{\mathrm{KL}}^{\rho_{\theta_{\text{old}}}}(\theta_{\text{old}},\theta) \le \delta\]

这就是实用 TRPO 求解的总体期望问题。注意期望取在旧策略的状态分布上：本轮数据正由旧策略采集，因此可以直接形成样本均值。若改取新策略的状态分布，现有批次不能直接估计；必须额外执行新策略，或引入占用度量比等离策略校正。

论文同时指出，类似的策略更新此前已有人提出（Bagnell 与 Schneider 2003；Peters 与 Schaal 2008b；Peters 等 2010），并在第 7 节与实验中与这些方法作了比较。与自然策略梯度、REPS 的逐项对照见子页 ③。

4.2 最大 KL 为什么在一般规模下不可行

两个原因：

  • 约束数量等于状态数量。连续状态空间下这是无穷多个约束，无法逐一写出，更无法交给求解器。
  • 用有限样本替代全状态最大值也不能恢复原约束。旧策略轨迹只覆盖其访问到的状态，样本最大值通常低估全状态上确界，却又对单个极端样本高度敏感；增加样本时，经验最大值只会不减，但仍无法保证发现低概率或未访问状态。平均 KL 的样本均值在独立同分布理想化下是总体平均 KL 的无偏估计，轨迹相关性会影响方差与有效样本量。论文只说明了约束数量过多，以上是统计层面的补充。

4.3 代价：平均不超过 δ，个别状态可以远超 δ

这是这处让步最核心的代价。平均 KL 按访问概率加权，所以低概率状态或状态区域对约束的贡献更小。在离散情形下，若某状态的概率为 p、其余状态的 KL 近似为零，则约束只要求该状态的 KL 不超过 δ/p；p = 1% 时可达到 100δ。连续状态空间中单点概率通常为零，应把同一结论理解为“概率质量为 p 的可测区域”，而不是单个点。有限批次还会叠加采样误差。

子页 ① 的理论用的是最大 KL，正是为了控制最坏的那个状态。改成平均之后，理论上的单调改进保证失去了最后一块支撑。论文自己在第 6 节把这一条列为理论与实用算法之间的第二条差距。后来 Achiam 等人在 CPO 中证明了一个以平均散度表示的下界，为这处让步提供了事后的理论依据，但给出的是最坏退化的上限而不是改进保证，见子页 ① 第十一节。

4.4 论文的实验证据

论文第 4 节末尾写道：「Our experiments also show that this type of constrained update has similar empirical performance to the maximum KL divergence constraint in Equation (11).」第 8 节给出了对应的实验：最大 KL 版本只在 cart-pole 上可算（状态维度低，能够遍历），实验结论是它「learned somewhat more slowly than our final method, due to the more restrictive form of the constraint」，但整体上「the average KL divergence constraint has a similar effect as the theorecally justified maximum KL divergence」（原文的 theorecally 为论文中的拼写）。曲线见子页 ⑦转载的论文 Figure 4。

五、KL 的方向：旧对新，还是新对旧

5.1 论文写的是「旧对新」

式 (12) 的 \(\bar D_{\mathrm{KL}}(\theta_{\text{old}},\theta)\) 中旧参数在前；式 (14) 写得更明确：约束是 \(\mathbb{E}_{s\sim\rho_{\theta_{\text{old}}}}\big[D_{\mathrm{KL}}(\pi_{\theta_{\text{old}}}(\cdot\mid s)\,\Vert\,\pi_{\theta}(\cdot\mid s))\big] \le \delta\)，即 KL(旧 ‖ 新)。

5.2 但各实现并不统一

值得注意的是 Spinning Up：同一个库里，高斯策略算「新对旧」，离散策略算「旧对新」，文档写「新对旧」。公开源码与文档没有说明这种差异的原因，因此不应断言它是设计选择还是历史问题。可以确定的是：不能仅凭“使用了 KL”推断方向，必须查看具体分布函数的参数顺序；两个方向只在旧策略处的二阶局部模型中一致。

5.3 为什么局部可以互换

在旧策略处，两个方向的 KL 值都为零、一阶导数也都为零，而且二阶项完全相同：两者的 Hessian 都等于 Fisher 信息矩阵。因此在二次近似的层面上，两个方向定义出的信任域是同一个椭球，TRPO 求解时用的也正是这个二次近似。完整证明见子页 ③ 第四节。

5.4 有限步时并不相同：一个可以手算的例子

取一维高斯策略，均值不动，只把标准差按 \(\sigma_{\text{new}} = \sigma_{\text{old}}e^{t}\) 改变。两个方向的 KL 都有闭式：

\[D_{\mathrm{KL}}(\text{旧}\,\Vert\,\text{新}) = t + \tfrac{1}{2}e^{-2t} - \tfrac{1}{2}, \qquad D_{\mathrm{KL}}(\text{新}\,\Vert\,\text{旧}) = -t + \tfrac{1}{2}e^{2t} - \tfrac{1}{2}\]

两者的二次近似都是 \(t^{2}\)，但有限的 t 下数值不同：

变动 t 二次近似 t² KL(旧 ‖ 新) KL(新 ‖ 旧)
标准差缩小约 9.5% −0.1 0.01000 0.01070 0.00937
标准差放大约 10.5% +0.1 0.01000 0.00937 0.01070
结论：以 δ = 0.01 为界，同一步更新在一个方向上违反约束、在另一个方向上却满足。本例中两者相差约 14%。训练中标准差通常是逐渐缩小的，此时「旧对新」这一侧的 KL 更大，用这个方向的实现会更早触发约束。这个算例在[子页 ④](/knowledge/reinforcement-learning/trpo/solver/)还会再用一次，用来解释线搜索为什么常常恰好回退一次。

实践含义有两条：其一，跨实现比较 δ 时必须同时记录 KL 方向；其二，FVP 在旧策略处使用二阶模型时两个方向给出同一个 Fisher 矩阵，但线搜索评估的是有限步的真实 KL，方向会影响接受结果。因此实现应明确并统一诊断与接受准则的方向，不能把局部二阶等价误当成有限步等价。

六、第三处让步：期望改为样本均值

6.1 先把 L 展开

式 (12) 中的 \(L_{\theta_{\text{old}}}(\theta)\) 含有一个与 θ 无关的常数 \(J(\pi_{\theta_{\text{old}}})\)，求最大值时可以丢掉。展开后就是论文的式 (13)：

\[\max_{\theta}\;\sum_{s}\rho_{\theta_{\text{old}}}(s)\sum_{a}\pi_{\theta}(a\mid s)\,A_{\theta_{\text{old}}}(s,a) \qquad \text{s.t.} \qquad \bar D_{\mathrm{KL}}^{\rho_{\theta_{\text{old}}}}(\theta_{\text{old}},\theta)\le\delta\]

6.2 三处替换

论文用三步把它变成可以用样本估计的形式。

其一，对状态的求和换成期望。由子页 ① 的第一条基本事实，\(\sum_s \rho(s)[\cdots] = \frac{1}{1-\gamma}\mathbb{E}_{s\sim\nu}[\cdots]\)。常数因子 \(1/(1-\gamma)\) 不改变最大值的位置，实现中直接省略。

其二，优势换成动作价值。论文的原话是这一步「only changes the objective by a constant」。理由是

\[\sum_{a}\pi_{\theta}(a\mid s)\,A_{\theta_{\text{old}}}(s,a) \;=\; \sum_{a}\pi_{\theta}(a\mid s)\,Q_{\theta_{\text{old}}}(s,a) \;-\; V_{\theta_{\text{old}}}(s)\]

而 \(V_{\theta_{\text{old}}}(s)\) 只与旧策略有关，与待优化的 θ 无关，对每个状态都是常数。

其三，对动作的求和换成重要性采样。设采样分布为 q，则

\[\sum_{a}\pi_{\theta}(a\mid s_n)\,A_{\theta_{\text{old}}}(s_n,a) \;=\; \mathbb{E}_{a\sim q}\left[\frac{\pi_{\theta}(a\mid s_n)}{q(a\mid s_n)}\,A_{\theta_{\text{old}}}(s_n,a)\right]\]

三步合起来，就是论文的式 (14)：

\[\max_{\theta}\;\mathbb{E}_{s\sim\rho_{\theta_{\text{old}}},\,a\sim q}\left[\frac{\pi_{\theta}(a\mid s)}{q(a\mid s)}\,Q_{\theta_{\text{old}}}(s,a)\right] \qquad \text{s.t.} \qquad \mathbb{E}_{s\sim\rho_{\theta_{\text{old}}}}\Big[D_{\mathrm{KL}}\big(\pi_{\theta_{\text{old}}}(\cdot\mid s)\,\Vert\,\pi_{\theta}(\cdot\mid s)\big)\Big]\le\delta\]

式中每一项都能用本轮采样的数据估计：状态来自旧策略跑出来的轨迹，动作来自采样分布 q，Q 值由蒙特卡洛估计，新策略的概率由候选网络前向计算。

6.3 现代实现里的写法

今天的实现（Spinning Up、SB3-Contrib、《动手学强化学习》）都取 \(q = \pi_{\theta_{\text{old}}}\)，并把 Q 换回优势的估计 \(\hat A\)（由 GAE 给出，见子页 ⑤）：

\[L(\theta) \;=\; \mathbb{E}\left[\frac{\pi_{\theta}(a\mid s)}{\pi_{\theta_{\text{old}}}(a\mid s)}\,\hat A\right]\]

两点说明：

  • 为什么最终用优势而不是 Q。如 6.2 所述，两者只差一个与 θ 无关的常数，最优解相同；但用优势的估计方差更小，这就是基线的作用，见策略梯度子页 ②。
  • 为什么需要重要性采样。候选策略还没有被执行过，无法直接从它采样；当 q 的支撑覆盖候选策略的支撑时，概率比可以把 q 下的动作期望改写成候选策略下的期望。它让同一批旧数据评估邻域内的候选 θ，但不意味着可以稳定评估任意远的策略：概率比过大时方差会急剧上升，KL 信任域也在控制这一风险。PPO 页使用的是同一换测度关系。
这里有一个容易被忽略的边界：重要性采样只修正“给定状态后，动作从哪个分布采”，没有修正“状态从哪个占用度量来”。状态分布差异正是局部近似 L 丢掉的部分（子页 ①）。占用度量比不能由单步动作似然比直接得到；在未知动力学下若要估计它，需要额外的密度比估计或离策略评估方法，并会引入新的误差。TRPO 不做这一步，而是让候选策略保持在旧策略附近，以控制忽略状态分布变化造成的误差。

七、样本从哪里来：single path 与 vine

论文第 5 节给出两种采样方案，Figure 1 把它们画在了一起。

图 2 · single path（左）与 vine（右）。图片取自论文 arXiv:1502.05477 v5 的 Figure 1，按原图裁切，未作其他修改。

7.1 single path

从初始分布采一个状态，用旧策略一路跑下去，得到一条轨迹；采样分布就是旧策略本身，即 \(q = \pi_{\theta_{\text{old}}}\)。轨迹上的每个状态动作对都进入目标，\(Q_{\theta_{\text{old}}}(s_t,a_t)\) 用该时刻之后的折扣回报估计。

论文强调它的一个优点：不需要重置环境，「requires no state resets and can be directly implemented on a physical system」（可以直接在实体系统上实现）。

7.2 vine

先用旧策略采若干条轨迹，从中挑出 N 个状态构成 rollout set；在每个状态 \(s_n\) 上按 q 采 K 个动作，对每个动作各做一次短 rollout 来估计它的 Q 值。三个要点：

  • 公共随机数。同一状态上 K 次 rollout 使用同一串随机数，这样比较不同动作时，环境噪声带来的差异被抵消掉，Q 值之差的方差大幅下降。
  • 离散动作可以全枚举。动作数不多时对每个动作都做一次 rollout，单个状态对目标的贡献是式 (15) 的 \(\sum_k \pi_\theta(a_k\mid s_n)\hat Q(s_n,a_k)\)。
  • 连续动作用自归一化重要性采样。式 (16) 的估计量分子分母都带重要性比值。论文指出它「removes the need to use a baseline for the Q-values」——因为给同一状态下所有 Q 值加常数，不改变归一化权重目标对 θ 的梯度。q 的选择上，论文说连续控制取当前迭代策略 \(q = \pi_{\theta_i}\) 效果好，而 Atari 这类离散任务取均匀分布有时能改善探索。这里的 \(\theta_i\) 是采样时固定的旧参数，不是正在优化的候选参数 θ。

7.4 为什么主流实现通常采用 single path

vine 的方差优势是实在的，但它要求系统恢复到选定状态，并从该状态在可比随机条件下反复 rollout。实体机器人通常难以安全、精确地恢复；仿真环境即使能存取内部状态，Gym/Gymnasium 的标准 reset/step 接口也不保证提供任意状态恢复。与此同时，GAE 能在不增加分支 rollout 的情况下控制优势估计的偏差—方差折中（子页 ⑤）。因此，本站核对的主流实现都采用 single path 加 GAE。

具体核对了 Spinning Up TF1、SB3-Contrib、OpenAI Baselines trpo_mpi、ikostrikov/pytorch-trpo、rllab NPO，以及第一作者的 modular_rl；这六套源码均未实现 vine。这个结论只描述所核对的实现，不能外推为“所有后续 TRPO 实现都没有 vine”。

八、三处让步之后的最终问题

把三处让步合起来，并采用 6.3 节的现代写法，TRPO 每一轮实际要解的问题是：

\[\max_{\theta}\;\; \hat{\mathbb{E}}\left[\frac{\pi_{\theta}(a\mid s)}{\pi_{\theta_{\text{old}}}(a\mid s)}\,\hat A\right] \qquad \text{s.t.} \qquad \hat{\mathbb{E}}\Big[D_{\mathrm{KL}}\big(\pi_{\theta_{\text{old}}}(\cdot\mid s)\,\Vert\,\pi_{\theta}(\cdot\mid s)\big)\Big] \le \delta\]

其中 \(\hat{\mathbb{E}}\) 表示在本轮批次上取样本平均；此处采用论文的“旧对新”方向，使用其他方向的实现必须相应地统一 FVP、线搜索与日志定义。

还要区分两层约束：式 (12) 约束的是旧策略状态分布下的总体平均 KL，上式实际检查的是有限批次上的经验平均 KL。即使经验值不超过 δ，总体期望也可能因采样误差而超过 δ；轨迹相关性、批量大小和低概率状态覆盖都会影响这段泛化差距。

这个问题的目标与约束都是几十万维参数的非线性函数，没有闭式解。子页 ③把它在旧参数附近展开成「线性目标加二次约束」，从而得到一个有解析解的近似问题；子页 ④再讲这个解在大网络上怎么真正算出来。

九、本页的反直觉结论

  1. 用 Q 替换优势不改变最优解，却改变方差。两者只差一个与 θ 无关的常数，所以论文说「only changes the objective by a constant」；但估计量的方差差别很大，所以现代实现又换回了优势（6.2、6.3 节）。
  2. 平均 KL 不超过 δ，不代表每个状态的 KL 都不超过 δ。访问概率为 p 的状态，其 KL 最大可到 δ/p（4.3 节的图 1）。
  3. KL 的方向在局部无所谓，有限步时却会改变结论。同一步更新可能在一个方向上违反约束、在另一个方向上满足（5.4 节）。
  4. 重要性采样只修正条件动作分布，没有修正状态占用度量。后者不能由单步动作似然比直接得到；TRPO 用信任域控制被忽略的状态分布变化，而不是显式估计占用度量比（6.3 节）。
  5. 方差更低的 vine 没有进入本站核对的六套主流实现。它依赖重复恢复状态，这个前提限制了适用场景（7.4 节）。
  6. 理论要求最大 KL，实验却显示平均 KL 效果相当。论文只在 cart-pole 上能算最大 KL 版本，结果是它学得稍慢（4.4 节）。

本页小结

  1. 惩罚改硬约束：C 按最坏情况取值、且含未知的 ε，改成半径 δ 之后步子才迈得动，代价是失去严格的单调改进保证。
  2. 最大 KL 改平均 KL：在连续状态空间中最大 KL 对应无穷多个逐状态约束，在大规模问题中也难以可靠估计；平均 KL 可由旧策略批次形成样本均值，代价是低概率区域的 KL 可远超 δ，且经验均值存在泛化误差。
  3. KL 的方向：论文用「旧对新」，SB3 与 Spinning Up 文档用「新对旧」，两者在旧策略处二阶一致，有限步时数值不同。
  4. 样本估计：对状态的求和换成期望、优势换成 Q、对动作的求和换成重要性采样，得到式 (14)；现代实现取 q 为旧策略并换回优势估计。
  5. 采样方案：single path 不需要任意状态恢复、可用于实体系统；vine 方差更低但要求重复恢复状态。本站核对的六套主流实现都采用前者，通常与 GAE 配合。

六套逻辑参数：明确谁优化、谁跟随

结构总览：在线 actor \(\mu_\phi\)、目标 actor \(\mu_{\phi'}\)，在线 critic \(Q_{\theta_1},Q_{\theta_2}\)，以及对应的目标 critic \(Q_{\theta'_1},Q_{\theta'_2}\)。三套在线参数参与梯度优化；三套目标参数不进入优化器，只从对应在线参数初始化并做 Polyak 跟随。“六网络”描述的是六个逻辑角色，不要求必须写成六个顶层模块。

MLP、经验回放和在线/目标网络基础已在 DDPG 展开；SAC 的随机 actor 与 twin Q 结构见 SAC 网络结构。相对 DDPG，TD3 在结构上新增第二套在线 critic 及其目标副本；关键不是“网络数量”本身，而是两个目标 Q 构造 target、在线 Q1 单独提供 actor 梯度的不对称职责。

1. 六网络职责矩阵

| 逻辑网络 | 输入 | 原始输出 | 参数如何更新 | 主要用途 | |---|---|---|---|---| | 在线 actor \(\mu_\phi\) | \(s:[B,d_s]\) | \(u:[B,d_a]\) | actor optimizer | 经动作变换后用于采样、actor loss、评估 | | 目标 actor \(\mu_{\phi'}\) | \(s':[B,d_s]\) | \(u':[B,d_a]\) | 仅 Polyak | 经目标平滑和动作变换后构造下一动作 | | 在线 \(Q_{\theta_1}\) | \([s,a]:[B,d_s+d_a]\) | \(q_1:[B,1]\) | critic optimizer | critic loss、actor loss | | 在线 \(Q_{\theta_2}\) | \([s,a]\) | \(q_2:[B,1]\) | critic optimizer | critic loss | | 目标 \(Q_{\theta'_1}\) | \([s',\tilde a']\) | \(q'_1:[B,1]\) | 仅 Polyak | Bellman target 的逐样本 min | | 目标 \(Q_{\theta'_2}\) | \([s',\tilde a']\) | \(q'_2:[B,1]\) | 仅 Polyak | Bellman target 的逐样本 min |

本页后续默认 actor 输出归一化动作 (u)，统一变换为环境物理动作 (a)，replay 与 critic 都使用 (a)。若选择让 critic 使用 (u)，则 replay、在线/目标 critic 和 actor-loss 路径都必须一起改成 (u)。

正确初始化关系是：

[ \phi’=\phi,\qquad \theta’_1=\theta_1,\qquad \theta’_2=\theta_2, \qquad\text{但通常}\quad \theta_1\ne\theta_2. ]

先独立随机初始化 Q1、Q2，再把每个在线网络的完整状态（参数和 buffers）复制到对应目标网络；目标副本必须数值相同但存储不别名。若把 Q2 直接复制成 Q1，二者在相同数据、target 和优化规则下可能始终相同，使 (\min(Q_1,Q_2)) 退化为单 critic。

2. 数据流与梯度边界

图中两个“在线 Actor”节点是同一套参数在采样和训练路径中的两次调用，并非两个 actor。实线表示前向/训练数据，虚线表示显式参数跟随。

三条梯度边界必须分清：

  • critic 更新：整个 target 分支 (y=r+\gamma m\min_iQ_{\theta’_i}(s’,\tilde a’)) 在 no_grad 下构造；replay 动作 (a) 不经过在线 actor，critic loss 不应更新 actor。
  • actor 更新：最小化 (L_\pi=-\mathbb E_s[Q_{\theta_1}(s,a_\phi(s))])。可以临时冻结 Q1 参数以节省计算，但不能对 (a_\phi(s)) 或 Q1 输出 detach；必须保留 (\partial Q_{\theta_1}/\partial a\cdot\partial a_\phi/\partial\phi)，且 actor optimizer 只更新 (\phi)。
  • 目标更新：Polyak 是显式参数赋值，不依赖 autograd；标准 TD3 在延迟 actor 更新事件后同步更新三套目标参数。

3. Actor：先统一动作坐标

本页推荐的基线约定是：actor 输出 (u=\tanh(z)\in[-1,1]^{d_a})，唯一的 ActionTransform 将其映射为物理动作：

[ a=a_{\text{bias}}+a_{\text{scale}}\odot u,\qquad a_{\text{bias}}=(a_{\max}+a_{\min})/2,\qquad a_{\text{scale}}=(a_{\max}-a_{\min})/2. ]

环境交互时必须保存真正导致 (r_t,s_{t+1}) 的动作，而不是裁剪前的“意图动作”：

[ a_t^{\mathrm{exec}} =\Pi_{\mathcal A}!\left( a_{\text{bias}}+a_{\text{scale}}\odot u_t+\epsilon_{\text{explore}} \right). ]

基线直接把 (a_t^{\mathrm{exec}}) 存入 replay。若改为存归一化动作，则应存 (u_t^{\mathrm{exec}}=(a_t^{\mathrm{exec}}-a_{\text{bias}})\oslash a_{\text{scale}})，并让所有 critic 路径都读取 (u)。安全层或环境若再次修改动作，应尽可能记录最终执行值，否则 critic 会把结果错误归因给另一个动作。

ActionTransform 应集中负责 scale、unscale 和 clip，并用往返测试验证 unscale(scale(u))≈u。上述仿射变换要求每维动作具有有限 Box 边界且 (a_{\max,j}>a_{\min,j})；非盒或耦合约束见第 9 节。

若 critic 接收物理动作，则 (a_{\text{scale}}) 会进入 actor 的链式梯度，而 tanh 饱和项会压低梯度：

[ \nabla_\phi Q(s,a_\phi) = \left[\nabla_aQ(s,a_\phi)\odot a_{\text{scale}} \odot(1-\tanh^2z)\right]\nabla_\phi z. ]

因此动作范围差异很大时，使用归一化 critic 接口可减少纯坐标尺度差异；无论选哪种接口，全链路必须一致。

4. Critic：独立性与归一化

critic 的核心是把状态表示和动作表示拼接后输入 MLP：

[ Q_\theta(s,a)=f_\theta([\,x_s,x_a\,]). ]

其中 (x_s) 可以是原始状态或标准化状态；按本页基线，(x_a=a)。若统一改用归一化动作，则 (x_a=u)，不应再对 (u) 做动态均值/方差归一化。状态或动作归一化是工程选择，不是 TD3 定义。

标准低维基线让 Q1、Q2 使用独立参数。高维视觉任务可有意共享 encoder，但这通常会提高误差相关性，削弱 twin critics 对共同高估的过滤能力；还必须明确共享参数由哪个 loss/optimizer 更新、target encoder 如何同步，以及 actor 是否对 encoder 回传。同一共享参数不应无意出现在两个 Adam optimizer 中并被重复 step。

归一化注意事项：

  • 网络外 observation normalizer 只根据已采集的训练数据更新；(s) 与 (s’) 以及全部在线/目标网络读取同一份当前统计；
  • target 前向和评估前向不更新统计，评估期间冻结更新；均值、方差和计数都要写入 checkpoint；
  • 固定正系数的 reward scaling 会同比改变理想 Q，同时改变 TD error 与 actor 梯度的数值尺度；动态 reward normalization 还会让 target 随统计量变化；
  • BatchNorm 的 running buffers 不会因只遍历 parameters() 做 Polyak 而自动同步。若使用它，需明确 target buffer 的复制规则和 train/eval 模式；低维基线优先不用 BatchNorm，或使用无运行统计的 LayerNorm。

5. Replay transition：终止与最终观测

最小 transition 为

[ (s_t,\;a_t^{\mathrm{exec}},\;r_t,\;s_{t+1},\; \text{terminated}_t,\;\text{truncated}_t). ]

不要只存混合的 done。通常仅真正终止阻断 bootstrap：

[ m_t=1-\mathbb 1[\text{terminated}_t]. ]

若任务把某类 timeout 明确定义为真正终止，再通过显式配置修改 mask。对需要 bootstrap 的截断 transition，(s_{t+1}) 必须是截断前的最终观测；自动重置环境可能把普通 next_obs 替换为下一 episode 的初始状态，此时应读取 final_observation 或 terminal_observation。

调试版本可额外保存 episode_id 和 step_index，用于发现错误的跨 episode 拼接或不兼容数据混入；它们不是标准 TD3 更新的必需输入。

6. 参数与优化器边界

Actor optimizer
只包含在线 actor 参数；目标 actor 不能注册进去。
Critic optimizer
可由一个 optimizer 管理 Q1+Q2，也可分开；两项 loss 仍要分别记录。
Target networks
建议 requires_grad=False，不进 optimizer、不被 weight decay；target 前向仍放在 no_grad 中。

一个 critic optimizer 同时管理 Q1、Q2 并不表示共享参数；Q1/Q2 也可以封装在同一个模块中。实现审计至少检查：

  1. 标准低维基线中，Q1、Q2 参数无别名，初始参数或固定 probe 输出不完全相同；
  2. 每个 target 与对应 online 的完整初始状态相等，但参数对象和底层存储不同；
  3. actor optimizer 的参数集合恰好等于在线 actor，critic optimizer 的参数并集恰好等于在线 Q1、Q2，且没有重复；
  4. target 参数不在任何 optimizer 的 param group 中；
  5. checkpoint 恢复时按参数名称、形状和 param-group 顺序核对 optimizer 状态，而非只假设列表顺序未变。

7. Polyak 更新：先看公式方向，再看 buffers

常用定义：

[ \theta’\leftarrow(1-\tau)\theta’+\tau\theta,\qquad \tau\ll1. ]

有的代码把 polyak=0.995 写成

[ \theta’\leftarrow\text{polyak}\cdot\theta’ +(1-\text{polyak})\cdot\theta. ]

两种记法等价，但参数数值含义相反：(\tau=0.005) 对应 polyak=0.995。移植配置时必须核对公式，不能只复制参数名。

上述公式只描述可训练参数。初始化应复制完整 state_dict；若网络含 BatchNorm 等 buffers，后续还要明确硬复制或专门同步规则。标准 TD3 在每次延迟 actor 更新后更新 actor target 与两个 critic target，而不是每次 critic 更新都执行。

8. 张量形状与广播审计

| 张量 | 推荐形状 | 典型静默错误 | |---|---|---| | reward | \([B,1]\) | 若误存为 \([B]\)，与 \([B,1]\) 的 Q 运算会广播为 \([B,B]\) | | bootstrap mask | \([B,1]\) | 若为 \([B]\)，构造 target 时可能广播为 \([B,B]\) | | Q 输出 | \([B,1]\) | 无条件 squeeze() 会使维数随 \(B\) 改变 | | action | \([B,d_a]\) | \(d_a=1\) 时误删动作维，\(B=1\) 时还可能误删 batch 维 | | target noise | 与 action 完全相同 | 仅为 \([d_a]\) 时，同一噪声向量会广播到整个 batch | | obs | \([B,d_s]\) | 单样本推理缺 batch 维 |

上表针对低维向量观测；图像、序列或字典观测应保留各自结构。([B]) 与 ([B,1]) 广播成 ([B,B]) 往往不报错，loss 仍返回标量，是最危险的静默 bug 之一。构造 loss 前应断言

[ \operatorname{shape}(y)=\operatorname{shape}(Q_1) =\operatorname{shape}(Q_2)=[B,1], ]

并检查 reward、mask、Q、action、noise 的 device 与浮点 dtype 一致；布尔 terminated 在计算 (m=1-\text{terminated.float()}) 时显式转换。

9. 结构选择边界

  • TD3 论文实验使用 400、300 单元的两层 ReLU MLP；作者当前公开 PyTorch 参考实现采用两层 256 单元。二者都只是起点；复现具体基线时必须同时报告网络宽度、激活函数、初始化、学习率和动作缩放。
  • actor 与 critic 不必同宽；先保证训练时序正确，再调容量。
  • 视觉 encoder、循环网络、Transformer 会引入表示漂移。若 target 侧也有 encoder，必须说明它是 Polyak 跟随、硬复制还是共享；不同选择会改变双 critic 的误差相关性。
  • 多任务或 goal-conditioned TD3 要把 goal 一致地输入 actor、所有 critic 与 replay。
  • 动作约束若不是盒约束，简单 tanh+clip 可能不够，应使用可行域投影或专门策略参数化。

10. 知识点、创新归因与验收

  • 结构知识点：TD3 有六个逻辑角色；模块怎样封装不改变在线/目标和 Q1/Q2 的职责边界。
  • 继承部分：经验回放、目标 actor、目标 critic、动作缩放与 Polyak 更新继承自 DDPG。
  • TD3 的结构新增点：相对 DDPG 增加第二个在线 critic 及其目标副本；两个目标 Q 共同构造 Bellman target，但 actor 只通过在线 Q1 更新。
  • 参数边界：标准低维基线中各逻辑参数不别名，Q1/Q2 独立初始化；有意共享 encoder 时，必须单独定义梯度所有权与 target encoder 规则。
  • 动作与数据边界：采样、replay、在线/目标 critic 共用一套动作坐标；transition 保存实际执行动作并区分 terminated 与 truncated。
  • 验收重点：target 路径无梯度，actor 路径保留动作梯度，optimizer 参数无遗漏或重复，目标初始状态完整复制，所有标量列统一为 ([B,1]) 且无隐式广播。

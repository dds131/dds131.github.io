08 · EXTENSIONS & RESEARCH MAP

先定位瓶颈，再选择 SAC 的下一步

REDQ、DroQ、TQC 与 CrossQ 都可能提高连续控制表现，却修改完全不同的环节。研究地图应记录“解决什么、改在哪里、付出什么”，而不是把带 Actor-Critic 的方法都装进“SAC 改进”标签。

先消除缩写歧义：本页 DSAC 专指 Duan et al. 的连续控制 Distributional Soft Actor-Critic（arXiv:2001.02811）；SD-SAC 指 Revisiting Discrete Soft Actor-Critic 提出的 Stable Discrete SAC。此外，Ma et al. 的风险敏感 distributional SAC（arXiv:2004.14547）也使用 DSAC 名称，因此引用时必须同时给出作者或论文编号，不能只写缩写。

本页统一用

\[\mathrm{UTD}_{\mathrm{updates}} =\frac{\text{每个 Critic 的 mini-batch 更新次数}}{\text{新增真实 transition 数}}\]

描述更新强度，并另报 replay sample ratio = 更新次数 × batch size / 新增真实 transition 数。论文若采用 ensemble，还要说明一次更新训练的成员数和 target 子集；不同计数口径不能只用一个“UTD”数字比较。

核心训练机制改进

REDQ · Randomized Ensembled Double Q-Learning

高 UTDQ ensemble随机子集最小值
问题
标准 SAC 每条新数据只做少量更新，环境样本利用有限；直接提高 UTD 容易放大 Q 偏差。
机制
使用多个独立初始化的 Q 网络及其目标副本；构造一个共享回归标量 target 时，从目标 Q ensemble 随机抽取子集 $$\mathcal M$$ 并取最小，同时让 Critic UTD 远高于 1。这里“共享 target”是指各 Critic 回归同一目标值，不是所有成员共用同一个网络对象。
公式
$$y=r+\gamma(1-d_{\mathrm{term}})[\min_{i\in\mathcal M}\bar Q_i(s',a')-\alpha\log\pi(a'\mid s')]$$；其中 $$d_{\mathrm{term}}$$ 只标记阻止 bootstrap 的真实终止。
Actor
原算法用全体 online Q 的平均更新策略，并把 Actor 更新比保持为每个真实 transition 约 1；“Critic UTD=20”不等于 Actor 也更新 20 次。
代价
更多参数与 Critic 梯度步；环境样本效率提高不等于墙钟更快。
研究点
分别消融 Critic UTD、Actor update ratio、ensemble size、subset size，并用与 Critic 同口径的 soft-return proxy 评估偏差。

DroQ · Dropout Q-Functions

高 UTD小 ensembleDropout + LayerNorm
问题
REDQ 的大 Q ensemble 计算昂贵。
机制
用较小的 Critic ensemble，给 Q 网络加入 dropout 与 LayerNorm，利用随机子网络形成隐式多样性。
收益
论文目标是同时改善环境样本效率和计算效率。
代价
dropout 训练/评估模式、LayerNorm 位置与高 UTD 强耦合。
不能推出
不能给任意标准 SAC 的 Q 随意加 dropout 就声称得到 DroQ。

论文 · 官方代码

TQC · Truncated Quantile Critics

Distributional RLQuantile regression截断高分位
问题
标量双 Q 取最小只能粗粒度控制过估计，并可能引入低估。
机制
每个 Critic 输出 soft return 分布的多个 quantile；汇总多个 Critic 的 target atoms，排序后丢弃最高的一部分，再用 quantile Huber loss 回归截断后的 target 分布。
创新
把偏差控制从“选哪个均值 Q”细化为“截断回报分布的多少右尾质量”；Actor 使用 learned quantiles 的均值，而不是直接优化某个最高分位。
代价
quantile regression、更多输出与截断超参数；过强截断会低估。
边界
return distribution 主要刻画策略/环境造成的 aleatoric 随机性；它不自动等于参数不确定性或 OOD 置信度。
实验
必须消融每个 Critic 的 quantile 数、Critic 数和每网络截断数，并报告总 atoms 与保留比例。

论文 · PyTorch 实现 · SB3-Contrib 文档

CrossQ · Batch Normalization for Greater Sample Efficiency

BatchNormUTD=1 路线无 Target Network
问题
高 UTD 方法有较高计算成本；off-policy TD 的当前 `(s,a)` 与下一 `(s',a')` 输入分布不同，朴素 BatchNorm 会产生不匹配统计。
机制
删除 target networks，把两批 Critic 输入拼接后做一次前向，使 BN 使用其混合分布的统一 moments；论文完整方案还使用更宽的 Critic。
收益
在论文设置中以 UTD=1 追求样本效率与计算效率。
风险
BN 统计、拼接方式、batch size、Critic 宽度和训练/评估 mode 均是算法组成。
不能推出
CrossQ 的结果不代表普通 SAC 可以直接删除 Target Critic，或单独加 BN 就能复现实验。

DSAC / DSAC-T · Distributional Soft Actor-Critic

回报分布价值估计机器人控制
问题
标量期望 Q 不表达 soft return 的随机分布，价值估计误差可能影响控制。
机制
DSAC 用参数化分布 Critic 近似 $$Z^\pi(s,a)$$；原论文以 Gaussian 的均值表示 Q、标准差表示回报离散程度，并用分布 Bellman 目标学习。DSAC-T（arXiv:2310.05858）后续加入 expected value substitution、twin value distribution learning 与 variance-based critic gradient adjustment 三项 refinement；不能只根据仓库名把 DSAC-v1、DSAC-T 和其他同名 DSAC 混用。
对照
TQC 用 quantile mixture 并截断右尾控制过估计；DSAC 系列的分布参数化、Loss 与偏差修正不同。
代价
输出、分布 Loss 与实现复杂度增加；Gaussian 是近似假设，不保证真实 return 分布为 Gaussian。
边界
分布的方差主要反映 aleatoric return randomness，不自动提供 epistemic/OOD uncertainty；“distributional”也不是多机 distributed training。

DSAC 论文 · DSAC-v1 · DSAC-v2 / DSAC-T

UTD—偏差—计算三角

方法 环境样本利用 主要偏差控制 主要计算策略
标准 SAC 低至中 UTD 双 Q 取最小 2 个在线 Q + 2 个 Target Q
REDQ Critic 高 UTD，Actor 约 1 大 ensemble + target 随机子集最小 用 Critic 算力换环境步数
DroQ 高 UTD dropout 隐式 ensemble 小 ensemble 降成本
CrossQ 低 UTD 路线 BN 统计与结构设计 移除 Target，保持轻量

“样本效率”只统计环境步会掩盖 gradient steps、参数量、能耗和墙钟差异。真实机器人研究必须把这些预算分开报告。

离散动作：不能直接照搬 Gaussian

Discrete SAC

连续重参数化 Actor 改为 categorical policy。对规模可控的离散动作集合，可精确对所有动作求和：

\[L_\pi(s)=\sum_a\pi_\theta(a\mid s) \left[\alpha\log\pi_\theta(a\mid s)-Q(s,a)\right].\]

soft value 也可按动作枚举求精确期望，不需要 tanh 或连续变量 Jacobian。Soft Actor-Critic for Discrete Action Settings 是相应入口。

\[V(s)=\sum_a\pi(a\mid s)\left[\min_i Q_i(s,a)-\alpha\log\pi(a\mid s)\right].\]

Categorical entropy 的范围是 \([0,\log\lvert\mathcal A\rvert]\)，与连续策略可能为负的微分熵不是同一对象；自动温度的 target 必须按离散熵范围重新定义，不能照搬连续动作的 -act_dim。

SD-SAC

Revisiting Discrete Soft Actor-Critic 将其方法命名为 Stable Discrete SAC（SD-SAC），针对离散 SAC 的策略熵骤变与 clipped double-Q 低估，组合 entropy-change penalty、Double Average Q-Learning 和 Q-clip。结论针对离散设置，不能未经实验移植到连续 SAC，也不要与上文 Distributional SAC（DSAC）混写。

更丰富的连续策略族

Mixture policy、normalizing flow 等可提高多模态表达，但必须同时解决可重参数化、精确或可估计 log density、动作边界与数值稳定。它们是研究方向，不是标准 SAC 的无代价替换。

数据制度：在线、混合与纯离线

制度 数据是否继续增长 主要风险 代表方法
标准 SAC 是，当前策略持续交互 replay 分布滞后、Q 偏差 SAC
Prior-data online 固定先验数据存在，在线 Replay 持续增长 两类数据比例、覆盖与奖励一致性 RLPD
Offline RL 否，固定数据集 Actor 选择 OOD 动作、Critic 外推 CQL

RLPD

Efficient Online Reinforcement Learning with Offline Data 不先做纯 offline 预训练，而是从在线训练开始就在每个 batch 中各采 50% 在线 Replay 与 50% 固定先验数据。论文还组合 Critic LayerNorm、sample-efficient ensemble 方法及任务相关的 UTD/更新选择。50/50 是论文的 symmetric sampling 起点，不是无需验证的普遍最优比例；新交互仍用于扩展和纠正覆盖。

CQL

Conservative Q-Learning for Offline Reinforcement Learning 在 Bellman error 外增加保守 Q 正则，降低部分数据外动作的估计。连续控制可使用 SAC 风格 Actor，但核心是保守价值目标。本站的离线强化学习页面提供更完整背景。

模型辅助：MBPO

When to Trust Your Model: Model-Based Policy Optimization 训练动力学 ensemble，从真实 Replay 状态分叉生成短 rollout，再将模型 transition 与真实 transition 混合用于 SAC 类 learner。短 rollout 用来控制长时模型误差累积；模型数据不算新增真实环境样本，模型更新后还需控制 Model Buffer 中旧预测的失效。并非生成数据越多越好。

MBPO 修改的是数据生成层，不是只改某一个 SAC Loss。完整模型路线见MPC 与 MBPO。

公平实验的最低要求

  1. 同时报告真实环境 transition、Critic/Actor 各自更新数、\(\mathrm{UTD}_{\mathrm{updates}}\)、replay sample ratio、参数量/显存、墙钟和硬件能耗；不能假装这些预算能同时完全对齐。
  2. 多随机种子，预先规定聚合方式并报告区间/离散程度，不只展示最佳曲线。
  3. 记录 Q bias proxy、Q disagreement、alpha、entropy、UTD 与吞吐；Q bias proxy 必须注明 raw 还是 soft return、策略和 bootstrap 口径。
  4. REDQ 分别消融 Critic UTD、Actor update ratio、ensemble size、subset size。
  5. DroQ 消融 dropout、LayerNorm、Q 数量和 UTD。
  6. TQC 消融 quantile/atoms、Critic 数和 truncation，并固定总输出预算做补充对照。
  7. CrossQ 消融 batch 拼接、BN、Critic 宽度和 Target Network，而非只比较最终组合。
  8. 视觉方法对齐 encoder、augmentation、frame stack 和环境版本。
  9. 数据方法公开离线/在线比例与数据覆盖。
  10. 不从单个 MuJoCo 任务直接推广到真机安全结论。

分类边界

  • REDQ、DroQ、TQC、CrossQ、Distributional SAC 可视为直接修改 SAC 价值学习或训练机制的家族；SD-SAC 属于离散动作分支。
  • SAC+AE、DrQ 在视觉层扩展基础 learner；DrQ-v2 已更换基础 learner。
  • RLPD 改变数据制度与训练强度；CQL 面向纯离线保守价值学习。
  • MBPO 在 SAC 外增加 learned dynamics 与模型数据。

把这些全部写成“在 SAC 上增加一个模块”会掩盖它们解决的问题与适用条件。

本页重点与创新视角

  • 知识点：UTD 是更新预算，ensemble/subset/truncation 是不同偏差旋钮，distributional critic 表示随机 return 而非天然置信区间。
  • 重点：比较方法前先拆开真实数据、Critic 更新、Actor 更新、网络规模与模型生成数据；只对齐环境步不是公平比较。
  • 创新视角：用“反馈回路位置”分类：REDQ/DroQ/CrossQ 改训练强度与价值稳定，TQC/DSAC 改价值表示，DrQ/SAC+AE 改观测表示，RLPD/CQL 改数据制度，MBPO 改数据生成。
  • 选择原则：诊断证据必须先于算法名称；若基础实现、终止语义或动作坐标尚未验证，换更复杂方法只会增加不可辨识因素。

PROBABILITY PATH · VALID-ELEMENT LOSS · NEGATIVE EULER

固定 LeRobot 实现把归一化动作置于 t=0、标准高斯噪声置于 t=1，训练动作专家预测 ε−A，推理以负步长从噪声端积分回动作端；这套 Flow Matching 数学主要继承自既有路线，SmolVLA 的新增贡献在轻量主干、较窄交错注意力专家与执行系统，而不在重新发明这组方程。

t=0 · A源码时间的归一化动作端。
t=1 · ε源码时间的标准高斯噪声端。
U=ε−A固定配对的常量样本速度。
Beta(1.5,1)训练更偏向源码的噪声侧。
N=10 · Δt=−0.1默认一阶显式 Euler。

条件生成动机与 Table 10 边界

逐元素 L2 单点回归的总体最优解是条件均值；逐元素 L1 的总体最优解是逐维条件中位数，且可能不唯一。它们并不假设现实只有一个正确动作，但一次确定性前向只返回一个代表点，不能单独保存完整的条件动作分布。Flow 生成器通过随机初态产生样本，因而可以表示条件分布；这仍不保证有限数据、容量和求解步数下没有 mode dropping、概率失准或不安全样本。

源码概率路径、速度与 CFM

设归一化动作 A、独立标准高斯噪声 ε。固定源码定义：

\[X_t=t\epsilon+(1-t)A,qquad t\in[0,1].\]

因此 X_0=A、X_1=ε，固定配对的样本速度为：

\[U=\frac{\mathrm dX_t}{\mathrm dt}=\epsilon-A.\]

样本速度不等于边缘条件速度场

训练知道 (A,ε)，可以直接监督 U=ε−A；推理只观察 X_t,t,o。平方损失的总体最优预测是：

\[v^*(x,t,o)=\mathbb E[\epsilon-A\mid X_t=x,t,o].\]

给定 X_t=x 后，噪声一般不再保持无条件零均值，所以不能把速度简化成 −A。固定配对路径是直线且样本速度常量，边缘场却通常依赖 x,t,o；学得 ODE 的生成轨迹不必是直线。

平方风险分解的适用范围

令 Z=(X_t,t,o)、U=ε−A、v*=E[U|Z]，则总体风险分成对边缘场的误差与一个参数无关项。在常规密度、可积性与交换微分/积分条件下，CFM 与直接边缘场匹配具有相同期望参数梯度。它不表示每个有限 mini-batch 梯度逐点相同，也不消除有限容量、非均匀时间加权或优化误差。

两类 padding 的网络与梯度语义

真实动作维 D<32 时，干净动作的补齐坐标为 0，但噪声仍覆盖全部 32 维，因此补齐坐标的网络输入为 tε_pad。它们进入动作投影和专家，只是对应输出在包装层裁掉、没有直接损失。episode 尾部 padding 同样进入网络，action_is_pad 只屏蔽损失，不是注意力 mask。

论文/代码冲突与换元纪律

论文 v1 显示 A^{τ_p}=τ_p A+(1−τ_p)ε，同时给出速度 ε−A；但对同一个 τ_p 直接求导得到 A−ε。这两行在同一时间方向下相差负号。能确定的是插值式、速度符号和积分方向没有全部采用同一约定；本页不替作者决定应修正哪一项。

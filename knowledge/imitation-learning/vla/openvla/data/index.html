70+ / 200 万+论文写作时 OpenX 候选池；不是 OpenVLA 训练集。

RLDS episode/step 与 OpenVLA 字段

RLDS 官方格式把 dataset 组织为 episodes，再把 episode 组织为 steps。step 强制字段是 is_first 与 is_last；observation、action、reward、is_terminal、discount 和额外 metadata 均可选。RLDS 不强制图像字段名、语言指令、机器人本体、动作维数、坐标系、单位或夹爪约定。

schema: openvla.rlds-container-contract.v1
rlds_official:
  hierarchy: dataset-to-episodes-to-steps
  mandatory_step_fields: [is_first, is_last]
  optional_step_fields: [observation, action, reward, is_terminal, discount, extra_metadata]
not_standardized_by_rlds:
  - image-role-names
  - language-instruction
  - action-dimension
  - coordinate-frame
  - units
  - gripper-convention
openvla_required_after-standardization: [observation, action, language_instruction]

逐数据集 transform 后，OpenVLA 重组出 observation.image_primary、observation.timestep、task.language_instruction、float32 action、canonical dataset_name 与 absolute_action_mask。固定训练只加载 primary 逻辑角色，load_depth=false、load_proprio=false、load_language=true、window_size=1、future_action_window_size=0、skip_unlabeled=true，归一化类型是 BOUNDS_Q99。

“primary”是逻辑角色，不是统一物理机位。各数据集原始相机字段由配置映射到 primary；它不能自动翻译成“第三人称正面相机”。

筛选和逐数据集标准化

论文首轮筛选要求至少一路第三人称相机、manipulation 数据和单臂 end-effector control。代码再为不同数据集选择 standardize_fn，执行字段重命名、动作拼接、旋转变换、缺失自由度补零和夹爪变换。统一后的张量形状只是接口合同，不表示原始机器人语义天然一致。

  2. dataset-specific standardized trajectory
  3. normalized trajectory
  4. interleaved frame stream
  5. transformed PyTorch sample
  6. collated training batch

7 维动作、mask 与物理语义缺口

统计量、split 顺序与 leakage 边界

权重如何变成 25 数据源期望概率

固定代码启用 balance_weights=true。w_i 是 mixtures.py 中的人工倍率，N_i 是 fixed statistics 的 transitions，p_i 是 frame-level sample_from_datasets 的数学期望：

p_i = w_i N_i / Σ_j(w_j N_j)。

w_i 不是百分比、质量分数或每条样本重复次数；轨迹数也不是这里的采样基数。有限运行的 batch share 是随机变量，不能由期望表冒充训练日志。

Bridge 清洗、语言过滤和 shuffle

Bridge 有两次不同原因的截断：先删除原始首帧，因为其首动作全零；再用下一状态差分重标 movement，因最后一步没有 next state 而删除末帧。不能把它们合成一句“删除首尾异常帧”。gripper 保留自 relabel 前动作，具体 transform 仍是 dataset-specific。

schema: openvla.bridge-cleaning-contract.v1
dataset_keys: [bridge_oxe, bridge_orig]
step_1: {operation: drop-first-timestep, reason: original-first-action-all-zero}
step_2:
  operation: relabel-movement-from-next-state-difference
  formula: action_move_t=EEF_state_t_plus_1-EEF_state_t
  consequence: drop-last-timestep
  reason: no-next-state-for-final-step
gripper: {source: retained-from-pre-relabel-action, exact-transform: dataset-specific}

skip_unlabeled=true 的 predicate 是轨迹级 reduce_any(language_instruction!="")：只保证全空语言轨迹被拒绝；混合空/非空 step 的轨迹可通过并在 flatten 后留下空语言 step。它不验证语言语义质量，也不去重指令。

schema: openvla.language-filter-contract.v1
configuration: skip_unlabeled=true
granularity: trajectory
predicate: reduce_any(language_instruction!="")
guarantee: [reject-trajectory-when-all-steps-empty]
not_guaranteed: [remove-every-empty-language-step, validate-language-semantic-quality, deduplicate-instructions]
risk: {mixed-empty-and-nonempty-trajectory: empty-step-can-survive-then-flatten}
status: repository-documented-plus-site-derived-risk

TFDS/RLDS 读取层 shuffle 不是全局随机排列。每数据源先 repeat，再做 trajectory transform 与 flatten，sample_from_datasets 按 p_i 进行 frame-level interleave，最后只有有限 shuffle_buffer_size。这些步骤不能证明相邻或同轨迹相关性完全消失，也不能称严格 IID。

接入自有数据至少要固定 canonical key 与版本、primary 物理相机映射、每个展平 step 的语言字段、动作顺序/frame/units/旋转约定/频率、gripper 语义、首末帧/no-op/异常值、standardize 后 train-only statistics、mask、mixture 期望与实测 share 的区别，以及 deployment unnorm_key 的精确绑定。缺少公开物理语义时应显示 unknown/not-encoded，而不是填默认值。

  subgraph N15[GR00T N1.5]

文本回退：两代都先把 224 tile 编成宽1152的视觉特征并进入宽2048的语言侧。N1经pixel shuffle得到64×4608、四段连接器、SmolLM2前12层和共享2048→1536投影；N1.5保留256×1152、使用单层1152→2048连接器、Qwen3前12层、Identity、vlln和四层VL self-attention，再以2048宽条件供DiT逐层读取。动态图块是两代共有能力；图中箭头只表示数据流，不表示单项性能因果。

主干身份、加载路径与语言截断

固定 checkpoint 的 eagle_path 是 NVEagle/eagle_er-qwen3_1_7B-Siglip2_400M_stage1_5_128gpu_er_v7_1mlp_nops。其中 qwen3_1_7B、Siglip2_400M、1mlp、nops 只分别提示语言谱系、视觉谱系、连接器深度与关闭pixel shuffle；EagleBackbone.__init__ 没有把该参数当远程地址，而是从打包的 DEFAULT_EAGLE_PATH 读取配置，再加载checkpoint权重。结构结论来自实际配置和执行分支，不来自文件夹命名。

语言侧固定配置
字段 N1 N1.5
family SmolLM2 / llama Qwen3 / qwen3
hidden 2048 2048
原始 / 执行层 24 / 12 28 / 12
Q / KV heads 32 / 32 16 / 8
intermediate 8192 6144

两代都循环 pop(-1) 到只剩12个decoder block，再取 hidden_states[12]；索引0是embedding输出，因此索引12是第12个block之后。N1删12层，N1.5删16层。词表比约3.085不等于总参数比或多语言能力证明；保留比例也不能用来比较“语义深浅”，Qwen3第12层没有公开最佳层消融。

视觉塔的核心形状在两份打包配置中均为 siglip_vision_model、宽1152、27层、16头、FFN宽4304、patch14、image224。形状相同不证明原始JSON或权重相同，也不能隔离视觉塔单项换代；官方支持的是整个VLM从Eagle2.5出发并面向接地与物理理解调校。

视觉 Token、动态图块与连接器账本

224/14=16，所以单tile先产生16²=256个patch token。N1用ratio0.5做2×2邻域重排，得到64×4608；N1.5 use_pixel_shuffle=false，保留256×1152。保存的 downsample_ratio=0.5 在关闭分支中不参与token计算。N1.5预处理器配置 min_dynamic_tiles=1、max_dynamic_tiles=12、use_thumbnail=true：多主tile时可追加缩略图，单原图最终tile数可能到13。若一个样本所有相机的最终tile总数是 MΣ，视觉token总数是 256MΣ，不是每帧固定256。

两代连接器；LayerNorm仿射和Linear bias均计入
版本 模块 参数
N1 LayerNorm(4608) → Linear(4608,2048) → GELU → Linear(2048,2048) 13,644,800
N1.5 Linear(1152,2048) 2,361,344
差值 N1.5 − N1 −11,283,456

关闭pixel shuffle与单层连接器是发布配置中的共同选择，不是数学必然，也没有独立消融可把系统收益归给某一项。设文本/模板token数为T，则N1与N1.5的VLM序列近似 T+64MΣ 和 T+256MΣ：只有视觉项是4倍；前12层VLM和四层VL适配器的注意力矩阵项近似随各自总序列平方变化，DiT cross项近似随query×KV长度变化。没有整模型FLOPs倍数或实测延迟结论。

VL→DiT 接口、交替块与参数增量

N1用共享 Linear(2048,1536) 先压缩全部VL条件；N1.5保存 project_to_dim=null，所以 eagle_linear=Identity()，条件保持2048。DiT query仍是1536，16层为32头×48维，动作投影宽1024；“条件宽度变成2048”不等于“DiT内部宽度变成2048”。奇偶层交替形成8个cross block和8个self block，只有cross block各自把2048宽K/V投到内部1536。

只计算共享投影与8个cross block的K/V宽度变化
项目 算式 参数差
每个cross block 2×(2048−1536)×1536 +1,572,864
8个cross block 8×1,572,864 +12,582,912
移除N1共享投影 2048×1536+1536 −3,147,264
净接口投影差 12,582,912−3,147,264 +9,435,648

K/V bias大小未随输入宽改变；账本不含 vlln、四层VL self-attention或future embedding。按层读取增加接口容量和投影自由度，但没有单项消融证明它保留了更多有效语义或独立提升性能。

后置 VL 适配器与 Padding Mask 断点

官方Research描述“对进入LLM的视觉和文本token embeddings加LayerNorm”；固定公开路径的一层mlp1只有Linear，文本embedding直接进入LLM，而公开 vlln=LayerNorm(2048) 位于截断LLM输出之后、四层VL self-attention之前。两者不是同一位置，现有证据不能证明它们是同一个层，也不能确定差异来自导出、重构或未发布训练代码。把 vlln 的4096个仿射参数解释为适配冻结特征尺度，只能标为机制假设。

公开动作头中的确定事实
环节 事实 边界
vlln LayerNorm(2048)，在截断LLM之后 与官方输入LN的对应未知
VL adapter 4层纯self-attention；32头×64=2048；dropout0.2 不接收Flow时间，不加独立位置嵌入
主干mask tokenizer左填充；Eagle消费并返回attention mask 主干内部可屏蔽padding
VL-SA forward无mask参数 主干mask未继续使用
DiT 接口接收encoder mask，但block调用传None block也未转发给Attention

静态结论只是 post-VLM 两段注意力未应用这份padding mask，不能未经实验直接定性为性能缺陷。官方称VLM在预训练和微调中冻结；公开默认 tune_llm=false,tune_visual=false。普通非LoRA路径中 vlln、VL-SA和future tokens无独立冻结开关，动作头未整体冻结时仍可训练；LoRA默认rank0，启用后由PEFT重写requires_grad，两套规则不能混用。

Future Token、间接梯度与查询复杂度

N1.5把32个可学习future token插在state与noisy action之间，每个宽1536，embedding表有 32×1536=49,152 个参数。query顺序为 [state, future, action]，总长 S+32+H；只有末H个动作位置经过输出投影和本体解码。动作token有专用学习式position embedding，state/future没有，DiT的额外position embedding也是null，因此future索引不等于已定义的未来时刻。

flowchart LR
  S[State tokens S] --> C[Concat]
  F[32 learned future tokens] --> C
  A[H noisy action tokens] --> C
  C --> Q[DiT queries S+32+H]
  V[VL condition N×2048] -->|8 cross blocks| Q
  Q -->|8 self blocks| Q
  Q --> O[只解码末H个动作位置]

公开forward设置 return_all_hidden_states=false，没有target encoder、projection heads或专用FLARE alignment loss，也不直接解码future位置；但8个self block让future与action交互，动作位置Flow MSE可沿注意力路径间接更新future embedding。所以准确状态是“无公开专用对齐监督，存在动作损失间接梯度”，FLARE语义对齐细节归②B页面。

常用S=1、H=16时，N1 query为17，N1.5为49，长度比约2.88235；只比较序列项，8个self block的注意力矩阵项比约 (49/17)²=8.30796，cross对query长度项约2.88235，且KV长度也因视觉token改变。它们不是整模型FLOPs或延迟比；S不为1时必须使用一般公式。

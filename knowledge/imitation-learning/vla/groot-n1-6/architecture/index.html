GR00T N1.6/① 架构增量
ARCHITECTURE · VERIFIED AGAINST N1.6-RELEASE

N1.6 的架构升级不是单独把 DiT 加深，而是同时调整感知主干、VLM—动作头接口、条件注意力节奏和可训练参数边界。本页按“可直接核实的结构 → 可能的机制含义 → 不能越过的证据边界”展开。

前代内容入口。 N1 的双系统分工、按本体边界层和基础 DiT 见 GR00T N1 · 网络架构与双系统；N1.5 的冻结 VLM 与后置四层 adapter 见 GR00T N1.5 · 架构增量。本页只解释 N1.6 的变化。

一、先分清三种 VLM 表述

证据 公开表述 能得出的结论 不能得出的结论
NVIDIA Research 内部 NVIDIA Cosmos-2B VLM 变体；灵活分辨率、原生宽高比；训练含一般 VL 与具身推理 这是 N1.6 的官方研究口径 不能仅凭名称还原内部预训练数据和完整网络
checkpoint config.json model_name: nvidia/Eagle-Block2A-2B-v2，backbone_embedding_dim: 2048 这是公开权重的加载标识与接口宽度 不能断言公开 Eagle 与内部 Cosmos 描述完全同构
固定源码 EagleBackbone 读取仓库内 Eagle 结构配置，以 AutoModel.from_config 构造骨干；外层 from_pretrained 再加载 checkpoint 参数 可核实运行时的层截断、冻结、输出与 mask 不能用源码填补未公开的基础预训练语料
模型卡文字 仍出现 SigLIP2/T5 说明 说明发布元数据存在历史/口径差异 不能覆盖固定源码实际加载路径

最稳妥的表述是：N1.6 Research 将骨干描述为 Cosmos 系 2B VLM 变体，公开 checkpoint 与代码通过 Eagle-Block2A-2B-v2 暴露其加载接口。页面不把两个名字拼成一个未经官方定义的新模型名。

二、EagleBackbone 实际做了什么

固定源码的关键顺序如下：

  1. 读取随仓库提供的 Eagle 结构配置并构造视觉语言模型；加载发布 checkpoint 时，由外层 Hugging Face from_pretrained 填入保存的参数；
  2. 当语言模型层数大于 select_layer 时从尾部逐层 pop，发布配置选择 16；
  3. 根据 tune_llm、tune_visual 和 tune_top_llm_layers 设置梯度；
  4. 前向时只传 input_ids、attention_mask、pixel_values；
  5. 取最后保留层的 hidden state；
  6. 用 image token id 生成 image_mask，与 attention mask 一起交给动作头。
images + text
  → 公开运行时：EagleBackbone
  → hidden_states[-1] : [B, S_vl, 2048]
  → image_mask        : [B, S_vl]
  → attention_mask    : [B, S_vl]

2.1 灵活分辨率的意义

NVIDIA Research 明确写明：该 VLM 支持灵活分辨率，并能以原生宽高比、无需 padding 地编码图像。这项能力避免了为了统一成方形输入而进行几何拉伸或补边。不过，“VLM 可无 padding 编码”不等于整条公开数据管线在所有 batch 中都没有任何对齐开销，也不能单凭这一点推出视觉 token 数或端到端计算量一定下降；这些还取决于图像处理器、batch 组织和实际分辨率。官方没有发布独立消融，因此它是已确认的输入能力，而不是已单独证明的性能来源。

2.2 select_layer=16 不等于“取完整模型第 16 层后还继续算”

源码直接删除更高层以节省计算，随后使用最后保留层输出。因此动作头读取的是截断骨干的末层特征。所谓“解冻顶部四层”在这一实现中指保留下来的语言模型顶端四层，不能脱离截断逻辑按原完整模型层号口语化推断。

三、删除 N1.5 adapter，改为预训练时解冻 VLM 顶部四层

N1.5 在 VLM 后放置四层视觉语言自注意力 adapter，使冻结主干的 token 在进入 DiT 前仍有可训练的重组空间。N1.6 Research 明确删除这四层，并在基础预训练中解冻 VLM 顶部四层。对公开动作损失路径而言，只要这四层保持 requires_grad=true，动作头的损失就可以经 cross-attention 条件特征反向传播到它们；但这只能说明梯度路径存在，不能据此还原 NVIDIA 内部基础预训练的全部损失项。

N1.5：骨干外适配

冻结 VLM，把可塑性放在 VLM 输出后的四层 adapter。优点是主干稳定；代价是具身任务适配发生在骨干之外。

N1.6：骨干内适配

移除 adapter，在基础预训练中更新 VLM 顶层。公开动作路径允许动作损失反传到这些层；它是否单独带来性能提升，官方没有给出消融。

三个开关有先后关系。 公共单节点微调入口默认写入 tune_llm=false、tune_visual=false；EagleBackbone 会先冻结整个语言模型和视觉分支，再依据 tune_top_llm_layers 重新打开截断语言模型顶部若干层。发布配置保存的是 tune_top_llm_layers=4，因此在该配置未被覆盖时，顶部四层仍有梯度。与此同时，训练前向会因 tune_llm=false 把整个 language model 置为 eval 模式：这会关闭其中的 dropout 等训练态行为，却不会自动把已重新启用的四层改回 requires_grad=false。所以应同时检查合并后的配置、模块 train/eval 状态与参数 requires_grad，不能把 tune_llm=false 简写成“语言模型完全不更新”。

四、32 层 AlternateVLDiT 的真实注意力节奏

发布配置：32 层、32 头、每头 48 维，因此内部注意力宽度为

\[d_{\text{inner}}=32\times48=1536.\]

它与 state/action embedding 的 1536 维一致。32 个 block 并不是每个都同时做 self-attention 和 cross-attention，而是严格交替：

flowchart LR
  B0[Block 0<br/>Cross: non-image/text] --> B1[Block 1<br/>Self: state + action]
  B1 --> B2[Block 2<br/>Cross: image]
  B2 --> B3[Block 3<br/>Self]
  B3 --> B4[Block 4<br/>Cross: non-image/text]
  B4 --> D[... 重复至 Block 31]

当 attend_text_every_n_blocks=2：

  • 奇数索引 block：state/action token 内部 self-attention；
  • 偶数索引 block：cross-attention；
  • 偶数 block 中，索引可被 4 整除时读取 non-image token，其余读取 image token。

所以 32 层里共有 16 个 self-attention block、8 个 non-image cross block、8 个 image cross block。这里的 “non-image” 通常含语言与其它非图像位置，但准确组成仍由 collator 的 token 序列决定。

4.1 为什么分开图像与非图像条件

从机制上看，分流让动作 token 在不同深度分别读取非图像条件与图像条件，使信息融合节奏更明确，也避免同一 cross block 同时竞争两类条件。需要注意：源码仍把完整的 encoder_hidden_states 传入 attention，只用布尔 mask 屏蔽当前不应读取的位置；除非底层 attention 内核进一步做稀疏化或压缩，否则这并不等价于缩短 key/value 序列，也不能直接宣称减少了计算量。所谓“降低条件竞争”同样只是代码结构启发的机制假设，不是官方消融结论。

4.2 AdaLN 如何注入时间

离散时间桶先经 TimestepEncoder 得到 1536 维条件向量 \(e_t\)。每个 block 的 AdaLayerNorm 只产生 scale 和 shift：

\[\widetilde h=\operatorname{LN}(h)\odot\bigl(1+s(e_t)\bigr)+b(e_t).\]

随后 self-attention 或 cross-attention 使用 \(\widetilde h\) 作为 query 输入，并与原输入做普通残差相加：

\[h'=h+\operatorname{Attn}(\widetilde h,\,c),\qquad h''=h'+\operatorname{FFN}(\operatorname{LN}(h')).\]

这里的 \(c\) 在 self-attention block 中为空，在 cross-attention block 中是经过图像或非图像 mask 筛选的 VL 条件。源码的 FFN 前使用普通 LayerNorm，没有时间 gate；AdaLayerNorm 也没有生成 gate。32 个 block 之后，输出头还会用同一个时间条件再做一次 scale/shift，再投影到 1024 维。

时间还通过另一条独立路径进入 action encoder：离散时间桶被编码为 1536 维正余弦向量，与带噪动作的 1536 维表示拼接。因而时间既影响动作 token 的输入表示，也影响每个 DiT block 的 attention 前归一化，但不能概括为“调节所有归一化和残差强度”。

五、按本体边界层：专属接口，共享 DiT

模块 输入 → 输出（checkpoint） 是否按本体选择参数 作用
state encoder 最多 128 → 1024 → 1536 是 将不同机器人状态映射到共享 token 空间
action encoder W1/W2/W3 动作 128 → 1536；时间 → 1536；拼接 3072 → 1536 → 1536 是 编码带噪动作与离散时间桶
AlternateVLDiT T_s+50 个 1536 维 token 否，共享 学习跨本体的条件速度场
action decoder 1024 → 1024 → 128 是 把共享隐状态还原到各本体动作槽位
action mask [B,50,128] 随样本 去除 padding 与无效动作元素

CategorySpecificLinear 保存形如 [num_embodiments,input_dim,output_dim] 的权重张量，再用 embodiment id 按 batch 选择对应矩阵。它不是在 token 中加入一个软提示，而是直接切换输入输出边界的参数。

六、完整张量流水

设 VL token 长度为 (S)，状态历史长度为 (T_s)，checkpoint 动作 horizon 为 (H=50)：

  1. VLM：[B,S,2048]。
  2. state encoder：[B,T_s,128] → [B,T_s,1536]。
  3. action encoder：带噪动作经 \(W_1\) 得到 [B,50,1536]，与广播到 50 步的 1536 维时间编码拼接，再经 \(W_2,W_3\) 回到 [B,50,1536]。
  4. 拼接 state/action：[B,T_s+50,1536]。
  5. 32 层 DiT 输出投影：[B,T_s+50,1024]。
  6. action decoder：[B,T_s+50,1024] → [B,T_s+50,128]。
  7. 只切最后 50 个 token，与动作速度目标比较。

最大宽度 128 只是一致的容器维度。实际机器人关节或末端动作可以更短，剩余元素由 mask 屏蔽；因此不能把 128 解释成“机器人有 128 个可控自由度”。

七、创新点与限制

  • 可直接确认的增量：Research 描述的 Cosmos 系骨干与原生宽高比能力、32 层动作头、删除 adapter、基础预训练解冻顶部四层，以及公开代码中的图像/非图像 mask 分流。
  • 必须注明配置层级：发布 checkpoint 与公共微调入口使用相对动作；但源码 Gr00tN1d6Config 类的声明默认值是 use_relative_action=false。因此只能说“发布模型采用相对动作”，不能无条件说“N1.6 源码默认始终采用相对动作”。
  • 合理但未消融的机制解释：把适配移入 VLM 顶层可能使感知特征更贴近动作任务；加深 DiT 增加动作条件建模容量；图文分流可能降低两类条件在同层竞争。
  • 不能宣称的结论：任一单项一定带来官方图中的全部提升；公开 Eagle 标识完整等价内部 Cosmos 模型；所有微调都更新顶部四层。
  • 实现层面的特殊状态：当 tune_llm=false 但 tune_top_llm_layers>0 时，顶部层可以保持梯度，同时整个 language model 处于 eval 模式。这一组合应在复现实验中明确记录。

如何读实验结果

页面使用两条证据车道。Published evidence 忠实登记 paper v3 已公开的字段，状态为 historical-reported 或 historical-partial；New evaluation 只有在 Page 62 的 artifact、binding、controller、safety、latency 与 protocol hash 全部齐全时才可标 protocol-complete。两条车道不混入同一排名表。

schema: openvla.experiment-evidence-state.v1
states:
  historical-reported: {result-source: paper-v3, protocol-complete-under-current-contract: false}
  historical-partial: {result-source: paper-v3, missing-fields: explicit}
  protocol-complete: {deployment-handoff: verified, result-artifacts: hashed}
  observation-only: {mechanism-claim: false}
automatic_promotion_to_reproduced: false
automatic_promotion_to_safe: false

每张结果卡必须同时给 experiment ID、checkpoint status、platform、task/count、ID/OOD、controller、metric、trial/seed、uncertainty、protocol completeness、supported claim 与 forbidden inference。历史 success rate 不是 safety success，误差条不是显著性检验。

通用双本体评测

OpenVLA、RT-1-X、RT-2-X 与 Octo 在相同任务和相同初始机器人/物体状态的 A/B 设置中比较。OpenVLA 直接使用通用预训练 checkpoint，不做目标任务微调：WidowX 为 17 tasks × 10 trials = 170；Google Robot 为 12 × 5 = 60；合计 29 tasks、230 rollouts/method。

method params openness 训练背景
RT-1-X 35M prior policy OpenX 子集、从零训练策略
Octo 93M open-source OpenX 子集、从零训练策略
RT-2-X 55B closed-source internet-pretrained VLM + robot
OpenVLA 7B released Prismatic + OpenX

泛化轴分别是 Visual（背景/干扰物/外观）、Motion（位置/朝向）、Physical（尺寸/形状）、Semantic（目标/指令/互联网概念）与 Language grounding（按 prompt 从多物体选择目标）。参数量不是受控变量，不能把差异全部归因于模型大小。

29 任务综合复核

组合时必须按 rollout/score 分母加权，而不是简单平均两个平台百分比：

OpenVLA = (120 + 51) / 230 = 74.35%
RT-2-X = (86 + 47) / 230 = 57.83%
absolute difference = 38 / 230 = 16.52 percentage points ≈ 16.5 pp

Bridge 的 score 含 0.5 partial，所以这里称 successes-equivalent。

五个对照分别是 Diffusion Policy scratch、matched DP、OpenX-pretrained Octo、无 OpenX robot pretraining 的 OpenVLA scratch，以及 OpenX-pretrained OpenVLA。原版 DP 使用 history、image、proprioception、action chunk 与 absolute Cartesian action；matched DP 改为单图、无 proprio/history、单步 relative action，只隔离部分接口差异。

LIBERO 设置与结果

Spatial、Object、Goal、Long/LIBERO-10 各含 10 tasks、每项原始 50 demonstrations。数据处理固定五步：动作重放重新渲染 256×256（不是简单放大 128×128）、过滤 translation/rotation 近零且 gripper 不变的全部 no-op、训练/测试图像旋转 180°、重放并删除失败轨迹、所有方法只用 static third-person image 而不用 wrist camera。

失败分类与未证明事项

论文 task success 没有充分报告 collision、near-miss、workspace violation、emergency stop、operator intervention、stale action、invalid token、timeout、latency tail、recovery time、unsafe force 或 repeated no-op。因此成功率不能当安全成功率。

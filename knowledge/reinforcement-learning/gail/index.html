前十四页的算法都默认奖励函数 \(r(s,a)\) 是给定的。真实任务里这个前提经常不成立：自动驾驶里「开得好」没有公式，机械臂叠衣服里「叠得整齐」也没有公式。手工设计的奖励要么写不出来，要么被策略钻空子。模仿学习换一条路：不给奖励，只给若干条专家轨迹，让智能体从数据里学出行为。GAIL 是这条路上把强化学习工具用得最彻底的一种——它不直接拟合动作，而是训练一个判别器去区分专家与策略，再把判别器的输出当作奖励交给一个标准的策略优化算法。

本页重点。必须精读三节：「占用度量：行为克隆匹配错了分布」，它解释了 GAIL 与行为克隆在目标函数层面的根本差别；「判别器如何充当奖励函数」，这是 GAIL 的全部算法内核；「训练不稳定的来源」，它决定了实现时判别器与策略的更新节奏怎么配。可以快速略过的部分：行为克隆复合误差的回顾（模仿学习总览已完整展开）、逆强化学习的双层优化（只需记住结论）、代码实现中 PPO 专家训练与绘图两段（均已压缩成要点）。本页符号沿用主线约定，另加 \(\phi\) 表示判别器参数、\(\rho\) 表示占用度量、\(\tau\) 表示轨迹。

本章要解决什么问题

强化学习的整套框架建立在一个假设上：环境会返回一个标量奖励 \(r(s,a)\)，而这个奖励确实刻画了我们想要的行为。前十四页从未质疑过这个假设，因为 CartPole 的「每存活一步加一分」与 Pendulum 的「角度偏差的负平方」确实就是任务本身。真实任务里这个假设经常不成立。

  • 奖励写不出来。「把杯子平稳地放到桌子中央」涉及位置、姿态、速度、接触力多个量，各项之间的权重没有客观依据，只能反复手调。
  • 奖励写得出来但会被钻空子。奖励塑形（reward shaping）加进去的中间项经常被策略以设计者没预料的方式最大化：给「靠近目标」加分，策略学会在目标附近反复横跳刷分而不去抓取。这类现象统称奖励作弊（reward hacking）。
  • 稀疏奖励下探索不可行。只在任务完成时给一分，随机策略几乎永远拿不到这一分，梯度全程为零。这个问题在目标导向强化学习一页另有处理办法。
  • 但演示是容易得到的。人来遥操作机械臂做十次、开车录十小时数据，都比写一个正确的奖励函数容易得多。

于是问题被改写成：给定若干条专家轨迹 \(\{\tau_1, \dots, \tau_N\}\)，其中每条 \(\tau_i = (s_0, a_0, s_1, a_1, \dots)\) 只含状态与动作、不含奖励，如何学出一个策略 \(\pi_\theta\)，使它的行为与专家一致。 这就是模仿学习（imitation learning，又称学徒学习 apprenticeship learning）。

与模仿学习总览一页的分工先说清楚。那一页站在机器人学习的视角，主线是行为克隆的分布漂移与复合误差，以及 DAgger、HG-DAgger、动作分块这些减小单步误差或减少决策次数的工程手段，最后接到 VLA 大模型。本页站在强化学习的视角，补的是另一条路线：不去改进监督学习，而是把模仿问题翻译成一个强化学习问题——用判别器造一个奖励，然后照常跑 PPO。两页在「行为克隆为什么不够」这一点上共用同一套分析，本页不重复展开，只做一段回顾。

本页要建立的核心认识是：行为克隆与 GAIL 的差别不在网络结构或训练技巧，而在它们匹配的是两个不同的分布。行为克隆匹配的是条件分布 \(\pi(a \mid s)\)，而且只在专家访问过的状态上匹配；GAIL 匹配的是状态-动作对的联合分布，也就是占用度量 \(\rho^{\pi}(s,a)\)。占用度量相同意味着两个策略在正占用状态上行为相同；对永远不会访问的零占用状态，策略仍可任意不同。

形式化定义：三类模仿学习与占用度量

问题设定。环境是一个去掉奖励的 MDP，记作 \(\mathcal{M} \setminus r = \langle \mathcal{S}, \mathcal{A}, P, \gamma \rangle\)。给定专家策略 \(\pi_E\) 采样出的数据集

\[\mathcal{D}_E = \{ (s_i, a_i) \}_{i=1}^{M}, \qquad (s_i, a_i) \sim \rho^{\pi_E}\]

目标是求 \(\pi_\theta\) 使其行为与 \(\pi_E\) 一致。注意 \(\mathcal{D}_E\) 里没有 \(r\)，这是与前十四页所有算法的唯一形式差别，却足以让整套值函数机器失去输入。

占用度量。沿用初探强化学习一页给出的定义，策略 \(\pi\) 的占用度量是状态-动作对上的归一化折扣访问频率：

\[\rho^{\pi}(s, a) = (1 - \gamma) \sum_{t=0}^{\infty} \gamma^{t}\, P\big(s_t = s,\ a_t = a \mid \pi\big)\]

它把「策略」这个函数对象翻译成「状态-动作空间上的一个概率分布」。相应地定义状态占用度量 \(\rho^{\pi}(s) = \sum_a \rho^{\pi}(s,a)\)，于是有分解

\[\rho^{\pi}(s, a) = \rho^{\pi}(s)\, \pi(a \mid s)\]

这个分解是本页后面所有论证的支点：占用度量是「访问哪些状态」与「在该状态下如何行动」两者的乘积，而行为克隆只管第二个因子。

关键性质（严格证明见马尔可夫决策过程一页）：合法占用度量能在其正占用支持集上反解策略：

\[\rho^{\pi_1}=\rho^{\pi_2}=\rho \quad\Longrightarrow\quad \pi_1(a\mid s)=\pi_2(a\mid s)=\frac{\rho(s,a)}{\sum_{a'}\rho(s,a')}, \quad \rho(s)>0.\]

当 \(\rho(s)=0\) 时分母为零，占用度量不能约束该状态上的动作分布。因此，文献中的“一一对应”应理解为：把只在永不访问状态上不同的策略视为行为等价，或预先规定这些状态上的策略取值。在固定初始分布、动力学与折扣因子下，占用度量相同足以保证可访问行为及任意有界状态—动作成本的期望相同，但不等于两个参数化策略在全状态空间逐点相等。

三类模仿学习的定位。

路线 学什么 匹配的对象 需要与环境交互 主要弱点
行为克隆 直接监督拟合状态到动作的映射 条件分布，且只在专家状态上 不需要 分布漂移导致复合误差二次增长
逆强化学习 先反推奖励函数，再用它做 RL 通过奖励间接匹配 需要，且很多 双层优化，内层每轮要解一次 RL
生成对抗模仿学习 用判别器直接给出奖励信号 占用度量（联合分布） 需要 对抗训练不稳定，判别器易过强

行为克隆的回顾（从简）。行为克隆把模仿当成监督学习，最小化

\[\theta^{*} = \arg\min_{\theta}\ \mathbb{E}_{(s,a)\sim \mathcal{D}_E}\big[ \ell\big(\pi_\theta(s),\ a\big) \big]\]

离散动作用交叉熵、连续动作用均方误差。它的问题是训练分布与测试分布不一致：训练时状态来自 \(\rho^{\pi_E}\)，测试时状态来自 \(\rho^{\pi_\theta}\)。单步误差率 \(\epsilon\) 在 \(T\) 步回合上累积出 \(O(\epsilon T^2)\) 量级的回报损失，即复合误差（compounding error）。这一段的完整推导、二次增长的来源、以及在真机上的具体表现，见模仿学习总览的「分布漂移的机理与复合误差的定量分析」一节，本页不重复。

逆强化学习的定位（只给结论）。IRL 假设专家在某个未知奖励 \(r\) 下是最优的，于是先找一个 \(r\) 使专家的回报显著高于其他策略，再用这个 \(r\) 跑强化学习。形式上是一个双层优化

\[\max_{r}\ \Big( \mathbb{E}_{\rho^{\pi_E}}[r(s,a)] \ -\ \max_{\pi}\ \mathbb{E}_{\rho^{\pi}}[r(s,a)] \Big)\]

内层的 \(\max_\pi\) 本身就是一整个强化学习问题，外层每更新一次奖励就要重解一次，计算代价极高。另一个结构性困难是奖励的不唯一性：常数平移、正数缩放、以及任意势函数塑形都不改变最优策略，因此仅凭专家数据无法定出唯一的 \(r\)。GAIL 的贡献之一正是说明：如果最终只关心策略而不关心奖励本身，那么这个双层优化可以被规约成一个单层的极小极大问题，中间那个显式的奖励函数根本不必求出来。

读图要点：行为克隆的监督目标不包含学习者访问分布；标准 GAIL 会在策略自己访问的状态—动作上重新计算判别器奖励。后者提供在线纠偏通路，但若判别器饱和，奖励也可能接近常数，不能概括为“偏得越远信号一定越强”。

核心一：占用度量——行为克隆匹配错了分布

这一节回答一个问题：既然行为克隆已经在专家数据上把 \(\pi_\theta(a\mid s)\) 拟合得很好了，为什么它学出来的行为还是会偏。答案不在优化不充分，而在目标函数本身就不是我们想要的那个。

两个目标在数学上不等价

把两种方法的目标写在一起对比。行为克隆最小化的是在专家状态分布下的条件分布差异：

\[\min_{\theta}\ \mathbb{E}_{s \sim \rho^{\pi_E}(s)}\Big[ D_{\mathrm{KL}}\big( \pi_E(\cdot \mid s)\ \big\|\ \pi_\theta(\cdot \mid s) \big) \Big]\]

这里期望的下标是 \(\rho^{\pi_E}(s)\)，即专家自己走出来的状态。GAIL 要最小化的则是两个联合分布之间的差异：

\[\min_{\theta}\ \psi\big( \rho^{\pi_\theta},\ \rho^{\pi_E} \big)\]

其中 \(\psi\) 是某种分布散度。用上一节的分解 \(\rho^{\pi}(s,a) = \rho^{\pi}(s)\pi(a\mid s)\) 展开，两者的差别就一目了然：行为克隆只约束了第二个因子 \(\pi(a\mid s)\)，而且只在第一个因子取 \(\rho^{\pi_E}(s)\) 的那些状态上约束；GAIL 同时约束两个因子。 状态访问分布 \(\rho^{\pi_\theta}(s)\) 在行为克隆的目标函数里根本没有出现。

更多专家数据和更合适的模型可以扩大覆盖、降低监督误差；在理想可实现且误差趋零时，行为克隆也可以复现专家。结构性差别在于它没有显式使用学习者自己的访问分布，因此有限数据和非零误差下仍有以下风险：

  • 专家没访问过的状态上完全没有约束。目标函数里那些状态的权重是零，网络在那里的输出由泛化能力决定，本质上是外推。
  • 误差有自我放大的通路。策略在某个状态输出了略微偏离的动作，环境把它带到一个略微陌生的状态；在那个状态上误差更大，于是下一步偏得更远。行为克隆的训练过程完全看不到这条通路，因为训练数据里根本没有这些状态。
  • 经典最坏情形会复合放大。在有限时域、每步分类错误率与有界成本等假设下，性能差距上界可出现 \(O(T^2\epsilon)\) 标度；这不是所有任务中“回报必然与误差二次相关”的等式。详见模仿学习总览。

占用度量匹配确定了哪些行为

占用度量匹配把“复现专家的可访问行为”换成了“让两个分布相同”。如果做到 \(\rho^{\pi_\theta}=\rho^{\pi_E}\)，那么按定义

\[\pi_\theta(a \mid s) = \frac{\rho^{\pi_\theta}(s,a)}{\sum_{a'}\rho^{\pi_\theta}(s,a')} = \frac{\rho^{\pi_E}(s,a)}{\sum_{a'}\rho^{\pi_E}(s,a')} = \pi_E(a \mid s)\]

这在所有 \(\rho^{\pi_E}(s)>0\) 的状态上成立；零占用状态不受约束。反过来，仅仅在有限专家样本覆盖的状态上拟合条件动作，一般推不出占用度量接近，因为动作误差会改变后续状态分布。

占用度量匹配目标中的 \(\rho^{\pi_\theta}\) 依赖当前策略。原始 on-policy GAIL 因此反复与环境交互并采集当前策略轨迹；后续离策略变体可复用数据，但必须处理旧策略分布和变化中的判别器奖励。行为克隆则不需要这种策略侧采样。

匹配分布需要一个散度，而散度需要样本

选定 \(\psi\) 为 Jensen-Shannon 散度，目标写成

\[\min_{\theta}\ D_{\mathrm{JS}}\big( \rho^{\pi_\theta}\ \|\ \rho^{\pi_E} \big)\]

问题是这个散度算不出来：两个分布都只有样本，没有密度函数。\(\rho^{\pi_E}\) 只有专家数据集里的有限个样本点，\(\rho^{\pi_\theta}\) 只能靠当前策略去环境里跑出来。任何需要显式密度的散度计算方式在这里都用不了。

出路是把散度的估计交给一个判别器。这正是 GAN 的思路，也是下一节的全部内容：训练一个二分类器去区分两个分布的样本，分类器的最优损失值本身就是这两个分布的 JS 散度（相差一个常数）。于是「最小化散度」变成了「让分类器分不出来」，而后者是可以用样本梯度下降去做的。

一句话总结本节：行为克隆问的是「专家在这个状态会做什么」，GAIL 问的是「当前策略产生的状态—动作分布能否与专家区分」。前者的监督信号只存在于专家数据覆盖处；后者会评价策略自己访问的样本，但信号强弱取决于判别器校准，饱和时也可能退化。理想占用相等只保证正占用支持集上的行为一致。

核心二：判别器如何充当奖励函数

上一节把模仿问题化归成了「让两个只有样本的分布尽量接近」。这一节给出 GAIL 的具体做法：训练一个二分类器来估计这个差距，再把分类器的输出反过来当成奖励交给策略。

判别器的定义与它的损失

判别器是一个参数为 \(\phi\) 的网络

\[D_\phi: \mathcal{S} \times \mathcal{A} \to (0, 1)\]

输入一个状态-动作对，输出一个介于 0 与 1 之间的标量。约定的语义是：输出越接近 1 表示越像策略产生的数据，越接近 0 表示越像专家数据。（不少实现取相反的约定，两种都可以，但奖励的符号要跟着改，实现时必须与代码里的标签保持一致，这是最常见的符号错误来源。）

判别器做的是标准二分类，专家样本标签为 0、策略样本标签为 1，损失是二元交叉熵：

\[\mathcal{L}(\phi) = -\,\mathbb{E}_{(s,a)\sim\rho^{\pi_\theta}}\big[ \log D_\phi(s,a) \big] \;-\; \mathbb{E}_{(s,a)\sim\rho^{\pi_E}}\big[ \log\big(1 - D_\phi(s,a)\big) \big]\]

判别器最小化 \(\mathcal{L}(\phi)\)，也就是尽力把两类样本分开。两个期望都用小批量样本估计：第一项用当前策略刚采到的一批转移，第二项用专家数据集里随机抽的一批。

最优判别器与 JS 散度

固定策略，对 \(D_\phi\) 逐点求最优。把两个期望写成对 \((s,a)\) 的积分，被积函数为

\[-\rho^{\pi_\theta}(s,a) \log D(s,a) - \rho^{\pi_E}(s,a) \log\big(1 - D(s,a)\big)\]

对 \(D\) 求导并令其为零。记 \(p = \rho^{\pi_\theta}(s,a)\)、\(q = \rho^{\pi_E}(s,a)\)，则

\[-\frac{p}{D} + \frac{q}{1-D} = 0 \quad \Longrightarrow \quad D^{*}(s,a) = \frac{\rho^{\pi_\theta}(s,a)}{\rho^{\pi_\theta}(s,a) + \rho^{\pi_E}(s,a)}\]

这个式子值得停下来看一眼，它说明最优判别器的输出就是两个占用度量的相对密度比。把 \(D^{*}\) 代回损失，整理后得到

\[\mathcal{L}(\phi^{*}) = 2\log 2 \;-\; 2\, D_{\mathrm{JS}}\big( \rho^{\pi_\theta} \,\|\, \rho^{\pi_E} \big)\]

于是：判别器达到最优时，它的损失值（相差一个常数与系数）就是我们想最小化的 JS 散度的相反数。 策略要最小化 JS 散度，等价于要最大化判别器在最优点处的损失，也就是让判别器分不出来。这就把一个无法直接计算的散度，变成了一个可以用样本训练的分类器。

两个极端情形可以用来校验直觉。两个分布完全重合时 \(D^{*} \equiv 1/2\)，判别器只能瞎猜，损失取到最大值 \(2\log 2\)，JS 散度为零；两个分布完全不重叠时判别器可以做到零损失，JS 散度取到最大值 \(\log 2\)。

把判别器变成奖励

现在关键的一步。策略侧要最大化判别器的损失，也就是要让 \(-\log D_\phi(s,a)\) 在自己的占用度量下尽量大。把这一项直接当成奖励：

\[r_\phi(s, a) \;=\; -\log D_\phi(s, a)\]

于是策略的目标写成一个标准的强化学习目标：

\[\max_{\theta}\ \mathbb{E}_{(s,a)\sim\rho^{\pi_\theta}}\big[ -\log D_\phi(s,a) \big]\]

这个奖励的行为完全符合直觉。判别器认为某个 \((s,a)\) 很像专家时 \(D_\phi\) 接近 0，\(-\log D_\phi\) 是一个很大的正数，策略被鼓励多做这类动作；判别器一眼看穿某个 \((s,a)\) 是策略瞎走的时 \(D_\phi\) 接近 1，\(-\log D_\phi\) 接近 0，策略在这里得不到奖励。注意这个奖励恒为正（因为 \(D_\phi \in (0,1)\)），这一点在实现上有一个不易察觉的后果：在可以提前终止的环境里，恒正奖励会诱导策略「尽量活得久」，这本身可能是也可能不是我们想要的偏好，第七节会再讨论。

拿到 \(r_\phi\) 之后，策略侧就是一个完全标准的强化学习问题：把 \(r_\phi(s,a)\) 填进采样到的转移里，交给 PPO（或 TRPO、SAC）照常更新。前十四页的所有工具在这里原样可用，包括优势估计、重要性采样比、裁剪目标。GAIL 没有发明新的策略优化算法，它只是把奖励换掉了。

极小极大博弈

把两侧写在一起。判别器最小化分类损失、策略最大化 \(-\log D_\phi\)，合成一个极小极大问题：

\[\min_{\theta}\ \max_{\phi}\ \ \mathbb{E}_{\rho^{\pi_\theta}}\big[ \log D_\phi(s,a) \big] \;+\; \mathbb{E}_{\rho^{\pi_E}}\big[ \log\big(1 - D_\phi(s,a)\big) \big] \;-\; \lambda H(\pi_\theta)\]

最后一项 \(H(\pi_\theta)\) 是折扣因果熵，\(\lambda\geq0\) 是其系数；它来自最大因果熵 IRL，并在占用匹配与随机性之间形成显式权衡。它与 SAC 都使用熵正则，但目标、策略更新和温度机制并不相同。本文最小代码没有加入策略熵 bonus，相当于取 \(\lambda=0\)；不要把它与 GAE 参数 LMBDA 混淆。

在无限数据、模型类足够表达、双方优化到全局鞍点且 \(\lambda=0\) 的理想条件下，占用度量相等时最优判别器为 \(D^*\equiv1/2\)，策略在专家正占用支持集上行为一致。有限样本、函数逼近、未收敛或 \(\lambda>0\) 时，这不是训练保证。

核心三：训练不稳定的来源

GAIL 在实现上比 PPO 难调，原因不在代码复杂度，而在它同时叠加了三种非平稳性。这一节把它们拆开说清楚，因为几乎所有调参决策都指向这里。

来源一：判别器过强导致奖励饱和

这是最主要、也最常遇到的失败模式。训练初期策略几乎是随机的，它产生的状态-动作对与专家数据差别巨大，判别器只需要几步更新就能把两类分得非常开——对策略样本输出接近 1，对专家样本输出接近 0。此时策略拿到的奖励是

\[r_\phi(s,a) = -\log D_\phi(s,a) \approx -\log 1 = 0\]

所有策略样本的奖励都接近 0，而且彼此几乎没有差别。 强化学习需要的是奖励的相对差异：优势 \(A(s,a)\) 衡量的是某个动作比平均好多少，如果一批样本的奖励全是接近 0 的常数，优势就全是噪声，策略梯度也就是噪声。策略学不到任何东西，而它学不到东西又意味着它下一轮产生的数据还是那么容易分辨，判别器继续赢。这是一个自锁的死循环。

对本页使用的策略梯度而言，直接问题是策略样本的奖励均值和方差趋近于零，优势信号退化；策略不会接收 \(-\log D_\phi\) 对动作或判别器输入的反向传播梯度。判别器饱和与 GAN 的梯度饱和有相似直觉，但 GAIL 还经过轨迹采样与信用分配，不能说成完全相同的梯度机制。

缓解办法：

  • 降低判别器的更新频率或学习率。最常用的一条，让判别器故意学得慢一些、弱一些，始终保持在「能分开但分不干净」的状态。
  • 给判别器加正则。权重衰减、梯度惩罚、谱归一化都能限制判别器的表达能力。
  • 标签平滑。把专家标签从 0 改成一个小正数（或把策略标签从 1 改成略小于 1 的值），直接阻止输出饱和到端点。
  • 改用 \(\log(1 - D_\phi)\) 形式的奖励或对奖励做限幅。改变奖励在饱和区的形状，让梯度不至于完全消失。
  • 减小判别器网络的容量。低维任务上判别器不需要很宽的网络，容量过大只会让它更早取得压倒性优势。

来源二：策略侧面对的是一个持续变化的奖励函数

前十四页的所有算法都假设奖励函数固定。GAIL 里 \(r_\phi\) 随 \(\phi\) 一起变，意味着策略正在优化一个每轮都在改的目标。后果有两层：

  • 值函数估计持续过时。PPO 的价值网络拟合的是当前奖励下的回报，判别器一更新，之前拟合的目标就作废了。表现是价值损失长期居高不下、优势估计噪声偏大。
  • 策略可能来回震荡。判别器发现策略在某个区域产生的样本太多，就把那里的奖励压低，策略于是跑去别的区域；判别器再把新区域压低，策略又跑回来。这种循环追逐在博弈类优化里很常见，表现是回报曲线周期性起伏而不收敛。

缓解办法主要是限制单轮的更新幅度：策略侧用 PPO 的裁剪目标或 TRPO 的 KL 约束（这正是原论文选 TRPO 的原因），判别器侧每轮只做少量梯度步。两边都走小步，博弈才有机会逐步逼近均衡而不是互相甩开。

来源三：专家数据有限带来的过拟合

专家数据集通常只有几十条轨迹，判别器完全可能把这几条轨迹背下来：不是学到「什么样的行为像专家」，而是学到「这几个具体的状态-动作对是专家的，其余都不是」。这样的判别器给出的奖励只会奖励策略去精确复现那几条轨迹上的点，泛化能力为零，稍微偏离一点就没有奖励。

征兆是判别器在专家训练样本上损失极低、而策略始终无法把回报提上来。缓解手段与来源一部分重合（正则、限制容量），另外可以给判别器输入加少量噪声、或对专家批量做数据增广。

两个网络的更新节奏怎么配

这是实现时最需要动手调的一处。总原则：判别器要弱于策略，但不能弱到没有区分度。 常见做法是每轮采样后，判别器只做一次或很少几次梯度更新，而策略侧跑完整的 PPO 内循环（若干个 epoch）。

回报上升后周期性大幅回落 两侧更新可能形成追逐，也可能是评估方差 固定评估协议，多 seed 检查，再减小单轮更新幅度
专家训练损失很低、留出专家数据表现明显更差 判别器过拟合 加正则、限制容量、补充数据或合理增广

判别器损失的数值基线取决于 reduction。本页代码把两个类别各自的平均 BCE 相加，所以 \(D\equiv0.5\) 时总损失是 \(2\log2\)；若对拼接后的平衡样本统一取平均，则基线是 \(\log2\)。随机猜测损失既可能表示两分布已匹配，也可能表示判别器没学会，必须同时看分类准确率、留出数据、伪奖励分布和独立策略评估，不能仅凭一条 loss 曲线确诊。

算法流程

整个流程分两个阶段。阶段零准备专家数据：本页用 PPO 在带真实奖励的 CartPole 上训一个专家，再用它采样若干条轨迹，然后把奖励丢掉、只留状态与动作。真实场景里这一步换成人类演示，环境奖励从头到尾都不存在。阶段一是 GAIL 本体，交替更新判别器与策略。

方括号内为该步骤对应的公式或小节。

输入: 专家数据集 D_E（只含状态与动作）, 折扣 gamma, GAE 参数 lambda,
      判别器学习率 lr_d, 策略与价值学习率 lr_pi / lr_v,
      每轮采样回合数 n_rollout, 判别器每轮更新次数 n_disc,
      PPO 内循环 epoch 数 K, 裁剪系数 eps

1  随机初始化判别器参数 phi、策略参数 theta、价值网络参数 w
2  for iteration = 1, 2, ... do
3      # ---- 采样：用当前策略与环境交互 ----
4      用 pi_theta 跑 n_rollout 个回合, 收集 (s, a, s_next, terminated, truncated)
5      记这批策略数据为 B_pi                              [注意：不使用环境奖励]
6      # ---- 更新判别器 ----
7      for j = 1 .. n_disc do
8          从 D_E 中抽一批专家样本 B_E, 数量与 B_pi 相当
9          d_pi   <- D_phi(B_pi 的 s 与 a)                # 期望接近 1
10         d_expert <- D_phi(B_E 的 s 与 a)               # 期望接近 0
11         loss_d <- BCE(d_pi, 全 1) + BCE(d_expert, 全 0) [判别器交叉熵]
12         对 phi 做一步梯度下降
13     end for
14     # ---- 构造伪奖励 ----
15     r_hat <- -log( D_phi(B_pi 的 s 与 a) )              [判别器充当奖励]
16     把 r_hat 逐条填入 B_pi, 得到带奖励的转移数据
17     # ---- 更新策略：标准 PPO ----
18     TD bootstrap 只屏蔽 terminated；GAE 递推在 terminated 或 truncated 处断开
19     记录旧策略的对数概率 log pi_old(a|s)
20     for k = 1 .. K do
21         ratio <- exp( log pi_theta(a|s) - log pi_old(a|s) )
22         loss_pi <- -mean( min( ratio * A, clip(ratio, 1-eps, 1+eps) * A ) )
23         loss_v  <- mean( ( V_w(s) - TD 目标 )^2 )
24         分别对 theta 与 w 做一步梯度下降
25     end for
26 end for

实现时最容易出错的六处，代码一节会逐条对应到具体行：

  • 第 5 行的 GAIL 更新不能使用环境奖励。CartPole 的真实奖励只用于阶段零训练示例专家和阶段一外部监控/独立评估；若把它混入策略训练，目标就不再是本页定义的纯 GAIL。数据流必须明确隔离。
  • 第 9 至 11 行的标签方向必须与第 15 行的奖励符号一致。本页约定策略为 1、专家为 0，因此奖励取 \(-\log D_\phi\)。若反过来约定，奖励公式也要相应改变。实现应以手工 logit 验证“越像专家奖励越大”，不能把某种回报曲线当成固定症状。
  • 第 8 行专家批量与策略批量的数量要相当。两类样本数量严重失衡会让判别器偏向多数类，等价于给奖励加了一个与状态无关的偏置。
  • 第 15 行要切断梯度。伪奖励是喂给策略的常量，不需要对 \(\phi\) 求导；留着计算图会让判别器接收到本不该有的梯度。
  • 第 15 行的对数需要数值保护。\(D_\phi\) 输出接近 0 时 \(-\log D_\phi\) 会溢出，实践中要么在对数里加一个小量，要么直接对奖励限幅。
  • 第 7 行与第 20 行的次数比决定训练是否稳定，即上一节讲的更新节奏配比。\(n_{\text{disc}}\) 通常取 1，而 \(K\) 可以取到十几。

代码实现

完整实现拆成七段，按顺序拼起来就是一个可直接运行的脚本，环境用 Gymnasium 的 CartPole-v1。样板段（第一、二、三、七段）讲解从简；判别器与 GAIL 主循环两段逐行讲。

第一段：依赖、超参数与环境（样板，从简）

HIDDEN_DIM = 128

N_EXPERT_TRAJ = 30        # 采集的专家轨迹条数

ROLLOUT_EPISODES = 1      # 每轮采样的回合数 n_rollout

np.random.seed(SEED)
torch.manual_seed(SEED)

CartPole 的状态是四维连续向量，动作是二维离散，默认时间上限为 500 步。GAIL 更新不使用环境奖励；示例仍累计该奖励作为训练 rollout 的外部监控值，但它不是独立评估。正式报告应另建评估环境、固定评估 seed，并明确确定性或随机评估策略。

第二段：策略网络与价值网络（样板，从简）

class PolicyNet(nn.Module):
    """离散动作策略 pi_theta(a|s)，输出动作概率分布。"""

    def __init__(self, state_dim, hidden_dim, action_dim):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, action_dim)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        return F.softmax(self.fc2(x), dim=1)      # 输出概率，和为 1


class ValueNet(nn.Module):
    """状态价值 V_w(s)，PPO 的基线。"""

    def __init__(self, state_dim, hidden_dim):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, 1)

    def forward(self, x):
        x = F.relu(self.fc1(x))
        return self.fc2(x)                        # 标量，不接激活

标准写法。两点提示：策略网络输出层接 softmax 而价值网络不接任何激活；价值网络在 GAIL 里拟合的是伪奖励下的回报，量级由判别器决定而不是环境，因此不能沿用为环境奖励调好的学习率就假定一定合适。

第三段：PPO（样板，从简，同时用于阶段零与阶段一）

def compute_gae(td_delta, trace_continue, gamma, lmbda):
    """GAE 反向递推；episode 边界不跨轨迹传播优势。"""
    td_delta = td_delta.detach().cpu().numpy()
    trace_continue = trace_continue.detach().cpu().numpy()
    advantage, out = 0.0, []
    for delta, cont in zip(td_delta[::-1], trace_continue[::-1], strict=True):
        advantage = delta + gamma * lmbda * cont * advantage
        out.append(advantage)
    out.reverse()
    return torch.tensor(np.array(out), dtype=torch.float, device=device)


class PPO:
    def __init__(self, state_dim, hidden_dim, action_dim):
        self.actor = PolicyNet(state_dim, hidden_dim, action_dim).to(device)
        self.critic = ValueNet(state_dim, hidden_dim).to(device)
        self.opt_a = torch.optim.Adam(self.actor.parameters(), lr=LR_ACTOR)
        self.opt_c = torch.optim.Adam(self.critic.parameters(), lr=LR_CRITIC)

    def take_action(self, state):
        state_t = torch.tensor(np.array([state]), dtype=torch.float, device=device)
        probs = self.actor(state_t)
        return int(torch.distributions.Categorical(probs).sample().item())

    def update(self, batch):
        s = torch.tensor(np.array(batch["states"]), dtype=torch.float, device=device)
        a = torch.tensor(batch["actions"], device=device).view(-1, 1)
        r = torch.tensor(batch["rewards"], dtype=torch.float, device=device).view(-1, 1)
        s_next = torch.tensor(np.array(batch["next_states"]), dtype=torch.float, device=device)
        terminated = torch.tensor(
            batch["terminated"], dtype=torch.float, device=device
        ).view(-1, 1)
        episode_end = torch.tensor(
            batch["episode_ends"], dtype=torch.float, device=device
        ).view(-1, 1)

        td_target = r + GAMMA * self.critic(s_next) * (1 - terminated)
        advantage = compute_gae(
            td_target - self.critic(s), 1 - episode_end, GAMMA, LMBDA
        )
        old_log_prob = torch.log(self.actor(s).gather(1, a)).detach()

        for _ in range(PPO_EPOCHS):
            log_prob = torch.log(self.actor(s).gather(1, a))
            ratio = torch.exp(log_prob - old_log_prob)          # 重要性采样比
            surr1 = ratio * advantage
            surr2 = torch.clamp(ratio, 1 - EPS_CLIP, 1 + EPS_CLIP) * advantage
            loss_a = torch.mean(-torch.min(surr1, surr2))       # 裁剪目标
            loss_c = torch.mean(F.mse_loss(self.critic(s), td_target.detach()))
            self.opt_a.zero_grad(); self.opt_c.zero_grad()
            loss_a.backward(); loss_c.backward()
            self.opt_a.step(); self.opt_c.step()

这里必须区分两个 mask：真正终止 terminated 阻断价值 bootstrap；episode_end = terminated or truncated 阻断 GAE 递推跨越 reset 边界。纯时间截断可从截断前最终观测 bootstrap，但不能把下一回合的优势接到上一回合。阶段一把环境奖励替换为判别器奖励；本例没有实现公式中的策略熵 bonus，相当于熵系数取 0。td_target 与 advantage 在 actor 更新中作为固定目标使用。

第四段：训练专家并采集专家数据（阶段零，从简）

def rollout_one_episode(env, agent, use_env_reward=True):
    """跑一个回合，返回转移字典与回合回报。"""
    batch = {
        "states": [], "actions": [], "rewards": [],
        "next_states": [], "terminated": [], "episode_ends": [],
    }
    state, _ = env.reset()
    ep_return, episode_end = 0.0, False
    while not episode_end:
        action = agent.take_action(state)
        next_state, reward, terminated, truncated, _ = env.step(action)
        batch["states"].append(state)
        batch["actions"].append(action)
        batch["rewards"].append(reward if use_env_reward else 0.0)
        batch["next_states"].append(next_state)
        batch["terminated"].append(float(terminated))
        batch["episode_ends"].append(float(terminated or truncated))
        state = next_state
        ep_return += reward        # 训练 rollout 的外部监控值，不进入 GAIL 更新
        episode_end = terminated or truncated
    return batch, ep_return


def train_expert(env, state_dim, action_dim):
    """阶段零：用环境真实奖励训一个 PPO 专家。"""
    expert = PPO(state_dim, HIDDEN_DIM, action_dim)
    for _ in range(EXPERT_EPISODES):
        batch, _ = rollout_one_episode(env, expert, use_env_reward=True)
        expert.update(batch)
    return expert


def sample_expert_data(env, expert, n_traj):
    """用训好的专家采样轨迹，只保留状态与动作，丢弃奖励。"""
    states, actions = [], []
    for _ in range(n_traj):
        batch, _ = rollout_one_episode(env, expert, use_env_reward=True)
        states.extend(batch["states"])
        actions.extend(batch["actions"])          # 奖励与下一状态都不保留
    return np.array(states), np.array(actions)

这一段是脚手架，真实任务里整段会被「读取人类演示数据集」替代。唯一需要强调的是 sample_expert_data 的返回值：只有 states 与 actions，没有 rewards。这不是省略，而是刻意的——它在代码层面表达了模仿学习的问题设定。rollout_one_episode 的 use_env_reward 开关同理，阶段一调用时传 False，奖励字段先填 0 占位，稍后由判别器覆盖。

第五段：判别器（核心，逐行讲）

class Discriminator(nn.Module):
    """输出 logit z；D_phi(s,a)=sigmoid(z) 是来自策略的概率。"""

    def __init__(self, state_dim, hidden_dim, action_dim):
        super().__init__()
        self.fc1 = nn.Linear(state_dim + action_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, 1)

    def forward(self, state, action_onehot):
        x = torch.cat([state, action_onehot], dim=1)   # 状态与动作拼接后一起输入
        x = F.relu(self.fc1(x))
        return self.fc2(x)                              # logit，不先做 sigmoid

这个网络只有两层，但每一处设计都对应前面推导里的一个要求：

  • 输入是 \((s,a)\) 的拼接，不是只有 \(s\)。只输入单个状态会匹配状态占用而不约束同一状态下的动作；从观察模仿的 GAIfO 通常判别状态转移 \((s,s')\)，不能简单等同于“把动作删掉”的 state-only GAIL。
  • 离散动作必须先转成 one-hot 再拼接。直接把动作的整数编号（0 或 1）作为一维实数喂进去，会让网络误以为动作之间存在「1 比 0 大一倍」这样的序关系，而离散动作之间只有区别、没有大小。连续动作则直接拼接原始向量。
  • 网络返回 logit，而不是先做 sigmoid。理论里的概率是 \(D_\phi=\sigma(z_\phi)\)；实现用 binary_cross_entropy_with_logits 和 softplus 直接处理 logit，避免先取概率再取对数的数值不稳定。
  • 单隐层 128 只是教学配置。容量必须结合训练/留出判别指标、奖励分布和策略性能验证，不存在判别器必须比策略小的通用规则。
  • 没有加正则是最小示例的取舍；是否增加权重衰减、梯度惩罚或谱归一化应由明确诊断与消融决定。

第六段：GAIL 主循环（核心，逐行讲）

class GAIL:
    def __init__(self, agent, state_dim, action_dim, hidden_dim, lr_d):
        self.discriminator = Discriminator(state_dim, hidden_dim, action_dim).to(device)
        if N_DISC_STEPS < 1:
            raise ValueError("N_DISC_STEPS must be at least 1")
        self.opt_d = torch.optim.Adam(self.discriminator.parameters(), lr=lr_d)
        self.agent = agent                # 内部持有一个标准 PPO
        self.action_dim = action_dim

    def _onehot(self, actions):
        """整数动作转 one-hot，形状 (N, action_dim)。"""
        return F.one_hot(torch.as_tensor(actions, device=device).long(),
                         num_classes=self.action_dim).float()

    def learn(self, expert_s, expert_a, batch):
        # ---- 张量化；按策略 batch 大小抽取专家样本 ----
        e_all_s = torch.as_tensor(expert_s, dtype=torch.float, device=device)
        e_all_a = self._onehot(expert_a)
        p_s = torch.tensor(np.array(batch["states"]), dtype=torch.float, device=device)
        p_a = self._onehot(batch["actions"])
        e_idx = torch.randint(e_all_s.shape[0], (p_s.shape[0],), device=device)
        e_s, e_a = e_all_s[e_idx], e_all_a[e_idx]

        # ---- 第一次前向：更新判别器 phi ----
        for _ in range(N_DISC_STEPS):
            z_expert = self.discriminator(e_s, e_a)   # logit 期望较负
            z_policy = self.discriminator(p_s, p_a)   # logit 期望较正
            loss_d = (
                F.binary_cross_entropy_with_logits(z_expert, torch.zeros_like(z_expert))
                + F.binary_cross_entropy_with_logits(z_policy, torch.ones_like(z_policy))
            )
            self.opt_d.zero_grad()
            loss_d.backward()
            self.opt_d.step()

        # ---- 第二次前向：用刚更新过的判别器造伪奖励，不回传梯度 ----
        with torch.no_grad():
            z_policy = self.discriminator(p_s, p_a)
            rewards = F.softplus(-z_policy)  # -log(sigmoid(z_policy))

        # ---- 把伪奖励填进策略数据，交给 PPO ----
        batch["rewards"] = rewards.squeeze(-1).cpu().numpy().tolist()
        self.agent.update(batch)
        return float(loss_d.item())

这三十来行是 GAIL 的全部算法内核，逐条对应到「算法流程」的编号步骤：

  • 专家批量按策略 batch 大小有放回抽取。本页的 loss 分别对两类样本取均值再相加，所以类别总权重相等；匹配 batch 大小主要控制计算量与方差。若改成拼接后统一平均，要显式处理类别先验。
  • _onehot 对应上一段讲的动作编码要求。用 F.one_hot 而不是手写索引赋值，一是简洁，二是它会在动作编号越界时直接报错，比静默产生错误编码好排查。
  • 本例先更新判别器，再用当前判别器计算本轮奖励。这是明确的调度约定，不是唯一合法顺序；其他实现若采用不同交替时序，应记录判别器版本并用实验验证。
  • 标签方向必须与奖励符号一致。这里专家标签为 0、策略标签为 1，所以策略奖励用 \(-\log D_\phi\)。应对手工 logit 做单元测试：越像专家（logit 越负），奖励应越大。
  • softplus(-z) 稳定实现 \(-\log\sigma(z)\)，无需先算概率再 clamp/log，避免概率饱和造成 inf。
  • torch.no_grad() 与随后的 .cpu().numpy() 双重切断了梯度。伪奖励对策略而言是常量，这与 DQN页里 TD 目标要切断梯度是同一类要求：被优化的量与作为标签的量必须分开。
  • self.agent.update(batch) 体现 on-policy 策略优化接口的模块化。TRPO/PPO 可在当前 rollout 上使用伪奖励；换成 SAC 等离策略算法还要设计 replay、旧策略分布与当前判别器重算奖励，不能只替换对象。
  • 返回 loss_d 是为了监控。建议同时记录分类准确率、两类 logit 与奖励统计，并与独立评估指标对照；单独一条判别器 loss 不能确诊训练状态。

绘图时应同时记录 disc_losses、判别器准确率、策略/专家两类 logit、伪奖励均值与方差，以及独立评估回报。判别器 loss 有诊断价值，但不能单独区分“分类器过强”“分类器没学会”和“占用分布已接近”；训练 rollout 的环境回报也不能代替独立评估。

实验设计与证据解释

本页没有给出实际运行日志，因此下面只列待检验假设和证据要求，不把预期趋势写成实验结果。应预先固定多个训练 seed、独立评估 seed、专家质量、数据预算和停止规则，并按训练 seed 汇总不确定性；具体需要多少 seed 取决于方差和所需精度。

训练过程中可能出现的现象：

  • 初始策略与专家差异大时，判别器可能很快降低损失；是否导致奖励退化，要看策略样本伪奖励的分布，而不是只看总 loss。
  • 策略变得更像专家时，判别任务可能变难，但 loss、准确率和回报不要求同步转折。
  • 是否接近专家水平必须由独立环境指标验证；占用匹配代理值下降不自动等于任务回报达到专家水平。
  • 环境真实奖励若只用于评估，必须与训练数据流隔离；真实任务没有该标尺时，应预先定义成功率、安全指标或人工评价协议。

四组消融，用来验证前文的机理：

改动 待检验假设 必须联合观察
提高判别器学习率或更新步数 分类器可能更快饱和 两类 logit、奖励均值/方差、独立回报
增大判别器容量 训练集区分更快，但过拟合风险可能增加 训练/留出判别指标、策略性能
减少专家轨迹 判别器泛化与策略性能可能下降 多个数据子样本和训练 seed 的区间
判别器只输入状态 目标退化为状态占用匹配，动作未必一致 状态分布距离、动作一致性、任务指标
故意翻转奖励方向 用作标签—奖励符号单元测试 手工 logit 下的奖励排序，不必长时间训练

专家数据减少后究竟出现欠拟合、判别器过拟合、模式遗漏还是性能不变，取决于任务与数据多样性；必须通过留出轨迹和多次训练验证，不能预设为某一种固定曲线。

与行为克隆的对照实验应使用同一批专家数据，扫描数据量并同时报告专家样本数、环境 transition、梯度步和墙钟时间。可检验的问题是：GAIL 的在线占用匹配是否在该任务上减轻 covariate shift，以及这项收益是否值得额外环境交互。

不能预先保证“小数据时 GAIL 一定下降更慢”或“两者都能接近专家”。行为克隆省环境交互，标准 GAIL 额外使用环境交互；谁更节省专家数据必须由同任务、同数据协议的实验回答。

另一个值得画出来的量是伪奖励的批均值与方差。健康训练里两者都应当保持在一个非退化的范围内；均值趋近于 0 且方差极小，就是奖励饱和的直接证据，比看判别器损失更早报警。

关键参数配置与原因

下表先给总览。GAIL 的超参分两组：判别器一组、策略优化一组，后者与 PPO页完全一致，此处只讲与 GAIL 相关的部分。

参数 本页取值 作用 敏感度
判别器学习率 1e-3 控制判别器变强的速度 很高
判别器每轮更新次数 1 与上一项共同决定更新节奏配比 很高
判别器隐层宽度 128, 单隐层 判别器容量 高
专家轨迹条数 30 决定判别器能否学到泛化的判据 高
策略学习率 1e-3 PPO 侧，同 PPO 页 中
裁剪系数 eps 0.2 限制单轮策略更新幅度 中
折扣因子 gamma 0.98 有效视野 中
GAE 参数 lambda 0.95 优势估计的偏差方差权衡 低

判别器学习率与更新次数

  • 取值：本页 1e-3、每轮 1 次。这两项要合在一起看，因为决定训练走向的是「判别器每轮实际变强多少」，而不是任一单项。
  • 为什么：这一对参数控制判别器每轮参数位移，应与策略更新量、batch、容量和正则一起看。本页损失按两类 BCE 之和定义，随机猜测基线是 \(2\log2\)，但它不是“健康训练必须贴近”的目标值。
  • 配错了会怎样：更新过强可能造成 logit 饱和和奖励退化；过弱也可能无法形成有用排序。两种情况不能只靠总 loss 区分，要联合查看准确率、留出数据、两类 logit 和奖励分布。

判别器网络容量

  • 取值：本页单隐层 128，只是 CartPole 教学配置，不存在“判别器不得大于策略网络”的通用规则。
  • 为什么：容量影响可分性、泛化和优化速度；过大可能更快拟合有限样本，过小可能欠拟合。
  • 怎样判断：比较训练/留出判别指标、logit 分布和策略评估，并在固定预算下做容量消融，不能仅按网络宽度判定过强。

专家轨迹条数

  • 取值：本页 30 条只是示例预算；是否足够必须由任务、专家多样性和统计验证决定，不能仅按状态维数给出保证。
  • 为什么：判别器要从专家数据里学到「什么样的行为像专家」这个可泛化的判据，而不是背下具体的样本点。样本太少时两者无法区分。
  • 怎样判断：按整条专家轨迹划分训练/验证集，扫描数据量并报告判别泛化与策略性能；不要把单一曲线形状写成固定失败模式。

专家批量与策略批量的比例

  • 取值：本页两者数量相当。
  • 为什么：真正决定类别先验的是 loss 的加权与 reduction，不只是原始样本数。本页分别对两类 BCE 取均值后相加，因此两类总权重相等；抽取相当大小的 batch 主要用于控制计算量和方差。
  • 配错了会怎样：若改为把全部样本拼接后统一平均，数量不平衡会改变隐含类别先验和判别器校准；此时应显式采样平衡或加权，而不能笼统说只增加常数偏置。

折扣因子 \(\gamma\)

  • 取值：本页 0.98，与主线其他页一致。
  • 为什么：GAIL 里 \(\gamma\) 有双重身份——它既是策略优化的折扣因子，也出现在占用度量的定义 \(\rho^{\pi}(s,a) = (1-\gamma)\sum_t \gamma^t P(\cdot)\) 里。也就是说，改 \(\gamma\) 就是在改「要匹配的那个分布」本身，而不只是改优化过程。
  • 配错了会怎样：偏小时占用度量被早期时间步主导，策略只学会模仿专家轨迹的开头，后段行为得不到足够权重。偏大时有效视野变长，伪奖励里的噪声（判别器本身在变）沿更长的时间跨度累积，优势估计方差上升。

伪奖励的形式与限幅

  • 取值：本页采用 \(-\log D_\phi\)，代码用 softplus(-logit) 稳定计算。
  • 为什么：该形式与本页“策略标签为 1”的判别器约定一致；直接使用 logit 公式可避免先求概率再取对数的溢出。
  • 边界：若先求概率再取对数，必须做数值保护；本页的 logit + softplus 写法直接规避了这个问题。还要注意 \(-\log D_\phi\) 恒为正，可能在可提前终止环境中引入偏向更长轨迹的激励。\(\log(1-D_\phi)\) 等替代形式具有不同的数值范围和终止偏好，应作为预先声明并通过消融验证的设计选择，而不是通用修复。

策略侧算法的选择

  • 取值：本页用 PPO，原论文用 TRPO。
  • 为什么：原论文用 TRPO 控制策略步长；PPO 是常见工程替代，但 clip 不等于严格 KL 约束，也不提供 GAIL 收敛保证。
  • 边界：REINFORCE 方差通常更高，但不能断言必然震荡。换成 SAC等离策略算法也不只是替换对象：需设计 replay 中旧策略数据的使用方式，并通常在采样训练 batch 时用当前判别器重算奖励。

与机器人学习主线的关系

GAIL 在机器人学习里很少被原样使用，但它提出的那个问题——没有奖励函数时，学习信号从哪里来——正是当前 VLA 后训练的核心问题。这一节简述几条相关路线，详细内容在各自页面。

与 HG-DAgger 的对比。HG-DAgger（见模仿学习总览）与 GAIL 处理的是同一个病症——策略偏离专家状态分布之后没有信号——但开的是两副药：

维度 HG-DAgger GAIL
偏离后的信号来源 人工接管，现场给出正确动作 判别器打分，说这里不像专家
是否需要在线专家 需要，人必须在场 不需要，专家数据一次性采好
信号形式 人类接管动作；质量取决于操作者 判别器给出的标量相似性信号
环境交互量 少，人的介入本身就在纠偏 多，要反复采样估计占用度量
主要成本 人的时间 仿真或真机的采样时间

实际选择取决于安全约束、是否能在线获得专家、仿真可信度、人工成本和环境交互成本。不能从方法名称推导“真机通常必选 HG-DAgger”或“仿真采样近乎免费”。

与 π0.6 的 RECAP 的关系。π0.6 与 RECAP一页讲的后训练方法没有使用 GAIL 式对抗判别器，而是利用任务结果标注与价值估计构造加权信号。它避免了判别器—策略的对抗博弈，但价值估计仍可能存在误差与分布偏移，不能无条件称为“更稳定”。

为什么 GAIL 在真机上不常直接用，有几条现实原因值得记住：

  • 在线交互成本可能成为瓶颈。原始 GAIL 反复采集当前策略轨迹；在真机上，这可能比离线演示收集更耗时且更受安全约束，但具体成本关系取决于任务和采集系统。
  • 训练失败的代价更高。对抗训练和策略探索若缺少安全层，可能造成停机、人工复位或硬件风险；仿真也并非免费，只是通常更容易并行和复现。
  • 高维观测下判别器更容易作弊。视觉输入时判别器可能抓住与任务无关的表面特征（光照、背景、渲染差异）来区分两类数据，学到的伪奖励与真正的行为相似度脱钩。

GAIL 与 RLHF 奖励模型都体现“学习一个标量反馈再优化策略”的宽泛范式，但监督来源、损失、数据生成和策略优化都不同。可以把 GAIL 作为理解学习型奖励的一种原型，不能把二者当成同一算法。

小结与下一章衔接

本章可以压缩成五句话：

  • 奖励函数写不出来或容易被钻空子时，改用专家演示作为学习信号，这就是模仿学习；三条路线是行为克隆、逆强化学习、生成对抗模仿学习。
  • 行为克隆只在专家数据分布上拟合条件动作分布；有限数据和非零误差下可能出现 covariate shift，经典最坏界可呈 \(O(T^2\epsilon)\)，但不是每个任务的必然等式。
  • GAIL 匹配状态—动作占用度量；理想的占用相等保证正占用支持集上的行为一致，不能约束永不访问的状态，也不是有限训练中的收敛保证。
  • 判别器提供两个占用度量的密度比信号；在理想最优判别器条件下，对抗目标的值与 JS 散度相联系。工程实现可把 \(-\log D_\phi(s,a)\) 作为伪奖励交给 PPO，但奖励随判别器更新而非平稳。
  • 主要难点包括对抗非平稳性、有限专家数据、环境采样成本、策略优化以及终止语义。判别器与策略的相对更新强度很重要，但必须和容量、正则、数据划分及独立评估一起判断。

遗留问题：环境交互仍可能很贵。 原始 GAIL 把模仿学习转化为一个包含环境采样的策略优化问题，需要反复采集当前策略轨迹来估计占用度量。仿真吞吐量高时较易承担；真机上通常受到安全、复位和采样速度约束，但不能把两类场景写成绝对分界。

下一章模型预测控制与 MBPO正面处理这个问题：学一个环境模型，让智能体在模型里试错，把真实交互次数压下来。 那一章会讲滚动时域规划为什么只执行第一步、交叉熵方法怎么解规划问题、模型集成如何抑制策略去利用模型的错误，以及 MBPO 如何把模型生成的短 rollout 与真实数据混合起来训 SAC。这条思路的表格版本已经在Dyna-Q一页出现过。

再往后，离线强化学习走的是另一个极端——完全不与环境交互，只用一个固定数据集训练。它与本页的联系很直接：数据集固定时，策略在数据覆盖之外的区域会做出虚高的估值，这与行为克隆在专家状态之外没有约束是同一类问题的两种表现。整条线的脉络见强化学习总览。

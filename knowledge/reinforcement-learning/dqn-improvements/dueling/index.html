子页① 处理的是目标值怎么算，本页处理的是网络怎么搭。两者互相正交，可以同时使用。

Dueling 的出发点是一个观察：在很多状态上，「当前状态好不好」很重要，而「各个动作之间差多少」并不重要。单流 Q 网络把这两件事混在同一组输出里学，于是每个状态的价值必须在每个动作上各学一遍。Dueling 把它们拆成两条流分别估计，再合并回 Q。真正的难点不在于「拆」，而在于拆完之后必须再减掉一项——否则这个分解在数学上根本不成立。

83.3%Human Starts 下 18 动作游戏对 Single 基线的胜率
1/√2进入最后卷积层的梯度缩放
正交与 Double DQN 的关系
本页重点。必须精读的是两节：「不可辨识性」讲清为什么 Q = V + A 直接实现会失败，以及论文把这个理论缺陷与实测表现直接挂钩的那句话；「两种聚合式的取舍」讲清最大值式与均值式各自牺牲了什么，以及为什么最终选了在语义上更不正确的那一个。

可以快读的是：「工程细节」一节的三处措施（记住存在性与量级即可）、「实验证据」中的逐项百分比。但工程细节里有一条关乎结论解读——论文给单流基线也用了同样的梯度裁剪并配平了参数量，所以 Dueling 的增益不能被归因于这两者。

符号约定与前置

本页沿用 Wang 等原论文的记号，它把网络参数按所属模块分成三份：

记号 指什么
\(\theta\) 共享的卷积层参数，两条流共用
\(\alpha\) 优势流（advantage stream）的全连接层参数
\(\beta\) 价值流（value stream）的全连接层参数
注意与上一个子页的记号冲突。子页①里的 theta 指在线网络的全部参数、theta 上标减号指目标网络，那是按「哪个网络」划分；本页的 theta 只指共享卷积部分，是按「哪个模块」划分。两处都沿用各自论文的原记号，跨页阅读时需按本表换算。

优势函数的定义本页只给一行，不展开：\(A^{\pi}(s,a) = Q^{\pi}(s,a) - V^{\pi}(s)\)，它衡量在状态 \(s\) 上选动作 \(a\) 比按策略 \(\pi\) 平均水平好多少。它在策略梯度谱系中的位置见 Actor-Critic。经验回放、目标网络与致命三要素见 DQN。

动机：两类信息的价值密度不同

论文用 Atari 的 Enduro（赛车）举例：是否该往左还是往右移动，只有在即将发生碰撞时才有意义。在空旷路段上，各个动作的优势几乎没有差别。但对自举类算法而言，情况正相反——每一个状态的状态价值估计都很重要，因为它会被写进下一轮的 TD 目标。

于是出现了一种不对称：

  • \(V(s)\)：每个状态都需要准确估计，且它与选哪个动作无关。
  • \(A(s,a)\)：只在少数状态上才需要分辨，大部分状态上各动作近乎持平。

单流 Q 网络没有办法利用这种不对称。它的输出层是 \([Q(s,a_1), \dots, Q(s,a_m)]\)，一次更新只会改动被执行的那个动作对应的那一项，因此状态价值这份信息必须在每个动作上分别重新学一遍。

saliency 证据：两条流确实学到了不同的东西

这个动机不只是设想。论文按 Simonyan 等 2013 的方法，计算训练好的价值流与优势流对输入视频的 Jacobian，得到两张显著性图（saliency map），结果是：

  • 价值流关注道路，特别是地平线——新车正是从那里出现的；它同时也关注分数。
  • 优势流在前方没有车时不太关注任何东西，只有当车就在正前方时才被激活。
这一点值得强调：两条流的分工是网络自己学出来的，没有任何额外监督，也没有为此设计辅助损失。论文原话是「自动产生对状态价值函数与优势函数的各自估计，无需任何额外监督」。约束只有一条——聚合公式的形式，下面就讲它。

网络结构

下层卷积与原始 DQN 完全相同。区别在于：卷积之后不是接一串全连接层，而是分叉成两串，最后再合并成单个 Q 输出。

论文给出的 Atari 版确切配置如下：

部分 配置
共享卷积 与 DQN 相同的三层：32 个 \(8\times8\) 步长 4 → 64 个 \(4\times4\) 步长 2 → 64 个 \(3\times3\) 步长 1
价值流 一层 512 单元全连接，再接一层全连接输出 1 个标量
优势流 一层 512 单元全连接，再接一层全连接输出 动作数 个值
非线性 相邻层之间一律插 rectifier
有效动作数 ALE 中介于 3 到 18 之间

两处细节值得对照着记。其一，两条流的宽度相同（都是 512），不对称的只有各自的输出维度——一个出标量、一个出动作数。其二，把它与单流网络比较时，单流版本的对应层是 512 单元（Nature 版 DQN），因此 Dueling 的参数量确实更大；论文的隔离实验正是为此把单流基线的第一个全连接层加宽到 1024 来配平，详见下面「论文自己做了变量隔离」一节。

两种结构的输入输出接口完全相同——都是「吃一个状态、吐出所有动作的 Q」。正因为接口一致，Dueling 可以直接套用现成的 Q 学习算法（DQN、Double DQN、SARSA）而无需改动训练流程。

不可辨识性：为什么不能直接写 Q = V + A

把两条流按字面意思相加，得到论文的式 (7)：

\[Q(s, a; \theta, \alpha, \beta) \;=\; V(s; \theta, \beta) + A(s, a; \theta, \alpha)\]

这个式子有一个致命问题：给定 \(Q\)，无法唯一地还原出 \(V\) 与 \(A\)。

论文给的说明只有一句：给 \(V(s;\theta,\beta)\) 加上一个常数，同时从 \(A(s,a;\theta,\alpha)\) 减去同一个常数，这个常数会相互抵消，得到完全相同的 \(Q\) 值。

\[\tilde{V}(s) = V(s) + c, \qquad \tilde{A}(s, a) = A(s, a) - c \qquad \Longrightarrow \qquad \tilde{V} + \tilde{A} = V + A\]

也就是说，监督信号只约束了两条流输出的和，对它们各自的绝对水平没有任何约束。同一个 \(Q = 10\)，可以由 \(V = 7, A = 3\) 给出，也可以由 \(V = 100, A = -90\) 给出，训练信号无法在这两者之间做出区分。

后果有三层：

  1. 两条流的输出失去意义。 论文明确写道，不能因为把网络这样搭出来，就断定 \(V(s;\theta,\beta)\) 是状态价值函数的好估计、或者 \(A(s,a;\theta,\alpha)\) 给出了合理的优势估计。上一节那张 saliency 图之所以能成立，前提正是聚合式做了约束。
  2. 收益消失。 如果 \(V\) 学不到「在所有动作间共享的那部分价值」，整个架构就退化成了一个参数更多、结构更绕的普通 Q 网络。
  3. 实测表现变差。 这是最关键的一句，论文把理论缺陷与实验现象直接挂上了钩：
论文原文：「这种不可辨识性在直接使用该式时，对应地表现为糟糕的实际性能。」（This lack of identifiability is mirrored by poor practical performance when this equation is used directly.）

换句话说，不可辨识性不是一个「理论上不够优雅但实践中无所谓」的瑕疵。它是可观测的：直接实现式 (7) 训练出来的网络，表现确实更差。这是一个很典型的例子——网络结构设计背后是一个数学问题，而不只是「多接了两个 head」。

两种聚合式的取舍

解决办法是给优势流加一个约束，消掉那个自由的常数。论文给了两个方案。

方案一：最大值式（式 8）

思路是强制被选中的那个动作优势为零：

\[Q(s, a; \theta, \alpha, \beta) \;=\; V(s; \theta, \beta) + \left( A(s, a; \theta, \alpha) - \max_{a' \in |\mathcal{A}|} A(s, a'; \theta, \alpha) \right)\]

这个式子有一个漂亮的性质。令 \(a^{*} = \arg\max_{a'} Q(s, a'; \theta, \alpha, \beta) = \arg\max_{a'} A(s, a'; \theta, \alpha)\)，代入可得

\[Q(s, a^{*}; \theta, \alpha, \beta) \;=\; V(s; \theta, \beta)\]

于是 \(V(s;\theta,\beta)\) 确实是状态价值函数的估计，另一条流确实是优势函数的估计——两条流的语义被完整保留了。

方案二：均值式（式 9）

把 max 换成平均：

\[Q(s, a; \theta, \alpha, \beta) \;=\; V(s; \theta, \beta) + \left( A(s, a; \theta, \alpha) - \frac{1}{|\mathcal{A}|} \sum_{a'} A(s, a'; \theta, \alpha) \right)\]

这个式子失去了上面那个漂亮性质：\(V\) 与 \(A\) 现在都与真正的状态价值、优势相差一个常数。

论文为什么选了语义更差的那个

全部实验用的都是式 (9)。理由是优化的稳定性：

用式 (9) 时，优势只需要跟上均值的变化速度；而用式 (8) 时，优势必须补偿最优动作优势的任何变化。

差别的根源在于：均值是所有动作的平滑聚合，变化缓慢；而 max 取决于当前哪个动作排第一，一旦 argmax 发生切换，被减掉的那一项就会跳变，整条优势流必须立刻重新对齐。

论文另外提到一个很少被转述的细节：他们还试过式 (8) 的 softmax 版本，发现结果与更简单的式 (9) 相近，因此最终统一采用式 (9)。

聚合方式 语义是否保留 优化稳定性 论文是否采用
直接相加 式(7) —— 不可辨识，两条流输出无意义 差，实测性能明显下降 否
最大值式 (8) 保留，\(V\) 就是状态价值 较差，argmax 切换时减项跳变 否
均值式 (9) 不保留，两者各差一个常数 较好，减项随均值平滑变化 是
softmax 式 介于两者之间 与式 (9) 相近 否（结果相近）

  NEED --> MAXF["式(8)：减去 max A"]
  NEED --> MEANF["式(9)：减去 A 的均值"]
  MAXF -->|"语义完整：此时 Q(s,a*) 恰等于 V(s)"| MAXOK["保住了语义"]
  MAXF -->|"argmax 一旦切换，减项跳变"| MAXBAD["优化不稳"]
  MEANF -->|"V 与 A 各偏离真值一个常数"| MEANBAD["失去语义"]
  MEANF -->|"减项随均值平滑变化"| MEANOK["优化更稳"]
  MAXBAD -.->|"论文的取舍：要稳定，不要语义"| PICK["全部实验采用式(9)"]
  MEANOK -.-> PICK
  PICK --> KEEP["代价可接受：常数偏移不改变相对排序<br/>因此贪心策略不受影响"]

减均值带来的两条实用性质

论文紧接着指出，虽然式 (9) 牺牲了语义，但它保住了两件真正要紧的事：

  1. 不改变相对排序。 减去的是一个与动作无关的量，因此 \(A\)（以及 \(Q\)）各项之间的相对大小关系不变，基于式 (7) 的 Q 值所导出的任何贪心或 \(\varepsilon\)-贪心策略都被完整保持。这正是「差一个常数无所谓」的确切含义——常数偏移不影响 \(\arg\max\)。
  2. 行动时只需要评估优势流。 既然 \(V(s)\) 对该状态下所有动作是同一个数，选动作时它完全不起作用。论文明确写了这一点：决策时求值优势流就够了。
还有一条实现层面的要点常被忽略：式 (9) 是作为网络的一部分来看待和实现的，而不是一个单独的算法步骤。训练 Dueling 架构和训练标准 Q 网络一样，只需要反向传播，不需要对算法流程做任何改动。这也是为什么它能与 DQN、Double DQN、SARSA 等直接组合。

三处工程细节

这三处在多数二手材料里被略过，但其中两处直接影响实验结论该怎么读。

梯度缩放 1/√2

\[\text{进入最后一个卷积层的合并梯度} \;\longleftarrow\; \frac{1}{\sqrt{2}} \times \text{合并梯度}\]

原因写得很直白：优势流与价值流在反向传播时都会向最后一个卷积层输送梯度，两股梯度在此汇合，量级因此偏大。论文对它的定位很克制——称其为一个「简单的启发式」，作用是「温和地提升稳定性」。

容易写错的一处：缩放施加在进入最后一个卷积层的那股合并梯度上，不是给两条流各自的梯度分别乘系数。这是汇合点上的一次缩放。

梯度范数裁剪到 10

把梯度裁剪到范数不超过 10。论文特意说明：这在深度强化学习里并不是标准做法，而是循环网络训练中的常见手段。

学习率：两个算法用的不一样

优化器与超参数沿用 van Hasselt 等 2015，只有学习率被调得略低一些。但论文括号里补了一句关键限定：对 double DQN 不做这个调整，因为那样会损害它的性能。

这意味着在论文的 Atari 对照里，Dueling 系与 double DQN 用的学习率并不相同。引用那些百分比时，这是一个需要一并说明的口径，否则容易把「学习率更合适」的收益也算到架构头上。

论文自己做了变量隔离

这一条是本节最该记住的。为了把 Dueling 架构本身的贡献分离出来，论文重新训练了一个单流基线，并让它享有同样的待遇：

  • 同样施加梯度裁剪；
  • 第一个全连接层用 1024 个隐单元，使两种架构的参数量大致相同。

这个重训后的基线被记为 Single Clip。因此下面那些百分比是同容量、同裁剪条件下的比较，Dueling 的增益不能被归因于「参数更多」或「用了梯度裁剪」。

实验证据

corridor：把「动作数」单独拎出来做变量

论文先做了一个策略评估任务，选它的理由是这类任务不含探索策略的选择、也不含策略改进与策略评估之间的相互作用这两类混杂因素，因而特别适合评估网络架构。

环境叫 corridor，由三条相连的走廊组成，智能体从左下角出发、走到右上角拿最大奖励。两个竖直段各 10 个状态，水平段 50 个状态。基础动作有 5 个：上、下、左、右、no-op。

关键设计在这里：10 动作与 20 动作的变体，是靠往原环境里加 no-op 动作构造出来的。也就是说，环境的动力学与最优策略完全没变，变的只有动作数。

项目 单流架构 Dueling 架构
层数 三层 MLP 三层
结构 每个隐层 50 个单元 第一隐层 50 个单元后分叉为两条两层 MLP，各 25 个隐单元

评价指标是对真值的平方误差 \(\sum_{s,a} (Q(s,a;\theta) - Q^{\pi}(s,a))^2\)——这个环境足够简单，所有 \((s,a)\) 的精确 \(Q^{\pi}\) 都能单独算出来。

结论：

  • 5 个动作时，两种架构收敛速度大致相同。
  • 动作数增加后，Dueling 明显优于传统 Q 网络。

机理正是开头那个动机：Dueling 里的 \(V(s;\theta,\beta)\) 学到的是一个在该状态下许多相似动作之间共享的通用价值，因而收敛更快。论文评价这个结果「很有前景」，因为许多大动作空间的控制任务都具有这个性质。

度量方式 比较对象 结果

读这张表必须连着「度量方式」一起读，否则会把两套口径拼在一起。论文给了两种评测协议（30 no-ops 与 Human Starts），18 动作那个子集在两种协议下各有一个数字：no-ops 下是 86.6%（26/30），Human Starts 下是 83.3%（25/30）。拿其中一个去和另一协议的全体比例作比较是没有意义的。

真正值得留意的是同一协议内部的对照：Human Starts 下，18 动作子集的胜率（83.3%）明显高于全体（70.2%）；no-ops 下同样是子集（86.6%）高于全体（80.7%）。两种协议各自都给出了同向的结论——动作越多，Dueling 的优势越明显。这与 corridor 上的结论在完全不同的实验设置下相互印证：一个是可精确计算真值的合成环境，一个是 57 个真实游戏。

论文进一步把 Dueling 与基于排序的优先经验回放组合（记为 Prior. Duel Clip），两项改进叠加后成绩继续提升。优先经验回放本身的机制与参数见优先经验回放，本页不展开。

与 Double DQN 的关系

两者正交，改的不是同一个东西：

维度 Double DQN Dueling DQN
改哪里 TD 目标的构造方式 网络结构
解决什么 最大化操作带来的正偏 状态价值的样本效率
是否改算法流程 是（目标值那一行） 否（只是网络前向的一部分）
能否叠加 可以——Dueling 论文的全部 Atari 实验正是在 DDQN 上训练 Dueling 网络 同左，两处改动互不干扰

需要澄清一个常见的混淆：Dueling 并不直接消除过估计。它改善的是状态价值的估计效率，从而间接改善整体估计质量。把两者说成「都是为了解决过估计」是不准确的。过估计的机理见子页①。

落到代码上

完整的三变体同骨架实现在 DQN 改进枢纽页，本页只对照网络前向这一处：

class VAnet(torch.nn.Module):
    def __init__(self, state_dim, hidden_dim, action_dim):
        super().__init__()
        self.fc1 = torch.nn.Linear(state_dim, hidden_dim)   # 共享部分，对应 theta
        self.fc_A = torch.nn.Linear(hidden_dim, action_dim) # 优势流，对应 alpha
        self.fc_V = torch.nn.Linear(hidden_dim, 1)          # 价值流，对应 beta，输出标量

    def forward(self, x):
        h = F.relu(self.fc1(x))
        A = self.fc_A(h)                                    # 形状 (batch, action_dim)
        V = self.fc_V(h)                                    # 形状 (batch, 1)，靠广播相加
        return V + A - A.mean(dim=1, keepdim=True)          # 式 (9)

两个不报错但会算错的坑：

  • A.mean(dim=1) 中的 dim 必须是动作维。写成 dim=0 会变成在 batch 维上求均值——不报错，但减掉的是一批样本之间的平均，含义完全不同。
  • keepdim=True 不能省。 省掉之后形状从 (batch, 1) 变成 (batch,)，与 A 相加时广播规则会把它当成最后一维对齐，结果是错的，同样不报错。

小结与出口

  • 拆成 \(V + A\) 的动机是两类信息的价值密度不同：状态价值每个状态都要准，动作优势只在少数状态上需要分辨。saliency 图证实两条流自己学出了这种分工。
  • 直接写 \(Q = V + A\) 不成立，因为加减同一个常数不改变 \(Q\)，监督信号约束不到两条流各自的水平。论文指出这个理论缺陷对应着可观测的性能下降。
  • 最大值式保留语义、均值式保留稳定性，论文选了后者：均值变化平滑，而 max 会随 argmax 切换而跳变。
  • 减均值不改变相对排序，因此策略不受影响；行动时只需评估优势流。
  • 引用 Atari 百分比时要一并说明：单流基线同样做了梯度裁剪并配平到相近参数量，但学习率口径与 double DQN 不同。

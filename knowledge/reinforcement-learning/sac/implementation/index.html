05 · PYTORCH & SOURCE AUDIT

代码能运行，不代表梯度走对了

本页给出教育性的 PyTorch 核心实现，并用 shape、梯度归属、动作边界和 checkpoint 测试审计它。工程项目可直接使用成熟库；从零实现的目的，是看懂每个细节为何存在。

SAC 枢纽 ← 训练流程 机器人与视觉 →

先写接口合同

Actor
get_action(obs)
返回环境动作 `[B,A]`、修正 log-prob `[B,1]`、`tanh(mu)` 确定性代理动作 `[B,A]`。
Critic
q(obs, action)
本页选择环境尺度作为内部合同并返回 `[B,1]`；归一化内部坐标也可，但 Replay、Actor 更新与 Critic 必须一致。
Replay batch
obs/actions/rewards/next_obs/mask
奖励与 mask 都是 `[B,1]`。
Temperature
alpha = log_alpha.exp()
`log_alpha` 是 `[1]` 可学习张量。

以下代码省略通用日志、并行环境和高性能 replay，只保留 SAC 最容易写错的路径。Gymnasium 环境、PyTorch 版本和随机种子应由项目配置固定。

Actor：重参数化、tanh 与动作缩放

import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.distributions.normal import Normal

LOG_STD_MIN = -5.0
LOG_STD_MAX = 2.0


class Actor(nn.Module):
    def __init__(self, obs_dim, action_low, action_high, hidden=256):
        super().__init__()
        act_dim = int(np.prod(action_low.shape))
        self.net = nn.Sequential(
            nn.Linear(obs_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
        )
        self.mean_head = nn.Linear(hidden, act_dim)
        self.log_std_head = nn.Linear(hidden, act_dim)

        low = torch.as_tensor(action_low, dtype=torch.float32)
        high = torch.as_tensor(action_high, dtype=torch.float32)
        if not torch.isfinite(low).all() or not torch.isfinite(high).all():
            raise ValueError("tanh-affine policy requires finite action bounds")
        if torch.any(high <= low):
            raise ValueError("every action dimension must satisfy high > low")
        self.register_buffer("action_scale", (high - low) / 2.0)
        self.register_buffer("action_bias", (high + low) / 2.0)

    def distribution(self, obs):
        h = self.net(obs)
        mean = self.mean_head(h)

        # 有界映射比无界 exp 更稳定；区间是实现选择，不是 SAC 定理。
        raw = torch.tanh(self.log_std_head(h))
        log_std = LOG_STD_MIN + 0.5 * (LOG_STD_MAX - LOG_STD_MIN) * (raw + 1.0)
        std = log_std.exp()
        return Normal(mean, std), mean, log_std

    def get_action(self, obs):
        normal, mean, _ = self.distribution(obs)

        # rsample 保留 u 对 mean/std 的可导路径。
        u = normal.rsample()
        z = torch.tanh(u)
        action = z * self.action_scale + self.action_bias

        # 稳定的 tanh log|det J|，再减环境动作 affine scale Jacobian。
        log_prob_u = normal.log_prob(u)
        tanh_log_det = 2.0 * (np.log(2.0) - u - F.softplus(-2.0 * u))
        log_prob = log_prob_u - tanh_log_det - torch.log(self.action_scale)
        log_prob = log_prob.sum(dim=-1, keepdim=True)

        # 这是常用确定性代理，不是 squashed Gaussian 的精确期望。
        deterministic_action = torch.tanh(mean) * self.action_scale + self.action_bias
        return action, log_prob, deterministic_action

逐行审计

  1. rsample() 而不是 sample()：否则 Q 对动作的梯度无法穿过随机采样回到 Actor。
  2. action_scale 与 action_bias 注册为 buffer：随模型保存、加载和迁移 device。
  3. 修正项只用一次 z=tanh(u)；不能对 action 再 tanh。
  4. sum(dim=-1, keepdim=True)：每个样本的联合 log density 是动作维之和。
  5. 本页的 log-prob 定义在环境动作坐标，scale Jacobian 与 target entropy 必须使用同一口径。
  6. 评估使用 tanh(mean) 再 scale 的确定性代理；它不是 squashed Gaussian 的精确均值。

Spinning Up 使用更宽的 log-std 下界，CleanRL 当前文档示例使用 -5。这不是谁“公式正确”的差异，而是工程默认。复现实验要锁定实现版本，不能只写“标准 SAC 参数”。

两个独立 Critic

class SoftQNetwork(nn.Module):
    def __init__(self, obs_dim, act_dim, hidden=256):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim + act_dim, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, 1),
        )

    def forward(self, obs, action):
        return self.net(torch.cat([obs, action], dim=-1))


q1 = SoftQNetwork(obs_dim, act_dim)
q2 = SoftQNetwork(obs_dim, act_dim)  # 新实例，不是 q2 = q1
q1_target = SoftQNetwork(obs_dim, act_dim)
q2_target = SoftQNetwork(obs_dim, act_dim)
q1_target.load_state_dict(q1.state_dict())
q2_target.load_state_dict(q2.state_dict())

for p in list(q1_target.parameters()) + list(q2_target.parameters()):
    p.requires_grad_(False)

Q1/Q2 输出都是 [B,1]。若视觉任务共享 encoder，应明确哪些梯度更新 encoder；共享表示会提高两个 Q 的误差相关性。

Optimizer 与温度初始化

actor_opt = torch.optim.Adam(actor.parameters(), lr=3e-4)
critic_opt = torch.optim.Adam(
    list(q1.parameters()) + list(q2.parameters()), lr=1e-3

# -act_dim 先视为归一化动作坐标中的启发式；本页 log_prob 包含 affine scale，
# 因而环境坐标中的目标熵也要加同一个 log-Jacobian 常数。
target_entropy_normalized = -float(act_dim)
target_entropy = (
    target_entropy_normalized + actor.action_scale.log().sum().item()
)
log_alpha = torch.zeros(1, device=device, requires_grad=True)
alpha_opt = torch.optim.Adam([log_alpha], lr=1e-3)

学习率仅作示例，取值接近 CleanRL 当前文档所展示的默认分工；实际项目应保存完整配置。-act_dim 是归一化坐标中的常见启发式，不是环境无关的最优值；若选择让 log-prob 不包含 scale Jacobian，则直接使用归一化目标，不再做上述平移。

Target 计算

def critic_target(batch, actor, q1_target, q2_target, log_alpha, gamma):
    with torch.no_grad():
        next_action, next_logp, _ = actor.get_action(batch.next_obs)
        q1_next = q1_target(batch.next_obs, next_action)
        q2_next = q2_target(batch.next_obs, next_action)
        alpha = log_alpha.exp()
        soft_next_q = torch.minimum(q1_next, q2_next) - alpha * next_logp
        return batch.rewards + gamma * batch.bootstrap_mask * soft_next_q

批量合同：

batch.rewards        [B, 1]
batch.bootstrap_mask [B, 1]
next_logp            [B, 1]
q1_next, q2_next     [B, 1]
target               [B, 1]

如果 mask 是 [B]，与 [B,1] 相乘可能广播成 [B,B]，代码仍运行但目标完全错误。应在更新函数入口写断言。

三组更新与 Polyak

def set_requires_grad(module, enabled):
    for p in module.parameters():
        p.requires_grad_(enabled)


@torch.no_grad()
def soft_update(source, target, tau):
    for src, dst in zip(source.parameters(), target.parameters()):
        dst.mul_(1.0 - tau).add_(src, alpha=tau)


def update_sac(
    batch, actor, q1, q2, q1_target, q2_target,
    actor_opt, critic_opt, log_alpha, alpha_opt, target_entropy,
    gamma=0.99, tau=0.005,
):
    assert batch.rewards.ndim == 2 and batch.rewards.shape[1] == 1
    assert batch.bootstrap_mask.shape == batch.rewards.shape

    # 1) Critic step
    y = critic_target(batch, actor, q1_target, q2_target, log_alpha, gamma)
    q1_pred = q1(batch.obs, batch.actions)
    q2_pred = q2(batch.obs, batch.actions)
    q1_loss = F.mse_loss(q1_pred, y)
    q2_loss = F.mse_loss(q2_pred, y)
    critic_loss = q1_loss + q2_loss

    critic_opt.zero_grad(set_to_none=True)
    critic_loss.backward()
    critic_opt.step()
    # 清除刚完成的 Critic 梯度，便于后续梯度归属检查。
    critic_opt.zero_grad(set_to_none=True)

    # 2) Actor step：冻结 Q 参数，但保留 Q 对 action 的导数。
    set_requires_grad(q1, False)
    set_requires_grad(q2, False)
    new_action, logp, _ = actor.get_action(batch.obs)
    min_q = torch.minimum(q1(batch.obs, new_action), q2(batch.obs, new_action))
    alpha_for_actor = log_alpha.exp().detach()
    actor_loss = (alpha_for_actor * logp - min_q).mean()

    actor_opt.zero_grad(set_to_none=True)
    actor_loss.backward()
    actor_opt.step()
    set_requires_grad(q1, True)
    set_requires_grad(q2, True)

    # 3) Temperature step：这里选 SB3 风格的 log_alpha surrogate；
    # 若使用严格 log 参数化，可把 log_alpha 换成 log_alpha.exp()。
    alpha_loss = -(log_alpha * (logp + target_entropy).detach()).mean()
    alpha_opt.zero_grad(set_to_none=True)
    alpha_loss.backward()
    alpha_opt.step()

    # 4) Target step
    soft_update(q1, q1_target, tau)
    soft_update(q2, q2_target, tau)

    return {
        "critic_loss": critic_loss.detach(),
        "actor_loss": actor_loss.detach(),
        "alpha_loss": alpha_loss.detach(),
        "alpha": log_alpha.exp().detach(),
        "q1": q1_pred.mean().detach(),
        "q2": q2_pred.mean().detach(),
        "target_q": y.mean().detach(),
        "entropy_sample": (-logp).mean().detach(),
    }

更新函数的四个关键点

  • critic_target 中整段 no_grad，不会更新 Actor、Target Q 或 alpha。
  • Actor step 冻结 Q 参数，但 Q 前向仍对 new_action 建图。
  • Alpha step 使用 (logp + target_entropy).detach()。
  • soft_update 不依赖 optimizer；此处的 zip(parameters) 要求 source/target 是同构实例且参数顺序一致。tau=0 应完全不变，tau=1 应完全复制。

Gymnasium 风格训练外壳

obs, info = env.reset(seed=seed)
for env_step in range(total_steps):
    if env_step < learning_starts:
        action = env.action_space.sample()
    else:
        with torch.no_grad():
            obs_t = torch.as_tensor(obs, dtype=torch.float32, device=device)[None]
            action_t, _, _ = actor.get_action(obs_t)
        action = action_t[0].cpu().numpy()

    next_obs, reward, terminated, truncated, info = env.step(action)

    # 仅时间限制时通常继续 bootstrap；项目应以 wrapper 语义为准。
    bootstrap_mask = 0.0 if terminated else 1.0
    replay.add(obs, action, reward, next_obs, bootstrap_mask)

    obs = next_obs
    if terminated or truncated:
        obs, info = env.reset()

    if env_step >= learning_starts and replay.size >= batch_size:
        for _ in range(gradient_steps):
            batch = replay.sample(batch_size, device=device)
            metrics = update_sac(
                batch, actor, q1, q2, q1_target, q2_target,
                actor_opt, critic_opt, log_alpha, alpha_opt,
                gamma=gamma, tau=tau, target_entropy=target_entropy,
            )

这里故意把 Replay Buffer 留成接口，且外壳假设非 autoreset 单环境。VectorEnv/autoreset 必须按所用 Gymnasium 版本从 final_observation 或 final_obs 取得真正末端观测后再写 Replay；真实项目还应为环形 buffer 单独测试索引、覆盖、dtype 和保存恢复。

公式—代码映射

数学对象 代码 最关键审计问题
\(\pi_\theta\) Actor.get_action rsample、两级 Jacobian、多维求和
\(Q_{\phi_1},Q_{\phi_2}\) q1, q2 独立实例、动作尺度统一
\(\bar Q\) q*_target 初始硬复制、无梯度、仅 soft update
\(y\) critic_target no_grad、终止 mask、shape
\(L_\pi\) actor_loss Q 未 detach、Critic 参数不 step
\(\alpha\) log_alpha.exp() 正值、两处 detach、目标熵口径
\(\mathbb E_\mathcal D\) batch .mean() 不在错误维度提前 reduce

十四个静默错误

01

sample() 替代 rsample()：Actor 无法获得路径梯度。

02

双重 tanh：已压缩 action 再进入 tanh 修正，log-prob 系统性错误。

03

多维未求和：alpha 的尺度随 shape 和 broadcasting 漂移。

04

忽略 action bias：非对称 Box 动作整体偏移错误。

05

scale 不是 buffer：迁移 GPU 或加载模型后 device 不一致。

06

q2=q1：双 Critic 退化成同一个估计器。

07

Target Q 在 optimizer：目标不再是慢速副本。

08

target 未 no_grad：梯度进入下一动作、Target Q 或 alpha。

09

Actor 的 Q 被 detach：只剩 entropy 梯度。

10

Alpha 的 log-prob 未 detach：温度目标反向更新 Actor。

11

[B] 与 [B,1]：广播为 [B,B] 而不报错。

12

truncated 全当终止：时间上限处系统性低估。

13

保存遗漏：log_alpha、normalizer 或 action scale 缺失导致恢复行为变化。

14

autoreset 观测混淆：把 reset 后观测当作结束 transition 的 next_obs。

六个微型测试

def test_actor_shapes_and_bounds(actor, obs, low, high):
    action, logp, deterministic_action = actor.get_action(obs)
    assert action.shape == deterministic_action.shape
    assert logp.shape == (obs.shape[0], 1)
    assert torch.all(action >= low - 1e-6)
    assert torch.all(action <= high + 1e-6)
    assert torch.isfinite(logp).all()


def test_soft_update_endpoints(source, target):
    before = [p.detach().clone() for p in target.parameters()]
    soft_update(source, target, tau=0.0)
    assert all(torch.equal(a, b) for a, b in zip(before, target.parameters()))
    soft_update(source, target, tau=1.0)
    assert all(torch.equal(a, b) for a, b in zip(source.parameters(), target.parameters()))

此外应实现：

  1. 梯度归属测试：每个 Loss backward 后检查哪些参数有梯度。
  2. log-prob 对照：随机非饱和输入与 TransformedDistribution 比较。
  3. checkpoint round-trip：保存加载后固定观测的 deterministic action、Q、alpha 一致。
  4. one-batch Critic overfit：固定 batch 的 MSE 可下降；它只证明回归路径连通，不证明整体算法正确。

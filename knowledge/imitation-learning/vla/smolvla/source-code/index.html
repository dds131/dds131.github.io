Prefix/Suffix、mask 与位置编号

prefix 按图像、语言、状态拼接。默认没有 image special tokens 时，图像与语言的 att_masks=0 属于同一双向 block，状态用 att_masks=1 新开一块。5D 图像和多时刻状态都只取最后一帧；因此 n_obs_steps>1 本身不能证明模型使用了观测历史。

图像至少一路真实相机；缺失相机追加空图。保持纵横比，左/上补边，像素 [0,1] → [-1,1]。
语言右侧 padding；与图像默认在同一双向 block。
状态状态投影单独开 block，可读取图像与语言；不乘隐藏维平方根。
动作 suffix每个动作 token 新开一块，形成因果下三角；没有直接 causal/bidirectional 字段。

KV cache、推理与 Euler 调用链

prefill 中每层先对 Q/K 应用 RoPE，再把 K/V 写入 cache；可执行语句支持“已旋转 K + 未旋转 V”，不能把简注扩大成 K/V 都经过 RoPE。每个 Euler 步中，self 层临时追加 suffix K/V，cross 层只读 prefix，步末 crop(prefix_len) 把增长层裁回条件长度。

同步、legacy async 与 RTC 代码位置

三种执行模式不共享一个队列 owner，也不应被描述成一个开关的三档。select_action 管同步内部队列；legacy async 位于外部 client/server；RTC 从 predict_action_chunk 接入 Euler hook，并由 rollout 侧管理队列。

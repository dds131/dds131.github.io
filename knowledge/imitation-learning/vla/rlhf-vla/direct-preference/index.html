DPOKTOAPO

三种方法都绕过显式 Reward Model，但监督结构并不相同

DPO 学习同一条件下的成对偏好；KTO 学习单样本 desirable/undesirable 标签；本页 APO 特指以人类介入数据、自回归动作 token 和连续误差重加权构成的论文方法。三者都需要可比较的 Current/Reference 概率，不能只换 loss 名称就套到 Flow Matching 动作头。

一、统一视角：先定义 log-ratio，再区分三种目标

定义公共的 reference-adjusted score：

\[s_\theta(x,a)=\log\frac{\pi_\theta(a\mid x)}{\pi_{ref}(a\mid x)}.\]

它不是单独训练的 Reward Model，而是由当前策略与冻结参考策略共同决定的隐式分数。DPO 把 $\beta$ 乘在成对 margin 上；KTO/APO 把 $\beta$ 放进效用函数的 sigmoid 中。先写 $s_\theta$ 能避免把两种温度位置重复计算。

flowchart LR
  D[监督数据] --> T{监督结构}
  T -->|同条件成对| P[DPO margin]
  T -->|单点二元标签| K[KTO utility]
  T -->|介入动作标签| A[APO utility + reweight]
  R[Frozen Reference] --> P
  R --> K
  R --> A
  O --> U[更新 Current Policy]
  P --> O[直接偏好目标]
  K --> O
  A --> O

Reference 只提供分母和行为锚点，不接收梯度。Current/Reference 必须使用相同输入、tokenizer、动作量化、有效 mask 和序列聚合方式。

二、DPO：同一条件下的成对偏好

对同一条件 $x$ 下的 chosen 动作 $a^+$ 和 rejected 动作 $a^-$：

\[\mathcal L_{DPO} =-\mathbb E\log\sigma\left( \beta\left[s_\theta(x,a^+)-s_\theta(x,a^-)\right] \right).\]

这不是任意构造出的排序损失。对 KL 正则奖励最大化，最优策略满足

\[\pi^*(a\mid x)=\frac{1}{Z(x)}\pi_{ref}(a\mid x) \exp\!\left(\frac{r^*(x,a)}{\beta}\right),\]

所以 $r^(x,a)=\beta s_{\theta^}(x,a)+\beta\log Z(x)$。在 Bradley–Terry 偏好模型下比较同一 $x$ 的两个候选时，$\log Z(x)$ 才会相消并得到上面的 DPO loss。不同条件的候选不能直接套用这一消去。

准确解释：DPO 直接增大 chosen 相对 rejected 的 reference-adjusted margin。由于概率归一化、共享参数和其他候选共同分配概率质量，该标量目标不保证每个样本的绝对概率都严格“一升一降”。

DPO 优化阶段不需要显式 RM、Critic 或新的 on-policy rollout；但它只能学习离线数据覆盖到的比较。机器人交互具有不可逆性时，很难在完全相同的观测历史下执行两次动作，这正是成对数据构造的主要限制。

三、KTO：单点 desirability

KTO 的一个样本是 $(x,a,y)$，$y\in{D,U}$ 表示 desirable 或 undesirable，不要求为每个 $a$ 找到同条件的另一候选。令

\[r_\theta(x,a)=s_\theta(x,a),\qquad z_0(x)=D_{\mathrm{KL}}\!\left( \pi_\theta(\cdot\mid x)\Vert\pi_{ref}(\cdot\mid x) \right),\] \[v(x,a)= \begin{cases} \lambda_D\sigma\!\left(\beta[r_\theta(x,a)-z_0]\right), & y=D,\\ \lambda_U\sigma\!\left(\beta[z_0-r_\theta(x,a)]\right), & y=U, \end{cases}\] \[\mathcal L_{KTO}=\mathbb E_{(x,a,y)}[\lambda_y-v(x,a)].\]

$z_0$ 是相对于 Reference 的参考点，不是某个负样本的 reward。原论文为稳定训练不通过 $z_0$ 反向传播；实际把 microbatch 输出循环错配，令 $j=(i\bmod m)+1$，计算

\[\hat z_0=\max\!\left(0,\frac1m\sum_{i=1}^{m} \log\frac{\pi_\theta(a_j\mid x_i)}{\pi_{ref}(a_j\mid x_i)}\right).\]

这是方便但有偏的共享 KL surrogate；截断还会增加向上的偏差，不能把它写成精确 KL。

当 desirable/undesirable 数量为 $n_D,n_U$ 时，原论文给出经验性权重范围

\[\frac{\lambda_Dn_D}{\lambda_Un_U}\in[1,1.5].\]

这是语言模型实验中的调参建议，不是机器人数据的普适定理；机器人任务应按安全代价、标签噪声和验证集重新选择。

“不配对”不等于“无需可比性”：KTO 不做逐样本两两比较，但正负标签仍须有一致定义，任务难度、初态、策略版本和操作者分布也要分层或校准。否则模型可能学到“困难任务＝undesirable”，而不是动作质量。

四、APO：介入标签驱动的动作偏好优化

这里的 APO 指论文 Human-assisted Robotic Policy Refinement via Action Preference Optimization 的具体方法，不是所有“动作偏好优化”的统称。它的核心样本不是严格的 chosen/rejected 对，而是从部署介入轨迹得到的单动作 binary desirability：

  • 专家示范动作标为 $c_t=1$。
  • 部署时未触发介入的策略动作标为 $c_t=1$，属于“未被否定”的弱正标签。
  • 人类接管后的纠正动作标为 $c_t=2$。
  • 人类介入前 $K$ 步的策略动作重标为 $c_t=0$，视作 undesirable。

优化时 $c_t\ne0$ 都进入 desirable 分支，$c_t=0$ 进入 undesirable 分支。介入时刻是因果代理而非精确失败定位；反应延迟和误介入会造成标签噪声，$K$ 必须随控制频率与任务动力学验证。

flowchart LR
  B[BC base policy] --> D[部署 + 人类监控]
  D --> C[正常动作 · 纠正动作 · 介入前窗口]
  C --> L[c=1/2 desirable · c=0 undesirable]
  L --> S[balanced sampling]
  S --> A[APO optimization]
  A --> N[下一轮 policy]
  N --> D

4.1 动作 token 概率

对 action token $u_{1:K}$：

\[\log\pi_\theta(a\mid h)= \sum_{k\in\mathcal M}\log p_\theta(u_k\mid h,u_{<k}),\]

$\mathcal M$ 只包含被定义为训练 action 的有效 token。视觉/文本 prompt、padding 和不属于该 action 的未来 token 不能混入；Current 与 Reference 的 mask 必须完全相同。

4.2 KTO 风格效用

APO 对离散动作 token $\hat a$ 定义

\[r_\theta(o,\hat a)= \log\frac{\pi_\theta(\hat a\mid o)}{\pi_{ref}(\hat a\mid o)},\]

再用与 KTO 同方向的 $z_0$ 参考点。对样本 $i$，APO 的效用与目标是

\[v_i= \begin{cases} \lambda_{D_i}\sigma\!\left(\beta[r_{\theta,i}-z_0]\right), & c_i\ne0,\\ \lambda_{U_i}\sigma\!\left(\beta[z_0-r_{\theta,i}]\right), & c_i=0, \end{cases} \qquad \mathcal L_{APO}=\mathbb E[-v_i].\]

每轮 deployment–optimization loop 开始时，Reference 由当前部署策略冻结得到；它不是训练过程中同步变化的副本。

4.3 连续误差自适应重加权

令 $\tilde a_\theta(o_i)$ 是 action token 解码后的连续动作预测，$a_i$ 是数据动作：

\[l_i=\|\tilde a_\theta(o_i)-a_i\|_1, \qquad w_i=\frac{l_i}{\sum_{j=1}^{B}l_j},\] \[\lambda_{D_i}=1-e^{-\beta_Dw_i}, \qquad \lambda_{U_i}=e^{-\beta_Uw_i}.\]

desirable 样本误差越大，$\lambda_{D_i}$ 越大，促使模型修正仍未学好的正确动作；undesirable 样本若与当前预测很接近，则 $l_i$ 较小、$\lambda_{U_i}$ 较大，优先压低模型仍可能执行的失败动作。工程实现要为分母加 $\varepsilon$；官方代码从离散 argmax 解码连续动作并 detach 误差权重，所以该权重不提供一条额外的可微回归梯度。

论文实验设置使用 $K=10$，并让 batch 由 50% 专家动作、25% 人类纠正动作、25% 失败动作组成。这些是论文设置，不是 APO 定义本身；迁移到新机器人时不能照抄为通用最优值。

APO 的论文证据覆盖自回归 VLA（包括离散 token 化动作）；论文也明确把 regression/diffusion policy 扩展列为未来工作。因此“APO 已解决任意连续动作 VLA 的偏好优化”是过度外推。

五、三者的数据要求

方法 最小监督 优化阶段 数据闭环 VLA 落地关键
DPO 同条件 chosen/rejected 无显式 RM/Critic；离线分类目标 可用固定偏好集 同条件比较、联合概率与长度处理
KTO 单样本 desirable/undesirable 无显式 RM/Critic；离线效用目标 可用固定二元反馈集 $z_0$ 估计、类别权重与条件覆盖
APO 介入时序产生的动作 desirability 无显式 RM/Critic；KTO 风格效用 论文方法需要部署—介入—再优化 标签窗口、balanced sampling、token mask 与连续误差权重

六、序列长度、支持集与动作变量

token 总和是自回归序列联合概率的精确 log-prob；长度不同会让 margin 尺度随 token 数改变。常见选择有：

  • token 总和：保留联合概率语义。
  • token 平均：减轻长度尺度差异，但已变成新的 surrogate。
  • 每个物理时间步聚合：适合明确按控制周期定义 action 的系统。
  • 仅已执行动作：只在策略概率也能对同一已执行子块正确边缘化/条件化时成立。

连续高斯策略可以计算 density ratio，但 Current/Reference 必须对同一动作变量有共同支持，tanh squash 要含 Jacobian，单位和尺度必须一致。若安全层把 commanded action 映射为 executed action，不能直接用 commanded-action density 给 executed action 打分。

不可混用：总和、平均和按步聚合对应不同目标。无论采用哪一种，Current/Reference、desirable/undesirable 以及训练/评估必须一致，并报告 mask 后的有效长度分布。

七、监督数据构造与混杂因素

监督可来自：

  1. 人类并排比较两段轨迹。
  2. 单次执行的接受/拒绝或安全标记。
  3. 人类介入前的策略动作与介入后的纠正动作。
  4. 同一任务的成功/失败轨迹。
  5. 外部 evaluator 对候选排序或打分。

只有第 1 类天然满足成对比较；其余来源若用于 DPO，必须解释如何得到同条件候选。成功/失败只给轨迹结果，不能自动确定每个动作的责任。数据划分还要按任务、初态、轨迹、场景与策略版本成组，避免相邻帧泄漏。

没有人类参与的标签应称自动偏好、结果监督或 evaluator feedback，不应统一包装成 RLHF。模型生成标签还要独立审计 evaluator 偏差。

八、离散动作与连续动作边界

OpenVLA 类 action-token 模型可直接取得归一化 token log-prob，因此最接近 DPO/KTO/APO 的前提。Flow Matching 常见训练量是速度场回归：

\[\mathcal L_{FM}=\mathbb E\|v_\theta(a_t,t,c)-u_t\|^2\]

它不是归一化 action log-prob，也不能直接代入 policy/reference ratio。Preference-weighted regression、pairwise energy、路径 density estimator、flow policy gradient 或 residual policy 可以是替代方案，但都引入了新目标或新估计器，不能称为“原公式直接可用”。

记录 checkpoint、tokenizer、量化器与预处理版本。
2 · 验证监督结构
DPO 检查 pair；KTO/APO 检查标签、窗口与类别分布。
3 · 验证 Log-prob
只统计定义中的有效 action token，Current/Reference 规则一致。
4 · 小集过拟合
分别观察 margin、$r_\theta-z_0$、权重与梯度方向。
5 · 独立闭环评估
任务成功、安全、保留能力和介入率不可由训练 loss 代替。

关键单元测试：

  1. Current 与 Reference 完全相同时，$s_\theta$ 应接近 0。
  2. 交换 DPO chosen/rejected 后，margin 和梯度方向应交换。
  3. KTO/APO 翻转标签后，应切换效用分支；$z_0$ 的梯度路径应符合实现约定。
  4. 重复 padding 不改变 loss；修改无效 token 不改变联合 log-prob。
  5. APO 的 $l_i$ 全为 0 时不产生 NaN；高误差 desirable 与低误差 undesirable 获得预期权重。
  6. 按任务/场景分层报告离线 margin 与闭环成功率，检查二者是否发生背离。

十、何时不选直接偏好路线

  • 需要优化器主动在线探索新状态并处理长期信用分配。
  • 只有稀疏终局评分，且动作概率不可得。
  • 安全成本需要独立约束优化。
  • 偏好数据与将部署策略分布差距很大。
  • 标签高度依赖未来后果，却无法可靠归因到动作或片段。

此时可考虑 RM+PPO、off-policy RL、intervention RL 或 preference-guided online RL。选择不同算法不会消除真机安全层、独立评测和数据审计的需要。

十一、知识点、重点与创新点

11.1 知识点

  • DPO 的 Bradley–Terry 假设、KL 重参数化和成对 margin。
  • KTO 的 binary desirability、KL 参考点、效用曲线与类别权重。
  • APO 的介入标签、部署—优化循环和连续误差自适应重加权。
  • 序列概率、有效 token mask、连续 density 与 Flow 边界。

11.2 重点

  • 三种 loss 的监督单位不同，不能只换标签名或共用错误的 batch schema。
  • Reference 必须冻结，概率必须对应同一动作变量与同一预处理。
  • “不成对”不等于“可跨不可比条件训练”；“无 PPO rollout”也不等于“APO 无部署数据循环”。
  • 训练 margin、utility 或 KL 不能替代闭环成功与安全评测。

11.3 创新点

  • DPO 把特定 KL 正则 RLHF 解转化为成对分类目标；成立范围由偏好模型假设限定。
  • KTO 以单点二元反馈和参考点效用降低严格配对需求；它提供数据接口优势，不保证在所有任务上优于 DPO。
  • APO 把人类介入时序变成动作 desirability，并以连续动作误差调制离散 token 偏好损失；当前证据边界是论文评测过的自回归 VLA。

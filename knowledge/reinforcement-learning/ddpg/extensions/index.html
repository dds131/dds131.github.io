DDPG 之后出现的算法并不是都在同一条轴上“增加一个模块”。TD3 直接修补价值误差； D4PG 同时扩展价值表示、回报长度与分布式数据系统；HER 改写 replay 中的目标与奖励； SAC 换成随机最大熵策略；MADDPG 改变多智能体 Critic 的信息集；TD3+BC 则处理离线数据外动作。 只有先区分问题轴，才能理解这些名称之间的关系。

本页是研究地图。每种方法只讲“DDPG 暴露了什么问题、它改了哪一层、没有改什么”。 完整 TD3 推导见TD3， 目标重标记见HER， 最大熵目标见SAC， 多智能体集中训练见MADDPG。

二、TD3：对 DDPG 三个失效点的直接修补

TD3 全称 Twin Delayed Deep Deterministic Policy Gradient。它保留 DDPG 的 off-policy replay、确定性 Actor、目标网络与动作梯度，但改了三个关键位置。

2.1 Clipped Double Q Learning

维护两个在线 Critic 与两个目标 Critic，target 取较小值：

\[y = r+\gamma(1-m_{\mathrm{term}}) \min_{i=1,2} Q_{\bar\phi_i} \left( s',\tilde a' \right).\]

取最小不是为了估计均值，而是用可能的向下偏差换取对危险正向高估的抑制。 两个 Critic 都拟合同一个保守 target。

2.2 Delayed Policy Updates

Critic 每次更新，Actor 与目标网络每隔若干 Critic step 更新。动机是先让价值估计多走几步， 减少 Actor 立即追逐每次 Critic 误差的速度。

2.3 Target Policy Smoothing

\[\tilde a' = \operatorname{clip} \left( \mu_{\bar\theta}(s')+\epsilon_c,\, \ell,u \right),\]

其中

\[\epsilon_c = \operatorname{clip} \left( \epsilon,\,-c,c \right), \qquad \epsilon\sim\mathcal N(0,\sigma_{\mathrm{targ}}^2I).\]

\(\epsilon_c\) 先逐维裁剪，带噪 target action 再裁到合法动作边界。 它只用于 Bellman target，和环境交互时的探索噪声不是同一个变量、不是同一个目的。

2.4 为什么 Actor 常只用 Q1

TD3 的双 Critic 主要用于 target 取最小。原算法的 Actor 更新使用第一个在线 Critic \(Q_{\phi_1}(s,\mu_\theta(s))\)，不对两个 Q 简单平均；min 操作放在 target 端。 这是 TD3 的具体算法定义，不能反推“用 Q1 在所有任务上理论最优”。

TD3 的三项修改必须作为一组理解：双 Critic 处理估值偏差，延迟更新降低策略追逐误差的速度， 目标平滑抑制对尖锐 Q 峰的依赖。只把 Critic 数从一改成二，并不自动等于完整 TD3。

三、D4PG：四个 D 不代表一件事

D4PG 全称 Distributed Distributional Deep Deterministic Policy Gradients。 四个 D 分别来自 Distributed、Distributional、Deep、Deterministic； 其中 distributed 是系统/data-collection 扩展，distributional 是 Critic 表示扩展， deep 与 deterministic 则继承深度确定性策略梯度主干。

3.1 Distributional Critic

普通 DDPG 学标量

\[Q(s,a)\in\mathbb R.\]

Distributional critic 学回报随机变量的分布

\[Z(s,a), \qquad Q(s,a)=\mathbb E[Z(s,a)].\]

“distributional”指回报分布，不表示 Actor 输出随机动作分布； D4PG 的策略仍是确定性的。

3.2 N-step Return

在没有提前终止的长度 \(n\) 片段上，分布目标可写成随机变量

\[\mathcal Y_t^{(n)} = \sum_{k=0}^{n-1} \gamma^k r_{t+k} + \gamma^n Z_{\bar\phi} \left( s_{t+n}, \mu_{\bar\theta}(s_{t+n}) \right).\]

实际 categorical critic 还要把该随机回报分布投影到固定原子支持：

\[Z_{\mathrm{target}} = \Pi_{\mathcal Z} \left( \mathcal Y_t^{(n)} \right).\]

对分布取期望才恢复常见的标量 n-step Q target。若片段内先发生真实 termination， 奖励和 bootstrap 必须在该边界截断；TimeLimit truncation 是否 bootstrap 仍由任务语义决定。 更长回报可加快奖励传播、减少尾端 bootstrap 依赖，但通常增加采样方差， 并要求 replay 正确保存连续片段和边界。原页的标量公式只能作为期望层示意， 不能代替 D4PG 的分布投影 loss。

3.3 Prioritized Replay

按 TD error 或 distributional TD error 等优先级提高样本被采到的概率。它改变采样分布； D4PG 原论文在 Critic 更新中使用与采样概率相关的 importance weight 降低偏差。 这不表示 Actor 的状态采样权重或所有分布失配都被完全校正； 优先级、权重指数/归一化和应用到哪些 loss 都属于必须报告的实现口径。

3.4 Distributed Actors

多个 actor 进程并行与环境交互，提高数据吞吐并增加行为多样性。 系统层的 actor 与算法里的 Actor 网络不是同一个语义层：多个采集进程可共享或周期同步策略参数。

3.5 Acme 实现边界

Acme 的 D4PG agent 文档和代码包含单进程版本：确定性策略、distributional critic、 n-step transition 与 replay。单进程示例不应被描述为已经实现完整分布式采集拓扑； 需要分别看 agent 配置与 distributed program。

四、HER：改 replay，不改 DDPG 策略梯度

HER（Hindsight Experience Replay）面向 goal-conditioned 稀疏奖励任务。 一次失败轨迹未到原目标 \(g\)，但到达了另一个 achieved goal \(g'\)； HER 用 \(g'\) 重标记 transition 并重新计算奖励。

\[\left(s,a,r(s,a,g),s',g\right) \quad\longrightarrow\quad \left(s,a,r(s,a,g'),s',g'\right).\]

4.1 保留什么

  • Actor 仍输出连续动作；
  • Critic 仍学习 goal-conditioned \(Q(s,a,g)\)；
  • Bellman target、动作梯度、目标网络仍是 DDPG 或其他 off-policy learner 的形式。

4.2 改变什么

  • Replay 中的目标条件；
  • 对应 reward；
  • 成功 / 失败标签与采样比例。
  • 若 desired goal 是 observation 的组成部分，当前与下一观测中的目标条件也必须一起替换。

4.3 为什么不是新 loss

HER 的创新在数据重解释。当前 Stable-Baselines3 也把 HER 提供为 HerReplayBuffer，与 DDPG、TD3、SAC 等 off-policy 算法组合， 而不是一个独立策略 optimizer。

4.4 适用前提

环境必须能从轨迹观测定义 achieved goal，并能对任意替代 goal 重新计算奖励。 若 termination 依赖是否达成目标，也要按环境定义一致重算 goal-dependent 终止语义， 但不能覆盖与目标无关的失败终止或 TimeLimit truncation。 若奖励/终止依赖未记录的隐藏信息，重标记可能改变 transition 语义。

五、SAC：不是 DDPG 加一个 entropy loss

SAC 学随机策略，并最大化奖励加熵：

\[J(\pi) = \mathbb E \left[ \sum_t\gamma^t \left( r_t+\alpha\mathcal H \left(\pi(\cdot\mid s_t)\right) \right) \right].\]

现代 SAC 的策略损失常写成

\[L_\pi = \mathbb E \left[ \alpha\log\pi_\theta(a\mid s) - \min_iQ_{\phi_i}(s,a) \right], \qquad a=f_\theta(s,\xi).\]

相对 DDPG，改变的不只是一个正则项：

  • Actor 从确定性映射变成可重参数化随机分布；
  • 探索属于策略本身，不再只靠外挂动作噪声；
  • Bellman target 含下一动作的熵项；
  • 常用双 Q；
  • 温度 \(\alpha\) 可自动调节。

因此，SAC 与 TD3 有共同的 off-policy、双 Q 和连续控制结构，但不是“TD3 或 DDPG 再加 entropy loss”的等价实现。

这里写的是当前常见的、无显式在线 value network 的 SAC 形式。SAC 的早期论文/实现版本 曾维护独立 \(V_\psi\) 与目标 value network；后续版本把目标改写为直接使用 target Q 与熵项。 比较论文、代码或框架时必须注明采用哪一版，不能把不同版本的网络数量和 loss 混成一套定义。

六、MADDPG：把 Critic 的信息集扩成联合状态—动作

在多智能体系统中，每个智能体的策略更新都会改变其他智能体眼中的环境， 单体 replay 更容易失效。MADDPG 采用集中训练、分散执行：

  • 执行期：第 \(i\) 个 Actor 只看本地观测 \(o_i\)。
  • 训练期：第 \(i\) 个 Critic 可看联合观测和联合动作 \(Q_i(o_1,\ldots,o_N,a_1,\ldots,a_N)\)。

它保留 DDPG 的确定性 Actor、replay、target 与动作梯度，但改变 Critic 的条件信息， 使训练时能解释其他智能体动作。

6.1 没有解决什么

  • 智能体数量增加时联合输入迅速变大；
  • replay 中其他智能体历史策略仍会造成陈旧；
  • 中心化信息在训练时是否可得是任务假设；
  • 协作、竞争和信用分配仍需额外设计。

七、TD3+BC：离线数据需要显式策略约束

在线 DDPG 若走到数据外动作，至少还能继续交互收集纠错数据；离线数据固定， 高估动作不会被真实环境反证。TD3+BC 在 TD3 Actor 目标中加入行为克隆约束：

\[L_\pi = -\lambda\, \mathbb E \left[ Q_{\phi_1} \left(s,\mu_\theta(s)\right) \right] + \mathbb E \left[ \left\lVert \mu_\theta(s)-a \right\rVert_2^2 \right].\]

BC 项限制策略偏离数据动作，Q 项保留策略改进方向；论文还采用状态归一化，并令

\[\lambda = \frac{\alpha} {\frac{1}{B}\sum_{i=1}^{B} \left|Q_{\phi_1}(s_i,\mu_\theta(s_i))\right|},\]

用 batch 上的 Q 量级调节两项相对尺度（实现需处理分母数值稳定性）。 Actor 更新时应把这个 batch 尺度视为常数；作者实现对均值绝对 Q 使用 detach()。若让梯度穿过 \(\lambda\) 的分母，Actor 会同时操纵归一化系数， 得到的已不是论文给出的简单“Q 项按当前量级缩放”目标。实际实现还应防止分母过小。 核心不是“给 DDPG 增加监督 loss 就能做离线 RL”， 而是显式处理数据支持与策略外推。

九、四组最容易混淆的概念

9.1 探索噪声 vs 目标策略平滑噪声

  • 探索噪声作用于环境交互动作，改变收集的数据。
  • TD3 target smoothing 噪声只用于计算 Bellman target，正则化 Critic。

9.2 Distributional vs Distributed

  • Distributional：预测回报分布 \(Z\)。
  • Distributed：多个计算进程 / actors 协同采集和学习。

D4PG 同时包含两者，词义不能互换。

9.3 HER vs 新奖励函数

HER 调用环境已有的 goal-conditioned 奖励函数，对替代目标重算奖励； 它不是随意把失败样本奖励改成成功。

9.4 随机 Actor vs 给确定性 Actor 加噪声

SAC 优化的是动作分布及其熵；DDPG 行为动作虽随机，目标 Actor 和 Actor loss 仍是确定性的。

十一、建议的源码对照顺序

  1. 固定 sfujim/TD3 的一个 commit，同时打开 OurDDPG.py 与 TD3.py。
  2. 先比 Actor 前向：通常几乎不变。
  3. 再比 Critic：一个变两个，target 取最小。
  4. 找 target action 加噪声的位置，确认它不进入环境。
  5. 找 policy_freq 条件，确认 Actor 和 target 同步延迟。
  6. 与 CleanRL 的 DDPG / TD3 单文件再次对照，记录环境 API 和默认值差异。
  7. 最后看 SB3：理解框架如何用 TD3 基类表达 DDPG 特殊配置。

十二、知识重点、创新归属与研究边界

12.1 知识点与重点

  1. 问题轴不等于继承树。 先判断问题发生在价值估计、数据语义、策略随机性、 信息结构还是离线支持，再寻找方法；不要把同表出现的方法都称为 DDPG 变体。
  2. 同名噪声不同用途。 DDPG exploration noise 改变环境数据； TD3 target noise 只平滑 Bellman target。
  3. 同名“分布”不同含义。 distributional critic 学回报分布， distributed actors 指系统并行，SAC stochastic policy 学动作分布。
  4. 数据技术与优化器分开。 HER 重标记 transition，PER 改采样权重； 它们都不自动定义新的策略梯度目标。

12.2 创新归属

  • TD3：直接针对 DDPG 的高估、尖峰利用和快速策略耦合，引入 clipped double Q、 target smoothing 与 delayed policy update。
  • D4PG：把 DDPG 扩展为 distributional critic、n-step、prioritized replay 与 distributed actors 的组合，并用分布投影训练 Critic。
  • HER：创新在目标条件 replay 的事后重解释，可与多种 off-policy learner 组合。
  • SAC：创新属于随机最大熵 Actor-Critic 路线，不是给 DDPG loss 附加一项。
  • MADDPG：创新在中心化训练/分散执行的信息结构。
  • TD3+BC：在固定离线数据上用 Q 改进与行为约束平衡策略偏移。

12.3 结论边界

  • TD3 的三项机制各有动机，但完整算法提升不能无消融地归因于其中单项。
  • Distributional critic 表示回报随机变量，不等于自动得到风险敏感策略。
  • 分布式 actors 提高吞吐和行为多样性，也会引入策略滞后与系统异步。
  • HER 只在替代目标的 reward/termination 可由已记录信息一致重算时语义成立。
  • SAC、TD3 或任何方法都不是跨环境无条件最优选择；预算、实现、数据和安全约束仍决定结果。
  • TD3+BC 是一种离线方案示例，不代表简单 BC 项足以解决所有数据外估计问题。

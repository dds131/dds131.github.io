几条读法建议

只想快速搞懂连续控制的四个主力算法，可以从第 8 章策略梯度直接进入，再按 DDPG → SAC → TD3 读完确定性策略这条线，最后单独读 PPO；但第 2 章的贝尔曼方程与第 4 章的时序差分是绕不过去的前置。

想对照另一条技术路线，可以看模仿学习总览——同样是让机器人学会动作，模仿学习不需要奖励函数，但需要人类示教数据；两条线在模仿学习与 GAIL这一章交汇。

想把 SAC 放进真实机器人系统，应在 SAC 之后进入 HIL-SERL：它不重复 SAC 的通用推导，而是集中回答人工何时接管、接管数据如何进入双经验池、视觉奖励怎样闭环，以及真实机械臂如何在有限时间内安全地在线学习。

PPO 还有一个与机器人控制无关的主要应用场景：大模型的人类反馈强化学习（RLHF）。那里的策略网络是 Transformer 语言模型，一个 token 就是一步动作，一整条回复就是一条轨迹。本主线不展开 Transformer 本身，其中的注意力机制与位置编码各有一张基础页；读 PPO 页最后一节前先过一遍这两页，会更容易理解「每一步的状态究竟包含什么」。

MDP 五元组与回报

强化学习问题被形式化成马尔可夫决策过程（Markov Decision Process, MDP），写成五元组

\[\mathcal{M} = \langle \mathcal{S},\ \mathcal{A},\ P,\ r,\ \gamma \rangle\]

这里最关键的假设是马尔可夫性：下一状态只依赖当前状态与当前动作，与更早的历史无关，即

\[P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots) = P(s_{t+1} \mid s_t, a_t)\]

真实机器人往往不满足这一点（例如只有单帧图像时看不出速度），工程上通常靠堆叠历史观测或引入循环网络来近似补齐。五个分量逐项如下。

  • 状态空间 \(\mathcal{S}\)。机械臂任务里通常是关节角、关节速度、末端位姿，加上相机观测。
  • 动作空间 \(\mathcal{A}\)。本板块四个算法全部面向连续动作空间，即 \(\mathcal{A} \subseteq \mathbb{R}^{d_a}\)，每一维都有上下界 \([a_{\min}, a_{\max}]\)，例如关节速度或末端增量位姿。
  • 状态转移概率 \(P(s' \mid s, a)\)。仿真里由物理引擎隐式给出，算法本身不需要显式知道它，这类算法称为 model-free（无模型）。
  • 奖励函数 \(r(s, a)\)。实践中最难的部分不是算法，而是奖励设计。
  • 折扣因子 \(\gamma \in [0, 1)\)。越接近 1 越看重长期回报，但自举误差的累积倍数约为 \(1/(1-\gamma)\)，因此越接近 1 也越难收敛，连续控制任务的常用区间是 0.95–0.99。

从时刻 \(t\) 起的折扣回报（return）定义为

\[G_t = \sum_{k=0}^{\infty} \gamma^{k}\, r(s_{t+k},\, a_{t+k})\]

折扣因子在这里承担两个作用：一是保证无限时域求和收敛，二是表达「近期奖励比远期奖励更可信」这一先验。强化学习的优化目标就是找到策略 \(\pi\) 使回报的期望最大：

\[\max_{\pi}\ J(\pi) = \mathbb{E}_{\tau \sim \pi}\left[ G_0 \right]\]

其中 \(\tau = (s_0, a_0, s_1, a_1, \dots)\) 是策略与环境交互产生的轨迹。

值函数与 Bellman 方程

直接优化 \(J(\pi)\) 很难，因为回报是整条轨迹的量，梯度估计的方差随轨迹长度增长。值函数（value function）把它拆成可以递归计算的形式，这是几乎所有实用算法的地基。

状态值函数衡量「在状态 \(s\) 按策略 \(\pi\) 走下去能拿多少」：

\[V^{\pi}(s) = \mathbb{E}_{\pi}\left[ G_t \mid s_t = s \right]\]

动作值函数则多问一句「如果这一步先强行执行动作 \(a\)，之后再按 \(\pi\) 走」：

\[Q^{\pi}(s, a) = \mathbb{E}_{\pi}\left[ G_t \mid s_t = s,\, a_t = a \right]\]

二者的关系是对动作分布求期望：

\[V^{\pi}(s) = \mathbb{E}_{a \sim \pi(\cdot \mid s)}\left[ Q^{\pi}(s, a) \right]\]

advantage（优势函数）定义为两者之差，表示「这个动作比该状态下的平均水平好多少」，是 PPO 的核心量：

\[A^{\pi}(s, a) = Q^{\pi}(s, a) - V^{\pi}(s)\]

Bellman 期望方程

把回报的定义拆成「一步奖励 + 剩余回报」，就得到 Q 函数的 Bellman 期望方程。它是 Critic 训练时 TD 目标的来源：

\[Q^{\pi}(s,a) = \mathbb{E}_{s' \sim P,\ a' \sim \pi}\left[ r(s,a) + \gamma\, Q^{\pi}(s', a') \right]\]

对应的状态值函数形式为

\[V^{\pi}(s) = \mathbb{E}_{a \sim \pi,\ s' \sim P}\left[ r(s,a) + \gamma\, V^{\pi}(s') \right]\]

Bellman 最优方程

若把「按当前策略取下一步动作」换成「取最优动作」，得到最优方程：

\[Q^{*}(s,a) = \mathbb{E}_{s' \sim P}\left[ r(s,a) + \gamma\, \max_{a' \in \mathcal{A}} Q^{*}(s', a') \right]\] \[V^{*}(s) = \max_{a \in \mathcal{A}} Q^{*}(s, a)\]

最优方程里的 \(\max_{a'}\) 是整条演进线的分水岭。离散动作空间可以枚举取最大，DQN 就是这么做的；连续动作空间无法枚举，于是要么训练一个 Actor 去近似这个 argmax（DDPG、TD3 的路线），要么改用随机策略并把 max 换成带 entropy 正则的 softmax（SAC 的路线）。

DDPG、TD3、SAC 三者的 Critic 训练形式完全一致——都是让网络输出去拟合 Bellman 方程右端的采样估计；它们的区别只在于右端的目标怎么构造：用不用两个 Critic、目标动作加不加噪声、要不要加 entropy 项。把这一点想清楚，三张算法页就只剩下三处差异要记。

on-policy 与 off-policy

这是理解四个算法分野的关键，也是初学时最容易含糊的一处。判据只有一条：采集数据的行为策略（behavior policy），与正在被优化的目标策略（target policy），是不是同一个策略。

  • on-policy：两者必须是同一个。策略参数一更新，之前采的数据就失效，只能丢弃后重新采样。
  • off-policy：两者可以不同。数据由任意历史策略采集，都能用来更新当前策略，因此可以放进 replay buffer（经验回放池）反复复用。
维度 on-policy off-policy
行为策略与目标策略 必须相同 允许不同
数据来源 只用当前策略刚采集的轨迹 可用历史策略采集的数据
replay buffer 一般不用，数据用完即弃 核心组件，反复复用
样本效率 低，每轮都要重新采样 高，一条数据被采样多次
主要风险 更新步长过大导致策略崩坏 分布偏移与 Q 值过估计
训练稳定性 相对稳，梯度与数据分布一致 存在分布偏移，需额外技巧
本板块代表 PPO DDPG、TD3、SAC

两条路线各自的代价值得说清楚。off-policy 用历史数据更新当前策略，严格来说需要重要性采样（importance sampling）修正分布差异，但重要性权重的方差会随轨迹长度指数增长，因此 DDPG 一系直接略去了这项修正，转而依赖 Bellman 方程本身与动作无关的性质——Q 学习的目标只依赖 \((s, a, r, s')\) 这一步转移，与这条数据由谁采集无关。代价是引入了自举误差的累积，也就是后面 TD3 要处理的 overestimation bias（过估计偏差）。on-policy 则用新鲜数据换掉了这些麻烦，代价是每次更新都要重新与环境交互。

真实机器人上采数据代价极高，所以 off-policy 的三个算法在具身智能里更常见；而 PPO 在仿真里可以开上千个并行环境，采样成本低，反而是其主场（腿足机器人的仿真训练以 PPO 为主）。

两条路线的取舍可以概括为：off-policy 用实现复杂度换样本效率，on-policy 用样本量换稳定性。前者靠 replay buffer 反复利用每条样本，代价是必须额外处理 Q 值过估计与分布偏移；后者每次更新都用当前策略的新鲜数据，梯度与数据分布始终一致，代价是环境交互次数。

Actor-Critic 框架

连续动作空间下，无法像离散动作那样对所有动作取 argmax，于是要专门训练一个网络来输出动作，这就是 Actor（策略网络）；同时训练另一个网络评估动作好坏，即 Critic（价值网络）。四个算法全部落在这个框架内。

为什么需要 Critic

不带 Critic 的纯策略梯度（REINFORCE）用整条轨迹的回报 \(G_t\) 当作梯度的权重。梯度是对轨迹取期望、并对轨迹内的每个时间步求和：

\[\nabla_{\theta} J(\theta) = \mathbb{E}_{\tau \sim \pi_{\theta}}\left[ \sum_{t} \nabla_{\theta} \log \pi_{\theta}(a_t \mid s_t)\, G_t \right]\]

其中 \(\tau\) 是一条完整轨迹。求和号不能省：策略梯度是把整条轨迹上每一步的贡献加起来，PPO 页里的同一公式用的是同一写法。

\(G_t\) 是整条轨迹上所有随机性（环境转移、策略采样）的累加结果，方差随时域长度增长，导致梯度估计噪声极大、需要海量样本才能收敛。Critic 的作用是用一个学出来的函数去替换这个高方差的蒙特卡洛量：

  • 用 \(Q_{\phi}(s_t, a_t)\) 或单步 TD 目标 \(r_t + \gamma V_{\phi}(s_{t+1})\) 替换 \(G_t\)，把「整条轨迹的随机性」压缩成「一步转移的随机性」，方差大幅下降。
  • 减去只依赖状态的基线 \(V_{\phi}(s_t)\) 得到 advantage，这一步不改变梯度的期望（无偏），却能进一步削掉与动作无关的那部分方差。
  • 代价是引入偏差：Critic 本身有逼近误差，误差会通过自举传播。整条演进线上大部分技巧，本质都在处理这个偏差。

这就是经典的偏差-方差权衡：Critic 用可控的偏差换掉了不可接受的方差。

框架内的五个通用部件：

  • Actor 输入状态、输出动作。DDPG 与 TD3 的 Actor 输出确定性动作，即一个状态对应唯一动作；SAC 与 PPO 的 Actor 输出随机策略的分布参数（通常是高斯的均值与标准差）。
  • Critic 输入状态（与动作）、输出标量估值。DDPG、TD3、SAC 学的是 \(Q(s, a)\)，PPO 学的是 \(V(s)\) 用于算 advantage。
  • target network（目标网络）：Critic 的回归目标里含 Critic 自己，直接自举会震荡，于是复制一份缓慢更新的副本充当目标。
  • replay buffer（经验回放池）：存 \((s, a, r, s', d)\) 五元组，训练时随机小批量采样，打破样本间时序相关性。
  • 探索（exploration）：确定性策略必须靠外部注入噪声探索；随机策略天然带随机性，SAC 更把这份随机性写进了优化目标。

软更新

target network 的 soft update（软更新）三个 off-policy 算法通用，写成

\[\phi' \leftarrow \tau \phi + (1 - \tau)\, \phi'\]

其中 \(\phi\) 是主网络参数，\(\phi'\) 是目标网络参数，\(\tau\) 是一个远小于 1 的小量（常见量级在千分之几）。\(\tau\) 越小目标越稳但跟得越慢，这是 off-policy 算法里最需要耐心调的一个系数。

Actor 与 Critic 的网络结构

四个算法的网络主体都是多层感知机（MLP），差别集中在输入怎么拼、输出怎么处理。下表按层拆开，以状态为低维向量（关节角、速度、位姿等）的机械臂任务为例；若观测是图像，则在 MLP 前先接一个卷积编码器把图像压成特征向量，后续结构不变。

层 / 模块 输入 → 输出 作用 为什么这样设计
Actor 输入层 状态 \(s \in \mathbb{R}^{d_s}\) → 隐层宽度 接收观测 只吃状态不吃动作，因为 Actor 的职责就是给出 \(s \mapsto a\) 的映射；把动作也当输入会让网络退化成一个评分器
Actor 隐层 隐层 → 隐层，两层，ReLU 拟合非线性策略 两层 256 单元左右是连续控制任务的常见配置，够表达关节耦合又不至于过拟合；ReLU 相比 sigmoid 不会在深层饱和，梯度传得回去
Actor 输出层 隐层 → \(d_a\) 维，接 tanh 后按动作上下界线性缩放 给出合法动作 不加 tanh 时线性输出可以是任意实数，执行前的硬裁剪会在边界处把梯度置零，Actor 一旦走到界外就再也学不回来；tanh 是处处可微的软饱和，把动作压进 \([-1,1]\) 后再缩放到 \([a_{\min}, a_{\max}]\)，边界附近仍有梯度
Critic 输入层 状态与动作拼接 \([s; a] \in \mathbb{R}^{d_s + d_a}\) → 隐层 接收状态-动作对 学的是 \(Q(s,a)\) 而非 \(V(s)\)，必须同时看到二者：确定性策略梯度要求对动作可微，只有把动作送进网络才能拿到 \(\nabla_a Q\)
Critic 拼接位置 早融合：第一层就拼；晚融合：状态先过一层再与动作拼 决定动作信息参与多少层非线性 早融合实现简单、是 TD3 官方实现的做法；DDPG 原论文用晚融合，动机是让状态先被充分编码。低维状态任务上两者差异不大，但晚融合时动作只经过较少的非线性层，\(\nabla_a Q\) 更平滑，对 Actor 的梯度噪声更小
Critic 隐层 隐层 → 隐层，两层，ReLU 拟合值函数 与 Actor 同量级即可；Critic 显著弱于 Actor 时会拖垮整个训练，因为 Actor 的更新方向完全由 Critic 决定
Critic 输出层 隐层 → 标量，不接激活 输出 Q 值 Q 值是折扣回报的期望，取值范围由奖励尺度与 \(\gamma\) 共同决定，可正可负、量级未知；套任何饱和激活都会人为设上限，导致高回报区域的估值被压平
target network 副本 主网络参数 → 缓慢跟随的副本 提供稳定的回归目标 目标里含网络自身，主网络一动目标就动，等于追一个自己在移动的靶子；软更新让靶子的移动速度慢一个量级，把自举回路近似成一个固定点迭代
一个容易被忽略的实现细节：Actor 的输出缩放必须与环境的动作上下界严格对齐。若环境的动作范围不是对称区间，tanh 之后需要做仿射变换而非简单乘一个系数，否则策略在整个训练过程中都无法到达一侧的边界。

连续控制四个主力算法共用的超参数

有几个超参数在四个算法里含义完全相同，值得在总览页一次讲清；算法专有的系数留在各自的页面展开。下面每项按「典型取值 → 为什么这么配 → 配错了会怎样」说明。凡带出处的数值均取自对应算法的原论文，其余写成典型范围。

折扣因子 gamma：0.99 与 0.95 的区别

  • 典型取值：DDPG、TD3、SAC、PPO 四篇原论文的连续控制配置全部取 0.99。常用区间是 0.95–0.99。
  • 为什么这么配：折扣回报 \(G_t = \sum_{k} \gamma^{k} r_{t+k}\) 里第 \(k\) 步奖励的权重是 \(\gamma^{k}\)。这列权重构成公比为 \(\gamma\) 的等比数列，求和为
\[\sum_{k=0}^{\infty} \gamma^{k} = \frac{1}{1 - \gamma}\]

所以常说「有效视野约为 \(1/(1-\gamma)\) 步」——这个数正是全部权重之和，也可以理解成回报里真正起作用的时间步数量级。代入具体数值：\(\gamma = 0.99\) 对应约 100 步，\(\gamma = 0.95\) 对应约 20 步，两者差了五倍。选哪个的判据是任务的关键因果链有多长：如果「现在做的动作」要经过五十步才体现为奖励，0.95 就把这条因果链截断了。

  • 配错了会怎样：\(\gamma\) 偏小时，有效视野之外的奖励几乎不参与优化，需要中长程规划的任务退化成贪心行为。\(\gamma\) 偏大时代价出现在另一侧：自举误差的稳态累积倍数同样是 \(1/(1-\gamma)\)（把每轮引入的偏差 \(\delta\) 按 \(\gamma\) 逐轮累加即得 \(\delta/(1-\gamma)\)），所以 \(\gamma\) 从 0.99 提到 0.999 时，有效视野与误差放大倍数同时从百倍量级跳到千倍量级。这就是稀疏奖励任务上盲目调大 \(\gamma\) 常常不升反降的原因。

学习率

  • 典型取值：DDPG 原论文 Actor 取 1e-4、Critic 取 1e-3；TD3 原论文两者同取 1e-3；SAC 原论文三组参数同取 3e-4；PPO 原论文连续控制取 3e-4。四者都用 Adam。
  • 为什么这么配：Actor 与 Critic 承担的任务性质不同。Critic 做的是有明确目标的回归，目标里含真实奖励，可以学得快；Actor 的更新方向完全由 Critic 提供，Critic 未稳定时把 Actor 推快只会把逼近误差搬进策略。因此惯例是 Actor 的学习率不高于 Critic。DDPG 靠学习率差一个数量级来实现这件事，TD3 改用延迟更新在频率上拉开、于是学习率可以相同，SAC 靠 entropy 项抑制策略塌缩、也不需要差异化学习率——同一个问题，三种解法。
  • 配错了会怎样：Actor 学习率过大时策略在 Critic 的误差峰之间跳动，典型现象是 Q 预测继续上升而实际回报下滑。Critic 学习率过大时自举回归本身震荡，target network 也压不住。两者都过小则训练极慢，off-policy 场景下 buffer 里还会逐渐塞满与当前策略无关的旧数据。

batch size

  • 典型取值：DDPG 原论文低维状态任务取 64，TD3 取 100，SAC 取 256；PPO 原论文连续控制的 minibatch 取 64（但它的一批数据是 2048 乘并行环境数，与 off-policy 的含义不同）。
  • 为什么这么配：batch size 决定单步梯度估计的方差。off-policy 算法每与环境交互一步就更新一次，一次更新只看一个小批量，批太小时 Critic 的回归噪声会经 \(\nabla_a Q\) 原样传给 Actor。SAC 用得比另外两个大，是因为它每步还要额外做重参数化采样与温度损失，这两项都依赖对策略分布的采样估计，对批量更敏感。
  • 配错了会怎样：过小时梯度噪声大，训练曲线抖动明显；SAC 里还会让 entropy 估计不准，进而带动温度系数抖动。过大时单步计算量线性上升，而每个环境步仍只更新一次，样本效率提升有限、墙钟时间变长。

replay buffer 容量

  • 典型取值：DDPG、TD3、SAC 三篇原论文都取 1e6 条转移。经验做法是让容量与整个训练的总环境步数处在同一量级。PPO 没有这一项：它的数据批在若干 epoch 之后整批丢弃。
  • 为什么这么配：容量决定 buffer 里数据的「策略年龄跨度」，也就是最旧的一条数据由多久以前的策略采集；同时它决定单条数据平均被采样多少次——容量越小，重复使用越频繁。
  • 配错了会怎样：容量太小时，早期数据被过早挤出，Critic 只在最近访问过的窄状态区域上有监督信号，对不再访问的区域会遗忘，而 Actor 一旦走回那里就得到不可靠估值，训练出现周期性震荡。容量相对总步数过大时，早期随机策略采集的数据长期占高比例，Critic 把容量花在再也不会访问的状态上，学习变慢。

warm-up 随机步数

  • 典型取值：万步量级，用均匀随机动作填充 buffer。这一项在 DDPG 原论文里没有单列，是后续实现的通行做法；TD3 论文明确在训练开始的若干步内使用纯随机策略采样。PPO 同样没有这一项：初始策略本身就是一个方差不小的随机分布，探索由策略自身的随机性与 entropy 正则维持。
  • 为什么这么配：网络刚初始化时 Actor 的输出集中在动作空间中部（tanh 在零附近近似线性，权重又是小随机数），用它采数据会让 buffer 缺少边界附近的样本；而 Critic 在没有数据的区域只能外推，外推值往往虚高，Actor 恰好会朝虚高处走。先用均匀随机动作把状态-动作空间铺开，能明显降低这个风险；同时也避免样本太少就开始更新、Critic 在极少数状态上迅速过拟合。
  • 配错了会怎样：完全省掉时，训练初期 Q 值剧烈震荡，部分随机种子直接不收敛。设得过长时，前期交互预算全部花在随机策略上，学习起步变慢。另一个常见错误是用未训练网络的输出代替均匀随机采样——两者的状态覆盖差别很大，前者集中在动作空间中部，起不到铺开的作用。

探索噪声尺度与衰减 DDPG、TD3 确定性策略的外加探索强度
延迟系数 d TD3 Actor 相对 Critic 的更新频率比
目标平滑噪声 sigma 与裁剪 c TD3 在动作邻域上对 Q 取平均的范围
温度系数 alpha 与目标 entropy SAC entropy 与奖励的换算比例，及其约束目标
对数标准差裁剪区间 SAC 防止方差塌缩导致对数概率发散
裁剪系数 eps PPO 单样本上新旧策略概率比的允许偏离
GAE 的 lambda PPO 优势估计在偏差与方差之间的权衡
epoch 数 K 与 minibatch M PPO 一批数据被重复训练多少轮、多少步
价值系数 c1 与 entropy 系数 c2 PPO 三项损失之间的权重
KL 早停阈值 PPO 整批策略偏移的兜底约束

连续控制四个主力算法的问题—机制关系

这不是一条按年份升级的版本链。图中箭头表示“共享了什么工程骨架、主要针对什么问题”，而不是宣称后一个算法由前一个算法直接演化而来。DDPG 把确定性策略梯度与深度网络、经验回放和目标网络结合起来；在这套 off-policy Actor-Critic 骨架上，可以沿两条并列思路继续：SAC 用随机策略与最大熵目标改善探索，TD3 用双 Critic、延迟更新和目标策略平滑抑制估值误差反馈。

  DDPG -->|"确定性策略依赖外部探索噪声"| SAC["SAC 2018<br/>随机策略加最大熵目标"]
  DDPG -->|"估值误差被策略与自举反复放大"| TD3["TD3 2018<br/>双 Critic 取最小、延迟更新、目标平滑"]
  PG["策略梯度 REINFORCE<br/>on-policy 支线"] -->|"更新步长不可控，一步走崩"| TRPO["TRPO 2015<br/>KL 信赖域约束"]
  TRPO -->|"二阶优化实现复杂、开销大"| PPO["PPO 2017<br/>clipping 一阶近似"]
算法 年份 策略类型 数据 所承接的问题与关键改动
DPG 2014 确定性 off-policy 随机策略梯度还要对动作分布积分，高维连续动作下估计代价高；DPG 给出确定性策略梯度定理，去掉这层动作积分
DDPG 2015 确定性 off-policy 把 DPG 与深度网络结合，并引入经验回放和目标网络处理样本相关与移动目标，形成深度连续控制的基础工程骨架
SAC 2018 随机 off-policy 沿探索与随机性分支：把 entropy 写入目标，使策略主动保持随机性；现代配方还使用双 Q，并可自动调节温度系数
TD3 2018 确定性 off-policy 沿估值稳定性分支：针对逼近误差被策略选择与自举传播放大的问题，引入双 Critic 取小、延迟 Actor/Target 更新和目标策略平滑
PPO 2017 随机 on-policy 属于另一条 on-policy 支线：TRPO 用 KL 信赖域限制更新但需二阶求解；PPO 用裁剪代理目标构造更易实现的一阶近端更新

需要强调三点。其一，SAC 与 TD3 是围绕不同瓶颈展开的并列路线，不存在“先学会 TD3 才能得到 SAC”或“后者全面替代前者”的关系。其二，本知识库把 SAC 排在 TD3 前，是为了让目录、前后页链接和推荐阅读路线保持一致；这是教学组织，不是论文继承关系。其三，PPO 属于 on-policy 近端更新支线，它解决的是如何在只使用当前策略数据时控制更新幅度，不能与 DDPG、SAC、TD3 排成同一条技术血缘。

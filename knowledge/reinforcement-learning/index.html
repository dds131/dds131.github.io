强化学习让智能体通过与环境交互、依据奖励信号改进策略。本页是知识图谱入口与共同口径页：先统一 transition、return、终止/截断、价值与 bootstrap，再按学习目标进入表格方法、深度价值学习、策略优化、连续控制、特殊问题设定和机器人系统。完整推导与实现下沉到专题页，本页不把所有方法压成一条“越新越好”的算法升级线。

维护口径：本页按前置依赖和问题类型组织入口，不用页面总数或未来规划定义知识结构。数量变化时以实际路由与专题互链为准，目录顺序不表示算法优劣或发布时间排名。
两张横向契约页：环境 API、终止截断与时间边界统一 transition、final observation 与 mask；评估、统计与可复现性统一 seed、聚合、区间估计与 checkpoint 选择。Monte Carlo则属于 DP → MC → TD 的基础方法链，不是横向契约页。

算法目录

目录保留“基础—进阶—系统专题”的阅读便利，但它不是单一血缘。问题设定、数据来源、优化方法和系统工程属于不同分类轴；请按前置依赖阅读，而不要把编号理解为优劣排名。

第一部分 · 基础

  1. 初探强化学习与多臂老虎机 —— 强化学习与监督学习的本质差别；多臂老虎机的累积懊悔，以及 ε-贪婪、UCB、汤普森采样三类探索策略的数学依据。
  2. 马尔可夫决策过程 —— 马尔可夫过程到 MRP 再到 MDP 的递进定义；贝尔曼方程的完整推导；占用度量。
  3. 动态规划 —— 策略迭代与价值迭代；策略评估的收敛性证明与策略提升定理。它假设环境模型已知，是理解后续采样方法与规划方法的基准。
  4. Monte Carlo：预测、控制与重要性采样 —— 不需要环境模型，使用完整 episode 回报做预测与控制；先区分 first/every visit，再进入 on/off-policy importance sampling。
  5. 时序差分 —— 无模型学习中的一步 bootstrap 主线。比较 Sarsa、Expected Sarsa 与 Q-learning，连接 \(n\) 步、TD(\(\lambda\))、最大化偏差和 termination/truncation 边界；CliffWalking 路径差异作为需按统一合同复现的经典现象。
  6. Dyna-Q —— 基于模型的规划与学习。用模型生成的虚拟经验换样本效率，以及模型不准时的失效模式。

第二部分 · 进阶

  1. DQN —— 从表格动作价值过渡到 Q 网络；区分冻结目标损失与半梯度，解释致命三要素、经验回放、目标网络、termination/truncation 与独立评估；另有两个子页：Atari 网络结构与预处理管线与训练与推理期的反常现象诊断。
  2. DQN 改进 —— DQN 改进体系的枢纽，本主线的多页专题之一：枢纽页讲每项改进针对哪个缺陷、改在训练流程的哪一步、彼此是否正交；子页逐项展开，目前已完成过估计偏差与 Double DQN、Dueling 价值与优势分解、优先经验回放、多步回报、分布型强化学习（Distributional RL）与 C51、NoisyNet 参数化噪声探索与Rainbow 组合与消融，七个子页已全部建成。
  3. 策略梯度 —— 基于策略这条线的起点，本主线的多页专题之一：枢纽页讲方法谱系、公式链与更新原理，另有五个子页分别展开定理与两条证明路径、方差、基线与降方差、策略网络与分布族参数化、REINFORCE 算法与实现与失效模式、诊断与调试。
  4. Actor-Critic —— 让参数化策略与学习得到的价值估计相互改进；Critic 可使用 MC、TD、n 步回报或 GAE，偏差—方差取决于具体目标与函数逼近。
  5. TRPO —— 信任域策略优化。替代目标、KL 约束、共轭梯度与线搜索。本主线数学最重的一章。
  6. DDPG —— 确定性连续控制专题：枢纽页统一四网络与训练闭环，七个子页分别展开 DPG 理论、网络与数据流、损失与更新、探索与回放、PyTorch 实现、异常诊断和算法演进。
  7. PPO —— 近端策略优化多页专题：枢纽页统一采样、GAE、概率比、裁剪目标与多 Epoch 更新；八个子页分别展开近端目标与裁剪、Rollout 与 GAE、网络与动作分布、Loss 与优化、PyTorch 与源码、机器人连续控制、异常诊断和改进算法与研究地图。
  8. SAC —— 最大熵连续控制多页专题：枢纽页统一 soft Bellman 闭环、版本差异与阅读路线；八个子页分别展开最大熵与 Soft 策略迭代、网络结构与数据流、Loss、温度与梯度、训练流程与超参数、PyTorch 实现与源码审计、机器人、视觉与数据效率、异常现象与诊断和改进算法与研究地图。
  9. TD3 —— 双延迟确定性连续控制多页专题：枢纽页统一函数逼近误差、三项稳定化机制和完整训练闭环；九个子页分别展开误差机理、Clipped Double Q、延迟更新、目标平滑、网络结构、Loss 与时序、PyTorch、异常诊断以及 TD3+BC、TD7、FastTD3 等研究路线。

第三部分 · 专题与系统

  1. HIL-SERL：人在环在线机器人强化学习 —— 把少量示教、在线 SAC/RLPD、人类接管、双经验池、视觉奖励分类器与安全控制闭合成真实机器人学习系统；七个子页分别展开架构与数据流、接管与双经验池、RLPD/SAC Loss、奖励与安全控制、训练与源码复现、实验现象与诊断和研究与 VLA 路线。
  2. 模仿学习与 GAIL —— 从行为克隆的分布偏移进入占用度量匹配；区分原始 GAIL 判别目标、奖励塑形、交替优化、终止语义与现代实现变体。
  3. 模型预测控制、PETS 与 MBPO —— 区分在线 MPC、PETS 的概率集成动力学与轨迹采样，以及 MBPO 的短模型 rollout；统一讨论模型误差、规划预算和不确定性。
  4. 离线强化学习与 CQL —— 固定数据集下的覆盖、外推误差与离线评估；说明 CQL 保守正则的对象、连续动作近似与部署边界。
  5. 目标导向强化学习与 HER —— 先定义 goal-conditioned MDP，再讲 relabel 的目标、奖励重算、终止/截断与 episode 边界；失败轨迹并不会自动变成所有目标下的成功数据。
  6. 多智能体强化学习入门 —— 区分随机博弈、POSG 与合作式 Dec-POMDP，拆开部分可观测、共同学习非平稳性与信用分配，并建立联合数据和 cross-play 评估契约。
  7. 多智能体进阶：MADDPG —— 逐智能体中心化 Critic、联合 replay、确定性 Actor 梯度与目标联合动作；说明 CTDE 缓解什么、不保证什么，并补齐策略集成与 MPE2 接口。
  8. DRPO 专题 —— 同名方法消歧、散度正则策略优化、解耦奖励、UniRL 实现、联邦离线、安全机器人与 VLA 研究路线。

几条读法建议

想快速进入连续控制，仍建议先完成 MDP → 动态规划 → 蒙特卡洛 → 时序差分，再读策略梯度与 Actor-Critic。算法分支上，DDPG → TD3 是确定性 off-policy 路线；SAC 是最大熵随机策略路线；PPO 是 on-policy 近端更新路线，三者不应串成一条升级链。

想对照另一条技术路线，可以看模仿学习总览——同样是让机器人学会动作，模仿学习不需要奖励函数，但需要人类示教数据；两条线在模仿学习与 GAIL这一章交汇。

想把 SAC 放进真实机器人系统，应在 SAC 之后进入 HIL-SERL：它不重复 SAC 的通用推导，而是集中回答人工何时接管、接管数据如何进入双经验池、视觉奖励怎样闭环，以及真实机械臂如何在有限时间内安全地在线学习。

PPO 还有一个与机器人控制无关的主要应用场景：大模型的人类反馈强化学习（RLHF）。那里的策略网络是 Transformer 语言模型，一个 token 就是一步动作，一整条回复就是一条轨迹。本主线不展开 Transformer 本身，其中的注意力机制与位置编码各有一张基础页；读 PPO 页最后一节前先过一遍这两页，会更容易理解「每一步的状态究竟包含什么」。

最小共同语言：任务、回报与边界

具体任务可写成：

\[\mathcal M=(\mathcal S,\mathcal A,p,R,\gamma,\rho_0).\]

教材常把初始状态分布 \(\rho_0\) 省略而称“MDP 五元组”；一旦要定义优化目标、reset 分布或比较实验，就必须把它补回来。本站统一 transition 时序为：

\[S_t,A_t \longrightarrow R_{t+1},S_{t+1}.\]
  • \(\mathcal S\) 是 Markov state 空间；传感器返回的是 observation，不一定足以成为 state。
  • \(\mathcal A\) 可以离散、连续或混合；只有连续控制分支才需要动作 squashing 与边界缩放。
  • \(p(s',r\mid s,a)\) 是奖励与后继状态的联合条件分布；model-free 表示更新时不显式查询这个模型，不表示经验不能复用。
  • \(\rho_0\) 定义 episode 的起点分布，也会改变最终目标。
  • 部分可观测问题更适合写成 POMDP；堆帧或 RNN 只能改善状态表示，不能保证恢复真实 Markov state。

折扣回报采用奖励后移一位的统一记号：

\[G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}.\]

\(\gamma<1\) 可用于保证无限和有限、表达时间偏好，或对应一种随机终止解释；这些是不同建模视角。有限时域任务即使 \(\gamma=1\) 也可有有限回报，不能把“远期奖励更不可信”写成普遍事实。

环境边界必须区分：

  • terminated=True：任务在 MDP 内真正结束，通常关闭 bootstrap；
  • truncated=True：采样器或外部时限截断，底层任务可能仍继续，通常保留 bootstrap；
  • auto-reset 后的新初始观测不能冒充上一 episode 的 final observation。

一步价值 target 的最小契约是：

\[y_t = R_{t+1} + \gamma\left(1-\mathbb 1_{\mathrm{terminated}_{t+1}}\right) V(S_{t+1}^{\mathrm{final}}).\]

reset mask、bootstrap mask 与 loss/valid mask 不能合并成一个 done。完整 API、vector env 与时间语义见环境边界页；MDP 的正式定义与推导见马尔可夫决策过程。

值函数、Bellman 算子与三类备份

值函数把未来回报压缩为状态或状态—动作对上的条件期望。统一时间下标后，三个核心量是

\[V^{\pi}(s)=\mathbb E_{\pi}[G_t\mid S_t=s],\qquad Q^{\pi}(s,a)=\mathbb E_{\pi}[G_t\mid S_t=s,A_t=a],\] \[A^{\pi}(s,a)=Q^{\pi}(s,a)-V^{\pi}(s),\qquad V^{\pi}(s)=\mathbb E_{A\sim\pi(\cdot\mid s)}[Q^{\pi}(s,A)].\]

advantage 表示动作相对于该状态下策略平均水平的增益；它不仅用于 PPO，也广泛出现在策略梯度、GAE 与方差降低中。

令 \(m_{t+1}^{\mathrm{boot}}\) 为 bootstrap mask：真正终止时为 0；仅因外部时间上限截断、且任务语义允许继续时为 1。Bellman 期望方程可写成

\[Q^{\pi}(s,a) = \mathbb E\!\left[ R_{t+1} + \gamma m_{t+1}^{\mathrm{boot}} \mathbb E_{A'\sim\pi(\cdot\mid S_{t+1})} Q^{\pi}(S_{t+1},A') \mid S_t=s,A_t=a \right].\]

如果把终止状态的后继值约定为 0，mask 可以隐含在边界条件里；工程实现中显式保留它更不容易把 terminated 与 truncated 混淆。

同一个 Bellman 关系产生三类不同的估计方式：

方法 目标从哪里来 是否 bootstrap 主要代价
动态规划（DP） 已知模型下对所有后继状态与奖励求期望 是 需要模型，且全状态扫描昂贵
蒙特卡洛（MC） 完整 episode 的实际回报 \(G_t\) 否 无需模型但方差高，通常要等 episode 结束
时序差分（TD） 样本奖励加当前价值估计 是 可在线更新，但引入自举偏差与稳定性问题

这三者不是互相替代的章节名称，而是从“精确期望”到“完整采样回报”再到“采样一步并 bootstrap”的连续设计空间。建议依次阅读动态规划、蒙特卡洛方法与时序差分。

控制问题对应的 Bellman 最优方程是

\[Q^*(s,a) = \mathbb E\!\left[ R_{t+1} + \gamma m_{t+1}^{\mathrm{boot}} \max_{a'}Q^*(S_{t+1},a') \mid S_t=s,A_t=a \right], \qquad V^*(s)=\max_a Q^*(s,a).\]

离散动作可枚举时，DQN 直接近似这个最大化；连续动作下，DDPG/TD3 用 Actor 近似 \(\arg\max_a Q(s,a)\)。SAC 优化的则是加入熵正则的软价值目标，通过对随机策略采样并加入 \(-\alpha\log\pi(a\mid s)\) 项实现，并不是简单地把 max 换成普通 softmax。

DDPG、TD3 与 SAC 都使用“一步奖励 + bootstrap”的 Critic 回归骨架，但它们的目标算子、策略类型、Critic 数量、熵项、目标网络和更新耦合并不相同。因此可以共用统一符号理解，不能把三者缩减成只有三处实现差异。

on-policy 与 off-policy：先分清数据由谁产生

令 \(b\) 表示采集数据的行为策略，\(\pi\) 表示正在评估或优化的目标策略。on/off-policy 描述的是二者的关系，不等同于“有没有 replay buffer”。

  • on-policy：更新所依据的数据分布必须来自当前策略，或仍处在算法允许的受控邻域。PPO 会对同一批 rollout 做若干轮 minibatch 更新，并用概率比与 clipping 限制偏移；不是参数一变，数据就瞬间在数学上全部失效。
  • off-policy：允许 \(b\ne\pi\)，但不代表任意历史数据都可靠。数据必须覆盖目标策略关心的状态—动作区域，并保持相容的环境动力学、奖励、边界和观测语义；覆盖不足会导致外推误差。
维度 on-policy off-policy
行为策略与目标策略 相同或受算法约束地接近 可以不同
常见数据生命周期 一批 rollout 内有限次复用，随后弃用 可长期进入 replay 或离线数据集
replay 是否为定义条件 否；短期 rollout buffer 很常见 否；但深度 off-policy 控制中很常见
主要优势 目标与采样分布较一致，分析更直接 能复用昂贵数据，通常样本效率更高
主要风险 交互量大、更新过猛仍会失稳 覆盖不足、分布偏移、外推误差与自举误差
本板块代表 PPO DDPG、TD3、SAC

重要性采样是否必需，要看估计对象。用行为策略轨迹直接估计另一策略的回报或策略梯度时，通常需要密度比或其他校正；完整轨迹权重又可能产生极高方差。Q-learning 一类控制方法根据条件转移样本逼近最优 Bellman 固定点，确定性策略梯度也可定义 off-policy 目标，所以它们通常不乘整条轨迹的重要性权重。这里的理由不是“Bellman 方程与动作无关”——Q 函数恰恰以动作为条件——也不表示数据分布无关：replay 的覆盖范围与采样权重仍决定学到哪里、误差如何传播。

在真实系统中，off-policy 数据复用通常更有吸引力；在可大规模并行仿真的任务中，PPO 等 on-policy 方法也可能有很强的吞吐与稳定性。具体选择还取决于安全约束、重置成本、观测形态和能否获得高覆盖数据，不能只用“样本效率高/稳定性高”一条轴下结论。

检查口径：先写清行为策略 $$b$$、目标策略 $$\pi$$、数据支持集和更新时允许的分布偏移，再讨论 replay、重要性采样或样本效率。on/off-policy 是估计问题的属性，不是某个容器组件的别名。

Actor-Critic：不是单一算法模板

Actor-Critic 并非连续动作专属。Actor 表示参数化策略，Critic 估计 \(V^\pi\)、\(Q^\pi\) 或 advantage；离散和连续动作都能使用。连续动作无法廉价枚举 \(\arg\max_a Q(s,a)\)，只是让显式 Actor 尤其重要。

从 Monte Carlo 策略梯度到 Critic

REINFORCE 的轨迹估计为

\[\widehat{\nabla_{\theta}J} = \sum_t \nabla_{\theta}\log\pi_\theta(A_t\mid S_t) \left(G_t-b(S_t)\right).\]

只要基线 \(b(S_t)\) 不依赖当前动作，减去它不会改变策略梯度的期望，却通常能降低方差。把基线学习成 \(V_\phi(S_t)\)，或直接学习 \(Q_\phi(S_t,A_t)\)，就得到 Actor-Critic 的基本形态。

Critic 的目标不必只有单步 TD。它可以使用完整 MC 回报、\(n\) 步回报、TD(\(\lambda\)) 或 GAE；bootstrap 越强通常方差越低、由价值逼近带来的偏差越明显。因而“Critic 把整条轨迹随机性压成一步随机性”只描述了单步 TD 的一端，不是 Actor-Critic 的定义。

两条常见数据流

on-policy 与 off-policy Actor-Critic 共用“策略 + 价值估计”的思想，但数据字段、目标构造和稳定化机制不同：

flowchart TB
  ENV["环境交互"] --> TR["转移<br/>S_t, A_t, R_next, S_next<br/>terminated / truncated"]
  TR --> ON["on-policy rollout<br/>保存 old log-prob 与 V"]
  TR --> OFF["off-policy replay<br/>保存边界与有效性 mask"]

  ON --> ADV["用 MC / n-step / GAE<br/>构造 return 与 advantage"]
  ADV --> ONA["在受控轮数内更新 Actor / Critic"]
  ONA --> DROP["丢弃或刷新该批 rollout"]

  OFF --> QT["按算法构造 Q target<br/>使用正确 bootstrap mask"]
  QT --> QC["更新一个或多个 Critic"]
  QC --> OA["按 DDPG / TD3 / SAC<br/>各自目标更新 Actor"]
  OA --> TGT["按算法更新目标网络"]
  • PPO：随机 Actor + 状态价值 Critic；rollout 内可做多轮 minibatch 更新，用概率比和 clipping 约束策略漂移。
  • DDPG：确定性 Actor + 单 Q Critic；通常有 Actor/Critic 目标网络和 replay。
  • TD3：确定性 Actor + 双 Q Critic；加入 clipped double Q、目标策略平滑与延迟策略更新。
  • SAC：随机 Actor + 双 Q Critic；优化熵正则目标，现代实现通常为 Q Critic 维护目标网络。
  • 探索不等于随机策略：DDPG/TD3 常在行为动作上加噪声；SAC/PPO 从策略分布采样，但评估时仍可选择确定性或低方差动作。

目标网络的适用边界

Polyak 软更新常见于 DDPG、TD3、SAC：

\[\bar{\phi} \leftarrow (1-\tau)\bar{\phi}+\tau\phi, \qquad 0<\tau\ll1.\]

\(\phi\) 是在线参数，\(\bar{\phi}\) 是目标参数。较小的 \(\tau\) 让目标变化更慢，但也增加滞后；它不能替代正确的终止 mask、目标算子和数据覆盖。哪些网络需要目标副本由算法决定：PPO 通常不使用这套目标网络机制，DDPG/TD3 与常见 SAC 实现维护的副本也不完全相同。

Actor 与 Critic 的网络结构：按观测和算法选择

低维连续控制常用 MLP，但它只是基线：图像观测需要视觉编码器，部分可观测任务可能需要历史堆叠、RNN/Transformer 或显式状态估计。编码器是否共享、是否冻结，以及归一化方式都会改变优化耦合，不能概括成“在 MLP 前接 CNN，后续不变”。

模块 DDPG / TD3 SAC PPO 实现检查点
Actor 输入 当前观测或其表征 当前观测或其表征 当前观测或其表征 区分真实状态与观测；历史依赖必须显式编码

Q 网络可以在输入层早融合 \([s;a]\)，也可以先编码状态再注入动作。DDPG 原文采用较晚的动作注入，TD3 常见实现采用早融合；没有普遍结论证明晚融合一定让 \(\nabla_aQ\) 更平滑。应通过多随机种子、梯度尺度和最终控制指标比较，而不是把架构偏好写成定律。

对有限动作区间，常见仿射缩放为

\[a = a_{\min} + \frac{\tanh(u)+1}{2} \left(a_{\max}-a_{\min}\right).\]

若直接输出无界动作再在环境侧硬裁剪，训练目标可能基于“未裁剪动作”，而环境执行的是“裁剪后动作”，造成动作与 log-prob/Q 梯度语义不一致。反过来，tanh 靠近边界也会饱和、梯度变小，并非边界附近始终保有充足梯度；SAC 还必须使用变量变换修正 log-prob。非对称动作上下界必须逐维仿射变换，并同时处理无界维度与数值容差。

跨算法的同名超参数：口径相同不等于配置相同

DDPG、TD3、SAC 与 PPO 都会出现 \(\gamma\)、学习率和 batch size，但相同名字不保证相同数据分布、更新次数或敏感性。以下给出选择逻辑，不把论文中的单个配置误写成通用最优值。

折扣因子：同时绑定时间尺度

\[G_t=\sum_{k=0}^{\infty}\gamma^kR_{t+k+1}, \qquad \sum_{k=0}^{\infty}\gamma^k=\frac{1}{1-\gamma}.\]

\(1/(1-\gamma)\) 是几何权重总量，可作为“有效时域数量级”的启发式，但不是严格截断步数，也不是任何误差都会精确放大该倍数。\(\gamma=0.99\) 与 0.95 分别给出约 100 与 20 的权重尺度；任务终止结构、奖励延迟和混合时间同样会影响实际时域。

环境步长或 action repeat 改变后，逐步 \(\gamma\) 也应重新解释。若希望保持连续时间折扣率 \(\lambda\)，可用 \(\gamma_{\Delta t}=\exp(-\lambda\Delta t)\) 对齐不同控制频率。折扣、时间上限与 terminated/truncated 必须联合检查，详见环境边界页。

学习率与更新比率

Actor、Critic、温度或价值头可以使用不同学习率，但“Actor 必须慢于 Critic”不是定律。稳定性还取决于梯度尺度、奖励/观测归一化、target 滞后、策略延迟和每个环境步的梯度更新次数（update-to-data ratio，UTD）。

比较学习率时必须同时记录优化器、batch size、网络规模、学习率调度和 UTD。只改学习率却让总更新次数不同，无法判断改善来自步长还是计算预算。

batch size 与 rollout/minibatch 语义

off-policy 的 batch 通常从 replay 抽取转移；PPO 的 minibatch 则来自一批具有时序结构的 rollout，并会在若干 epoch 内复用。batch 增大通常降低单步梯度噪声，但也改变更新频率、内存、墙钟时间和每条样本的复用方式，不能独立断言“越大越稳定”。

对 RNN、序列模型或 \(n\) 步目标，采样单位还可能是连续片段而不是独立转移；此时 burn-in、序列长度和 padding mask 都属于 batch 配置。

replay 容量、采样与 warm-up

replay 容量控制策略年龄跨度与覆盖范围，但并不存在“必须与总环境步数同量级”的规则。容量、采样优先级、数据保留策略和 UTD 共同决定样本被看见多少次。容量过小可能丢失覆盖，过大也不必然有害；真正要监控的是样本年龄、覆盖、TD 误差分布和训练—采样比。

DDPG/TD3/SAC 常在开始更新前收集一段数据，动作可来自均匀随机策略或带探索的初始策略。warm-up 长度应相对于动作维度、重置成本和最小 batch 设定；“万步”只是部分基准的经验值，不保证适用于机器人、稀疏奖励或受约束动作空间。PPO 通常先采满首批 rollout 再更新，这与 replay warm-up 不是同一机制。

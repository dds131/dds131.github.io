OpenVLA 总览/网络架构与 Prismatic 主干

OPENVLA · BASE 7B · ARCHITECTURE CONTRACT

同一张 RGB 图像经 DINOv2 与 SigLIP 两套预处理和两座视觉塔，形成两个等长的 256-token patch 序列；它们沿特征维拼接，经固定发布物中的三层 projector 映射到 Llama 2 7B 的 4096 维嵌入空间。

视觉 token 插在输入首 token（通常为 BOS）之后，与提示和输出 token 组成一条因果序列。架构只输出完整词表 logits；动作 token 的合法 ID、数值语义和反量化由下一页负责。

fixed release · base-7bpaper v3 · repo commit · HF revision两项证据差异显式保留model/runtime validation: not-run

前置知识与本页角色

本页接受 OpenVLA 总览给出的模型身份，不重新定义方法族：base-7b 是基于 Prismatic-7B、DINOv2、SigLIP 与 Llama 2 7B 的监督式动作 token 路线。这里负责张量形状、模块连线、因果可见性和 fixed release 差异；动作量化、数据配方、训练超参数、部署 ABI 与实验结果由后续页面分别持有。

VLM 与空间 grounding应先理解视觉特征如何进入语言嵌入空间。对应基础条目尚由共享 registry 解析，本页不生成未确认的悬空链接。
ViT、patch token 与因果注意力用于区分视觉塔内部 patch 序列与 Llama 的因果可见性。 位置编码与 RoPE用于区分二维 patch 位置与拼接后一维序列位置。

图像预处理与双接口

fixed base-7b 对同一 RGB observation 执行两套独立变换。两路都用 resize-naive 把图像双三次缩放到 224×224，但归一化不同：DINOv2 路径采用约 [0.485,0.456,0.406] / [0.229,0.224,0.225] 的 mean/std，SigLIP 路径采用 [0.5,0.5,0.5] / [0.5,0.5,0.5]。尺寸相同不表示预处理可互换。

resize-naive 会改变非方形输入的长宽比；它是 fixed checkpoint 的输入分布事实，不是一般最优选择。替换 crop、分辨率、颜色空间或两路顺序都需要重新验证；相机、外参与部署图像源则由 Deployment 页面处理。

双视觉塔与 patch 合同

两座塔的输入大小和 patch size 都是 224 与 14，所以每边 224 / 14 = 16，共同网格为 16 × 16 = 256 patch。DINOv2 和 SigLIP 是并行路径，不是串联；它们最终必须保留相同 patch 数和顺序，才能按位置融合。

倒数第二层与输出 token

固定仓库和 fixed HF custom model 都通过 get_intermediate_layers 取 len(blocks)-2：DINOv2 取 index 22，SigLIP 取 index 25。DINO 内部 prefix token 参与视觉 attention，但输出端移除；SigLIP 的 pooling 也不进入这条 fixed intermediate path。两路送给 projector 的长度均为 256。

常见误读 fixed release 的准确口径
“使用最后一层特征” 取倒数第二个 block
“DINO 向 projector 输出 261 token” 261 是塔内中间长度，输出是 256 patch
“SigLIP pooling 参与融合” fixed intermediate path 不调用 pooling
“倒数第二层一定更适合机器人” 当前证据没有隔离出普遍因果贡献，结论为 unknown

固定实现接受的 timm 范围是 0.9.10、0.9.11、0.9.12 与 0.9.16；超出该版本集合时，terminal norm、prefix 处理与 monkey patch 行为不能从本页直接继承。

通道拼接与 projector 冲突

拼接发生在最后一维：[B,256,1024] ||feature [B,256,1152] → [B,256,2176]。如果沿 token 维堆叠会得到 512 个 token，那不是 fixed OpenVLA 路径。相同长度只是必要条件；同一 observation、相同网格、相同 raster 顺序和一致 crop/几何映射也必须成立。

fixed fused projector 执行：Linear 2176→8704、GELU、Linear 8704→4096、GELU、Linear 4096→4096，所以输出与 Llama hidden width 对齐为 [B,256,4096]。

架构结论与动作表示入口

  1. fixed OpenVLA 将两座等网格视觉塔的 patch features 沿特征维拼接，而不是沿 token 维堆叠。
  2. fixed fused projector 把 2176 维 patch 映射为 4096 维 Llama embedding，执行三个 Linear；论文的 2-layer 描述作为未消解差异保留。
  3. 256 个视觉 token 插在首 token 后，与文本和输出共同接受一维因果 attention；视觉 label -100 不会移除其 hidden state。
  4. 架构只交出完整词表 logits；哪些 token 表示动作、如何归一化、量化与反量化，都由 Action Tokenizer 定义。

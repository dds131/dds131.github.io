前五个子页动的都是学习这一侧。本页动的是探索：把可学习的噪声直接加进网络权重，用它取代 \(\varepsilon\)-贪心。

这项改进真正的分量不在「加噪声」三个字上——\(\varepsilon\)-贪心也是加噪声。差别在于噪声加在哪一层、以及它在时间上是否连贯。

+48%DQN 中位人类归一化分数的相对提升
p + q因子化方案的噪声变量数，独立方案是 pq + q
≈ ×2每个被替换的线性层参数量
不一定σ 是否随训练衰减
本页重点。必须精读的是两节：「探索形态的差别」讲清一次权重扰动为何能产生 ε-贪心给不了的东西；「σ 到底怎么变」给出论文的实测结论，它推翻了一个流行的说法——σ 并非总是衰减，智能体也不必然演化向确定性解。

另有两条容易被想当然写错、本页特意标出的事实：选择因子化噪声的理由是计算开销而非统计优势；以及论文自己承认性能提升中的探索成分与优化成分尚未被分离。

探索形态的差别

\(\varepsilon\)-贪心的做法是：在动作层上，每一步以概率 \(\varepsilon\) 进入随机分支。常见实现让各步的随机抽样彼此独立，并在随机分支中按与状态无关的均匀分布选动作；但完整策略并非状态无关，因为另外 \(1-\varepsilon\) 的贪心分支仍由状态决定。

NoisyNet 的核心洞察正是冲着这两点来的。论文的原话是：

对权重向量的一次改变，可以在多个时间步上引起一致的、并且可能非常复杂的、状态相关的策略变化——这与抖动式方法不同，后者在每一步都向策略加入去相关的噪声（就 ε-贪心而言，还是状态无关的）。

换个说法：\(\varepsilon\)-贪心每步重新决定是否进入随机分支；NoisyNet 的一次采样则决定一整套权重，在下一次重采样之前形成一致、状态相关的随机化价值函数。持续多久由算法协议决定：原论文的 DQN 每个动作步都做一次优化，因此每个动作前都会重采样；A3C 才在整个 \(n\) 步 rollout 内固定同一份噪声。

图表达的是潜在的时间一致性，不是“DQN 中一份噪声固定整局”。原论文 NoisyNet-DQN 因每个动作步恰有一次优化而在每个动作前重采样；NoisyNet-A3C 才把同一噪声固定在整个 rollout。参数噪声可提高多步探索的一致性，但不构成深度探索或高效到达稀疏奖励状态的普遍保证；ε-贪心也并非到不了，只是连续随机动作的概率可能很小。

噪声线性层

普通全连接层是 \(y = wx + b\)。噪声层把权重与偏置都替换成带参数的零均值噪声扰动：

\[w = \mu^{w} + \sigma^{w} \odot \varepsilon^{w}, \qquad b = \mu^{b} + \sigma^{b} \odot \varepsilon^{b}\]

于是输出为

\[y = \big( \mu^{w} + \sigma^{w} \odot \varepsilon^{w} \big) x + \big( \mu^{b} + \sigma^{b} \odot \varepsilon^{b} \big)\]

其中 \(\mu^{w}, \mu^{b}, \sigma^{w}, \sigma^{b}\) 是网络的可学习参数，\(\varepsilon^{w}, \varepsilon^{b}\) 是噪声随机变量，\(\odot\) 是逐元素乘。这里的 \(\sigma\) 更准确地说是可学习噪声尺度，不是扰动的方差本身：实际方差还取决于 \(\sigma^2\) 与噪声分布的二阶矩。论文把它称为 variance parameter，但并未施加非负约束，后文也用 \(\lvert\sigma\rvert\) 衡量噪声强度。

这里有一个常被忽略的代价：每个被替换的线性层都为权重与偏置各增加一套 $$\sigma$$，所以这些层的可学习参数量约翻倍；若只替换网络末端，整个网络并不会翻倍。$$\sigma$$ 与 $$\mu$$ 一起用强化学习损失的梯度学习——这正是“参数化噪声”中“参数化”的含义。

两种噪声方案

论文给了两种统计结构不同的方案：独立方案为每个参数单独采样，因子化方案让多个权重共享输入/输出噪声因子，因此权重噪声之间相关。论文在 DQN 与 Dueling 中选择因子化方案的主要理由是降低随机数生成开销，而不是证明它在统计上更优。

方案 构造 噪声变量个数
独立高斯 每个权重、每个偏置各用一个独立的单位高斯 \(pq + q\)
因子化高斯 每个输入一个、每个输出一个，再相乘 \(p + q\)

（\(p\) 为该层输入数、\(q\) 为输出数。）

因子化的构造是：

\[\varepsilon^{w}_{j,i} = f(\varepsilon^{\mathrm{out}}_j)\, f(\varepsilon^{\mathrm{in}}_i), \qquad \varepsilon^{b}_{j} = f(\varepsilon^{\mathrm{out}}_j)\]

其中 \(f\) 是实值函数，论文实验中取

\[f(x) = \operatorname{sgn}(x)\sqrt{\lvert x \rvert}\]

论文补了一句：偏置那一式本来可以取 \(f(x) = x\)，但他们决定让权重与偏置使用相同的输出噪声。

为什么用因子化？这一条极易被写成「统计上更好」，但论文给的理由是计算。原文说：使用因子化高斯噪声的主要理由是减少算法中随机数生成的计算时间；这项开销对 DQN、Dueling 这类单线程智能体尤其难以承受。

因此论文的选择是：DQN 与 Dueling 用因子化噪声，异步多工作线程的 A3C 用独立噪声——后者的随机数生成时间不是主要瓶颈。换言之，这是一个工程取舍，不是理论优劣。

梯度与噪声重采样

先补一个记号：把上一节那些可学习参数打包记作

\[\zeta \;\equiv\; (\mu,\ \Sigma)\]

其中 \(\mu\) 是全部均值参数、\(\Sigma\) 是全部可学习噪声尺度（即前面的 \(\mu^{w},\mu^{b}\) 与 \(\sigma^{w},\sigma^{b}\)）。带噪参数本身则记作 \(\theta = \mu + \Sigma \odot \varepsilon\)。优化是对 \(\zeta\) 做的，不是把某一次抽到的 \(\theta\) 当成持久参数直接学习。

噪声网络的损失是对噪声取的期望 \(\bar{L}(\zeta) = \mathbb{E}[L(\theta)]\)，因此梯度可以直接写出：

\[\nabla \bar{L}(\zeta) = \nabla \mathbb{E}[L(\theta)] = \mathbb{E}\big[ \nabla_{\mu, \Sigma} L(\mu + \Sigma \odot \varepsilon) \big]\]

在满足可微与可交换梯度、期望等常规条件时，实践中用蒙特卡洛近似，每一步优化只取单个噪声样本 \(\xi\)：

\[\nabla \bar{L}(\zeta) \approx \nabla_{\mu, \Sigma} L(\mu + \Sigma \odot \xi)\]

重采样的时机很明确：

噪声网络智能体在每一步优化之后采样一组新的参数。在两次优化步之间，智能体按一组固定的参数（权重与偏置）行动。这保证了智能体总是按从当前噪声分布中抽出的参数来行动。

“不要每次前向都重采样”不是完整规则，关键是按用途与算法边界采样。原论文的 NoisyNet-DQN 在一个回放批次内固定噪声，但为在线损失网络、目标网络和行为动作各抽一份相互独立的噪声；作者明确说这样可避免在线与目标噪声相关带来的偏差。因为该实验每个动作步恰做一次优化，所以行为噪声也在每个动作前更新，而不是固定整段轨迹。

在 on-policy A3C 中，同一份噪声才被固定在整个 $$n$$ 步 rollout，以保持该 rollout 内策略一致并获得论文所需的无偏梯度。若工程实现改成“每 $$K$$ 个环境步更新一次”，相干长度也随之变为最多 $$K$$ 步；这属于协议变化，必须记录。

训练与评估协议检查

  1. 行为动作：为在线网络抽一份行为噪声，用随机化 \(Q\) 的贪心动作，不再叠加 \(\varepsilon\)-贪心。
  2. 回放更新：在线损失网络与目标网络各用一份新的独立噪声；同一批次内固定。原论文的 Dueling 版本采用 Double-DQN 型目标，还为下一状态的动作选择再抽一份在线网络噪声。
  3. 独立性不是装饰：行为、当前值、目标值，以及 Dueling 的目标动作选择，必须按所实现的公式区分；不能因共用一个 online 对象而无意复用噪声。
  4. 目标同步：复制整个网络的可学习参数，包括普通层参数和噪声层的 \(\mu,\sigma\)；\(\varepsilon\) 缓冲不是学到的模型知识，同步后应重新抽样。直接复制包含持久 buffer 的完整 state_dict 可能把当前噪声也复制过去。
  5. 评估：原论文报告了随机 no-op、定期暂停学习等协议，却没有把“统一关闭噪声”写成 NoisyNet 的定义。实现必须明确是保留随机策略、多次独立采样汇总，还是令 \(\varepsilon=0\) 使用 \(\mu\)；三者不可混报。自定义 NoisyLinear 的 model.eval() 也不会自动关闭噪声，除非代码显式规定。

初始化

两种方案的初始化不同，不能混用：

方案 \(\mu_{i,j}\) 的初始化 \(\sigma_{i,j}\) 的初始化
未因子化 \(\mathcal{U}\big[-\sqrt{3/p},\, +\sqrt{3/p}\big]\) 常数 \(0.017\)
因子化 \(\mathcal{U}\big[-1/\sqrt{p},\, +1/\sqrt{p}\big]\) \(\sigma_0 / \sqrt{p}\)，其中 \(\sigma_0 = 0.5\)

这里的 \(p\) 是相应线性层的输入数。论文第 3.2 节用统一的“每个元素”叙述初始化，没有另列偏置的分母；下面的代码因此让权重和偏置都按该层输入数 \(p\) 缩放。若要复现某个使用 \(\sqrt q\) 初始化偏置尺度的库，应把它记录为库的实现约定，不能反写成论文明确给出的独立公式。

论文对未因子化那个 \(0.017\) 的来历是坦白的：它取自此前一篇监督学习工作中效果不错的相近取值，并且没有对这个参数做过调优——作者认为同一量级上的不同取值应当给出相似结果。

可执行的因子化层

下面这个因子化层把“重采样”做成显式方法，避免每次 forward 偷偷换噪声：

import math
import torch
from torch import nn
from torch.nn import functional as F


class NoisyLinear(nn.Module):
    def __init__(self, in_features, out_features, sigma0=0.5):
        super().__init__()
        if not isinstance(in_features, int) or in_features <= 0:
            raise ValueError("in_features must be a positive integer")
        if not isinstance(out_features, int) or out_features <= 0:
            raise ValueError("out_features must be a positive integer")
        if not math.isfinite(sigma0) or sigma0 < 0:
            raise ValueError("sigma0 must be finite and non-negative")
        self.in_features = in_features
        self.out_features = out_features
        self.weight_mu = nn.Parameter(torch.empty(out_features, in_features))
        self.weight_sigma = nn.Parameter(torch.empty(out_features, in_features))
        self.bias_mu = nn.Parameter(torch.empty(out_features))
        self.bias_sigma = nn.Parameter(torch.empty(out_features))
        # epsilon 会随设备移动，但不进入 state_dict，避免目标同步/检查点把一次噪声当成知识。
        self.register_buffer(
            "weight_epsilon", torch.empty(out_features, in_features), persistent=False
        )
        self.register_buffer("bias_epsilon", torch.empty(out_features), persistent=False)

        bound = 1.0 / math.sqrt(in_features)
        nn.init.uniform_(self.weight_mu, -bound, bound)
        nn.init.uniform_(self.bias_mu, -bound, bound)
        sigma_init = sigma0 / math.sqrt(in_features)
        nn.init.constant_(self.weight_sigma, sigma_init)
        nn.init.constant_(self.bias_sigma, sigma_init)
        self.reset_noise()

    @staticmethod
    def _scaled_noise(size, device, dtype):
        x = torch.randn(size, device=device, dtype=dtype)
        return x.sign() * x.abs().sqrt()

    @torch.no_grad()
    def reset_noise(self):
        eps_in = self._scaled_noise(
            self.in_features, self.weight_mu.device, self.weight_mu.dtype
        )
        eps_out = self._scaled_noise(
            self.out_features, self.weight_mu.device, self.weight_mu.dtype
        )
        self.weight_epsilon.copy_(eps_out.outer(eps_in))
        self.bias_epsilon.copy_(eps_out)

    def forward(self, x, use_noise=True):
        if use_noise:
            weight = self.weight_mu + self.weight_sigma * self.weight_epsilon
            bias = self.bias_mu + self.bias_sigma * self.bias_epsilon
        else:
            weight, bias = self.weight_mu, self.bias_mu
        return F.linear(x, weight, bias)

训练时不能只笼统地对 online/target 各调用一次：普通 NoisyNet-DQN 至少要区分行为、在线损失和目标三种用途；若按论文的 Dueling/Double 目标实现，还要给目标动作选择单独的在线噪声。上面把 \(\varepsilon\) buffer 设为 persistent=False，所以参数同步与 checkpoint 不会携带某一次随机样本；加载或同步后应调用 reset_noise()。评估时显式传 use_noise=False 才是确定性均值网络，不能假设 .eval() 会替你完成。

同一个 online 模块的安全更新顺序。先在 `torch.no_grad()` 下重采样 online，计算并缓存下一状态的动作选择；再独立重采样 target，计算并缓存目标值。随后才为 online 当前值重采样，完成带梯度前向、损失和 `backward()`，在反向传播结束前不要再次原地改写该模块的 $$\varepsilon$$ buffer。优化和可选的目标同步完成后，再重采样行为噪声用于下一次环境动作。这样既满足用途间独立，又避免 PyTorch 因前向保存的噪声张量被原地修改而报版本错误或产生错误梯度。普通 DQN 没有 Double 目标的在线动作选择步骤，可省去第一步。

σ 到底怎么变：实验不支持“必然衰减”

很多二手材料会说“\(\sigma\) 必然自动衰减，于是探索强度会自适应退火”。论文对 5 个所选 Atari 游戏、两个末端层的观测不支持这个全称说法；但这组结果也不能反过来证明所有任务中的 \(\sigma\) 都会上升或保持非零。

论文定义了一个刻画噪声层随机性的量——某层 \(\sigma^{w}\) 的平均绝对值：

\[\bar{\Sigma} = \frac{1}{N_{\text{weights}}} \sum_i \big\lvert \sigma^{w}_i \big\rvert\]

然后在若干 Atari 游戏上跟踪它随训练的变化（3 个随机种子取平均）。结论分两层：

位置 实测结果
最后一层 \(\bar{\Sigma}\) 在所有情况下都随学习进行而下降
倒数第二层 只有 5 个游戏里的 2 个（Pong 与 Beam rider）下降，其余 3 个反而上升

论文据此得出的、限定在该 NoisyNet-DQN 实验内的结论是：智能体不一定演化到确定性解。这不是对所有层、游戏或训练配置的普遍保证。

论文还观察到：\(\bar{\Sigma}\) 的轨迹在游戏之间、某些情况下在随机种子之间也明显不同。作者的措辞本来就是对称的——训练可按需把噪声水平压下去或抬上来。所以准确表述是“可学习、任务相关地调节”，而不是“必然自适应衰减”。

实验结果

先看数字的统计口径，否则很容易把“最好检查点”误读成最终性能。论文在 57 个 Atari 游戏上比较对应基线与 NoisyNet 版本，使用 3 个随机种子；每 100 万环境帧暂停学习并评估 50 万帧，单回合最多 10.8 万帧。原文报告 DQN 与 A3C 分别训练 2 亿和 3.2 亿帧。每个游戏用于最大分数汇总的值，是训练过程中评估到的最大原始分数再对 3 个种子取平均；因此它不是“最后一次评估分数”。这些设置支持同一算法内部的 baseline/NoisyNet 对照，不支持只看表中绝对数值就断言 DQN、Dueling 与 A3C 谁更优。

智能体 基线均值 基线中位数 NoisyNet 均值 NoisyNet 中位数 中位数上的相对提升
DQN 319 83 379 123 48%
Dueling 524 132 633 172 30%
A3C 293 80 347 94 18%

按表题和算术定义的“中位数相对提升”计，NoisyNet-DQN、Dueling、A3C 分别为 48%、30%、18%：例如 \((123-83)/83\approx48\%\)。它们不是“48、30、18 个百分点”。原始中位人类归一化分数的绝对变化分别是 83→123、132→172、80→94，即 +40、+40、+14 个分数点。论文正文把 18–48 写成 percentage points，与同页表题和数值计算不一致；页面应以可复算的表格定义为准。三种智能体的跨游戏均值也都提高；论文文字使用了 “significantly improved”，但相邻表格和正文未报告显著性检验方法、置信区间或 \(p\) 值，不能据此补写统计显著性结论。

论文把 Dueling 上仍有增益解释为 NoisyNet 与若干 DQN 改进“正交”。更谨慎地说，这一行提供的是在受测配置中的可组合性证据：NoisyNet-Dueling 的中位数相对基线提高 30%。单项聚合结果不能证明统计独立、机制无交互，也不能保证与任意组件叠加都增益。Dueling 本身见子页②。

论文自己划出的一条限定

论文明确写道：性能的改善也可能来自优化层面，因为代价函数被改动了；虽然 NoisyNet 引入的参数不确定性是该方法唯一的探索机制，但要把探索效应与优化效应分离开，还需要进一步的分析。

这句限定值得照抄。它意味着我们不能把 Table 1 的提升全部归因于「探索变好了」——至少在这篇论文里，这件事没有被实验分离。

与几种相近方法的界线

对照方法 差别
变分推断类 \(\mu,\sigma\) 定义的是采样规则；NoisyNet 不维护显式权重后验，也不优化带先验 KL 的变分目标
Thompson 采样 参数噪声分布不必然收敛到后验近似，所以不能把 \(\sigma\) 当成校准后的认知不确定性
Bootstrapped DQN 同属随机化值函数，但后者需要网络若干部分的多份副本；NoisyNet 不需要

NoisyNet 移除了 \(\varepsilon\) 调度或 A3C 熵奖励系数的那套探索超参数，但并没有让探索“零超参”：仍需选择噪声层位置、\(\sigma_0\)、重采样频率与评估策略。它的探索可依上下文而变，因为同一份参数扰动会经状态特征产生不同动作值变化。熵正则路线见 SAC。

小结与出口

  • NoisyNet 把随机性从动作层移到参数层；时间一致性由重采样协议决定。原论文 DQN 每动作一步一更新、因而每个动作前重采样；A3C 才固定整个 rollout。
  • 被替换的噪声层把 \(w,b\) 换成 \(\mu+\sigma\odot\varepsilon\)，这些层的可学习参数约翻倍；整个网络是否翻倍取决于替换范围。
  • 因子化方案把噪声变量从 \(pq+q\) 降到 \(p+q\)，理由是随机数生成开销；这不是统计优势定理。
  • 行为、在线损失、目标，以及 Dueling/Double 目标中的动作选择，应按所实现的公式独立采样；一个回放批次内固定。目标同步复制可学习参数，不应复制一次性的 \(\varepsilon\)。评估是否保留噪声也必须显式记录。
  • 在论文所选 5 局中，最后一层 \(\bar\Sigma\) 都下降，倒数第二层有 3 局上升；这反驳“必然衰减”，但不是跨任务定理。
  • 表中 18%–48% 是中位数的相对提升而非百分点；Dueling 结果说明受测配置可组合，但探索与优化效应仍未分离。

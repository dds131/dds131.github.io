知识库/机器人模仿学习与 VLA/ACT/Attention 内部机制

ADVANCED ENGINEERING · Q/K/V → MASK → RESIDUAL → NORM

本页的唯一任务：定位 ACT 每次 attention 的 Q/K/V 来自哪里、原始位置编码在哪里直接注入、哪些 mask 实参真正生效。

可跳过：这是高级工程页，不属于 ACT 核心学习路线。可从 Network 主线进入，也可从 Network Analysis 可选分支合流；两条前驱看到同一正文，唯一后继都是 Reproduction。</div>

CVAE ENCODER SELFQ=K=encoder_input+pos_tableV=encoder_input；唯一有效 padding mask 为 [False,False,is_pad...]。
MAIN ENCODER SELFQ=K=src+posV=src；latent/proprio可学习位置与视觉二维正弦位置拼接；mask=None。
DECODER SELFQ=K=tgt+query_posV=tgt；tgt_mask=None，H 个 query slot 可相互注意。
DECODER CROSSQ=tgt+query_posK=memory+pos，V=memory；query 长 H，key/value 长 S。
前驱 A：Network前驱 B：Network Analysis（可选合流）下一步：Reproduction

计数口径：四个运行上下文只落在三个源码 MHA 调用点：encoder layer 一个调用点被两种 encoder 容器复用，decoder layer 内有 self/cross 两个调用点；不能写成四套独立实现。</div>

阅读门槛锚点

阅读门槛与最小 Attention 先修

只需要三条先修：Attention 按 softmax(QKᵀ/√d_h)V 聚合 value；self-attention 的 Q/K/V 来自同一序列，cross-attention 的 query 与 key/value 来自不同序列；固定配置把 512 维分成 8×64。本页不证明通用公式，也不要求先读参数量、MAC、显存或梯度分析。

2 分钟术语对齐
Q · query当前位置要查找什么；决定输出行数 L_q。
K · key每个可被检索位置的匹配键；长度 L_k。
V · value按注意力权重聚合的内容；长度与 K 对齐。

attn_mask 屏蔽 query-key 位置对；key_padding_mask 屏蔽 key 位置并对所有 query 生效。布尔 True 在本页固定接口中表示 masked/padding。

学习产出固定为三件：一张四行 Q/K/V 来源表、一张六行 mask 实参表，以及从固定源码定位 with_pos_embed、三个 attention 调用点和两种不同 [0] 的能力。完整 token 组织沿用 Network，架构意图沿用 Transformer。

MHA 合同锚点

seq-first、MHA 与四个运行上下文

固定实现没有覆盖 batch_first，因此按 PyTorch 2.0.0 默认使用 seq-first。固定 MHA 合同是 d_model=512、nheads=8、d_head=64、batch_first=False、dropout=0.1、bias=True、add_bias_kv=False；FFN 激活为 ReLU，宽度为 512→3200→512。8 heads 是同一序列的通道分头，不是 8 套独立输入。

Seq-first 输入合同：第一维始终是序列长度
上下文 Q 长度 K/V 长度 输入布局
CVAE encoder self H+2 H+2 [H+2,B,512]
主 encoder self S=2+300K S [S,B,512]
decoder self H H [H,B,512]
decoder cross H S Q [H,B,512]；K/V [S,B,512]

nn.MultiheadAttention 返回二元组 (attn_output, attn_output_weights)。三个源码调用都用 [0] 取得 tuple 第一项并丢弃权重；这与 DETRVAE.forward 从 [7,B,H,512] decoder 层堆栈取 hs[0] 完全不同。前者不是第 0 个 head，后者也不是 tuple 解包。

PyTorch 2.0.0 默认 need_weights=True、average_attn_weights=True，理论返回的平均权重为 [B,L_q,L_k]；但调用者没有保存第二项，所以本站没有现成 attention 热图。未来逐头观察必须另行冻结软件版本、average_attn_weights、模式、随机性和样本，当前状态为 NOT_RUN。

QKV 总表锚点

ACT 的 Q/K/V 与位置编码总表

固定提交 Q/K/V 来源与实际 padding mask
上下文 Query Key Value 位置来源 有效 padding mask
CVAE encoder self encoder_input+pos_table 同 Q encoder_input 固定正弦 pos_table [False,False,is_pad...]
主 encoder self src+pos 同 Q src 两个特殊 token 可学习位置 + 视觉二维正弦 无
decoder self tgt+query_pos 同 Q tgt 可学习 action query 无
decoder cross tgt+query_pos memory+pos memory action query 对 memory 位置 无

准确边界是：原始位置编码在本次 attention 调用中直接进入 Q/K 输入，不直接进入 V 输入。不能把它简化成“V 永远不含位置信息”，因为深层 src/tgt/memory 已受前层位置相关计算影响，位置还会经注意力权重间接影响加权结果。decoder 每层都重新接收同一 query_pos 与 pos，不是只在入口相加一次。

Encoder Attention 锚点

两个 encoder 的 self-attention

两种 encoder 都由 4 层 TransformerEncoderLayer 组成，但容器和参数独立，不共享权重。它们的目的、序列、位置和 mask 完全不同。

同层类、不同序列合同
维度 CVAE posterior encoder 主 encoder
目的 从 qpos 与目标 actions 推断 posterior 融合 latent、proprio 与视觉 token
序列 [CLS,qpos,actions_0...actions_(H-1)] [latent,proprio,visual_0...visual_(300K-1)]
长度 H+2 2+300K
Q/K 位置 固定 pos_table 两个可学习位置 + 视觉二维正弦
Key padding mask 前两列 False，后接 is_pad None
容器末尾 norm 默认 None 默认 None

默认 post-norm 单层按七步前进：Q/K 加位置 → self-attention → attention 输出 dropout + residual → norm1 → 512→3200→512 FFN（内部含 dropout）→ FFN 输出 dropout + residual → norm2。单层不改变序列长度和 512 特征维。CVAE mask 只把 padding actions 屏蔽为 key；CLS 和 qpos 的前两列强制为 False。主 encoder 不继承该 mask。

Decoder Attention 锚点

decoder 的 self-attention 与 cross-attention

第一层的 tgt 全零。在 eval 且关闭 dropout 时，self-attention 的 V 沿 H 个 query 位置相同；每行 softmax 权重和为 1，因此该子层给各位置相同的共享输出。query_pos 的确定性位置分化主要在随后 cross-attention 读取 memory 时出现。训练模式下，attention-weight dropout 与残差 dropout 会破坏单次前向的逐位置精确相等，不能把 eval 推导无条件套到 train。

固定 decoder 输出堆栈为 [7,B,H,512]，DETRVAE.forward 使用 hs[0]，动作头只读取第 0 个 decoder layer。这里只陈述固定版本事实，不猜测设计意图；后六层的参数、任务梯度与算力后果由 Network Analysis 核验。

Mask 追踪锚点

六个 mask 形参与实际取值

固定标准调用：唯一非 None 的 attention mask 实参是 CVAE key-padding mask
形参 主 encoder 主 decoder CVAE encoder
src_mask / encoder mask None 不适用 None
src_key_padding_mask None 不适用 [False,False,is_pad...]
tgt_mask 不适用 None 不适用
memory_mask 不适用 None 不适用
tgt_key_padding_mask 不适用 None 不适用
memory_key_padding_mask 不适用 None 不适用

attn_mask 按 query-key 位置对屏蔽，key_padding_mask 按 key 位置屏蔽并对所有 query 生效；布尔 True=masked/padding。decoder 四个 mask 都是 None，尤其没有 tgt_mask，所以 H 个 action query 之间没有方向性或 causal mask，支持并行解码。

“并行解码”不等于动作位置统计独立：decoder self-attention 本来允许 query-query 交互；固定提交又只把 hs[0] 送入动作头，必须与完整多层 decoder 的一般能力分开讨论。

Norm Dropout 锚点

post-norm、dropout 与固定版本边界

官方默认命令不启用 --pre_norm，所以三个 Transformer 容器走 post-norm；源码仍支持显式 pre-norm。两种残差顺序是：post-norm: x ← LN(x + Dropout(f(x)))；pre-norm: x ← x + Dropout(f(LN(x)))。本页不判断哪一种普遍更优，也不把小学习率与 post-norm 建立未经消融的因果关系。

容器末尾 norm主 encoder 与 CVAE encoder 的容器末尾 norm 默认 None；主 decoder 有共享 decoder_norm，并作用于返回的中间层输出。
三类 dropout 位置MHA 内部 dropout 作用于 softmax 后的 attention weights；dropout1/2/3 位于子层输出到残差相加之间；FFN 内另有一次 dropout。
初始化边界主 Transformer 在 clone 后执行 _reset_parameters；CVAE encoder 不经过这次重置。这里只记实现差异，不推断性能或作者动机。

dropout 的“数量”只有先定义口径才有意义：MHA 权重 dropout、残差支路 dropout 与 FFN 内 dropout 不是同一个位置。PyTorch、ACT 和 DETR 的初始化细节也必须锁定版本；逐层参数独立性与训练后分化归 Network Analysis。

代码调试锚点

代码映射、调试观察与下一步

问题 → 稳定符号 → 静态期望 → 常见误判
问题 固定符号 静态期望 常见误判
Q/K 为什么含位置 with_pos_embed 三处调用的 Q/K 显式相加 误写成 V 也直接加原始 pos

未来动态观察必须登记固定 commit、PyTorch 版本、train/eval 模式、随机 seed、B/K/H、hook 路径、预期 shape、容差与输出去向，统一标为 NOT_RUN。当前只做静态追踪，没有 import/实例化 ACT 模型、注册 hook 或生成 attention 热图。

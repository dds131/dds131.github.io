VLA 模型家族/X-VLA 总览/① 网络架构与 Token 组织

ARCHITECTURE ① · TENSOR CONTRACT · FIXED RELEASE INSTANCE

X‑VLA 把动作、主视角图文、辅助视角与域提示组织成一个双向序列；默认发布配置的 262 个 token 是 30 + 100 + 100 + 32 的实现实例，不是方法本身不可改变的长度。

4 input streams控制、主视角图文、辅助视觉与显式域条件。
50 tokens / view224 输入经 7×7 空间网格与两种池化推导。
230 + 32 = 262位置表只覆盖 prompt 前 230 个普通 token。
[B,30,20]固定实例的动作块输出；不是运行时 policy ABI。

执行边界：本页是静态结构审计，不颁发运行时 I/O 合同；未 import 模型、加载权重、训练、推理、启动服务、评测、仿真、SIL/HIL 或操作机器人。

四路输入与汇合顺序

四条流最终按 action → VLM → auxiliary visual → soft prompt 排列。动作段必须在最前，因为输出直接切 x[:, :num_actions]；即使主干使用全双向注意力，前三段仍有绝对位置编码，不能任意换序。

1 · 控制流 · 私有边界含噪动作、proprioception、时刻在通道维拼成 72 维，经 domain_id 选择的输入投影形成 30 token。
2 · 主视角图文 · 共享第 0 路图像 50 token 与文本 50 token 进入 Florence language encoder，形成 100 token。
3 · 辅助视觉 · 共享第 1、2 路各 50 token，复用完整 Florence 图像路径，但绕过 language encoder。
4 · 域条件 · 私有domain_id 查出 32×1024 Soft Prompt，并同时选择动作输入、输出矩阵。

每路 50 个视觉 Token

固定公开训练路径使用 224×224 单帧输入。卷积单边输出通式为 n_out=floor((n_in+2p-k)/s)+1；按 patch_size=[7,3,3,3]、stride=[4,2,2,2]、padding=[3,1,1,1] 逐层计算：

空间边长224 → 56 → 28 → 14 → 7
DaViT unpool7×7 = 49 positions
[B,49,2048]
两种池化spatial average = 1
temporal average = 49
拼接与投影1+49=50
2048→1024
N_v = T + H_s × W_s；默认 N_v = 1 + 7 × 7 = 50。

_encode_image 对非四维输入抛异常，所以固定路径只支持单帧。T=1 时 temporal average 没有跨帧聚合，但池化前已加入 Florence 的二维图像位置与 temporal 表示；这些 token 不是“无位置信息的裸 DaViT 平均”。50 是当前分辨率、stride、池化源和单帧路径共同产生的实例值，不是方法常数。

主辅视角共享与分流

pixel_values:[B,V,3,H,W] 先把 B,V 展平，有效图像在一次 self.vlm._encode_image 调用中处理，再还原到 [B,3,50,1024]。共享范围包括 DaViT、图像位置/时间表示、池化、image_projection 和 image_proj_norm，不是只共享 DaViT。

共享前端[B×3,3,224,224] → 同一 Florence 图像路径 → [B,3,50,1024]
主视角 index 0与 50 个文本 embedding 拼接，进入 12 层 language encoder，输出 [B,100,1024]。
辅助视角 indices 1,2绕过 language encoder，直接 reshape 成 [B,100,1024]。

缺失视角与占位边界

少于三路视角时，处理器补零并创建长度为 3 的 image_mask。该 mask 只跳过无效图像的视觉编码；相应的 50-token 槽位随后回填为零，但 mask 不会传入 24 层动作 Transformer。

占位不等于消失：辅助占位经过带 bias 的 aux_visual_proj 并加动作主干位置编码后通常不再为零，仍占固定位置并参与全注意力。它可能成为可学习占位模式，也会增加计算；两种效果均未被专门消融。

configured_views: 3
processor_behavior: zero-pad-to-three
image_mask_scope: {skips-vision-encoder: true, masks-action-transformer: false}
placeholder_tokens_per_missing_view: 50
post_projection_zero_guarantee: false

固定 forward_vlm 主要检查整个 batch 至少存在一个有效视角，而不是逐样本检查。接入侧应增加 image_mask.any(dim=1) 的逐样本断言；这是迁移建议，不冒充当前源码行为。处理器也没有安全截断多余视角；扩相机需同步处理器、mask、主视角语义、辅助 reshape 和序列容量。

72 维控制流与时间嵌入

固定实例中，含噪动作为 [B,30,20]；proprioception [B,20] 和时间 embedding [B,32] 都广播到 30 个动作位置，再沿通道维拼接为 [B,30,72]。状态与时间不额外占 token。

20（含噪动作）+ 20（proprioception）+ 32（时间嵌入）= 72；DomainAwareLinear：72 → 1024。

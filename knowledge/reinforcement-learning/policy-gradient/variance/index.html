定理保证了梯度估计量在期望意义上是对的。本页处理的是另一半问题：这个估计量单次采样能有多不准。策略梯度全部的训练困难都来自这里，而整条策略类算法的演进史，很大程度上就是一部降方差史。

3方差的来源
2不引入偏差的降方差手段
1/N批量平均后方差的衰减率
2018动作相关基线被证伪的年份
本页重点。必须精读的是三节：「无偏不等于可用」把两个常被混为一谈的性质形式化地分开；「基线的完整无偏性证明」是全站唯一的完整版本，其中为什么 b 不能依赖动作决定了 Actor-Critic 的全部合理性边界；「最优基线的闭式解」说明一个几乎所有中文材料都写错的结论——最优基线并不是状态价值函数。

可以略过的是：「方差怎么随时域增长」一节里的定量推导（结论记住即可）、「参数空间探索」一节（它是对照材料，不是本专题的主线）。本页符号沿用专题枢纽页。

本页要解决什么问题

策略梯度定理给出

\[\nabla_\theta J(\theta) \;=\; \mathbb{E}\left[ \sum_{t} \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, \Psi_t \right]\]

实际算法用 \(N\) 条轨迹的样本平均来估计它：

\[\hat{g} \;=\; \frac{1}{N} \sum_{i=1}^{N} \sum_{t} \nabla_\theta \log \pi_\theta\big(a_t^{(i)} \mid s_t^{(i)}\big)\, \Psi_t^{(i)}\]

定理保证 \(\mathbb{E}[\hat{g}] = \nabla_\theta J(\theta)\)。本页要回答的是围绕 \(\mathrm{Var}[\hat{g}]\) 的六个问题。

  • 方差从哪来。 有三个独立的随机性来源，它们沿时间累加。
  • 为什么无偏不救场。 无偏是关于均值的陈述，它对单次采样的偏离幅度不作任何承诺。
  • 两种不引入偏差的降方差手段各自做了什么。 因果性与基线，两者的证明结构相同。
  • 最优的基线是什么。 答案不是 \(V(s)\)，而实践中用 \(V(s)\) 是有理由的。
  • 哪些看起来像基线的东西其实不是。 除以标准差、动作相关基线，两者都不受无偏性定理保护，但性质完全不同。
  • 方差怎么量化。 不能只靠看训练曲线抖不抖。

高方差的三个来源

梯度估计量的随机性来自三个独立的地方。分清它们，才能判断某一项降方差手段究竟压住了哪一部分。

来源一：策略自身的随机性

同一个状态 \(s_t\)，策略每次可能采出不同的动作。这带来两重随机：采到哪个动作，以及该动作的得分函数 \(\nabla_\theta \log \pi_\theta(a_t \mid s_t)\) 取什么值。

这一项是策略梯度必须付出的代价——探索正是靠它，把它压到零就等于放弃探索。熵正则与降方差在这一点上是直接冲突的，这一冲突在子页 ③ 里展开。

来源二：环境的随机性

同一个 \((s_t, a_t)\)，环境可能给出不同的奖励与不同的后继状态。于是同一个状态动作对，在不同轨迹里得到的 \(G_t\) 可以差得很远。

这一项与策略无关，无法通过改进算法消除，只能通过多采样来平均掉。确定性环境里这一项为零，这也是为什么在确定性仿真里策略梯度往往比真机稳定得多。

来源三：初始状态的随机性

不同的 \(s_0\) 通向完全不同的轨迹分布。回合制任务里这一项常被低估——初始状态分布越宽，单条轨迹的代表性越差。

三者如何沿时间放大

真正的问题不在于每一步的随机性有多大，而在于它们沿时间累加。\(G_t\) 是从 \(t\) 到回合结束全部奖励的折扣和，这条路径上每一步的策略采样与环境转移都会改变它的取值。回合越长，累加进来的随机项越多。

一个具体的表现：同一个 \((s_t, a_t)\)，在一条后续运气好的轨迹里可能得到 \(G_t = 100\)，在一条后续走偏了的轨迹里可能得到 \(G_t = -20\)。乘上同一个得分函数向量之后，这两个样本给出的梯度方向截然不同。

信用分配：为什么一个标量要为几百个动作背锅

上一节最后那个现象有一个更根本的名字：信用分配问题。

问题的形式

朴素策略梯度用同一条轨迹的回报去加权这条轨迹上所有时间步的得分函数。因果性那一步把「整条回报」收缩成了「从该步起的回报」，但问题并没有消失：\(G_t\) 仍然是一个混合了该动作的效果与后续所有动作、所有环境随机性的标量。

于是会发生两件事：

  • 一个坏动作可能因为后续运气好而拿到正权重。 它被鼓励了，尽管它本身是错的。
  • 一个好动作可能因为后续犯了错而拿到负权重。 它被抑制了，尽管它本身是对的。

Berkeley CS285 用「一条轨迹最终赢了，不代表里面每一个动作都好」来概括这件事，非常贴切。

为什么这在理论上没问题、在实践中是大问题

理论上没问题：这些误判是零均值的。采样足够多时，同一个动作在各种后续情形下的权重会平均掉，剩下的正是它真实的价值。定理保证的就是这件事。

实践中是大问题：采样从来不够多。有限样本下，这些误判表现为梯度方向的剧烈抖动，而且抖动幅度随回合长度增长。

这正是后续算法的共同动机

把这条线索理清，后面一整串算法就不再是孤立的技巧：

  • 基线去掉「这个状态本身好不好」这部分与动作无关的成分。
  • 优势函数把权重变成「这个动作比该状态的平均水平好多少」，直接对准信用分配。
  • Critic 用一个学出来的估计替换蒙特卡洛回报，把后续随机性一次性吸收掉。
  • GAE 在「信任真实回报」与「信任 Critic」之间连续调节。

四者解决的是同一个问题的不同层面。本页讲前两者，后两者见 Actor-Critic 与 TRPO。

无偏不等于可用：把两件事形式化地分开

这是初学策略梯度时最容易误判的一点。

两个性质是独立的

无偏说的是

\[\mathbb{E}\left[ \hat{g} \right] \;=\; \nabla_\theta J(\theta)\]

方差说的是

\[\mathrm{Var}\left[ \hat{g} \right] \;=\; \mathbb{E}\left[ \left\| \hat{g} - \mathbb{E}[\hat{g}] \right\|^{2} \right]\]

这两个量之间没有任何约束关系。一个估计量可以无偏且方差极大，也可以有偏但方差极小。REINFORCE 是前者的典型，Critic 自举是后者的典型。

一个能把问题讲透的构造

考虑这样一个估计量：以概率 \(1 - p\) 取 \(0\)，以概率 \(p\) 取 \(c/p\)。它的期望恰好是 \(c\)，完全无偏。但当 \(p = 10^{-4}\) 时，跑一万次采样平均下来，多数情况下你得到的仍然是一堆 \(0\) 和偶尔一个巨大的 \(c \times 10^{4}\)。

这个估计量无偏，但用它做梯度下降是灾难。 策略梯度虽然不至于这么极端，但结构是同一个：它的取值分布高度不对称、长尾，均值被少数大样本主导。

批量平均能解决多少

\(N\) 条独立轨迹平均之后，方差按 \(1/N\) 衰减：

\[\mathrm{Var}\left[ \hat{g}_N \right] \;=\; \frac{1}{N}\, \mathrm{Var}\left[ \hat{g}_1 \right]\]

标准差按 \(1/\sqrt{N}\) 衰减。这意味着要把梯度的相对误差降低一个数量级，样本量要增加两个数量级。单靠加大批量来压方差，代价是不可接受的。

这正是降方差手段存在的理由：它们把 \(\mathrm{Var}[\hat{g}_1]\) 本身压下去，而不是靠堆样本。

判断一个降方差手段值不值得用，看的是它把方差压低的倍数，与它引入的偏差之间的权衡。因果性与基线是两个特例：它们的偏差恰好为零，因此是无条件该用的。从 Critic 开始，后面每一步降方差都要付偏差的代价，那才进入真正的权衡。

方差怎么随时域增长

这一节给出定量的直觉。结论比推导重要。

回报本身的方差

\(R(\tau) = \sum_{t=0}^{T-1} \gamma^{t} r_t\) 是 \(T\) 个随机量之和。若各项方差相当且相关性不强，

\[\mathrm{Var}\left[ R(\tau) \right] \;\sim\; \sum_{t=0}^{T-1} \gamma^{2t}\, \sigma_r^{2}\]

无折扣时这是 \(T \sigma_r^2\)，随 \(T\) 线性增长；折扣时它收敛到 \(\sigma_r^2 / (1 - \gamma^2)\)，也就是被有效时域截断。

梯度估计量的方差

梯度估计量里还有第二个求和号：

\[\hat{g}_1 \;=\; \left( \sum_{t} \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right) R(\tau)\]

两个 \(T\) 项的和相乘，方差与 \(T^{2}\) 同阶。换成 reward-to-go 形式之后，第 \(t\) 项只与 \(G_t\) 相乘而不是与整条回报相乘，去掉了大量交叉项，阶数降一级。

标准的说法是：在奖励有界等标准假设下，整轨迹回报形式的方差随时域超线性增长，reward-to-go 形式降一阶。具体的量级取决于回报的均值是否为零：若奖励均值不为零，\(\mathbb{E}[R^2]\) 本身就是 \(T^2\) 量级，乘上 \(T\) 项得分函数之和后可达 \(T^3\)；把均值用基线去掉之后才退到 \(T^2\)。Peters 与 Schaal 2008 的 Example 1 给出的正是「至少三次方」这一量级。

不要写成「方差正比于 \(T^2\)」这种无条件断言——它依赖独立性与有界性假设，不同文献给出的常数与形式并不一致。

降方差手段一：reward-to-go

因果性那一步的证明在子页 ① 已经给出，这里只说它在方差这条线上的意义。

它把权重从

\[R(\tau) \;=\; \underbrace{r_0 + \gamma r_1 + \dots + \gamma^{t-1} r_{t-1}}_{\text{与动作 } a_t \text{ 无关，期望贡献为零}} \;+\; \underbrace{\gamma^{t} r_t + \dots}_{\text{动作 } a_t \text{ 可能影响}}\]

收缩成只保留后半部分。去掉的是对期望没有贡献、对方差有贡献的成分——按 Spinning Up 的说法，别让过去干扰你。

需要严谨一点：「去掉一个零均值项一定降方差」不是无条件成立的命题。设估计量为 \(X + Y\)，其中 \(\mathbb{E}[Y] = 0\)，则

\[\mathrm{Var}[X + Y] - \mathrm{Var}[X] \;=\; \mathrm{Var}[Y] + 2\,\mathrm{Cov}[X, Y]\]

只有这个量为正时去掉 \(Y\) 才降方差。在标准设定下它确实为正，所有教材也都把 reward-to-go 作为第一项降方差手段，但它是一条经验上稳固的结论而不是无条件定理。

降方差手段二：基线的完整无偏性证明

这是全站唯一给出完整证明的地方。枢纽页给了压缩版，本节给逐步依据与边界条件。

命题

给权重减去一个只依赖状态、不依赖动作、且不依赖 \(\theta\) 的量 \(b(s)\)，梯度的期望不变：

\[\nabla_\theta J(\theta) \;=\; \mathbb{E}\left[ \sum_{t} \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, \big( G_t - b(s_t) \big) \right]\]

证明

只需证明多减掉的那一项期望为零。以离散动作为例，连续动作把求和换成积分，每一步同样成立：

\[\mathbb{E}_{a \sim \pi_\theta}\left[ \nabla_\theta \log \pi_\theta(a \mid s)\, b(s) \right] = \sum_{a} \pi_\theta(a \mid s)\, \nabla_\theta \log \pi_\theta(a \mid s)\, b(s)\] \[= \sum_{a} \pi_\theta(a \mid s)\, \frac{\nabla_\theta \pi_\theta(a \mid s)}{\pi_\theta(a \mid s)}\, b(s) = b(s) \sum_{a} \nabla_\theta \pi_\theta(a \mid s)\] \[= b(s)\, \nabla_\theta \sum_{a} \pi_\theta(a \mid s) \;=\; b(s)\, \nabla_\theta 1 \;=\; 0\]

每一步的依据：

  • 第一个等号：把期望写成对动作的求和。
  • 第二个等号：对数导数技巧展开 \(\nabla_\theta \log \pi_\theta\)。这里用到 \(\pi_\theta > 0\)。
  • 第三个等号：约去 \(\pi_\theta(a \mid s)\)，并且把 \(b(s)\) 提到求和号外面。这一步是全部证明的关键，它成立的唯一条件就是 \(b\) 不依赖 \(a\)。
  • 第四个等号：交换求和与梯度。有限动作集下无条件成立；连续动作需要子页 ① 里的正则性条件一。
  • 第五个等号：概率归一化，\(\sum_a \pi_\theta(a \mid s) = 1\)。
  • 最后：常数的梯度为零。

再对状态取外层期望，整体仍为零。证毕。

前提只有一条，另一条是常见的误传

  • \(b\) 不能依赖动作。 这是唯一的硬条件，下一节给出违反时的确切代价。
  • \(b\) 依赖 \(\theta\) 并不破坏无偏性。 这一点常被误传成第二个前提，其实不是：证明的第三个等号已经把 \(b\) 提到了对动作的求和号外面，此后 \(\nabla_\theta\) 只作用在 \(\pi_\theta\) 上，不会多出任何交叉项。等价地看，\(\mathbb{E}_{a \sim \pi_\theta}[\nabla_\theta \log \pi_\theta] = 0\) 恒成立，乘上任何与 \(a\) 无关的量（哪怕它含 \(\theta\)）结果仍是零。
  • \(b\) 与用来算梯度的那批动作应当统计独立。 这一条才是真正容易被忽略的，见下面的说明。

既然 \(b\) 依赖 \(\theta\) 无害，为什么实践中仍然要对 \(V_\phi\) 调用 detach？理由有两条，都与「梯度是否有偏」无关：其一，把替代损失写成 \(L = -\log \pi_\theta \cdot (G - V_\phi)\) 交给自动微分时，求导会多出一项 \(+\log \pi_\theta \cdot \nabla V_\phi\)——这是替代损失这个构造带来的伪影，不是梯度估计量本身的问题；其二，不 detach 会让策略损失的梯度流进价值网络，把它推去缩小优势而不是把价值估准。

一处需要澄清的常见说法。教材里常写「用学出来的 \(V_\phi\) 当基线时定理仍然保证无偏，\(V_\phi\) 学得不准只会让方差降得少，不会让梯度变有偏」。这句话在 \(V_\phi\) 与当前这批动作独立时成立。但实践中 \(V_\phi\) 往往用同一批数据拟合，此时它与被加权的动作之间有相关性，严格意义上的独立性被破坏，会引入 \(O(1/N)\) 量级的偏差。这个偏差在实践中小到可以忽略，但把它说成「严格无偏」是不准确的。

为什么减去基线能降方差

无偏是前提，降方差才是目的。单个时间步的梯度估计量 \(g = \nabla_\theta \log \pi_\theta(a \mid s)\,(G - b(s))\) 的方差是

\[\mathrm{Var}[g] \;=\; \mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta(a \mid s) \right\|^{2} \big( G - b(s) \big)^{2} \right] \;-\; \left\| \mathbb{E}[g] \right\|^{2}\]

第二项与 \(b\) 无关——这正是上面证明的结论。所以降方差就是让第一项里的 \(\big(G - b(s)\big)^{2}\) 尽可能小。

关键在于：这里起作用的是二阶矩而不是方差。\(G\) 围绕其均值的离散程度不会因为减去一个常数而改变，但 \(G^2\) 与 \((G - b)^2\) 可以差出几个数量级。

取 \(b(s) = V^{\pi_\theta}(s)\) 时，权重变成

\[G_t - V^{\pi_\theta}(s_t) \;\approx\; A^{\pi_\theta}(s_t, a_t)\]

这就是优势函数在策略梯度里的来历，也是 Actor-Critic 的起点。优势函数本身的性质、以及把 Critic 从「基线」升级为「替换回报」时偏差如何进来，在 Actor-Critic。

最优基线的闭式解，以及为什么实践用 V(s)

上一节说「应当让 \(b(s)\) 接近 \(G\) 在该状态上的典型取值」，于是取 \(V(s)\)。这个推理是对的但不精确——真正最小化方差的基线并不是 \(V(s)\)。

推导

最小化 \(\mathrm{Var}[g]\)，由于第二项与 \(b\) 无关，只需最小化

\[h(b) \;=\; \mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta \right\|^{2} (G - b)^{2} \right]\]

对 \(b\) 求导并令其为零：

\[\frac{\mathrm{d}h}{\mathrm{d}b} \;=\; -2\, \mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta \right\|^{2} (G - b) \right] \;=\; 0\]

解出

\[\boxed{\; b^{*} \;=\; \frac{\mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta \right\|^{2} G \right]}{\mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta \right\|^{2} \right]} \;}\]

它和 V(s) 差在哪

对照两者：

\[V^{\pi}(s) \;=\; \mathbb{E}\left[ G \mid s \right], \qquad b^{*} \;=\; \frac{\mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta \right\|^{2} G \right]}{\mathbb{E}\left[ \left\| \nabla_\theta \log \pi_\theta \right\|^{2} \right]}\]

\(V(s)\) 是 \(G\) 的等权期望；\(b^{*}\) 是以得分函数平方范数为权的期望。两者只在「得分函数的大小与回报无关」时才相等。

直觉上 \(b^{*}\) 更合理：得分函数范数大的样本对梯度贡献大，基线应当优先照顾这些样本。

一个几乎所有中文材料都写漏的细节

上面那个推导把 \(b\) 当成标量处理。严格地说，\(\hat{g}\) 是一个向量，每个参数分量的方差可以分别最小化，因此

最优基线逐参数分量各不相同，严格意义上的「最优基线」是一个向量而不是一个标量。

Peters 与 Schaal 给出的逐分量形式是（对回合制 REINFORCE）：

\[b^{*}_{h} \;=\; \frac{\mathbb{E}\left[ \big( \sum_{t} \partial_{h} \log \pi_\theta(a_t \mid s_t) \big)^{2}\, R(\tau) \right]}{\mathbb{E}\left[ \big( \sum_{t} \partial_{h} \log \pi_\theta(a_t \mid s_t) \big)^{2} \right]}\]

其中 \(\partial_h\) 表示对第 \(h\) 个参数分量求偏导。上面那个标量版本相当于用总范数把所有分量合并处理。

为什么实践中还是用 V(s)

四条理由，都很实在。

理由 说明
估计代价 最优基线的分子分母都是二阶统计量，用样本估计时本身噪声很大，估出来的基线可能比 V 还差
可泛化 V 是状态的函数，网络能在状态之间泛化；最优基线的逐分量形式没有这种结构
有语义 减去 V 得到的是优势，有明确含义，能直接接到 Actor-Critic 与 GAE 上
反正都要学 V Actor-Critic 与 GAE 本来就需要一个价值网络，用它当基线是零额外成本

需要澄清一处常见的误引：Greensmith、Bartlett 与 Baxter 在 JMLR 2004 里给出的不是「差距很小」的结论，恰恰相反——他们在摘要里明说「用平均回报定义基线这种流行做法可能是次优的」「把真实价值函数用作 critic 可能是次优的」。该文给出的是一个精确等式：任意基线相对最优基线的超额方差，等于一个以得分函数平方范数为权的平方距离。由此可读出条件：只有当得分函数的平方范数与回报近似独立时，\(V(s)\) 才接近最优。

所以正确的说法是：知道最优基线不是 \(V(s)\) 很重要；工程上仍然用 \(V(s)\)，理由是上表那四条（估计代价、可泛化、有语义、反正都要学），而不是「两者差距很小」。

动作相关基线与控制变量：配方、代价，与那场证伪

基线不能依赖动作，这是定理的硬条件。但如果一定要用依赖动作的量呢？这条线索值得完整讲一遍，因为它的结局很有教学价值。

违反条件的确切代价

设 \(b(s, a)\) 依赖动作但不依赖 \(\theta\)。多减掉的那一项不再为零，而是

\[\mathbb{E}_{a \sim \pi_\theta}\left[ \nabla_\theta \log \pi_\theta(a \mid s)\, b(s, a) \right] = \sum_{a} \nabla_\theta \pi_\theta(a \mid s)\, b(s, a) = \nabla_\theta \sum_{a} \pi_\theta(a \mid s)\, b(s, a)\]

也就是

\[\boxed{\; \mathbb{E}_{a \sim \pi_\theta}\left[ \nabla_\theta \log \pi_\theta(a \mid s)\, b(s, a) \right] \;=\; \nabla_\theta\, \mathbb{E}_{a \sim \pi_\theta}\left[ b(s, a) \right] \;}\]

推导的关键在第二个等号：\(b\) 不依赖 \(\theta\)，所以 \(\nabla_\theta\) 可以整体提到求和号外面。对照上一节的证明会发现，\(b\) 只依赖状态时 \(\mathbb{E}_{a}[b(s)] = b(s)\) 是常数，梯度为零，两者完全自洽。

这个式子同时是问题和答案

它说明偏差是多少，也直接给出了修正配方：把这一项加回去，估计量就重新无偏。

\[\hat{g} \;=\; \underbrace{\nabla_\theta \log \pi_\theta(a \mid s)\, \big( G - b(s,a) \big)}_{\text{有偏}} \;+\; \underbrace{\nabla_\theta\, \mathbb{E}_{a \sim \pi_\theta}\left[ b(s, a) \right]}_{\text{修正项}}\]

修正项需要能对动作分布求期望并求梯度。若 \(b\) 取成一个对动作可微的函数（例如 Critic 的一阶泰勒展开），这个期望可以解析地算出或用重参数化估计。这正是 Q-Prop（Gu 等 2017）与 Stein 控制变量（Liu 等 2018）所做的事。

这类方法在统计学里叫控制变量：用一个与目标相关、且期望已知的量去抵消随机性。基线是控制变量最简单的特例。

结局：2018 年的那次证伪

一系列论文报告动作相关基线带来了显著的方差下降与性能提升。然后 Tucker 等人在 ICML 2018 发表《The Mirage of Action-Dependent Baselines in Reinforcement Learning》，复现了这些工作并发现：

他们用方差分解直接证明：在常测基准上，学出来的动作相关基线相对状态基线并没有真的降低方差。随后审查开源代码发现，先前论文报告的性能提升来自一些细微的实现决定——这些决定实际上引入了偏差、换来了方差下降——以及价值函数拟合不良造成的对比失真。（论文用的是中性的 implementation decisions，不是「缺陷」。）

这条线索的价值不在于方法本身，而在于它是一个已发表方法被系统性证伪的完整案例。它给出的实践教训是：强化学习里「方差下降了」这个结论极难可靠地测量，报告改进时必须给出方差的直接度量，而不是只给回报曲线。

从这一节应当带走的是三件事：依赖动作的基线偏差有确切表达式；这个表达式本身就是修正配方；以及即使修正了，实际收益也很有限。工程上的结论很简单：用状态基线就够了。

奖励平移与缩放为什么污染策略梯度

这一节处理一个常见的错误表述，并给出正确口径。

缩放：等价于改学习率

把所有奖励乘以 \(k > 0\)，则所有 \(G_t\) 乘以 \(k\)，梯度估计量整体乘以 \(k\)：

\[\hat{g} \;\longrightarrow\; k\, \hat{g}\]
  • 最优策略不变。 所有 \(V\) 与 \(Q\) 同比例缩放，排序不变。
  • 对策略梯度的影响等价于把学习率乘以 \(k\)。 这一点很实用：奖励尺度与学习率是耦合的，换一个奖励尺度就要重新调学习率。回报标准化正是为了解耦这两者。

平移：常见表述是错的

常见的说法是「给所有奖励统一加一个常数不改变最优策略，却会污染梯度」。前半句在变长回合任务里是错的。

把所有奖励加上常数 \(c\)，一条长度为 \(T\) 的轨迹的回报变成

\[R(\tau) + c\, \frac{1 - \gamma^{T}}{1 - \gamma}\]

多出来的那一项依赖 \(T\)，而 \(T\) 由策略决定。于是不同策略得到的额外收益并不相同，排序可能改变。

正确口径分三层：

情形 常数平移是否改变最优策略 原因
无终止的连续型任务 不变 所有 V 与 Q 同加 c/(1-gamma)，排序不变
回合长度与策略无关（固定时域） 不变 所有轨迹多出同一个常数
终止时刻由策略决定（变长回合） 可能改变 额外收益依赖回合长度，长短回合的相对价值被改变

第三行的经典反例是最短路径问题：每步奖励 \(-1\)、到达目标终止，最优策略是尽快到达。把奖励整体加上 \(+2\) 变成每步 \(+1\) 之后，最优策略变成永远不要到达目标——完全反转。

反过来，CartPole 这类「终止是坏事」的任务里，加一个正常数恰好不改变最优策略（回报仍是回合长度的增函数）。所以这个错误表述在 CartPole 上验证不出来，这也是它容易被沿用的原因。

加性改写里唯一安全的形式

在加性的奖励塑形里，对任意 MDP 都保证最优策略不变的形式只有一种，即势函数塑形：

\[F(s, a, s') \;=\; \gamma\, \Phi(s') - \Phi(s)\]

其中 \(\Phi\) 是任意的状态势函数（无折扣情形还需势函数在吸收态上取值为零；Ng 等原文把该吸收态记作 \(s_0\)，与本专题用 \(s_0\) 表示初始状态的约定不同，读原文时注意区分）。Ng、Harada 与 Russell 在 1999 年的 Theorem 1 里证明这个形式是充要的，但必要性带一个重要的量词，不能省：原文的表述是「若 \(F\) 不是势函数形式，则存在某组转移函数 \(T\) 与奖励函数 \(R\)，使得 \(M'\) 的最优策略在 \(M\) 中都不最优」。也就是说，它是在「只给定 \(S\)、\(A\)、\(\gamma\)，对 \(T\) 与 \(R\) 一无所知」的意义下唯一——论文自称这是一个 weak converse。对一个具体已知的 MDP，非势函数形式的塑形完全可能碰巧保持最优策略不变。

另外要与上一小节的结论对齐：这里说的是加性改写。整体乘一个正常数属于正线性变换，同样保持最优策略不变——该论文摘要里就把两者并列写成「besides the positive linear transformation familiar from utility theory, one can add a reward … expressible as the difference in value of an arbitrary potential function」。

对策略梯度的具体影响

即便在最优策略确实不变的情形里，平移仍然改变算法行为。把权重整体平移之后：

  • 所有被采样到的动作权重同号，梯度只是在幅度上有差别。
  • 有用的信号是幅度之差，而更新量的尺度由幅度之绝对值决定。
  • 于是信噪比被压低，收敛显著变慢。

回报标准化：收益与它引入的偏差

实践中最常见的做法是把整批回报标准化：

\[\tilde{\Psi}_t \;=\; \frac{\Psi_t - \hat{\mu}}{\hat{\sigma} + \epsilon}\]

其中 \(\hat{\mu}\) 与 \(\hat{\sigma}\) 是这一批样本的均值与标准差。这一步实际上包含两个性质完全不同的操作，必须分开看。

减均值：是基线，无偏

\(\hat{\mu}\) 是一个常数，不依赖动作，因此它是一个合法的基线，受上面的定理保护。

严格说有一处细节：\(\hat{\mu}\) 由同一批数据算出，因此与被加权的动作相关，独立性被破坏，引入 \(O(1/N)\) 量级的偏差——与用同批数据拟合 \(V_\phi\) 是同一个问题。批量不太小时可以忽略。

除以标准差：不是基线，不受定理保护

\[\mathbb{E}\left[ \frac{\Psi - \mu}{\hat{\sigma}} \nabla_\theta \log \pi_\theta \right] \;\neq\; \frac{1}{\sigma}\, \mathbb{E}\left[ (\Psi - \mu) \nabla_\theta \log \pi_\theta \right]\]

因为 \(\hat{\sigma}\) 是一个随机变量，且与分子相关，不能提到期望外面。

它的实际作用是：按批自适应地缩放学习率，使梯度的尺度与奖励尺度解耦。这在奖励尺度未知或在训练中变化的任务上收益很大，所以实践中普遍采用。但要清楚它是一个有偏的启发式，不是定理保证的操作。

操作 是否基线 偏差 主要收益
减整批均值 是 同批估计带来 O(1/N) 量级偏差 权重出现正负号，信噪比提高
除以整批标准差 否 有偏，幅度不易界定 梯度尺度与奖励尺度解耦，学习率好调
减学出来的 V(s) 是 同上，且 V 有逼近误差 按状态区分基线，降方差最充分
加 epsilon 防止除零 不适用 可忽略 批内权重几乎相同时防止放大噪声

最后一行需要说清适用范围。常见的说法是「回合很短且每步奖励相同时整批标准差接近零，不加 \(\epsilon\) 会得到 NaN」——在 reward-to-go 口径下这种情形并不会发生：\(\gamma < 1\) 时即使每步奖励完全相同，\(G_t = (1 - \gamma^{\,T-t})/(1-\gamma)\) 也随 \(t\) 严格递减，批内并不退化。真正会退化的是 \(T = 1\)：此时批内只有一个样本，而 torch.std 默认走无偏（\(n-1\)）口径，返回的是 NaN，加 \(\epsilon\) 对 NaN 无效。所以 \(\epsilon\) 的实际作用是「批内权重几乎相同时防止放大噪声」，而要挡住 \(T=1\) 那种情形，得改用有偏口径或直接跳过这一批。对应的代码写法见子页 ④。

方差怎么量化

只看训练曲线抖不抖是不够的——曲线的抖动混合了梯度噪声与策略自身的随机性两部分。要判断一项降方差手段是否真的起作用，需要直接测量。下面三个量都可以直接打印。

量一：两个独立小批梯度的余弦相似度

把一批数据随机分成两半，分别算出 \(\hat{g}_A\) 与 \(\hat{g}_B\)，计算

\[\cos\langle \hat{g}_A, \hat{g}_B \rangle \;=\; \frac{\hat{g}_A \cdot \hat{g}_B}{\left\| \hat{g}_A \right\| \left\| \hat{g}_B \right\|}\]

这是最直接的信噪比指标。接近 1 说明梯度方向可靠；接近 0 说明两半数据给出的方向几乎正交，噪声完全主导。 实践中这个值往往比人们预期的低得多，这本身就很有说明性。

量二：权重的相对离散度

\[\frac{\mathrm{std}\left[ \Psi_t \right]}{\left| \mathrm{mean}\left[ \Psi_t \right] \right| + \epsilon}\]

直接反映权重里「共有成分」与「差异成分」的比例。加基线之前这个值很小（均值大、差异小），加基线之后应当显著变大——这个指标变大是基线起作用的标志，与直觉相反，值得注意。

量三：梯度范数在批间的相对标准差

固定参数不动，重复采样 \(M\) 批，各算一个 \(\hat{g}_m\)，计算 \(\left\| \hat{g}_m \right\|\) 的标准差与均值之比。它度量的是梯度幅度的不稳定性，与量一度量的方向不稳定性互补。

对照实验怎么设计

  • 固定参数。 测方差必须在同一组 \(\theta\) 上重复采样，否则测到的是参数变化与采样噪声的混合。
  • 只改一个变量。 加基线与不加基线的对照，除基线外的一切（种子、批量、网络初始化）都要一致。
  • 多个种子。 单种子下的方差估计本身方差就很大，至少要跑若干个种子并报告区间。
  • 报告方差而不只是回报。 这正是上面 2018 年那次证伪给出的教训：只给回报曲线无法支撑「方差下降了」这个结论。

另一条路线：参数空间探索与进化策略

本页最后放一个对照，它能把「方差为什么随时域增长」这件事解释得更清楚。

策略梯度在动作空间加扰动：每一步都随机采样一个动作，梯度通过 \(T\) 个得分函数项累加起来。进化策略在参数空间加扰动：

\[\theta_i \;=\; \theta + \sigma \epsilon_i, \qquad \epsilon_i \sim \mathcal{N}(0, I)\]

然后用每组扰动参数跑一整个回合，得到一个标量回报 \(J(\theta_i)\)，按

\[\hat{g} \;\approx\; \frac{1}{N \sigma} \sum_{i=1}^{N} \epsilon_i\, J(\theta_i)\]

估计梯度。

关键差别

一条轨迹只贡献一个标量。 于是估计量里没有那个对时间步的求和号，方差不会因为「把 \(T\) 个得分函数项加起来」而累加。这正好从反面说明了策略梯度方差增长的来源：它来自这个求和结构，而不是来自回报本身。

需要说准的是，这不等于「与 \(T\) 完全无关」：\(J(\theta_i)\) 本身就是一条轨迹的回报，它的方差按本页「方差怎么随时域增长」一节的分析仍随 \(T\) 变化，只是这一项不再被 \(T\) 个得分函数项放大一次。

维度 策略梯度 进化策略
扰动加在哪 动作空间，每步一次 参数空间，每回合一次
一条轨迹提供的信息 T 个得分函数项与对应权重 一个标量回报
方差与时域的关系 随 T 增长，来自逐步求和 不因逐步求和而累加
利用时间结构 利用，能做逐步的信用分配 完全不利用
并行性 需要同步梯度 极易并行，只需传标量
样本需求 相对少 通常显著更多

Salimans 等人在 2017 年的工作说明了进化策略在大规模并行下可以与策略梯度竞争。它的代价是完全丢弃了时间结构：策略梯度知道是哪一步的哪个动作带来了回报，进化策略只知道「这组参数整体好还是不好」。

这个对照给出的结论是：策略梯度的高方差不是缺陷，而是「利用时间结构」所付出的代价。 想要方差低，就得放弃逐步的信用分配；想要信用分配，就得接受方差。后续算法做的全部工作，就是在这两者之间找更好的平衡点。

常见误解与准确说法

常见说法 准确说法
基线的作用是让梯度无偏 梯度本来就无偏；基线的作用是降方差，无偏是它不破坏的东西，不是它带来的东西
最优基线就是状态价值 V(s) 最优基线是以得分函数平方范数加权的回报期望，且严格来说逐参数分量各不相同
减去基线让 G 的波动变小了 G 围绕其均值的离散程度不变；变小的是二阶矩，而方差表达式里起作用的正是二阶矩
基线不能用 Q(s,a) 是因为 Q 不准 与准不准无关，是因为依赖动作时无偏性证明的关键一步直接失效，偏差有确切表达式
回报标准化整体是一个基线 减均值是基线，除以标准差不是，后者不受定理保护，相当于按批自适应地缩放学习率
用学出来的 V_phi 当基线严格无偏 只在 V_phi 与当前批动作独立时严格成立；同批数据拟合会引入 O(1/N) 量级偏差
给所有奖励加常数不改变最优策略 只在无终止任务或回合长度与策略无关时成立；变长回合任务里可能完全反转
奖励乘一个正数不影响训练 最优策略不变，但梯度整体缩放，等价于改变学习率；这正是回报标准化要解耦的东西
方差大就是训练曲线抖 曲线抖混合了梯度噪声与策略随机性两部分；要判断降方差是否奏效必须直接测梯度的一致性
加大批量是解决高方差的办法 方差按 1/N 衰减，精度提高一个数量级要多两个数量级的样本，代价不可接受
动作相关基线是一个有效的改进方向 2018 年的复现工作表明先前报告的收益主要来自一些引入偏差的实现决定（论文用的是中性的 implementation decisions），正确实现下收益微乎其微

小结与出口指针

四句话回顾

  • 方差有三个来源（策略随机性、环境随机性、初始状态随机性），它们沿时间累加，因此梯度估计量的方差随回合长度超线性增长；折扣因子的作用是把有效时域截断。
  • 无偏与低方差是两个独立的性质。批量平均只能让方差按 \(1/N\) 衰减，靠堆样本解决不了问题，必须从估计量本身入手。
  • 因果性与基线是仅有的两条既降方差又不引入偏差的路径。基线的证明归结为概率归一化，全部重量压在「\(b\) 只能依赖状态」这一个条件上；违反它的确切代价是 \(\nabla_\theta \mathbb{E}_{a \sim \pi_\theta}[b(s,a)]\)。
  • 最优基线不是 \(V(s)\)，而是以得分函数平方范数加权的回报期望，且逐参数分量各不相同；实践用 \(V(s)\) 的理由是可泛化、有语义、且反正都要学它。

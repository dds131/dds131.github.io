GR00T N1 总览/① 网络架构与双系统

EAGLE‑2 · 17 ACTION-SIDE TOKENS · ALTERNATING DiT

GR00T N1 先用 Eagle-2 把多图像与指令编码为 1536 维条件序列，再把 1 个状态 token 和 16 个含噪动作 token 送入 16 个独立的交替 cross/self-attention DiT 块；按本体的三组边界网络负责异构接口，但视觉语言主干和 DiT 仍共享，因此它隔离的是输入输出语义，不是消除跨本体干扰或保证零样本接入。

24 → 12SmolLM2 后 12 层在固定实现中被物理删除。
256 → 64每帧视觉空间槽经 pixel shuffle 减少，元素先重排后压缩。
1 + 16一个状态 token 与十六个动作 token 构成固定查询侧。
8 + 816 个独立块交替执行 cross 与 self attention。

架构选择必须同时回答“节省或隔离了什么”和“付出了什么”，不能只列优点。

System 2：视觉压缩、散射、截断与投影

视觉塔与 256→64 路径

Eagle 子配置给出 force_image_size=224、patch 14、视觉 hidden 1152、27 层和16个头。每边 patch 数为 224/14=16，所以每帧得到 16²=256 个 patch token。固定发布路径使用 SiglipVisionModel，不会执行非 SigLIP 分支中的 vit_embeds[:,1:,:]，不能无依据把256减为255。

pixel_shuffle(scale_factor=0.5) 完成：

\[(BF)\times16\times16\times1152 \rightarrow(BF)\times8\times8\times4608 \rightarrow(BF)\times64\times4608.\]

元素数守恒：256×1152=64×4608=294,912。因此 pixel shuffle 本身是空间到通道的重排：独立空间槽位减少75%，但此时并未丢弃元素。真正的学习式瓶颈是后续 mlp1 的 4608→2048 投影。

mlp1：LayerNorm(4608) → Linear(4608,2048) → GELU → Linear(2048,2048)

LayerNorm 2×4608 9,216
Linear1 4608×2048+2048 9,439,232
Linear2 2048×2048+2048 4,196,352
mlp1 合计 三者之和 13,644,800

图像 token 散射与 causal 序列

get_embeddings 先取得文本 token embedding，再用 input_ids==img_context_token_id 选择占位，将 vit_embeds.reshape(-1,2048) 散射到这些位置。它要求至少存在一个 image context token、选中占位数等于全部视觉 token 数、processor template 与模型 template 相同，并且 processor 的 num_image_token 与模型计算值一致。

发布模板名是 qwen2-chat，语言模型配置却采用 LlamaForCausalLM 结构和 SmolLM2‑1.7B‑Instruct 路径。模板定义对话格式，不把模型身份改成 Qwen2。SmolLM2 是 causal LM，图文联合序列仍受 token 顺序与 causal mask 约束；本页不承诺任意模板顺序下图像与文本双向可见。

SmolLM2 24→12 的物理截断

Eagle 子配置中的语言主干为 hidden 2048、24层、32 heads、intermediate 8192、vocab 49,164；发布顶层 config 保存 select_layer=12。固定实现把 lm_head 替换为 Identity，循环 pop(-1) 直到只剩12层，请求 output_hidden_states=True，再读取截断模型的 hidden_states[-1]。

所以“第12层表示”是原模型前12层的最后输出，不是先运行24层再旁路读取。它节省后12层计算与参数，但词嵌入、前12层、视觉塔和接口层仍存在，不能写成整个 VLM 精确减半。论文报告的效果归 Experiments；为何中间层可能更合适归 Phenomena。

System 1：动作 token、交替 DiT 与时间调制

状态、动作、时间与位置

状态由按本体两层 MLP 64→1024→1536 编成一个 token，ReLU 位于两层之间。动作 encoder 依次执行：32→1536；把离散流时间扩展到16个动作槽并生成无参数1536维正弦编码；拼接为3072维；3072→1536 后接 swish；再做 1536→1536。最后加入学习式动作位置表 nn.Embedding(1024,1536) 的前16项。

状态 token 不加动作位置向量；动作正弦时间编码与学习式位置 embedding 也不是同一种信号。位置表长度1024是 dataclass 最大序列默认，不是本发布实例的动作块长度。

同一离散时间的三条结构路径

  1. 输入级：动作 encoder 用1536维无参数正弦编码，与动作 embedding 拼接。
  2. 逐块：Timesteps(256) → TimestepEmbedding(...,1536) 生成 temb，每块 AdaLayerNorm 再产生 scale/shift。
  3. 输出级：proj_out_1(SiLU(temb)) 生成另一组 scale/shift，调制 norm_out，再由 proj_out_2 做1536→1024。

输入正弦实现与 DiT 的 diffusers 时间模块不是同一组件，只是接收同一离散步。“早期粗、后期细”只能作为待验证直觉，Flow 损失并不强制这种语义；时间分布和方向归 Flow Matching 页。

三种 Mask、调用边界与未证明事项

三种 mask 的真实用途

固定实现中的 mask 路径；“存在”不等于动作头实际消费
mask 是否存在 固定用途 不会做什么
VL attention_mask 是 SmolLM2 内部 causal/padding；backbone 返回 不进入 DiT cross-attention
state_mask 上游可能提供 动作头未读取 不屏蔽 state encoder 输入或注意力
action_mask 是 逐元素 MSE 乘 mask，再除有效数 不屏蔽动作加噪、编码或 DiT 输入

Backbone 返回 backbone_attention_mask，训练动作头也把它作为 encoder_attention_mask 传给 DiT；但 DiT.forward 对每个 block 显式传 encoder_attention_mask=None，block 调用 Attention 的对应参数也被注释，推理同样没有传入。因此证据只支持“VL padding mask 在进入 DiT attention 前被丢弃”，风险大小仍取决于 batch padding、pad token 表征和模板，不能冒充论文有意设计。

训练对完整 B×16×32 加噪并由稠密 W1 编码，所以 padding 动作维即使真值为0也会含噪，并可能耦合到有效输出。action_mask 仅消除无效输出维的直接损失。归约为 sum(masked_mse)/action_mask.sum()，没有显式零分母防护；数据管线必须保证每 batch 至少有一个有效动作标量。

训练与推理调用边界

GR00T_N1.forward 执行 prepare → backbone一次 → action head训练前向一次。GR00T_N1.get_action 执行 prepare → backbone一次 → action head get_action；后者在 K 个 Euler 步中重复 action encoder、DiT、decoder 和更新。

固定代码在单次 get_action 的积分循环外复用 VLM 输出 tensor，但每步仍重新运行 cross-attention 的 K/V 投影，没有显式跨步 K/V cache。动作 query 随动作更新，可以在每步重新加权条件。每个新控制 tick 再次调用 get_action 时会重新运行 backbone；“VLM一次”不等于整个控制会话只运行一次。

本页要建立的判断有五条。其一，优势估计在预训练与后训练两个阶段不同，而且预训练公式在论文中存在下标歧义，复现时不能悄悄选一种读法。其二，优势条件不是孤立技巧，它来自正则化强化学习与条件策略之间的贝叶斯关系；理论结果说明理想条件下可以改进参考策略，但不等于对有限数据、近似价值函数和神经网络训练给出无条件保证。其三，二值阈值承担了主要的策略锐化职责，论文主要依靠阈值，只在有用时结合中等的 \(\beta\)（附录 E 举例为 1.5–2.5）。其四，训练时以 30% 概率丢弃条件，从而训练无条件分支、支持 CFG，并在期望目标层面替代 Eq. 3 的乘子 \(\alpha\)。其五，条件法让所有样本都贡献训练信号；但正条件分布仍只由正标签样本直接监督，不能把“全量参与”误写成“正条件的有效样本量等于全量”。

一、本页在专题中的位置

子页 ④ 讲完了价值函数，它的产物是一个可以对任意观测给出标量价值的网络。本页接着讲：这个标量怎么变成策略的训练信号。

需要从前面带过来的三个前提：

前提 出自 本页如何使用
成功样本回报等于负的剩余步数；价值是条件期望 ④ 第二节 用于解释优势的近似语义与边界
价值函数估计的是行为策略的价值，会随轮次漂移 ④ 第八节 用于解释阈值为什么要逐轮重估
流匹配分支有一个对数似然下界 ② 第三节 本页第三节说明它为何必需

二、优势的定义与两个阶段的不同估计

2.1 一般定义

论文第三节给出的优势是一个 \(N\) 步估计：

\[\mathrm{Adv}^{\pi}(o_t,\, a_t) = \mathbb{E}_{\rho_{\pi}(\tau)}\!\left[\sum_{t'=t}^{t+N-1} r_{t'} + V^{\pi}\!\left(o_{t+N}\right)\right] - V^{\pi}(o_t)\]

含义是：执行这段动作并向前走 \(N\) 步之后，实际拿到的回报加上那时的价值，与出发时的价值相比，是升还是降。升则这段动作优于行为分布的平均水平，降则劣于。

2.2 ★ 两个阶段用的不是同一个估计

这一点在论文附录 F 中给出，此前本站未记录。

阶段 前瞻步数 估计式 需要几次价值推理 方差
后训练 \(N = 50\) 标准 \(N\) 步式，\(o_{t+N}\) 取自同一条轨迹中 50 步之后的观测 两次：\(V(o_t)\) 与 \(V(o_{t+50})\) 较低
预训练 论文写 \(N = T\) 附录公式印为整条 episode 总回报减当前价值；与一般式的下标并不完全一致 一次：只需 \(V(o_t)\) 较高

附录 F 实际印出的预训练式是

\[\widehat{\mathrm{Adv}}^{\pi}_{\mathrm{pre}}(o_t,\,a_t) = \sum_{t'=0}^{T}r_{t'}-V^\pi(o_t)\]

这里必须保留论文的歧义，而不是替作者改公式。一般 \(N\) 步式从当前时刻 \(t\) 求和；若窗口一直延伸到终止，通常会写成 \(R_t-V(o_t)\)，其中 \(R_t=\sum_{t'=t}^{T}r_{t'}\)。但附录 F 明确印成从 \(0\) 到 \(T\)，同时又称其为“令 \(N=T\)”。它可能表示作者把每个训练片段重新以 0 编号，也可能只是下标笔误，论文没有解释。两种读法在原始 episode 坐标下相差当前时刻之前的累计奖励，标签可能不同。本站不再替它选定答案；复现时应查看官方训练代码或向作者确认，并把所采用的坐标约定写入测试。

论文对这个选择给出的理由非常具体：这样做使得可以在预训练期间用对价值函数的一次推理调用就即时算出优势值；并且论文说，经验上发现当策略在预训练期间用来自多样任务的大量数据训练时，这个更高方差的估计效果很好。

这条把子页 ③第六节那件事补完整了。那里说价值函数在 VLA 训练期间即时运行且主干只有 670M；附录 F 又明确给出，预训练估计对每个样本只需调用一次价值函数。若使用 \(N=50\) 形式，则概念上需要当前与未来两个状态的价值，并要求数据流水线能取得 50 步后的观测；实际批处理能否复用计算、增加多少墙钟时间，论文没有量化。

2.3 代入奖励定义之后，优势在度量什么

把子页 ④的奖励代进去。对一段未终止的轨迹，中间每步奖励都是 \(-1\)，于是后训练期的优势化简为

\[\widehat{\mathrm{Adv}}(o_t,\, a_t) = V\!\left(o_{t+50}\right)-V(o_t)-50\]

这个化简只适用于窗口内没有提前终止、奖励仍为每步 \(-1\) 的情形。若以未归一化步数为单位，并暂时忽略失败概率，\(V\) 可以近似解释成负的预期剩余步数，于是：

  • 走完这 50 步，如果预期剩余步数减少得比 50 还多，说明这段执行推进得比行为分布的平均水平更快，优势为正。
  • 如果减少得不足 50 步，说明这 50 步没有换来相应的进展，优势为负。
  • 恰好减少 50 步时估计值为零，即与价值函数所代表的行为基线相当。

实际实现把价值按任务最大 episode 长度 \(L_\ell\) 归一化。若奖励也按同一尺度处理，一致量纲下的式子应为

\[\widehat{\mathrm{Adv}}_{\mathrm{norm}} = V_{\mathrm{norm}}(o_{t+50})-V_{\mathrm{norm}}(o_t)-\frac{50}{L_\ell}.\]

论文没有交代“先归一化回报再算优势”还是“先用原始量算优势再缩放”的代码顺序，因此本页只给出量纲一致的写法，不声称这是官方代码逐行实现。只要奖励和价值使用同一尺度，优势正负不因整体正比例缩放而改变。

这就是「速度」这一维度进入学习信号的确切位置。注意它不需要任何额外的奖励项——子页 ④第二节讲的那个「每步 −1」的奖励设计，在这里兑现了它的作用。

由此也能看出优势把三类数据各自变成了什么：

数据片段 优势的取值倾向 原因
演示中干净利落的片段 正 价值上升快于步数消耗
演示中勉强凑合的片段 接近零甚至为负 同样成功，但推进慢
失败 rollout 中导致失败的片段 显著为负 价值向失败区间下滑
人工纠错片段 由估计决定；训练标签强制为正 论文以专家纠正通常有益为前提，覆盖估计得到的标签
反复重试同一动作的停滞片段 接近零或为负 步数在消耗，价值不升

这张表是由公式得到的定性倾向，不是逐片段必然标签：有限样本、价值误差、终止窗口和阈值都会改变结果。停滞片段即使属于最终成功轨迹，也可能因步数持续消耗而得到较低优势；这正是 episode 级成功标签无法直接表达的局部信息。

三、策略提取：三个标准与两条被排除的路线

有了价值函数，如何用它训练出更好的策略，这一步称为策略提取（policy extraction）。论文先立标准，再排除，最后给出选择。

3.1 三个标准

论文明确列出了在这个场景下策略提取方法必须满足的三条：

# 标准 为什么这个场景需要它
1 有效利用多样的 off-policy 数据 数据包含初始演示、专家介入、以及来自最新策略与更旧策略的自主 episode；论文指出这与离线强化学习面临的挑战密切相关
2 可扩展且易于应用到大型 VLA，包括用流匹配或扩散生成动作的模型 本方法的目标模型就是这一类
3 同时有效利用好数据与坏数据 若要用自主经验改进策略，坏数据必须能用上

3.2 为什么排除策略梯度

策略梯度方法（包括正则化策略梯度与重参数化梯度）也许是应用最广的一类。论文排除它们的理由落在第 2 条标准上：

这些方法难以应用到流匹配模型，因为流匹配不易提供可处理的对数似然，这使得它们难以扩展到现代 VLA 架构。

这一句与子页 ②第三节形成了闭环。那里讲到，论文在附录 C 专门为连续动作推导了一个对数似然的证据下界，并说明这段推导的目的是「为策略改进计算对数似然」。现在可以看到这两件事的关系：

流匹配没有可处理的对数似然 → 需要似然的策略提取方法（如策略梯度）用不了 → 于是论文有两条出路：要么造一个似然的可计算代理，要么换一类不需要似然的方法。论文两件事都做了：附录 C 推出了似然下界（使得 PPO 风格的对照实现成为可能，见附录 D），而主方法选择了优势条件这条不依赖策略梯度的路线。

3.3 为什么排除加权回归

另一条常见路线是加权回归，例如 AWR。论文承认它的优点：隐式地提供了对行为策略的正则化，并且使用一个简单的（重要性加权的）监督学习目标。

但论文排除它的理由落在第 3 条标准上：

这些方法丢弃或显著降低了相当一部分数据的权重，实际上实现了一种过滤式模仿（filtered imitation）。

“过滤式模仿”点出了论文所关心的问题：如果低优势数据的权重被压到接近零，方法会接近“只模仿高优势数据”，而第 3 条标准要求低质量数据也产生可用信号。第十节会说明有效样本量诊断能支持什么、不能支持什么。

3.4 论文的选择

论文采用优势条件的一个变体：策略在全部数据上用监督学习训练，但多一个输入，指示该动作按优势衡量有多最优。论文指出这与文献中一系列「以轨迹的某个函数为条件」的方法密切相关，而其具体形式最接近 CFGRL。

四、优势条件的理论来源

这一节回答一个容易被跳过的问题：把优势当条件，凭什么能得到一个更好的策略，而不只是一个「会模仿不同质量动作」的策略。

4.1 起点：KL 正则化强化学习的经典解

论文第三节先给出正则化强化学习的目标——在最大化回报的同时保持接近参考策略：

\[J(\pi,\, \pi_{\mathrm{ref}}) = \mathbb{E}_{\tau \sim \rho_{\pi_{\theta}}}\!\left[\sum_{t=0}^{T} \gamma^{t} r_t\right] - \beta\, \mathbb{E}_{o \sim \rho_{\pi_{\theta}}}\!\left[D\!\left(\pi(\cdot \mid o)\,\|\,\pi_{\mathrm{ref}}(\cdot \mid o)\right)\right]\]

论文说明了为什么需要这一项正则：例如当我们要在同一批数据上做很多步梯度更新时，\(\pi_{\mathrm{ref}}\) 通常就对应采集这批训练数据的行为策略。

当散度 \(D\) 取 KL 时，有一个众所周知的结果——最优解为

\[\hat{\pi}(a \mid o) \propto \pi_{\mathrm{ref}}(a \mid o)\, \exp\!\left(\frac{\mathrm{Adv}^{\pi_{\mathrm{ref}}}(o,a)}{\beta}\right)\]

其中 \(\beta\) 是拉格朗日乘子。加权回归那一类方法正是直接照着这个式子做的：把指数项当作样本权重。

4.2 论文用的是一个「鲜为人知」的相关结果

论文明确写道，其优势条件策略提取方法基于一个密切相关但鲜为人知的结果（论文引用 [4] 与 [71]，即 Frans 等人的 CFGRL 与 Wang 等人的指数加权模仿学习）。这个结果本身是一条改进保证：若定义

\[\hat{\pi}(a \mid o) \propto \pi_{\mathrm{ref}}(a \mid o)\, p\!\left(I \mid \mathrm{Adv}^{\pi_{\mathrm{ref}}}(o, a)\right)^{\beta}, \qquad p\!\left(I \mid \mathrm{Adv}^{\pi_{\mathrm{ref}}}(o, a)\right) = \frac{g\!\left(\mathrm{Adv}^{\pi_{\mathrm{ref}}}(o, a)\right)}{\int g\!\left(\mathrm{Adv}^{\pi_{\mathrm{ref}}}(o, a')\right) da'}\]

其中 \(g\) 是单调递增函数，\(p(I \mid \cdot)\) 表示以优势衡量的改进事件。论文引用的结果在其理论假设下给出 \(J(\hat{\pi})\geq J(\pi_{\mathrm{ref}})\)。这个结论解释了条件提取的方向，但它针对由精确分布定义的理想策略；实际系统还要估计价值、二值化标签并用有限容量网络拟合条件分布，所以不能把该不等式直接当成每次实际训练必然提升的保证。

接下来的关键一步，是用贝叶斯规则把这个「改进概率」改写成两个策略分布之比：

\[p\!\left(I \mid a,o\right) = p(I\mid o)\, \frac{\pi_{\mathrm{ref}}(a \mid I,o)} {\pi_{\mathrm{ref}}(a \mid o)} \ \propto\ \frac{\pi_{\mathrm{ref}}(a \mid I,o)} {\pi_{\mathrm{ref}}(a \mid o)}\]

严格的贝叶斯公式包含与动作 \(a\) 无关的因子 \(p(I\mid o)\)；由于最终策略还要对动作归一化，这个因子会被比例常数吸收。论文在文字推导中省略了它。把动作相关的比值代回去并加上语言条件，就得到改进策略的另一种闭式（论文 Eq. 2）：

\[\hat{\pi}(a \mid o,\, \ell)\ \propto\ \pi_{\mathrm{ref}}(a \mid o,\, \ell) \left[\frac{\pi_{\mathrm{ref}}(a \mid I,\, o,\, \ell)}{\pi_{\mathrm{ref}}(a \mid o,\, \ell)}\right]^{\beta}\]

4.3 这个改写换来了什么

对比 4.1 与 4.2 两个式子，差别在于指数项被替换掉了：

  经典解（加权回归所依据的） Eq. 2（本方法所依据的）
改进因子 \(\exp(\mathrm{Adv} / \beta)\) \(\left[\pi_{\mathrm{ref}}(a\mid I,o,\ell) / \pi_{\mathrm{ref}}(a\mid o,\ell)\right]^{\beta}\)
需要什么 需要标量优势值本身 只需要有条件与无条件两个策略分布
怎么用 把因子当样本权重 训练一个能同时表示两者的模型

论文点明了这个改写的核心好处：可以表示 \(\hat{\pi}\) 而不需要显式表示改进概率 \(p(I \mid \mathrm{Adv})\)，只要训练的策略能够同时表示 \(\pi_{\mathrm{ref}}(a \mid o, \ell)\) 与 \(\pi_{\mathrm{ref}}(a \mid I, o, \ell)\) 即可。论文并指出，这个原理类似于 classifier-free guidance 中的做法——扩散模型被训练为同时建模有条件与无条件的数据。

4.4 β = 1 的特例：为什么推理时只要取条件就够了

Eq. 2 在 \(\beta = 1\) 时会发生一件很方便的事：

\[\hat{\pi}(a \mid o,\, \ell) = \pi_{\mathrm{ref}}(a \mid I,\, o,\, \ell)\]

分子分母上的 \(\pi_{\mathrm{ref}}(a \mid o, \ell)\) 直接抵消。也就是说，改进后的策略恰好就是条件策略本身。

这就是推理时把条件固定取正的理论依据：在 Eq. 2 的理想分布关系成立、且条件模型拟合准确时，它是 \(\beta=1\) 的代数结果。实际神经网络只能近似这些分布，因此不应把“精确抵消”扩大成模型误差为零。若要进一步锐化条件分布，才使用第九节的 CFG。

五、二值化：delta 分布与任务相关阈值

Eq. 2 里的 \(I\) 还是一个抽象的「改进指示」。论文把它具体化为一个 delta 分布：

\[p\!\left(I \mid \mathrm{Adv}^{\pi_{\mathrm{ref}}}(o,\, a,\, \ell)\right) = \delta\!\left(\mathrm{Adv}^{\pi_{\mathrm{ref}}}(o,\, a,\, \ell) > \epsilon_{\ell}\right)\]

即：优势超过阈值 \(\epsilon_{\ell}\) 就是正，否则为负。取值集合只有两个元素，因此这是一个一位信息的条件。

\(\epsilon_{\ell}\) 的下标 \(\ell\) 表示它是任务相关的——每个任务有自己的阈值。论文对这个设计给出的作用描述很关键：

这个阈值使我们能够控制最优性指示，并最小化了在训练之后为锐化改进条件分布而寻找衰减因子 \(\beta\) 的需要。

这句话说明阈值与引导强度的功能部分重叠：两者都能锐化最终分布，但发生在不同阶段。论文主要在训练标注阶段用阈值调节，只在有用时于推理阶段采用中等 \(\beta\)；不是完全禁止调 \(\beta\)。第九节会说明原因。

此外还有一条硬规则：人工纠正的动作强制置为正。论文的说法是，为了纳入人类纠正，他们发现把自主 rollout 过程中由人提供的动作强制设为 \(I_t = \text{True}\) 是有用的；论文给出的前提是：如果假设人类专家总能提供好的纠正动作，这个选择就是合理的。

这条规则与论文第五节 D 的另一段论述之间有一处值得注意的张力：那里论文明确说，即使是专家操作员也无法保证介入质量一致，纠正本身并不提供最优监督（见子页 ③第八节）。也就是说，「强制置为正」依赖的前提，论文自己也承认在实践中不总成立。论文没有讨论两者如何协调，本页只把两处原文并列。

六、阈值的三种口径

这是本页订正最集中的一处。论文在两个位置给出了阈值的设定方式，而且它们不是同一种说法，应当如实并列。

6.1 第五节 D 的表述

预训练阶段，把 \(\epsilon_{\ell}\) 设为该任务下价值函数预测值的 30% 分位数。

6.2 附录 F 的表述：分三种情形

阶段 / 任务 阈值如何设定 论文给的理由
预训练 为每个任务选阈值，使约 30% 的演示数据具有正优势（在 1 万个数据点的随机样本上计算） —
微调（一般情形） 一般设阈值，使每一轮中约 40% 的评测 rollout 具有正优势 —
T 恤与短裤衣物折叠 提高阈值，使只有约 10% 的数据具有正优势 该任务用高质量演示数据训练得到的策略速度慢但成功率高

6.3 两处表述的差别

第五节 D 说的是「在价值预测值上取 30% 分位数」，附录 F 说的是「选阈值使约 30% 的数据具有正优势」。被取分位数的对象不同——前者是价值的分布，后者是优势的分布，而价值与优势不是同一个量。本页并列给出两处原文口径，不把它们合并成一种说法，也不推算两者之间的换算关系。论文没有说明两处以哪一处为准；本站的建议是，复现时可以把附录 F 的描述作为主要参照，因为它更具体（给出了正优势所占比例与计算所用的样本数）。

6.4 第三种口径为什么值得单独记住

那条 10% 规则是针对特定任务的工程设定，它所回应的现象很重要：在这个任务上，高质量演示训练出的策略成功率高，但速度慢。

提高阈值、让约 10% 的数据为正，会只保留估计优势最高的一小部分作为正条件监督，从而更强地偏向相对高效的片段。高优势常与更快进展有关，但也可能来自纠错恢复或避免失败，因此不能把它严格等同为“最快 10%”。论文没有报告沿用 30% 或 40% 时具体有多少慢片段会被判正。

这件事的完整含义——人类演示不等于最优策略，模仿学习的上限只能逼近演示者——放在子页 ⑥与其他反直觉现象一起讨论。本页只记录阈值层面的做法。

七、条件怎么注入序列

论文第五节 B 小节给出的注入方式在实现上非常轻：把二值指示写成一段文本——\(I_t\) 为真时输入「Advantage: positive」，否则输入「Advantage: negative」——位置在模型自己预测的子任务文本 \(\hat{\ell}\) 之后、（离散与连续）动作 之前，因此只有动作的似然受它影响。除此之外模型与基座那一代没有区别。

这个位置的选择有两层含义：

  • 条件排在动作之前，因此动作的生成以优势指示为条件。 之所以「排在前面」就等于「成为条件」，是因为序列的这一段走的是因果注意力：靠后的 token 能读到靠前的，反过来不行。相关机制见子页 ①第五节与注意力机制。
  • 条件排在子任务之后，因此子任务的预测不受优势指示影响。 高层「打算做什么」与低层「做得好不好」被分在了序列的两段。

这条通路是现成的，不是为 RECAP 新建的。子页 ①第三节讲过，π0.6 基座本来就支持把 metadata 以文本写进 prompt 来调制任务执行方式；优势指示走的是同一条语言通路。这正是这套方法能够以很小的结构改动接到一个既有 VLA 上的原因。

文本的确切写法由论文第五节 B 小节直接给出，即上文的「Advantage: positive」与「Advantage: negative」。（本站旧稿曾误写为「论文未给出确切拼写」，已订正。）

另有一处写法差异需要注意：附录 C 的 Eq. 6 在形式上把子任务项也写成以 \(I_t\) 为条件，即 \(\pi_{\theta}(\hat{\ell} \mid I_t, o_t, \ell)\)；而第五节 B 小节明确说指示位于 \(\hat{\ell}\) 之后、只影响动作的似然。本页按第五节 B 小节理解，即子任务的预测不受优势指示影响。

八、训练目标与 30% 条件丢弃

8.1 论文给出的目标

论文 Eq. 3 把策略目标写成一个负对数似然的最小化：

\[\min_{\theta}\ \mathbb{E}_{\mathcal{D}_{\pi_{\mathrm{ref}}}} \left[ -\log \pi_{\theta}\!\left(a_t \mid o_t,\, \ell\right) \ -\ \alpha \log \pi_{\theta}\!\left(a_t \mid I_t,\, o_t,\, \ell\right) \right], \qquad I_t = \mathbf{1}\!\left(\mathrm{Adv}^{\pi_{\mathrm{ref}}}(o_t, a_t, \ell) > \epsilon_{\ell}\right)\]

两项分别对应第四节所说的那件事：模型要同时能表示无条件分布与有条件分布。第一项训练前者，第二项训练后者，\(\alpha\) 是两者之间的权衡系数。

数据集 \(\mathcal{D}_{\pi_{\mathrm{ref}}}\) 是至今收集的全部数据，因此 \(\pi_{\mathrm{ref}}\) 是人类行为与此前各版策略行为的混合，这一点见子页 ④第八节。

8.2 实现上不调 α，而是随机丢弃条件

论文附录 F 给出了实际做法：训练时以 30% 的概率丢弃对优势指示的条件化。这一个操作同时达成三件事：

作用 说明
得到无条件模型 被丢弃的那 30% 样本训练的正是 \(\pi_{\theta}(a_t \mid o_t, \ell)\)，即 Eq. 3 的第一项
支持 CFG 推理时可以直接从条件策略或无条件策略采样，从而实现 \(\beta > 1\) 的引导
替代损失乘子 \(\alpha\) 论文原文即如此表述：它实际上替代了损失乘子 \(\alpha\)

第三条需要精确限定。两种写法的期望目标可以对应起来，但单步随机梯度与计算图并不完全相同：

  • 调 \(\alpha\)： 每个样本都算两项损失，用 \(\alpha\) 决定第二项占多大比重。
  • 随机丢弃： 每个样本随机走条件或无条件输入，以 70% 概率贡献条件损失、30% 概率贡献无条件损失。若两类样本采用相同采样与归一化，期望损失是 \(0.3L_{\mathrm{uncond}}+0.7L_{\mathrm{cond}}\)；整体除以 0.3 后，对应 Eq. 3 的相对系数 \(\alpha=0.7/0.3\approx2.33\)。这是本站从概率推得的目标比例，不是论文公布的 \(\alpha\)，且随机丢弃的梯度方差与“每个样本同时算两项”不同。

丢弃使每个样本只采用一种条件状态，一次常规前向即可得到对应损失；若要对同一样本显式计算 Eq. 3 的两项，通常要构造两种输入。它把相对权重的控制转移到丢弃概率。论文只明确说 30% 丢弃“有效地替代” \(\alpha\)，没有给出计算量对比或等效数值。

论文写出了带 \(\alpha\) 的 Eq. 3，但实际实现说明使用 30% 条件丢弃替代它，未给 \(\alpha\) 数值。复现实际配方时，不应在没有说明的情况下再额外乘一个 \(\alpha\)，否则会改变条件/无条件的相对权重。若去掉丢弃，就必须显式保留无条件训练；若既不做丢弃、又只训练条件项，模型没有可靠的无条件分支，无法按附录 E 做 CFG，但仍可直接使用正条件策略。

8.3 训练与推理时条件取值的差别

  条件取什么 模型学到 / 用到什么
训练时 取由估计优势和阈值得到的标签 \(I_t\)；纠正动作强制为真；30% 概率省略条件 学习正条件、负条件与无条件三种输入状态下的动作分布
推理时 直接条件采样时固定取 \(I_t = \text{True}\)；CFG 还需无条件分支 正条件在训练中出现过，但状态分布变化时仍可能发生分布外泛化

低优势样本在训练中照常参与基础损失，未被优势权重压到接近零。它们直接监督“负条件下观察到的动作”，并通过共享参数影响表示学习；这不等于论文把每个负标签动作都定义为绝对错误，也不等于它们直接监督正条件分布。

九、推理：β = 1、CFG，以及论文为什么不靠调 β

9.1 两种推理模式

模式 做法 依据
\(\beta = 1\)（直接条件采样） 以 \(I_t = \text{True}\) 从条件策略采样 第 4.4 节：理想关系下 \(\hat{\pi}\) 等于条件策略
\(\beta > 1\)（可选） 同时用条件与无条件模型做 classifier-free guidance 论文附录 E

附录 E 给出的形式是：训练之后可以通过设 \(\beta > 1\) 进一步锐化用于评测的策略，且不需要额外训练，因为它已经由学到的两个策略隐式定义。具体做法是按下面的梯度方向做流匹配推理：

\[\nabla_a \log \pi_{\theta}(a \mid o, \ell) + \beta\left[ \nabla_a \log \pi_{\theta}(a \mid I, o, \ell) - \nabla_a \log \pi_{\theta}(a \mid o, \ell) \right]\]

论文指出这一步的依据是：扩散模型实际上学到的是似然的梯度，因此可以把条件与无条件两个模型的输出按上式组合。

9.2 ★ 论文为什么最终不靠调 β

这是本页最值得记住的一段。论文在脚注中明确对照了先前工作的做法：

先前工作统一取 \(\epsilon = 0\)，并在测试时调 \(\beta\)，就像 classifier-free guidance 中那样。然而，高 CFG 权重会把动作分布推向其支撑集的角落（导致激进的行为），并且不会影响模型的自回归部分。我们发现，改为用阈值 \(\epsilon_{\ell}\) 来权衡正则化与最优性，更容易取得好结果。

这里给出了两条机制层面的理由，需要分开理解：

理由 机制 后果
高引导权重把动作分布推向支撑集的角落 CFG 的组合式是一个外推：它沿着「条件方向减无条件方向」继续往外走。\(\beta\) 越大，外推越远，越容易落到训练数据覆盖不到的区域 动作变得激进
CFG 不影响自回归部分 引导作用在流匹配那一路的似然梯度上；而离散动作 token 是自回归生成的，不经过这条路径 调大 \(\beta\) 只能锐化连续动作那一路，离散动作那一路的分布不随之锐化

第二条尤其容易被忽略。它说明 \(\beta\) 这个旋钮的作用范围是不完整的——它只作用在两路动作中的一路上。而阈值 \(\epsilon_{\ell}\) 作用在训练数据的标注上，离散与连续两路动作都以同一个指示为条件训练，因此阈值对两路动作都起作用。（子任务文本位于指示之前，不以指示为条件，阈值与 \(\beta\) 都不影响它。）

附录 E 对这件事还有一段更具体的说明：训练后用较高的 \(\beta\) 锐化分布，可能把动作分布推向其学到的支撑集的边界，从而导致过于激进的动作；因此论文主要依靠阈值 \(\epsilon_{\ell}\) 在训练后直接得到一个好的条件策略，并在有用时结合中等的 \(\beta\) 取值（例如 \(\beta \in [1.5, 2.5]\)）。附录 E 还指出，\(\beta\) 与阈值之间只是松散地相关：两者都在锐化分布，一个在推理时，一个在训练时。

把第五节与本节连起来看，论文的设计逻辑就清楚了：阈值与 \(\beta\) 是两个功能重叠的旋钮，论文以前者为主、后者只在有用时取中等值。阈值在训练前生效、作用于离散与连续两路动作，且取的是训练数据中已有的条件分布；\(\beta\) 在推理时生效、只作用于连续动作，调大有外推风险。第五节引用的那句原文——阈值「最小化了在训练之后为锐化改进条件分布而寻找衰减因子 \(\beta\) 的需要」——正是这个意思。论文没有说明哪些实验用了哪个 \(\beta\) 以及对应的结果，本页不作推测。

这一现象与其余六个反直觉现象的并列讨论见子页 ⑥第 9.4 节。

十、与「按优势加权」相比，数据利用率为什么更高

第 3.3 节说过，论文批评加权回归会丢弃或显著降低一部分数据的权重，近似过滤式模仿。下面先给出加权法常用的诊断量，再说明它不能直接拿来宣称条件法的正分支有效样本量等于全量。

加权法的目标形如

\[\mathcal{L}_{\mathrm{weighted}}(\theta) = \mathbb{E}\!\left[\, w\!\left(\mathrm{Adv}(o_t, A_t)\right) \cdot \mathcal{L}_{\text{action}}\!\left(\theta;\, o_t, A_t\right)\right]\]

其中 \(w(\cdot)\) 是非负权重函数，常见取指数形式 \(w = \exp(\mathrm{Adv}/\beta)\)——也就是第 4.1 节那个经典解直接搬过来。

对只考虑标量样本权重的估计，一批 \(M\) 个样本常用下式描述权重集中度：

\[M_{\mathrm{eff}} = \frac{\left(\sum_{i=1}^{M} w_i\right)^{2}}{\sum_{i=1}^{M} w_i^{2}}\]

当权重高度不均时，\(M_{\mathrm{eff}}\) 会远小于 \(M\)，说明少数样本主导加权统计量。这个公式是一般性诊断，不是论文对 π0.6 数据计算出的结果；深度网络梯度还受样本相关性、损失大小与优化器影响，不能把它当作精确的训练样本数。

条件法没有用连续优势权重把低优势样本压到接近零：每个被抽到的样本都以普通监督损失更新共享模型，只是条件标签不同。不过，正条件分布仍主要由正标签子集直接约束；负样本对正分支的帮助来自参数共享，而不是等价于新增正样本。

  加权回归 优势条件（本方法）
低优势数据的处理 可能被显著降权；程度取决于权重函数 作为负条件样本参与普通监督损失
全部样本是否更新共享参数 极小权重样本贡献可能近于零 是，但 30% 条件丢弃会改变其输入状态
正策略的直接监督 由所有样本按不同权重贡献 主要来自正标签子集，不等于全量
低优势数据提供的信息 以较小权重影响同一分布 直接学习负条件分布，并共享表示
对模型容量的要求 较低，只建模一个分布 较高，要同时建模两个条件分布
推理时的用法 直接采样 需要指定条件取值

用信息的语言说：加权法主要把优势用于改变样本份量，条件法把它变成输入标签，因此能显式区分正、负两种条件分布。论文把后者描述为能利用好数据与坏数据；“一定保留更多有效信息”还取决于标签质量、模型容量和两类覆盖，不能只凭形式断言。

代价在表格最后两行：模型必须有足够容量同时建模正负两个条件分布，并且必须保证被选中的那一档有足够样本。本站的理解是，这也是阈值口径（第六节）按「正优势所占比例」而不是按优势的绝对值来定的一个好处——正档样本的比例始终维持在一个可控的水平。论文本身没有这样解释。

本节的有效样本量公式只是解释加权集中现象的一般性工具。论文没有给出权重分布或 \(M_{\mathrm{eff}}\) 数值，也没有证明条件法的分支有效样本量等于总数据量。

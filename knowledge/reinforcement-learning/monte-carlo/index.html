知识库 / 强化学习 / Monte Carlo
Complete returns · sample averages · off-policy estimation

等一局结束，用真实回报学习

动态规划对模型求期望；Monte Carlo 不要模型，等 episode 完成后把真实回报当样本；时序差分进一步不等结局，用当前估计 bootstrap。MC 是从“已知模型”走向“只凭经验”的第一座桥。

0 个模型不需要转移概率与奖励表
0 次 bootstrap纯 episodic MC 的定义特征
2 种 visitfirst-visit / every-visit
12 项测试回报、覆盖、权重与边界

一句话契约：在策略 $\pi$ 下采样到完整 episode，用

\[G_t=\sum_{k=0}^{T-t-1}\gamma^kR_{t+k+1}\]

作为 $v_\pi(S_t)$ 或 $q_\pi(S_t,A_t)$ 的样本。若 episode 是被 MDP 外部截断的，尾部再接价值估计就已经是 bootstrapped partial return，不能继续称为“纯 MC 完整回报”。

1. 为什么 MC 位于 DP 与 TD 之间

方法 需要环境模型 target 来源 何时更新 主要代价
动态规划（DP） 需要 $p(s’,r\mid s,a)$ 对全部后继求精确期望 可做 sweep 模型通常不可得
Monte Carlo（MC） 不需要 完整 episode 的采样回报 $G_t$ 通常在 episode 结束后 高方差、需等待结局
时序差分（TD） 不需要 $R_{t+1}+\gamma V(S_{t+1})$ 每一步 有 bootstrap 偏差与耦合 
flowchart LR
  DP["DP<br/>模型期望"] -->|"去掉模型<br/>用完整样本"| MC["Monte Carlo<br/>完整 return"]
  MC -->|"不等结局<br/>加入 bootstrap"| TD["TD<br/>一步或多步 target"]
  DP -. "expected backup" .-> ROOT["价值估计"]
  MC -. "sample backup" .-> ROOT
  TD -. "sample + estimate" .-> ROOT

前置阅读：强化学习初探与多臂老虎机、MDP、动态规划。学完本页再读时序差分，才能真正看清 bootstrap 带来的变化。

2. Episode、奖励下标与回报

采用标准轨迹记号：

\[S_0,A_0,R_1,S_1,A_1,R_2,\ldots,R_T,S_T.\]

$R_{t+1}$ 是执行 $A_t$ 后收到的奖励。有限 episode 在时刻 $T$ 结束，时刻 $t$ 的 discounted return 为：

\[G_t = R_{t+1}+\gamma R_{t+2}+\cdots+\gamma^{T-t-1}R_T.\]

递推式是：

\[G_t=R_{t+1}+\gamma G_{t+1}, \qquad G_{T-1}=R_T.\]

常见错位 把 $R_t$ 当成动作 $A_t$ 的即时奖励，会让整条 return 向前或向后错一位。代码中建议让 rewards[t] 明确表示数学上的 $R_{t+1}$，并在数据类注释中固定这一约定。

2.1 逆序计算

G = 0.0
returns = zeros(T)
for t in reversed(range(T)):
    G = rewards[t] + gamma * G
    returns[t] = G

这种实现只扫描一次 episode。若 $\gamma=0$，立即退化为 returns[t] == rewards[t]；这是很有用的边界测试。

2.2 MC 估计的对象

状态价值：

\[v_\pi(s)=\mathbb E_\pi[G_t\mid S_t=s].\]

动作价值：

\[q_\pi(s,a)=\mathbb E_\pi[G_t\mid S_t=s,A_t=a].\]

MC 不要求知道转移模型，但仍要求：

  • 数据确实由声明的策略分布产生，或有正确的 off-policy 修正；
  • episode/边界语义正确；
  • 回报的期望存在；
  • 被估计的状态或状态—动作对得到足够覆盖。

3. First-visit 与 Every-visit prediction

假设同一个状态 $s$ 在一条 episode 中出现多次。

  • First-visit MC：每条 episode 只用 $s$ 的第一次出现；
  • Every-visit MC：使用 $s$ 的每一次出现。

对动作价值，把“状态出现”换成“状态—动作对出现”。

first-visit 的“第一次”是按环境时间从前向后看最早的访问，不是逆序计算 return 时最先遇到的访问。逆序循环配一个 seen 集合会保留最后一次访问，这是非常常见的实现错误。

3.1 无歧义的实现

先逆序算出全部 return，再正序选择访问：

returns = discounted_returns(rewards, gamma)
seen = set()

for t, state in enumerate(states[:-1]):
    if state in seen:
        continue
    seen.add(state)
    update_state_value(state, returns[t])

Every-visit 则不使用 seen：

for t, state in enumerate(states[:-1]):
    update_state_value(state, returns[t])

在有限 MDP、适当覆盖和标准随机近似条件下，两者都能收敛到 $v_\pi$；有限样本方差与相关性不同。不要把“都收敛”误写成“任意数据量都给出相同数值”。

3.2 一个重复状态例子

轨迹：

\[S_0=A,\quad S_1=B,\quad S_2=A,\quad S_3=\text{terminal}.\]

若三个奖励为 $1,2,4$，$\gamma=1$，则：

\[G_0=7,\quad G_1=6,\quad G_2=4.\]
  • first-visit 对 $A$ 只更新 $G_0=7$；
  • every-visit 对 $A$ 更新 $7$ 与 $4$；
  • 一个从后向前的 seen 错误实现只会留下 $G_2=4$，那是 last-visit，不是 first-visit。

4. 样本均值与增量更新

收集到状态 $s$ 的第 $N$ 个合格回报样本 $G_N$ 后，先令 $N(s)\leftarrow N(s)+1$，再更新：

\[V(s) \leftarrow V(s)+\frac{1}{N(s)}\left(G_N-V(s)\right).\]

它与保存全部 return 后求 batch mean 完全等价，却只需常数额外存储。

count[s] += 1
value[s] += (G - value[s]) / count[s]

4.1 常数步长不是普通样本均值

非平稳问题中常用：

\[V(s)\leftarrow V(s)+\alpha\left(G-V(s)\right), \qquad 0<\alpha\le1.\]

展开后，近期样本获得更高的指数权重。它能追踪漂移，但不再是所有历史 return 的算术平均；不能继续用“无偏样本均值”解释。

步长 $1/N$

平稳目标下自然收敛；早期样本长期保留影响；每个状态需要独立计数。

常数步长 $\alpha$

适合非平稳追踪；存在稳态噪声；需单独报告 $\alpha$，不能伪装成 batch mean。

5. 从状态价值到动作价值

无模型控制无法在 $V(s)$ 上直接做

\[\arg\max_a \sum_{s',r}p(s',r\mid s,a)[r+\gamma V(s')],\]

因为这个表达式需要模型。MC control 因而学习 $Q(s,a)$，直接比较动作价值：

\[\pi(s)\in\arg\max_a Q(s,a).\]

First-visit MC action-value prediction 的合格样本由 (state, action) 首次出现决定，不是只看 state：

seen_pairs = set()
for t, (state, action) in enumerate(zip(states[:-1], actions)):
    pair = (state, action)
    if pair in seen_pairs:
        continue
    seen_pairs.add(pair)
    update_q(pair, returns[t])

6. Generalized Policy Iteration

MC control 仍遵循广义策略迭代（GPI）：

  1. 策略评估：用 episode return 更新 $Q^\pi$；
  2. 策略改进：让策略更偏向当前高价值动作；
  3. 两者交替，直到稳定或达到训练预算。
flowchart LR
  P["当前策略 π"] --> S["采样完整 episode"]
  S --> E["MC 评估 Qπ"]
  E --> I["ε-soft / greedy 改进"]
  I --> P

困难不在公式，而在覆盖：如果策略从不尝试某个动作，就没有它的 return 样本，也无法知道它是否更优。

7. Exploring starts：有用的理论装置

Exploring starts 假设每个 episode 的初始 $(S_0,A_0)$ 都以正概率覆盖所有状态—动作对。它能为 MC control 的理论分析提供充分探索，却通常不适合真实系统：

  • 很多状态无法安全或物理上直接初始化；
  • 任意初始动作可能造成碰撞；
  • 高维连续状态—动作空间无法枚举；
  • reset 分布本身是任务的一部分，不能随意改写。

因此，exploring starts 应理解为“保证覆盖的理想化条件”，而不是机器人系统的默认实现建议。

8. On-policy MC control 与 epsilon-soft 策略

若行为策略就是要优化的目标策略，可让它保持 $\epsilon$-soft。对有限离散动作集 $\mathcal A(s)$，若唯一 greedy action 为 $a^*$：

\[\pi(a\mid s) = \begin{cases} 1-\epsilon+\epsilon/|\mathcal A(s)|,&a=a^\*,\\ \epsilon/|\mathcal A(s)|,&a\ne a^\*. \end{cases}\]

若有 $m$ 个并列 greedy actions，应把 exploitation 部分 $1-\epsilon$ 在这 $m$ 个动作间分配，而不是由数组顺序永久偏向第一个。

8.1 算法骨架

initialize Q(s, a), count(s, a)
initialize epsilon_soft_policy(Q, epsilon)

for episode in range(num_episodes):
    trajectory = generate_episode(policy)
    returns = discounted_returns(trajectory.rewards, gamma)
    seen_pairs = set()

    for t, (s, a) in enumerate(trajectory.state_action_pairs):
        if (s, a) in seen_pairs:
            continue
        seen_pairs.add((s, a))

        count[s, a] += 1
        Q[s, a] += (returns[t] - Q[s, a]) / count[s, a]

        policy[s] = epsilon_soft_distribution(Q[s], epsilon)

在 tabular 条件下，持续但逐渐减弱的探索可形成 GLIE 思路；固定 $\epsilon>0$ 则收敛目标是受 $\epsilon$-soft 约束的策略，而非完全 deterministic greedy policy。

$\epsilon$-soft 只保证每个离散动作在已访问状态有非零概率，不保证高维状态空间、稀疏奖励或安全约束下的充分探索。探索的完整设计由后续探索专页负责。

9. Off-policy：目标策略与行为策略

  • target policy $\pi$：想评估或优化的策略；
  • behavior policy $b$：实际生成数据的策略。

要从 $b$ 的轨迹估计 $\pi$，必须满足 coverage：

\[\pi(a\mid s)>0 \Longrightarrow b(a\mid s)>0\]

至少要在目标策略可能经过的相关状态—动作上成立。如果目标动作在 behavior 下概率为 0，数据中没有任何权重可以“补出”缺失行动。

9.1 状态价值的 trajectory ratio

估计 $v_\pi(S_t)$ 时，未来动作序列的比率为：

\[\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k\mid S_k)} {b(A_k\mid S_k)}.\]

环境转移概率与奖励分布在分子分母中相消，前提是两种策略面对的是同一个环境机制。

9.2 动作价值的比率起点

估计 $q_\pi(S_t,A_t)$ 时已经条件化在当前动作 $A_t$ 上，标准 continuation ratio 从下一步开始：

\[\rho_{t+1:T-1} = \prod_{k=t+1}^{T-1} \frac{\pi(A_k\mid S_k)} {b(A_k\mid S_k)}.\]

这也是 weighted off-policy MC control 逆序算法在更新当前 $Q(S_t,A_t)$ 之后才把当前 behavior 概率除进权重的原因。若某篇资料把乘积从 $t$ 开始，先确认它估计的是状态价值、联合事件，还是采用了不同归一化；不能只复制上下标。

10. Ordinary 与 Weighted Importance Sampling

对同一状态得到 $N$ 个 return $G_i$ 与 ratio $\rho_i$。

10.1 Ordinary IS

\[V_{\mathrm{ordinary}}(s) = \frac{1}{N}\sum_{i=1}^{N}\rho_iG_i.\]

在 coverage 与可积性条件满足时，它可无偏，但单个极大权重会主导估计，方差甚至可能无穷大。

10.2 Weighted / self-normalized IS

\[V_{\mathrm{weighted}}(s) = \frac{\sum_{i=1}^{N}\rho_iG_i} {\sum_{i=1}^{N}\rho_i}.\]

它有限样本一般有偏，但一致，且常更稳定。如果分母为 0：

  • 不能把估计值写成 0；
  • 应返回“当前不可估计”、NaN 或保留旧估计并发出诊断；
  • 必须报告有效样本数与 coverage failure。

若所有 $G_i=c$ 且分母大于 0，weighted IS 必须精确返回 $c$；这是很好的单元测试。

估计器 有限样本偏差 方差 分母为零 典型风险
ordinary IS 可无偏 很高，可能无穷 无自归一化分母 极少数轨迹支配均值
weighted IS 通常有偏 常较低 必须显式处理 低有效样本量时仍不可靠
clipped IS 被人为引入偏差 可显著降低 仍需诊断 把稳定错当正确
per-decision IS 依问题而异 常低于整轨迹乘积 每步仍需 coverage 实现上下标易错

11. Per-decision Importance Sampling

整条 trajectory ratio 把所有未来动作比率乘在整个 return 上。利用 return 的加和结构，可让第 $k$ 个奖励只承担到产生它为止的比率：

\[\mathbb E_b\left[ \sum_{k=t}^{T-1} \gamma^{k-t} \rho_{t:k}R_{k+1} \;\middle|\;S_t=s \right],\]

其中

\[\rho_{t:k} = \prod_{j=t}^{k} \frac{\pi(A_j\mid S_j)} {b(A_j\mid S_j)}.\]

早期奖励不再乘上与它因果上无关的更晚动作比率，通常能降低方差。它不是“随意把 trajectory ratio 截短”；推导必须与奖励时序、状态价值/动作价值条件一致。

12. 数值稳定、有效样本量与覆盖诊断

12.1 在 log 空间累计

长 horizon 下直接连乘会 overflow 或 underflow：

\[\log\rho_{t:T-1} = \sum_{k=t}^{T-1} \left[ \log\pi(A_k\mid S_k)-\log b(A_k\mid S_k) \right].\]

计算前应检查：

  • behavior probability 是否严格大于 0；
  • log-prob 是否针对真实采样动作；
  • action transform、mask 和温度是否一致；
  • float dtype 与 exponentiation 范围。

12.2 Effective sample size

对非负权重 $w_i$，常用：

\[\mathrm{ESS} = \frac{\left(\sum_iw_i\right)^2}{\sum_iw_i^2}.\]

ESS 接近 1 表示几乎只有一条轨迹在贡献。报告 N 而不报告 ESS 会掩盖严重权重退化。

12.3 必须同时看的统计量

覆盖

零 behavior 概率次数、目标动作未出现率、支持集重叠。

权重

median、p90、p99、max、零权重比例、有限值比例。

有效数据

ESS、非零权重 episode 数、每状态/动作的有效访问数。

敏感性

不同 clip 阈值、不同 behavior 模型、不同 horizon 的估计漂移。

截断权重、归一化 log-weight 或混合模型估计都可能实用，但必须标注它们改变了统计估计器，不能继续宣称与原始 ordinary IS 具有相同无偏性。

13. Weighted off-policy MC control

当 target policy 是对 $Q$ 的 deterministic greedy policy 时，标准逆序骨架为：

for each episode generated by behavior b:
    G = 0.0
    W = 1.0

    for t in reversed(range(T)):
        s, a, r_next = S[t], A[t], R[t + 1]
        G = gamma * G + r_next

        C[s, a] += W
        Q[s, a] += (W / C[s, a]) * (G - Q[s, a])

        target_action = argmax_with_declared_tie_break(Q[s])
        pi[s] = target_action

        if a != target_action:
            break

        prob = b(a | s)
        assert prob > 0
        W = W / prob

为什么遇到 a != target_action 就停止？deterministic target 对该动作概率为 0，更早时间步的完整 ratio 因而变成 0。为什么先更新再更新 $W$？当前 $Q(s,a)$ 已条件化当前动作，更新它需要的是后续动作的 ratio。

常见错误 先执行 W /= b(a|s) 再更新当前 $Q(s,a)$，会把当前动作概率重复纳入条件化动作价值的权重。

并列最大动作必须有固定、可记录的 tie-breaking；behavior 策略概率必须是当时采样所用的概率，而不是训练后重新计算的新版策略概率。

14. Terminated、truncated 与“完整 episode”

MC 的无 bootstrap 特征依赖真正完成的 episodic return。边界语义由环境 API、终止截断与时间边界统一定义。

14.1 真终止

若 terminated=True，任务定义在此结束：

\[G_{T-1}=R_T\]

不接终点之后的价值。

14.2 外部截断

若在 $H$ 时刻因采样器限制 truncated=True，底层任务仍会继续。只把已观察奖励相加：

\[\sum_{k=t}^{H-1}\gamma^{k-t}R_{k+1}\]

通常低估余下回报。若使用价值函数补尾：

\[\widehat G_t^{\mathrm{partial}} = \sum_{k=t}^{H-1}\gamma^{k-t}R_{k+1} + \gamma^{H-t}\widehat V(o_H^{\mathrm{final}}),\]

这是合理的 partial-episode bootstrapping，但不再是纯 MC target。必须使用截断前最后真实观测，不能使用 auto-reset 后新 episode 初始观测。

14.3 没有尾部价值怎么办

不能默默令尾部为 0。可选择：

  • 延长采样直到自然终止；
  • 只在任务确实为有限时域时把时限建模进状态；
  • 引入单独价值估计并明确承认 bootstrap；
  • 使用有理论说明的截断/删失估计；
  • 报告仅保留自然终止 episode 造成的选择偏差。

“MC 必须等 episode 结束”不等于“任何 reset 都能制造一个合法终点”。reset 是采样操作；terminal 是任务语义。

15. Continuing task 怎么办

没有自然终点的 continuing task 不直接提供有限 episodic return。常见路线包括：

  • discounted continuing return，配合 TD 或人为窗口与尾部估计；
  • average-reward formulation；
  • 找到真正的 regenerative state，把访问周期当自然 episode；
  • 固定窗口估计，并显式分析 truncation bias。

把无限任务每 1000 步 reset 一次、然后把最后一步标成 terminal，只是改变数据，不会自动让原任务变成正确的 episodic MDP。

16. MC 与 TD：偏差—方差不是唯一差别

维度 Monte Carlo TD(0)
target 实际完整回报 $G_t$ $R_{t+1}+\gamma V(S_{t+1})$
bootstrap 纯 MC 不使用 使用
更新时机 episode 结束后 每一步
target 偏差 完整 on-policy return 样本本身不含 bootstrap 偏差 当前估计带来 bootstrap 偏差
方差 通常更高，长时延奖励尤其明显 通常较低
continuing task 需额外处理 天然可在线更新
非 Markov 观测 return 仍可采样，但价值条件发生混叠 同样受混叠影响
off-policy IS 乘积可极高方差 也需校正且可能有致命三元组问题

“MC 无偏、TD 有偏”只是简化口号。函数逼近、有限数据、截断、off-policy 权重、策略不断变化都会引入额外误差；比较时要说明估计对象和数据生成过程。

18. 常见错误与定位

现象 常见根因 优先检查
first-visit 结果像 last-visit 逆序循环直接用 seen 是否先算 return、再正序判首次
return 全部偏一位 $R_t/R_{t+1}$ 混用 轨迹数据结构与两步手算
MC 值系统性偏低 truncation 当 terminal terminated / truncated 与尾部价值
off-policy 值偶发爆炸 长 ratio product log-weight、p99/max、ESS
weighted IS 总给 0 分母 0 被默认替换 不可估计分支与 coverage
Q 的权重多乘一项 当前动作重复进入 ratio ratio 起点与更新 $W$ 的顺序
策略只选动作 0 argmax tie 固定偏置 初始化、随机 tie-breaking
训练数据很多但估计不稳 名义 $N$ 大、ESS 极小 权重分布与支持集重叠
固定 $\epsilon$ 后仍未 greedy 优化对象理解错误 是否声明 epsilon-soft 约束
只保留成功 episode 选择偏差 采样过滤规则与失败轨迹

调试顺序：先手算一条短 episode → 验证奖励下标 → 验证 visit 选择 → 验证增量均值 → 再开启策略改进 → 最后加入 importance sampling。不要在基础 return 还没过测试时调 $\epsilon$ 或 clip ratio。

19. 与其他页面的职责边界

  • 多臂老虎机：解释无状态动作价值的样本均值与探索；
  • 动态规划：保留已知模型下的 exact expectation 与 GPI；
  • 本页：负责完整 episodic return、MC prediction/control 与 IS 基础；
  • 时序差分：负责 bootstrap、Sarsa 与 Q-learning；
  • 策略梯度：REINFORCE 使用 return，但梯度目标不等于 tabular MC control；
  • 离线强化学习：固定数据、分布偏移与 OPE 只保留摘要，并回链本页的 IS 基础；
  • 环境时间边界：统一 terminal、truncation、auto-reset 与 bootstrap mask。

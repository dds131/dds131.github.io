上一章的动态规划要求把转移概率 \(P(s' \mid s,a)\) 与奖励函数 \(r(s,a)\) 全都摆在算法面前。真实机器人上这个假设不成立：没有人能写出「机械爪以某个速度接触杯壁后杯子滑向何处」的概率表。本章丢掉这个假设，只保留一件事——能与环境交互，能观察到一条条转移 \((s, a, r, s')\)。这就是无模型（model-free）方法的起点，之后主线上的所有算法都在这个设定里。

本页重点：必须精读两节。一是「时序差分误差与自举」，它把增量式均值推广成 TD 更新式，是 Sarsa、Q-learning、DQN 乃至 Actor-Critic 的共同核心；二是「Q-learning 与 Sarsa 的唯一差别」，全章最有价值的部分——两个算法的更新式只差一处（目标里用 max 还是用实际采样的动作），却在同一个悬崖漫步上学出两条完全不同的路径，这一节配备份图与实验对照。可以快速略过的是 n 步 Sarsa（只需记住 n 在偏差与方差之间做权衡）、环境类代码（与动态规划页完全相同）与绘图部分。

本章要解决什么问题

动态规划用模型枚举全部后继分支，蒙特卡洛不用模型、直接使用完整 episode 回报。本页再走一步：只观察转移样本，同时用当前价值估计 bootstrap，从而在线更新。

维度 Monte Carlo Temporal Difference
典型 target 完整回报 \(G_t\) \(R_{t+1}+\gamma m_{t+1}^{boot}V(S_{t+1})\)
bootstrap 否 是
更新时机 通常在所需尾部回报已知后 一步或多步后
持续任务 需定义有限窗口、平均回报等额外口径 可自然在线更新
误差来源 有限样本、覆盖、截断/IS 等 还包含当前估值和 bootstrap 的耦合
bias/variance 取决于回报、截断与采样方案 取决于当前估计、步数、相关性与函数逼近

不能把两者无条件写成“MC 永远无偏高方差、TD 永远有偏低方差”。完整且正确处理边界的 MC return 才是相应价值的样本；人工截断会产生尾部偏差。给定当前 \(V\) 时，一步 TD target 可以是 Bellman backup 的条件无偏样本，但它通常不是未知真值 \(V^\pi\) 的无偏样本。

本页建立四件事：

  • fixed-policy TD(0) prediction 与 TD error；
  • Sarsa、Expected Sarsa 和 Q-learning 的 target 差异；
  • behavior policy 与 target policy 的关系及 coverage 条件；
  • terminated、truncated、\(n\) 步 flush 和独立 greedy evaluation 的实现合同。

标准 CliffWalking 只作为放大行为差异的受控例子；路径与回报结论必须以共享环境夹具和多 seed 实验为准。

形式化定义：prediction、control 与边界 mask

一步样本统一写成

\[S_t,\ A_t,\ R_{t+1},\ S_{t+1}^{final}, \ terminated_{t+1},\ truncated_{t+1}.\]

final 表示 auto-reset vector env 中必须取真正的末观测，而不是 reset 后的新 episode 首观测。定义

\[m_{t+1}^{boot} = 1-\mathbf 1_{\{terminated_{t+1}\}},\]

外部时间上限截断且任务语义允许继续时，\(m^{boot}=1\)。reset mask、bootstrap mask 与 padding/loss mask 不能合并成一个 done。

固定策略 prediction

对固定平稳策略 \(\pi\)，

\[V^\pi(s) = \mathbb E_\pi[ R_{t+1} + \gamma m_{t+1}^{boot}V^\pi(S_{t+1}^{final}) \mid S_t=s ].\]

TD(0) 用一条样本逼近右侧条件期望；此阶段先冻结策略，避免把 changing-policy control 与 prediction 的收敛叙述混在一起。

control 与行为策略

model-free value-based control 通常直接学习 \(Q(S,A)\)，因为没有模型时无法从 \(V\) 枚举动作后果。但“所有无模型方法都必须学 Q”不成立：REINFORCE 可不用 Critic，PPO 常学 \(V\)，bandit 和直接策略优化也有其他形式。

本页行为策略用带固定 tie rule 的 \(\epsilon\)-greedy：

\[b(a\mid s) = (1-\epsilon)\mathbf 1\{a=g_Q(s)\} + \frac{\epsilon}{|\mathcal A|}, \qquad g_Q(s)=\operatorname*{argmax}^{tie}_a Q(s,a).\]

固定 \(\epsilon>0\) 有助于有限任务中的覆盖，但不自动满足所有状态—动作对无限访问；环境可达性、episode 起点与训练期限同样重要。渐近收敛结论还要求对应的步长、覆盖和策略变化条件，不能由一张有限训练曲线代替。

完整边界实现见环境边界页。

重点一：TD error、bootstrap 与收敛条件

所有增量估计都可写成

\[\text{estimate} \leftarrow \text{estimate} + \alpha(\text{target}-\text{estimate}).\]

MC prediction 把 target 设为完整回报；TD(0) 则设为

\[Y_t^{TD} = R_{t+1} + \gamma m_{t+1}^{boot}V(S_{t+1}^{final}).\]

TD error 为

\[\delta_t = Y_t^{TD}-V(S_t),\]

更新为

\[V(S_t) \leftarrow V(S_t)+\alpha_t(S_t)\delta_t.\]

为什么这叫 bootstrap

target 使用同一估计器在后继状态的当前输出，因此价值信息可在 episode 结束前传播。好处是在线更新和通常更短的随机尾部；代价是 target 随估计器变化，误差、数据相关性和更新分布会相互耦合。

“有 bootstrap”不能单独解释 target network、Double Q 或 TD3 的全部动机：

  • target network 主要减慢移动目标；
  • replay 改变相关性和数据复用；
  • Double Q/TD3 处理动作选择与估值误差耦合导致的过估计；
  • off-policy + bootstrap + function approximation 的组合构成 deadly triad 风险。

条件无偏与真值偏差是两件事

固定当前函数 \(V\) 时，若转移样本来自正确环境，

\[\mathbb E[Y_t^{TD}\mid S_t=s] = (\mathcal T^\pi V)(s).\]

所以单步 target 可对当前 Bellman backup 条件无偏。但只要 \(V\ne V^\pi\)，\(Y_t^{TD}\) 一般不是未知真值 \(V^\pi(s)\) 的无偏样本。把这两种“无偏”混在一起，会错误地把所有 TD 偏差归因于采样。

同样，MC 的方差不必在每个问题上都大于 TD，\(n\) 步 target 的 bias/variance 也不保证随 \(n\) 严格单调。它们是常见趋势，需要由具体转移、奖励、估计误差和相关性验证。

表格型 fixed-policy TD(0) 的保证

在有限 MDP、固定策略、充分访问、有界奖励，以及逐状态步长满足

\[\sum_k\alpha_k(s)=\infty, \qquad \sum_k\alpha_k(s)^2<\infty\]

等条件下，表格型 TD(0) 可收敛到 \(V^\pi\)。常数步长通常用于跟踪变化目标，会在噪声邻域内波动，不应与 Robbins–Monro 渐近结论混写。

函数逼近并不意味着“保证一律消失”：on-policy 线性 TD 有经典结果；真正危险的是在缺少附加条件时把 off-policy、bootstrap 和非线性函数逼近组合起来。

flowchart LR
  DP["DP<br/>模型期望 + bootstrap"] --> MC["MC<br/>样本完整回报"]
  MC --> N["n-step / TD(lambda)<br/>样本奖励 + 延迟 bootstrap"]
  N --> TD["TD(0)<br/>一步样本 + bootstrap"]

这是一条 target 设计谱，不是一条“越往右越先进”的升级线。

Sarsa、Expected Sarsa 与 Q-learning

三种一步控制方法共享

\[Q(S_t,A_t) \leftarrow Q(S_t,A_t) + \alpha\left[ Y_t-Q(S_t,A_t) \right],\]

差异只在 target operator。

Sarsa：采样下一行为动作

先按当前行为策略 \(b\) 采样 \(A_{t+1}\)，并把同一个动作传入 target 和下一次 env.step：

\[Y_t^{Sarsa} = R_{t+1} + \gamma m_{t+1}^{boot} Q(S_{t+1}^{final},A_{t+1}), \qquad A_{t+1}\sim b(\cdot\mid S_{t+1}).\]

这是一种 on-policy sample backup。若 \(b\) 仍随 Q 改变，它是控制过程，不应在每个有限训练时刻都声称“已经收敛到某个固定 \(Q^{\pi_\epsilon}\)”。固定 \(\epsilon\)、常数 \(\alpha\) 的演示配置也不能与 GLIE + Robbins–Monro 的渐近最优收敛定理混写。

Expected Sarsa：对下一动作取期望

\[Y_t^{ExpSarsa} = R_{t+1} + \gamma m_{t+1}^{boot} \sum_a b(a\mid S_{t+1}^{final})Q(S_{t+1}^{final},a).\]

它保留当前行为策略的期望算子，但消除了“下一动作再采一次”带来的条件方差。Sarsa 与 Expected Sarsa 的区别说明：on-policy 不等于 target 必须只用一个采样动作。

Q-learning：对目标动作取最大

\[Y_t^{Q} = R_{t+1} + \gamma m_{t+1}^{boot} \max_a Q(S_{t+1}^{final},a).\]

行为策略仍可用 \(\epsilon\)-greedy 收集覆盖，target policy 则是对当前 Q 贪婪的策略。一步更新通常不乘完整轨迹 importance ratio，因为它根据条件转移样本逼近 Bellman optimality fixed point；这不表示数据来源与分布无关。

方法 下一动作 target behavior / target 关系 主要随机性
Sarsa \(A_{t+1}\sim b\) 的样本 Q 相同 转移 + 下一动作
Expected Sarsa 对 \(b(\cdot\mid S_{t+1})\) 求期望 相同 转移
Q-learning \(\max_a Q(S_{t+1},a)\) 可以不同 转移；另有 max 选择偏差

off-policy 不等于任意数据都可用

Q-learning 的表格收敛仍要求环境动力学一致、奖励有界、每个相关状态—动作对充分访问、合适的逐 pair 步长等条件。旧策略、演示或离线数据若缺少目标策略需要的覆盖，无法仅凭 max 恢复缺失动作的价值；函数逼近下还会出现分布外外推和 deadly triad 风险。

replay buffer 也不是 on/off-policy 的定义。朴素 Sarsa 的 target 需要“当时行为策略实际选出的下一动作”，随意重放旧轨迹会改变估计对象；但保存 next action/behavior probability、限制策略滞后，或采用 importance sampling、Retrace、V-trace、tree-backup 等校正后，on-policy 结构也可以有限复用数据。不能写成“Sarsa 绝对不能 replay”。

\(n\) 步 target 与边界

对未跨越真正终止的轨迹，\(n\) 步 Sarsa target 为

\[G_{t:t+n} = \sum_{k=0}^{n-1} \gamma^kR_{t+k+1} + \gamma^n m_{t+n}^{boot} Q(S_{t+n}^{final},A_{t+n}).\]

实现必须在 episode 结束时 flush 尚未更新的前缀。真正 termination 令尾部 bootstrap 为 0；外部 truncation 若语义允许继续，应从 final observation bootstrap，而不是简单把 terminated or truncated 合成 done。

增加 \(n\) 通常让更多真实奖励直接进入 target、减少对当前估计的依赖，但 bias/variance、信用传播速度和最终策略保守程度不保证严格单调。诸如“5 步 Sarsa 必然更保守”的结论必须由当前环境上的多 seed 证据支持。

CliffWalking 只在统一合同下解释

标准 Sutton–Barto/Gymnasium 合同中，踏崖奖励 \(-100\)、回到起点且 episode 继续；到达目标才终止。固定 \(\epsilon\) 的 Sarsa 会评估探索动作的后果，因而可能避开高风险通道；Q-learning 的 greedy target 更接近最短路径目标。

这是受控例子的典型现象，不是“on-policy 永远更安全”或“off-policy greedy 策略一定更好”的普遍定理。比较时必须分开：

  • 训练期 behavior return；
  • 冻结 Q 后的 greedy evaluation return；
  • 跌崖次数、成功率与 episode length；
  • 有限预算表现与满足收敛条件时的极限结论。

算法流程与可审计实现

三种一步 target 的统一伪代码

输入: alpha, gamma, behavior b, target_type
初始化 Q(s,a)

对每个 episode:
  reset 得到 S
  A <- b(.|S)                       # Sarsa 需提前携带动作
  while episode 未结束:
    执行 A，得到 R_next, S_next, terminated, truncated
    boot <- 0 if terminated else 1
    A_next <- b(.|S_next)            # 即使外部截断，bootstrap 仍可能需要

    if target_type == sarsa:
        next_value <- Q(S_next,A_next)
    elif target_type == expected_sarsa:
        next_value <- sum_a b(a|S_next) Q(S_next,a)
    elif target_type == q_learning:
        next_value <- max_a Q(S_next,a)

    Y <- R_next + gamma * boot * next_value
    Q(S,A) <- Q(S,A) + alpha * (Y - Q(S,A))

    if terminated or truncated: break
    S,A <- S_next,A_next

一步算法代码

import gymnasium as gym
import numpy as np


class TabularTD:
    def __init__(
        self,
        n_state: int,
        n_action: int,
        alpha: float = 0.1,
        gamma: float = 0.9,
        epsilon: float = 0.1,
        target_type: str = "sarsa",
        seed: int = 0,
    ):
        if target_type not in {"sarsa", "expected_sarsa", "q_learning"}:
            raise ValueError(target_type)
        self.q = np.zeros((n_state, n_action), dtype=np.float64)
        self.n_action = n_action
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.target_type = target_type
        self.rng = np.random.default_rng(seed)

    def greedy_set(self, state: int) -> np.ndarray:
        row = self.q[state]
        return np.flatnonzero(np.isclose(row, row.max()))

    def policy_probs(self, state: int, explore: bool = True) -> np.ndarray:
        probs = np.zeros(self.n_action, dtype=np.float64)
        best = self.greedy_set(state)
        if explore:
            probs.fill(self.epsilon / self.n_action)
            probs[best] += (1.0 - self.epsilon) / len(best)
        else:
            probs[best] = 1.0 / len(best)
        return probs

    def act(self, state: int, explore: bool = True) -> int:
        if not explore:
            return int(self.greedy_set(state)[0])
        probs = self.policy_probs(state, explore=True)
        return int(self.rng.choice(self.n_action, p=probs))

    def update(
        self,
        state: int,
        action: int,
        reward_next: float,
        next_state: int,
        next_action: int,
        terminated: bool,
    ) -> float:
        bootstrap_mask = 0.0 if terminated else 1.0

        if self.target_type == "sarsa":
            next_value = self.q[next_state, next_action]
        elif self.target_type == "expected_sarsa":
            next_value = float(
                self.policy_probs(next_state) @ self.q[next_state]
            )
        else:
            next_value = float(self.q[next_state].max())

        target = (
            reward_next
            + self.gamma * bootstrap_mask * next_value
        )
        td_error = target - self.q[state, action]
        self.q[state, action] += self.alpha * td_error
        return float(td_error)

truncated 没传进 update，是因为它不决定 bootstrap mask；训练循环仍保留该字段，用它决定何时 reset。

训练循环：边界与动作携带分开

def train(
    agent: TabularTD,
    episodes: int,
    seed: int,
    max_steps: int = 500,
) -> list[float]:
    env = gym.make("CliffWalking-v1")
    env.action_space.seed(seed)
    returns = []

    for episode in range(episodes):
        state, _ = env.reset(seed=seed + episode)
        action = agent.act(state, explore=True)
        episode_return = 0.0

        for step in range(max_steps):
            (
                next_state,
                reward_next,
                terminated,
                env_truncated,
                _,
            ) = env.step(action)

            # 本地预算结束是 truncation，不是 MDP termination。
            budget_truncated = (
                step + 1 == max_steps and not terminated
            )
            truncated = env_truncated or budget_truncated

            # Sarsa 必须把同一个 next_action 用于 target 和下一次 step。
            next_action = agent.act(next_state, explore=True)
            agent.update(
                state,
                action,
                float(reward_next),
                next_state,
                next_action,
                terminated=terminated,
            )

            episode_return += float(reward_next)
            if terminated or truncated:
                break
            state, action = next_state, next_action

        returns.append(episode_return)

    env.close()
    return returns

若 vector env 自动 reset，next_state 必须替换为 final_observation；否则 truncation 后会错误地从下个 episode 的初始状态 bootstrap。

\(n\) 步队列的 flush 合同

一步代码之外，\(n\) 步实现必须通过以下四项测试：

  1. 队列保存 \(S_t,A_t,R_{t+1}\) 以及边界字段，索引不平移。
  2. 队列长度达到 \(n\) 时更新最旧条目；正常 episode 结束后继续 flush，直到队列为空。
  3. 中途遇到真正 termination，之后的奖励和 bootstrap 都不存在。
  4. 遇到 truncation，停止收集当前 episode，但若任务语义允许继续，用 final observation 与对应策略动作补上 bootstrap。

固定手算轨迹应逐一核对 \(n=1\)、\(n=2\)、\(n\) 大于剩余长度三种情况。完整的边界夹具见环境边界页。

独立评估与标准环境夹具

def evaluate_greedy(
    agent: TabularTD,
    episodes: int,
    seed: int,
    max_steps: int = 500,
) -> np.ndarray:
    env = gym.make("CliffWalking-v1")
    scores = np.empty(episodes, dtype=np.float64)

    for episode in range(episodes):
        state, _ = env.reset(seed=seed + episode)
        score = 0.0
        for _ in range(max_steps):
            action = agent.act(state, explore=False)
            state, reward_next, terminated, truncated, _ = env.step(action)
            score += float(reward_next)
            if terminated or truncated:
                break
        scores[episode] = score

    env.close()
    return scores

实验与结果分析：先固定口径，再报告证据

本页不把某一次运行的路径图或未经附带产物验证的数字写成既定结果。CliffWalking 的经典现象适合作为待复现实验假设：固定非零 \(\epsilon\) 时，Sarsa 学习行为策略的价值，可能为降低探索跌崖代价而形成较远的路径；Q-learning 的 greedy target 更倾向于标准环境中的最短路径。它不是跨环境定理，也不能由单个 seed 证明。

最小可复现实验矩阵

因子 至少包含 为什么必须控制
算法 Sarsa、Expected Sarsa、Q-learning 分离采样 target、期望 target 与 greedy target
探索率 固定 \(\epsilon\) 与预注册的衰减日程 Sarsa 的估计对象随行为策略改变
随机性 至少多个独立训练 seed 跌崖事件会造成重尾波动
预算 相同环境步数，而不只相同 episode 数 不同算法的 episode length 不同
评估 冻结 Q、\(\epsilon=0\)、独立 seed 与训练期 behavior return 分开
环境 Gymnasium 版本、环境 ID、TimeLimit、wrapper 顺序 防止把不同合同的任务误作同一基准

每个运行保存逐 episode return、length、cliff-entry count、成功标记和累计环境步数；每个检查点另跑独立 greedy evaluation。聚合时报告中位数或均值及不确定性区间，同时保留每个 seed 的原始曲线，不能只给最后一百回合的单点平均。

四个必须回答的问题

  1. 训练期表现：带探索的 behavior policy 实际获得多少回报、发生多少次跌崖？
  2. 部署策略表现：冻结后确定性 greedy policy 的回报、成功率和路径长度是多少？
  3. 样本效率：达到预先声明阈值需要多少环境步，而不是多少回合？
  4. 稳健性：结论是否在多个 seed、\(\epsilon\) 和学习率下保持，还是只在一个配置上出现？

若要比较路径，可画每个状态的确定性 tie-break greedy action，并同时报告访问计数。未访问状态的箭头只是初始化和 tie-break 的产物，不能被解释成“学到的策略”。

预期现象、反例与结论边界

在标准合同、固定非零 \(\epsilon\) 和充分训练下，可以检验以下预期：

  • Q-learning 的 greedy evaluation 可能更接近最短路径；
  • Sarsa 的训练期 behavior return 可能更高，因为其 target 计入持续探索的风险；
  • \(\epsilon\) 减小时，两者策略差异通常缩小，但有限样本下不保证单调；
  • Expected Sarsa 可能降低下一动作采样带来的 target 方差，但效果依赖访问分布和步长。

任何一项若未出现，先检查环境合同、终止 mask、动作携带、tie-breaking、探索日程与训练预算；检查后仍不出现，就如实报告反例。不能把“在一个经典网格中常见”写成“on-policy 普遍更安全”或“off-policy 普遍部署更优”。

与动态规划的公平对照

动态规划、Sarsa 和 Q-learning 只有在同一个环境模型、同一个 \(\gamma\)、同一个 termination 定义下才可比较。建议从 env.unwrapped.P 计算价值迭代基准，再对每个已学习 greedy policy 做精确 policy evaluation，并验证：

\[\lVert T^*Q-Q\rVert_\infty, \qquad J(\pi_{greedy}), \qquad \Pr(\text{success}), \qquad \mathbb{E}[\text{episode length}].\]

“Q-learning 复现 DP 最优策略”只有在残差、策略值和访问覆盖均支持时才能下结论。完整 manifest、seed 聚合和置信区间规范见评估与可复现页。

关键参数：机制、风险与调参顺序

参数 它控制什么 常见风险 建议检查
\(\alpha\) 新 TD error 对当前估计的权重 固定过大时振荡；过小时有限预算内传播慢 多个对数尺度候选，报告最终与学习速度
\(\epsilon\) behavior coverage；对 Sarsa 还定义估计对象 太小导致覆盖不足；固定较大带来持续执行代价 同时记录探索日程与实际动作概率
\(\gamma\) 任务目标的时间偏好与 bootstrap 传播 不能只按“有效视野”机械设定；接近 1 时误差传播更敏感 与任务时标、termination 和奖励尺度联合选择
\(n\) 真实奖励与 bootstrap 的混合跨度 边界 flush 错位；更大不保证更稳或更保守 用手算轨迹测试 \(n=1,2\) 和回合尾部
初始化 未访问动作的相对偏好 乐观初始化会改变探索，零初始化也并非中性 报告初值并查看访问计数
预算 覆盖和估计精度 相同 episode 不等于相同样本量 以环境步为主轴，episode 为辅助
seed 环境、动作空间和算法 RNG 漏设某一随机源导致不可复现 分离训练与评估 seed，保存 manifest

不存在对所有表格型任务都正确的“\(\alpha=0.1\)、\(\epsilon=0.1\)、训练 500 回合”。推荐顺序是：先锁定环境与边界合同，再固定评估协议；随后小范围联调 \(\alpha\) 和探索日程；最后比较算法和 \(n\)。\(\gamma\) 若属于任务定义，应先于算法调参固定，不能为美化曲线随意改变。

理论上，访问相关的递减步长和 GLIE 类探索日程可支撑部分表格型收敛结论；工程上常用固定步长与非零探索是在追踪能力、覆盖和渐近精确之间做取舍。页面必须明确自己讨论的是哪一种设定，不能把固定超参数实验直接等同于渐近定理。

小结与下一章的衔接

本章应记住五件事：

  1. TD 用真实的一步奖励加 bootstrap 构造 target；它既不是完整模型期望，也不是完整 Monte Carlo return。
  2. “target 对当前样本的条件期望正确”不等于当前价值估计无偏；收敛保证还依赖表格表示、访问覆盖和步长条件。
  3. Sarsa、Expected Sarsa 与 Q-learning 的核心差异是下一状态价值由采样行为动作、行为策略期望还是 greedy target 给出。
  4. terminated 决定真正的 bootstrap 边界，truncated 决定采样何时 reset；两者不能先合并成一个 done。
  5. 训练期 behavior 指标与冻结策略 evaluation 指标回答不同问题，任何安全性或最优性结论都必须注明口径。

留下的限制与下游

表格型 TD 无法自然泛化到连续或高维状态。它也没有自动复用数据或规划未来的机制，但“每条转移只能使用一次”并不是算法定理：数据能否重放取决于 target、策略滞后、覆盖和是否进行了必要的 off-policy 校正。

Dyna-Q在真实 TD 更新之外学习模型并生成规划更新；DQN用函数逼近和 replay 扩展 Q-learning。Q-learning 的 off-policy 结构使经验重放更自然，但并不意味着任意旧数据都安全；Sarsa 类方法也不是绝对不能复用数据，只是必须保留行为信息或采用相应校正。

最大化估计会引出过估计偏差，后续见 Double DQN 与 Dueling DQN 和 TD3；连续动作下不能枚举 \(\max_a\)，由 DDPG 等 Actor–Critic 方法处理。若希望先建立无 bootstrap 的完整采样基线，应先读蒙特卡洛页。

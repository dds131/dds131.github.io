GR00T N1 总览/③ Flow Matching、损失与时间方向

CONDITIONAL FLOW · GLOBAL MASK REDUCTION · FORWARD EULER

GR00T N1 用 x_τ=(1-τ)ε+τY 把噪声连接到任一连续监督目标；固定源码以 Y-ε 训练并用正向 Euler 积分，三者彼此自洽，而论文式 (1) 印刷的 ε-A 与其端点和正更新号相反。这个冲突必须保留，不能静默改写，也不能让统一公式抹去真机、仿真、latent 与 IDM 伪标签的 provenance。

τ: 0 → 1噪声端 ε 到监督目标端 Y；每个样本的整个动作块共享一个连续 τ。
Y − ε固定源码速度目标，与直线路径导数和正向 Euler 同号。
E[τ] ≈ 0.3994α=1.5、β=1、s=0.999 的源码时刻变换均值。
K = 4 / 16论文报告 4 步；固定发布配置默认 16 步，未给完整优劣消融。
paper · printed sign conflictsource · self-consistent directionconfig · release K=16math audit ≠ runtime evidence

为什么使用条件生成

同一观测和任务可能对应多条合理动作块。确定性网络在平方损失下倾向条件均值，该均值可能处于多个模式之间；Flow Matching 用随机初始噪声与条件速度场表示条件分布，不同 ε 可以产生不同样本。

方法边界：这不证明连续动作必须使用 Flow。混合密度、连续潜变量、diffusion 或联合离散模型也能建模多峰；逐维独立分类若不建模联合结构，也不会自动保留跨时间和跨关节相关性。Flow Matching 不是 diffusion 的同义词，更不是 N1 首创。

直线路径、端点与边缘速度

给定条件 c，从监督目标与标准高斯分别采样 Y 和 ε：

Y ~ p_target(Y | c)
epsilon ~ Normal(0, I)
x_tau = (1 - tau) * epsilon + tau * Y
d x_tau / d tau = Y - epsilon

模型只观察 x_τ,τ,c，看不到生成该点的完整配对，因此平方回归的最优边缘速度是：

u_tau(x | c) = E[Y - epsilon | x_tau = x, tau, c]

在常见正则条件下，解 dx/dτ=u_τ(x|c) 可以把噪声分布搬运至条件 target 分布。固定配对路径为直线，不表示学习后的边缘 ODE 轨迹也必为直线，更不能据此证明四步 Euler 足够或全局误差很小。

论文反号与固定源码自洽方向

论文 v2 同时给出：

A_t^tau = tau * A_t + (1 - tau) * epsilon
paper target = epsilon - A_t
A_t^(tau+1/K) = A_t^tau + (1/K) * V_theta(...)
K = 4 works well

第一式的导数是 A_t-ε，却与论文 target 相反。若从 x_0=ε 以常向量 ε-A 正向积分一个单位，符号玩具反证的终点是 2ε-A，不是 A。这个玩具只裁决符号，不冒充真实边缘网络输出。

固定 n1-release 的训练路径是：

noise = randn_like(Y)
tau = sample_time(B)[:, None, None]
x_tau = (1 - tau) * noise + tau * Y
v_star = Y - noise
k = trunc(1000 * tau)
v_pred = decoder(DiT(encoder(x_tau, k, embodiment_id), k, condition))

源码的插值、Y-ε 目标与正向 Euler 同号且内部自洽。最窄、可核验的结论是“论文式 (1) 很可能有符号转写错误”；这是推断，官方原因未知，不能编造为来自 π0 的翻转失误。论文函数签名 V_θ(φ_t,A_t^τ,q_t) 没显式列 τ，但正文说明 denoising-step conditioning；把 τ 写进实际模型输入是实现显式化，不是篡改论文原式。

全 batch mask 损失与 provenance 风险

固定源码的基础 Flow loss 是整个 batch 的逐有效标量平均：

L_fm = sum_bhj M_bhj * (V_theta_bhj - (Y_bhj - epsilon_bhj))^2
       / sum_bhj M_bhj

它不是先按样本、本体、来源或动作块求均值；有效动作维较多的样本贡献更多标量项，来源权重与本体平衡不会在动作头内自动校正。论文式 (1) 没写 mask，并只显式写 E_τ；论文抽象目标和源码 mini-batch estimator 必须分层。

同一公式不等于同一真值等级
supervision Y 的语义 能拟合 不能保证
recorded 归一化实机动作 记录分布 动作无噪声或最优
simulator 仿真器动作 仿真分布 sim-to-real
latent 量化前视觉变化 embedding LAPA target 分布 可执行控制
IDM 模型预测动作块 伪标签分布 伪标签正确

公开 action_mask 只标有效 feature dimension，不标 episode 边界产生的时间 padding，也没有 label truth mask。噪声和插值先在完整32维产生，mask 只用于最终 MSE；无效输入维仍可能经稠密 action encoder 耦合到有效 hidden。若 M.sum()==0，源码没有分母保护。

Beta 时刻变换、论文记号与负桶

发布配置为 α=1.5、β=1.0、s=0.999；固定源码执行：

U ~ Beta(1.5, 1)
tau_src = (s - U) / s = 1 - U/s

因此支持集是 [(s-1)/s,1]≈[-0.001001001,1]。E[U]=0.6，所以 E[τ_src]≈0.399399399，标准差约 0.262123592。规范化密度含变量变换 Jacobian：

f_tau(tau) = alpha * s^alpha * (1 - tau)^(alpha - 1)
support: 1 - 1/s <= tau <= 1

论文写 p(τ)=Beta((s-τ)/s;1.5,1)，却没给支持集与 Jacobian。一个可讨论但不唯一的 change-of-variable reading 是 tau_paper=s(1-U)，支持 [0,s]、均值约 0.3996；它不等于源码 1-U/s，两者均值差约 0.000200601，逐点最大差约 0.001001001。

负连续时刻概率与离散桶必须分开：

P(tau_src < 0) = P(U > s) = 1 - s^1.5
                 ~= 0.001499625 = 0.1499625%
bucket -1 requires U >= 0.999999
P(bucket -1) ~= 1.5e-6, about once per 666,667 samples
P(bucket 1000) = 0 under a continuous distribution

PyTorch 浮点转整数向零截断，所以大多数轻微负 τ 别名到桶0；但插值发生在桶化之前，连续外推不会被别名撤销。源码最大负外推约 0.001001001，实际影响没有公开消融；也没有证据证明该 Beta 优于均匀采样。

Euler 数学、K=4/16 与运行时下沉

固定源码的正向 Euler 数学闭环为：

x_0 ~ Normal(0, I)
dt = 1 / K
for i in 0..K-1:
    tau_i = i / K
    k_i = int(1000 * tau_i)
    x_(i+1) = x_i + dt * V_theta(x_i, k_i, c)
return x_K

网络只在左端点 0,1/K,...,(K-1)/K 求值；最后一次更新给出 τ=1 的近似，不在1再次调用。循环没有重加噪、校正器、classifier guidance 或显式 clamp。

OPTIONAL ANALYSIS · STATIC LEDGER · NOT A BENCHMARK

这是固定源码的静态解析，不是 benchmark。参数量、矩阵乘加和名义张量容量都不等于吞吐、时延、峰值显存、功耗或任务性能。

SIM JOINT CONFIG · SOURCE/DERIVEDK=1 · H=100 · S=302300视觉token；CVAE长度102；query [100,512]；动作输出 [B,100,14]。
REAL JOINT CONFIG · SOURCE/DERIVEDK=4 · H=90 · S=12021200视觉token；CVAE长度92；query [90,512]；动作输出 [B,90,14]。

不可作相机单变量消融：K 与 H 同时变化。隔离 K 的影响必须固定 H；否则参数、query、CVAE 长度和 decoder 算量也一起改变。</div>

参数账本锚点

参数账本：逐模块、逐层与三种总量

固定 d=512、f=3200：P_MHA=4d²+4d=1,050,624；P_FFN=2df+f+d=3,280,512；P_LN=2d=1,024；P_enc_layer=4,333,184；P_dec_layer=5,384,832。

十个小模块：合计 128,079
模块 参数 模块 参数
input_proj_robot_state 7,680 cls_embed 512
encoder_action_proj 7,680 encoder_joint_proj 7,680
latent_proj 32,832 latent_out_proj 16,896
additional_pos_embed 1,024 query_embed 46,080
action_head 7,182 is_pad_head 513

三种总量不能混用：83,917,967 是注册参数；51,608,462 是扣除后六层 32,308,992 与 is_pad_head 513 后的结构任务梯度上限；34,227,022 再扣除 posterior-only 17,381,440，代表需要新类与键映射的整模块 inference-only 保留集合。最后一个值仍保留 latent_out_proj，不是数学最小等价网络。

查看参数公式包含项

MHA含Q/K/V与输出投影的权重和bias；FFN含两层线性权重和bias；每个LayerNorm含scale与bias。encoder层含1个MHA、1个FFN、2个LN；decoder层含2个MHA、1个FFN、3个LN。百分比和显示用M值仅供阅读，所有总量由整数相加。

算量账本锚点

算量账本：encoder、decoder 与 CVAE

只计矩阵乘加 MAC：C_enc(S)=4Sd²+2S²d+2Sdf；C_dec(S,H)=(4Hd²+2H²d)+(2Hd²+2Sd²+2HSd)+2Hdf。不含 LayerNorm、softmax、激活、dropout、偏置、数据搬运和框架调度。

DERIVED · Transformer 解析 MAC，不含视觉主干
部件 K=1/H=100 K=4/H=90
encoder 单层 1.400 G 6.679 G
decoder 单层 0.684 G 1.186 G
主4层encoder + 7层decoder 10.39 G 35.01 G
CVAE 4层encoder 1.81 G 1.63 G

K=4使主encoder的线性项随S增长、attention项随S²增长，所以单层为4.77倍而不是精确4倍。decoder的1.73倍同时受H与S影响，不能归因于单一变量；CVAE真机值更小来自H=90而非相机数。MAC不能直接换算实际时延、吞吐、功耗或硬件瓶颈。

查看两条公式的口径限制

公式只覆盖Transformer线性投影、score/value矩阵乘与FFN矩阵乘；未纳入ResNet、非矩阵算子和运行时开销。若实现使用融合kernel、混合精度或不同数据布局，硬件行为仍须单独测量。

名义容量锚点

名义容量：attention score 不是峰值显存

固定 PyTorch 2.0.0、need_weights=True、B=8、heads=8、fp32，单个主encoder层内部逐头score/weight张量名义容量按 B×heads×S×S×4 bytes 计算。

NOMINAL · 假定显式物化一个逐头score或weight张量
配置 S 名义容量 相对值
K=1/H=100 302 22.3 MiB 1×
K=4/H=90 1202 352.7 MiB 约15.8×

该数字不包含Q/K/V、softmax/dropout中间量、其他激活、反向保存、参数、梯度、优化器状态、allocator保留和框架拷贝；不能乘层数后称为峰值，也不能称总显存、显存下界或实测。融合attention、混合精度、重计算与不同 need_weights 路径都可能改变物化行为。

未来测量协议必须固定版本、硬件、B/K/H、dtype、train/eval、grad/no-grad、allocator统计口径、warmup、重复次数、峰值API与原始日志；当前状态 NOT_MEASURED / NOT_RUN，未加载模型或分配GPU。

梯度可达性锚点

梯度可达性：L1、KL、零梯度与 None

KL没有直接视觉/主干路径；L1可经重参数化到posterior。后六层与is_pad_head的optimizer语义不能混同：若grad是数值零而非None，AdamW仍可能施加解耦权重衰减；grad=None时通常跳过。实际 grad is None、最大绝对值与一步更新差异均为 NOT_RUN。51,608,462只称结构上限，不是观测到非零梯度的参数数。

Checkpoint兼容锚点

超参—shape—checkpoint 兼容矩阵

能载入不等于语义兼容；strict=False不等于迁移完成
改动 shape或语义影响 strict checkpoint边界
chunk_size / num_queries / H query行数、pos_table H+2、动作输出。 query_embed/pos_table shape冲突。
camera_names / K S、MAC、容量与视角语义；camera order可静默错位。 固定H时参数shape可相同，但语义未必兼容。
nheads 每头维、缩放与通道分组。 d可整除时权重shape可能可载入，但函数语义改变。

state_dim qpos输入投影。 对应输入层shape冲突。
action_dim action投影与输出head。 对应输入/输出层shape冲突。

兼容记录必须同时保存 producer config、consumer config、冲突键、迁移规则和未初始化参数。只有“load成功”或使用 strict=False，不足以证明接口与语义迁移完成。

Inference裁剪锚点

inference-only 裁剪边界与 CNNMLP 对照

原始rollout自动跳过posterior前向，但完整checkpoint中的posterior参数仍驻留。按整模块inference-only重构可移除CVAE encoder、cls_embed、encoder_action_proj、encoder_joint_proj和latent_proj，合计17,381,440；固定 hs[0] 又使decoder layers 1–6不影响动作输出，is_pad_head也未被消费。

裁剪是新实现合同，不是从原类直接删成员
分支 必须保留或新增 当前证据状态
忠实复现 原类、完整键、完整7层执行与固定[0]行为。 SOURCE；保持官方checkpoint行为。
整模块inference-only 新类、键过滤/映射、保留输出合同、相同输入动作对比。 DERIVED；等价验证NOT_RUN。
常量折叠 把保留的latent_out_proj(z=0)进一步折为bias常量。 额外图变换；NOT_RUN。
架构修复 若改用[-1]、裁层或加auxiliary loss，必须重训并使用新版本ID。 不声称兼容官方行为。

34,227,022不得称官方模型或论文参数量，也不是已证明的最小等价网络。任何裁剪都不能靠删除成员后继续strict load来替代键映射与输出等价检查。

CNNMLP对照锚点

CNNMLP 只作固定源码结构基线

CNNMLP K=4：注册参数 56,485,196（56.49M）
组成或接口 CNNMLP DETRVAE 对照

汇入Attention锚点

结论、限制与汇入 Attention

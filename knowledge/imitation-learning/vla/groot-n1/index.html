DUAL BACKBONE · CROSS-EMBODIMENT · DATA PYRAMID

GR00T N1 以 Eagle‑2 视觉语言主干和 Flow Matching DiT 动作主干构成 2.2B 参数双系统策略，通过按本体输入输出层与数据金字塔统一多类机器人和视频监督；它展示的是初代通用人形 VLA 的系统组合，不等于任意本体零样本、长时移动操作或安全关键部署已成立。

2.2B论文报告的总参数规模。
1.34B论文中的 Eagle‑2 VLM 组件口径。
H = 16发布实例的连续动作块长度。
1 + 8一个总览与八个职责互斥的子页。

三组约束与系统选择

N1 把三个耦合问题放在同一系统中处理，但这些选择不是唯一可行答案，也不构成最优性证明。

本体接口异构不同机器人的状态和动作字段、维度与语义不同。N1 用按本体 State Encoder、Action Encoder 与 Action Decoder 把差异限制在共享主干的边界。
连续联合动作动作维度相互关联，且一次预测 H=16。N1 用共享 DiT 上的 Flow Matching 生成连续动作块。
真实机器人数据昂贵真机轨迹规模有限。N1 把真实机器人、仿真、人类视频与神经生成视频组织为异构数据金字塔。

双系统调用与跨本体边界

System 2 使用 Eagle‑2：SigLIP‑2 视觉编码器、视觉连接器和 SmolLM2 语言模型把图像与语言编码为条件 token。论文描述 224×224 图像经 pixel shuffle 后形成每帧 64 个视觉 token；固定实现通过保留前 12 层获得中间表示，并将 2048 维表示投影到 1536 维动作条件空间。64 是进入语言模型的处理后序列口径，不是视觉塔原始 patch 计算量。

System 1 把按本体编码后的 1 个状态 token 与 16 个含噪动作 token 送入 16 个参数独立的 DiT 块。交替模式下，偶数块通过交叉注意力读取视觉语言条件，奇数块在状态/动作序列上执行自注意力；末端只取 16 个动作 token，经共享输出投影与按本体 decoder 得到速度场。“共享动作主干”指多本体共享 DiT，不是 16 个块共用权重。

九页专题地图

专题内部只有一个学习顺序：Architecture → Data Pyramid → Flow Matching → Training → Inference Deployment → Experiments → Phenomena → Source Code。新增 Inference Deployment 用于填补“模型能前向”到“策略能安全、可诊断地运行”之间的接口空白；当前为 accepted new page，不能伪装成既有源页。

四张事实摘要

Flow：端点、符号和步数

固定实现使用

\[A^\tau=\tau A+(1-\tau)\epsilon, \qquad \tau=0\text{ 为噪声端，}\tau=1\text{ 为数据端。}\]

插值导数是 $A-\epsilon$，固定源码也以 actions - noise 为训练目标，并从噪声端用正步长 Euler 前进，源码内部自洽。论文式 (1) 印刷为 $\epsilon-A$，符号相反；本页保留冲突，不静默改写论文。论文记号可反解为 $\tau=s(1-u)$，固定源码实现为 $\tau=(s-u)/s$，其中 $u\sim\mathrm{Beta}(1.5,1)$、$s=0.999$；两式接近但不相等，源码存在约 $-0.001001$ 的极小负尾部。

论文报告 $K=4$ 工作良好，发布配置保存 num_inference_timesteps=16。两者属于不同来源；实际运行必须记录 override 后的 num_steps，不能任选一个覆盖另一个。

实验：点估计与归因上限

论文在三个仿真集合与 GR‑1 真机桌面任务上比较完整系统和从零训练基线。真机汇总中，N1 使用 10% 后训练数据为 42.6%，Diffusion Policy 使用 100% 数据为 46.4%；这支持该协议下的样本效率判断。N1 使用 100% 数据为 76.8%，但比较同时改变预训练、架构、容量和数据，差值不能拆成某个单组件的因果贡献。

神经轨迹的正增益被作者称为 preliminary，真机仅测试低数据档。平滑、抓取准确和 baseline 起始帧不动是定性观察；在没有误差条、置信区间或多种子信息时，不应写成统计显著，也不能把 GR‑1 的趋势外推到全部仿真集合。

已支持的焦点论文所训练本体和任务范围内的短时桌面操作、协议内样本效率与多来源共训。

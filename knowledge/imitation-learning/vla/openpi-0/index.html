π0 的问题定位与系统边界

π0 处理的是大规模视觉—语言条件如何连接到连续机器人动作块。最小系统链是：图像/语言形成 VLM prefix；机器人状态、流时间与含噪动作形成 action suffix；固定模态双专家在每层联合注意力中交换信息；动作侧输出与动作块同形的速度；数值积分后得到连续动作块。

它不是把预训练 VLM 后面简单串一个完全独立 decoder，也不是带 learned router 与 load-balancing loss 的标准稀疏 MoE。模态路由是固定的，两侧拥有不同宽度与权重，但在联合注意力中交互。动作专家较小不能推出“动作比语言简单”，PaliGemma 初始化也不能推出开放世界任务保证。

贡献应概括为四类接口组合：动作专家接口；连续高频动作块生成；跨本体预训练—后训练系统；真实机器人规模化评测。PaliGemma、Flow Matching、Action Chunking、专家模型和跨本体训练均有前序工作，不能写成 π0 逐项首创。

双专家系统缩略图锚点

最小系统链：prefix、suffix 与双专家

缓存必须分开两层陈述：设计上不变的条件可缓存；固定提交实际缓存哪些prefix、在哪个后端实现，必须以源码页为准。“允许缓存”不能改写成“所有实现都已缓存”，推理也不能描述成完整网络每步全部重算。

最小FlowMatching心智模型锚点

最小生成链：噪声、速度场与动作块

论文 v4 以 tau=0 为噪声、tau=1 为动作，固定动作—噪声对的线性配对目标是 A-epsilon；固定 openpi 以 t=1 为噪声、t=0 为动作，目标是 epsilon-A。二者满足 tau=1-t，是坐标与速度符号约定，不是两种算法。

网络学习的是给定含噪动作、时间与条件后的边缘速度场。固定样本对的条件路径是线性的，不代表混合分布的速度场或 ODE 推理轨迹全局直线。shifted-Beta、截断、Euler步长、NFE和v3符号史下沉Time/Flow责任页。

随机初始噪声提供采样入口，但不能保证选到任务正确模式、自动恢复或物理安全；生成动作仍需执行协议、有效性检查和独立安全链。

动作与跨本体合同锚点

动作合同、跨本体与 H/E/R

π0 输出长度 H=50 的连续动作块，不是离散动作 token 路线。H 是预测长度；E 是每次实际消费的步数；R 是重新获取观测/调用策略的周期。三者必须分别记录，不能假设完整50步全部开环执行。

跨本体合同至少冻结：相机/状态字段；关节或末端动作语义；绝对/增量/速度模式；维度与padding/mask；frame/unit；夹爪编码；normalizer与统计量；控制频率；H/E/R；反归一化、限幅和底层控制器。补零只解决张量宽度，不解决语义对齐。

论文接口宽度18与固定源码类默认Pi0Config.action_dim=32分开；具体命名config可以覆盖默认。图像有效mask、动作维mask和序列padding也不能互换。

训练推理边界锚点

训练、推理与缓存的阶段差异

同一网络在不同阶段消费不同随机量与系统状态
阶段 起点 网络工作 输出/消费 必须另报
训练 真实动作、噪声与单个时间样本。 构造含噪动作，一次前向回归速度；不执行完整采样循环。 masked/reduced flow loss。 数据、normalizer、时间采样、optimizer、EMA/LoRA、配置与checkpoint。
推理 观测条件prefix与初始噪声动作。 先计算条件，再多步更新action suffix；缓存范围绑定实现。 连续动作块样本。 NFE、每次评估模块、p50/p95、硬件、精度与网络时延。
执行 反归一化动作块与最新系统状态。 adapter、安全检查、队列和控制器按H/E/R消费。 控制命令、拒绝、重规划或fallback。 control deadline、action age、jitter、限位、碰撞与接管。

总览不保留易被配置覆盖的类默认表，也不把“设计可缓存”写成“固定实现已缓存全部不变条件”。计算成本必须同时记录NFE和每次评估模块范围；只报采样步数不足以比较端到端时延。

实验与能力边界锚点

证据边界、完成语义与 π0.5 出口

所有性能结论必须进入Experiments，并携带任务、机器人、训练阶段、checkpoint、评分rubric、trial/seed、硬件、NFE、控制频率和执行协议。论文的归一化任务进度不能统一改叫成功率，演示视频不是定量证据。

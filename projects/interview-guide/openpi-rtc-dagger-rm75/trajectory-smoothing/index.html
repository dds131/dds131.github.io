二、30 Hz 到 110 Hz 怎样插值

源码确认 对相邻 30 Hz 关节路点 (q_i,q_{i+1})，110 Hz 发送时刻按照所在时间区间计算线性权重：

[ q(t)=(1-\alpha)q_i+\alpha q_{i+1},\qquad \alpha=\frac{t-t_i}{t_{i+1}-t_i}. ]

110/30 不是整数，因此不能固定地在每两个路点间插入同样数量的帧；实现按时间位置取样，避免长期相位漂移。夹爪不是连续关节轨迹：它取最近策略路点，再吸附到 {0, 0.5, 1}，不对开、保持、闭三种命令做连续混合。

常见误区：“30 Hz 模型、110 Hz 下发”不等于每个模型点复制 3 或 4 次。固定插帧会因为 110/30 非整数而累计时间误差。

三、安全平滑的执行顺序

源码确认

  1. 对候选关节目标做状态化 EMA；
  2. 计算各关节速度限制，使用一个共同缩放因子同比例缩放；
  3. 接近软限位时提前刹车；
  4. 接近目标时降低速度，避免过冲；
  5. 对加速度变化再次使用共同缩放因子；
  6. 最后执行硬关节限位裁剪；
  7. 通过唯一发送点写入机器人。

共同缩放因子保持关节空间运动方向；若每个关节独立裁剪，会改变多关节协同轨迹的方向。安全链处理的是“实际允许怎样下发”，RTC 处理的是“新动作块怎样生成并承接旧计划”，二者互补但不等价。

四、EMA 输出低通逻辑

单级 EMA 系数按照采样率 (f_s) 和截止频率 (f_c) 计算：

[ a=1-e^{-2\pi f_c/f_s},\qquad y_t=a x_t+(1-a)y_{t-1}. ]

lpf_order=2 表示串联两级 EMA。截止频率越低、阶数越高，高频抑制越强，但群延迟也更大。夹爪保持离散命令，不经过关节低通。

离线复算 fc=5 Hz 的 ss1.0 记录结果：

指标 滤波前 滤波后 / 保留 解释
指令加速度 RMS 262 113 高频变化明显降低
换向次数 9.5 次/s 3.9 次/s 命令方向抖动减少
1.5 Hz 以下主运动 — 99.8% 低频主体基本保留
估算群延迟 — 约 55 ms 平滑代价，不属于 RTC 推理延迟
3–6 Hz 残留主体位置幅值 — 约下降 7% LPF 对中频主体作用有限

这些是离线命令频谱和统计结果，不是任务成功率，也不应把数值量纲不明的 RMS 改写成物理加速度单位。

五、RTC 离线连续性对照

离线复算 checkpoint 060000 在同一样本、同一噪声下保存了两个 seed 的 RTC/no-RTC 输出：

Seed frozen-prefix MAE：RTC / no-RTC 降低 模型空间二阶差分：RTC / no-RTC 降低
42 0.001814 / 0.023995 92.44% 0.024429 / 0.028038 12.87%
123 0.000474 / 0.006189 92.34% 0.021939 / 0.025196 12.93%

二阶差分没有按时间尺度换算，因此不是物理 jerk；两个 seed 也不能替代多 trial 真机 A/B。单次推理耗时在两个 seed 上方向相反，所以页面不声称 RTC 一定更快或更慢。

六、轨迹“优化”到底是什么

本项目可验证的是一条分层轨迹处理链：

模型空间前缀约束 → 30/110 Hz 时间重采样 → 状态化运动约束 → 可选输出低通

它不是在线求解全局最短路径、碰撞距离、接触力或能耗的最优控制器。准确表述是“轨迹连续性和安全下发优化”，而不是“全局轨迹最优”。

七、参数优化顺序

  1. 锁定 checkpoint、30 Hz 动作语义和 50 步块长；
  2. 关闭额外 LPF，验证 RTC 前缀索引、拒块和队列行为；
  3. 在同输入离线扫描 horizon、guidance 和 schedule；
  4. 用真实控制日志确认 110 Hz 周期没有被记录或 I/O 干扰；
  5. 再扫描 lpf_fc 与阶数，记录平滑改善和群延迟；
  6. 最后做基线、仅 RTC、仅执行侧平滑、二者组合四组 A/B。
面试一句话：RTC 不是客户端事后平均；它在模型生成时约束前缀。客户端再把 30 Hz 关节路点按时间线性插值到 110 Hz，经安全链和可选双级 EMA 下发，夹爪则保持离散三档。

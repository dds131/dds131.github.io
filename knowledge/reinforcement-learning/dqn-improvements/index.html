本专题要解决什么问题

六类缺陷里，最大化操作带来的过估计被研究得最早也最透，本节就以它作为整条改进链的入口；其余五类各自的病因在对应子页展开。

DQN 研究常记录当前状态上的最大 Q 估计，并把它与同一评估策略在相同环境封装下得到的折扣回报估计比较。在 Double DQN 论文的部分 Atari 游戏中，两者出现显著且持续的差距；这说明过估计可能很严重，但不是「每个任务、每个实现都必然不收敛」的普遍定律。要在本地实验中复现这一诊断，必须先统一奖励变换、折扣、终止处理与评估状态分布。

这件事的危害不在于数字难看，而在于它会改变策略本身：

  • Q 值高估如果在所有动作上均匀发生，贪心策略不受影响，因为 argmax 与常数偏移无关。
  • 实际误差通常不均匀，max 更容易选中被高估的动作；访问稀少处往往不确定性更大，但「一定被推向稀少区域」仍需由访问计数或不确定性诊断验证。
  • 自举会把当前目标中的误差传给后续更新，可能形成持续偏差或不稳定；其量级取决于误差相关性、策略、状态分布和优化过程，不能仅凭一个几何级数断言。

需要先明确一件事：本页正文展开的这两项改进解决的不是同一个问题。Double DQN 针对的是「目标值构造」这一步的统计偏差；Dueling DQN 针对的是「网络结构」的表达效率，它并不直接消除过估计，而是让状态价值 \(V\) 在更多样本上被更新，从而间接改善估计质量。把两者混为一谈是最常见的理解错误。

过估计偏差与 Double DQN：要点

本节只保留结论、关键式子与对照表。完整推导——最大期望值与期望最大值这两个量的区分、Jensen 不等式与赢家诅咒、Thrun 上界与 van Hasselt 下界定理、双估计量为什么反而低估、原版 Double Q-learning 的双表算法与轮盘赌实验、Atari 上的实证数字——见子页过估计偏差与 Double DQN。

病因

DQN 的 TD 目标是

\[y = r + \gamma \max_{a'} Q_{\bar\theta}(s', a')\]

问题出在 \(\max_{a'}\) 这一步。最大值函数是凸函数。若各动作估计在期望上等于真实动作价值，则 Jensen 不等式给出：

\[\mathbb{E}\left[ \max_{a} \hat Q(s, a) \right] \;\geq\; \max_{a} \mathbb{E}\left[ \hat Q(s, a) \right] \;=\; \max_{a} Q(s, a)\]

直观上，max 会偏向误差较大的候选；但不应写成「每个样本都挑到正误差」。不等式可能取等号，例如估计已完全准确、所有动作共享同一误差，或特定退化情形。只要估计误差仍有合适的离散度与相关结构，增加动作候选往往会增强该效应；若训练最终把误差压到零，偏差也会消失。

自举可能传播并放大偏差，但不存在对一般 DQN 都成立的固定 \(1/(1-\gamma)\) 放大倍数。只有在一个刻意简化的玩具模型中——每一步都注入同号常数偏差 \(b\)，且其余条件不变——几何级数才给出 \(b/(1-\gamma)\)（若 \(b\) 定义在下一状态价值上，则当前目标多一个 \(\gamma\)）。有界奖励下的 \(R_{\max}/(1-\gamma)\) 或 \(R_{\mathrm{abs}}/(1-\gamma)\) 还要求无限时域、固定奖励界和一致的终止语义；违反正确值域是红旗，但不能单独证明根因就是 max 过估计。

对策

把目标里那一个 max 拆成「选」与「评」两步，交给不同的网络承担：

\[\max_{a'} Q_{\bar\theta}(s', a') \;=\; Q_{\bar\theta}\Big(s',\ \arg\max_{a'} Q_{\bar\theta}(s', a')\Big)\]

右端暴露出 DQN 的问题：选择与评估用的是同一份带噪估值，等于用同一批数据既选出了赢家、又宣布了赢家的成绩。Double DQN 把评估换给另一个网络：

\[y^{\text{Double}} \;=\; r + \gamma\, Q_{\bar\theta}\Big(s',\ \arg\max_{a'} Q_{\theta}(s', a')\Big)\]

唯一的改动是 argmax 里的下标从 \(\bar\theta\) 换成了 \(\theta\)：选动作用在线网络，评估该动作用目标网络。 落到代码上就是一行。

算法 选择用 评估用 偏差
Q-learning / DQN \(\bar\theta\) \(\bar\theta\) 在无偏且有估计噪声等条件下为非负；严格性依问题而定
Double Q-learning 一组估计 另一组估计 双估计量在相应条件下偏差非正，也可能为零
Double DQN \(\theta\) \(\bar\theta\) 论文中通常显著降低；符号与残余量无普遍保证
两处最容易被记错。其一，Double DQN 的核心不是「从一个网络变成两个网络」——DQN 本来就有在线与目标网络，改的是目标构造中的职责分工。其二，目标网络是在线网络的历史副本，论文明确说二者「并未完全解耦」，因此 Double DQN 不是无偏保证。极端的逐步硬同步会让两组参数几乎相同，接近退化回 DQN；但同步间隔增大也不保证误差相关性单调下降，因为数据、目标与优化历史仍然共享。

Dueling 价值与优势分解：要点

本节只保留结论与两条式子。完整展开——不可辨识性的确切含义与它对应的实测后果、最大值式与均值式的取舍理由、减均值带来的两条实用性质、梯度缩放与梯度裁剪两处工程措施、corridor 与 Atari 的定量证据——见子页Dueling 价值与优势分解。

动机

在很多状态上，「当前状态好不好」很重要，而「各个动作之间差多少」并不重要。单个 TD 样本直接监督被选动作的 Q，但共享主干也会间接影响其他动作，因此不能说一次更新只改变一个输出。Dueling 的真正结构性改动，是显式提供一条跨动作共享的价值流 \(V(s)\) 与一条动作相关的优势流 \(A(s,a)\)，再聚合成完整 Q。

为什么不能直接写 Q = V + A

因为这个分解不唯一。给 \(V\) 加上常数 \(c\)、同时从 \(A\) 减去同一个 \(c\)，两者抵消，得到完全相同的 \(Q\)：

\[\tilde{V}(s) = V(s) + c, \qquad \tilde{A}(s, a) = A(s, a) - c \qquad \Longrightarrow \qquad \tilde{V} + \tilde{A} = V + A\]

监督信号只约束了两条流输出的和，对各自的绝对水平没有任何约束。同一个 \(Q = 10\) 可以由 \(V=7, A=3\) 给出，也可以由 \(V=100, A=-90\) 给出。论文指出，这种不可辨识性对应着直接使用该式时可观测的性能下降。

聚合式

消掉那个自由常数的办法是给优势流加约束。论文给了两个方案，最终采用减均值这一个：

\[Q(s, a; \theta, \alpha, \beta) \;=\; V(s; \theta, \beta) + \left( A(s, a; \theta, \alpha) - \frac{1}{|\mathcal{A}|} \sum_{a'} A(s, a'; \theta, \alpha) \right)\]

另一个方案是减去 \(\max_{a'} A(s,a')\)，此时 \(V(s)=\max_a Q(s,a)\)，与贪心状态价值对齐。论文最终采用均值式，理由是优势只需随均值移动，而最大值式要补偿最优动作优势的变化。连续输出的 max 本身仍连续；argmax 切换改变的是梯度分支，并列处不可微，不能误写成数值跳变。

减均值固定了优势的零均值基准，并保留动作间相对排序，因此 \(\arg\max_a Q=\arg\max_a A\)。这表示动作选择只依赖优势排序；实现仍要计算共享特征，常见前向也会同时计算价值 head。聚合式是网络前向的一部分，不是独立算法步骤，因此接口上可套用 DQN、Double DQN、SARSA 等算法。

与 Double DQN 的关系

两者作用位置不同、可以组合：Double DQN 改 TD 目标，Dueling 改网络表示。可组合不等于统计独立，因为它们仍共享数据、目标与优化过程，组合收益必须用消融验证。Dueling 不直接消除 max 过估计；它希望提高跨动作共享价值信息的学习效率。

算法流程

本节压缩处理。Dueling 只在第 1 行更换网络结构，Double DQN 只在第 12 行更换目标构造；环境交互、回放采样与优化外壳保持一致。

输入: 折扣 gamma, 学习率 alpha, 批量 B, buffer 容量 N,
      目标网络同步间隔 C, 探索系数 epsilon, 变体 variant

1  初始化在线网络 Q_theta；按 variant 选择单流或 Dueling 结构
2  硬拷贝目标网络 theta_bar <- theta
3  初始化空 replay buffer D
4  for episode = 1, 2, ... do
5      重置环境得到 s
6      for t = 1 .. T do
7          以概率 epsilon 随机取 a，否则 a <- argmax_a Q_theta(s, a)
8          执行 a，得到 r, s_next, terminated, truncated
9          把 (s, a, r, s_next, terminated, truncated) 存入 D
10         if |D| >= 起始学习阈值:
11             从 D 均匀采样一批转移
12             variant 含 double:
                   a_star <- argmax_a' Q_theta(s_next, a')      # 在线网络选
                   q_next <- Q_theta_bar(s_next, a_star)        # 目标网络评
               否则:
                   q_next <- max_a' Q_theta_bar(s_next, a')     # 同一估值选与评
13             td_target <- r + gamma * (1 - terminated) * q_next
14             在不对 td_target 求梯度的条件下，最小化 TD 损失
15             每 C 次参数更新执行 theta_bar <- theta
16         s <- s_next
17         if terminated or truncated then break
18     end for
19 end for

这里把环境边界写成两个变量：terminated 决定是否屏蔽自举，terminated or truncated 决定是否结束当前采样回合。目标计算使用半梯度约定，不对 td_target 反传。硬同步也可换成软更新；本页保留硬同步以便与 DQN/Double DQN 公式对应。

值得单独强调的只有一点：第 12 行的两个分支里，Q_theta 与 Q_theta_bar 的位置不能互换。 上一节的 callout 已经说明写反的后果。

代码实现

下面的教学实现用两个布尔开关覆盖四种组合：vanilla、Double、Dueling、Double+Dueling。它便于检查目标构造和张量形状，但不是附带基准结果的数据资产。示例使用 Gymnasium 的 Pendulum-v1 并离散化一维力矩；它能展示完整流程，却不能预先保证一定出现某种过估计曲线，任何结论都要由多种子实验和价值校准支持。

代码按依赖顺序分成六段，复制到同一个文件里即可运行。前三段是样板，讲解从简；第四段的目标值构造与第三段的 Dueling 前向是本节要讲透的地方。

第一段：依赖与超参数（样板）

import random
from collections import deque

import gymnasium as gym
import matplotlib.pyplot as plt
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F

# ---- 超参数：四种组合完全共用，便于做配对消融 ----
LR = 1e-2                 # 学习率 alpha
NUM_EPISODES = 200        # 训练回合数
HIDDEN_DIM = 128          # 隐层宽度
GAMMA = 0.98              # 折扣因子
EPSILON = 0.01            # epsilon 贪心的探索概率
TARGET_UPDATE = 50        # 目标网络硬同步间隔（单位：更新次数）
BUFFER_SIZE = 5000        # replay buffer 容量
MINIMAL_SIZE = 1000       # buffer 里样本数达到该值才开始更新
BATCH_SIZE = 64
ACTION_DIM = 11           # Pendulum 的连续力矩离散成 11 档
SEED = 0

DEVICE = torch.device("cuda" if torch.cuda.is_available() else "cpu")

random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

这组数值只用于低维教学示例，不是推荐基准。ACTION_DIM = 11 让离散控制保留一定分辨率；动作数增加会在「各动作真值接近、误差有离散度」等条件下增强 max 选择效应，但并非无条件单调。TARGET_UPDATE = 50 控制目标陈旧度与跟随速度的折中，不能等同于网络独立性。固定 EPSILON 便于控制探索强度，但正式实验仍应使用多个配对种子。

第二段：replay buffer（样板）

class ReplayBuffer:
    """先进先出的经验回放池，与 DQN 页的实现完全相同。"""

    def __init__(self, capacity):
        self.buffer = deque(maxlen=capacity)

    def add(self, state, action, reward, next_state, terminated, truncated):
        self.buffer.append(
            (state, action, reward, next_state, terminated, truncated)
        )

    def sample(self, batch_size):
        transitions = random.sample(self.buffer, batch_size)
        state, action, reward, next_state, terminated, truncated = zip(*transitions)
        return (
            np.array(state, dtype=np.float32),
            np.array(action, dtype=np.int64),
            np.array(reward, dtype=np.float32),
            np.array(next_state, dtype=np.float32),
            np.array(terminated, dtype=np.float32),
            np.array(truncated, dtype=np.float32),
        )

    def __len__(self):
        return len(self.buffer)

action 必须以 int64 返回，因为后面作为 gather 索引。回放池同时保留 terminated 与 truncated：前者控制 Bellman 自举掩码，后者只参与采样回合边界。把二者提前压成一个 done 会丢失训练目标所需的信息。

第三段：两种网络结构（Dueling 分支是重点）

class QNet(nn.Module):
    """普通 DQN 用的单分支网络：状态进，每个动作一个 Q 值出。"""

    def __init__(self, state_dim, hidden_dim, action_dim):
        super().__init__()
        self.fc1 = nn.Linear(state_dim, hidden_dim)
        self.fc2 = nn.Linear(hidden_dim, action_dim)

    def forward(self, x):
        return self.fc2(F.relu(self.fc1(x)))


class VANet(nn.Module):
    """Dueling DQN 用的双分支网络：共享主干，分出 V 支与 A 支。"""

    def __init__(self, state_dim, hidden_dim, action_dim):
        super().__init__()
        self.fc_shared = nn.Linear(state_dim, hidden_dim)   # 共享特征主干
        self.fc_A = nn.Linear(hidden_dim, action_dim)       # 优势支，输出 |A| 维
        self.fc_V = nn.Linear(hidden_dim, 1)                # 价值支，输出标量

    def forward(self, x):
        feature = F.relu(self.fc_shared(x))
        advantage = self.fc_A(feature)                      # 形状 (B, action_dim)
        value = self.fc_V(feature)                          # 形状 (B, 1)
        # 关键一行：减去优势在动作维上的均值，把 V 与 A 的平移自由度钉死
        return value + advantage - advantage.mean(dim=1, keepdim=True)

QNet 是样板，跳过。要讲的是 VANet 的 forward，它把上一节的公式一比一落到代码上。

  • advantage 与 value 分别对应 \(A_{\theta}(s, \cdot)\) 与 \(V_{\theta}(s)\)，形状分别是 (B, action_dim) 与 (B, 1)。返回时 value 靠广播加到每个动作上，这正是「\(V\) 与动作无关」在张量层面的体现。
  • advantage.mean(dim=1, keepdim=True) 是沿动作维求均值，得到形状 (B, 1)。维度不能写错：写成 dim=0 会变成沿批量维求均值，把同一批里不同状态的优势混在一起，语义完全错误，而且不会报错——张量形状恰好也能广播，这是本段最隐蔽的一个坑。
  • keepdim=True 保留动作维，结果为 (B, 1)。省略后得到 (B,)：通常当 B != action_dim 时会直接报维度不匹配；当两者恰好相等时才可能静默广播成错误结果。
  • 减均值没有可学习参数，它固定了分解的基准。去掉后代码仍可能运行，但 \(V\) 与 \(A\) 不可辨识；论文报告直接相加表现较差，不能进一步断言所有任务上的 Dueling 收益必然归零。
  • 若要改用最大值形式，把 advantage.mean(dim=1, keepdim=True) 换成 advantage.max(dim=1, keepdim=True)[0] 即可。max 返回的是 (values, indices) 二元组，取 [0] 才是数值——漏掉这个下标会让整支代码在类型上出错。
两种网络的输出形状完全一致，都是 (B, action_dim)。这是 Dueling 能作为「插件」使用的原因：算法类里除了实例化哪个网络，其余代码一行都不用改。下一段的 DQN 类会看到这一点。

第四段：算法类与目标值构造（本节核心）

class DQNAgent:
    """四种组合共用的算法类。variant 取 'vanilla' / 'double' / 'dueling' /
    'dueling_double'；两个特性作用位置不同，可以同时打开。"""

    def __init__(self, state_dim, hidden_dim, action_dim, variant="vanilla"):
        self.action_dim = action_dim
        self.gamma = GAMMA
        self.epsilon = EPSILON
        self.target_update = TARGET_UPDATE
        self.device = DEVICE
        self.count = 0                                   # 已完成的更新次数

        # 两个开关分别决定网络结构与目标构造；训练效果仍可能交互
        self.use_dueling = "dueling" in variant
        self.use_double = "double" in variant

        net_cls = VANet if self.use_dueling else QNet
        self.q_net = net_cls(state_dim, hidden_dim, action_dim).to(self.device)
        self.target_q_net = net_cls(state_dim, hidden_dim, action_dim).to(self.device)
        self.target_q_net.load_state_dict(self.q_net.state_dict())   # 硬拷贝初始化
        self.optimizer = torch.optim.Adam(self.q_net.parameters(), lr=LR)

    def take_action(self, state):
        """epsilon 贪心。"""
        if np.random.random() < self.epsilon:
            return np.random.randint(self.action_dim)
        state_t = torch.tensor(np.array([state]), dtype=torch.float, device=self.device)
        with torch.no_grad():
            return int(self.q_net(state_t).argmax(dim=1).item())

    def max_q_value(self, state):
        """诊断量：当前状态上的最大 Q 值，用来观察过估计。"""
        state_t = torch.tensor(np.array([state]), dtype=torch.float, device=self.device)
        with torch.no_grad():
            return float(self.q_net(state_t).max().item())

    def update(self, batch):
        states, actions, rewards, next_states, terminateds, truncateds = batch
        states = torch.tensor(states, dtype=torch.float, device=self.device)
        actions = torch.tensor(actions, device=self.device).view(-1, 1)
        rewards = torch.tensor(rewards, dtype=torch.float, device=self.device).view(-1, 1)
        next_states = torch.tensor(next_states, dtype=torch.float, device=self.device)
        terminateds = torch.tensor(
            terminateds, dtype=torch.float, device=self.device
        ).view(-1, 1)
        # truncateds 用于采样回合边界，不屏蔽这里的自举
        _truncateds = truncateds

        # 当前估值：取出实际执行过的那个动作对应的 Q
        q_values = self.q_net(states).gather(1, actions)

        # ======== Double DQN 的目标构造分叉点 ========
        with torch.no_grad():
            if self.use_double:
                # 选动作：在线网络。评估该动作：目标网络。两步用不同的网络
                best_action = self.q_net(next_states).argmax(dim=1, keepdim=True)
                max_next_q = self.target_q_net(next_states).gather(1, best_action)
            else:
                # 同一份估值既选又评，Jensen 偏差由此产生
                max_next_q = self.target_q_net(next_states).max(dim=1, keepdim=True)[0]
            td_target = rewards + self.gamma * max_next_q * (1 - terminateds)

        loss = F.mse_loss(q_values, td_target)
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()

        self.count += 1
        if self.count % self.target_update == 0:
            self.target_q_net.load_state_dict(self.q_net.state_dict())
        return float(loss.item())

use_dueling 决定网络类，use_double 决定目标分支，因此软件接口上容易组合；这只能证明实现模块化，不能证明学习动态或最终收益互不影响。组合实验仍需与三个单项基线一起做消融。

q_values = self.q_net(states).gather(1, actions) 这一行是所有 DQN 实现的公共写法：网络输出的是全部动作的 Q，而损失只应该作用在实际执行过的那个动作上。gather(1, actions) 沿动作维按索引取值，actions 必须是形状 (B, 1) 的整型张量，这就是第二段里强调存成 int64 的原因。

接下来是本节的重点，两种目标值构造的逐行对比：

写法 选动作用哪个网络 评估用哪个网络 对应公式
max(dim=1)[0] 目标网络 目标网络 \(r + \gamma \max_{a'} Q_{\bar\theta}(s', a')\)
argmax + gather 在线网络 目标网络 \(r + \gamma Q_{\bar\theta}(s', \arg\max_{a'} Q_{\theta}(s', a'))\)
  • 普通分支：self.target_q_net(next_states).max(dim=1, keepdim=True)[0]。一次前向就把选与评都做完了，因为 max 同时完成了「找出最大值在哪」和「返回那个最大值」。这份紧凑正是偏差的来源——两件事共用了同一次带噪输出。
  • Double 分支：在线网络的 argmax 产生动作索引，目标网络的 gather 评估该动作。索引取决于在线网络误差，所以不能说在线噪声完全没有进入目标；解耦的是「用同一数值既赢得选择又作为评估值」这一耦合。
  • argmax 与 gather 的职责不能互换。 反过来会变成另一种目标定义，并让评估值直接跟随在线网络每步变化。这里整个目标块已在 no_grad 中，差异不是梯度路径，而是数值目标与稳定性语义。
  • keepdim=True 保持 max_next_q 为 (B,1)。 省略后通常维度不匹配；若 B 恰好等于某个尾维，则可能静默广播成错误的 (B,B)。
  • torch.no_grad() 实现半梯度目标。 它避免为目标网络建立无用计算图和累积梯度；Double 分支中的离散 argmax 本来也不可导。不能把缺少 no_grad 简化成「优化器会自动同时更新两端」——目标网络参数并未交给该优化器。
  • (1 - terminateds) 只屏蔽真实终止。 truncated 结束当前采样回合，但在时间限制的 continuing-task 解释下仍应自举。

第五段：动作离散化与训练循环（外壳部分从简）

def dis_to_con(discrete_action, env, action_dim):
    """把离散档位映射回 Pendulum 的连续力矩。"""
    low = float(env.action_space.low[0])
    high = float(env.action_space.high[0])
    return low + (high - low) * discrete_action / (action_dim - 1)


def train(variant, env_name="Pendulum-v1", num_episodes=NUM_EPISODES):
    env = gym.make(env_name)
    env.reset(seed=SEED)
    env.action_space.seed(SEED)

    discrete = isinstance(env.action_space, gym.spaces.Discrete)
    action_dim = env.action_space.n if discrete else ACTION_DIM
    state_dim = env.observation_space.shape[0]

    agent = DQNAgent(state_dim, HIDDEN_DIM, action_dim, variant=variant)
    buffer = ReplayBuffer(BUFFER_SIZE)
    return_list, max_q_list = [], []
    smoothed_q = 0.0

    for episode in range(num_episodes):
        state, _ = env.reset()
        episode_return, done = 0.0, False
        while not done:
            action = agent.take_action(state)
            # 诊断量做滑动平均，否则单步噪声会淹没趋势
            smoothed_q = agent.max_q_value(state) * 0.005 + smoothed_q * 0.995
            max_q_list.append(smoothed_q)

            if discrete:
                env_action = action
            else:
                env_action = [dis_to_con(action, env, action_dim)]
            next_state, reward, terminated, truncated, _ = env.step(env_action)
            done = terminated or truncated
            # 两个边界都保留；目标掩码只使用 terminated
            buffer.add(
                state, action, reward, next_state,
                float(terminated), float(truncated),
            )
            state = next_state
            episode_return += reward

            if len(buffer) >= MINIMAL_SIZE:
                agent.update(buffer.sample(BATCH_SIZE))

        return_list.append(episode_return)

    env.close()
    return return_list, max_q_list

训练循环是标准外壳，只讲三处与本页结论直接相关的地方，其余（回合循环、返回值收集）不展开。

  • dis_to_con 的离散化。 Pendulum-v1 的动作是一维连续力矩，离散 DQN 需要先选定有限档位。增加档数同时改变控制分辨率、每个动作的数据量和误差相关结构；只有在可比真值与合适噪声假设下，更多候选才预期增强 max 偏差，不能承诺调大 ACTION_DIM 就必然复现。
  • smoothed_q 的滑动平均。 单步的最大 Q 值抖动很大，直接画出来看不出趋势。这里用一个衰减系数很接近 1 的指数滑动平均把高频噪声滤掉，保留系统性的漂移——我们要观察的正是「有没有系统性地往上漂」，不是单步取值。
  • terminated 与 truncated 必须分开。 存进 buffer 的终止标志只用 terminated。Pendulum-v1 没有真正的失败状态，回合全部由时间上限截断结束，如果把 truncated 也当成终止，等于告诉网络「到点之后没有任何回报」，Q 值会被系统性压低——那会与本页要观察的过估计现象混在一起，实验结论就作废了。这是本段最容易毁掉整个实验的一处。

绘图代码只是一次单种子冒烟运行。为每个变体重置同一随机种子可形成配对设计、减少部分外部差异，但随机调用路径会在算法分叉后改变，不能因此声称曲线差异只来自算法。CartPole-v1 会自动走离散分支，适合做接口检查；它与 Pendulum 的奖励、终止和动作结构不同，结果不能直接横向比较。

实验与结果分析

上面的代码是可运行的教学骨架，仓库中没有与它绑定的原始日志、随机种子清单和统计汇总，因此本页不宣称已经得到某条稳定曲线。Double DQN 与 Dueling 原论文的结论见对应子页；若要用本地 Pendulum/CartPole 示例验证机制，应按下面的协议生成证据。

最小可审计实验协议

  1. 对 vanilla、Double、Dueling、Double+Dueling 使用相同的一组配对种子，每个变体至少运行足以观察种子方差的若干次；保存逐回合原始数据，不只保存平滑图。
  2. 训练指标与评估指标分离。训练仍用 epsilon 探索；每隔固定环境步，用独立评估环境、epsilon=0、固定评估回合数测回报。
  3. 记录奖励变换、gamma、时间限制、terminated/truncated 处理、目标同步计数单位，以及离散化映射。任一项不同，Q 的量级都不可直接比较。
  4. 报告每个种子的曲线、聚合中心和不确定区间，并预先固定评估时点；不要挑选最佳 checkpoint 后再把同一批评估回合作为无偏成绩。
  5. 做完整四格消融，而不只比较 vanilla 与组合版。组合收益可能小于、等于或大于单项收益之和。

如何校准「过估计」

当前状态上的 max Q 只能作为诊断量，不能直接充当真实值。更可靠的做法是在一批留出状态—动作对上，按同一评估策略采样多条折扣轨迹，估计 Monte Carlo 回报 \(\hat G(s,a)\)，再报告

\[\operatorname{Bias}_{\mathrm{eval}} = \frac{1}{M}\sum_{i=1}^{M}\left[\hat Q(s_i,a_i)-\hat G(s_i,a_i)\right].\]

轨迹回报本身也有采样方差，因此同时报告置信区间或 bootstrap 区间。若只检查值域：在奖励、折扣和终止契约正确时，超出理论界限是实现或估值异常的强警报；它不能单独区分 max 过估计、终止掩码错误、奖励缩放错误或训练发散。

可检验假设，而不是预写结果

  • Double DQN：预期在存在选择—评估耦合的任务上降低观测到的正偏差；残余偏差可能为正、为负或接近零，回报也不保证必然提高。
  • Dueling：在许多动作价值相近、状态价值可跨动作共享时，可能提高学习效率；它不直接修改 max 目标，因此对值偏差的净影响必须测量。
  • 组合版：软件上可以同时启用，但共享的数据与优化会产生交互，不能把「目标像 Double、回报像 Dueling」当作无需验证的结论。
  • CartPole 与 Pendulum：前者动作少且奖励/终止结构不同，差距可能较小，也可能受其他因素支配；这应作为任务依赖性的检验，不是预定答案。

必须一起报告的量

至少同时报告无探索评估回报、训练回报、校准后的 Q 偏差、TD 损失/梯度异常和样本量。只看 Q 会把数值偏高误当成性能，只看回报又无法判断 Double DQN 是否真的通过降低过估计起作用。所有机制性结论都应由「消融 + 多种子 + 价值校准」共同支持。

关键参数配置与原因

与 DQN 页重复的项（折扣因子 gamma、replay buffer 容量、batch size、起始学习阈值）本节不重复，见 DQN 与总览页的对应小节。这里只写与本页正文展开的两项改进（Double 与 Dueling）直接相关的四项。

目标网络同步间隔 C

  • 典型取值：本页代码每 50 次更新同步一次，仅适用于低维教学示例。原始 Atari DQN 使用 10000 次参数更新，Double DQN 论文的一组调参实验使用 30000；这些是特定实现的经验选择，不是「越大越好」的规律。
  • 为什么这么配：\(C\) 同时控制目标跟随速度与陈旧度。很小会使两网接近，削弱选择—评估分离；很大则让目标长期陈旧。误差相关性还受共享数据、目标和优化轨迹影响，不随 \(C\) 保证单调变化，应通过验证曲线与偏差诊断选择。
  • 配错了会怎样：\(C\) 取得过小（极端情况每步同步）时，目标网络与在线网络几乎相同，argmax 与 gather 落在同一份估值上，两者的目标趋于相同，Double DQN 的解耦作用会显著减弱；这一退化趋势不会触发代码错误。\(C\) 取得过大时，目标值长期陈旧，回归目标与当前网络脱节，学习变慢；在非平稳的早期训练阶段尤其明显。

离散化档数（动作数）

  • 典型取值：本页把 Pendulum-v1 的力矩切成 11 档。实际任务按控制精度需求定，通常在个位数到几十档之间。
  • 为什么这么配：档数同时改变控制精度、每个动作获得的样本量以及估计误差的相关性。对真值相近、误差近似同分布且有离散度的候选，增加动作数通常会增大 max 的选择偏差；脱离这些条件就没有普遍的单调结论。11 档只是教学折中，不能保证现象一定清楚。
  • 配错了会怎样：档数太少时动作粒度粗，摆锤这类需要精细力矩的任务无法稳定在目标位置，表现为回报曲线到某个水平就不再上升。档数太多时除了过估计加剧，还有一个实际问题——每个档位分到的样本变少，逼近误差变大，与偏差放大形成叠加。多维动作时更要注意：把 \(d\) 维动作各切 \(n\) 档，动作数是 \(n^{d}\)，这个组合爆炸正是基于价值的方法在连续控制上走不通的根本原因，也是下一章要处理的问题。

是否用均值形式还是最大值形式

  • 典型取值：均值形式，即减去 advantage.mean(dim=1, keepdim=True)。
  • 为什么这么配：两种形式都消除常数自由度。均值式把基准分摊到全部动作；最大值式的值仍连续，但并列处不可微，梯度由当前最大分支承担，并要求其他优势补偿最优优势变化。论文报告均值式优化更稳定。均值式下 \(V\) 等于动作 Q 的均值这一网络分解量，不应自动解释为某个策略的真实 \(V^\pi\)。
  • 配错了会怎样：完全不中心化会留下不可辨识性，论文报告实践表现较差；但不能把它提升为「任何任务收益必为零或必发散」的定理。dim 写成批量维会混合不同状态；keepdim 省略则通常报维度错误，在批量大小恰等于动作数时还可能静默广播。

学习率 alpha 与隐层宽度

  • 典型取值：本页取 LR = 1e-2 与隐层 128，适合低维状态的小任务；视觉输入任务通常小两到三个数量级并配更宽的网络。
  • 为什么这么配：这两项本身与本页改进无关，但有一处必须注意——做变体对比时它们必须完全相同。四种组合的受控差异只有目标构造与网络分支两处，任何其他差异都会污染结论。Dueling 网络多出一支，参数量略高于普通网络，严格的对照实验会把普通网络的隐层调宽一点使参数量对齐，以排除「收益只是来自参数变多」的可能。
  • 配错了会怎样：学习率过大时 TD 回归本身震荡，目标网络也压不住，Q 值可能发散到数量级异常——这时看到的 Q 值飙升是发散而不是过估计，两者会被混淆。学习率过小则训练极慢，偏差还没积累到可见就已经跑完了预定回合数，实验可能误判为「四种组合没有差别」。

③ 优先经验回放

优先重放同时带来两个副作用：多样性损失用随机化优先级缓解，分布偏差用重要性采样修正——而偏差改变的是收敛到的那个解，不是收敛速度。另含两种变体各自的数据结构（sum-tree 只属于比例式）、beta 退火的理由，以及它与「均匀采样打破相关性」之间的张力究竟出在哪一层。

④ 多步回报

唯一一项在理论上站不住却被普遍接受的改进：未修正的 n 步回报不修正行为策略与目标策略的差异。本页讲清这笔欠账欠在哪、为何仍被接受，以及一条反直觉的实证——剥掉多步回报的智能体不再能从更大的回放池中获益，剥掉其它组件的却仍然可以。

n-step · 偏差方差 · 离策略欠账 · 回放容量交互

⑤ 分布式强化学习与 C51

本专题公式最重的一页，核心是一个缺口：理论保证建立在 Wasserstein 上，而算法实际最小化的是交叉熵——恰恰是算子不压缩的那个度量。缺口的来源是样本 Wasserstein 梯度有偏。另含控制情形下一条更强的负面结论：最优性算子在期望值上压缩，但在任何分布度量下都不压缩。

值分布 · Wasserstein · 有偏梯度 · 投影算子 · 交叉熵

⑥ NoisyNet 参数化噪声探索

与 epsilon 贪心的差别不在噪声大小，而在噪声的相干长度：一次权重扰动能在多个时间步上引起一致且状态相关的策略变化。本页另纠正一个流行说法——论文实测表明 sigma 并不总是衰减，倒数第二层在多数游戏上反而上升，智能体不必然演化向确定性解。

参数化噪声 · 因子化高斯 · 相干探索 · sigma 实测演化

⑦ Rainbow：组合与消融

专题收尾页。组合不是叠加——放在一起时每一项都要改（PER 的优先级换成 KL 损失、Dueling 的聚合搬到每个原子上、超参重调）。消融给出完整排序，并澄清一条流传较广但机制被说错的结论：去掉 Double 影响有限，真实原因是分布支撑有界，而非分布式学习消除了过估计。

小结与下一章衔接

三句话回顾（本页正文展开的部分）

  • max 会把估计误差转化为选择偏差，但结论有条件。 在各动作估计无偏等前提下，Jensen 给出非负偏差；严格正偏、动作数效应与自举放大量都取决于误差结构，不能固定写成 \(1/(1-\gamma)\)。
  • Double DQN 分离选择与评估的数值来源。 在线网络选动作、目标网络评估，论文中通常显著降低过估计；由于两网相关，它不是无偏或固定偏差符号的保证。
  • Dueling DQN 显式分出 V 与 A，并需选择一个中心化约束。 原论文采用减均值；不中心化会不可辨识且论文实测较差，但收益大小和组合效果都依任务与优化而定。

与 TD3 的双 Critic 是同一个思想

TD3 处理连续动作时，不枚举显式 \(\max_{a'}\)，而由 Actor 近似寻找 Critic 认为更优的动作。函数逼近误差可能被策略更新利用并形成过估计，这是与 Double Q 思想相通的地方；但 Actor 未必找到全局最大值，偏差大小与符号也不是仅由这一句话保证。

两者的解法思路一致、手段不同：

维度 Double DQN TD3 的 Clipped Double Q
动作空间 离散 连续
max 的形式 显式枚举 argmax Actor 网络近似
用几份估值 在线网络与其目标副本 两套 Critic 及各自目标网络
组合方式 在线选择、目标网络评估 两个目标 Critic 都评估并取较小者
误差关系 共享训练轨迹，高度相关 参数分开，但共享数据与 Bellman 目标，仍可能相关
偏差方向 通常降低正偏；符号无普遍保证 min 显式引入保守倾向，程度依误差相关性

TD3 的两个 Critic 具有分开的参数和优化器，但它们读取相同回放数据并共享目标构造，误差并不独立。取 min 会产生保守倾向，用来抵消策略利用高估误差的风险，也可能带来低估；其效果不能归因于「足够独立所以不会过度保守」。完整推导见 TD3。

下一章：为什么要换一条路线

本专题的六项改进都围绕价值学习展开。对一般连续动作，\(\arg\max_a Q(s,a)\) 通常没有解析解，数值全局优化也可能昂贵；它不是逻辑上「无法计算」，而是难以在每个环境步可靠、高效地求解。 本页的做法是把连续动作离散化，代价上面已经算过——\(d\) 维动作各切 \(n\) 档就是 \(n^{d}\) 个动作，维度稍高就会组合爆炸；档数增加还会改变 max 偏差，但方向与幅度取决于前述误差条件。

下一章换一条完全不同的路线：不再学价值函数再导出策略，而是直接把策略参数化，对目标函数求梯度。这条路线天然支持连续动作，代价是要处理另一个问题——梯度估计的方差。之后的 Actor-Critic 把两条路线合起来，本页的价值函数以 Critic 的身份重新出场。

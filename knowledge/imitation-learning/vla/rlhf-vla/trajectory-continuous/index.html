RLHF-VLA/三分支架构/轨迹偏好与连续策略

TRAJECTORY_CONTINUOUS branch · objective · training · credit assignment

轨迹偏好扩大了评价范围，却没有自动得到逐动作因果归因；连续策略能生成动作，也不等于拥有可直接代入 TPO 的轨迹 likelihood。

本分支从 Architecture 直接进入，按 trajectory log-ratio、learned-reward diffusion RL、CNF density 或 likelihood-free method-specific route 路由；不要求先完成 RM→PPO 或 Direct Preference。

监督 scope、条件、初态、长度与终止对齐

监督 scope 必须唯一声明为 segment | stage | trajectory | episode-result | trajectory-pair | segment-pair | ranked-set | scalar-trajectory | unknown，并记录 start/end event、observation/action opportunity、history/outcome visibility、label authority/confidence、complete/censored/partial、parent IDs 与 eligible/forbidden routes。episode result 不能自动下沉成逐动作因果标签。

condition key 至少绑定 task/instruction/success revision、reset seed 与 measured initial state、scene/objects/disturbance、robot/calibration/sensors、observation/history/timestamps、Action ABI/controller/rate、安全 filter/limits/takeover、horizon/time budget、environment/software 和 evaluator visibility。相同任务名不等于同条件，same seed 也不保证物理初态一致；equivalence 为 exact | measured-equivalent | matched-stratum | approximate | counterfactual | unknown。

chosen/rejected 要有可比 observation/action opportunity、control frequency、horizon/timeout、abort/takeover policy、evaluator view、censoring、assistance 与 disturbance exposure。若一条 safety-abort、一条 natural completion，必须明确是惩罚 abort、比较到共同 cutoff、补 absorbing suffix 还是保留 censored；不可静默 padding。

终止至少拆为 success、task-failure、natural-terminal、timeout、truncated、safety-abort、human-takeover、operator-abort、environment/sensor/collector failure、reset、unknown；每种绑定 last executed action、next observation、absorbing semantics、eligibility 和 pair policy，单个 done 不合格。

length 同时报 environment/control steps、policy decisions、chunk factors、tokens，以及 observation/action/executed/credit/terminal/loss masks、padding/missing policy、effective denominator 与 chosen/rejected/task/termination 分布。sum、mean、discount、weight 和 cutoff 是不同 objectives。

完整轨迹密度、policy likelihood 与环境项相消

完整 physical trajectory density 为：

\[p_\pi(\zeta\mid x)= \rho_0(s_1\mid x) \prod_{t=1}^{T} \pi(a_t\mid h_t,x) P(s_{t+1}\mid s_t,a_t,x).\]

$\rho_0$、policy factors 与 $P$ 各自声明 variable、support 和 base measure；连续 state/action 是 density，离散事件是 probability mass，不能混成一个“概率”。

第一层 cancellation 只发生在同一 recorded $\zeta$ 内：Current/Reference 必须共享 condition、initial distribution、environment kernel、安全 mapping/controller、action variable，并对同一 history/action/mask 求值：

\[\log\frac{p_{\pi_\theta}(\zeta\mid x)} {p_{\pi_{ref}}(\zeta\mid x)} =\sum_{t\in\mathcal M_\zeta} \log\frac{\pi_\theta(a_t\mid h_t,x)} {\pi_{ref}(a_t\mid h_t,x)}.\]

第二层再比较 chosen 与 rejected 各自的 policy-ratio score；两条不同 trajectory 的 dynamics factors 不彼此直接相消。合法逻辑是分别证明 $\zeta_w$ 与 $\zeta_l$ 内部的共同 factors，再在共同 condition 下做 Bradley–Terry pair objective。

adapter、controller/safety revision、command vs executed action、environment/reset/calibration、augmentation/noise、裁剪/插值、support 或 measure 任一不同，状态为 incompatible/review-required/unknown。每个 factor 保存 context/action hashes、Current/Reference artifacts、log-probs、mask、precision/clamp、transform/Jacobian、support 与 recompute hash；历史 Reference 无法重算时只能使用同 contract revision 的 sealed receipt。

GRAPE TPO：原式、逐步展开、长度与记号冲突

只含 policy action factors 的 trajectory likelihood：

\[\Pi_\theta(\zeta\mid x):= \prod_{t\in\mathcal M_\zeta}\pi_\theta(a_t\mid h_t,x).\]

GRAPE v2 的 pair loss：

\[\mathcal L_{TPO}=-\mathbb E\log\sigma\left( \beta\left[ \log\frac{\Pi_\theta(\zeta_w\mid x)}{\Pi_{ref}(\zeta_w\mid x)} -\log\frac{\Pi_\theta(\zeta_l\mid x)}{\Pi_{ref}(\zeta_l\mid x)} \right]\right).\]

其 step-policy 展开为：

\[S_\theta(\zeta)= \sum_{t\in\mathcal M_\zeta} \left[ \log\pi_\theta(a_t\mid h_t,x) -\log\pi_{ref}(a_t\mid h_t,x) \right].\]

paper original 是有效 factors 的 unweighted sum。action factor 可以是 token、control-step group、Gaussian action、macro chunk 或显式 chunk factor，但必须固定 order、teacher-forced prefix、token/dimension/executed masks、units/frame/support/measure。

长度会与 temperature/entropy 尺度耦合；报告 raw sum、factor count、per-factor descriptive mean、termination、log-ratio quantiles、β 和 common-horizon sensitivity。mean、discounted、stage mean、event-weighted 或 common-prefix 都是新 method version。

固定显示 含义
paper-printed: $Z(\zeta)$ GRAPE v2 HTML Eq.3 的可见记号
derivation-required: $Z(x/q)$ DPO 类消去所需的 condition-only normalizer
state: source-notation-conflict 不用本站推断覆盖原文

若 $Z$ 真依赖 trajectory，chosen/rejected 间一般不能相消。weighted/local TPO 必须登记 weight source、normalization、future information、gradient、causal claim、ablation 和新 method ID；不能冒充 paper original。

GCPG：stage/keypoint/cost/self/success 与 pair dependence

GCPG 是可替换 preference producer；TPO 是 pair consumer。producer 链为 trajectory → stage decomposer → keypoints → stage costs → external/self/success → aggregate → rank/tie → pair selection → immutable view。更换 producer 不改 TPO 公式，却会改变 label semantics、bias 和 evidence；producer/evaluator 默认不接 TPO gradient。

external score：

\[R_{ext}(\zeta)=\prod_{s=1}^{S}e^{-C_s} =\exp\left(-\sum_{s=1}^{S}C_s\right).\]

乘积代数对 stage 排列可交换；时序信息只能来自 segmentation/order、keypoint history、$C_s$ 的前序依赖、missing-stage policy、gating/veto 或 evaluator sequence input，不能由乘号本身证明。

\[R_{GCPG}(\zeta)= \lambda_1R_{self}+\lambda_2R_{ext}+\lambda_3I_{success}, \qquad R_{self}=\sum_t\log\pi_{collector}(a_t\mid o_t,q).\]

三项分别记录 units/range/direction、normalization、missingness、source、uncertainty、weight 与 veto precedence。$R_{self}$ 可能偏向 collector 已高概率行为，产生保守/自证偏差；不是独立 success 或 safety judge。

stage/prompt/code、keypoint detector/calibration、cost code/threshold/units、collector likelihood、success verifier/false-positive、component scale、hard veto、tie/unknown 与 human audit 全部版本化。GCPG preference 标 automatic-evaluator，不冒充 human preference。

top-$m$ × bottom-$m$ 得到 $m^2$ pair edges，不等于 $m^2$ IID observations；同一 trajectory 重复出现。split 按 parent trajectory/seed/task/iteration connected component，interval/effective sample 以 raw dependencies 计算，并记录 selection exposure 与未选中中间 trajectories。

长时信用、事件窗口、时间对齐与因果边界

profile 作用 核心假设 主要失效
uniform 全有效 trajectory 共享 label 接受全局方向噪声 无关动作同向更新
event-window 事件附近加权 event time 与责任相关 delay、误窗、future leakage
stage/DTW alignment 对齐阶段/关键点 correspondence 可比 跳阶段、速度 shortcut
distillation trajectory score→step reward/value teacher 可识别局部 credit shortcut/non-stationarity
shared-prefix/counterfactual 同前缀、不同后缀 扰动与 selection 受控 hidden state/environment noise

每个 profile 输出 assumptions、temporal scope、weights、future visibility、gradient target、causal claim、validation 与 fallback。TPO uniform 会更新所有有效 factors，包括等待、正确 prefix 和无关动作；必须观察 per-time/per-stage contribution、length 和 event distance。

event window 绑定 detection/physical/annotation timestamps、latency uncertainty、control rate、chunk/replan 和 execution mapping。用 future failure time 产生的 weight 必须标 offline hindsight；窗口不跨 reset/episode，takeover 后未执行 suffix credit 为 zero/unknown。窗口外置零已改变 paper TPO。

action chunk、重规划、执行前缀与多时间轴

必须分开 environment/control step $t$、decision/replan $d$、chunk factor $j$、diffusion denoising $k/\tau$、flow path $s$、optimizer step $n$，另存 wall-clock event/inference/command/execution/feedback/ingest timestamps。它们不能因为都写成 step 就混用。

两种 MDP action 不可偷换：full-chunk macro-action 只有在 environment 承诺按定义消费完整 chunk 时才能用 full likelihood；executed-prefix action 只消费 replan 前实际前缀，policy probability 必须是同一 prefix 的合法 conditional/marginal density。生成 16、执行 4 时，不能用 16-step joint likelihood 解释 4-step 后果，也不能简单删 suffix 就声称得到 prefix marginal。

Gaussian、Diffusion、CNF/Flow、Residual 的 capability router

route 必需 capability 不足时
trajectory log-ratio/TPO Current/Reference comparable trajectory action likelihood incompatible/review
learned reward + diffusion RL reverse transitions、reward、outer/inner MDP、KL/constraint route-specific review

likelihood-free surrogate 新 objective 与 target validation 不继承 TPO 理论
residual policy residual/composed density 与 frozen base composition review

Gaussian 要对同一 latent/action、support/measure、units/frame、parameterization、squash/scale/Jacobian 求 density，并保存 pre-squash latent 和 boundary policy；技术上有 density 不证明 pair、credit 或 safety 合格。

Diffusion 分开 denoising loss、reverse transition $p_\theta(A^{k-1} A^k,c)$、full reverse-chain joint、final marginal $p_\theta(A^0 c)$、DDPM stochastic 与 DDIM/ODE sampler、inner denoising PG、final KL 与 transition-KL bound。reverse transitions tractable 不等于 final marginal 易算；outer environment MDP 的 $t$ 与 inner denoising MDP 的 $k$、done、reward、mask 分开。

若 $dA^s/ds=v_\theta(A^s,s,c)$ 定义可逆 CNF：

\[\log p_1(A^1\mid c)=\log p_0(A^0) -\int_0^1\nabla_A\cdot v_\theta(A^s,s,c)\,ds.\]

contract 固定 base、direction、invertibility、ODE solver/tolerance、exact/Hutchinson divergence、probe seed、NFE、error、gradient、memory 和 wall time。Flow Matching loss

\[\mathcal L_{FM}=\mathbb E\|v_\theta(A^s,s,c)-u_s\|^2\]

只训练 vector field，不自动产生 final density receipt。Flow VLA 只有实现并验证 CNF evaluation 与 Action ABI 后才能标 density-capable。

Residual route 定义 base action $a_b$、residual $\delta$ 和 $a=g(a_b,\delta)$；base owner、residual support/frame、invertibility/Jacobian、安全 projection 和 composed density 都要明确。只知道 residual density 而 $g$ many-to-one，不等于完整 action density已知。

FDPP/DPPO、likelihood-free surrogate、训练与计算所有权

Diffusion outer MDP 是 environment history→final action chunk→transition/reward/termination；inner MDP 是 $A^K\rightarrow\cdots\rightarrow A^0$ reverse chain。固定 outer horizon、inner steps、trainable steps、noise schedule/sampler、reward/advantage broadcast、masks 和 stochasticity。

FDPP route 是 preference pairs → preference RM → frozen RM/converter → diffusion rollout → reverse-chain policy gradient → transition-KL upper bound → independent evaluation：

\[\nabla_\theta J= \mathbb E\left[ r_\psi(S_t,A_t) \sum_{k=1}^{K} \nabla_\theta\log p_\theta(A_t^{k-1}\mid A_t^k,S_t) \right].\]

RM input/score/calibration/support/OOD 固定，policy update 时 RM/converter frozen。transition KL upper bound 不能称 exact final-action KL。DPPO v3 是 diffusion PG/PPO route，不自带 human/preference reward；接入需另补 reward source、roles、freshness、outer/inner advantage、termination、安全与 release authority。

likelihood-free candidates 可为 preference-weighted regression/vector-field、energy ranking、reward guidance、advantage-weighted denoising、distillation、residual optimization；每项建立新 objective/variables、data scope、weights、gradient owner、support/execution scope、bias/shortcut、compute、ablation/falsifier 和 closed-loop validation，并固定 inherits_tpo_or_dpo_theory: false。chosen MSE − rejected MSE 若可通过无界增大 rejected error 优化，必须拒绝。

参数矩阵覆盖 vision/VLM、proprio/temporal、action/vector-field head、adapters、RM、Critic、Reference、base/residual、evaluator 和 buffers；每区固定 update/frozen-full-function/stop/no-path、loss edge、optimizer、step order、precision/accumulation/clip/export。labels、GCPG、Reference、frozen RM/base、targets、evaluator 与 safety gate 默认无 policy-loss gradient。

compute receipt 同报 train/inference NFE、reverse log-prob、ODE accepted/rejected steps、divergence probes、RM/evaluator calls、dimensions、peak memory、wall time、throughput/energy/queue、control deadline/jitter/miss/fallback 与 target hardware/software/precision。missed deadline 是系统失效，不能被平均 latency 掩盖。run 固定 data/split/dependency、artifacts、Action ABI、environment/controller、objective/credit、sampler/solver/noise/path、compute target、evaluator 和 safety；禁止 latest hot swap。

验证、失效诊断、evaluator 与独立安全门

验证阶梯为 schema/condition → density cancellation/toy → TPO formula/mask/length/conflict → credit/multitime/chunk replay → dependency/leakage → diffusion/CNF/numerical/gradient/compute → evaluator shortcut → closed-loop → authority review。当前只定义这些检查，不执行训练、评测、仿真或机器人。

RLHF-VLA/三分支架构/Reward Model

RM_PPO branch · objective · calibration · evaluation

Reward Model 学到的是带条件的偏好代理

它只在给定数据、标注规则和输入视图下成立；RM ≠ Critic ≠ task evaluator ≠ safety monitor。原始分数不是成功率、绝对效用、逐步 reward、return、advantage 或执行许可。

RM → converter → PPO15 versioned contractstarget experiment: not-run
定义评价对象固定转换链检查代理风险返回三分支选择

输入粒度、评价对象与标签语义

最小样本是 $x_i=(q_i,v_i^A,v_i^B,y_i,w_i,m_i,r_i)$：$q$ 为任务/目标条件，$v^A/v^B$ 为版本化 feedback views，$y$ 为关系标签，$w$ 是独立于标签语义的权重，$m$ 是来源/策略/机器人/场景/时钟元数据，$r$ 是 rubric/guideline revision。

评价 target 必须显式区分 overall-preference | task-success-quality | process-quality | safety-attribute | single-attribute | composite-rubric。综合目标要给冲突属性、优先级与不可抵消项；人类给出的 safety attribute 仍只是 feedback signal，不替代 hard safety。共享 trunk/多 heads 时，head ID、label subset 与 loss weight 分开。

label scope target 主要风险 最小字段
episode 完整 trial 长、归因粗 initial state、termination、all masks
segment/window 对齐片段 上下文截断 parent episode、start/end、context policy
event-centered 失败/接触/接管附近 detector selection bias event type/revision、pre/post window
chunk VLA action block 只有部分元素执行 generated/executed masks、replan boundary
transition/step 单步 state-action 局部代理最强 state/history、action view、next observation

粒度是 label scope，不是输出粒度；episode pair 训练 step scorer 或 latent-event scorer 会引入额外结构假设。每个 eligible view 还要固定 observation/camera/crop/rate、language/history、proprio/force/tactile units/frame/rate、generated/commanded/post-safety/executed action view、clocks/alignment/missing/mask、termination/reset、annotator-visible 与 model-visible fields、privacy/license/access。

模型不得读取 label、annotator decision time、post-hoc success、winner ordering、文件名或 split marker。若 labeler 看完整 outcome 而 model 只看局部 view，目标应写“从有限 view 预测该 population 的偏好”，不能写复原完整人类信息。

pair group ID 由 dataset revision、A/B view IDs、rubric revision、query batch 构成，A/B 交换仍属同 group 且不跨 split。状态固定为 a-preferred | b-preferred | tie | abstain | incomparable | invalid | pending | disputed | unknown；abstain、incomparable、invalid 分别是“不判”“不可形成关系”“数据/界面故障”，不能并成 tie。

偏好似然、tie/abstain 与标识性

令单 view raw score 为 $s_\phi(q,v)$，training temperature 为 $\tau_{train}>0$：

\[z_\phi=\frac{s_\phi(q,v^A)-s_\phi(q,v^B)}{\tau_{train}},\qquad p_\phi(A\succ B)=\sigma(z_\phi).\]

对严格偏好 $y_i\in{0,1}$：

\[\mathcal L_{BT}=-\frac{\sum_i m_iw_i[y_i\log p_i+(1-y_i)\log(1-p_i)]}{\sum_i m_iw_i}.\]

$m_i$ 是 valid mask；必须报告 denominator，避免 invalid ratio 暗改 batch loss scale。$w$ 的来源可以是 repeat agreement、quality review、sampling correction 或明确 confidence，但逐项登记 raw/clipped/normalized、bounds、finite check 与 revision。不能用 model 自己的 confidence 放大同一 loss；annotator confidence 也不是 ground-truth reliability。

tie 方案必须互斥选择：soft-binary-tie 用 $y=0.5$，只代表两方向目标各半而不是独立 tie mass；three-class 显式 A/B/tie；davidson-like 使用 tie parameter；drop-from-preference-loss 保留 coverage/quality。abstain/incomparable/invalid 默认不进 BT；另建 abstention head 时与主 loss 分离。

BT 标识性边界：$s(v)+c$ 与 $s(v)$ 给同样 pair probability，绝对零点不可识别；$s$ 与 $\tau_{train}$ 同比例缩放可保 logits，scale 必须约束。pair probability 不是 $P(success\mid v)$；孤立 comparison components 的 raw scores 不直接可比；高 score gap 没有线性效用单位。training temperature、post-hoc calibration temperature 与 PPO reward scale 是三个不同 IDs。

pair graph 报告 connected components、degree、duplicate、A/B orientation、cycle、transitivity violations、annotator overlap 与 task coverage；cycles 可能来自 noise 或 multidimensional preference，不能静默删除。

VLA 多模态与时序架构

flowchart LR
  V["video / image tokens"] --> F["multimodal fusion"]
  Q["task language / rubric"] --> F
  P["proprio / force / tactile"] --> F
  A["action view + provenance"] --> F
  F --> T["temporal encoder"] --> G["mask-aware aggregation"]
  G --> H["scalar / step / attribute heads"] --> S["raw score artifact"]

各 modality 先按 contract 对齐 clock/frame，fusion/temporal encoder 只消费授权字段，aggregation 使用 valid masks、termination 与 segment boundary，head 输出有 scope 的 raw score。仅视觉可观察终局外观，却不自动测得 force/torque、command smoothness 或 safety override；缺 channel 时分别显示 visual proxy | not observable | not measured | unknown | target missing。

每个 sample 固定 environment/sensor/policy-inference/command/execution times、clock source/max skew、resampling/interpolation、generated chunk/selected prefix/commanded/post-safety/executed actions、unit/frame/normalization/inverse transform、dropped/missing/delayed masks、termination/truncation/abort/takeover/reset。labeler 只看 executed video 而 model 读 generated action 时，记录 information asymmetry 并做 ablation。

输出可为 terminal-scalar | additive-step | mean-step | event-heads | multi-attribute | potential-head。sum/mean 改变 length preference；step/event/potential 都引入归因假设。参数分区至少含 vision/VLM trunk、proprio/action encoders、temporal fusion、aggregation、scalar/attribute heads 与 adapters，每区记录 hash、trainable/frozen/detached、optimizer、precision/clip、loss edges 与 stop-gradient。若 PPO 要求 frozen RM，必须加载 immutable full-function snapshot 或冻结所有依赖参数。

训练、分组切分、采样与标注分布

split group 优先于随机 sample：同 episode adjacent windows、A/B reversed pair、same media transcode、same rollout reslice、near duplicate 都不得跨 split。group keys 至少覆盖 episode/media parent/pair group/query batch/policy artifact/task/scene/object/operator/robot/annotator pool/time bucket。

评估集分开发布 IID-like、task/scene/object held-out、policy-version held-out、robot/sensor held-out、temporal/guideline held-out、adversarial shortcut probes 与 policy-induced candidates，不压成一个 “test accuracy”。

训练阶段固定为：冻结 dataset/split/guideline/input contract → 验证 schema/media/clock/mask/privacy/eligibility → group-aware train/calibration/model-selection/test → 初始化 base/trunk/adapters/heads → 训练 pair/auxiliary objectives → model-selection set 选 checkpoint → 独立 calibration set 拟合 transform → 冻结 candidate RM/calibration → 设计 shortcut/OOD/policy-level validation → 独立 authority 决定 promotion。

active query 可来自 random coverage、near-boundary、ensemble disagreement、new policy、rare failure、new task/scene 或 safety-event oversampling；每批登记 proposal pool、selection policy/probability/score、budget、dedup 与 annotator routing。它会改变 distribution；总体指标须用独立 natural-sampling set，或明确 propensity correction 和 variance。

annotator population 使用 pseudonymous pool、qualification、rubric exposure、anchor checks、assignment、repeat、adjudication 与 population weight；agreement 只说明 label stability，不是 target correctness。禁止 model 读取 label/annotator/winner ordering/quality decision/post-hoc outcome；calibration/test 不选 architecture，train-only preprocessing stats，calibration transform 只 fit calibration split。

score、probability、reward 与转换链

object semantics PPO-ready
raw score $s_\phi(q,v)$ single view；arbitrary offset/scale no
pair logit $(s_A-s_B)/\tau_{train}$ pair relation no
uncalibrated probability $\sigma(z)$ pair relation no
calibrated probability $g_{cal}(z,slice)$ pair/population no
converted reward $r_{pref}$ step/chunk/episode + revision only after contract gate

Critic 估计 total reward/termination 下的 return；RM raw score 不是 value target。Reward conversion 是有序程序：validate input/mask → aggregate raw score → compose attributes → center → scale → clip → densify/shape → allocate horizon → combine task/cost/KL → fixed reward revision。每步可以 identity，但不能缺字段；clip-before-sum 与 sum-before-clip 不等价。

center 指定 fixed train mean/reference-policy mean/zero 和 refresh timing；scale 固定 std/MAD/quantile range，不在每个 PPO minibatch 自适应改变；clip 记录 bounds/rate/tail slices 且不等于 calibration。跨 converter revisions 的 normalized scores 不直接比较，RM refresh 使旧 center/scale 默认 stale。

长度策略必须选择 sum | mean | terminal-only | discounted allocation | learned attribution | event allocation。length normalization 是目标选择，不是显示变换，要有 length-matched/counterfactual probes。

potential shaping 若使用 $F_t=\gamma\Phi(s_{t+1})-\Phi(s_t)$，receipt 需固定 state/history、same $\gamma$、terminal potential、truncation/abort、frozen potential、original reward retention、POMDP assumptions 与 invariance claim。缺条件时改名 progress-difference heuristic，状态为 transfer-hypothesis。

total reward 可登记为 $r_t^{total}=\alpha r_t^{pref}+\beta r_t^{task}-\sum_j\eta_jc_{j,t}-\lambda_{KL}k_t$，但不替代 PPO 页。每项保存 raw/normalized/weighted value、version/hash、missing behavior 与 veto semantics；critical safety cost 不可被 preference score 抵消。

校准、不确定性与阈值

校准对象是特定 population 上 $P(A\succ B\mid q,v^A,v^B,rubric)$，不是 single view absolute success。calibration artifact 读取 pair logit 并输出 pair probability；若 transform 非单调，必须解释 ranking 改变。

calibration set 不参与 parameter training 或 checkpoint selection，A/B orientations 与 pair groups 同组。temperature scaling、Platt、isotonic 或 hierarchical method 要固定 method/parameters/fit split；样本不足标 insufficient。tie/three-class 使用匹配的 multiclass calibration，不能无说明复用 binary ECE。

指标至少有 NLL、Brier、ECE、reliability diagram、calibration slope/intercept 与 selective risk，并声明 label mapping、weights/reduction、bins fixed/adaptive、minimum count、CI/bootstrap unit、coverage/threshold/cost。报告 pre/post calibration、overall/key slices、estimate/interval；ECE 对 binning 敏感，不是唯一 gate。

uncertainty 分为 aleatoric/label ambiguity、epistemic/model disagreement、distributional/OOD 与 system unknown。entropy/margin/ensemble variance 只是 proxies；threshold 从 validation 定义并报告 coverage-error tradeoff。unknown 默认拒绝 PPO，不能默认为 low reward。query、abstain、OOD-review、training-stop、deployment-monitor thresholds 分别有 ID；query threshold 不是 safety threshold。

OOD、捷径与代理奖励过优化

support 分五层：data（task/scene/object/robot/operator/time）、sensor（camera/resolution/light/drop/clock/force）、representation（token/action range/normalization/history/horizon）、policy（artifact/update distance/state-action occupancy）、feedback（rubric/population/query/prevalence）。每层为 in-support | near-boundary | shifted | out-of-support | unknown，并记录 detector/reference/threshold/FPR/FNR 或不可估原因。

shortcut probes 至少覆盖 length/horizon、camera/background、overlay/text leakage、policy identity、action magnitude、annotator routing。每个 probe 要有 paired control/counterfactual、fixed task/outcome、effect size/CI 与 missing controls；correlation 不自动证明 causality，也不能因一个 probe pass 就宣称无 shortcut。

policy 越强地优化 proxy，distribution 越可能移向 RM support 边缘并利用漏洞。必须并列 proxy RM reward、independent human/task utility、safety/cost 三条 curves；只有 proxy 上升不是改进。Overoptimization gate 包含 optimization budget、policy/RM distance、OOD rate、held-out trend、safety trend、stop/rollback threshold 与 independent approver。

任一条件阻断：proxy up 而 independent utility down；OOD/unknown 超预算；shortcut effect 超 threshold；calibration/coverage 恶化；critical safety event；reward distribution 超 support；需要未授权 input/action view；RM/converter/critic binding stale；blind human review 与 RM ranking 持续反向。停止不代表安全，rollback 回到固定 policy/RM/converter/reward-chain receipts。

验证证据阶梯与 policy-level 检查

七层证据依次为 schema/media/clock/mask/label integrity；group split/leakage audit；pair discrimination；calibration/ranking；slice/OOD/shortcut/robustness；policy-level held-out evaluation；independent safety/release review。下层数字不能替代上层，pair metrics 好也不证明 policy search 后有效。

pair accuracy 报 tie policy、weights、orientation、class balance 与 denominator；rank metric 仅在同 task/initial condition 可比，Kendall/Spearman 处理 ties。跨 task raw score 不因可排序就有 global rank meaning。

policy-level protocol 让 candidate checkpoints 在隔离条件产生 trials，RM 可先 rank，但 independent evaluator 使用 blind human pair/rank、task success/quality、process/efficiency、safety/cost、OOD/abstention 与 failure taxonomy。盲化 RM score、policy identity、training step、candidate order 与 expected direction，并固定 trial unit/initial condition/task distribution/robot or simulator/seed/sample size/CI/exclusion。

只有存在可观察 reference utility $U$ 时才报告 regret；否则用 selection error | utility gap proxy | regret proxy 并列 missing utility assumptions。结论状态为 pass | pass-with-limit | inconclusive | fail | blocked | not-run | not-applicable | unknown；当前 target experiment 一律 not-run。

主动刷新、版本绑定与失效传播

完整 lineage 是 feedback dataset → split manifest → preprocessing/input contract → code/config → base/trunk/adapter/head → RM checkpoint → calibration transform → reward converter → total reward chain → Critic → PPO batch/policy candidate。每条 edge 保存 schema/version/hash、producer/time、purpose、compatibility 与 invalidation trigger，禁止 latest。

refresh triggers 包括 policy support shift、task/scene/object/robot/sensor change、rubric/population drift、camera/clock/action adapter/normalization update、shortcut/calibration/OOD/overoptimization gate fail、新 safety/failure cluster、label correction/privacy revocation、RM architecture/recipe change、converter center/scale/clip/aggregation change。trigger 只产生 review-required，不自动训练或 promotion。

失效传播：feedback/input/split 改变使 RM 需 retrain/compat proof；RM hash 改变使 calibration/converter stale；calibration 改变使 probability thresholds stale；converter 改变使 total reward revision 改变；total reward/termination/discount 改变使 Critic/cached return/advantage stale；policy shift 触发 support/calibration/policy-level review；sensor/action adapter 改变使 compatibility invalid；privacy revocation 触发 lineage impact assessment。

RM candidate/champion 使用 immutable IDs，promotion receipt 绑定 evidence/approver/scope/expiry/rollback。RM promotion 与 policy promotion 分开。若同一 RM 选择 query、生成 AI labels、训练并自评，必须保留 independent random coverage、human anchors、external task metrics 与 blind policy set，否则标 self-referential/inconclusive。

部署、安全边界与 PPO 交接

RM train 时 RM candidate updating、calibration 未 fit、converter design-only；validate 时 RM frozen、calibration fit/frozen、converter candidate；PPO rollout/update 中 promoted RM、consumed calibration 与 converter 固定；policy evaluation 可将 RM 作为 frozen/report-only scorer；deployment 默认只需 Actor、adapters、I/O 与 safety chain，RM/calibration/converter 可删除或显式保留为 monitor/reranker。

若运行时保留 RM，manifest 必须列 latency、input availability、false alarm、fallback、authority 与不干扰 control loop 的证据。RM 只可输出 score、uncertainty proxy 与 review signal；不可 bypass limits/interlock/watchdog/E-stop/takeover，不可把 unobserved risk 判 safe，不可用 reward 抵消 critical event，也不可批准 rollout、promotion 或 real-robot expansion。

PPO Critic 绑定 total_reward_revision + discount + termination/bootstrap + action/observation view + horizon；RM 只绑定其中 preference component。RM/converter/total reward 改变时 Critic 和 cached targets 默认 stale。

handoff state 为 ready | ready-with-limits | review-required | unsupported | forbidden | stale | revoked | unknown。只有前两项进入 PPO design，limits 必须显示；unknown 不是 zero reward，unsupported 不回退 raw score。本页 prev 仅 Architecture，next 仅 PPO；Direct/Trajectory 从 Architecture 绕过本页。

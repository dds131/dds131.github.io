← Actor-Critic 枢纽·⑦ 家族谱系

Actor-Critic 是一种组织原则：一个可直接优化的 Actor 产生决策，一个学习得到的 Critic 评价状态或动作并塑造 Actor 更新。公式看起来不同的算法，可能共享这套闭环；名字相近的算法，也可能只共享其中一个组件。

这不是单继承“家谱”。下面四条主轴彼此正交，同一算法会同时落在多个标签上。表格描述常见深度 RL 实现，不把“通常配一个 value baseline”误写成算法定义；网络数量、target network、集中式/特权 Critic 和分布式采样是额外实现轴。

一、判定标准与术语边界

一个方法通常可称为 Actor-Critic，需要同时满足：

  1. 存在显式参数化策略 \(\pi_\theta\) 或 \(\mu_\theta\)，Actor 参数被直接优化；
  2. 存在学习得到的 \(V\)、\(Q\)、soft-Q 或其他价值型 Critic；
  3. Critic 的输出进入 Actor 更新方向，而不是仅用于单独报告、评估或模型选择。

DQN 有 Q 网络但没有单独被直接优化的策略参数，通常不归为 Actor-Critic。REINFORCE with learned baseline 同时有策略和价值估计器，广义上可称为 Actor-Critic；但 Sutton 与 Barto 的窄分类把它与 bootstrap Actor-Critic 分开：其 value 用 Monte Carlo return 训练，并只作为不改变期望梯度的 baseline。这里是术语口径，不是某个公式“错误”。

TRPO 和 PPO 的定义核心分别是 trust-region 更新与 proximal surrogate；它们可以使用 Monte Carlo advantage 或其他 baseline。常见深度实现会另外拟合 value function，因此工程上常被放入 Actor-Critic 家族，但“有 V-Critic”不是 TRPO/PPO 目标成立的必要定义条件。阅读论文时要分清算法的定义组件和常用实现组件。

二、四条主分类轴

Critic 学什么V、Q、双 Q、soft Q，或完整的价值分布。
Actor 梯度怎么来得分函数、确定性策略梯度、重参数化路径导数。
数据从哪里来on-policy、带校正的 off-policy、replay-based off-policy 或纯离线数据。
更新受什么约束普通梯度、trust region/clipping、最大熵、自然梯度或行为约束。

四条轴不是互斥选项。例如 SAC 同时是“Q-Critic + 重参数化 + replay off-policy + 最大熵”；PPO 常是“V baseline + 得分函数 + 最新 rollout + clipped surrogate”。再往工程层还要问：Critic 是单个、双 Q 还是 ensemble；输入普通观测、特权状态还是多智能体联合信息；是否有 target network；Actor 与 learner 是否解耦。仅按发表年份或算法缩写排成一条线，会丢失这些真正决定实现的差异。

三、三类 Actor 梯度

3.1 得分函数型

\[\nabla_\theta J =\mathbb E\!\left[ \nabla_\theta\log\pi_\theta(a\mid s) \operatorname{sg}(\hat A(s,a)) \right].\]

这类梯度适用于离散动作和随机连续策略；A2C/A3C 以及 TRPO/PPO 的策略更新都建立在此类恒等式上。环境动力学和实际动作采样不必可导，代价通常是方差较高。式中省略状态访问分布、时间求和和折扣口径，\(\hat A\) 在 Actor 更新时必须停止梯度。TRPO/PPO 常用 learned V 估计 advantage，但其定义性创新分别是 trust region 和 surrogate/clipping，而不是该 V 网络本身。

3.2 确定性策略梯度

\[\begin{aligned} \nabla_\theta J_\beta(\mu_\theta) &\approx\mathbb E_{s\sim\rho^\beta}\!\Bigl[\\[-0.2em] &\quad\nabla_\theta\mu_\theta(s)\\ &\quad\nabla_aQ^{\mu}(s,a) \big|_{a=\mu_\theta(s)}\Bigr]. \end{aligned}\]

DDPG/TD3 属于此类。\(\rho^\beta\) 是行为策略的状态分布；原始 off-policy DPG 推导本身使用近似号，实践还会以学习到的 \(Q_\phi\) 代替真实 \(Q^\mu\)。梯度直接穿过 Critic 对动作的导数，因而要求可微的连续动作路径。确定性 target policy 不等于确定性数据收集：行为动作通常叠加探索噪声；TD3 的 target policy smoothing 又是构造 Critic 靶标的另一种噪声，不能混为一谈。

3.3 重参数化路径导数

现代常用的连续动作 SAC 令 \(a=f_\theta(\epsilon;s)\)，\(\epsilon\) 来自无参数噪声分布。其常见的、需要最小化的 Actor 目标为：

\[\begin{aligned} J_\pi(\theta)=\mathbb E_{s\sim\mathcal D,\epsilon}\!\Bigl[ &\alpha\log\pi_\theta(a\mid s)\\ &-\min_{j\in\{1,2\}}Q_{\phi_j}(s,a) \Bigr]. \end{aligned}\]

Actor step 中冻结 Critic 参数，但梯度仍经 \(Q(s,a)\) 对动作的导数回到 Actor。若动作经 tanh 和仿射缩放，\(\log\pi\) 必须是变换后动作的密度。双 Q、自动温度以及是否保留独立 V 网络取决于 SAC 版本；离散 SAC 往往可对动作精确求和或采用其他估计，不能把连续动作重参数化代码原样套用。

四、家族总表

方法 常见 Critic/基线 Actor 梯度 数据 关键稳定机制
单步 AC V 或 Q 得分函数 on-policy TD 误差、两时间尺度
A2C/A3C V 得分函数 on-policy n 步优势、并行环境、熵
TRPO 常见实现用 V baseline 得分函数 on-policy rollout KL 信任域、共轭梯度与线搜索
PPO 常见实现用 V baseline 得分函数 最新 rollout；多 epoch 内相对新策略逐渐变旧 old/new ratio、clipped surrogate、有限 epoch
ACER Q/V 得分函数 replay + off-policy 校正 截断重要性采样、显式偏差修正、trust region
IMPALA V 得分函数 actor-learner off-policy V-trace、解耦采样与学习
DDPG Q 确定性路径 replay target networks、软更新、探索噪声
TD3 双 Q 确定性路径 replay clipped double Q、延迟 Actor、target policy smoothing
SAC（连续动作现代常用版） 双 soft-Q 重参数化 replay 最大熵、双 Q、自动/固定温度 \(\alpha\)

表中的 “on-policy/off-policy” 描述训练数据与目标策略的关系，不是“有没有并行环境”；“V baseline”描述常用方差降低实现，不把 TRPO/PPO 重新定义成必须有 Critic 的算法。target network、双 Q 和多 epoch 也属于不同轴，不能用一个“更稳定”标签代替具体机制。

五、on-policy 与 off-policy 的分水岭

on-policy Actor-Critic 用当前或明确冻结的行为策略收集 rollout，再估计该策略的更新方向；每批数据通常很快丢弃。off-policy 方法可使用其他策略生成的数据，却必须明确分布不匹配如何进入目标：

  • 单步动作比率 \(\rho_t=\pi(a_t\mid s_t)/\mu(a_t\mid s_t)\) 修正给定状态下的动作分布，不能单独消除 \(d^\mu(s)\) 与 \(d^\pi(s)\) 的状态访问差异；完整轨迹比率又会随时域产生高方差。
  • ACER 对重要性权重做截断并加入显式偏差修正项。V-trace 则用截断的 \(\bar\rho_t,\bar c_t\) 构造多步 target：\(\bar\rho\) 的截断决定其固定点对应的中间目标策略，\(\bar c\) 主要控制 trace 长度及方差；它不是 ACER 显式偏差修正式的同名复制品。
  • DDPG/TD3/SAC 用 replay 状态训练 Bellman Q-Critic，再让 Actor 通过该 Q 更新。其合理性来自各自的 off-policy 目标与近似条件，不是“Q 接受任意动作”这一接口事实本身。
  • off-policy 不等于 replay：IMPALA/V-trace 可处理策略滞后的流式数据而不做长期随机回放；反过来，拥有 replay 容器也不会自动修正错误目标。
  • replay 不是免费的样本效率。Critic 外推误差、策略滞后、分布外动作和陈旧归一化统计都会成为主要风险。
  • 纯离线数据还多一层支持集问题。把在线 DDPG/TD3/SAC 停掉环境交互不会自动得到可靠 offline RL；通常需要行为约束、保守价值或其他分布外控制。

六、组件组合图，而非年代家谱

flowchart LR
  AC["Actor-Critic 组织原则"] --> SV["随机 Actor + value/Q baseline"]
  SV --> EST["n 步 / GAE：优势估计器"]
  SV --> CON["TRPO / PPO：更新约束"]
  SV --> PAR["A2C / A3C：rollout 与并行"]
  EST --> PAR
  PAR --> IMP["IMPALA：解耦 actors + V-trace"]
  AC --> QC["可微 Q-Critic"]
  QC --> DPG["DPG / DDPG"] --> TD3["TD3"]
  QC --> ME["随机 Actor + 最大熵"] --> SAC["SAC"]

图中节点是可组合组件：GAE 是优势估计器，不是完整策略优化算法；TRPO/PPO 主要改变策略更新约束；A2C/A3C 主要改变 rollout 与并行更新结构；DDPG/TD3/SAC 组合了 Q-Critic、off-policy 数据和不同 Actor 目标。箭头不宣称唯一直接祖先，也不保证发表时间先后。

例如 TRPO 论文发表于 GAE 论文之前，PPO 的关键创新是允许多 epoch minibatch 更新的 surrogate 目标，而非“发明 GAE”。IMPALA 继承并行 actor 思路，但 actor 与 learner 明确解耦，并用 V-trace 处理行为策略滞后，因此也不是简单扩大 A3C worker 数。

七、容易混淆的边界

  • PPO/TRPO 常配共享 Actor-Critic 网络，但其定义性创新是策略更新约束；移除 learned V 会增大方差，却不自动让 surrogate 公式失效。
  • GAE 是 advantage estimator，可服务于 PPO、TRPO 或其他 on-policy 更新；它本身不规定 Actor 优化器。
  • “确定性策略”描述 target Actor 的映射，不表示训练行为不探索；DDPG/TD3 的行为噪声与 TD3 target smoothing 作用位置不同。
  • SAC 不等于“随机版 TD3”。它优化软价值与熵正则目标，Critic target 和 Actor loss 都含熵语义。
  • TD3 的双 Critic 取最小值是保守的过估计修正；Double DQN 的选择/评估解耦不能原样搬到连续动作 Actor。
  • A2C 不是所有 Advantage Actor-Critic 的泛称；现代工程语境里通常指同步并行版本。
  • on-policy 不等于“每批只做一次反传”。PPO 可以多 epoch 使用冻结的 old log-prob，但必须用 ratio/clipping/KL 等监控约束偏离。

八、按任务选择阅读路线

  • 离散控制与公式入门：单步 AC → A2C/A3C → PPO。
  • 机器人 on-policy：GAE → PPO → 非对称/特权 Critic 与大规模并行环境。
  • 连续控制样本效率：DPG/DDPG → TD3 → SAC，并同步学习 replay 与 target network 契约。
  • 分布式系统：A3C → IMPALA/V-trace，再研究 learner 吞吐、队列与策略滞后。
  • 离线强化学习：先理解 replay-based Q-Critic，再学习支持集偏移、行为约束与 CQL、IQL、TD3+BC 等专门目标。

九、遇到新算法如何定位

不要先问“它像 PPO 还是 SAC”，而应依次回答：

  1. Actor 是显式随机策略、确定性策略，还是从 Q 隐式导出的动作？
  2. Actor 梯度来自 log-prob、\(\nabla_aQ\)、重参数化，还是黑盒/搜索方法？
  3. Critic 预测 V、Q、soft-Q、cost value、分布或 ensemble？它看普通观测、特权状态还是联合信息？
  4. 数据由哪个行为策略产生，保存多久，是否 replay/离线，策略版本如何记录？
  5. 分布不匹配靠 ratio、V-trace、Bellman off-policy target、行为约束，还是根本没有处理？
  6. 更新幅度靠 KL、clipping、target network、双 Q、延迟更新、熵或自然梯度中的哪些机制控制？
  7. 终止/截断、动作变换、归一化统计和 old/new log-prob 的实现契约是否与目标一致？

得到这七项答案后，算法通常可以被准确放进多轴坐标，而不必强行塞进单一“家族分支”。

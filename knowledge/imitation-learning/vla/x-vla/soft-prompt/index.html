MECHANISM ② · DOMAIN LATENT · EVIDENCE-BOUNDED

条件混合与负迁移

设域 d∈{1,…,H}、采样概率 ρ_d、模型可见条件 o、域内观测密度 p_d(o) 与动作分布 π_d(A|o)：

p(d,o,A) = ρ_d · p_d(o) · π_d(A|o) p(A|o) = Σ_d p(d|o) · π_d(A|o) p(d|o) = ρ_d p_d(o) / Σ_j ρ_j p_j(o)

混合权重依赖观测 o，不能由全局轨迹占比替代。若可见条件足以识别域，p(d|o) 可接近 one-hot；困难区域是观测或内部表示发生混叠，而不同域要求不同条件最优动作。

直接 MSE 玩具模型下，不带域条件的 Bayes 最优预测是：

A*(o) = E[A|o] = Σ_d p(d|o) E_{π_d}[A|o] 显式域条件把有歧义的 p(A|o) 还原为 p(A|o,d)。

四种异构条件化方案

A · 末端动作投影A_d=W_d g_θ(o)+b_d。可把同一表示映射成不同动作，但显式域标签不能改变已经完成的视觉选择与非线性融合。
B · HPT-style每域独立 cross-attention resampler 在共享 DiT 前映射观测，并保留域专属动作头；分布漂移是作者解释，不是唯一因果证明。
C · 硬件语言提示把 embodiment、camera setup、frequency 写进 VLM 文本；人类可读但依赖人工模板，粒度与措辞需要治理。
D · Soft Prompt连续可学习 token 进入动作 Transformer；不复制域专属主干，但仍需要人工域划分与正确 domain_id。

论文定义与固定实现

论文把域专属可学习参数写为：

P^H = {p_i}_{i=1}^H p_i ≈ Φ(h_i)，Φ: H → R^k

h_i 表示硬件配置，Φ 被描述为隐式映射；prompt 由随机初始化和端到端动作相关目标学习。论文措辞是“被期望编码”，没有显式硬件量监督，也未给 k 或 token 数。固定实现的 32×1024 不能反向写成方法定义。

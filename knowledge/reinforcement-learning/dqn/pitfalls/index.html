本页与专题里其他页的定位都不同：它不推导算法，而是一份诊断手册。训练 DQN 时会看到一些与监督学习经验相悖的现象——损失在降但分数不涨、Q 值涨到几十万、换个随机种子结论就反了。本页把这些现象与底层原因对应起来，并尽量给出可操作的判据。

先给适用范围：van Hasselt 等研究的是一族带经验回放的深度 Q 网络配置。论文在其测试范围内观察到大量“越过理论值界后又恢复”的轨迹，却没有观察到无界数值发散；这不能外推成“深度强化学习通常稳定”。

R / (1−γ)有界奖励下的估值尺度审计
4 类信号Q 尺度、非有限值、回报、梯度
多 seed结论以独立 run 为统计单位
限定范围论文证据不自动跨任务成立
本页重点。「Q 值膨胀」一节给出按奖励界计算的任务相关审计阈值，但阈值越界不是单独的停训判据；「致命三要素」一节整理六条假设在论文被测配置中的结果，其中“容量更大更稳”在该实验里的方向相反。

本页不重推致命三要素的算子与范数不匹配——那部分在 DQN 枢纽页已写得很硬，本页只做实证与诊断。

现象一：loss 在降，分数不涨

这是最常被问到的一个。它的根源很简单，但与监督学习的直觉冲突。

监督学习里，损失下降意味着预测更接近给定的标签。而 DQN 的回归目标是

\[y = r + \gamma \max_{a'} Q_{\phi^{-}}(s', a')\]

这个 \(y\) 不是给定的标签，它本身也是网络算出来的。

于是 \(L = (Q_\phi - y)^2\) 变小，只说明当前的 \(Q_\phi\) 更接近当前的自举目标。它既不保证 \(Q_\phi \to Q^{*}\)，更不保证当前策略的回报更高。

把它说得更具体：目标 \(y\) 会在目标网络同步、数据分布变化和策略变化后移动。即使每个固定目标窗口内的回归 loss 下降，目标本身也可能有偏或覆盖不足；loss 衡量当前批次上的拟合误差，不是策略正确性的直接度量。

因此诊断时不能只看 loss。至少联看独立评估回报、Q 值分布与尺度、TD 误差分位数、梯度范数、边界比例和数据覆盖；任何单个量都不足以单独定因。

现象二：Q 值膨胀——软发散与无界发散

这一节给出一个可以直接计算、但必须结合任务语义使用的尺度审计。

判据从哪来

若训练目标使用的奖励满足 \(\lvert r_t\rvert\le R_{\mathrm{abs}}\) 且 \(0\le\gamma<1\)，则同一奖励语义下任意策略的无限时域折扣价值满足

\[\lvert Q^{\pi}(s,a) \rvert \;\leq\; \frac{R_{\mathrm{abs}}}{1-\gamma}.\]

有限剩余时域 \(H\) 还可使用更紧的 \(R_{\mathrm{abs}}(1-\gamma^H)/(1-\gamma)\)。边界必须与训练时的奖励变换、折扣、终止语义和价值定义一致；若网络估计的是未裁剪回报，就不能套用裁剪奖励的界。

Atari 论文配置把奖励裁剪到 \([-1,1]\) 且取 \(\gamma=0.99\)，于是上界为 100。van Hasselt 等把 \(|q|>100\) 称为软发散（soft divergence）：估值已与该训练目标的理论尺度不一致。

这不是通用阈值，也不是单独的失败判据。换奖励尺度、折扣、时域或价值定义后必须重算；越界后还要结合持续时间、评估回报、TD 误差、梯度与非有限值判断影响。

论文被测配置中的观察

论文追踪了训练中的最大绝对动作价值。下图是对其观察的概念示意，不是原论文数据重绘，也不能当作本项目的实测曲线：

越过任务相关值界说明估值尺度不一致，但是否构成训练失败还取决于持续性与策略性能。NaN/Inf 是明确的数值故障，却不是“无界发散”的唯一定义；持续膨胀、梯度非有限、回报塌陷或策略退化也需要处理。

在论文测试的网络、任务和超参数中，软发散确实出现，某些估值曾超过百万量级；作者同时报告，许多轨迹后来回到 100 以下，并且该实验集合没有观察到转为无界数值发散的案例。这里的“0 次”只描述被测集合，不是对其他 DQN 实现的概率保证。

诊断动作：首次越界时保存 checkpoint 与原始日志，检查奖励变换、bootstrap mask、Q 分布分位数、TD 误差、梯度范数和独立评估回报。若出现 NaN/Inf 或非有限梯度，应立即中止该 run 并定位数值来源；若值有限但持续越界，也不能只等待“自动恢复”，应按预先定义的持续窗口与性能规则处理。

现象三：致命三要素到底有多致命

DQN 枢纽页 从算子与范数的角度说明了为什么函数逼近、自举、离策略三者相加可能发散。但那是理论上的可能性。论文指出一个现实：

函数逼近的发散例子通常是人为构造的；而在深度非线性函数空间上，关于发散是否常见、以及是否该归咎于致命三要素，几乎没有指引。

于是论文提出六条可检验假设。下表的“结果”只复述论文在其算法族、任务、指标与超参数扫描中的报告，不表示这些方向已经成为跨任务定律。

假设 论文预期的方向 被测配置中的报告
1 深度发散 常规深度 Q 网络不常出现无界发散 出现软发散；该实验集合未观察到无界案例
2 目标网络 独立网络自举时更少发散 按论文指标获强支持
3 过估计 修正过估计时更少发散 按论文指标获强支持
4 多步 更长多步回报更少发散 在测试范围内获支持
5 容量 更大网络更少发散 测得相反方向：更大容量伴随更多不稳定
6 优先级 更强更新优先级更易发散 在测试范围内获支持
第 5 条尤其需要保留范围。论文 Figure 3 图注报告“增大网络容量加剧不稳定（against Hypothesis 5）”，结论段则称容量与其他因素的交互比最初假设更微妙。

准确表述是：在该论文测试的配置与软发散指标下，更大网络呈现相反方向。它既不支持“网络越大越稳”，也不足以证明所有任务中容量越大越不稳。

一个值得学习的实验设计

假设 2（独立目标网络）与假设 3（选择—评估解耦）容易混在一起。论文构造四个 bootstrap 变体：

\[\begin{aligned} v(s) &= \max_a q(s,a) && \text{普通 Q-learning} \\ v(s) &= \max_a q'(s,a) && \text{目标 Q-learning} \\ v(s) &= q\big(s,\arg\max_a q'(s,a)\big) && \text{逆向 double Q-learning} \\ v(s) &= q'\big(s,\arg\max_a q(s,a)\big) && \text{double Q-learning}, \end{aligned}\]

其中 \(q'\) 是目标网络。这构成“是否用另一网络评估”与“是否解耦选择、评估”的近似 \(2\times2\) 对照。论文在其测试扫描中观察到与预期偏序一致的结果：存在过估计、或在同一网络上自举时，软发散更常见。

这支持两个因素与不稳定性的关联，但不是任意 DQN 配置的充分必要条件。论文进一步强调，致命三要素相关的不稳定性会与 bootstrap 估计误差相互作用；这不等于每次过估计都会发散，也不等于修正过估计就足以保证稳定。解耦机理见过估计与 Double DQN。

现象四：换个随机种子，结论就变了

同一份代码、同一组超参，只换随机种子，结果能差多少？

Henderson 等给出过一个历史性示例：同一超参配置运行 10 次，只改随机种子，再拆成两组各 5 次。它用于展示小样本分组可能产生截然不同的结论，不是“5 个 seed 足够”的样本量建议。

论文报告其中一项比较的双样本 t 检验为 t = −9.0916、p = 0.0016，说明当时那一实验与统计构造对 seed 分组很敏感。

不要把这个 p 值当作 DQN 的证据或通用效应量。该示例来自连续控制中的 TRPO 与 DDPG；任务、算法和统计单位都不同。现代报告还应给出每个独立 run、效应量与不确定性区间，并避免把同一 run 内高度相关的训练点当作独立样本。

实用推论：报告独立训练 run 数与完整分布，而不是单条曲线或孤立 p 值。比较方法时预先定义聚合指标、预算和 checkpoint 规则，并报告效应量与置信区间。

现象五：目标网络更新频率的双向失效

目标网络更新周期 \(C\) 存在两端权衡，下面是可能症状而非必然结果：

取值 可能影响 应联看的量
\(C\) 较小 目标紧跟在线网络，解耦作用减弱 Q 尺度、TD 误差、梯度、同步事件
\(C\) 较大 目标滞后，学习变慢或产生陈旧标签偏差 评估回报、目标—在线网络差距

当硬同步按 learner update 计数且 \(C=1\) 时，目标参数在每次同步后与在线参数相同，只保留至下一更新前的短暂滞后；这接近在线目标，但失败与否仍取决于学习率、更新比率和数据。目标网络为什么有助于减慢反馈，见 DQN 枢纽页。

DQN 原论文自己也做过这项消融：在开关经验回放与用不用独立目标网络的全部组合下、配合三种不同学习率各训练 1000 万帧。注意该消融的训练量与主结果（5000 万帧）口径不同。

现象六：回放池的两个旋钮

回放容量与 replay ratio 是两个不同参数，但会通过样本复用次数与数据年龄分布相互作用：

参数 含义
回放容量 池子能存多少条转移
replay ratio 按所引 Fedus 等的定义，是梯度更新次数与新采集环境步数之比，不乘 minibatch 大小；基线为 0.25，即每 4 条新经验约一次更新

容量还影响池中最老数据的年龄，可作为“潜在陈旧程度”的粗略代理；它不等于严格的离策略距离，因为实际差异还取决于策略变化速度、覆盖和采样权重。另一个常见口径是“每个环境步从回放池抽取多少条样本”：minibatch 为 \(B\)、每 \(K\) 个环境步更新一次时为 \(B/K\)。它与 Fedus 定义的 \(1/K\) 不是同一个量，报告时必须显式命名。

容量过小可能保留较强相关和窄覆盖，过大可能让很旧的数据长期存在；两种影响都不是单调定律，还受 replay ratio、采样方式和策略变化速度影响。

但要注意：「增大回放容量是否有收益」并不是一个只取决于容量的问题——它还取决于算法里有没有多步回报。这条交互见多步回报子页，本页不重复。

高频实现故障：先查数据与梯度合同

下表不是新的算法推导，而是把最容易造成“曲线看似能跑、结论却错”的实现问题前置。任何一项不清楚，都应先修合同，再调网络或超参数。

检查项 正确合同 最短验证
终止、截断与自动重置 真正的 MDP 终止通常不 bootstrap；外部时间截断若对应 continuing-task 目标，通常仍需 bootstrap。向量环境自动重置时，target 使用终止前的 final observation，不能误用重置后的首帧。若任务本身把有限时域定义为终止，则按该任务合同置零 构造一条 terminated=true、一条 truncated=true 的固定转移，逐项断言 mask 与 next observation
TD target 梯度隔离 target 分支在 no_grad/detach 语义下计算，目标网络不进入在线优化器；只有在线 \(Q(s,a)\) 分支接收该损失的梯度 单批反传后断言目标网络所有梯度为空，在线网络存在有限梯度
动作索引与形状 离散动作索引使用整数类型，gather 只取执行动作对应的 \(Q(s,a)\)；batch 维不能因 squeeze 被意外删除 用手工 Q 矩阵与动作索引核对逐行选值，并覆盖 batch size 1
回放转移与帧堆叠边界 \((s_t,a_t,r_t,s_{t+1})\) 时间对齐；回合边界后不得把新回合画面拼进旧状态历史。若采用懒帧或数组视图，写入后数据不能被后续原地修改 写入带唯一编号的短轨迹，采样后逐字段核对；修改采集端缓冲区后再次确认历史样本未变化
目标同步的对象与单位 明确按 learner update、环境决策步还是原始帧计数；硬同步应复制完整模型状态。若模型含归一化等 buffer，只复制参数并不完整 在已知计数点检查同步事件，并比较在线/目标 state_dict 的键和值
训练与评估协议 评估关闭学习与训练探索，固定并报告评估 \(\varepsilon\)；观测预处理、动作重复、生命边界和原始回报统计口径保持可审计，不能把训练奖励裁剪后的累计值冒充原始游戏分数 同一 checkpoint 重复评估并记录协议字段；同时保存 raw return 与 transformed reward

终止、截断、自动重置与 final observation 的完整语义由环境 API、终止截断与时间边界统一维护；本页只保留 DQN 需要执行的检查。

诊断清单

观察信号 立即核对 解释与动作
loss 下降、评估回报不涨 独立评估协议、目标同步、采样分布、Q/TD 分位数 批次拟合改善不等于策略改善
max \(\lvert Q\rvert\) 超过任务相关值界 奖励变换、\(\gamma\)、剩余时域、bootstrap mask 尺度审计失败；结合持续窗口与性能判断
NaN/Inf 或非有限梯度 首个异常 step、输入与奖励、学习率、dtype、除法/开方 数值故障；保存现场后停止该 run
有限 Q 持续膨胀且回报下降 目标周期、更新比率、奖励尺度、覆盖与 max 偏差 不稳定候选；做单变量消融，不能只等恢复
seed 改变后结论反转 独立 run 数、配对方式、checkpoint 规则与区间 当前证据不足，报告完整分布
对同步周期高度敏感 先明确单位，再与学习率、更新比率联合扫描 超参数耦合，不保证单向增大 \(C\) 能修复
截断处 Q 系统性偏低或跨回合污染 terminated/truncated、final observation、帧堆叠边界 修正 bootstrap 与自动重置数据合同
目标网络出现梯度或随在线优化器改变 no_grad/detach、优化器参数集合、同步事件 阻断 target 梯度；只在定义的同步点复制完整状态
batch size 1 时形状异常或动作值错位 动作 dtype、gather 维度、squeeze 位置 用手工小张量写固定断言

有界但系统性偏高的 Q 值需要与同条件 Monte Carlo 回报或其他校准目标比较；max 偏差的机理与对照方法见过估计与 Double DQN。

不要把诊断压缩成“越界但没 NaN 就继续”。任务相关值界、NaN/Inf、评估回报、TD 误差与梯度分别回答不同问题。应在实验前定义告警阈值、持续窗口、停训条件和失败 run 的报告方式，避免看到曲线后临时修改规则。

小结与专题收尾

  • loss 是辅助诊断量，不是策略质量代理：它必须与独立评估回报、Q/TD 分布、梯度和数据覆盖一起解释。
  • 软发散阈值取决于任务合同：\(R_{\mathrm{abs}}/(1-\gamma)\) 只适用于同一有界奖励与无限时域语义；有限时域可用更紧上界。
  • 越界、数值故障与性能失败是不同事件：论文被测集合中曾观察到大幅越界后恢复，但这不保证其他 run 会恢复。
  • 六条假设是限定范围内的实证结果：目标网络与过估计修正在被测配置中获支持，容量假设呈相反方向；都不能无条件外推。
  • 随机种子是实验因素，不是结论解释：用独立训练 run、效应量和不确定性区间报告结果，不能依赖单条曲线或孤立 p 值。

本页完成的是诊断闭环：先校验任务与数据合同，再检查数值量、估值尺度和策略性能，最后用控制变量与多 seed 证据定位原因。算法改进的组合与贡献继续见 DQN 改进专题。

逐条核验过的来源

  1. Deep Reinforcement Learning and the Deadly Triad（van Hasselt 等；arXiv:1812.02648）
    核验内容：摘要的问题陈述（理论上三者相加可发散、但多个算法成功组合了它们，说明理解存在缺口）；「函数逼近的发散例子通常是人为构造的、在深度非线性空间上几乎没有指引」；六条假设的原文表述（深度发散、目标网络、过估计、多步、容量、优先级）；软发散的定义——因奖励裁剪到 \([-1,1]\) 且 \(\gamma=0.99\)，真值上界为 \(1/(1-\gamma)=100\)，故 \(\lvert q\rvert>100\) 即不现实；Hypothesis 1 的结论——软发散确实发生、有时涨到离谱量级，但从未变成无界、从未产生浮点 NaN；追踪最大绝对值后的观察——值估计经常快速增长到超过一百万，但通常又降回 100 以下，该性质与「深度网络与强化学习通常不稳定」的常见看法相悖；四个自举变体的定义式与由两条假设导出的偏序（Q-learning 发散最多、double Q-learning 最少）；「发散在存在过估计偏差时、以及在同一网络上自举时更容易发生」这一强支持结论；多步与优先级两条假设获支持、而容量一条 Figure 3 图注明确判为 against Hypothesis 5（增大网络容量加剧不稳定）、结论段另称其与其他成分的交互「比最初假设的更微妙」；以及「致命三要素引起的不稳定性与自举方法带来的统计估计问题相互作用」这一核心判断。

  2. Deep Reinforcement Learning that Matters（Henderson 等；AAAI 2018，arXiv:1709.06560）
    核验内容：实验设计——同一超参配置跑 10 次、只改随机种子、再拆成两组各 5 次取平均；结论——仅凭随机种子即可得到统计上不同的分布；其中一项的双样本 t 检验 t = −9.0916、p = 0.0016。★ 适用范围：该实验在连续控制任务上用 TRPO 与 DDPG 完成，不是 Atari 也不是 DQN，本页在引用处已标明这一限定。

  3. Revisiting Fundamentals of Experience Replay（Fedus 等；ICML 2020，arXiv:2007.06700）
    核验内容：把回放容量与 replay ratio（梯度更新次数与采集环境步数之比，不乘 minibatch 大小）作为两个基本属性分开考察；replay ratio 的默认值 0.25，即每 4 个动作一次梯度更新；回放池大小直接影响最老策略的年龄，该量可宽松视作池中数据离策略程度的代理。（n 步回报与容量的交互归[多步回报]子页，本页不展开。）

  4. Human-level control through deep reinforcement learning（Mnih 等；Nature 2015）
    核验内容：Extended Data Table 3 的消融设计——在开关经验回放与用不用独立目标网络的全部组合下配合三种学习率各训练 1000 万帧，及其与主结果 5000 万帧的口径差异。取自 DeepMind 官方公开 PDF，详见 Atari 子页 的取数说明。

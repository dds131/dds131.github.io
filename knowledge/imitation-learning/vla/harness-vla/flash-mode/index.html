  • 一句话定义：Flash 用冻结的高层程序替代 online Planner 决策，但保留 live perception、spatial re-binding、VLA/解析原语、检查、有限恢复、安全与控制。
  • 不是动作缓存：plan 固定 what/order；SAM3、Molmo 或等价 localizer、VLA、controller 和 verifier 仍可能在线工作。
  • 不是 open-loop replay：历史 coordinate、pixel、mask、joint/action sequence 都不能直接获得当前执行权。
  • 证据边界：论文阈值、重试次数与 56.17 s 是 LIBERO/paper protocol 事实；current 78-pair inventory 与 60.19 s 是易变的官方文档快照。

Flash 固定什么、仍在线什么

Flash 的加速点是 compiled orchestration：高层 step order、policy prompt/non-spatial arguments、checks 与有限 retry branches 在 episode 前固定。它不声称做 policy-output acceleration、低层控制器加速或 VLA action caching。

layer Flash 固定什么 runtime 仍在线 不能推出
task orchestration plan order、prompt、non-spatial args、compiled checks/retry step state、condition verification、有限分支 能处理新 subgoal 或重排
perception / policy 不固定 output observation、localization、VLA contact action、mask/point/depth 零模型推理或零 GPU cost
controller / plant 不固定 low-level trajectory frame/IK/control、reachability、collision/limits、安全与物理执行 controller 或 physical motion 自动加速 
flowchart LR
  P["compiled plan · fixed what/order"] --> L["live perception + localization"]
  L --> V["live VLA / analytic primitive"]
  V --> C["controller + plant"]
  S["independent Safety"] --> V
  S --> C
  E["fresh verifier evidence"] --> P

compiled orchestration、policy-output acceleration、orchestration/service cache 和 low-level execution acceleration 是四个不同问题。service reuse 只有在 key/revision/freshness/invalidation 有记录时才是可审计 cache；重复使用上一帧 anchor 且不验 freshness 是危险 stale reuse。

本站教学分解为：

Online Harness = online planning + online perception/policy + governed execution
Flash          = compiled planning + online perception/policy + governed execution

这不是 latency 加法公式；各 span 可能异步、重叠或共享 service。计划顺序固定但每次抓取仍调用 VLA，属于 compiled orchestration；录制 joint sequence 按时间重放，属于 open-loop trajectory replay，不属于本页 Flash。

plan/anchor pair 与 provenance

flowchart TD
  M["PublishedMemorySnapshot"] --> P["FlashPlanAnchorPair"]
  P --> A["FlashPlanArtifact"]
  P --> H["FlashAnchorArtifact"]
  P --> S["source success receipt"]
  P --> C["compiler / selector / reviewer receipts"]
  P --> V["compatibility + content hashes"]
  P --> O["verified pair handle · not execution authority"]

plan 与 anchor 必须同 pair 发布。缺件、hash mismatch、revision divergence、revoked/superseded/quarantined 或 compatibility unknown 都进入 UNAVAILABLE；不能用空 anchors、旧 sibling file 或猜测路径补齐。

plan 最少包含 task/suite/regime、robot/adapter/environment、primitive registry 与 policy I/O compatibility，ordered steps + dependencies、primitive/version、non-executable argument template、binding slots、pre/postconditions、retry/stop/fallback policy、source success/compile/select/review receipts 与限制。anchor 最少包含 semantic role、kind、reference evidence、frame/calibration、non-replayable reference geometry、localizer contract、binding slot、transformation mode、confidence/ambiguity/freshness policy 与 unsupported assumptions。

source episode success 只证明某一 environment/layout/version/verifier 下这条 composition 曾成功；它不证明 current anchor 可见、layout 在 envelope 内、robot/adapter 未变、identity 无歧义或 live waypoint 安全可达。

eligibility 与 preflight

eligibility 只有 ACCEPT / REJECT / NEEDS_REVIEW 三态；unknown 不能当 accept。task gate 要求 task identity/language/suite/regime 一致、subgoal order 可预先固定、目标可由允许的 live sensors 直接定位、扰动在声明 envelope 内、failure 可由预定义分支处理、不需要新 semantic choice/reorder/search，而且 protocol 允许 Flash treatment。

artifact gate 核对 snapshot/hash、完整 pair、source receipt、registry/adapter、localizer/camera/frame/calibration、policy I/O、retry/stop/fallback policy 与 revocation/staleness。runtime preflight 再核对 synchronized RGB/depth/proprioception、service health/model revision、initial state、fault/E-stop/owner、Safety/controller/verifier、budgets、trace sink 和 frozen evaluation manifest。

gate accept evidence reject / needs-review example
task applicability fixed order、direct localization、known recovery new semantic branch、occlusion search、different task key
artifact compatibility pair complete、hash/revision/registry match plan without anchor、revoked asset、unknown localizer
geometry capability perturbation in declared transform envelope required rotation/z/scale/articulation beyond XY
runtime health fresh observation/calibration、services、Safety/controller healthy stale calibration、depth invalid、conflicting physical owner
protocol evaluation-only treatment/fallback policy frozen exploration inbox、write/merge mode、undeclared fallback

runtime 状态机

stateDiagram-v2
  [*] --> UNAVAILABLE
  UNAVAILABLE --> ELIGIBILITY_CHECK: pair + request
  ELIGIBILITY_CHECK --> READY: all gates accept
  ELIGIBILITY_CHECK --> UNAVAILABLE: reject / unknown
  READY --> PREFLIGHT: authorized start
  PREFLIGHT --> LOCALIZING: runtime healthy
  LOCALIZING --> BINDING: anchors resolved
  BINDING --> ADMISSION: candidate target accepted
  ADMISSION --> EXECUTING: primitive + Safety + controller accept
  EXECUTING --> VERIFYING: terminal result
  VERIFYING --> LOCALIZING: next step / bounded retry
  VERIFYING --> COMPLETE: external goal verified
  VERIFYING --> FALLBACK_REQUESTED: compiled recovery exhausted
  FALLBACK_REQUESTED --> FALLBACK_HANDOFF: protocol permits
  FALLBACK_REQUESTED --> SAFE_STOP: fallback forbidden
  PREFLIGHT --> SAFE_STOP: unsafe / unavailable
  LOCALIZING --> TIMED_OUT: deadline
  EXECUTING --> CANCELLED: cancel acknowledged
  TIMED_OUT --> SAFE_STOP
  CANCELLED --> SAFE_STOP

loader 只在 UNAVAILABLE 收集缺失原因；eligibility coordinator 只读核验；run coordinator 在 READY 等待授权；runtime/Safety 做 preflight；localizer/binder 不能发 actuator command；admission 由 primitive/Safety/controller owners 独立作出；verifier 不信任 Flash summary；fallback owner 决定 handoff/stop；terminal 后 late result 不改 outcome。

每个 transition 记录 run/transition IDs、from/to、monotonic time、trigger/evidence、owner、deadline/budget、idempotency key、terminal guard 与 hash chain。任一 physical primitive 前必须经历 current localization/binding/admission 或显式 no-binding reason；COMPLETE 只由 external success authority 触发；retry 不添加 step/改 goal/解除 safety；fallback 后立刻重标 hybrid/online-fallback。

current localization 与 spatial binding

localization request 绑定 anchor/semantic role、allowed kind/interface、current observation IDs/timestamps、camera/frame/calibration、requested mask/point/pose + uncertainty、visibility/ambiguity policy、timeout/cancel 和 run/step/binding-slot lineage。reference pixel/xyz/old mask 不能冒充 current result。

outcome meaning default action
MATCH 单一候选且证据过 policy 进入 binding
ABSENT 当前视野支持未见 预定义 search/retry 或 stop
AMBIGUOUS 多候选/identity 不清 不取最高分硬执行
LOW_CONFIDENCE 候选不足 alternate view/retry/stop
STALE observation/calibration/result 超时 丢弃并重请求
SERVICE_ERROR localizer 不可用 bounded retry/fallback/stop
FRAME_ERROR transform/calibration 不一致 SAFE_STOP

论文 LIBERO implementation 的二维绑定为：

\[\Delta\mathbf{x}_{i,xy}=\mathbf{x}^{\mathrm{ref}}_{i,xy}-\mathbf{a}^{\mathrm{ref}}_{j(i),xy}, \qquad \mathbf{x}^{\mathrm{run}}_{i,xy}=\widehat{\mathbf{a}}_{j(i),xy}+\Delta\mathbf{x}_{i,xy}.\]

只有水平距离不超过 $0.20\,\mathrm m$ 的 move_to/move_pose waypoint 才可按论文规则绑定。该阈值是 paper LIBERO-specific exact fact，不是跨 backend 默认、安全阈值或站点建议。paper 保留 recorded height/non-spatial args，unanchored waypoint 保留旧 coordinate；这描述历史实现，不证明 changed geometry 下安全。

perturbation paper XY translation site contract
same-plane translation 假设成立时可能 仍需 uncertainty/reachability/Safety
anchor rotation 不充分 explicit pose/rotation model，否则 reject
scale/shape change 不充分 geometry-aware binding，否则 reject
vertical layout 不充分；paper 保留 reference height 不盲用旧 z
articulated state 通常不充分 state-aware plan/verification
camera/calibration 不充分 fresh transform/calibration receipt
held-object offset 仅有 correction 时部分处理 显式 evidence/uncertainty
unanchored waypoint paper 保留旧 coordinate changed geometry 默认不 replay

check、retry、stop 与 fallback

action changes plan? pure Flash? trigger
check no yes grasp/postcondition/anchor state
retry only compiled branch yes eligible failure within budget
stop no terminal Flash failure unsafe or required evidence missing
online fallback may replan no unforeseen recovery/new decision

retry 记录 policy/version、eligible failure、per-step/per-anchor/global budget、backoff/alternate view、dependency invalidation、repeated-side-effect guard、re-localization、termination 和 consumed budget。论文 LIBERO 的最多三次 grasp attempts 只是 paper-specific example，不是其他 backend/真机默认值。

unconfirmed grasp 后必须 invalidate/skip dependent transport，不继续假设已持有物体，也不生成 held-object offset；retry 前重新定位/验证 current state。compiled recovery exhausted 后可 stop 或按 protocol request fallback。

fallback 不是默认在线 Planner。它必须记录 trigger、exhausted branches、current state/artifact、已发生 side effects、invalid assumptions、Safety、remaining budgets、target/owner、protocol permission、state transfer、timing boundary 与 treatment relabel。owner 缺失、protocol 禁止或 state transfer 不完整时 safe stop。

timeout、cancel、并发与服务退化

timeout 层级包括 localization、VLA inference/chunk、primitive execution、verification、step、episode wall-clock、可选 startup 和 fallback handoff；子 timeout 不得延长 episode deadline，clock 与 deadline source 必须记录。cancel 要有 request/owner/requested-at/acknowledged-at/affected call/controller stop-or-hold/terminal/late disposition；发送 cancel 不等于 physical stop completed。

terminal 或 superseded result 标 late/stale，不更新 binding、budget、success 或 terminal outcome，也不触发 next step。它只保留 diagnostics evidence。同一 robot/session 只能有一个 physical execution owner；并行预取 localization 必须绑定 observation epoch/dependency，scene change 后失效。

failure fail-closed response
localizer down bounded retry / permitted fallback / stop
VLA service down 不用 analytic action 冒充等价替代
depth invalid 不以 reference z/guessed distance 补齐
calibration stale frame error + stop
trace sink failure stop 或显式 unscorable，按 protocol
verifier unavailable 不宣称 success
Safety/controller unavailable safe stop

service reuse 可减少 startup，但报告必须区分 cold/warm、model residency、cache state、concurrency 和 load；cache hit 仍需 key/revision/observation epoch/invalidation，绝不跨 scene 复用 coordinate result。

论文 Flash Mode (max) 对每个 task 从全部 successful-run cards 中，用同一 ten-seed batch 选 observed success rate 最高者，再在同一批 seeds 报告。它是 retrospective best-card，不是 independent held-out selection；候选更多时 optimism risk 通常更大，但本站不虚构 correction factor。

capability、quality、risk trade-off

axis possible benefit cost / risk
latency 去除 online Planner decision spans localization/execution 仍在，fallback 可增时
compute/cost 减少 Planner calls/tokens VLA/localizer/controller 成本仍在
quality 复用 reviewed procedure、降低 planning variance fixed order 不处理新 semantic decision
capability declared perturbation 内稳定 replay OOD/occlusion/reorder/new subgoal 较弱
safety/reliability auditable branch/budget stale/bad card 可系统性重复错误

long but fixed routine 可能 eligible；short task needing new choice 仍需 online planning。heavy occlusion/search 倾向 online/hybrid；large rotation/z/scale 需 explicit transform，否则 reject；new object/tool/contract 要 recompile/review；safety-critical novel state 要 safe stop/operator。

Flash 只能描述为“在声明扰动范围内复用 procedure、减少 online planning responsibilities、固定顺序下低方差编排”，不能写成更强模型、无推理、零延迟、通用 replay 或安全保证。compiled error 可能跨 layouts 一致重复，因此要有 revoke/supersede、health monitoring、failure clustering、held-out revalidation、rollback 和 safe stop；同一 card 的重复 evidence 不是独立多样性。

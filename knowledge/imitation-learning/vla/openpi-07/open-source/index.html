结论模板固定为“在固定 commit 的公开文档中观察到”→“仓库维护者自述”→“本页未运行”。不使用“完整复现”“官方兼容”“论文同款”“可直接部署”“已验证”等无证据宣传词；不做性能排行，不按 Star / fork / watcher 判断可信度，不把新提交自动视为更成熟，也不从文件名、类名或 issue 标题推断功能完成。

刷新流程固定为：远端 HEAD 变化 → 读取固定 commit 差异 → 重审 claim / license / artifact → 更新规格与 checker → 再改页面。只改快照日期或 HEAD 不算审计；新增结论必须先绑定身份、提交、许可、制品 hash 和验证协议。

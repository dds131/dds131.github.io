← Actor-Critic 枢纽·① 数学基础·② Critic 学习

Critic 不是一个静态标签预测器。它在策略持续变化时追踪当前策略的价值；监督目标又可能包含自己的预测，因此同时面对移动目标、自举与相关样本。本页固定讨论随机策略的 on-policy V-Critic；Q-Critic、off-policy 分布校正与目标网络只在需要划清边界时出现。

先分清两次停止梯度。Critic loss 要切断 bootstrap 目标分支，这是“半梯度 TD”；Actor loss 要切断优势/TD 权重，这是“得分函数乘固定样本权重”。两者目的不同，漏掉任意一处都会改变算法。detach 只控制自动微分图，不会自动解决目标滞后、数据分布或函数逼近误差。

一、Critic 究竟学习什么

对 on-policy 的 V 型 Actor-Critic，目标是

\[V^{\pi_\theta}(s) =\mathbb E_{\pi_\theta}\!\left[\sum_{k=0}^{\infty}\gamma^k r_{t+k}\mid s_t=s\right].\]

它不是最优价值 \(V^*\)，也不含 DQN 式的动作最大化。Actor 改变后，\(V^{\pi_\theta}\) 与策略诱导的状态分布都会改变，所以“旧 Critic 在旧数据上拟合得很好”不等于“它仍适合新策略”。有限时域若影响后续回报，剩余时间必须是状态的一部分；否则同一观测在不同剩余时长下对应不同价值，Critic 面对的就不是单值 Markov 目标。

对 off-policy Q-Critic，行为策略负责采样、目标策略决定 Bellman 目标，二者可以不同；这已超出本页的 on-policy 主线，不能把“当前采样策略的 V”这句话机械套到 DDPG、TD3 或 SAC。

V-Critic输入状态、输出标量；常见于 A2C、A3C、PPO。
Q-Critic输入状态与动作、输出标量；常见于 DDPG、TD3、SAC。
Advantage 近似器直接拟合较少见；理想优势在策略动作分布下均值为零。若与 V 联合分解 Q，必须固定这一“平移自由度”。

二、四种常见回归目标

目标 形式 是否自举 主要权衡与边界
完整目标回报 \(y_t=G_t\) 否 不含 bootstrap 误差、方差高；必须采到目标定义下的完整尾部。人工截断处没有纯蒙特卡洛标签
一步 TD \(y_t=r_t+\gamma c_t\operatorname{sg}[V_\phi(s_{t+1})]\) 是 更新及时、条件方差通常较低；偏差受下一状态价值误差影响
n 步目标 \(y_t=\sum_{k=0}^{n-1}\gamma^k C_{t,k}r_{t+k}+\gamma^n C_{t,n} \operatorname{sg}[V_\phi(s_{t+n})]\) 未提前终止时是 一步与完整回报之间折中；\(C_{t,k}\) 是到第 \(k\) 步仍有 continuation 的连乘掩码
λ-回报 不同 n 步目标的几何加权 通常是 用 \(\lambda\) 连续控制有效时域；\(\lambda=1\) 只有在完整尾部或边界 continuation 正确时才退化为无 bootstrap 误差的回报；见子页 ③

记 \(c_t\in\{0,1\}\) 为“目标下是否还有 continuation”的 bootstrap 掩码：真正吸收终止或任务内生的有限时域末端取 0，人工采样截断取 1。\(C_{t,k}=\prod_{j=0}^{k-1}c_{t+j}\)，且 \(C_{t,0}=1\)。这比把所有“循环结束”都写成 done 更准确。

最常用的回归损失是

\[L_V(\phi)=\frac12\mathbb E\!\left[(V_\phi(s_t)-\operatorname{sg}(y_t))^2\right].\]

其中 sg 只切断目标分支的梯度，不等于额外维护 target network：A2C 的 V-Critic 常读取当前网络的下一状态值后 detach；PPO 通常先用采样时的价值预测算好并冻结 returns/advantages，再做多个 epoch；DDPG、TD3、SAC 的 Q-Critic 才通常另有慢更新目标网络。

损失/约束 作用 容易误读的地方
MSE 大残差得到更大梯度，目标与高斯负对数似然同形 对回报离群值敏感；数值大小随奖励尺度平方变化
Huber / Smooth L1 大残差区转为近似线性，降低离群点影响 改变了优化目标，阈值也必须结合价值尺度解释
value gradient clipping 限制单次参数更新的梯度范数 只限制优化步，不修复错误 target 或错误终止掩码
PPO 式 value clipping 相对旧预测裁剪新旧差值，并以未裁剪/裁剪后误差中的较大者约束更新 是可选启发式，不等同于 target network；其效果依赖奖励尺度

目标选择与损失选择是两件事：把 MSE 换成 Huber 不会消除 bootstrap 偏差；把梯度裁剪得很小也不会使错误的 target 变正确。

三、为什么 TD 使用半梯度

一步 TD 的数值目标含有 \(V_\phi(s_{t+1})\)。标准 TD 更新只对当前状态预测求导：

\[\phi\leftarrow\phi+\alpha_V\,\delta_t\nabla_\phi V_\phi(s_t),\qquad \delta_t=r_t+\gamma c_tV_\phi(s_{t+1})-V_\phi(s_t).\]

这不是完整地最小化“TD 误差平方”，故称半梯度。它把下一状态预测当作固定靶标，使期望更新对应 Bellman 误差投影的随机逼近；这句话只有在给定采样分布与函数族后才有精确定义，不能简化成“沿某个普通 MSE 的真梯度下降”。

若不停止目标分支的梯度，对单条样本的平方 TD 误差反向传播会得到

\[\nabla_\phi\frac12\delta_t^2 =\delta_t\big(\gamma c_t\nabla_\phi V_\phi(s_{t+1})-\nabla_\phi V_\phi(s_t)\big).\]

它会同时拉动“预测”和“靶标”。这里必须区分两个目标：

\[J_{\mathrm{MSBE}}=\frac12\mathbb E_s\!\left[ \left(\mathbb E[\delta_t\mid s_t=s]\right)^2\right], \qquad J_{\mathrm{MSTDE}}=\frac12\mathbb E[\delta_t^2].\]

Bellman 残差平方 \(J_{\mathrm{MSBE}}\) 的梯度包含“两个条件期望的乘积”；用同一条随机转移同时估计这两个因子一般有偏，需要两个条件独立的下一状态样本或已知模型，这就是双采样问题。直接反传单样本 \(\delta_t^2\) 则是在优化含转移噪声方差的另一个目标 \(J_{\mathrm{MSTDE}}\)。因此“忘记 detach”既不是标准半梯度 TD，也不能自动等同于理论上的 residual-gradient 算法。

收敛边界。“半梯度对应投影 Bellman 更新”不等于神经网络 Critic 必然收敛。表格型或满足遍历性、步长与特征条件的 on-policy 线性 TD 有相应理论；非线性函数逼近本身也可能破坏这些结论。当函数逼近、自举和 off-policy 数据同时出现时，更进入经典“致命三元组”风险区，甚至线性值函数也可能发散。目标网络、回放、梯度裁剪与较小步长可以改善特定实现，却不是任意非线性网络的收敛证明。

四、半梯度最终学到什么：投影、分布与误差错位

对线性 Critic \(V_w=\Phi w\)，固定策略、on-policy 状态权重矩阵 \(D\) 下，TD(0) 的期望更新为零意味着

\[\Phi^\top D\big(T^\pi\Phi w-\Phi w\big)=0,\]

在常见满秩条件下等价于投影 Bellman 方程

\[\Phi w=\Pi_D T^\pi\Phi w.\]

因此 TD 的极限一般是 Bellman 更新后再投影回函数空间的固定点，并不一定是直接最小化真实价值误差 \(\lVert V_w-V^\pi\rVert_D^2\) 的解，也不是逐点让每个状态 TD 误差为零。Tsitsiklis 与 Van Roy 的线性 on-policy 结果给出了收敛条件、固定点与误差界；换成神经网络后，不能直接继承这个全局投影结论。

三个后果必须单独记住：

  1. 训练 loss 小，不等于真实价值误差小。自举目标本身来自当前 Critic，错误预测可能互相支持；在训练样本上的 TD 残差还会受相关性与过拟合影响。
  2. 采样分布决定“哪里拟合得好”。频繁状态在 \(D\) 中权重大，稀有但策略敏感的状态可能被忽略；Actor 改变后，这个权重也在移动。
  3. 值函数 MSE 小，不保证 Actor 偏差小。第 ① 页给出的单步 Actor 偏差取决于 \(\gamma\,\mathbb E[h_t(Pe)(s_t,a_t)]\)，它按得分函数和“动作会去往哪里”加权；普通 MSE 对所有误差的权重不同。诊断 Critic 时必须同时看预测质量与策略更新相关信号。

最小验证实验。冻结一个策略，重新采一批完整评估轨迹；用训练批拟合 Critic，用按“整条轨迹”划分的留出批比较价值预测与独立的长回报。若训练 TD loss 继续下降、留出回报误差却上升，就是目标自洽或过拟合信号。长回报本身方差高，不能把一次偏差当成真值；应报告多轨迹均值、分位数与置信区间。

五、Actor 侧也必须停止梯度

策略损失写成

\[L_\pi(\theta)=-\mathbb E[\log\pi_\theta(a_t\mid s_t)\operatorname{sg}(\hat A_t)].\]

停止梯度有两个目的：一是实现策略梯度定理要求的得分函数乘权重；二是避免 Actor loss 通过共享的优势计算路径偷偷更新 Critic。若 Actor 与 Critic 共享主干，主干仍可同时接收策略损失和值损失，但应当通过各自明确的头部和损失进入，而不是穿过 TD 靶标。

# 单步 V-Critic 的核心口径；多步/GAE 同样要冻结 target 与 advantage
target = reward + gamma * bootstrap_mask * value_next.detach()
advantage = target - value.detach()

policy_loss = -(log_prob * advantage).mean()
value_loss  = 0.5 * (value - target).square().mean()

在简单在线算法中，应先用更新前的参数计算 \(\delta_t\)，再把同一个数值分别用于 Actor 与 Critic 更新。批量 A2C/PPO/TRPO 中，应在 rollout 完成后用采样时的价值函数计算并冻结 advantages/returns；不要在每个 value epoch 后重算同一批优势，否则 Actor 的样本权重会随 Critic 拟合过程改变，已不再是原先那次策略梯度估计。GAE 论文的算法也明确先用旧价值函数算优势，再更新策略与价值函数。

一个可执行的梯度单元测试是：只对 policy_loss.backward()，价值头独有参数的梯度应为空；共享骨干可以收到来自 \(\log\pi\) 的策略梯度，这是预期行为。再单独对 value_loss.backward()，检查 bootstrap 的下一状态分支没有梯度。

六、两时间尺度不是“Critic 学习率永远更大”

经典两时间尺度分析使用两组递减步长 \(\alpha_t^V\) 与 \(\alpha_t^\pi\)。典型充分条件写成

\[\sum_t\alpha_t^V=\sum_t\alpha_t^\pi=\infty,\qquad \sum_t(\alpha_t^V)^2<\infty,\quad \sum_t(\alpha_t^\pi)^2<\infty,\qquad \frac{\alpha_t^\pi}{\alpha_t^V}\rightarrow0.\]

最后一条的含义是：Actor 的参数变化在渐近意义上比 Critic 慢；在 Actor 看来 Critic 近似已经跟上，在 Critic 看来策略近似静止。它不是“任何时候把 Critic 学习率设得更大”的经验定律。深度 RL 常用固定学习率、Adam/RMSProp、有限批量与重复 epoch，并不满足该定理的全部条件；工程上会通过 Critic 更新次数、Actor 学习率、warm-up 或某些算法中的延迟 Actor 更新控制相对速度。vf_coef 只是在联合损失里缩放价值梯度：共享主干时它还会改变表征梯度冲突，分离优化器时则未必等价于更快的 Critic。有效步长还受梯度尺度、优化器状态、归一化和更新次数影响，不能只比较两个标量学习率。

七、如何判断 Critic 是否真的在变好

单看训练 MSE 不够。所有比较都应标注：使用哪一版策略采样、目标是哪种 return、是否含人工截断 bootstrap，以及统计量来自训练批还是新 rollout。

指标 能说明什么 不能说明什么 / 危险信号
explained variance \(1-\mathrm{Var}(y-V)/\mathrm{Var}(y)\) 接近 1 表示残差的方差相对目标方差小 任意常数预测的 EV 都为 0；常数偏移可得到 EV=1，因此不检查绝对校准；\(\mathrm{Var}(y)\approx0\) 时不稳定
signed error \(\mathbb E[V-y]\)、MAE/RMSE 检查整体高估/低估与绝对尺度 target 若含错误 bootstrap，指标会一起“自洽”地错误
value loss 同一 target、同一奖励尺度和同一分布下可比较优化进度 奖励缩放或目标分布变化后，跨实验绝对值不可直接比较
TD 误差均值与分位数 长尾、单侧漂移和异常 transition 总均值接近 0 可能只是正负抵消；并不证明每个 \((s,a)\) 的优势准确
value–return 散点与分箱校准 斜率、饱和、系统偏移；可按剩余时域、终止类型分层 单条蒙特卡洛 return 噪声高，应聚合多轨迹
训练/留出轨迹误差 识别 Critic 对相关 rollout 的过拟合 必须按轨迹划分，随机拆散相邻时间步会泄漏
value/actor 梯度范数与裁剪率 优化是否爆炸、消失或长期被裁剪 范数正常不代表方向正确

SB3 文档把 EV=0 解释为“和预测零一样”；由于公式只看方差，更精确地说是“和任意常数预测一样”。至少把 EV 与 signed error、RMSE、目标标准差一起记录。对 Actor，还应把冻结优势与独立更长回报构造的参考优势比较符号翻转率或相关性；这只是带噪诊断，不是真优势标签。

八、实用设置、单元测试与排错顺序

  1. 先验算 target。构造一步终止样本，目标必须等于奖励；构造人工截断样本，目标必须保留 \(\gamma V(s')\)；再测 n 步中途终止不会越界累加奖励。
  2. 验算梯度边界。target.requires_grad 与 advantage.requires_grad 应为 False；仅反传 Actor loss 时，价值头独有参数不应得到梯度。
  3. 冻结策略做 Critic-only 测试。固定 rollout 分布训练若仍不收敛，再查 target、奖励尺度、容量、优化器与归一化；不要先把问题归咎于策略非平稳。
  4. 记录分布而非单个均值。同时记录 value、target、advantage、TD error 的均值、标准差、分位数、最大绝对值，并按 terminated/truncated 分组。
  5. 用新轨迹验证。按完整 episode 划分训练/留出，比较 EV、signed error、RMSE 与校准散点；训练 TD loss 不能代替这一步。
  6. 再调相对速度。若 Critic 在冻结策略下能学好、联合训练却跟不上，再增加 value 更新次数或降低 Actor 有效步长；不要只看学习率数值，也不要立即放大 vf_coef。
  7. 做结构消融。共享主干不稳定时，与完全分离网络对照；若分离后改善，再检查梯度余弦、损失尺度与归一化，而不是直接宣称“共享一定有害”。

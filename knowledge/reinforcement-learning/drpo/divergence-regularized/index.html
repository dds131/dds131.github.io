Divergence Regularized Policy Optimization · 2026

不是再换一个 Clip 阈值，而是换一套策略位移几何

DRPO 保留 token 级策略梯度，用采样 token 的绝对概率位移建立信任域，再用平滑二次正则替代 DPPO 的硬 mask。

Binary-TV约束采样 token 的绝对概率差
平滑正则边界前衰减、边界后可纠正
有界权重长尾低概率区域不无界放大
无需新增网络主要改变策略目标

同名提醒。 本页的 DRPO 是 Rethinking the Divergence Regularization in LLM RL，不是奖励解耦、安全机器人、联邦离线或高频交易分支。

1. PPO 的 ratio 为什么可能量错了？

行为策略为 \(\mu\)，学习策略为 \(\pi_\theta\)，采样 token 为 \(y_t\)：

\[r_t=\frac{\pi_\theta(y_t\mid s_t)}{\mu(y_t\mid s_t)}.\]

PPO 用固定 ratio 窗口控制代理目标，但 ratio 衡量的是相对变化。LLM 词表长尾使相对变化与概率质量移动明显错位：

旧概率 \(\mu_t\) 新概率 \(\pi_t\) ratio 绝对概率位移 固定 ratio 视角
\(0.00001\) \(0.001\) \(100\) \(0.00099\) 看起来极端，实际移动质量很小
\(0.99\) \(0.80\) \(0.808\) \(0.19\) ratio 不夸张，实际移动质量很大

固定 ratio 窗口由此可能过度限制稀有 token，却低估高概率 token 的显著漂移。DRPO 不是无条件放宽稀有 token，而是让边界跟绝对概率位移对齐。

2. PPO → SPO → DPPO → DRPO

方法 信任域几何 机制 越界后的梯度
PPO 固定 \(\lvert r_t-1\rvert\le\epsilon\) 逐样本硬裁剪 有害方向置零
SPO 固定 ratio 边界 优势加权二次正则 平滑并可反向纠正，但低概率尾部权重可无界
DPPO Binary-TV 固定 \(\lvert\pi_t-\mu_t\rvert\le\delta\) 散度硬 mask 越界且继续发散时置零
DRPO 同一绝对概率边界 \(\mu_t\) 加权二次正则 边界前衰减，边界后反向纠正

DPPO 的 Binary-TV 把词表分成“当前采样 token”和“其余 token”两个事件：

\[D_t^{\mathrm{Bin-TV}} =|\pi_\theta(y_t\mid s_t)-\mu(y_t\mid s_t)| =\mu_t|r_t-1|.\]

因此

\[D_t^{\mathrm{Bin-TV}}\le\delta \quad\Longleftrightarrow\quad |r_t-1|\le\frac{\delta}{\mu_t}.\]

这是一条 token 自适应 ratio 边界：低旧概率 token 得到更宽的 ratio 容忍区间，高旧概率 token 得到更窄区间，但两者允许的绝对概率位移相同。

Binary-TV 是采样 token 的 Bernoulli 代理，不是逐步精确计算完整词表的 TV。它比 ratio 更接近概率质量位移，但仍是可扩展训练中的近似。

3. DRPO 目标函数逐项拆解

最大化形式：

\[\mathcal L_{\mathrm{DRPO}}(\theta) =\mathbb E_{y\sim\mu}\left[ \sum_t r_t\hat A_t -\frac{|\hat A_t|\mu_t}{2\delta}(r_t-1)^2 \right].\]

实现中优化器通常最小化：

\[\ell_t=-\hat A_t r_t+ \frac{|\hat A_t|\mu_t}{2\delta}(r_t-1)^2.\]

\(r_t\hat A_t\)

沿奖励改进方向更新采样 token；ratio 修正数据来自行为策略而参数属于当前策略的偏差。

\(\lvert\hat A_t\rvert\)

让正则强度随学习信号大小缩放，同时不改变正负优势的边界方向；边界不因奖励整体缩放而漂移。

\(\mu_t\)

最关键的新因子：把固定 ratio 二次惩罚改造成绝对概率位移几何。

\(\delta\)

绝对概率位移尺度。不能直接拿 PPO 的 ratio clip \(\epsilon\) 数值做一一对照。

4. 梯度权重：理解 DRPO 的最短路径

论文把正则后的梯度写成普通策略梯度乘连续权重：

\[w_t=1- \operatorname{sign}(\hat A_t(r_t-1)) \frac{|\pi_t-\mu_t|}{\delta}.\]
优势 当前位移 更新语义 权重趋势
\(\hat A_t>0\) \(\pi_t>\mu_t\) 已在增大好动作概率，继续会远离行为策略 位移越大，权重越小
\(\hat A_t<0\) \(\pi_t<\mu_t\) 已在降低坏动作概率，继续会远离行为策略 位移越大，权重越小
\(\hat A_t>0\) \(\pi_t<\mu_t\) 奖励梯度把概率拉回行为策略方向 权重大于 1
\(\hat A_t<0\) \(\pi_t>\mu_t\) 同样属于回拉方向 权重大于 1

发散方向达到 \(\lvert\pi_t-\mu_t\rvert=\delta\) 时，\(w_t=0\)；继续越界则 \(w_t<0\)，梯度变为纠正方向。收敛方向则被放大。

由于 \(\lvert\pi_t-\mu_t\rvert\le1\)：

\[1-\frac1\delta\le w_t\le1+\frac1\delta.\]

目标能力与具体配置要分开。 UniRL 当前默认 drpo_epsilon=12.5 时，权重范围约为 \([0.92,1.08]\)，不会变成负数。因此可说目标函数在足够越界时具备反向纠正机制，但不能说该默认实验中经常发生梯度反转。

5. 为什么多一个 \(\mu_t\) 会改变几何？

对采样取期望后，DRPO 正则对应优势加权的平方 \(\ell_2\) 概率距离：

\[\sum_{a\in\mathcal A}|\hat A(a)| \big(\pi(a\mid s)-\mu(a\mid s)\big)^2.\]

SPO 删除 \(\mu_t\) 后对应：

\[\sum_{a\in\mathcal A}|\hat A(a)| \frac{\big(\pi(a\mid s)-\mu(a\mid s)\big)^2}{\mu(a\mid s)},\]

即 Pearson-\(\chi^2\) 型几何。同样的绝对概率差会被 \(1/\mu\) 放大，旧概率越低越敏感；这就是 SPO 在长尾区域的梯度权重可能无界，而 DRPO 权重保持有界的底层原因。

6. 训练闭环：DRPO 改了哪里、没改哪里

flowchart LR
  P[Prompt] --> M["行为策略 / Rollout 引擎"]
  M --> Y["回答 token + old_logp"]
  Y --> R[Reward / Verifier]
  R --> A[组内优势]
  Y --> N["训练策略重算 new_logp"]
  A --> L[DRPO token loss]
  N --> L
  L --> U[反向传播与优化]
  U --> S[权重同步]
  S --> M
  • 主要变化发生在策略 Loss，不要求新增独立 Critic、Target Actor 或双 Q。
  • UniRL 当前示例可用组内奖励中心化形成优势；这是一种训练配方，不是理论禁止使用 Critic。
  • Rollout、Reward、Advantage、Train、Weight Sync 的系统层仍必须正确；Loss 更稳定不会修复数据契约错误。

7. 四类反常现象

更新前 ratio_mean 就不为 1

即便模型权重名义一致，推理引擎与训练前向的数值精度、batch 几何、sampling temperature、chat template 或同步时点不同，都会让 old_logp 与 new_logp 不一致。先做冻结权重回放恒等检查，再谈学习率。

ratio_max 巨大，但绝对概率位移很小

常见于旧概率极低的 token。只看 ratio 会把相对放大误判为大分布漂移；应按 old_prob 分桶，同时观察 \(\lvert\pi_t-\mu_t\rvert\) 和二次 penalty。

奖励有变化，部分样本却没有梯度

如果同一问题的所有回答获得相同奖励，组内均值中心化优势为零；此外 loss_mask 会排除 prompt、padding 或其他不训练 token。两类“无梯度”需要分别计数。

平均 KL 很小，但少数高概率 token 已漂移

平均值会淹没尾部。至少同时记录中位数、95/99 分位数、最大值，并按旧概率与 token 类型分桶。

8. 创新、局限与可证伪问题

创新 它解决什么 仍未解决什么
绝对概率位移边界 ratio 与长尾概率质量错位 Binary-TV 仍是采样 token 代理
平滑二次正则 DPPO 阈值不连续、越界后零梯度 \(\delta\) 与更新次数仍需调节
优势绝对值加权 边界不随奖励尺度改变 优势本身可因 reward/分组失真
有界梯度权重 SPO 低概率尾部潜在无界 引擎 log-prob 不一致仍会污染 ratio

最有价值的验证不是只比较最终 reward，而是回答：在相同计算预算下，DRPO 是否减少高概率 token 的过度漂移、保留稀有推理 token 的有效梯度，并降低多更新/多精度设置下的崩溃率？

RTC/ ④ Training-Time/ ⑤ 源码与接入

RTC 的论文公式、仿真参考代码和完整机器人系统不在同一个仓库里。复现时最危险的做法，是把某个当前分支的函数名当成永久 API，或把 Kinetix 仿真实现当作 Physical Intelligence 的完整真机部署栈。本页先固定版本，再把算法、队列与异步生命周期逐层对应。

论文算法定义与公开实验事实
Kinetix · JAX官方模拟实验参考实现
LeRobot · PyTorch社区维护的模块化工程集成
第三方项目按各自 README 自述核验

版本钉住：本页代码结论基于 Kinetix 9296f31d62d5bfeb5779dcb2f9bcf71ca37f448b 与 LeRobot b863b4228356dc53db25d097f2404e4f02a60834，核对日期为 2026-10-09。分支 main 只作为寻找新版的入口。

一、先划清开源边界

层级 能回答什么 不能据此推断什么
RTC 原论文 原始推理时方法、公式、Algorithm 1、公开仿真与真机结果 未公开的生产部署代码、全部硬件参数
Training-Time RTC 训练时动作前缀条件与公开实验 任意普通 checkpoint 自动支持 trained 模式
Kinetix 仓库 JAX FlowPolicy、仿真数据、训练与评测参考 PI 真机栈、openpi 完整替代品
LeRobot RTC PyTorch guided、Pi05 trained、动作队列与异步引擎 所有模型、所有历史版本都支持相同接口
第三方集成 特定机器人或 VLA 的工程探索 官方基准复现或通用性能保证

openpi 是 π 系列模型的开源基础代码；Kinetix RTC 仓库是用于论文仿真实验的独立参考项目。二者有概念联系，但不能把文件路径互相替换。

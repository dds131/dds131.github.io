VLA 总览/GR00T N1.6/③A 相对动作表示

REFERENCE-BOUND CHUNK · GROUP POLICY · FORWARD/INVERSE CONTRACT

相对动作是目标表示，不是闭环控制器：每个动作组必须显式绑定 reference、坐标、格式、单位与正逆变换；任何 statistics、mask 或 clip 都不能修复这些语义错误。

one referencestate-relative chunk 的所有步共享同一最后采样 state。
group AND globalActionConfig.rep==RELATIVE 且 use_relative_action=true 才转换。
static-specifiedround-trip fixture 仍为 NOT_RUN，不升级离线或运行时状态。

入站合同与 absolute / state-relative / delta

producer_page_id: groot-n1-6-relative-action-data
consumer_page_id: groot-n1-6-relative-action
edge_type: branch

“相对”必须说明相对谁，不能把两种差分统称为增量
表示 最小定义 关键边界
Absolute 目标直接处于声明的 coordinate frame 仍需单位、ordered fields 与 rotation format
State-relative chunk 每一步相对同一个 reference state 不是从第二步开始链式累加
Stepwise delta 首项在显式 reference 存在时相对 reference；后续相对前一个 absolute action 无 reference 时首项零/单位策略取决于实现，必须标注 
flowchart LR
  S[shared reference s_ref] --> R0[r0]
  S --> R1[r1]
  S --> R2[r2]
  S --> D0[d0]
  D0 --> A0[absolute a0] --> D1[d1] --> A1[absolute a1] --> D2[d2]

文本回退：state-relative 的 r0、r1、r2 全部指向同一 s_ref；stepwise delta 的 d0 可相对显式 reference，但 d1、d2 分别依赖前一个 absolute action，因此两者不等价。

Reference、offset 与 timestamp

设动作采样 offsets 为 τ₀,…,τH−1，reference 为 state config 的最后采样状态 s_ref。state-relative 的表示公式为：

\[r_k=a_{t+\tau_k}\ominus s_{\mathrm{ref}},\qquad k=0,\ldots,H-1.\]

只有 state 最后 offset 为0时才可写 s_ref=s_t；action offsets 来自配置，可包含0，不能固定为 t+1…t+H。reference/action 时间戳和采样延迟都必须进入合同，缺失时 fail closed。

按动作组策略与格式合同

维度只校验 shape，不推断 type、format 或 frame
每组字段 要求 错误处理
ActionType 明确 NON_EEF 或 EEF 未知类型拒绝
ActionFormat 声明 joint/rot6d/rotvec/quaternion 等实际格式 不能从维度猜格式
ActionRepresentation group RELATIVE 与全局 true 同时满足才转换 未满足时保持 ABSOLUTE，不静默改策略
frame / units / ordered fields 三者独立版本化，变换前后可追踪 mask 不能修复顺序或单位错误

显式 state_key 优先，否则回退同名 action key；缺 state 或 key 都报错。同一本体允许相对 arm/EEF 与 absolute gripper 混合。checkpoint 全局 use_relative_action=true，但这不推出全部 group 或全部维度相对化。

Joint 与 EEF 的成对变换

对同一关节顺序、单位和角度约定下的 NON_EEF 向量：

\[r_k=q^{\mathrm{abs}}_k-q_{\mathrm{ref}},\qquad q^{\mathrm{abs}}_k=q_{\mathrm{ref}}+r_k.\]

角度 wrap policy 必须单独记录。对 EEF 齐次刚体变换：

\[T^{\mathrm{rel}}_k=T_{\mathrm{ref}}^{-1}T^{\mathrm{abs}}_k,\qquad T^{\mathrm{abs}}_k=T_{\mathrm{ref}}T^{\mathrm{rel}}_k.\]

旋转必须从声明的 rot6d、rotvec 或 quaternion 编码还原到 SO(3) 后复合；quaternion 使用时需归一化。把编码元素直接相加既不等价于群复合，也不能作为 round-trip 证明。

flowchart TB
  JA[joint absolute q_k] -->|minus q_ref| JR[joint relative r_k]
  JR -->|plus q_ref| JA2[restored q_k]
  EA[EEF absolute T_k] -->|inverse T_ref times T_k| ER[relative T_rel,k]
  ER -->|T_ref times T_rel,k| EA2[restored T_k]

文本回退：Joint 路径使用同序同单位向量的减/加；EEF 路径使用 SE(3) 逆与矩阵复合。两条路径都共享 chunk reference，但几何运算不可互换。

apply / unapply、raw_state 与 shape

训练 apply_action 的固定顺序是：deep copy absolute action → 解析 group 与 reference → 在启用时 absolute→relative → 选择 representation-matched statistics → normalize → 可选 clip 到 [-1,1]。先归一化再变换是错误次序；缺 relative statistics 不得回退 absolute statistics。

推理 unapply_action 的顺序是：选择匹配 statistics → denormalize → 解析 reference → relative→absolute。支持 [T,D] 与 [B,T,D]，每个 batch 样本独立取 state 序列最后一步为 reference，输出恢复原 batch 形态的 absolute action chunk。

sin/cos state encoding 不可唯一反演。当联合 unapply 不能从 state transform 恢复原角度时，相对动作必须使用带 timestamp 与 schema 的 raw_state；禁止在没有分支策略的情况下从 sin/cos 猜角度。

Round-trip、typed errors 与 first divergence

离线 fixture 的唯一最小路径是 absolute→relative→absolute，当前状态为 NOT_RUN。Joint 分别报告最大绝对误差与 wrap 后角度误差；EEF 分别报告平移范数与 rotation geodesic angle。用例覆盖 unbatched、batched、relative/absolute mixed groups、nonuniform offsets 与每种已声明 rotation format，不需要机器人对象。

clip 与 mask 都不得作为 schema 错误恢复
Typed error 触发条件
REFERENCE_STATE_MISSING 缺 reference state
REFERENCE_KEY_MISSING reference 中缺配置 key
STATE_ACTION_DIM_MISMATCH state/action 维不匹配
UNKNOWN_ACTION_TYPE 未支持的 ActionType
ACTION_FORMAT_INVALID format 或编码约束不成立
NONFINITE_INPUT 输入含非有限值
TIMESTAMP_MISALIGNED reference 与 action 时间未对齐
ROUND_TRIP_MISMATCH 往返误差超过合同阈值 
flowchart LR
  A[raw absolute] --> S[reference state] --> R[relative] --> N[normalized]
  N --> O[model output] --> D[denormalized relative] --> X[restored absolute]

文本回退：按 raw absolute、reference、relative、normalized、model output、denormalized relative、restored absolute 七阶段记录 shape、dtype、finite、mask count、summary 与 error；最早不一致阶段就是 first divergence。该诊断仍为 NOT_RUN。

方差条件、块级漂移与证据边界

对标量维度，方差恒等式与下降条件分别是：

\[\operatorname{Var}(A-S)=\operatorname{Var}(A)+\operatorname{Var}(S)-2\operatorname{Cov}(A,S), \qquad \operatorname{Var}(A-S)<\operatorname{Var}(A)\iff2\operatorname{Cov}(A,S)>\operatorname{Var}(S).\]

局部控制相关性和 episode 原点抵消可能使分布更集中，但都只是可检验机制；EEF 旋转必须在声明表示或切空间定义统计。官方“更平滑、更准确”只适用于其报告设置，不是普遍保证。

块级误差可线性化为：

\[e_{j+1}\approx A_j e_j+b_j+w_j.\]

A_j 是闭环误差传播，b_j 是系统性策略偏差，w_j 汇总估计、执行和环境扰动。只有 A_j≈I 才近似简单累加；收缩系统可能纠错，非收缩或持续偏差可能积累。每次重锚可减少绝对零位不一致，但不能自动消除漂移。

闭环角色、mask 与 statistics 交接

DAgger补充策略真实访问到的偏移状态，处理分布恢复数据。
RTC协调异步或重叠动作块，不重新定义动作表示。
State estimator决定 reference state 的质量与时间对齐。
Low-level controller跟踪 absolute target；独立 safety supervisor 保留 inhibit/stop authority。

相对动作只拥有 target representation，这些角色互补但不可互相替代，运行细节归 Inference 页。action_mask 的容器 shape 为 B×50×128，有效域是有效时间与有效维的交集；它可限定变换检查范围，却不能修复 key order、coordinate frame、units、rotation format 或 reference。

本页签发 representation_id、per-group semantics、forward/inverse transform ID 与 reference contract ID；并列 Data Statistics 页提供 statistics_id 与 mask_contract_id。两者不匹配时拒绝 receipt，不在本页决定 min/max/mean/std、clip、override、padding 或 mask 生成。

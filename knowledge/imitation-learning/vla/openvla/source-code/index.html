原生推理链

schema: openvla.native-predict-action.v1
entrypoint: prismatic.models.vlas.openvla.OpenVLA.predict_action
explicit_inputs: [image, instruction, unnorm_key]
preconditions_observed: [unnorm-key-membership-in-norm-stats]
prompt: {template: "In: What action should the robot take to {instruction.lower()}?\\nOut:"}
tokenizer: {add_special_tokens: true, appended_token_id: 29871}
generation: {do_sample: false, max_new_tokens: action-dimension-from-q01}
decode: {source: last-D-generated-token-ids, formula: vocab_size-minus-token_id, clip_index: true}
unnormalize: {range: [-1, 1], stats: [q01, q99, mask]}
returns: continuous-action-vector

控制流为：检查 key membership → lower-case prompt → tokenize 并补 29871 → 图像 transform → greedy 生成最多 D 个 token → 取最后 D 个 id → decode bins → 对 mask=true 维度用 q01/q99 反归一化。这里没有硬 action-token mask、逐 token 合法断言或“恰好 D 个有效动作 token”断言；early EOS/文本 token 可能经 clip 变成有限值。D 由 q01 长度推导，不是独立 action schema。

执行门：该路径可产生数值动作，但只有在 policy I/O 合同、统计键语义、动作维度、单位/坐标系与安全门全部闭合后，才可作为可执行动作。

DATA AXIS · OFFLINE NEURAL TRAJECTORY · PSEUDO-ACTION BOUNDARY

DreamGen 回答“生成什么训练数据”：适配世界模型、离线生成视频、用 IDM 或 LAPA 补伪动作，再训练策略；它不是部署时实时视频规划器，也不是 FLARE 目标轴的前驱。

N1 已有基线与 DreamGen 增量

DreamGen不是首次提出“先生成视频，再补伪动作”。N1 v2已报告88.4小时真机GR-1遥操数据与827.3小时神经视频，合计915.7小时，神经/真机时长比约9.3586；论文还用“约10倍”“约30万条神经轨迹”“约105,000 L40 GPU·h”描述规模。这些全是N1基线口径，不是DreamGen新实验或N1.5五源绝对规模。

DreamGen的增量是把路线系统化为可跨策略使用的四阶段方法，并把目标从扩量拓展到行为泛化、环境泛化和生成质量诊断。它同时保留IDM物理动作与LAPA潜在动作两路，但不证明所有策略、本体或标签路线收益相同。

四阶段离线神经轨迹管线

flowchart LR
  R[目标本体遥操视频] --> W[① LoRA适配视频世界模型]
  I[初始帧 + 语言指令] --> G[② 离线生成机器人视频]
  W --> G
  G --> P{③ 补伪动作}
  P -->|IDM| A[物理动作块]
  P -->|LAPA| Z[连续潜在动作]
  A --> T[④ 训练视觉运动策略]
  Z --> T

文本回退：先用目标本体视频LoRA适配视频世界模型，再由初始帧与指令离线生成机器人视频；第三步选择IDM物理动作块或LAPA连续潜在动作补标签；最后以“视频+伪动作”训练视觉运动策略。世界模型只在训练数据准备阶段运行，输出的neural trajectory既不是真值机器人轨迹，也未经安全认证。

世界模型适配、生成输入与人工入口

论文默认以LoRA适配目标本体，作者动机是减轻互联网视频先验遗忘；没有“全量微调必然退化”的独立消融。多数下游实验使用WAN2.1，Bench另比较Hunyuan、CogVideoX、WAN2.1与Cosmos；论文没有在本页证据中披露可固定的WAN2.1 checkpoint revision。RoboCasa与DROID多视角被排成2×2网格并留一格黑色，这只是输入排版，不保证跨视角几何重建或标定。

减少遥操轨迹不等于消除人工输入
目标 初始帧 仍需人工或已知边界
仿真扩增 仿真器采样 随机化目标物或环境位置
真机扩增 人工拍摄 随机化目标物位置
环境泛化 新环境拍摄 仍需进入新环境取得入口图像
行为泛化 已有起始图像 新行为提示词由人编写
图生图入口随机化 未作为默认实现 论文列为future work

世界模型只输出机器人视频，不验证目标可达性、碰撞、安全或控制可执行性。选择世界模型时使用Instruction Following与Physics Alignment，但这两项仍是生成质量指标，不是机器人闭环保证。

IDM：物理伪动作、滑窗与未决端点

IDM使用SigLIP-2视觉编码器和Diffusion Transformer，以Flow Matching训练；条件恰为两帧图像，输出帧间长度H的目标本体物理动作块，不输入语言或proprioception。默认训练数据与对应世界模型适配数据相同，伪标注滑窗每次右移一帧。为表达多解性，可写派生接口 Â_t ~ pψ(A_t | x_t, x_{t+Δ})，但它只是页面接口化记法：通用Δ、控制周期、Flow时间方向和采样步数均未披露。

论文同时写“输出H个动作”和 â_t…â_{t+H}；若包含两端，后者是H+1项。本页不替论文决定端点，实施时须以真实张量horizon为门。stride=1也意味着内部时刻可能得到多个候选预测，而聚合/选择规则未公开。同一对端点帧可对应不同速度、接触力和冗余关节轨迹，所以IDM标签不是唯一真实动作；IDM组件训练需要目标本体真值动作，标签潜在可落在物理空间也不等于已通过安全执行门。

LAPA：连续潜在动作与物理桥边界

LAPA以Transformer encoder-decoder和VQ-VAE目标，从当前帧与1秒后未来帧提取视觉变化。DreamGen实际使用量化前连续嵌入 z_pre，不是离散code index；该表示没有关节角、末端位姿或速度物理单位，不能直接发送给机器人。附录配置为codebook size 8、量化序列长16、训练100K步、batch1024；这些是DreamGen论文实验配置，不是N1.5发布配置。

两条路线都是伪监督
路线 输出 目标本体真值动作 执行边界
IDM H×physical_action_dim动作块 训练IDM需要 仍需本体绑定、时序与安全验证
LAPA 量化前连续视觉变化嵌入 组件训练不需要 没有物理单位，完整可执行策略仍需物理动作桥

在有遥操数据的报告设置中，IDM与LAPA联合训练收益相近；论文随后默认IDM，因为它能用于“只用神经轨迹训练并直接评测策略”。这不是IDM普遍优于LAPA的证明。目标本体完全没有真值数据时的新行为/新环境泛化仍是开放问题。

策略接入、缺失状态与采样分母

record neural_trajectory {
  instruction: text
  image_sequence: generated frames
  state: zeros                    # 未披露显式 missing-state mask
  supervision:
    IDM  -> H x physical_action_dim pseudo-action chunk
    LAPA -> continuous pre-quantized latent target
  provenance: world-model + initial-frame + prompt + pseudo-labeler
  safety_status: unverified
}

论文在Diffusion Policy、π0与GR00T N1三类策略上验证数据接口，只能支持“可跨这三类策略使用”。神经轨迹没有proprioception时以数值零填状态；论文只报告“初步实验未观察到伤害”。零不是缺失mask，也可能与归一化真实状态重合，不能推出策略从不使用状态或所有任务安全。

GR00T N1集成把真实与神经轨迹视作独立embodiment，使用不同动作encoder/decoder并共享主干；它可能隔离标签分布，但没有独立消融，不能推广为Diffusion Policy/π0通用接法，也不能静默认定N1.5使用相同路由。

联合训练报告真实:神经为1:1，但没有说明分母是轨迹、batch item、帧、时长、token还是采样概率；neural-only实验限定IDM标签。优化器、总loss和采样实现归③Training，本页不执行采样。

两套结果：22 行为与 12 动词

任务数、模型和训练设置不同，不合并
系统 结果 可说 不可说
DreamGen v2 22个新行为、10个新环境；含seen/unseen组合 DreamGen自身在DP、π0、N1等策略上的实验 不能改写成N1.5的12动词实验
N1.5 Research 12个新动词；N1 13.1%，N1.5 38.3% 差25.2百分点，比率约2.9237；没有收集对应任务遥操数据 模型训练过这些动词的DreamGen轨迹，不能称严格未见训练词

因此准确说法是“12个任务无对应遥操数据”，而不是严格zero-shot或“训练数据中未出现动词”。完整N1.5结果表、协议比较与统计不确定性归⑤Experiments。

DreamGen Bench、扩展成本与风险边界

Instruction Following（IF）主文用Qwen2.5-VL对指令和视频给二值0/1，同时表列GPT-4o与人工版；Physics Alignment（PA）取VideoCon-Physics和Qwen2.5-VL物理分数的算术平均。自动IF与人工IF平均Pearson相关大于0.9，只支持评审器一致性，不是机器人可执行性。

Bench比较Hunyuan、CogVideoX、WAN2.1、Cosmos四个模型的zero-shot/fine-tuned共8个变体；RoboCasa、GR1 Object、GR1 Behavior、GR1 Environment四子集评估数为48/50/47/30。相关性实验为每个变体生成7,000条神经轨迹，共56,000条，只用这些轨迹在RoboCasa训练策略；图中Bench分数为IF(GPT)+PA平均，并呈正相关。主文没有具体Pearson/Spearman系数，也未隔离IDM误差，所以只能将其视作该实验中的低成本前置诊断，不能称普适成功率预测器。

RoboCasa扩展实验覆盖24任务、真值轨迹720/2,400/7,200三档与0–240,000条神经轨迹；240,000/720≈333.33支撑“最高约333×”，不是每档都333×。neural-only IDM平均成功率20.6%。24万样本由1,500张L40运行54小时，派生总量81,000 L40 GPU·h；54小时是并行墙钟，不是总计算量或单卡时间。log-linear只限已测区间，不外推无界规模。

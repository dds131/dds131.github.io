经典随机策略、V 型 Critic 的单步 Actor-Critic 建立在一条关键等式上：当 Critic 准确时，TD 误差的条件期望恰好是优势函数。本页把这条等式前后的数学讲完整——为什么优势是规范化的动作相对信号，TD 误差在什么前提下才能代替它，Critic 不准时误差怎样进入梯度、朝哪个方向偏，以及方差为什么会下降、什么时候不会。Q 型、确定性与最大熵 Actor-Critic 还有各自的梯度依据，不能由这一条等式概括，统一边界见子页 ⑦。

7 种权重从整条轨迹回报到 GAE
3 个前提TD 误差无偏所需的条件

本页重点。第三节的手算例子说明「期望相同的两种权重，方差可以差两个数量级」，同时给出一个必须保留的边界：\(V^\pi\) 是最常用的基线，但一般不等于严格的方差最优基线。第五节给出 TD 误差无偏性的完整证明，并逐条说明三个前提各自不成立时会怎样；第六节给出固定 Critic、单次 Actor 更新内的偏差精确形式；第七节用 TD 误差序列的鞅差性质，算出真值 Critic 条件下相对蒙特卡洛权重去掉的方差。可以略读：第二节的符号表（与枢纽页一致）与第九节的教材算法框（与枢纽页 4.4 节同一内容的逐行展开）。

一、本页要解决什么问题

本页先固定目标口径。对折扣回合型的起始状态目标

\[J_\gamma(\theta)=\mathbb E_{\tau\sim\pi_\theta}\!\left[G_0\right], \qquad G_t=\sum_{k\ge 0}\gamma^k r_{t+k},\]

记得分函数 \(h_t=\nabla_\theta\log\pi_\theta(a_t\mid s_t)\)。似然比恒等式与因果性给出两种等价写法：

\[\nabla_\theta J_\gamma =\mathbb E\!\left[G_0\sum_t h_t\right] =\mathbb E\!\left[\sum_t\gamma^t h_t G_t\right].\]

第一式允许“整条轨迹回报”给每个时间步加权；第二式去掉了动作之前的奖励，因此从 \(G_t\)、\(Q^\pi\)、\(A^\pi\) 到满足条件的 \(\delta_t\)，都应放在 \(\gamma^t h_t\Psi_t\) 这个因果形式里。状态访问分布也由当前策略产生，并不是一个固定的监督学习数据集。深度实现常省略外层 \(\gamma^t\)，那会改变时间步的权重；第四节会把这一例外单列，避免把两种公式混用。

本页采用的 Actor-Critic 边界。窄义 Actor-Critic 指：Actor 更新中的动作评价信号由一个学习中的价值估计器提供，并通常含 bootstrap；经典 V 型单步方法用 \(r_t+\gamma V_\phi(s_{t+1})-V_\phi(s_t)\)。如果 \(V_\phi(s_t)\) 只从完整蒙特卡洛回报回归，并仅作为 \(G_t-V_\phi(s_t)\) 的状态基线，它在数学上仍是“带学习基线的 REINFORCE”，不是窄义的 bootstrapped Actor-Critic。工程资料有时把任何“策略头 + 价值头”都宽泛称为 Actor-Critic；本专题除非特别说明，采用前述窄义边界。

在本页讨论的随机策略、得分函数型更新中，Actor-Critic 选择用 Critic 构造的权重 \(\Psi_t\)（单步时为 \(\delta_t\)）。无论 Actor 与 Critic 是否共享骨干，Actor loss 都必须把这个权重视作样本常量，即停止梯度；Critic 由自己的价值损失更新。本页回答四个问题：

  1. 为什么优势 \(A^\pi\) 是规范化的动作相对信号，它与严格的方差最优基线又有什么区别（第三、四节）？
  2. \(\delta_t\) 在什么前提下是 \(A^\pi\) 的无偏估计（第五节）？
  3. Critic 不准时，误差以什么形式、朝什么方向进入梯度（第六节）？
  4. 换成 \(\delta_t\) 之后方差到底去掉了哪一部分，什么情况下去不掉（第七节）？

二、符号与终止处理

2.1 符号

记号 含义 在本页中的角色
\(\pi_\theta(a \mid s)\) Actor，参数 \(\theta\) 被优化的策略
\(V_\phi(s)\)，\(Q_\phi(s,a)\) Critic，参数 \(\phi\)（教材记作 \(w\)） V 型与 Q 型两种 Critic
\(V^\pi, Q^\pi, A^\pi\) 当前策略的真实状态价值、动作价值、优势 只存在于分析中
\(r_t\) 在 \(s_t\) 执行 \(a_t\) 后得到的奖励（教材 \(R_{t+1}\)） 一步转移的随机量
\(G_t = \sum_{k \ge 0} \gamma^k r_{t+k}\) 动作之后的折扣回报 REINFORCE 的权重
\(\delta_t\) TD 误差 \(r_t + \gamma V(s_{t+1}) - V(s_t)\) 本专题的核心量
\(e(s) = V_\phi(s) - V^\pi(s)\) Critic 的逼近误差 第六节偏差分析
\(d_t\) 目标一致的“无后续价值”标志；声明的任务在该步后没有 continuation 时为 1 bootstrap 掩码

2.2 终止与截断

TD 误差含下一状态的估值。这里的关键不是“循环是否停止”，而是按已声明的学习目标，下一状态是否还有 continuation value：

\[\delta_t \;=\; r_t + \gamma\,(1 - d_t)\, V_\phi(s_{t+1}) - V_\phi(s_t).\]

若到达真正吸收终止，或到达任务定义内生的有限时域末端，则后续价值为零、\(d_t=1\)。有限时域若会影响最优决策，剩余时间必须进入状态/观测，才能保持 Markov 性。相反，采样器片段末端、训练预算或任务外部 TimeLimit 造成的人工截断只是“数据没有继续采”，并不把 MDP 的 continuation value 变成零，此时 \(d_t=0\)，必须从 \(V_\phi(s_{t+1})\) 自举。

Gymnasium 的 step 用 terminated 与 truncated 区分这两类事件；用于 bootstrap 的掩码通常只看 terminated。但字段名不是最终数学依据：若环境把任务内生的有限时域建模为 termination，它同样属于 \(d_t=1\)。把人工截断当作终止会在第六节的偏差分析里留下一个确定的误差项；片段末端自举与并行环境掩码在子页 ③ 展开。

三、优势函数：为什么它是规范化的动作相对信号

3.1 定义与三条性质

\[A^\pi(s, a) \;=\; Q^\pi(s, a) - V^\pi(s)\]

性质一：在当前策略下平均为零。由 \(V^\pi(s) = \sum_a \pi(a \mid s)\, Q^\pi(s,a)\) 直接得到

\[\mathbb{E}_{a \sim \pi(\cdot \mid s)}\big[A^\pi(s,a)\big] \;=\; \sum_a \pi(a \mid s)\, Q^\pi(s,a) - V^\pi(s) \;=\; 0\]

所以优势衡量的是「这个动作比当前策略在这个状态下的平均水平好多少」，正负号本身就有意义：\(A^\pi > 0\) 的动作值得多做，\(A^\pi < 0\) 的动作应当少做。GAE 论文第 2 节正是用这一点解释为什么优势是好的权重：一次策略梯度更新应当提高好于平均的动作的概率、降低差于平均的动作的概率。

性质二：不改变贪心改进的方向。对固定状态，\(A^\pi(s,a)\) 与 \(Q^\pi(s,a)\) 只差一个与动作无关的常数，所以 \(\arg\max_a A^\pi(s,a) = \arg\max_a Q^\pi(s,a)\)；又因为平均为零，最优动作的优势一定不小于零。

性质三：用它作权重，梯度期望不变。\(\mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta(a \mid s)\big] = 0\)，于是 \(\mathbb{E}_a\big[\nabla_\theta \ln \pi_\theta \cdot V^\pi(s)\big] = 0\)，从而

\[\mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta(a \mid s)\, Q^\pi(s,a)\big] \;=\; \mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta(a \mid s)\, A^\pi(s,a)\big]\]

这就是「减去状态基线不改变梯度期望」在 \(b(s) = V^\pi(s)\) 时的特例，完整证明见策略梯度 · 方差、基线与降方差。

重要边界：优势不是普遍意义下的“最小方差权重”。令 \(h(a,s)=\nabla_\theta\log\pi_\theta(a\mid s)\)。若目标是在固定状态 \(s\) 上最小化单样本梯度 \(h(Q-b)\) 的二阶矩，则最优的标量状态基线是

\[b^\star(s)= \frac{\mathbb E_{a\sim\pi}\!\left[\lVert h(a,s)\rVert^2 Q^\pi(s,a)\right]} {\mathbb E_{a\sim\pi}\!\left[\lVert h(a,s)\rVert^2\right]}.\]

它只有在得分函数范数与动作无关，或二者的相关性可忽略时，才退化为 \(V^\pi(s)=\mathbb E_a[Q^\pi(s,a)]\)。因此准确说法是：优势把与动作无关的状态价值中心化掉，是最自然、最常用且通常显著降方差的信号；但对给定策略参数化，严格的方差最优基线还要按得分函数平方范数加权。Greensmith、Bartlett 与 Baxter（2004）给出了这一类最优基线分析。

3.2 一个可以手算的例子：期望相同，方差差两个数量级

性质三说明用 \(Q\) 与用 \(A\) 作权重，梯度的期望完全一样。差别在方差。下面用一个构造的单状态例子把它算出来：一个状态、三个动作，策略是对 logits 做 softmax，当前概率 \(\pi = (0.5, 0.3, 0.2)\)，三个动作的真实动作价值取 \(Q = (21, 20, 17)\)。

对 logits 求导时，动作 \(a\) 的得分函数是 \(\nabla_z \ln \pi_a = e_a - \pi\)（\(e_a\) 为第 \(a\) 个分量为 1 的单位向量，推导见策略梯度 · 策略网络与分布族参数化）。单样本梯度估计为 \(g = (e_a - \pi)\,\Psi_a\)，逐项计算：

动作 \(\pi(a)\) \(Q\) \(A = Q - V\) \(\lVert e_a - \pi \rVert^2\)
a1 0.5 21 +1.1 0.38
a2 0.3 20 +0.1 0.78
a3 0.2 17 −2.9 0.98

期望梯度相同。两种权重下 \(\mathbb{E}[g]_i = \pi_i\,(Q_i - V) = \pi_i A_i\)，都等于 \((0.55,\ 0.03,\ -0.58)\)，其平方范数为 0.6398。

总方差（协方差矩阵的迹）\(= \mathbb{E}\lVert g \rVert^2 - \lVert \mathbb{E} g \rVert^2\)：用 \(Q\) 时约为 233.39，用 \(A\) 时约为 1.24，相差约 188 倍。

这个例子说明一件容易被忽略的事：权重本身在动作之间的方差其实一样（\(Q\) 与 \(A\) 只差一个常数，两者的方差都是 2.29），真正拉开差距的是权重的二阶矩 \(\mathbb{E}[\Psi^2]\)——398.3 对 2.29。梯度估计的方差由 \(\mathbb{E}\big[\lVert \nabla \ln \pi \rVert^2\, \Psi^2\big]\) 主导，一个数值很大、但对所有动作都差不多的权重，会让每次采样都把被采到的动作「大力鼓励」，再靠大量样本互相抵消。优势把这个公共部分预先扣掉了。

3.3 优势与策略改进的关系

优势不只是一个方便的权重，它还直接刻画了换策略能带来多少收益：新旧策略的性能差可以写成「新策略访问的状态上、按新策略选的动作、在旧策略下的优势」的期望（Kakade 与 Langford 2002 给出的性能差恒等式）。因此，若这个按新策略状态占用分布计算的期望为正，性能才得到严格改进；仅仅提高某个正优势动作的概率，而不考虑概率归一化与状态分布变化，并不是全局改进证明。策略梯度把它转化为旧策略附近的一阶局部方向。TRPO 的整条推导从恒等式与受控分布变化出发，完整推导见 TRPO 专题。

4.3 两条分界线

第一条：学到的价值量只是基线，还是参与动作评价。①②不使用学习值函数；③即使使用学到的 \(b(s_t)\)，只要它不依赖当前动作且在 Actor loss 中停止梯度，学不准也不改变期望。④–⑦ 的学习值函数会参与动作评价或 bootstrap，一般需要真值才无偏；第 ⑦ 行的完整蒙特卡洛极限是有明确尾部条件的例外。这条线正是窄义 Actor-Critic 与“带学习基线的 REINFORCE”的数学边界。

第二条：方差怎样被一步步拿走。① 到 ② 用因果性去掉 \(t\) 之前的奖励；② 到 ③ 扣掉与动作无关的状态成分；② 到 ④ 是把未来随机回报换成条件期望，② 到 ⑥ 则只保留一步真实转移、其后交给价值估计。④ 与 ⑤ 之间只差状态基线；3.2 节的 188 倍只是一个构造例，不是普遍倍率。

五、TD 误差是优势的无偏估计

5.1 完整证明

前提：\(V\) 取当前策略的真实价值 \(V^\pi\)；期望只对环境的随机性（奖励与转移）取；终止状态的价值按定义为零。

给定 \((s_t, a_t)\) 后，\(V^\pi(s_t)\) 是常数，可以提到期望外：

\[\mathbb{E}\big[\delta_t \mid s_t, a_t\big] \;=\; \mathbb{E}\big[r_t + \gamma (1 - d_t) V^\pi(s_{t+1}) \mid s_t, a_t\big] - V^\pi(s_t)\]

Bellman 期望方程给出的正是第一项：

\[Q^\pi(s, a) \;=\; \mathbb{E}\big[r_t + \gamma (1 - d_t) V^\pi(s_{t+1}) \mid s_t = s,\ a_t = a\big]\]

代回即得

\[\mathbb{E}\big[\delta_t \mid s_t, a_t\big] \;=\; Q^\pi(s_t, a_t) - V^\pi(s_t) \;=\; A^\pi(s_t, a_t)\]

再用全期望公式，把它放回策略梯度里：

\[\mathbb{E}\big[\nabla_\theta \ln \pi_\theta(a_t \mid s_t)\, \delta_t\big] \;=\; \mathbb{E}\Big[\nabla_\theta \ln \pi_\theta(a_t \mid s_t)\, \mathbb{E}\big[\delta_t \mid s_t, a_t\big]\Big] \;=\; \mathbb{E}\big[\nabla_\theta \ln \pi_\theta(a_t \mid s_t)\, A^\pi(s_t, a_t)\big]\]

这条等式是随机策略、V 型单步 Actor-Critic 的关键合法性来源：一条采样转移算出的 \(\delta_t\)，在条件期望意义上与真实优势 \(A^\pi\) 等价。它不是所有 Actor-Critic 方法的统一证明：Q 型方法可直接使用动作价值，DDPG/TD3 使用确定性策略梯度，SAC 的重参数化 Actor 又有不同目标。David Silver 的策略梯度课件（Lecture 7）把本节这一步写作「对真实价值函数 \(V^{\pi_\theta}\)，TD 误差是优势函数的无偏估计」，并指出这种 V 型写法只需要一套 Critic 参数。

5.2 三个前提，各自不成立时会怎样

前提一：\(V\) 是当前策略的真实价值。训练中的 Critic 通常只是在追踪变化的当前策略，并不精确等于任何策略的真值。为了看清“策略滞后”这一种误差，假设它恰好等于旧策略 \(\pi_{\text{old}}\) 的真值，则同一条推导给出

\[\mathbb{E}\big[\delta_t \mid s_t, a_t\big] \;=\; A^{\pi_{\text{old}}}(s_t, a_t)\]

但 Actor 的得分函数与状态—动作分布来自当前策略 \(\pi_\theta\)。除非 \(\pi_{\text{old}}=\pi_\theta\)，或另有严格的 off-policy 校正，这个乘积一般不是当前策略也不是旧策略的精确梯度；它只是按过时价值产生的近似更新。这正是两时间尺度分析要求 Critic 更快跟踪 Actor 的原因之一，展开见子页 ②；滞后严重时的表现见子页 ⑧。

前提二：期望只对环境取。\(\delta_t\) 是随机量，单次采样与 \(A^\pi\) 可以相差很远；等式只在条件期望层面成立。上图第三行的等号就属于这类简写。

前提三：continuation、折扣与目标一致。只有目标定义下没有后续价值时才置零，人工截断仍要自举（2.2 节）；\(\delta_t\) 中的 \(\gamma\) 还必须与这里定义 \(V^\pi,Q^\pi,A^\pi\) 的目标折扣一致。GAE 论文采用不折扣任务目标、另把 \(\gamma\) 当估计器参数，因此论文所说的“\(\gamma<1\) 引入偏差”是相对不折扣目标而言；若本站直接把 \(J_\gamma\) 声明为优化目标，同一个 \(\gamma\) 定义的是目标本身，不应再重复算作估计偏差。相关实现见子页 ③。

六、近似 Critic 下的偏差：精确分解

6.1 误差怎么进入 TD 误差

实际算出的是 \(\hat\delta_t = r_t + \gamma (1 - d_t) V_\phi(s_{t+1}) - V_\phi(s_t)\)。把 \(V_\phi = V^\pi + e\) 代入，得到一个精确的分解：

\[\hat\delta_t \;=\; \underbrace{\delta_t}_{\text{条件期望为 } A^\pi} \;+\; \underbrace{\gamma (1 - d_t)\, e(s_{t+1})}_{\text{下一状态的误差}} \;-\; \underbrace{e(s_t)}_{\text{当前状态的误差}}\]

三项的地位完全不同。

6.2 只有一项会进入梯度

记

\[(Pe)(s,a) = \mathbb{E}\big[(1-d_t)e(s_{t+1}) \mid s_t=s,\ a_t=a\big],\]

即「从 \((s,a)\) 出发，下一状态上 Critic 误差的期望」（转移到目标终止状态时该项按零计）。对动作取期望：

\[\mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta(a \mid s)\, \hat\delta\big] \;=\; \underbrace{\mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta\, A^\pi(s,a)\big]}_{\text{真梯度的那一项}} \;+\; \gamma\, \mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta\, (Pe)(s,a)\big] \;-\; e(s)\, \underbrace{\mathbb{E}_{a \sim \pi}\big[\nabla_\theta \ln \pi_\theta\big]}_{= 0}\]

第三项因得分函数的期望为零而消失：\(e(s)\) 与动作无关，它的作用与基线完全一样，只影响方差、不产生偏差。第二项用 \(\pi_\theta \nabla_\theta \ln \pi_\theta = \nabla_\theta \pi_\theta\) 改写：

\[\text{偏差}(s) \;=\; \gamma \sum_a \nabla_\theta \pi_\theta(a \mid s)\, (Pe)(s,a) \;=\; \gamma\, \nabla_\theta \Big[\sum_a \pi_\theta(a \mid s)\, (Pe)(s,a)\Big]_{e,\,P \text{ 视为固定}}\]

（连续动作把求和换成积分，结论不变。）

上式是一个固定状态、固定转移核、把 Critic 误差函数视为常量的局部结论。实现中必须对优势或 TD 目标停止梯度；若 Actor 与 Critic 共享骨干而没有正确切断 Actor loss 到价值头的梯度，\(e\) 还会随 \(\theta\) 直接变化，上式不再覆盖那条额外梯度通路。对本页声明的起点折扣目标，完整 Actor 偏差还要按当前策略的状态占用分布求平均，并保留外层时间权重：\(\mathbb E[\sum_t\gamma^t\,\text{偏差}(s_t)]\)。这里局部式子前的 \(\gamma\) 来自一步 bootstrap，不能替代外层 \(\gamma^t\)；本节只分析最容易被忽略的“动作改变下一状态”通路。

6.3 偏差的方向：Actor 会朝 Critic 高估的地方走

上式右边是一个梯度——「下一状态上 Critic 误差的期望」对策略参数的梯度。也就是说，Actor 在沿真实性能梯度上升的同时，还在顺带最大化 \(\gamma\,\mathbb{E}_{a \sim \pi}[(Pe)(s,a)]\)：哪个动作能把系统带到 Critic 高估（\(e > 0\)）的状态，它的概率就被额外推高。

在“本批数据与本次 Actor 更新期间固定 Critic”的条件下，这个式子解释了三件常被观察到的事：

  • 增加同分布样本不会把它平均为零。样本均值只会更准确地逼近这个有偏期望；这与零均值采样噪声不同。
  • 偏差可能形成自我强化。若策略被持续推向高估区域，而 Critic 的新数据又不足以及时纠正该区域，访问分布会进一步集中并形成正反馈。它不是必然现象：Critic 更新后 \(e\) 会变化，后续批次的偏差方向也可能改变或抵消。诊断见子页 ⑧。
  • Q 型 Critic 上有同构的现象。确定性 Actor 沿 \(\nabla_a Q_\phi\) 上升时，同样会沿着 \(Q_\phi\) 的误差上升，这正是 TD3 用两个 Critic 取较小值要压制的问题，见 TD3。

6.4 两个值得单独记住的特例

特例一：Critic 整体偏高或偏低一个常数。设所有非终止状态上 \(e(s) = c\)，则 \((Pe)(s,a) = c\,\big(1 - p(s,a)\big)\)，其中 \(p(s,a)\) 是从 \((s,a)\) 出发下一步真终止的概率，于是

\[\text{偏差}(s) \;=\; -\,\gamma\, c\, \nabla_\theta \Big[\sum_a \pi_\theta(a \mid s)\, p(s,a)\Big]\]

结论很具体：在没有终止、或终止概率与动作无关的任务里，常数偏移完全不产生偏差（它退化成一个基线）；而在终止概率依赖动作的任务里（例如失败即终止的 CartPole），Critic 整体高估（\(c > 0\)）会额外推着策略去降低终止概率，整体低估则相反。本页旧版本把这一情形写成「偏差退化为 \((\gamma - 1)e\)」，那是把「TD 误差的偏移」当成了「梯度的偏差」，两者不是一回事。

特例二：把截断当成终止。此时并不是 Critic 函数本身突然产生了 \(e=-V^\pi\)，而是 bootstrap 掩码把本应保留的 \(\gamma V^\pi(s_{t+1})\) 强行删掉，给 TD 目标加入了 \(-\gamma V^\pi(s_{t+1})\) 的确定性误差。该误差随下一状态变化，因而同样经「动作决定下一状态」进入 Actor 更新；在价值为正的持续任务里，它系统性地压低截断边界附近的评价。实现口径见子页 ③，它在曲线上的表现见子页 ⑧。

6.5 为什么多采样消不掉这部分偏差

对一个固定的 Critic 与固定的一步估计器，增加同分布 Actor 样本只会让估计更接近它自己的有偏期望，不能把该偏差平均掉。要改变偏差，必须改变进入式子的动作相关误差投影：例如把 Critic 训得更准、改用更长回报降低边界 bootstrap 的占比，或在满足严格条件时使用相容逼近。GAE 论文在引言中的核心警告是：方差可由更多样本压低，而固定偏差即使在样本无限时仍可能把优化带向错误解。

因此，「偏差与采样多少数据无关」只对固定 Critic、固定估计器的 Actor 采样成立。联合训练中，更多 Critic 数据可能间接改善 \(V_\phi\)；反过来，分布漂移或优化误差也可能使它没有改善。

七、方差为什么下降、什么时候不下降

7.1 回报与 TD 误差序列的望远镜关系

仍设 \(V = V^\pi\)、回合型任务且终止状态价值为零。把 \(\delta\) 逐项展开，中间的价值项两两抵消：

\[\sum_{k \ge 0} \gamma^k \delta_{t+k} = \sum_{k \ge 0} \gamma^k \big(r_{t+k} + \gamma V^\pi(s_{t+k+1}) - V^\pi(s_{t+k})\big) = G_t - V^\pi(s_t)\]

也就是说，带基线的蒙特卡洛权重恰好是整条 TD 误差序列的折扣和，而 Actor-Critic 只保留其中的第一项。

7.2 条件方差的精确分解

假设相关回报与 TD 误差具有有限二阶矩。对 \(k \ge 1\)，给定到 \(s_{t+k}\) 为止的全部历史，对动作 \(a_{t+k} \sim \pi\) 以及随后一步的奖励与转移取期望即得

\[\mathbb{E}\big[\delta_{t+k} \mid s_t, a_t, \ldots, s_{t+k}\big] \;=\; \mathbb{E}_{a \sim \pi}\big[A^\pi(s_{t+k}, a)\big] \;=\; 0\]

即 \(\{\gamma^k \delta_{t+k}\}_{k \ge 1}\) 是一列鞅差。鞅差与之前的一切都不相关，交叉项全部为零，于是

\[\mathrm{Var}\big[G_t \mid s_t, a_t\big] \;=\; \mathrm{Var}\big[\delta_t \mid s_t, a_t\big] \;+\; \sum_{k \ge 1} \gamma^{2k}\, \mathbb{E}\big[\delta_{t+k}^2 \mid s_t, a_t\big]\]

（左边用到 \(V^\pi(s_t)\) 在给定 \(s_t\) 时是常数，减去它不改变方差。）

这给出一个干净但有明确范围的结论：在真值 Critic 条件下，把带真值基线的蒙特卡洛权重 \(G_t-V^\pi(s_t)\) 换成 \(\delta_t\)，去掉的正是「后续每一步 TD 误差的二阶矩按 \(\gamma^{2k}\) 加权的总和」，而且这一项一定非负。若后续各步的 \(\mathbb{E}[\delta^2]\) 大致相当、记为 \(\sigma^2\)，被去掉的量约为 \(\sigma^2 \gamma^2 / (1 - \gamma^2)\)。因此在其他条件相近时，\(\gamma\) 越接近 1、有效时域越长，单步 bootstrap 可去掉的未来噪声越多；这不是对所有任务训练效果的无条件保证。

上式比较的是权重本身在给定 \((s_t, a_t)\) 时的条件方差。此时得分函数已经是常量，所以同一 \((s_t,a_t)\) 下，梯度贡献的条件协方差确实按得分函数外积缩放；但若不再条件化、还要对状态与动作采样求方差，得分函数大小与权重可能相关，不能仅比较权重方差就断言完整梯度方差的大小。整条轨迹上不同时间步之间还存在协方差，本页的分解不覆盖这些项。

7.3 什么时候方差不会下降

  • Critic 不准时。上面的分解以 \(V = V^\pi\) 为前提。用 \(V_\phi\) 时权重多出 \(\gamma e(s_{t+1}) - e(s_t)\)，这一项本身带方差，\(\delta_t\) 甚至可能比 \(G_t - V_\phi(s_t)\) 更差。仅凭“训练初期不动”不能反推原因就是 Critic；还应同时检查回报尺度、策略熵、梯度范数、终止掩码与优化器状态（子页 ⑧）。
  • 时域很短。被去掉的是 \(k \ge 1\) 的项；在单步任务（多臂老虎机式）里这部分为零，两种权重完全一样。
  • 一步随机性本来就很大。\(\mathrm{Var}[\delta_t \mid s_t, a_t]\) 由一步奖励与一步转移的随机性决定，它不会被 Critic 消掉；奖励噪声很大的任务里，降方差的空间有限。
  • 折扣很小。\(\gamma^{2k}\) 衰减快，可去掉的部分本来就小。

八、V 型与 Q 型 Critic

8.1 Q 型 Actor-Critic 的原型

最直接的做法是让 Critic 直接学动作价值，用它当权重（第四节第 ④ 行）。David Silver 的 Lecture 7 给出的 QAC 算法是这类方法的教科书形态：Critic 用线性近似 \(Q_w(s,a) = \varphi(s,a)^\top w\)、按 TD(0) 更新，Actor 用 \(Q_w\) 作权重：

function QAC
  初始化 θ、w 与状态 s，并按 π_θ(·|s) 采样 a
  for 每一步 do
      执行动作 a，观察奖励 r、下一状态 s′ 与终止标志 d
      if d = 1 then
          δ = r − Q_w(s, a)
      else
          按 π_θ(·|s′) 采样下一动作 a′
          δ = r + γ Q_w(s′, a′) − Q_w(s, a)
      end if
      θ ← θ + α Q_w(s, a) ∇_θ log π_θ(a|s)
      w ← w + β δ φ(s, a)
      if d = 1 then break
      a ← a′,  s ← s′
  end for
end function

上面按课件保留的 QAC 原型没有写教材第 13.5 节中的 \(I=\gamma^t\)。若把它解释为本页声明的回合起点目标 \(J_\gamma=\mathbb E[G_0]\)，Actor 更新还应写成 \(\theta\leftarrow\theta+\alpha I Q_w(s,a)\nabla_\theta\log\pi_\theta(a\mid s)\)，并在每步令 \(I\leftarrow\gamma I\)；否则它采用的是常见的逐时刻等权更新口径。这个区别不改变 Critic 的 SARSA 形式，但会改变 Actor 对时间步的加权，不能悄悄省略。

两点值得注意。其一，Critic 这里用的是 SARSA 形式的 TD 目标：非终止时的下一动作由当前策略采样，目标里没有取最大值——它评估的是当前策略，而不是最优策略；终止时不能再采样 \(a'\)，bootstrap 项为零。其二，Actor 的权重是 \(Q_w\) 而不是优势，未去掉状态基线，往往会增加梯度方差；3.2 节展示的是一个可能相差很大的构造例，不能据此断言所有任务都“大得多”。

8.2 想要优势，就得多一步

Q 型 Critic 给出的是 \(Q\)，要拿到优势还需要 \(V\)，常见做法有两种：

  • 学两个网络。同时维护 \(V_v(s) \approx V^{\pi_\theta}(s)\) 与 \(Q_w(s,a) \approx Q^{\pi_\theta}(s,a)\)，用 \(A(s,a) = Q_w(s,a) - V_v(s)\) 当权重（Silver Lecture 7 的「Estimating the Advantage Function (1)」）。代价是两套参数、两个回归问题。
  • 用 Critic 在当前策略下的动作期望作中心化项。离散且动作数可枚举时，可直接计算 \(\hat V_w(s)=\sum_a\pi(a\mid s)Q_w(s,a)\)，再用 \(Q_w(s,a)-\hat V_w(s)\)。对真实 \(Q^\pi\)，该期望恒等于 \(V^\pi\)；对近似 \(Q_w\)，它只是 Critic 自身在策略下的期望，不应冒充真实 \(V^\pi\)，但中心化后的动作均值严格为零。连续动作的积分在特殊分布与函数形式下可能解析可算，通常需要蒙特卡洛或数值近似。

而 V 型 Critic 走的是另一条路：不去估 \(Q\)，直接用一步真实转移构造 \(\delta_t\)——第五节证明了它在期望意义上就是优势。Silver 的课件把这一点总结为「这种做法只需要一套 Critic 参数」。

8.3 相容函数逼近：什么时候用近似量也不引入偏差

第四节说过，用一般学习函数替换 \(Q^\pi\) 会引入偏差，但相容函数逼近给出一个严格例外。若

\[f_w(s,a)=w^\top\nabla_\theta\log\pi_\theta(a\mid s),\]

并且 \(w\) 在当前策略的状态—动作加权分布下，使 \(f_w\) 对真 \(Q^\pi\)（等价地，对真优势）的均方误差满足正规方程，那么

\[\mathbb E[h_t f_w(s_t,a_t)]=\mathbb E[h_t Q^\pi(s_t,a_t)].\]

因此它保留的是策略梯度所需的投影，而不要求逐点重建整个 \(Q^\pi\)。又因 \(\mathbb E_{a\sim\pi}[h_t\mid s]=0\)，\(f_w\) 在每个状态上的动作均值为零，更准确地说它表示 Q 的动作相关投影/优势分量，不是包含任意状态基线的完整 Q。这个结论依赖特定特征、加权分布与拟合驻点，并不自动适用于普通深度 Critic。完整条件见策略梯度 · 定理与两条证明路径；Konda 与 Tsitsiklis 的结果说明 Critic 所需子空间由 Actor 参数化决定，展开见子页 ②。

8.4 为什么 on-policy 的深度 Actor-Critic 多用 V 型 Critic

GAE 论文附录 A.2 给出作者选择 V 型估计器的两条动机：状态价值函数输入维度更低，通常更容易拟合；用 \(\lambda\) 可以在其一套估计器内从一步 bootstrap 平滑过渡到完整回报。论文把“直接使用一个参数化 Q”描述为该比较中的高偏差端，并报告其任务上一步估计（\(\lambda=0\)）偏差过大；这是一项方法动机与经验观察，不是 Q 型 Critic 在数学上只能做一步估计的普遍定理。论文紧接着也明确说，降低参数化 Q 偏差的其他算法空间仍可探索。

九、教材中的单步 Actor-Critic 逐行

9.1 算法框

Sutton 与 Barto 第二版第 13.5 节给出的「One-step Actor–Critic (episodic)」如下（教材把 Critic 参数记作 \(w\)、奖励记作 \(R_{t+1}\)，这里保留教材写法以便对照）：

输入：可微的策略参数化 π(a|s,θ)
输入：可微的状态价值参数化 v̂(s,w)
参数：步长 α^θ > 0，α^w > 0
初始化 θ ∈ R^d′ 与 w ∈ R^d（例如全零）

对每个回合循环：
初始化 S（回合的第一个状态）
I ← 1
当 S 不是终止状态时循环（对每一步）：
A ∼ π(·|S,θ)
执行动作 A，观察到 S′ 与 R
δ ← R + γ v̂(S′,w) − v̂(S,w) （若 S′ 为终止状态，则 v̂(S′,w) ≐ 0）
w ← w + α^w δ ∇v̂(S,w)
θ ← θ + α^θ I δ ∇ln π(A|S,θ)
I ← γ I
S ← S′

9.2 逐行说明

  • A ∼ π(·|S,θ)：在这套采样型 on-policy 算法里应按 \(\pi_\theta\) 采样，不能把训练动作擅自换成 argmax。有限离散动作若能精确枚举动作期望，或另有正确的 off-policy 校正，可以构造其他合法估计器；那已经不是此算法框中的单样本更新。
  • δ ← R + γ v̂(S′,w) − v̂(S,w)：第五节证明过，它的条件期望是优势；括号里的终止约定就是 2.2 节的 \(1 - d_t\)。
  • w ← w + α^w δ ∇v̂(S,w)：这是半梯度 TD(0)——目标里的 \(v̂(S′,w)\) 被当作常数，不对它求导。为什么必须如此、不这样做会得到什么，是子页 ② 的主题。
  • θ ← θ + α^θ I δ ∇ln π(A|S,θ)：Actor 沿得分函数乘权重的方向上升。数值上可复用同一个 \(\delta\)，但在自动微分实现里必须把 Actor 权重写成 delta.detach()；Critic 则通过独立的价值损失接收梯度。若共享骨干，两个 loss 都可以更新共享表示，但 Actor loss 不能沿优势/TD 目标这条支路反传。
  • I ← γ I：\(I\) 从 1 开始、每步乘 \(\gamma\)，因此第 \(t\) 步的 \(I = \gamma^t\)（见 9.4）。
  • 整体：全部在线、增量，处理完一步就丢弃这一步的数据，不需要缓存回合。

9.3 与带基线的 REINFORCE 逐行对照

同一本书第 13.4 节的「REINFORCE with Baseline (episodic)」与上面的算法框只差一处：

步骤 带基线的 REINFORCE（第 13.4 节） 单步 Actor-Critic（第 13.5 节）
何时更新 跑完整个回合后，再对回合中的每一步 \(t\) 更新 每一步立刻更新
权重 \(\delta \leftarrow G_t - \hat v(S_t, w)\)，\(G_t\) 为蒙特卡洛回报 \(\delta \leftarrow R + \gamma \hat v(S', w) - \hat v(S, w)\)
Critic 更新 \(w \leftarrow w + \alpha^w \delta \nabla \hat v(S_t, w)\) \(w \leftarrow w + \alpha^w \delta \nabla \hat v(S, w)\)
Actor 更新 \(\theta \leftarrow \theta + \alpha^\theta \gamma^t \delta \nabla \ln \pi\) \(\theta \leftarrow \theta + \alpha^\theta I \delta \nabla \ln \pi\)，\(I = \gamma^t\)
价值函数的角色 只作基线，作用于转移的第一个状态 Critic，还作用于第二个状态

两条算法的核心数学差别在权重那一行：前者使用完整蒙特卡洛回报，学习到的 \(V\) 只作基线；后者把下一状态价值放进 TD 目标，发生 bootstrap，因此是窄义 Actor-Critic。这个改变也带来“回合后更新”与“逐步在线更新”的流程差异。

9.4 Actor 更新里的 γ 的 t 次幂

教材算法框里的 \(I\) 实现的是折扣回合型问题中理论上应有的 \(\gamma^t\) 因子——S&B 的文献注记指出，是 Thomas（2014）首先意识到这一点。许多深度实现（包括常见的 A2C、A3C、PPO 实现）省略它，等价于在采样批内把各时间步同等对待。省略之后更新量与「折扣目标的梯度」之间是什么关系，策略梯度 · 定理与两条证明路径里有专门一节讨论，本专题不重复。

十一、小结与出口

  • 优势是规范化的动作相对信号：它在当前策略下平均为零、不改变贪心改进方向、用它作权重期望正确且通常显著降方差；但严格的方差最优基线还取决于得分函数的平方范数。用 \(Q\) 与用 \(A\) 的期望梯度相同，本页构造例中总方差相差约 188 倍，这个数值不是普遍常数。
  • 权重谱系上有两条分界线：一条区分“学习值函数只作动作无关基线”与“它参与动作评价/bootstrap”，也区分了带学习基线的 REINFORCE 与窄义 Actor-Critic；另一条标出方差如何被逐步移除。
  • \(\delta_t\) 能当优势估计，依据是 \(\mathbb{E}[\delta_t \mid s_t, a_t] = A^\pi(s_t, a_t)\)；前提是 \(V\) 为当前策略真值、continuation 掩码与目标一致、折扣定义一致，且 Actor 对该权重停止梯度。
  • Critic 不准时，一步估计的局部偏差是 \(\gamma\) 乘“下一状态误差期望”对策略参数的梯度：固定 Critic 时，增加 Actor 样本不能消除它；联合训练中则还取决于 Critic 是否随数据改善。
  • 方差下降的量可以精确写出：\(\sum_{k \ge 1} \gamma^{2k} \mathbb{E}[\delta_{t+k}^2]\)。时域越长去掉得越多，Critic 不准或时域很短时则未必。

判断一个方法是什么，要看反馈怎样进入计算图，而不是只看论文标题

同一段人类接管日志可以被解释成新示范、二元可取性标签或干预奖励；三种解释会形成不同的数据字段、损失函数和训练闭环。先把“反馈从哪里来”“反馈表达什么”“反馈如何进入优化”三件事分开，后面的网络与 Loss 才不会混在一起。

一、五层对象不能混为一谈

把评价者对轨迹 $\tau$ 的潜在效用记为 $U_h(\tau)$。这只是建模记号：它通常不可直接观测，也不保证随时间不变或在不同评价者之间一致。算法能看到的是评价者给出的反馈：

\[f_h\sim p(f\mid U_h,\tau_i,\tau_j,z_h)\]

$z_h$ 汇总评价者经验、偏好、疲劳和反应延迟等因素。系统随后可能学习代理奖励 $R_\phi$，再让策略最大化由它构造的累计回报。于是至少要区分五层对象：

层 符号 含义 典型误解
人类效用 $U_h$ 真正希望机器人满足的目标 认为它能被直接读取
观测反馈 $f_h$ 比较、好坏、评分、接管 认为每条反馈都无噪声
代理奖励 $R_\phi$ 从反馈拟合的可计算模型 把高分当作真实成功
样本回报 $G_t$ 一次轨迹上折扣后的奖励和 把它与单步 RM 输出等同
价值函数 $V^\pi,Q^\pi$ 给定条件下未来回报的期望 认为它就是 Reward Model

若训练时形成的逐步奖励为 $\tilde r_t$，则有限时域样本回报与状态价值分别是

\[G_t=\sum_{k=t}^{T}\gamma^{k-t}\tilde r_k, \qquad V^\pi(c_t)=\mathbb E_{\tau\sim\pi}[G_t\mid c_t].\]

其中 $c_t$ 是策略在时刻 $t$ 可用的条件信息。$G_t$ 是一次采样得到的随机量，$V^\pi$ 是条件期望；$R_\phi$ 则可以输出轨迹分数、片段分数或逐步奖励，必须先定义怎样把它变成 $\tilde r_t$。

关键结论：$R_\phi$ 是对人类目标的有限数据近似，不是目标本身；Critic 的 $V/Q$ 又是对策略未来代理回报的预测。因此，即使这些网络都输出标量，训练标签、条件变量和数学语义也不同。

二、RLHF 与行为克隆

行为克隆学习给定条件下的目标动作：

\[\mathcal L_{BC}=-\mathbb E_{(c,a^*)\sim\mathcal D_E}\log\pi_\theta(a^*\mid c)\]

这里的 $c$ 可包含视觉观测、语言指令、本体状态和历史；$a^*$ 也可以是一段 action chunk。对离散动作，$\log\pi_\theta$ 是对数概率；对连续动作，它是所选概率模型下的对数密度。该目标优化“像不像数据中的目标动作”，并不直接等价于任务成功、安全或效率。RLHF 常先用 BC/SFT 初始化，再引入输出质量反馈。

维度 行为克隆 RLHF / 偏好后训练
监督对象 数据中的目标动作 动作、片段或轨迹的质量
失败数据 标准最大似然 BC 通常不给失败动作正似然；能否使用取决于数据构造 可显式利用比较、拒绝项或低奖励行为
训练目标 示范似然 奖励或相对偏好
数据采集 可完全离线，也可交互采集 可完全离线，也可在线迭代采集
主要风险 分布偏移、复制示范缺陷 代理奖励失配、反馈偏差

三、RLHF 与 DAgger / HG-DAgger

DAgger 类方法在策略访问的状态上查询专家动作，再把正确动作加入监督数据。HG-DAgger 进一步由人决定何时接管并产生恢复轨迹。这些方法的基本标签仍是“这里应该执行什么动作”。

HAPO 论文中的 Action Preference Optimization（APO）对接管数据作了另一种解释：人工纠正动作被标为 desirable，失败相关的策略动作被标为 undesirable，再用二元可取性目标更新自回归 VLA。它不要求把不可逆环境中的两个动作伪装成“同一物理状态下的严格配对比较”，而是使用二元标签、平衡采样和自适应重加权。因此：

  • 只把纠正动作加入 BC，仍是交互式模仿学习。
  • 同时把纠正动作与失败相关动作标成相反的二元可取性信号，才进入 APO 式直接偏好优化。
  • 从“是否发生接管”构造奖励或代价并执行 RL，则更接近 RLIF 式干预强化学习。

接管与控制权状态机见HG-DAgger 专题；本专题只解释反馈标签怎样改变优化目标。

四、经典 RLHF：显式学习奖励，再执行 RL

设 $c_t$ 表示状态、观测与历史等策略条件，经典路线可用下面的正则化目标概括：

\[\mathcal D_{pref}\longrightarrow R_\phi, \qquad J(\theta)=\mathbb E_{\tau\sim\pi_\theta}[R_\phi(\tau)] -\beta\,\mathbb E_{c_t\sim d^{\pi_\theta}} D_{KL}\!\left( \pi_\theta(\cdot\mid c_t)\,\Vert\,\pi_{ref}(\cdot\mid c_t) \right).\]

$d^{\pi_\theta}$ 是当前策略诱导的条件分布，$\beta>0$ 控制对参考策略的偏离。实现中常以采样动作的 $\log\pi_\theta(a_t\mid c_t)-\log\pi_{ref}(a_t\mid c_t)$ 估计 KL 项；单个样本的 log-ratio 可以为负，只有对 $a_t\sim\pi_\theta$ 取期望后才是非负 KL。若 $R_\phi$ 输出轨迹级分数，还需明确它如何广播或分配到时间步。

它通常包括三个阶段：

  1. BC/SFT 初始化策略。
  2. 人类比较输出，训练 Reward Model。
  3. 用 PPO、SAC 等适合相应动作空间的 RL 算法优化策略，并用 Reference 约束偏移。

2017 年的人类偏好强化学习展示了如何从轨迹片段比较学习奖励；InstructGPT 则把 SFT、Reward Model、PPO 系统化为语言模型三阶段管线。机器人 RLHF 借用相同思想，但要面对真实环境不可逆和连续动作问题。

五、DPO、KTO、APO：广义偏好对齐，但不一定有显式 RL

DPO 从同一条件输入 $x$ 下的成对偏好 $(y_w,y_l)$ 更新策略：

\[\mathcal L_{DPO}=-\mathbb E_{(x,y_w,y_l)\sim\mathcal D_{pref}}\log\sigma\left( \beta\left[ \log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)} -\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)} \right]\right)\]

这里 $y_w\succ y_l$，$\beta$ 控制策略相对参考策略变化的尺度。DPO 不训练独立 Reward Model，也不使用 PPO Critic；但它把特定 KL 正则化奖励最大化问题的最优策略重参数化为 reward，并结合 Bradley–Terry 型偏好似然得到上述目标。因此，“省去显式 RM 和 RL 内环”不等于在任意奖励模型、任意散度或任意数据分布下都与 PPO-RLHF 等价。

KTO 使用单条 desirable/undesirable 标签，不要求每个样本都有显式配对。这降低了不可逆机器人交互中构造“同一状态、两个动作”严格比较的要求，但只是数据接口上的适配性；是否优于其他控制目标仍需按任务验证。HAPO/APO 在这一类二元可取性目标上，进一步针对自回归动作 token 引入平衡采样，并依据解码后的连续动作 L1 误差自适应重加权，以处理 token 概率差与物理动作误差不一致的问题。

术语边界：DPO/KTO/APO 经常被放在广义 RLHF 或 preference alignment 体系中讨论，但其训练循环没有显式策略 rollout、Reward Model 和 Actor-Critic 更新时，不应写成经典 PPO-RLHF。

六、RLVR、RLAIF 与自动偏好

  • RLVR：训练信号由程序、判题器或可验证规则产生；规则可以由人设计，但不依赖人逐条比较样本。
  • RLAIF：偏好、评分或批评信号主要来自 AI 评价器；后续仍可接 RM+RL 或直接偏好目标。
  • VLP：从视觉语言关系构造偏好数据，再服务下游奖励学习或直接优化。
  • GRAPE：用 VLM、关键点与阶段约束构造轨迹代价，主要不是由人逐条成对比较。

这些路线可以服务相似的 VLA 后训练目标，但“反馈来源”不决定唯一算法：AI 可以产生成对偏好，程序可以产生标量奖励，人也可以提供动作示范。页面必须同时写清来源、监督语义和优化目标，不能笼统都称 RLHF。

七、机器人领域的六个额外困难

状态不可逆

物体已被移动、液体已倾倒或碰撞已发生，无法在完全相同状态试另一动作。

连续动作

token 概率变化不一定与关节或末端误差单调对应。

反馈延迟

人发现风险到接管生效之间跨过多个动作或一个 chunk。

长期信用分配

终局失败可能源自很早的定位或抓取动作。

探索成本

失败会损坏物体、机器人或环境，不能无限试错。

多模态错位

相机、本体、命令和真实执行动作的时间戳不一致会污染标签。

九、知识点、重点与创新点

9.1 知识点

  • 人类效用、反馈、代理奖励和价值函数的层次。
  • 模仿、奖励学习、直接偏好和干预式 RL 的训练路径。
  • 反馈来源、监督语义与优化器是三个应分别记录的维度。

9.2 重点

  • 不能依据标题中是否出现 RLHF 分类。
  • 人类接管可生成动作监督、二元可取性或干预奖励三种监督语义。
  • 经典 RLHF 与广义偏好对齐要并列而非互相替代。
  • DPO 的闭式关系有建模前提，KTO 的非配对数据优势也不是性能保证。

9.3 方法演进与创新边界

  1. 人类偏好 RL：以轨迹片段比较学习代理奖励，再用 RL 优化策略，减少手写复杂 reward 的需求。
  2. InstructGPT：把 SFT、输出排序 Reward Model 与 PPO 组织成可扩展的三阶段语言模型对齐管线。
  3. DPO：在特定 KL 正则化和偏好模型假设下，把显式奖励学习与在线 RL 内环化为策略/参考策略 log-ratio 的分类目标。
  4. KTO：用前景理论启发的效用目标消费单条二元 desirability 标签，不要求严格成对数据。
  5. HAPO/APO：把人工接管形成的二元动作可取性信号用于自回归 VLA，并用连续动作误差自适应重加权；这是面向特定模型与数据流程的设计，不是对所有机器人策略的通用最优性证明。

确定性 Actor 在相同状态总给出相同动作。它省掉了策略梯度中的动作分布积分， 也同时失去了随机策略自带的探索。DDPG 的解决思路是把“要学的目标策略”和 “用来产生数据的行为策略”分开，再用 ReplayBuffer 把多个历史行为策略的数据混合利用。

本页重点。第二节的 warm-up / learning-start 分工、第三节 OU 与 Gaussian 的准确边界、 第五节 replay 的三项收益与三项代价、第六节覆盖外外推。确定性策略梯度的 off-policy 目标见子页 ①； 更新时钟见子页 ③。

一、目标策略与行为策略

1.1 目标策略

要优化和部署的是确定性策略

\[a=\mu_\theta(s).\]

确定性评估时直接执行这个动作，不加训练探索噪声。

1.2 行为策略

在第 \(t\) 个环境步，参数为 \(\theta_t\) 的 Actor 常通过下面的行为过程采样：

\[a_t^{\mathrm{exec}} = \operatorname{clip} \left( \mu_{\theta_t}(s_t)+\epsilon_t,\, \ell,u \right). \tag{1}\]

随机变量 \(\epsilon_t\) 与裁剪共同诱导出一个随机条件分布 \(\beta_t(a\mid s)\)。它是行为策略，用于在线收集数据；被优化和部署的 \(\mu_\theta\) 仍是确定性函数。这与 SAC 直接参数化随机目标策略不同。 时间下标还提醒我们：ReplayBuffer 通常混合多个历史参数 \(\theta_0,\theta_1,\ldots\) 产生的数据，而不是只包含当前策略的数据。

这里的 \(\beta_t(a\mid s)\) 对独立 Gaussian 噪声是直接的条件分布记号；若噪声本身有内部状态， 例如 OU 状态 \(x_t\) 或一个 rollout 内固定的参数扰动，则动作还依赖这项历史信息。 严格地说，此时行为过程在增广状态 \((s_t,x_t)\) 上才是 Markov，单写 \(\beta_t(a\mid s)\) 只是把噪声状态边缘化后的简写，不应据此宣称行为策略是只依赖环境状态的 固定平稳 Markov 策略。Replay 学习可以使用这种非平稳历史数据，但它与理论分析中的固定 \(\rho^\beta\) 又隔着一层经验近似。

1.3 Replay 动作必须与 Critic 的动作接口一致

先明确 Critic 中 \(Q(s,a)\) 的 \(a\) 指哪个控制接口。最常见实现把探索噪声与边界裁剪放在 env.step 前，此时应存传给环境的裁剪后命令：

\[\left( s_t,\, a_t^{\mathrm{critic}},\, r_t,\, s_{t+1},\, \mathrm{terminated}_t \right), \qquad a_t^{\mathrm{critic}}=a_t^{\mathrm{exec}}.\]

若存的是裁剪前 \(\mu_{\theta_t}(s_t)+\epsilon_t\)，而环境收到的是裁剪后动作，Critic 的动作标签 与转移不一致；在大量动作触边时会很严重。但“实际动作”也不能无限向执行器内部追溯：若安全过滤器、 低层控制器或执行器动力学属于环境转移的一部分，Critic 可以定义在上层命令接口。此时 Replay、 Critic 训练和 Actor 更新都必须使用同一接口，并在 Actor loss 路径中包含同一动作变换；不能训练时存 内部关节力矩、更新 Actor 时却把未过滤命令直接送进 Critic。

  S["state"] --> M["deterministic actor mu(s)"]
  N["exploration noise"] --> X["add + clip"]
  M --> X
  X -->|"command at Critic interface"| E["environment / declared adapter"]

二、训练早期：随机 warm-up 与学习启动

2.1 为什么只给随机 Actor 加小噪声不够

初始化 Actor 的输出通常集中在某个狭小区域。若一开始就执行 \(\mu_\theta(s)+\epsilon\)，而噪声又较小，ReplayBuffer 可能只覆盖动作空间的一小块； Critic 尚未学到有意义的地形，Actor 已开始沿随机斜率移动。

常见做法是在前 start_steps 个环境步从允许的动作分布中随机采样， 先建立基础覆盖。在标准基准中常用动作空间均匀采样；在真实机器人或安全约束环境中， “整个动作空间合法”不等于“任意随机动作安全”，必须先限定安全采样集合或经过独立安全层。

2.2 三个容易混淆的时刻

参数语义 之前做什么 之后做什么 是否一定相等
random warm-up 结束 环境随机动作 Actor + 噪声 否
learning starts 只收集数据 开始 mini-batch 更新 否
evaluation starts 不评估或仅基线 周期性确定性评估 否

可先收集一段随机数据再训练，也可在仍使用随机行为时就开始 Critic 更新。 实现必须分别记录，不应用一个模糊的 warmup 同时承担所有语义。

2.3 warm-up 不是越长越好

  • 太短：动作覆盖不足，初始 Critic 和 Actor 强耦合。
  • 太长：大量低质量随机 transition 占据有限 buffer，策略数据进入得更晚。
  • 合理长度依赖环境维度、奖励稀疏度、buffer 容量和总训练预算。

不能只报告“warm-up 10,000 步”而不报告总步数：对 100,000 步任务是 10%， 对 10,000,000 步任务只有 0.1%。

三、动作噪声：Gaussian 与 Ornstein–Uhlenbeck

3.1 独立 Gaussian

每个时间步独立采样

\[\epsilon_t\sim\mathcal N(0,\Sigma).\]

若动作已规范化到 \([-1,1]\)，可在规范化空间定义标准差；若 Actor 直接输出物理动作， 则常按每维 action_scale（上下界的半范围）缩放噪声：

\[\epsilon_{t,j} = \sigma_{\mathrm{rel}}\, \mathrm{scale}_j\,\xi_{t,j}, \qquad \xi_{t,j}\sim\mathcal N(0,1).\]

其中

\[\mathrm{scale}_j=\frac{u_j-\ell_j}{2}.\]

所以 \(\sigma_{\mathrm{rel}}\) 是相对于半范围而不是全范围的标准差比例。 例如 \(\sigma_{\mathrm{rel}}=0.1\) 表示标准差为该维全范围的 5%。若各维量纲不同， 应逐维缩放，不能用同一个物理单位的绝对标准差直接相加。

3.2 Ornstein–Uhlenbeck 过程

连续时间 OU 随机微分方程经 Euler–Maruyama 离散后常写为

\[x_{t+1} = x_t + \vartheta(\mu-x_t)\Delta t + \sigma\sqrt{\Delta t}\,\xi_t. \tag{2}\]

它具有均值回归与时间相关性，连续若干步的噪声方向更平滑。式 (2) 中的 \(\vartheta\)、\(\sigma\) 与 \(\Delta t\) 共同决定离散序列；如果代码采用 \(x_{t+1}=x_t+\vartheta(\mu-x_t)+\sigma\xi_t\)，就等价于固定了特定离散约定， 不能再把同名参数脱离该约定比较。

DDPG 原论文在具有物理惯性的控制任务中使用 OU 过程，并报告 \(\vartheta=0.15\)、\(\sigma=0.2\)。这些数字属于其实现配置，不是定理要求； 复现实验还要报告离散公式、时间步、初值、动作尺度以及是否在 episode 边界重置。 在并行向量环境中，每个子环境需要独立 OU 状态；只重置已经结束的对应状态。让所有子环境共享 同一个 OU 状态会人为制造跨环境相关，让一个子环境的 reset 改变其他子环境的行为噪声。

3.3 选择边界

维度 Gaussian OU
时间相关 无 有
参数 标准差 / 协方差 均值、回归率、扩散、时间步
重置 每步独立，无内部状态 通常在 episode 边界重置；否则噪声状态会跨回合延续
解释与复现 简单 需固定离散化与初值
理论地位 合法行为噪声 合法行为噪声

CleanRL 文档明确指出其现代 DDPG 实现使用 Gaussian，而原论文使用 OU。 因此不能写“没有 OU 就不是 DDPG”，也不能在没有对照实验时写“OU 一定更适合物理控制”。

3.4 噪声衰减

噪声可固定，也可随训练衰减。衰减太快会让行为策略在 Critic 尚不可靠时失去覆盖； 不衰减则训练后期数据持续带大扰动。评估应始终独立关闭探索噪声， 否则无法区分策略质量与采样随机性。

四、动作裁剪改变了噪声分布

式 (1) 的 clip 不是无害后处理。靠近边界时，所有同方向越界样本都被映射到同一个端点， 使执行动作分布在边界产生点质量：

  • 执行动作分布不再是高斯或 OU。
  • 相对 Actor 输出的实际扰动不再零均值，并被边界向可行域内侧偏置。
  • 若饱和率高，增大标准差只会产生更多相同边界动作。

必须记录每一动作维的：

  1. Actor 原始输出；
  2. 加噪后、clip 前动作；
  3. 实际执行动作；
  4. clip / saturation 比例。
若动作有安全约束，clip 只能保证数值落在边界内，不能证明轨迹安全。 力矩速率、碰撞、工作空间和状态约束需要独立安全层或约束控制器。

五、ReplayBuffer 的三项收益

5.1 打散时间相关

相邻状态高度相关。若按轨迹顺序连续更新，mini-batch 有效样本量可能很小， 梯度会随当前局部轨迹剧烈摆动。均匀随机采样把不同回合、不同时间的数据混合， 通常能降低短时相关性，但不会让样本严格独立同分布：它们仍来自同一受控系统， 而且 buffer 分布会随行为策略变化。

5.2 复用昂贵交互

一条 transition 可被多次采样。相对于通常需要持续收集新轨迹的 on-policy 更新， 这是 off-policy 方法在交互昂贵场景中的主要吸引力之一。它提高的是 transition 复用能力，不保证墙钟时间或真实系统样本效率一定更高；收益还取决于 UTD、模型容量、 覆盖质量与优化稳定性。

5.3 把 learner 与当前行为部分解耦

ReplayBuffer 混合多个历史行为策略。Critic 不只追逐最新一小段轨迹， Actor 也能在更广的历史状态集合上更新。

六、ReplayBuffer 的三项代价

6.1 数据陈旧

容量很大时，样本可能来自很久以前的策略。历史状态对当前策略未必重要， 当前 Actor 动作在这些状态附近也未必有足够行为动作支持。

6.2 覆盖外外推

Critic 只在 buffer 支持的 \((s,a)\) 区域受到数据约束。Actor 却会沿 \(\nabla_aQ\) 移动，可能把动作推入数据稀疏区；那里的高 Q 可能只是函数逼近误差。

6.3 过度复用

若每加入一条新 transition 就做很多梯度步，Critic 会反复拟合同一有限数据集， Actor 又不断寻找其误差峰。高更新/数据比可能提高计算利用，也可能放大过拟合与自举误差。

设置 直接收益 主要风险 建议记录
小 buffer 数据新鲜 多样性低、遗忘快 样本年龄、状态覆盖
大 buffer 多样性高 旧策略数据占比高 年龄分布、最近样本比例
低 UTD 不易过拟合 学习慢、样本利用低 每千环境步更新数
高 UTD 充分利用数据 Critic 误差与 Actor exploitation 留出 replay 子集的 TD 误差、Q/回报校准

七、环形 ReplayBuffer 的字段与语义

一个最小 buffer 保存：

  • obs：当前观测；
  • action：与 Critic 定义一致的动作接口；常见情形是加噪、裁剪后传给环境的命令；
  • reward：该 transition 奖励；
  • next_obs：真实下一观测；
  • terminated：是否停止 bootstrap；
  • 可额外保存 truncated：用于 episode 分析与 wrapper 审计。

环形数组写满后覆盖最旧样本，使容量同时控制记忆长度。均匀采样是原始 DDPG 和多数教学实现的基础选择。优先经验回放属于额外扩展：它改变 Critic 看到的 transition 权重，也可能改变 Actor 更新所用的状态权重。重要性权重可以校正 Critic 采样偏差， 但是否完全校正取决于权重指数与实现；Actor 是否加权则必须单独说明。

next_obs 必须是该 transition 的真实后继观测。向量环境是否在同一步自动重置以及 终止观测所在字段，取决于库版本和 autoreset 模式；可能需要读取 final_obs、 final_observation 或框架等价字段。实现应针对实际版本做一次终止/截断契约测试： 若同一步返回的观测已是新回合初始状态，却取不到对应 final observation，应报错停止，而不是静默 把重置观测写入 transition。否则 Bellman target 会跨回合串接。

7.1 不能从 buffer 重建的隐含状态

若策略或环境依赖：

  • RNN 隐状态；
  • 观测归一化所依赖的统计版本；
  • frame stack；
  • domain randomization 参数；
  • 隐式时间相位；

只存单步观测可能不足以重建训练语义。必须把 Markov 所需信息纳入 observation， 或保存可重建序列。若 buffer 存原始观测却用不断变化的统计量重新归一化，同一 transition 在不同训练时刻还可能得到不同输入；应固定统计、保存必要版本，或明确这种非平稳性。 否则问题不在 DDPG loss，而在 transition 定义不完整。

Replay 也不是跨任务永久兼容的数据格式。若观测语义、reward、动作适配器、控制频率、wrapper、 domain-randomization 隐变量或终止条件发生改变，旧 transition 通常不再属于同一 MDP。 除非有明确的版本字段与等价性证明，否则应让 checkpoint 与 replay schema 绑定，并拒绝混用。

八、Replay off-policy 不等于 offline RL

在线 DDPG 每次更新后仍继续与环境交互。若 Actor 移到一个 Critic 高估区域， 后续行为数据有机会揭示真实回报并纠正 Q，但前提是探索确实到达该区域且系统没有先失稳； 这不是自动保证。纯 offline RL 的数据固定，策略走到数据外后没有新的环境反馈。

因此：

  • ReplayBuffer 中有旧数据，不代表任务已经是 offline RL。
  • 把 DDPG 直接用于静态数据集，不会自动获得保守性。
  • TD3+BC、CQL 等离线方法分别代表行为约束或保守价值估计等思路，目的都是缓解数据外动作问题； 它们是例子，不表示所有静态数据集都必须采用同一种修正。

九、参数空间噪声：另一种探索方向

动作噪声每个时间步扰动输出；参数噪声先采样 \(\Delta\theta\)，并在一段 rollout 内固定该扰动，从而形成状态相关且时间一致的行为变化。直观上，它可能产生更连贯的策略级探索：

\[a_t=\mu_{\theta+\Delta\theta}(s_t).\]

这里的扰动 Actor 只定义行为策略；Bellman target 通常仍使用未扰动的目标 Actor。 参数噪声不是 DDPG 原始必要组件，需要额外规定扰动尺度、重采样频率和自适应规则。 它可能改善某些任务的探索，但不存在普遍优势保证，因此这里只把它列为研究扩展， 不与 OU / Gaussian 的基础实现混为一谈。

十、探索与回放的阶段图

flowchart LR
  I["初始化"] --> C["持续收集 transition<br/>写入 Replay"]
  I --> W["行为分支：随机动作"]
  W -->|"达到 start_steps"| B["行为分支：Actor + 噪声"]
  W --> C
  B --> C
  C -->|"达到 update_after / learning_starts"| L["learner 分支启用"]
  L --> R["从 Replay 混合新旧数据"]
  R --> U["Critic / Actor 更新"]
  U --> L
  U --> E["独立确定性评估<br/>不写 replay"]

图中行为分支与 learner 分支由不同阈值控制；learning 可以在随机行为尚未结束时启动， 也可以等到 Actor + 噪声已经采样后才启动，不能从图形顺序推断二者必然相等。

评估环境必须与训练环境的观测、动作与奖励 wrapper 一致，但关闭探索噪声且不更新网络。 训练 return 来自变化中的随机行为策略，评估 return 来自冻结参数的确定性策略； 前者可能因扰动破坏好动作而更低，也可能因噪声偶然纠正差动作而更高。 它们对应不同策略与数据分布，必须分别记录，不能把差值简单解释成固定方向的偏差。

十一、知识重点、机制创新与结论边界

11.1 知识点与重点

  1. 两种策略。 \(\mu_\theta\) 是被优化的确定性目标策略；噪声、随机 warm-up 与裁剪共同定义收集数据的行为策略 \(\beta_t\)。
  2. 两个启动阈值。 start_steps 控制何时从随机动作切到 Actor， learning_starts 控制 learner 何时开始更新，二者没有数学上的相等要求。
  3. 两类分布变化。 clip 会改变动作噪声分布；ReplayBuffer 会混合不同时刻的 状态—动作分布。两者都会影响 Critic 实际看到的数据支持域。
  4. 三项收益与三项代价。 Replay 降低短时相关、复用 transition、解耦采样与更新； 同时带来数据陈旧、覆盖外外推和过度复用风险。

11.2 机制来源与 DDPG 的探索—回放组合

随机行为策略学习确定性目标策略的分工首先来自 off-policy DPG；经验回放也早于 DDPG， 并在 DQN 中成为深度价值学习的关键稳定化机制。DDPG 的贡献不是重新发明这两点，而是把 确定性深度 Actor、动作梯度 Critic、带噪数据采集、replay 与双目标网络接成连续控制训练闭环。

因此，OU 只是原论文选用的一种行为噪声；更值得强调的 DDPG 组合是：部署目标保持确定性， 收集过程允许随机且随训练变化，ReplayBuffer 再复用多代行为过程的数据来训练深度 Actor-Critic。

11.3 必须保留的边界

  • OU 是原论文的实验选择，不是 DDPG 身份条件；Gaussian 也不是普遍最优。
  • 随机回放只降低相关性，不产生严格 i.i.d. 数据，也不消除分布失配。
  • 更大的 buffer、更高的 UTD 或更大的噪声都不是单调收益旋钮。
  • 在线反馈只提供纠错机会，不保证覆盖外高估一定会被及时修正。
  • 动作 clip 和探索噪声都不构成安全性证明。

前两个子页始终把 \(\nabla_\theta \log \pi_\theta(a \mid s)\) 当作一个抽象的向量。本页把它算出来。

需要先破除一个常见预期：策略梯度没有固定的网络结构。它是一种优化策略的方法，不是某一种神经网络。网络只负责一件事——把状态映射成一个概率分布的参数。真正决定 \(\nabla_\theta \log \pi_\theta\) 长什么样的，是选了哪个分布族，而不是选了多少层 MLP。

2最常用的分布族
e_a − πsoftmax 的得分函数
z² − 1高斯对 log σ 的得分函数
1对角高斯熵对 log σ 的偏导
本页重点。必须精读的是三节：「离散动作」给出 softmax 的得分函数恰好是 one-hot 向量减去概率向量，它逐字就是交叉熵损失的梯度，这是策略梯度与监督学习同构的最短证明；「连续动作」给出对角高斯的两个得分函数分量，其中对数标准差方向的得分是 z 平方减一、零点在 z 等于正负一，它直接解释了标准差为什么会收缩；「策略熵为什么倾向于收缩」把上一条做成完整的机制说明，并给出熵正则项在其中的确切作用。

可以略过的是：「视觉与序列输入的编码器」一节（它只是指路）、「非法动作屏蔽」一节（只在离散动作且存在非法动作的任务里需要）。本页只讲分布族的数学，具体的工程配置见 PPO 页的网络结构一节，不在本页重复。

本页要解决什么问题

  • 策略网络输出的到底是什么。 它与 Q 网络输出的东西在类型上就不同，这个区别决定了后面所有差异。
  • \(\nabla_\theta \log \pi_\theta\) 的解析形式。 离散与连续两种情形各有一个漂亮的闭式结果，它们解释了很多训练现象。
  • 为什么参数化 \(\log \sigma\) 而不是 \(\sigma\)。 通常的回答是「保证为正」，这只是理由之一，而且不是主要的那个。
  • 动作有边界时怎么办。 三种做法，偏差各不相同，其中一种做法有一个很容易踩的陷阱。
  • 探索从哪来。 以及为什么策略梯度不需要 \(\varepsilon\)-greedy，却需要处理相反的问题。
  • 策略熵为什么会自己收缩。 这是连续控制里最常见的失效模式的根源。

策略网络与 Q 网络的本质区别

输出的类型不同

维度 Q 网络（价值方法） 策略网络（策略梯度）
输出是什么 每个动作的价值估计，一组实数 一个概率分布的参数
输出的量纲 与回报同量纲，范围由奖励尺度决定 概率或分布参数，范围由分布族决定
怎么得到动作 对输出取 argmax，再外加探索机制 从输出的分布里采样
输出层激活 线性，不能加有界激活 离散用 softmax，连续用线性均值加一个尺度量
动作数很多时 输出层维度等于动作数，无法处理连续动作 输出维度只随动作维度线性增长
训练信号 回归到自举目标，是监督式的 加权的对数似然上升，权重可正可负

最后两行是分野的关键。

输出维度。 七自由度机械臂若离散化成每维 10 档，Q 网络输出层要有 \(10^{7}\) 个单元；策略网络输出 7 个均值加 7 个对数标准差，一共 14 个数。这是策略梯度能做连续控制、而价值方法不能的直接原因。

训练信号的性质。 Q 网络的损失是回归损失，目标值是确定的，误差越小越好。策略网络的损失是加权对数似然，权重可以为负——为负时它在把概率质量从这个动作上推走。监督学习里没有这种操作。

一个结构性推论

因为策略网络输出的是分布参数，同一个主干网络配不同的分布头，就能处理完全不同的动作空间。主干可以是 MLP、CNN、Transformer，与策略梯度本身无关；换动作空间时只需要换分布头与对应的对数概率计算。

flowchart TB
  OBS["观测 s：向量、图像或序列"]
  OBS --> ENC["编码器主干：MLP 或 CNN 或 Transformer<br/>与策略梯度无关，按观测模态选"]
  ENC --> H["特征向量"]
  H --> D1["离散分布头：线性层输出 logits"]
  H --> D2["连续分布头：线性层输出均值，另加一个对数标准差"]
  D1 --> DIST["分布对象<br/>Categorical 或 对角高斯"]
  D2 --> DIST
  DIST --> O1["采样：得到动作，送给环境。这条边不需要梯度"]
  DIST --> O2["对数概率：log pi(a|s)，梯度经这条边回传"]
  DIST --> O3["熵：进入熵正则项，梯度经这条边回传"]
  O1 -.->|"把采到的动作再喂回来算对数概率"| O2

图中只有两条边承载梯度：对数概率与熵。采样那条边不需要梯度——得分函数估计量的全部作用就是绕开「对采样求导」这件事。这一点与重参数化方法正好相反，对照见子页 ①。

离散动作：Categorical、logits 与得分函数的解析形式

参数化

网络输出 \(K\) 个实数 \(z = (z_1, \dots, z_K)\)，称为 logits；经 softmax 变成概率：

\[\pi_\theta(a_i \mid s) \;=\; \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}\]

然后从这个分布采样：\(a \sim \mathrm{Categorical}(\pi_\theta(\cdot \mid s))\)。

注意不是 argmax。 取 argmax 会让策略变成确定性的，得分函数没有定义，整套推导失效（见子页 ① 的正则性条件二）。

为什么输出 logits 而不是直接输出概率

三条理由：

  • 无约束优化。 logits 可以取任意实数，网络输出层是普通线性层；直接输出概率则要满足非负且和为 1，是带约束的输出。
  • 数值稳定。 概率可以非常接近 0，直接表示会下溢，而 \(\log \pi\) 是策略梯度里必用的量。在 logits 空间计算 \(\log \pi\) 可以避开这个问题，见下文。
  • 梯度形式简洁。 这是下一小节的内容。

得分函数的解析形式

先写出对数概率。用 logsumexp 记号 \(\mathrm{LSE}(z) = \log \sum_j e^{z_j}\)：

\[\log \pi_\theta(a_i \mid s) \;=\; z_i - \mathrm{LSE}(z)\]

对第 \(k\) 个 logit 求偏导：

\[\frac{\partial}{\partial z_k} \log \pi_\theta(a_i \mid s) \;=\; \delta_{ik} - \frac{\partial}{\partial z_k} \mathrm{LSE}(z) \;=\; \delta_{ik} - \frac{e^{z_k}}{\sum_j e^{z_j}} \;=\; \delta_{ik} - \pi_k\]

写成向量形式，设 \(e_a\) 是被采样动作对应的 one-hot 向量：

\[\boxed{\; \nabla_z \log \pi_\theta(a \mid s) \;=\; e_a - \pi_\theta(\cdot \mid s) \;}\]

再经链式法则传给网络参数 \(\theta\)。

这个结果值得单独讲三点

其一：分量之和恒为零。

\[\sum_{k} \left( \delta_{ak} - \pi_k \right) \;=\; 1 - 1 \;=\; 0\]

它的含义正是概率质量守恒：提高被采样动作的 logit，必然相对压低其余动作的 logit。这与子页 ① 里得分函数期望为零的性质是同一件事在 logits 空间的体现。

其二：它逐字就是交叉熵损失的梯度。

监督分类里，以 \(a\) 为标签的交叉熵损失是 \(L = -\log \pi(a \mid s)\)，其对 logits 的梯度恰好是 \(\pi - e_a\)。于是策略梯度的替代损失

\[L_{\text{PG}} \;=\; -\,\Psi_t\, \log \pi_\theta(a_t \mid s_t)\]

就是一个以实际执行过的动作为标签、以 \(\Psi_t\) 为样本权重的交叉熵损失。这是「策略梯度等于加权行为克隆」这个论断最短的证明，也解释了为什么在代码里它可以直接复用分类任务的那套实现。

其三：更新的几何含义。

\(e_a - \pi\) 这个向量指向「把概率单纯形上的当前点，朝被采样动作那个顶点推」的方向。乘上权重之后：

  • \(\Psi_t > 0\)：朝该顶点推，概率质量向这个动作集中。
  • \(\Psi_t < 0\)：朝反方向推，概率质量从这个动作散开到其余动作上。

推的幅度是 \(1 - \pi_a\)：当前概率越小的动作被推得越狠。这是一个自带的自适应机制——已经很确信的动作不会再被大幅推高。反过来也意味着，一旦 \(\pi_a \to 1\)，这个梯度趋于零，策略就学不动了。这一点在熵收缩那一节还会回来。

数值稳定：为什么必须用 logsumexp

直接实现 \(\log(\mathrm{softmax}(z))\) 会出两个问题：\(e^{z_j}\) 在 \(z_j\) 较大时上溢；\(\pi_a\) 极小时 \(\log \pi_a\) 下溢成负无穷，梯度随之变成 NaN。

标准做法是利用 softmax 的平移不变性：给所有 logits 减去同一个常数不改变分布，

\[\mathrm{softmax}(z) \;=\; \mathrm{softmax}(z - c) \quad \text{对任意常数 } c\]

取 \(c = \max_j z_j\) 之后指数项都不超过 1，上溢消失；再把 \(\log\) 与 \(\mathrm{LSE}\) 合并计算，下溢也消失：

\[\log \pi_\theta(a_i \mid s) \;=\; (z_i - c) - \log \sum_j e^{z_j - c}\]

深度学习框架里的 log_softmax 与分布类的 log_prob 都已经这样实现。实践上的建议是：不要自己写「先 softmax 再取 log」，直接用框架提供的分布对象。 这一点在子页 ④ 的代码一节还会具体对应到某一行。

温度：显式的与隐式的

softmax 可以带一个温度参数：

\[\pi_\theta(a_i \mid s) \;=\; \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}\]

\(T \to 0\) 时趋于 argmax（确定性），\(T \to \infty\) 时趋于均匀分布。

策略梯度里通常不显式使用温度，但有一个隐式的等价物：输出层的权重尺度。把输出层权重整体乘以 \(1/T\)，效果与设温度 \(T\) 完全相同。因此：

  • 输出层初始化的增益，实际上决定了初始策略的温度，也就决定了初始熵。 增益大则初始策略就很尖锐，探索不足。
  • 训练过程中 \(\lVert \theta \rVert\) 增长，等价于温度自发下降——这是熵收缩的一条路径。

这也说明一件事：线性 softmax 策略只能在 \(\lVert \theta \rVert \to \infty\) 时趋于确定性，永远达不到。而此时得分函数 \(e_a - \pi \to 0\)，梯度同时消失。熵下降与梯度消失是同一个过程的两面。

连续动作：对角高斯及其三个陷阱

参数化

网络输出均值向量与对数标准差向量：

\[s \;\longrightarrow\; \mu_\theta(s) \in \mathbb{R}^{d}, \quad \log \sigma_\theta \in \mathbb{R}^{d}\] \[\pi_\theta(a \mid s) \;=\; \mathcal{N}\big( \mu_\theta(s),\ \mathrm{diag}(\sigma_\theta^{2}) \big)\]

「对角」指协方差矩阵只有对角线非零，即各动作维度条件独立。这是绝大多数连续控制实现的默认选择。

对数概率

\[\log \pi_\theta(a \mid s) \;=\; -\sum_{i=1}^{d} \left[ \frac{(a_i - \mu_i)^{2}}{2 \sigma_i^{2}} \;+\; \log \sigma_i \;+\; \frac{1}{2}\log(2\pi) \right]\]

引入标准化残差 \(z_i = (a_i - \mu_i) / \sigma_i\)，式子会干净很多。

两个得分函数分量

对均值求偏导：

\[\frac{\partial \log \pi_\theta}{\partial \mu_i} \;=\; \frac{a_i - \mu_i}{\sigma_i^{2}} \;=\; \frac{z_i}{\sigma_i}\]

对对数标准差求偏导（设 \(u_i = \log \sigma_i\)，则 \(\sigma_i = e^{u_i}\)）：

\[\frac{\partial \log \pi_\theta}{\partial u_i} \;=\; \frac{(a_i - \mu_i)^{2}}{\sigma_i^{2}} - 1 \;=\; z_i^{2} - 1\] \[\boxed{\; \nabla_{\mu_i} \log \pi_\theta \;=\; \frac{z_i}{\sigma_i}, \qquad \nabla_{\log \sigma_i} \log \pi_\theta \;=\; z_i^{2} - 1 \;}\]

两者都满足得分函数期望为零：\(\mathbb{E}[z_i] = 0\)，\(\mathbb{E}[z_i^2] = 1\)。

这两个式子解释了什么

陷阱一：标准差趋于零时得分函数发散。

\(\nabla_{\mu} \log \pi_\theta = z / \sigma\) 里有一个 \(1/\sigma\)。策略收敛、\(\sigma\) 变小之后，这个梯度的量级会反比于 \(\sigma\) 增长。于是训练后期常常出现：回报曲线看起来已经平了，梯度范数却在涨。这不是 bug，是这个参数化的固有性质。

实践上的对策是梯度裁剪，以及给 \(\log \sigma\) 设一个下界（常见做法是把它裁剪到某个区间内）。具体配置见 PPO 与 SAC。

陷阱二：高斯的支撑集是整条实轴。

采出来的动作可以是任意实数，而真实的执行器有物理边界。直接把超界的值送进环境会出问题，处理方式见下一节。

陷阱三：单峰。

对角高斯只能表示单峰分布。如果某个状态下「向左绕」和「向右绕」都是好动作、而中间是障碍物，高斯策略会把均值放在两者中间——一个两边都不好的位置。这类问题需要混合高斯、归一化流或扩散策略，是模仿学习与 VLA 里选择扩散模型的主要动机之一，见 ACT 专题。

为什么参数化 log σ 而不是 σ

常见的回答是「保证 \(\sigma > 0\)」。这是理由之一，但不是主要的那个——用 softplus 同样能保证为正。

真正的理由在优化的条件数。计算两种参数化下的 Fisher 信息：

\[F_{\mu} \;=\; \mathbb{E}\left[ \left( \frac{z}{\sigma} \right)^{2} \right] \;=\; \frac{1}{\sigma^{2}}, \qquad F_{\log \sigma} \;=\; \mathbb{E}\left[ (z^{2}-1)^{2} \right] \;=\; 3 - 2 + 1 \;=\; 2\]

而直接用 \(\sigma\) 参数化时，\(\partial \log \pi / \partial \sigma = (z^2 - 1)/\sigma\)，于是

\[F_{\sigma} \;=\; \frac{2}{\sigma^{2}}\]

关键对比：\(F_{\log \sigma} = 2\) 是一个常数，与 \(\sigma\) 无关；而 \(F_{\sigma} = 2/\sigma^{2}\) 随 \(\sigma\) 变小而爆炸。

也就是说，用 \(\log \sigma\) 参数化时，尺度方向上的曲率不随训练进程改变，一个固定的学习率在整个训练过程中都合适；直接用 \(\sigma\) 则曲率随 \(\sigma\) 变化几个数量级，同一个学习率在训练前后期的实际效果完全不同。

这也顺带解释了 TRPO 里提到的现象：Fisher 矩阵中与均值相关的元素正比于 \(1/\sigma^{2}\)，\(\sigma\) 很小时矩阵条件数恶化、共轭梯度迭代变得不稳定。均值方向的病态是躲不掉的，但尺度方向的病态可以靠参数化消除，这就是选 \(\log \sigma\) 的实质理由。

状态相关还是状态无关

\(\log \sigma\) 可以是网络的输出（状态相关），也可以是一个与状态无关的可学习向量。两种做法都有，取舍属于工程配置：PPO 通常用状态无关的，SAC 用状态相关的，各自的理由在那两页里已经讲过，本页不重复。

有界动作的三种处理与各自的偏差

高斯的支撑集是整条实轴，而真实动作有边界。三种标准做法，偏差性质完全不同。

做法一：裁剪

采样后把动作裁剪到合法区间再送进环境：\(a_{\text{env}} = \mathrm{clip}(a, a_{\min}, a_{\max})\)。

这里有一个非常容易踩的陷阱：对数概率必须用未裁剪的值计算。

\[\log \pi_\theta(a \mid s), \quad \text{其中 } a \text{ 是采样得到的原值，不是裁剪后的值}\]

原因是：算法优化的是「采样分布」，而采样分布是那个未被裁剪的高斯。如果用裁剪后的值去算对数概率，就等于假装分布是另一个东西，梯度直接有偏。

这个错误的表现很隐蔽：训练能跑，但收敛到次优，且动作长期贴在边界上。

裁剪本身带来的偏差是：实际执行的动作分布在两个边界上各有一个概率原子（所有超界的概率质量被压到边界点上），与算法认为的连续分布不同。实践中通常接受这个偏差，因为它只在策略把均值推到边界附近时才显著。

做法二：tanh 压缩

令 \(u \sim \mathcal{N}(\mu, \sigma^2)\)，再取 \(a = \tanh(u)\)，得到支撑集为 \((-1, 1)\) 的分布。

这是一个可逆变换，对数概率要加雅可比修正项：

\[\log \pi(a \mid s) \;=\; \log \pi(u \mid s) \;-\; \sum_{i} \log\left( 1 - \tanh^{2}(u_i) \right)\]

漏掉修正项是另一个常见错误，它会让熵的计算与梯度都不正确。

这条路线的完整推导（包括数值稳定的写法与它与最大熵目标的配合）在 SAC，本页不展开。

代价是：\(\tanh\) 在饱和区梯度趋于零，动作接近边界时学习变慢。

做法三：Beta 分布

直接用支撑集为 \([0,1]\) 的 Beta 分布（再线性映射到实际区间）。网络输出两个正的形状参数。

  • 没有边界概率原子，分布本身就落在合法区间内。
  • 不需要雅可比修正。
  • 代价：分布形状受限，且两个形状参数的优化不如高斯稳定；实现与生态支持也不如高斯普遍。

对照

做法 偏差来源 需要额外处理 常见场景
裁剪 实际动作分布在边界上有概率原子 必须用未裁剪值算对数概率 PPO 及多数 on-policy 实现
tanh 压缩 无（变换可逆），但必须补雅可比项 雅可比修正、饱和区处理 SAC 及多数最大熵方法

多维动作的独立分解与它的代价

对角高斯下，\(d\) 维动作的对数概率是各维之和：

\[\log \pi_\theta(a \mid s) \;=\; \sum_{i=1}^{d} \log \pi_\theta(a_i \mid s)\]

这直接来自各维条件独立的假设。实现上非常方便：各维分别算、求和即可，参数量只随 \(d\) 线性增长。

代价是什么

丢掉的是给定状态之后、各动作维度之间的相关性。

以双臂协同为例：某个状态下，「左臂向前同时右臂向后」与「左臂向后同时右臂向前」都是好动作，而「两臂同时向前」会撞上。对角高斯无法表达这种反相关——它只能给每条手臂各自一个独立的分布，于是四种组合的概率是两个边缘概率的乘积，坏组合一定会被采到。

需要区分的两件事

有一个常见的混淆需要澄清：对角协方差丢掉的只是「同一时刻各维噪声之间的相关性」，它并没有丢掉：

  • 均值之间的耦合。 \(\mu_\theta(s)\) 是一个向量函数，各维共享同一个主干网络，完全可以协调。
  • 时间上的相关性。 策略在相邻时刻的输出通过状态耦合，仍然可以产生协调的运动。

所以对角高斯在多数连续控制任务上够用。真正需要满协方差的情形是「同一时刻必须协同、且协同方式有多种」这一类。

满协方差为什么少见

要表示 \(d\) 维满协方差需要 \(d(d+1)/2\) 个参数，而且必须保证矩阵正定——通常的做法是让网络输出 Cholesky 因子的下三角部分，对角线取指数保证为正。代价是参数量按 \(d^2\) 增长、数值上更容易出问题，而收益在多数任务上不明显。

多峰性（而不是相关性）往往是更迫切的需求，这也是扩散策略在机器人领域受关注的原因。

非法动作屏蔽

离散动作任务里常有「当前状态下某些动作非法」的情形（棋类的落子规则、资源不足时不能执行的操作）。

价值方法与策略梯度的差别

价值方法处理起来很简单：把非法动作的 \(Q\) 置成负无穷，argmax 自然不会选到它。

策略梯度要小心，因为它需要屏蔽之后的东西仍然是一个合法的概率分布，并且梯度仍然是这个分布的策略梯度。

正确做法

在 logits 上屏蔽，而不是在概率上屏蔽：

\[z_i' \;=\; \begin{cases} z_i & a_i \text{ 合法} \\ -\infty & a_i \text{ 非法} \end{cases} \qquad\Longrightarrow\qquad \pi_\theta(a_i \mid s) = 0 \ \text{对非法动作}\]

经 softmax 之后非法动作的概率恰为零，其余动作在合法集合上重新归一化。梯度不会流向被屏蔽的 logits，因为它们对输出没有贡献。

Huang 与 Ontañón 在 2022 年的工作给出了论证：这样得到的更新仍然是被屏蔽之后那个策略的有效策略梯度。换句话说，屏蔽不是一个近似，它定义了一个新的策略族，定理在这个族上照常成立。

两个要避开的错误做法

  • 在概率上乘掩码再归一化。 需要澄清一个常见的误说法：这种写法在数学上与 logits 屏蔽完全等价——对合法动作 \(a\) 有 \(\log \pi'_a = z_a - \mathrm{LSE}_V(z)\)（\(V\) 为合法集），与 logits 屏蔽逐字相同；0/1 掩码下非法动作的概率恰为零，对被屏蔽 logits 的偏导也恰为零（\(-p_k\) 与归一化项贡献的 \(+p_k\) 精确抵消）。推荐在 logits 上屏蔽的真正理由是数值路径：直接在 logits 上做可以保留 logsumexp 的稳定形式，而「先 softmax、再乘掩码、再归一化、再取对数」会丢掉这种稳定性（极小概率下溢、算熵时出现 \(0 \cdot \log 0\)）。另需注意实现细节：真实代码通常把被屏蔽的 logits 置成一个很大的负数而不是真正的 \(-\infty\)，因为后者在反向传播里可能产生 NaN。
  • 采样后再拒绝重采。 这改变了实际的采样分布，而对数概率仍按原分布计算，直接有偏。

与正则性条件的关系

子页 ① 的条件二要求 \(\pi_\theta(a \mid s) > 0\)。屏蔽之后非法动作的概率恰好是 0，看起来违反了这一条。

准确的理解是：定理是在「合法动作构成的动作空间」上成立的。在这个受限的动作空间里，所有动作的概率仍然为正，条件满足。被屏蔽的动作根本不在这个空间里，谈不上违反。

视觉与序列输入的编码器

这一节只指路。策略梯度对主干网络没有任何要求——它只要求「从状态到分布参数」这个映射对 \(\theta\) 可微。因此：

  • 低维本体状态：两层 MLP 就够，隐层宽度通常在 64–256 之间。
  • 图像观测：CNN 编码器，或者预训练视觉主干加一个投影层。
  • 多模态与序列观测：Transformer 编码器。

这三种都不改变本页任何一条结论：得分函数的解析形式只取决于分布头，与主干无关。主干换成什么，\(\nabla_z \log \pi = e_a - \pi\) 与 \(\nabla_{\log \sigma} \log \pi = z^2 - 1\) 照样成立，只是链式法则后面多接几层。

视觉与序列主干的具体设计见 ACT 专题 与 VLA 总览；Actor 与 Critic 是否共享主干、观测怎么标准化等工程取舍见 PPO。

Gymnasium 的 Pendulum 环境，引自官方文档。它的动作是一个连续的力矩标量，正是本页对角高斯策略的最小载体——策略网络输出一个均值与一个对数标准差，采样得到力矩。价值方法要处理它必须先把力矩离散化，而策略梯度直接参数化分布。本页不下载该图，直接外链官方资源。

探索：随机策略自带的探索

与价值方法的结构性差别

价值方法学到的是 \(Q\)，由它导出的贪心策略是确定性的，因此必须外挂一个探索机制——\(\varepsilon\)-greedy、噪声网络、或者像 DDPG 那样往动作上加噪声。这个机制与被学习的对象是分离的。

策略梯度学到的直接就是一个随机策略，采样本身就带探索：

\[a \sim \pi_\theta(\cdot \mid s)\]

不需要 \(\varepsilon\)-greedy。这是策略梯度的一项结构性优势。

但探索强度是被优化的对象

代价随之而来：探索强度由策略的熵决定，而熵本身是被梯度更新的对象。价值方法里 \(\varepsilon\) 是一个外部超参数，可以按预定计划衰减；策略梯度里没有这样一个旋钮，熵完全由目标函数与数据决定。

于是问题从「怎么加探索」变成了「怎么防止探索消失得太快」。这正是下一节的内容。

一个常被忽略的优势：能表示随机最优策略

\(\varepsilon\)-greedy 策略的形式被限死了：以 \(1-\varepsilon\) 的概率取某一个动作，其余概率均分。它无法表示任意的随机策略。

这在部分可观测或状态混叠的问题里是真实的限制。如果两个物理上不同的状态在观测里看起来一样，而它们需要不同的动作，那么最优的无记忆策略本身就是随机的——按某个特定比例在两个动作之间随机选择。Sutton 与 Barto 第 13.1 节的短走廊例子给出了一个最小构造。

策略梯度直接参数化分布，可以收敛到这个特定比例；价值方法做不到。这是子页 ① 里「三个创新点」中第三项的另一半。

策略熵为什么倾向于收缩

这是连续控制里最常见失效模式的根源，值得完整讲一遍机制。

先说清楚：熵下降本身是正确行为

标准强化学习目标（不含熵项）的最优解通常是确定性策略——在每个状态上选那个最优动作。因此训练过程中熵下降是算法在正确地收敛，不是病态。

病态在两个地方：下降得太早（还没充分探索就确定了），以及下降之后无法恢复（自我强化）。

机制：对角高斯情形

看 \(\log \sigma\) 方向的期望更新量。单个样本的贡献是得分函数乘以权重：

\[\mathbb{E}\left[ \left( z^{2} - 1 \right) \Psi \right]\]

其中 \(z = (a - \mu)/\sigma\) 是标准化残差。回顾上面那张图：

  • \(\lvert z \rvert < 1\)（采样落在一个标准差以内）时，\(z^2 - 1 < 0\)。
  • \(\lvert z \rvert > 1\)（采样落在一个标准差之外）时，\(z^2 - 1 > 0\)。

于是：

如果优势在均值附近更高（也就是目标函数在动作空间上局部是凹的，均值已经落在一个较好的位置），那么 \(\lvert z \rvert\) 小的样本拿到的 \(\Psi\) 偏大、\(\lvert z \rvert\) 大的样本拿到的 \(\Psi\) 偏小，整个期望为负，\(\sigma\) 收缩。

反过来，如果当前均值偏离好动作，远处的样本反而更好，期望为正，\(\sigma\) 扩张。

这是一个合理的自适应机制：找对了就收紧，找错了就放开。问题在于它是单向自我强化的——\(\sigma\) 一旦收缩，采样范围变窄，就更难发现远处有更好的动作，于是继续收缩。

熵正则项做了什么

给目标加上熵奖励 \(\beta H[\pi_\theta]\)。对角高斯的熵有一个非常干净的形式：

\[H\left[ \mathcal{N}(\mu, \mathrm{diag}(\sigma^2)) \right] \;=\; \sum_{i} \left( \log \sigma_i + \frac{1}{2}\log(2\pi e) \right)\]

注意它只依赖 \(\log \sigma\)，而且是线性的。于是

\[\boxed{\; \frac{\partial H}{\partial \log \sigma_i} \;=\; 1 \;}\]

熵对对数标准差的偏导恒等于 1，与 \(\sigma\) 的当前取值无关。

这意味着熵正则项在 \(\log \sigma\) 方向上提供一个大小恒为 \(\beta\) 的向上推力。平衡点落在

\[\mathbb{E}\left[ (z^{2}-1)\, \Psi \right] \;+\; \beta \;=\; 0 \qquad\Longleftrightarrow\qquad \mathbb{E}\left[ (z^{2}-1)\, \Psi \right] \;=\; -\beta\]

也就是说，\(\beta\) 直接设定了「策略愿意为保持探索付出多少优势」的兑换率。这个恒定推力的性质也解释了为什么熵系数在整个训练过程中通常可以固定不变——它不会因为 \(\sigma\) 变小而失效。但要补两个限定：其一，恒定的只是熵这一侧，平衡方程另一侧的 \(\mathbb{E}[(z^2-1)\Psi]\) 会随优势的尺度线性缩放，所以「系数含义稳定」还需要优势尺度本身稳定（例如做了优势标准化）；其二，\(\partial H / \partial \log \sigma = 1\) 是对角高斯特有的，离散 softmax 的熵对 logits 的偏导不是常数，那里熵系数退火是常见做法。

（把熵从「正则项」提升为「目标的一部分」并自动调节 \(\beta\)，是最大熵强化学习的做法，见 SAC。本页只讲熵作为正则项时的机制。）

机制：离散情形

softmax 策略下的对应现象在前面已经提过：更新把概率质量朝被采样动作推，推力大小是 \(1 - \pi_a\)。随着某个动作的概率趋于 1：

  • 熵趋于 0，探索停止。
  • 同时得分函数 \(e_a - \pi \to 0\)，梯度也趋于 0。

两件事同时发生。所以离散情形下熵坍缩的典型表现不是「训练崩掉」，而是「训练停滞」——曲线平了，梯度范数也很小，看起来像收敛了，实际上只是策略把自己锁死了。

判断方法很直接：打印策略熵。真正收敛时熵低是正常的；如果熵在回报还很低的时候就已经接近 0，那就是过早坍缩。

与降方差的冲突

最后指出一件事：降低方差与保持探索在这一点上是直接冲突的。

\(\sigma\) 越小，采样越集中，梯度估计的方差越低，训练看起来越稳。但探索也越弱。子页 ② 讲的全部降方差手段都不触碰这一项——它们处理的是权重 \(\Psi\) 那一侧的方差，而不是策略自身随机性带来的方差。策略自身的随机性是必须付的代价，不能压。

熵正则做的正是反向的事：它主动阻止这一项被压低。把熵系数理解成「为探索保留多少方差」的预算，比理解成一个玄学的正则化超参数更准确。

初始化：让初始策略接近均匀分布

结合前面两节，初始化的原则就很清楚了。

离散情形

输出层权重要初始化得小，使初始 logits 接近全零，softmax 输出接近均匀分布。

理由：输出层权重的尺度等价于 softmax 的温度（见上文）。初始化增益大就相当于初始温度低，策略一开始就很尖锐，探索严重不足；而策略梯度完全依赖策略自身的随机性来探索，没有 \(\varepsilon\)-greedy 兜底。

失败表现：训练早期就锁死在一个坏动作上，回报停在低位不再上升，同时策略熵很低。

连续情形

  • 均值头用小增益初始化，使初始均值接近零（或动作空间中心）。
  • 初始 \(\log \sigma\) 通常设为 0 附近（即 \(\sigma \approx 1\)）或略负，取决于动作空间被归一化到什么尺度。

一个值得注意的细节：初始均值如果离散得厉害，训练前几轮会产生剧烈的分布变化。在 on-policy 算法里这直接表现为新旧策略差异过大——PPO 的裁剪会频繁触发，前期几乎不前进。这也是为什么 on-policy 实现普遍强调策略输出层的初始化。

具体的初始化方案（正交初始化、增益取值）属于工程配置，见 PPO，本页不重复。

常见误解与准确说法

常见说法 准确说法
策略梯度有一套专门的网络结构 它对主干没有任何要求；决定得分函数形式的是分布族，不是网络层数
策略网络和 DQN 一样输出每个动作的值 输出的是分布参数；连续动作下输出维度只随动作维度线性增长，而不是随动作数增长
得到概率之后取概率最大的动作 训练时必须采样；取 argmax 会让策略确定性化，得分函数没有定义，整套推导失效
先 softmax 再取 log 就能得到对数概率 数值上会上溢或下溢；必须用 logsumexp 形式，直接调用框架的 log_softmax 或分布对象的 log_prob
参数化 log sigma 是为了保证标准差为正 这只是理由之一；主要理由是它让尺度方向的 Fisher 信息成为常数，条件数不随训练变化
动作裁剪之后用裁剪值算对数概率 必须用未裁剪的采样值；用裁剪值等于假装分布是另一个东西，梯度直接有偏
tanh 压缩只是把动作映到区间内 它是一个可逆变换，对数概率必须补雅可比修正项，漏掉会让熵与梯度都不正确
对角高斯丢掉了动作维度之间的一切关联 丢掉的只是同一时刻各维噪声的相关性；均值向量各维共享主干，仍然可以协调
非法动作可以先采样再拒绝重采 这改变了实际采样分布而对数概率仍按原分布算，直接有偏；正确做法是在 logits 上屏蔽
策略梯度需要 epsilon 贪心提供探索 随机策略自带探索；真正的问题是相反方向的，即熵收缩得太快
策略熵单调下降 不存在这样的定理；准确说法是系统性收缩倾向，机制是优势在均值附近更高时尺度方向的期望更新为负
熵下降说明训练出问题了 熵下降本身是正确收敛；病态在于过早下降以及下降后的自我强化
熵系数需要随训练衰减 对角高斯的熵对 log sigma 偏导恒为 1，正则项提供恒定推力，因此系数通常可以固定

小结与出口指针

四句话回顾

  • 策略梯度没有固定网络结构，网络只负责把状态映射成分布参数；得分函数的形式只取决于分布族。
  • 离散情形下 \(\nabla_z \log \pi = e_a - \pi\)，分量和恒为零、逐字就是交叉熵损失的梯度，推力大小是 \(1 - \pi_a\)——概率越高推力越小，这既防过度自信也造成后期梯度消失。
  • 连续情形下 \(\nabla_\mu \log \pi = z/\sigma\)、\(\nabla_{\log \sigma} \log \pi = z^2 - 1\)。前者在 \(\sigma \to 0\) 时发散，后者的零点在 \(z = \pm 1\)，直接解释了标准差为什么收缩。选 \(\log \sigma\) 参数化的实质理由是它让尺度方向的 Fisher 信息成为常数。
  • 探索由策略自身承担，代价是探索强度成了被优化的对象。熵正则在 \(\log \sigma\) 方向提供恒为 \(\beta\) 的推力，平衡点由 \(\mathbb{E}[(z^2-1)\Psi] = -\beta\) 给出。

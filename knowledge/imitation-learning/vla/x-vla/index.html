跨本体异构性四象限

动作空间与自由度单臂、双臂、移动底盘和通道布局不同；补零只能对齐形状，不能证明语义相同。
相机配置固定视角、腕部视角、视角数量与标定不同；固定槽位不自动完成视觉语义对齐。
控制语义与频率坐标系、单位、delta/absolute、频率和控制器不同；共享维度不等于可直接执行。
数据与任务风格操作者、任务分布、重试策略和质量不同；domain_id 不能单独修复不平衡或标签噪声。

显式域条件的动机可用一个本站分析式说明：

\[f^*(x)=\mathbb{E}[A\mid x] =\sum_d p(d\mid x)\,\mathbb{E}[A\mid x,d].\]

只有不同域的条件动作确实冲突、且域无法从其他输入可靠识别时，混合均值才会偏离域内最优。若可见条件已能识别域，或监督本来一致，显式 domain_id 不必然增益；它也不解决数据不平衡、错误标准化和标签噪声。

论文 Table 1 的累积路径给出一条受限 observation：定制学习率、无预训练基线为 39.6，直接加入未充分对齐的异构预训练后为 25.0，差值为 −14.6 个百分点。它只说明该累积路径发生负迁移，不证明异构数据普遍有害，也不能拆成单组件因果效应。

共享参数与域私有预算

共享Florence‑2 encoder、主辅图像编码路径、视觉投影、绝对位置嵌入、24 层 Transformer encoder 与输出 LayerNorm。
域私有Soft Prompt 行、动作输入投影的权重与 bias 行、动作输出投影的权重与 bias 行。
配置相关use_hetero_proj 打开时，VLM 与辅助视觉投影也可能按域变化。
外部责任domain_id 语义映射、相机/状态/动作 schema、归一化、控制器和安全包络。

固定发布实例里，soft_prompt_hub 以 domain_id 取一行并 reshape 为 [B,32,1024]。Prompt 在普通 token 加完绝对位置编码后追加，自身不获得同一位置编码；主干是无 mask 的双向注意力，所以位于序列末尾不妨碍其他 token 读取它。

证据边界与六个易误解点

  1. Soft Prompt 不是已证明的 morphology embedding。 它是可学习 domain latent，可能混合本体、相机、任务分布和操作者因素。
  2. 私有参数不只有 Prompt。 动作输入和输出投影同样按域查表；只迁移 Prompt 会漏掉动作量纲边界。
  3. 固定代码不回归速度场。 论文方法仍可称 Flow Matching，但当前固定仓库的训练目标是干净动作 x0。
  4. 固定推理不是 Euler integration。 循环没有累加更新，而是复用同一噪声进行重混和自精化。
  5. 30 anchors 不是独立 query 模块。 它是动作块/数据重采样约定；固定序列长度 262 也随视角、文本、动作和 Prompt 配置改变。
  6. 没有全新本体零样本部署证明。 新域仍需要 demonstrations、槽位、三处私有参数、schema、绑定和分阶段验收。

论文评测覆盖 6 个仿真环境和 3 个真实机器人平台，scaling 只在已测试的模型容量、数据多样性和数据量范围内未饱和。held-out action prediction error 是代理指标，不等于闭环成功率；0.9B 最优性、当前通用 SOTA、无限扩展和项目视频证明鲁棒性都不成立。

Soft‑Fold 的论文口径包括 1,200 demonstrations，并描述单次收集约 1.5 分钟、每小时约 20–25 个 episode；项目主页另有每小时 33 次和 120 分钟视频标签。标签不是“连续运行两小时”的论文指标，二者不能合并。

VLA/后训练与对齐/RLT/Actor-Critic

本页在 frozen feature 上定义一次 chunk-level learner update：VLA 与 RL-token encoder 的 Stage 2 写权限为 none，critic step 只写 online Q，actor step 只写 actor，target updater 只写 target Q。TD target 必须整体 stop-gradient；actor step 则只冻结 critic 参数写入，必须保留 ∂Q/∂a。

flowchart LR
  O["o at t_k"] --> F["frozen VLA + RL-token encoder"]
  F --> X["x_k · feature bundle pinned"]
  R["reference chunk"] --> A["actor θ"]
  X --> A
  A --> E["execute L_k ≤ C"]
  E --> N["x_k+1 at t_k + L_k"]
  N --> T["target action snapshot"]
  T --> QP["target Q1′ / Q2′"]
  QP --> Y["detached y_k"]
  X --> Q["online Q1 / Q2"]
  Y --> Q
核对写权限检查 TD target审计 transaction返回 RLT 总览

Frozen feature 与参数所有权

Stage 2 输入是 x_k=concat(z^rl_k,s^p_k)。每条输入都必须绑定 feature_bundle_id、shape、dtype、normalization revision、observation timestamp 与 chunk index；bundle 任一组成变化都定义新 state space，旧 Replay 不得在没有迁移证明时混用。

组件 Critic step Actor step Target update Stage 2 写权限
VLA θ_vla read/no-grad read/no-grad 无 none
RL-token encoder φ_enc read/no-grad read/no-grad 无 none
actor θ target action read-only update copy source 是否使用须声明 actor optimizer only
online critics ψ_1,ψ_2 update parameters read-only，保留 action gradient copy source critic optimizers only
target critics ψ'_1,ψ'_2 read/no-grad 不参与 declared rule target updater only
processor/normalizer revisioned read revisioned read 无 none

actor step 的“冻结 critic”只禁止 parameter mutation，不得把整个 Q forward 放进 no_grad；否则 ∂Q/∂a 也会被切断，actor 无法获得 value gradient。parameter hash 不变同样不能证明 processor、normalizer 或 cache 未漂移。

schema: rlt.actor-critic-ownership.v1
frozen: {vla: no-write, rl_token_encoder: no-write}
trainable:
  actor_theta: {optimizer: actor-only}
  critic_psi_1: {optimizer: critic-1-only}
  critic_psi_2: {optimizer: critic-2-only}
targets: {critic_target_1: target-updater-only, critic_target_2: target-updater-only}
actor_step: {critic_parameters: read-only, action_gradient_through_critic: required}

FrozenFeatureReceipt 还要记录 VLA hash、RL-token encoder hash、processor/normalizer revisions、eval/train mode、output test-vector hash 与 write authority。

Chunk transition 与实际执行长度

t 是低层控制步，k 是 RL chunk 决策索引，t_k 是第 k 个 chunk 的起始物理步，C 是最大 chunk 长度，L_k 是实际执行长度。本站合同要求 1≤L_k≤C<H 且 t_{k+1}=t_k+L_k；若实现使用其他对齐规则，必须显式声明。

critic 的 Bellman action 必须是实际执行的 chunk prefix，而不是 actor planned chunk、VLA reference，或 safety layer 改写前的 commanded chunk。若 human/safety 中途接管，就截断 transition、重标 behavior source 或按系统合同拆分，不能把混合动作伪装成纯 actor action。

ChunkTransitionContract:
  transition_id: required
  feature_bundle_id: required
  x_k: required
  x_next: required
  chunk_index_k: required
  physical_start_t_k: required
  planned_length_C: required
  executed_length_L_k: required
  action_executed: required
  action_commanded_hash: required
  action_reference_id: required-or-none
  reward_sequence: required
  reward_valid_mask: required
  termination_cause: required
  bootstrap_type: required
  behavior_source: required
  policy_version: required
  reward_revision: required

valid reward 数量必须与 L_k 一致，x_next 必须对应实际下一次 chunk decision observation，executed action、reward 与 termination 需要覆盖同一时间区间。padding 不得进入 reward sum 或 critic loss denominator；overlapping subsampled chunks 仍须保存各自真实跨度和 transition IDs。

C-step TD target 与 continuation discount

论文对完整 C 步 chunk 给出：

\[R_k^{(C)}=\sum_{i=0}^{C-1}\gamma^i r_{t_k+i},\qquad y_k=R_k^{(C)}+\gamma^C\mathbb E_{a'\sim\pi}[Q_{\psi'}(x_{k+1},a')].\]

它不自动覆盖 early stop、truncation 或 unknown label。本站把完整与 partial chunk 统一为：

\[R_k^{(L_k)}=\sum_{i=0}^{L_k-1}\gamma^i r_{t_k+i},\quad d_k=b_k\gamma^{L_k},\quad y_k=\operatorname{sg}\!\left(R_k^{(L_k)}+d_k\min_jQ_{\psi'_j}(x_{k+1},a'_{k+1})\right).\]
continuation 类型 b_k bootstrap 语义
true task success/failure terminal 0 不 bootstrap
ordinary full chunk continuation 1 L_k=C，continuation 为 γ^C
time-limit truncation environment-defined 需说明是否存在可继续状态
safety/infrastructure truncation contract-defined 不默认等于 task failure
unknown label invalid/pending transaction abort，不填 0 或 1

跨 C 步只乘 γ、已折扣 reward 再逐步折扣、L_k<C 仍使用 γ^C、true terminal 仍 bootstrap，分别造成时间尺度错误、double discount、实际跨度错误和 episode 外价值泄漏。每个 y_k 必须绑定 reward revision、γ/L_k/b_k、bootstrap type、next feature bundle/reference provenance、next-action policy snapshot、target-Q snapshot、aggregation、estimator 与 target computation version。

schema: rlt.continuation-discount.v1
gamma: required
planned_C: required
executed_L: required
reward_valid_mask: required
termination_cause: required
bootstrap_type: terminal | continuing | truncation | unknown
bootstrap_allowed: true | false | unresolved
discount_exponent: executed_L
continuation_discount: gamma_power_L_times_bootstrap_mask

Twin-Q、target critics 与 next-action snapshot

必须区分四个 Q：online Q_{ψ_1} 与 Q_{ψ_2} 各自由 critic optimizer 回归；target Q_{ψ'_1} 与 Q_{ψ'_2} 只由 declared target updater 改变。RLT Appendix B 支持 target value 使用 min(Q_{ψ'_1},Q_{ψ'_2})，但不证明 actor objective 也使用 minimum。

Twin-Q ≠ target network：前者是两个价值估计，后者是滞后参数快照。Q1/Q2 ≠ shared alias；若参数或 output tensor 相同，minimum 没有双估计意义。minimum target 旨在抑制过估计，并非无偏估计，仍可能低估。target critic 在 loss 中 frozen 也不表示永不更新；stochastic next action 更不等于 entropy objective。

论文写 a'~π_θ 并明确 target critic ψ′，但未唯一说明 actor 是否有 target copy，也未固定期望估计器。因此必须记录：

NextActionSnapshot:
  policy_kind: current_actor | target_actor | other | unknown
  policy_checkpoint_id: required
  actor_read_only_in_target: true
  reference_source: next_observation
  reference_checkpoint_id: required
  sample_count: required
  estimator: sample-mean | deterministic-mean | other
  target_policy_smoothing: declared

target network 还须声明 soft/hard update、source/target parameter IDs、coefficient、frequency、initial sync，以及发生在 critic/actor step 前后哪一侧。Polyak 只可作为候选，不能写成 RLT 唯一规则。

schema: rlt.td-target.v1
reward_return: discounted_valid_rewards
next_state: actual_next_chunk_decision
next_action_snapshot: required
target_critics: [q1_target, q2_target]
target_q_aggregation: min
target_stop_gradient: true
target_policy_smoothing: declared-or-unknown
target_actor_kind: current | target | other | unknown
sample_estimator: required

Critic Loss、mask 与 reduction

两个 online critic 对同一个 detached target 分别回归：

\[\mathcal L_{Q_j}(\psi_j)=\mathbb E_{\mathcal B}\left[w_k\left(y_k-Q_{\psi_j}(x_k,a_{\mathrm{exec},k})\right)^2\right],\qquad j\in\{1,2\}.\]

两者必须分别产生 prediction、loss、gradient、optimizer step 和 pre/post parameter hash。w_k 可以组合 valid-sample、importance 或 quality mask，但每个因子都须命名，不能用一个无解释权重吞并 termination、provenance 与质量语义。

CriticObjectiveRecord:
  target_id: required-detached
  q1_prediction: required
  q2_prediction: required
  per_sample_squared_td_error: true
  twin_reduction: separate-sum | separate-mean | independent-optimizers
  batch_reduction: mean | sum | implementation-defined
  invalid_unknown_exclusion: required
  sample_weight_denominator: required
  mixed_precision_scaling: declared
  non_finite_policy: reject-batch | isolate-sample
  write_set: [critic_psi_1, critic_psi_2]

critic step 禁止更新 actor θ、target critics、VLA、RL-token encoder、processor 或 normalizer。target tensor 必须 requires_grad=false 或具有等价可审计证据。receipt 记录 batch/transition IDs、target snapshot IDs、prediction/TD-error stats、loss、gradient norm、optimizer step、hash、skipped samples 与 non-finite status。

Actor objective 与梯度路由

论文 actor 是由 state 和 VLA reference chunk ã_k 条件化、具有固定小方差的 Gaussian chunk policy；其目标为：

\[a_k\sim\pi_\theta(\cdot\mid x_k,\tilde a_k),\qquad \mathcal L_\pi(\theta)=\mathbb E\left[-Q_\psi(x_k,a_k)+\beta\|a_k-\tilde a_k\|_2^2\right].\]

θ 同时接收 value term 和 BC term 的梯度；critic parameters 在 actor step 中 read-only，但 a_k 必须通过 ∂Q/∂a 将梯度传回 actor；reference 默认作为 condition/target 只读，是否 stop-gradient 需登记；VLA 与 encoder 始终 no-write。β、reference dropout、action mask、units/frame/normalization 与 reduction 交给第 42 页，本页不给通用数值。

Eq. 5 写单个 Q_ψ，Appendix B 只明确 twin minimum 用于 target value。因此 actor Q aggregation 只能登记为 q1 | q2 | min | mean | other | unknown，未绑定实现 revision 时不得从“follow TD3”推断。Gaussian sample 的梯度 estimator 也必须声明为 reparameterized、score-function、deterministic mean 或 implementation-defined；不可微 sample 不能直接宣称 action gradient 可回传。

schema: rlt.actor-objective.v1
value_term: negative_q
actor_q_aggregation: q1 | q2 | min | mean | other | unknown
bc_term: beta_times_squared_distance_to_reference
reference_contract: required
action_mask: required
reduction: required
critic_parameters_during_actor_step: read-only
action_gradient_through_critic: true
stochastic_gradient_estimator: required
sigma_status: fixed | trainable | implementation-defined
explicit_entropy_term: false-in-paper-equation

TD3/SAC 边界与未确认机制

机制 证据状态 本页结论
off-policy actor-critic、target critic ψ′ RLT 明确 方法事实
two Q + min target RLT Appendix 明确 Appendix 实验/实现协议
two critic updates / actor update RLT 系统明确 公开实验协议，不是常量
target policy smoothing TD3 原方法有；RLT 未明确 unknown
target actor copy RLT 未唯一明确 implementation-defined
explicit entropy term RLT Eq. 5 无 不称 maximum-entropy SAC
fixed small Gaussian standard deviation RLT Appendix 明确 实验协议，不等于 entropy objective

SAC 的定义核心是 maximum-entropy objective，actor 同时优化 expected return 与 entropy；随机 actor、SAC worker 名称或复用通用基类都不足以把 RLT Eq. 5 改写为 SAC。RLT 使用 TD3-style target critic、Twin-Q minimum 与较慢 actor 更新，但 Gaussian reference-conditioned actor 不等于标准 TD3，且论文未确认 target policy smoothing、target actor、target update coefficient 等全部细节。因此只能说使用 TD3-style components，不能说“就是标准 TD3”。

更新频率、UTD 与 snapshot 时序

论文公开系统采用 asynchronous rollout/learning，每个 actor update 对应两个 critic updates，公开实验报告 UTD=5，并在 warmup 后不久开始 learning。这些是论文系统/实验 protocol，不是所有任务的推荐常量。UTD 若没有 denominator 就不可比较：按 low-level steps、chunk decisions、Replay inserts 或 unique physical steps 计算会给出不同数字。

UpdateScheduleContract:
  critic_updates: required
  actor_updates: required
  target_updates: required
  utd_numerator: gradient_updates
  utd_denominator: low_level_steps | chunk_decisions | replay_inserts | unique_physical_steps
  subsampling_stride: required-or-none
  overlapping_transition_policy: required
  schedule_clock: learner_step | environment_step | replay_insert

若 stride 产生 overlapping chunks，按 Replay inserts 与 unique physical steps 计算的 UTD 必须分别标注，不能把重叠样本当成新增独立物理数据。一次 transaction 还要 pin feature bundle、reward revision、actor、reference generator、target-Q pair 与 normalization revision；中途异步更新时，本 batch 继续使用开始时 snapshots 或明确 abort/retry。

target schedule 必须声明 initial hard sync、critic step、actor step 和 target step 的顺序，不能让同一个 y_k 混用 pre-update 与 post-update target Q。

一轮 learner transaction

BEGIN transaction(update_id)
  pin feature/reward/actor/reference/target-Q snapshots
  sample batch B; validate version + time/action/reward invariants
  compute frozen x_k, x_next or verify cached features against bundle

  with target_no_grad:
    obtain next reference from next-observation provenance
    estimate next action with declared NextActionSnapshot
    q_boot = min(Q1_target(x_next,a_next), Q2_target(x_next,a_next))
    y = reward_return(L_k) + continuation_discount(L_k,type) * q_boot

  update Q1_online and Q2_online against the same detached y
  if actor_due: update actor only with declared Q aggregation + BC term
  if target_due: update target critics by declared rule and order
  emit LearnerUpdateReceipt; COMMIT or ABORT

这是一轮无循环 transaction：y 使用 pinned target-Q snapshot，不读取当前 critic loss 正在修改的 online prediction；critic update 时 actor target path 只读；target update 发生在 loss/optimizer step 之外的明确位置。

遇到 feature/reward/action contract mismatch、L_k 与 masks 不一致、unknown bootstrap label、next reference 来自当前而非 next observation、non-finite target/loss、target 存在梯度路径、Q1/Q2 alias、optimizer 含越权参数、snapshot 中途变化，或 post-step hash 与 write set 不符，必须 abort。

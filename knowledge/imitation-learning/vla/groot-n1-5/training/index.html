可复现边界 公开资产不足以完整复现 可审计公开路径，但不等于官方训练

官方还披露AdamW、cosine schedule、warmup ratio0.05、预训练/后训练FLARE coefficient均0.2，以及VLM在pretraining和finetuning冻结。未公开峰值LR、Adam β/epsilon、weight decay、gradient clipping/accumulation、并行/分片拓扑、wall time/利用率、checkpoint cadence、两项loss reduction和五源精确分母；不能用公开脚本或FLARE附录反向填空。

FLARE附录的target encoder预训练为256 H100、batch8192、150K steps；策略实验是32 H100、batch1024、80K steps。其β=(0.95,0.999)、epsilon=1e-8、weight decay1e-5、cosine、warmup0.05恰与公开微调数值相同，只能称“数值相同、证据主体不同”，不能据此推定N1.5内部训练使用这些值。

官方规模、总损失与分母账本

若250K等于250,000个optimizer updates且global batch按每update样本数计，则名义样本槽位为 250000×16384=4,096,000,000。这不是40.96亿条独立轨迹；同一轨迹可重采样，视频窗口可重叠。“1K H100”保留原词，不能改成精确1000台，也不能用16384÷1000=16.384反推per-device batch：设备数不等于data-parallel replicas，gradient accumulation、model parallel和sharding未知；没有wall time/利用率也不能算GPU-hours。

L_total = L_FM + 0.2 * L_FLARE
DreamGen data axis -> selects/weights samples
FLARE objective axis -> defines auxiliary supervision

0.2不是FLARE梯度恰占20%，因为两项的有效元素、mask、归约、梯度范数和适用样本不同。每个组件必须分别记录numerator、valid denominator、unweighted loss、weighted contribution与applicable sample count，并为无有效组件显式选择skip或reject。

标准DDP等量rank下 B_eff=B_device×N_GPU×G；公开默认 32×1×1=32，10,000 updates对应320,000名义样本槽位。减半micro-batch并翻倍accumulation可保持B_eff，却不保持激活峰值、吞吐、通信频率或梯度噪声时间结构，槽位也不是唯一轨迹。

AdamW、Warmup 与精度加载边界

公开脚本显式使用adamw_torch、β1=0.95、β2=0.999、epsilon=1e-8、peak LR=1e-4、weight decay=1e-5。optimizer只收requires_grad=true参数；非norm且非bias进decay组，norm或名称含bias进zero-decay组。冻结参数不分配Adam状态；norm/bias免衰减是实现启发式，不是数学定理。脚本未显式设置max_grad_norm，库默认不能冒充仓库事实。

warmup ratio0.05；若按ceil，K=10,000得到500 warmup updates，默认warmup样本槽位 500×32=16,000。轴是optimizer update；改变accumulation但保持K不变不会改变500，却会改变见到的样本槽位。精确cosine端点由Transformers版本决定，示意分段函数不是源码逐行等式。

公开TrainingArguments还显式：bf16=true、tf32=true、gradient_checkpointing=false、workers12/进程、prefetch4/worker、pin_memory=false、deepspeed=""，视频后端torchcodec。降低batch主要压激活，冻结DiT减少梯度/optimizer state，LoRA减少可训练权重/状态；三者都不保证消除全部激活OOM。gradient_checkpointing不是现成ArgsConfig字段，本页不虚构CLI开关。

数据采样、Flow 与 Masked MSE

内部五源是internal GR-1、OpenXE、Sim GR-1/DexMG、DreamGen neural trajectories、AgiBot-Beta，完整快照、过滤、绝对规模和权重分母未知。公开脚本接受一个或多个LeRobot数据集，初始权重均1.0，并默认balance_dataset_weights=true、balance_trajectory_weights=true；equal base weight不等于数据集等概率，轨迹长度加权更接近可抽取时间位置采样。归一、replacement和epoch长度归LeRobotMixtureDataset，不能冒充官方五源比例。

公开动作头采样与动作同形高斯噪声，时间来自Beta(1.5,1.0)并经s=0.999变换：z_t=(1−t)ε+t·a，velocity target为a−ε，连续t离散成1000 buckets供action encoder与DiT。正号与插值导数及FLARE附录一致，不能因FLARE正文反号而修改公开target。

令M∈{0,1}^{B×H×dmax}，公开loss为 sum[M(û−u*)²]/sum[M]。动作pad到max_action_dim，只有真实维为1，所以分母是valid action scalar count，不是固定B×H×dmax；padding不稀释loss，但不同任务难度仍不可直接比较。源码无全零mask下界，数据门必须拒绝sum M=0。

公开path还设置return_all_hidden_states=false并注明not using flare now，只有masked Flow MSE；缺future frame input、target encoder/projectors、cosine alignment、EMA teacher与robot/video routing。这是objective graph差异，不是把λ调成0；future token仍存在并接收动作loss间接梯度。

冻结、Trainability 与 Optimizer 所有权

公开默认false/false/true/true分别对应tune_llm/tune_visual/tune_projector/tune_diffusion_model；checkpoint JSON不是最终微调状态，from_pretrained后脚本再调用set_trainable_parameters，必须以加载后的named-parameter requires_grad清单验收。tune_projector只控制列出的state/action encoder/decoder和position embedding，不代表整个action head。

普通非LoRA路径先让action head全可训练再局部冻结；vlln、vl_self_attention、future_tokens未进入两个动作头冻结分支，即使projector和DiT都关仍可训练，且无独立freeze switch。冻结LLM/visual、关闭的DiT和关闭的三类projector进入eval；mlp1随visual冻结但未显式eval，当前LayerNorm/Linear/GELU无dropout/BN，因此train/eval行为相同。默认可训练VL-SA含dropout，保持train符合公开路径。

optimizer在构建时按requires_grad分组；之后动态改freeze不会自动更新membership，必须重建或迁移state。完整FLARE中policy projector应进optimizer，target teacher不进optimizer，由optimizer step后no_grad EMA更新；公开脚本没有这些组。

单步链、DDP 与 LoRA 语义

flowchart LR
  B[batch] --> X[transform + mask]
  X --> V[frozen backbone eval]
  V --> A[vlln + VL-SA]
  A --> N[noise + time]
  N --> Q[state + future + action]
  Q --> D[DiT velocity]
  D --> M[masked Flow MSE]
  M --> G[backward / accumulate]
  G --> O[AdamW + scheduler]
  O --> C[optional checkpoint]
  O -. full FLARE only .-> E[post-step EMA teacher]

文本回退：公开路径按transform/mask、冻结主干、VL适配、噪声/时间、state+future+action、DiT速度、masked Flow、反传/累积、AdamW、scheduler和可选保存执行；只有完整FLARE路径在optimizer后追加teacher EMA。

公开ddp_find_unused_parameters=false、ddp_bucket_cap_mb=100、DeepSpeed为空。加入条件FLARE、人类视频mask或可选target路径后，部分rank可能unused而多卡报错/等待，单卡不暴露；未来需robot-only/video-only/mixed batch小步验收，本阶段不运行。

LoRA默认rank0关闭，启用默认alpha16、dropout0.1、lora_full_model=false；scope限定名称含action_head，目标Linear匹配q_proj/k_proj/v_proj/to_q/to_k/to_v，默认不含output projection或FFN。get_peft_model重写可训练集合，须用print_trainable_parameters输出验收；full_model会给主干加adapter，基础VLM权重虽冻结但不能简称“VLM完全不适配”。task_type=CAUSAL_LM只是PEFT包装枚举，不表示动作头做语言建模。

Checkpoint、动作头迁移与 Claim Ledger

公开checkpoint至少需核验：weights/config、processor/modality、normalization stats、action horizon/dim、embodiment mapping、source commit/args、global step/seed；完整FLARE还要teacher/target projectors、EMAρ/step和两分量loss状态。公开checkpoint没有这些FLARE组件。resume parity未来应比较next batch、LR、optimizer/scheduler、RNG和输出；当前状态not-run。

当数据action_horizon或max_action_dim与checkpoint不同，脚本重建action head；物理动作维更小时优先padding+mask，不应无故缩头。同shape键全拷，识别的形变键尝试部分拷，否则随机初始化。helper按action_encoder + W1.weight和action_decoder + weight/bias匹配，而CategorySpecificLinear实际参数名是大写W和小写b，存在匹配不到并落入random的静态风险；函数标为very experimental。必须记录copied/random计数、逐键shape和新旧prefix，不能声称已运行验证。

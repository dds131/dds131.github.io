VLA 总览/ π0.7 总览/ ① 网络架构与输入输出

本页只分析低层 π0.7 VLA：多视角历史、子目标、文本条件和本体状态如何成为上下文，以及 860M Action Expert 如何在这些上下文上生成 50 步连续动作块。高层语义策略和 BAGEL 世界模型是独立组件，见④ 高层策略与世界模型。

约 5B低层 VLA 总规模
Gemma 3 4BVLM 主干
约 400M主干内视觉编码器
860MAction Expert
最多 4 × 6相机路数 × 每路帧数
50动作 Token 数

1. 条件动作模型

\[\mathbf A_t=(\mathbf a_t,\ldots,\mathbf a_{t+L-1}),\qquad L=50,\] \[\mathbf A_t\sim \pi_\theta\!\left( \mathbf A\mid \mathbf o_{t-T:t}, \ell_t,\hat{\ell}_t,\mathbf g_t,m_t,c_t \right).\]

$\mathbf A_t$ 是从时刻 $t$ 开始、恰含 50 步的动作块；$\mathbf o_{t-T:t}$ 包含多视角图像与本体状态历史；其余条件依次为总体任务、当前子任务、视觉子目标、Episode Metadata 和控制模式。架构的关键不只是输入更多字段，而是让 Action Expert 能读取这些字段在 VLM 中形成的上下文表示。

2. 模块级数据流

flowchart LR
  I[最多 4 路相机<br/>每路最多 6 帧] --> M[MEM 风格视觉编码器]
  G[最多 3 路目标图像] --> M
  M --> V[Gemma 3 4B VLM]
  Q[当前与历史状态<br/>线性投影] --> V
  T[任务 / 子任务 / Metadata / 控制模式] --> V
  V --> C[上下文激活]
  N[带噪 50 步动作块] --> E[860M Action Expert]
  C --> E
  Tau[Flow 时间] --> A[adaptive RMSNorm]
  A --> E
  E --> O[50 步速度场]

Action Expert 并不是第二个完整视觉语言模型。视觉和文字先由 VLM 建立上下文，Action Expert 再以较小 Transformer 读取这些激活并预测连续动作速度场。

3. 多视角视觉与目标

输入 路数与历史 预处理 作用
观察图像 前视、两腕部、可选后视；每路最多 6 帧 448×448 当前场景与最近运动
子目标图像 最多 3 路，不含后视目标 448×448 希望在近未来达到的多视角结果
本体状态 当前与历史状态 线性投影到主干维度 关节、夹爪和视觉不可见动态

历史视觉经过时间和空间压缩，输出与单帧相同数量的 Token；因此 Token 数不会简单扩大到 24 倍。具体时序机制见③ MEM 历史视觉。

4. 连续状态 Token

π0.6 把状态离散为文本 Token；π0.7 按 MEM 设计改用线性投影：

\[\mathbf e^q_{t-k}=W_q\mathbf q_{t-k}+b_q.\]

每个历史状态成为独立 Token。若对应历史图像被丢弃，该状态 Token 也被掩码，避免把不同时刻的视觉和状态拼成一个不存在的场景。

解释边界。线性投影保留连续数值并便于时间对齐，这是结构层面的解释；论文没有单独消融证明每一项优势，也没有公开投影层的全部维度。

5. Action Expert

Action Expert：

  • 是 860M 参数 Transformer；
  • 固定处理 50 个动作 Token；
  • 动作 Token 之间使用双向注意力；
  • 可以读取 VLM 主干激活；
  • 以 adaptive RMSNorm 注入 Flow 时间；
  • 输出连续动作速度场。

其接口可写为：

\[v_\theta(A_\tau,\tau,C)\approx u_\tau.\]

本页不重新推导插值方向和 Flow Matching Loss；详见⑤ 数据、训练流程与 Loss以及站内π0 Flow Matching。

6. 注意力不是“全序列全部互看”

依据论文 Appendix A-B：

Token 组 主要可见性
历史感知观察图像 组内全局双向
文本 Prompt 按因果顺序读取先前视觉与文本
目标图像 作为额外块，组内双向，并可读取观察上下文
FAST 动作 Token 仅训练期；监督 VLM
Flow Action Token 属于 Action Expert，组内双向并读取 VLM 激活

FAST Token 与 Flow Action 不互相注意；训练时，Action Expert 的 Flow Matching 梯度也不回传到 VLM 主干。前者是注意力可见性边界，后者是梯度边界：FAST 交叉熵负责训练 VLM 表征，连续 Flow 目标负责训练 Action Expert，二者不能混为同一机制。

CFG 推理可以把正条件和负条件分支打包到同一序列，但两条分支通过树形注意力掩码隔离，不会互相读取。

7. 相比 π0.6 的确切变化

方面 基础 π0.6 π0.7
历史视觉 基础多视角输入 MEM 风格多帧历史压缩
状态 离散文本 Token 历史连续状态线性投影
视觉目标 无完整生成链路 最多三路目标图像
上下文 任务与有限条件 子任务、目标、细化 Metadata、控制模式
实时动作 既有动作块 加入 training-time RTC 条件

这里的比较对象是基础 π0.6；论文同时把 π0.6-MEM 视为 π0.7 的直接前身。因此，MEM 历史编码不是 π0.7 凭空提出的新模块，而是被纳入更完整的多模态条件系统。Gemma 3 4B、860M Action Expert、FAST 与 Flow 双路监督等共性已在 π0.6 专题说明，本页不重复。

8. 创新点与证据边界

π0.7 的架构价值主要是系统组合：把 MEM 历史、视觉子目标、细粒度 Prompt、Knowledge Insulation 与连续动作生成接入同一低层策略。论文明确指出，其重点不是宣称一个全新的单一架构，而是提出利用多源异质数据的方法，并通过实验展示组合后的泛化与可引导性。

还要区分“可输入”与“会遵循”：加入 Metadata、子任务或目标图像只提供了条件通道；模型真正学会速度、质量或策略控制，还依赖训练数据中这些条件与行为差异之间存在稳定对应。页面后续的训练与现象分析都应以这一前提为基础。

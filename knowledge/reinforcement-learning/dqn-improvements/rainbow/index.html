前六个子页各讲一项改进。本页是专题的收尾，不重讲任何一项的机理，只回答论文摘要提出的那个问题：

社区对 DQN 提出了若干改进，但尚不清楚这些扩展中哪些是互补的、能否有效组合。

Rainbow 的贡献不只有更高的 Atari 分数：它还给出了一套具体的整合方式，并通过逐项移除实验分析各组件在这套组合里的边际贡献。这里的消融回答的是“在该算法、该超参数与该 Atari 协议中移除一项会怎样”，不是对组件普遍价值的最终裁决。

7M 帧追平 DQN 最佳性能所需
53 / 57完整体同时胜过两种关键消融
ε = 0无随机动作分支，仍有参数噪声探索
6 → 1六项改进整合进单一智能体
本页重点。必须精读的是两节：「组合时的互相适配」——有些组件需要改写目标、损失或网络输出，有些则按明确接口接入，其中 PER 改用 KL 损失作优先级最值得注意；「消融说明了什么」——区分论文观察、作者假设与可推广结论，并澄清一条广为流传但机制被说错的说法。

本页不重复任何单项的推导。每一项的完整展开见对应子页，正文中会逐处给出链接。

六项改进各自解决什么

论文引言用一句话概括了每一项针对的问题。这张表同时也是本专题的索引。

改进 它针对的问题（论文原述）
Double DQN 处理 Q-learning 的过估计偏差，做法是解耦自举动作的选择与评估
优先经验回放 改善数据效率，更频繁地重放那些可学到更多的转移
Dueling 网络 通过分别表示状态价值与动作优势，帮助在动作之间泛化
多步自举目标 移动偏差-方差权衡，并帮助把新观察到的奖励更快传播到更早访问的状态
分布型强化学习 学习折扣回报的类别分布，而不是估计其均值
Noisy DQN 用随机网络层来做探索

各项链接：过估计与 Double、Dueling 分解、优先经验回放、多步回报、分布型强化学习与 C51、NoisyNet。

论文给出的组合理由是两条：这些算法各自解决的是截然不同的问题，而且它们建立在同一套框架之上，因此看起来是可以合并的。此前已有部分组合的先例（例如 Prioritized DDQN 与 Dueling DDQN 都用了 double Q-learning）。

组合时的互相适配

这是本页独占的内容，也是最容易被忽略的一节：Rainbow 不是把六个开关随意打开，而是规定了它们之间的数据流与接口；其中多步、Double、PER 与 Dueling 都要适配回报分布目标，NoisyNet 则替换相应的线性层。

多步与分布目标：收缩再平移

先把 1 步的分布损失换成多步变体。目标分布的构造方式是：把 \(S_{t+n}\) 处的值分布按累积折扣收缩，再按截断 \(n\) 步折扣回报平移：

\[d_t^{(n)} = \Big( R_t^{(n)} + \gamma_t^{(n)} \bm{z}, \; \bm{p}_{\bar\theta}\big(S_{t+n}, a^{*}_{t+n}\big) \Big)\]

令 \(m_t = \Phi_{\bm z}d_t^{(n)}\) 为投影后的目标概率，当前在线网络对已执行动作的预测为 \(\bm p_\theta(S_t,A_t)\)。每个样本的分布损失为：

\[\ell_t = D_{\mathrm{KL}}\Big(m_t\,\big\|\,\bm p_\theta(S_t,A_t)\Big).\]

其中 \(\Phi_{\bm{z}}\) 是投影到固定支撑 \(\bm{z}\) 上的算子（见子页⑤）。优化时常直接计算交叉熵 \(-\sum_i m_{t,i}\log p_{\theta,i}\)；对单个固定目标 \(m_t\)，它与 KL 只差目标熵，对在线参数的梯度相同。

但“梯度相同”不代表数值可以在所有用途互换：

\[H(m_t, p_\theta)=D_{\mathrm{KL}}(m_t\|p_\theta)+H(m_t).\]

不同样本的投影目标 \(m_t\) 可以有不同熵，因此交叉熵与 KL 可能给出不同的优先级排序。训练损失可用交叉熵实现同一梯度；若要严格复现论文的 PER 优先级，则应使用 KL 数值，而不是未经修正的交叉熵。

注意「收缩加平移」作用在目标原子的位置上：原子位置乘以实际自举折扣 \(\gamma_t^{(n)}\)，再加截断多步回报 \(R_t^{(n)}\)；目标网络给出的概率随这些原子一起搬移，再由 \(\Phi_{\bm z}\) 重新分配到固定支撑。若序列在不足 \(n\) 步时结束，就应使用实际步数 \(k\)；真正终止时关闭自举，时间截断则按环境 API 的语义决定是否从最终观测自举。不能无条件写成 \(\gamma^n\)。完整边界处理见子页④。

原论文的组合公式直接使用回放轨迹上的 \(n\) 步回报，并没有写入逐步重要性采样比率来修正行为策略与目标贪心策略的差异。因此不能把这个多步目标宣称为一般意义下的“严格无偏 off-policy 估计”；它是论文在 Atari 上以 \(n=3\) 验证的工程组合。终止与现代环境 API 的边界处理是实现补充，不是原文声称解决了全部 off-policy 理论问题。

Double：嵌在自举动作的选取里

多步分布损失与 double Q-learning 的结合方式是：用在线网络在 \(S_{t+n}\) 上选出的贪心动作作为自举动作 \(a^{*}_{t+n}\)，再用目标网络去评估它。这与子页①的解耦是同一件事，只是被搬进了回报分布框架。

PER：改用 KL 损失作优先级

标准的比例式优先经验回放用绝对 TD 误差作优先级。在分布设定下这仍然算得出来（用均值动作值），但 Rainbow 没有这么做：

\[p_t \;\propto\; \ell_t^{\omega} = \Big[D_{\mathrm{KL}}\big(m_t\,\|\,\bm p_\theta(S_t,A_t)\big)\Big]^{\omega}.\]

用前面的记号，更清楚地写就是 \(p_t \propto \ell_t^{\omega}\)；\(p_t\) 是用于抽样的相对权重，归一化后才是概率 \(P(t)=p_t/\sum_jp_j\)。工程实现通常给 KL 加一个很小的正数，以免样本获得零概率，并在参数更新后用停止梯度的逐样本 KL刷新起始转移的优先级；不要把 batch 平均损失、乘过重要性权重的损失或未经减去目标熵的交叉熵写回所有样本。论文的理由是：KL 损失正是算法在最小化的量。它还提出一项可能性解释：

论文的原话是“可能”更鲁棒：在回报非确定时，KL 损失仍可能继续下降。直觉上，单次采样形成的标量 TD 误差会受固有随机性影响，而分布模型有机会表示这种随机性。

这不是“KL 必然收敛”或“TD 误差必然永久很大”的定理：目标网络漂移、函数逼近、分布投影、模型容量与单样本估计都会影响损失。应把它视为作者对所观察设计的解释，而不是随机环境中的普遍保证。

Dueling：在每个原子上聚合，再过 softmax

网络采用适配了回报分布的 dueling 架构：共享表示 \(\phi = f_\xi(s)\)，送入有 \(N_{\text{atoms}}\) 个输出的价值流 \(v_\eta\)，以及有 \(N_{\text{atoms}} \times N_{\text{actions}}\) 个输出的优势流 \(a_\psi\)。对每个原子 \(z^i\) 按 dueling DQN 的方式聚合价值与优势，然后过一个 softmax 层得到归一化的概率：

\[p^i_\theta(s, a) = \frac{\exp\big( v^i_\eta(\phi) + a^i_\psi(\phi, a) - \bar{a}^i_\psi(s) \big)}{\sum_j \exp\big( v^j_\eta(\phi) + a^j_\psi(\phi, a) - \bar{a}^j_\psi(s) \big)}, \qquad \bar{a}^i_\psi(s) = \frac{1}{N_{\text{actions}}} \sum_{a'} a^i_\psi(\phi, a')\]

减均值的形式被完整保留（理由见子页②），只是现在它作用在每个原子上，且最后多了一层 softmax 把结果归一化成分布。实现时要分清两个轴：\(\bar a^i\) 对固定原子 \(i\) 沿动作轴求均值；softmax 的分母对固定动作 \(a\) 沿原子轴求和。把任一轴写反都会得到错误的概率模型。

NoisyNet：替换全部线性层

最后，原论文的 Rainbow 网络把所有线性层都替换成噪声版本，其中使用因子化高斯噪声（见子页⑥）。这里的 linear layers 指线性/全连接层，不是把卷积算子也改成噪声层；它描述的是论文的具体架构，也不意味着任何后续 Rainbow 实现都必须替换所有可学习算子。实现时还要明确行为、在线当前值、Double 动作选择与目标值各自在何时重采样；“用了 NoisyNet”本身没有消除噪声生命周期的约定。

一次训练更新的组合契约

把上述公式落实到代码时，建议逐项核对下面的顺序。它也能避免“单项实现都对，组合后却错”的隐蔽故障：

  1. 从 PER 按 \(P(i)\) 抽样，同时保留每个样本的重要性权重；优先级归属于片段起点 \((S_t,A_t)\)。回放项可以预存聚合后的 \(n\) 步回报、累计折扣与自举状态，也可以在采样时重建连续片段，但都不能跨越 episode 边界；新转移按比例式 PER 的规则以当前最大优先级插入。
  2. 对每条片段构造实际 \(k\le n\) 步的 \(R_t^{(k)}\) 与自举掩码。真正终止关闭自举；允许自举的截断要使用环境返回的最终观测。
  3. 在无梯度目标构造阶段，用在线网络在 \(S_{t+k}\) 上按分布期望选动作；再用目标网络给该动作的原子概率。两次前向使用各自约定的独立 NoisyNet 样本，目标分支停止梯度。
  4. 将目标原子变换为 \(R_t^{(k)}+\gamma_t^{(k)}z_i\)，再投影到 \([V_{\min},V_{\max}]\)；投影必须守恒总概率，且正确处理恰落在原子上的情况。
  5. 训练可计算逐样本交叉熵并乘各自的重要性权重后聚合；PER 优先级则按论文用未乘重要性权重、已停止梯度的逐样本 KL 刷新，即交叉熵还要减去目标熵。
  6. 完成当前值的带梯度前向后，要保持该份 online 噪声直到 backward() 结束；不要在中途原地重采样。随后按既定频率同步目标网络的可学习参数并重新采样一次性噪声。行为动作再使用独立噪声；安全顺序见 NoisyNet 子页。

两个容易混淆的量：重要性权重修正的是“非均匀抽样后如何聚合梯度”；优先级决定的是“下次多大概率再抽到该样本”。前者不应混进后者。另一个常见错误是用目标网络选动作——那会退回非 Double 的目标。

先固定实验口径，再读消融

Rainbow 的消融结论来自一套明确且有历史背景的 Atari 协议：

读图纪律。“中位数曲线更高”不是统计显著性的同义词；“53/57”也不是 53 个独立显著性检验。中位数会隐藏逐游戏的正负变化，而 best-snapshot 最终评估还带有模型选择口径。以下结论都限定在这套组合和协议内，也不能代表今天的 Atari 最佳水平，更不能直接外推到机器人、连续控制或离线 RL。

消融说明了什么

消融的做法是：每次从完整的 Rainbow 中移除一个组件，在其余配置保持为该组合设定时比较中位人类归一化曲线、不同性能阈值下的游戏数，以及逐游戏的全程表现。它测得的是该组件在完整组合中的条件边际贡献；组件之间存在交互，所以不能据此把六项贡献简单相加。

条形长度只是对论文文字结论的定性示意，不是从图中读数后等比绘制，也不是带误差条的统计排名。Dueling 与 Double 在这套完整组合里的中位聚合边际影响较小，但逐游戏有升有降；这不等于组件普遍无用。

最关键的两项：优先回放与多步回报

优先经验回放与多步学习是 Rainbow 最关键的两个组件，移除其中任何一个都会造成中位性能的大幅下降。

两条细节：

  • 移除任一都会损害早期性能，这不意外；
  • 更令人意外的是，移除多步学习也损害了最终性能。
  • 按论文 Figure 4 使用的全程学习曲线面积逐游戏看，完整 Rainbow 在 57 个游戏中的 53 个上同时优于“去掉 PER”和“去掉多步”两种消融。该图把面积相对 Rainbow 与 DQN 归一化，并省略了 DQN 胜过 Rainbow 的两个游戏；53/57 是正文对全部游戏的汇总结论，不是 53 次带显著性检验的独立结论。

分布型强化学习：作用出现得晚

它的重要性紧随前两者之后，但时间特征很特别：

在早期学习中看不出差别——前 4000 万帧里，去掉分布学习的变体表现得与完整智能体一样好。但在那之后，没有分布的智能体开始落后。

按人类水平分层看，分布学习消融主要在达到或超过人类水平的那些游戏上落后。

这不是“只删掉分布输出头”的纯消融。完整 Rainbow 的 PER 优先级使用 KL；一旦移除分布学习，就没有类别目标与 KL 可用，只能退回标量目标相应的 TD 误差优先级。论文没有把这两个接口变化再拆成二因素实验。因此，观测到的差异是“标量学习目标 + 标量优先级”相对“分布学习目标 + KL 优先级”的条件效应；这是根据论文两段算法定义得到的实现层面推论，不应把全部差异单独归因于回报表示。

NoisyNet：总体有利，但并非普遍

以中位性能计，包含 NoisyNet 时更好；把它去掉后，论文改用传统 \(\varepsilon\)-贪心，并在前 25 万帧把 \(\varepsilon\) 退火到 0.01，聚合表现更差。逐游戏看则并不单向：移除 NoisyNet 在若干游戏上造成大幅下降，同时也在另一些游戏上带来小幅提升。因此这项消融同时改变了网络层与探索机制，比较的是两套完整探索配置。

Dueling：聚合差别小，逐游戏并不一致

论文表述为：总体上，从完整 Rainbow 中移除 dueling 网络“没有观察到显著差别”。但正文没有随这句话报告假设检验、置信区间或多种子统计，因此这里应把“显著”按可见的聚合差异不明显来理解，而不是严格的统计显著性结论。

中位数还会掩盖逐游戏差异：论文谨慎地说，Dueling 也许改善了超过 200% 人类水平的游戏数，同时降低了超过 20% 人类水平的游戏数。这既不能证明因果机制，也不能推出 Dueling 可删除。

Double：影响有限，但机制常被说错

这是本页最需要讲准的一条。

事实部分：在中位性能上，移除 double Q-learning 的可见差别有限；按逐游戏图，它有时对应提升、有时对应下降。这个结果只说明其在当前有限支撑组合中的边际效果被压小，不能说明 Double 的过估计机制已经失效。

机制部分——论文做了一步额外的检查，把训练好的智能体的预测与由裁剪奖励算出的实际折扣回报作比较：

论文的观察是：实际回报常常高于 10，因而落在分布支撑（从 −10 到 +10）之外。这导致的是回报被低估，而不是被高估。论文由此提出一个假设：把值裁剪到这个受限范围，抵消了 Q-learning 的过估计偏差。

并且论文紧接着给出了适用边界：如果把分布的支撑范围扩大，double Q-learning 的重要性可能会上升。

因此，「在 Rainbow 里 Double 没用，是因为分布学习本身消除了过估计」这个流传较广的说法并不准确。准确的表述是三层：

其一，起作用的是支撑有界这个事实（\([-10, 10]\) 的截断），而不是「学分布」本身；
其二，论文用的是假设（hypothesize）的措辞，不是已证结论；
其三，论文明确说扩大支撑后 Double 的重要性可能回升——也就是说这个「没用」是特定配置下的现象，不是普遍结论。

过估计本身的机理见子页①，分布支撑的设定见子页⑤。

数据效率

论文强调组合带来的提升同时体现在数据效率与最终性能两方面。以 57 个游戏的中位人类归一化性能计：

里程碑 论文 Figure 1 的结果
追平 DQN 的最佳中位性能 700 万帧
超过图中所有比较基线的最佳中位性能 4400 万帧
2 亿帧训练后的最终表现 论文报告相对这些历史基线有大幅提升

Figure 1 的曲线是 57 个游戏的人类归一化中位数，并做了 5 点移动平均。700 万与 4400 万是这张聚合曲线上的历史比较，不是所有游戏逐一达到同一门槛，也不是对任意硬件、代码库或现代基线的速度保证。论文还报告：单 GPU 上 700 万帧少于 10 小时，2 亿帧约 10 天；作者明确指出跨不同并行度和硬件比较墙钟时间并不直接公平。

最终评估使用最佳快照：Rainbow 在 no-op starts 与 human starts 下的中位人类归一化分数分别为 223% 和 153%。表中部分带星号的基线来自各自论文，其余是作者重跑；因此“超过基线”应连同来源差异一起解读。

专题收尾

到这里，DQN 改进专题的七个子页齐了。把它们放在一起看，有三条贯穿性的判断：

  1. 各项改进主要作用在不同接口，但并非彼此独立或互不影响。 Double 改自举动作，Dueling 改网络头，PER 改采样分布，多步改回报目标，C51 改学习对象，NoisyNet 改探索；它们可以模块化组合，却会通过目标分布、优先级和有限支撑发生交互。
  2. 组合需要明确契约。 PER 用分布损失定义优先级，Dueling 在每个原子的 logit 上聚合，Double 进入分布目标的自举动作选择，多步目标再投影到固定支撑；NoisyNet 还要求显式管理噪声采样。超参数也需重新校准，例如优先级指数从 PER 原论文的 0.6 变为 Rainbow 的 0.5。
  3. 消融是有条件的边际证据。 Dueling 与 Double 在这套配置的中位聚合结果中边际影响较小，但逐游戏仍有正负变化；PER 与多步最关键也只是该协议中的实证结论。判断组件是否保留，应结合任务、支撑范围、计算预算、随机种子和交互消融重新验证。

后续方向（本专题不展开）：沿分位数参数化的 QR-DQN 与 IQN 换了一条路来做分布型强化学习；R2D2 与 Ape-X 则把重点移到了分布式采集与循环网络上。
